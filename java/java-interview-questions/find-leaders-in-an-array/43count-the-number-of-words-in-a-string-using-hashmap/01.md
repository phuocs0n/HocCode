## Thought Process

Suppose we have to count the number of words in the following string.

```java
text = it was an amazing amazing amazing day
```

We will first split it into an array of words using split() method using a space as a delimiter.

```java
words = {"it" "was" "an" "amazing" "amazing" "amazing" "day"}
```

Now, we will use HashMap to count the number of words in the string because it allows us to store each character as a key in the HashMap and its count as the corresponding value.

We will loop through each string in the words array and check whether it exists in the HashMap. If it does, we would increment its value by 1. Otherwise, we would add it to the HashMap with a value of 1.

| Charcter | Count |
| --- | --- |
| it | 1 |
| was | 1 |
| an | 1 |
| amazing | 3 |
| day | 1 |

Here, we have the count each of word in the text string.

Now, let's see how we can implement this logic in our program for text string.

- Split the text into an array of words using the split() method with space as the delimiter.
- Create a new HashMap object to store the word count.
- Loop through each word in the array using a for-each loop.
- Check if the word already exists in the HashMap using the containsKey() method.
- If the word exists, increment its count using the get() method and update it in the HashMap using the put() method.
- If the word does not exist, add it to the HashMap with a count of 1 using the put() method.
- After looping through all the words, print the final HashMap.
