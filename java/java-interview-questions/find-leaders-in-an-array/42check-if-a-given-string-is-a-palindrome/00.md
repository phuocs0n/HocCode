## Question

Write a Java program to check if a given string is a palindrome after converting it to lowercase and removing all spaces and special characters.

A string is said to be a palindrome if it reads the same backwards as forwards i.e, from left to right and right to left. For example,

```java
text = "A man, a plan, a canal, Panama!"
output = true
reason = "amanaplanacanalpanama" is a palindrome as it reads the same from left to right and right to left
```

```java
text = "Was it a car or a cat I saw?"
output = true
reason = "wasitacaroracatisaw" is a palindrome as it reads the same from left to right and right to left
```

```java
text = "Hello, world!"
output = false
reason = "helloworld" is not a palindrome as it does not read the same from left to right and right to left
```
