## Question

Suppose you are given an array of numbers and a target value. Write a Java program to find all the combinations of list elements whose sum equals the target value. For example,

```java
numbers = [2, 7, 11, 15]
target = 9

output: [2, 7]
```

```java
numbers = [2, 7, 11, 15]
target = 22

output: [7, 15]
```

```java
numbers = {2, 3, 4, 5, 6}
target = 9

output = [5, 4]
```
