## Thought Process

Suppose we have the following array and a target value:

```java
numbers = [2, 7, 11, 15]
target = 9
```

To find the elements that add up to the target value, we will check if the array contains the target - element. This is because adding two elements, a and b, gives the result t, then subtracting one element from the result gives another element:

```java
a + b = t
t - a = b
t - b = a
```

Subtracting target with element will give us the value of the other number that adds up to the target value:

```java
9 - 2 = 7
```

Since 7 is in the array numbers, we have found the combination that adds up to the target value.

Here are the steps to solve this problem:

- Create an empty temporary list temp.
- Loop through each element in the original array numbers.
- For each element num in numbers, check if the difference between the target value and num is in the temporary list temp. If it is, then return an array containing num and target - num, as these are the two numbers in the array that add up to the target value.
- If the difference is not in the temporary list, add num to the temporary list.
- If no combination of two numbers in the array add up to the target value, return -1, -1.
