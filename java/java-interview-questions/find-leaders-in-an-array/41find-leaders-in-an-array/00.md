## Question

Find all the leaders in a non-empty array of integers and print them.

Leaders in an array: An element is called a leader if it is greatest rightmost element in an array.

```java
array = {16, 17, 4, 3, 5, 2}, 
output: [17, 5, 2]
reason = 17 and 5 is greater than all the elements to its right side, 2 is the right most element
```

```java
array = {23, 43, 5, 6, 7} 
output:[7, 43]
reason = 43 is greater than all the elements to its right side, 7 is the right most element
```

```java
array = {2, 1, 45, 567, 6}
output: [6, 567]
reason = 567 is greater than all the elements to its right side, 6 is the right most element
```
