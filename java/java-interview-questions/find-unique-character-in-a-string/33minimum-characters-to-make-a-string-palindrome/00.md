## Question

Given a non-empty string text, find the minimum number of characters to be added to the front to make name a palindrome. For example,

```java
text = joe
output = 2
reason = adding 2 characters e and o at the beginning makes text palindrome
```

```java
text = racecarr
output = 1
reason = adding 1 character r at the beginning makes text palindrome
```

```java
text = refers
output = 1
reason = adding 1 character s at the beginning makes text palindrome
```
