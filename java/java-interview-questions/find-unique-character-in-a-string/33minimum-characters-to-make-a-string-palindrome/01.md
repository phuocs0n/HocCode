## Thought Process

Suppose we have the following string to find the minimum number of characters that need to be added to make it a palindrome.

```java
text = pepsi
```

We will check if the text is palindrome or not.

As pepsi is not palidrome, we will now check the text is palindrome up to the second last character.

And set our counter to 1.

```java
text = peps
```

As peps is not palindrome, we will again remove the last character and check if the string is palindrome.

```java
text = pep
```

As pep is palindrome, we now know that if we add s and i at the beginning of the text, the text will become palindrome. Hence, we must add 2 characters to make the text palindrome.

Now, let's see how we can implement this logic in our program for a string variable text.

1. Declare an integer variable counter and initialize it to 0.
2. Use a while loop to check if the length of the input string text is greater than 0.
3. Inside the loop, check if the input string text is a palindrome using the isPalindrome() method.
4. If text is a palindrome, break out of the loop.
5. If text is not a palindrome, delete the last character of text using the substring method, and increase the counter variable by 1.
6. Return the counter variable when the loop is finished.
