## Thought Process

Here's a thought process of how we will find a missing number in a sequence of natural number.

Suppose

```java
array = {1, 2, 4, 5}
```

To find the missing number, we first need to find the sum all numbers of the array.

```java
sum of numbers of array 1 + 2 + 4 + 5 = 12
```

Next, we need to determine the expected sum of all the numbers in the sequence if there were no missing numbers.

Since there are four elements in the array, and one number is missing, there should be 4 + 1 = 5 elements in the sequence.

We then need to find the sum of natural numbers from 1 to 4 + 1.

```java
sum of n natural numbers = n * (n+1)/2
sum of 5 natural numbers = 15
```

Now,

```java
missing number = sum of natural numbers - sum of numbers in array
               = 15 - 12
               = 3
```

To solve this problem:

- Create a variable named sumOfCurrentArray and initialize it to zero.
- Use a for loop to iterate through each element in the array:
- Inside the loop, add the current element to sumOfCurrentArray.
- Create a variable named n and initialize it to the length of the input array + 1.
- Create a variable named sumOfSequence and calculate it as n * (n+1)/2.
- Create a variable named missingNumber and calculate it as sumOfSequence - sumOfCurrentArray.
