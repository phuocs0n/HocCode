## Thought Process

To find whether the number is Armstrong or not, we first need to find the number of digits in that number. Then we will check if the sum of the digits raised to the power of the number of digits.

Let's take the example of the number 371 to check if it is an Armstrong number or not:

First, we need to find the number of digits in the number. We can do this by repeatedly dividing the 371 by 10 until the quotient becomes 0. In this case, we would divide 371 as follows:

```java
371 / 10 = 37
37 / 10 = 3
3 / 10 = 0
```

We divided 3 times, so the number of digits is 3.

Next, we need to check if the number is an Armstrong number. To do this, we can start from the rightmost digit (which is 1 in this case) and take its cube (since there are 3 digits). We then add this value to a sum.

```text
sum=13=1\text{sum} = 1^3 = 1sum=13=1
```

We then remove the rightmost digit by dividing the number by 10, and repeat the previous step until the number becomes 0.

```text
371 / 10=37371 \ / \ 10 = 37371 / 10=3737 % 10=737 \ \%  \ 10 = 737 % 10=7sum=1+73=344\text{sum} = 1 + 7^3 = 344sum=1+73=344
```

```text
37 / 10=337\  /  \ 10 = 337 / 10=33 % 10=33 \ \% \ 10 = 33 % 10=3sum=344+33=371\text{sum} = 344 + 3^3 = 371sum=344+33=371
```

```text
3 / 10=03 \ / \ 10 = 03 / 10=0
```

Finally, we compare the sum with the original number. If they are equal, then the number is an Armstrong number, otherwise it is not. In this case, since the sum is 371 and the original number is 371, we can conclude that 371 is an Armstrong number.
