## Question

Find whether a given positive integer is an armstrong number or not.

A positive integer is called an Armstrong number if the sum of the digits raised to the power of the number of digits is equal to the original number. For example,

```java
number = 1634
output = Armstrong
reason = 14 + 64 + 34 + 44 = 1634 
(4 is the number of digits)
```

```java
number = 370
output = Armstrong
reason = 33 + 73 + 03 = 370
(3 is the number of digits)
```

```java
number = 9
output = Armstrong
reason = 91 = 9
(1 is the number of digit)
```

```java
number = 250
output = Not Armstrong 
reason 23 + 53 + 03 != 250
(3 is the number of digits)
```
