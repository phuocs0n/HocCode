## Thought Process

To reverse a string, we need to access each character of the string from the last to the first and assign those characters in a new string.

Let's see a detailed overview of how we can reverse a string.

- Create a new empty string to store the reversed input string.
- Iterate through each character of the input string from the end to the beginning. For this, we can convert the given string to an array using the toCharArray() method and then loop through the array.
- Inside the loop, add characters from the input string to the new string so that the last character will be the first for the new string, and so on.
- Finally, print the new string which now has the reversed string.
