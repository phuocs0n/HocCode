## Thought Process

To count the number of capital letters in a string, check if a character is uppercase, and if it is we will count it.

Let's see a detailed overview of how to solve this problem.

1. Convert the string into a character array using the CharArray() method. This will make it easier to work with the individual characters of the string.
2. Initialize a counter variable named count to 0. This will keep count of the number of capital letters.
3. Use a for loop to loop through the character array. Inside the loop, use the isUpperCase() method to check if the character is in uppercase. If true, increase count by 1.
4. Finally, print count.
