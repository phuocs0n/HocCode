## Thought Process

To solve this problem, toggle the case of each character and add it to a new string.

Let's see a detailed overview of how to solve this problem.

Suppose we are toggling the case of the text string.

- Initialize an empty string toggledString to add the toggled string.
- Loop through each character in the text string.
- Check whether text is an uppercase character or not using an if statement.
- If the character is uppercase, convert it to lowercase using the toLowerCase() method and add it to toggledString.
- If the character is not uppercase, convert it to uppercase using the toUpperCase() method and add it to toggledString.
