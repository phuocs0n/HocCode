## Thought Process

To solve this problem, recursively add preceding two numbers of n.

Let's see a detailed overview of how to solve this problem.

- Create a base case. If n is 0 or 1. Return n.
- Create a recursive case. In each recursive call, return the sum of (n - 1)th and (n - 2)th.
