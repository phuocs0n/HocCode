## Question

Write a program to find the nth fibonacci number.

Fibonacci Numbers are a series of numbers in which each number is the sum of two preceding numbers.

For example,

```java
Fibonacci sequence: 0, 1, 1, 2, 3, 5, 8
```

Here,

```java
0th fibonacci number: 0
1st fibonacci number: 1
2nd fibonacci number: 1 (0th fibonacci number + 1st fibonacci number)
3rd fibonacci number: 2 (2ndfibonacci number + 3rd fibonacci number)
.
.
nth fibonacci number: (n-2)th fibonacci number + (n-1)th  fibonacci number
```

You need to find the nth fibonacci number. For example,

```java
n = 5
output = 5
reason = 3rd fibonacci number (2) + 4th fibonacci number (3) = 5
```

```java
n = 6
output = 8
reason = 4th fibonacci number (3) + 5th fibonacci number (5) = 8
```

```java
n = 19
output = 4181
reason = 17th fibonacci number (1597) + 18th fibonacci number (2584) = 5
```
