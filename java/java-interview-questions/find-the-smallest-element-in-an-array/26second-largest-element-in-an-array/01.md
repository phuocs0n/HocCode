## Thought Process

To solve this problem, we need to find the second largest number, we need to iterate through the array, and keep track of the largest and second largest numbers.

Let's see a detailed overview of how we can solve this problem.

- Initialize two variables: largest and secondLargest with the first and second elements of the array, such that the largest variable should contain the larger element among the first and second elements.
- Iterate through the rest of the array elements in the array.
- Compare each element of the array (excluding the first and second), with largest and secondLargest variables.
- If the element is greater than largest, assign largest to secondLargest and the element to largest.
- If the element is greater than the current value of secondLargest, but less than the current largest, assign the element to secondLargest.
- Once the loop ends, return the value of secondLargest as the result of the method.
