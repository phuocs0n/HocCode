## Thought Process

To check if a given string is an anagram, check if both strings have same set of characters.

Let's see a detailed overview of how to solve this problem.

- First convert the given two strings to char arrays using the toCharArray() method
- Sort the char arrays using the Arrays.sort() method.
- Check if the sorted char arrays are equal using the Arrays.equals() method.

If the two character arrays are equal, it means the two strings are anagrams, else they are not.
