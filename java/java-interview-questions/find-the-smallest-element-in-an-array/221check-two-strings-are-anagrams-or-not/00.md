## Question

Given two non-empty strings. Write a program to check whether the two strings are anagrams or not. If they are anagrams print "Anagram" else print "Not Anagrams".

Anagrams are those strings that have the same characters occurring an equal number of times in both the strings. For example

```java
text1 = listen
text2 = silent
output = Anagram
reason = both text same set of characters
```

```java
text1 = night
text2 = thing
output = Anagram
reason = both text same set of characters
```

```java
text1 = rice
text2 = nice
output = Not Anagram
reason = both text don't same set of characters
```
