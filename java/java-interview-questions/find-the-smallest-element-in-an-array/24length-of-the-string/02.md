## Thought Process

To find the length of a string, we can iterate through the string and count the number of characters in it.

Let's see a detailed overview of how to find the length text string.

- Assign 0 to the count variable, which counts the number of characters in the string.
- Convert the string to a character array using the toCharArray() method to simplify iterating through characters.
- Using a for loop, iterate through each character in the character array.
- In each iteration of the loop, increase the counter variable by 1.
- Finally, after the loop, the value of the counter variable will have the length of the string.
- Print the value of the counter variable, which represents the length of the string.
