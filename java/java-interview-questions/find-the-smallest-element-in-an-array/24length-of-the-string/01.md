## Question

Write a Java program to find the length of the string without using the length() method. For example,

```java
text = "Jump"
output = 4
reason = There are 4 letters in Jump.
```

```java
text = "Smooth"
output = 6
reason = There are 6 letters in Smooth.
```

```java
text = "SKY"
output = 3
reason = There are 3 letters in Sky.
```
