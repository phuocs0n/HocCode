## Thought Process

To separate 0's and 1's from an array, count the number of 0's in it, create a new array of the same size, fill the first count positions in the new array with 0's and the remaining positions with 1's.

Let's see a detailed overview of how to solve this problem.

- Traverse the array and count the number of 0's. Let's say the count is stored in a variable called count.
- Calculate the number of 1's in the array as array.length - count.
- Create a new array of the same size as the input array to store the output.
- Fill the first count positions in the new array with 0's.
- Fill the remaining positions in the new array with 1's.
- Return the new array.
