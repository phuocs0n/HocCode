## Question

Given an non-empty array of integer numbers, write a program to separate even numbers and odd numbers from the array.

Make two ArrayList: evenNumbers and oddNumbers and add even numbers and odd numbers to those lists respectively. For example,

```java
numbers = {1, 2, 3, 4, 5, 6}

Output 


even numbers = [2, 4, 6]
odd numbers = [1, 3, 5]
```

```java
numbers = {222, 33, 11, 22, 41, 2}

Output 


even numbers = [222, 22, 2]
odd numbers = [33, 11, 41]
```

```java
numbers = {32, 11, 22, 31, 22, 11}

Output 


even numbers = [32, 22, 22]
odd numbers = [11, 31, 11]
```
