## Thought Process

To find the total number of vowels in a non-empty string, we can iterate through the string and count the number of vowels present by checking if each character is a vowel or not.

Let's see a detailed overview of how to find the total number of vowels in the text string.

- Convert the given string to lowercase using toLowerCase(). This is to avoid checking vowels for both uppercase and lowercase characters.
- Access each character of the converted string using a loop and charAt() method. For example, charAt(0) will give the first character of the string at index 0.
- Compare each character to lowercase vowels.
- Use a counter variable to record the number of vowels based on the above comparison.
