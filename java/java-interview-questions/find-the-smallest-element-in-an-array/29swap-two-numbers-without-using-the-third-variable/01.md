## Thought Process

To solve this problem, without using a third variable, you will use arithmetic operators + and -.

Let's see a detailed overview of how you can solve this problem.

Suppose, number1 = 5 and number2 = 6.

- Add the values of number1 and number2 and store it in number1. Now, number1 will have the sum of both values. (5 + 6 = 11)
- Now, assign the original value of number1 to number2. For that subtract number1 and number2 and assign it to number2. Now, 11 - 6 = 5 (original value of number1) will get assigned to number2.
- Now, assign the original value of number2 to number1. For that subtract number1 and number2. Now, 11 - 5 = 6 (original value of number2) will get assigned to number1.
