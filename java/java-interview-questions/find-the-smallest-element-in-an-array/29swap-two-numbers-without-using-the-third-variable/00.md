## Question

You are given two numbers number1 and number2. Write a Java program to swap these two numbers without using a third variable. For example,

```java
number1 = 5
number2 = 6

Output
number1 = 6
number2 = 5
```

```java
number1 = 11
number2 = 22

Output
number1 = 22
number2 = 11
```

```java
number1 = 88
number2 = 22

Output
number1 = 22
number2 = 88
```
