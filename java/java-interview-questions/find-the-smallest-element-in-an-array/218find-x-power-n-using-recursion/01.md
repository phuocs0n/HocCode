## Thought Process

To find x to the power n using recursion, multiply x and x, n times.

Let's see a detailed overview of how to solve this problem recursively.

- Create a recursive function, that takes parameters x and n.
- If n is 0, the return 1, as any number raised to the power of 0 is 1.
- If n is greater than 0, calculate the result of x raised to the power of n-1 by calling itself recursively with x and n-1 as arguments, and then multiply the result by x.
