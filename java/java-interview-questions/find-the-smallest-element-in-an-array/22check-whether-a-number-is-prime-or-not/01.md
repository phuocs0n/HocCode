## Question

Write a Java program to take an integer input and check whether it is prime or not. If the number is prime print Prime else print Not Prime.

Prime numbers are numbers that are only divisible by 1 and itself. For example,

```java
number = 2
output = Prime
reason = 2 is only divisible by 2 and 1
```

```java
number = 11
output = Prime
reason = 11 is only divisible by 11 and 1
```

```java
number = 4
output = Not Prime
reason = 4 is divisible by 4, 2, and 1
```
