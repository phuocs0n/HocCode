## Thought Process

To check if a string is a palindrome, compare the characters at opposite ends of the string, and finally, return true if all the characters match.

Let's see a detailed overview of how to solve this problem.

- Check if string is empty or has only one character. If so return true, as they are palidrome.
- Use a for loop to iterate over the first half of the characters in the string.
- Inside the loop, compare the character at the current index (suppose i) with the character at the opposite index( which is calculated using the length of the string as str.length() - i - 1).
- If all the characters are the same in both positions, then the string is a palindrome. If any of the characters are different, then the string is not a palindrome.
