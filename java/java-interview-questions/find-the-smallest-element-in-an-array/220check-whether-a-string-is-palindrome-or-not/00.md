## Question

Given a string, write a program to check whether the string is a palindrome or not. If the string is a palindrome print true, if not print false.

Palindrome - a word, that reads the same backward as forward.

```java
text = "pop"
output = true
reason = is read same forward and backwards
```

```java
text = "radar"
output = true
reason = is read same forward and backwards
```

```java
text = "love"
output = false
reason = is not read same forward and backwards
```

```java
text = ""
output = true
reason = empty string is read same forward and backwards
```

```java
text = "s"
output = true
reason = single character is read same forward and backwards
```
