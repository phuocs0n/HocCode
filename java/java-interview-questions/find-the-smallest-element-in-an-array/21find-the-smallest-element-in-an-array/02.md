## Thought Process

To find the smallest element in an array, we initially assume that the first element is the smallest.

We then compare the first element with the rest of the array elements and update our assumption when we find an even smaller element.

After looping through all the array elements, the assumed smallest element will be our answer.

Let's see a detailed overview of how to find the smallest element in the numbers array.

- Assign the first element of the numbers array to the min variable.
- Using a for loop, iterate through each element of the array.
- Inside the for loop, use the if statement compares min with every value of the array.
- Assign the array element to min if the array element is equal to or less than min. By the end of the iteration, we will have a minimum value in the min variable.
- Print the min variable.
