## Thought Process

To find the index of the first occurrence, we will check each element of the array from the first index, and to find the last occurrence of an element inside the array, check each element of the array from the last index till we find the element.

Let's see a detailed overview of how to solve this problem.

- Initialize two integer variables called firstOccurrence and lastOccurrence to -1 to store the indices of the first and last occurrences of the element.
- Iterate through the array using a for loop. For each element in the array, compare it to the element parameter. If the element is equal to element, store the index in the firstOccurrence variable and exit the loop using the break keyword.
- Iterate through the array again, this time starting from the end and going backwards. For each element in the array, compare it to the element parameter. If the array element is equal to element parameter, store the index in the lastOccurrence variable and exit the loop using the break keyword.
