## Thought Process

To reverse an array without using the reverse() method, iterate over the array in reverse order, copy the elements from the original array to a new array in reverse order.

Let's see a detailed overview of how to solve this problem

- Create a new empty array with the same length as the original array. This array will be used to store the elements in the reverse order of the original array.
- Initialize a counter variable j to 0 that is used to keep track of the current index in the new array.
- Using a for loop, iterate through the original array in reverse order, starting from the last element and ending at the first element.
- Inside the loop, for each element in the original array, add it to the corresponding position in the new array.
