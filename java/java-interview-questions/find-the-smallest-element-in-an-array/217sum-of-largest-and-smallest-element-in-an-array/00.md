## Question

Given an non-empty array of numbers. Find the sum of the largest and smallest number in that array. For example,

```java
array = {3, 4, 5, 8, 1, 2}
output = 9
reason = sum of largest (8) and smallest (1) number is 9
```

```java
array = {22, 33, 44, 55, 66, 33}
output = 88
reason = sum of largest (22) and smallest (66) number is 88
```

```java
array = {21, 23, 34, 546, 67, 77}
output = 567
reason = sum of largest (546) and smallest (21) number is 567
```
