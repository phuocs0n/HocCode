## Sum of Array Elements

Remember this code to find the sum of array elements.

```java
1class Main {
2    public static void main(String[] args) {
3        
4        // Create double array
5        double[] numbers = {13.55, 81.19, 31.6, -44.8};
6        
7        // Initial total
8        double total = 0;
9        
10        // Access array elements using the for loop
11        for (int index = 0; index < 4; ++index) {
12            // Add each element to total
13            total = total + numbers[index];
14        }
15        
16        // Print total
17        System.out.println("Total: " + total);
18    }
19}
```

Output

```text
Total: 81.54
```

Now let's use the for-each loop instead of the for loop.

```java
1class Main {
2    public static void main(String[] args) {
3        
4        // Create double array
5        double[] numbers = {13.55, 81.19, 31.6, -44.8};
6        
7        // Initial total
8        double total = 0;
9        
10        for (double number : numbers) {
11            total = total + number;
12        }
13        
14        // Print total
15        System.out.println("Total: " + total);
16    }
17}
```

Output

```text
Total: 81.54
```

Here, you can see we get the same output. However, the code using the for-each loop looks much cleaner.
