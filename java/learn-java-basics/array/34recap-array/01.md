Creating an Array

An array can only store data of similar types.

```java
1class Main {
2    public static void main(String[] args) {
3        
4        // Create an array
5        int[] primeNumbers = {2, 3, 5, 7};
6        
7        System.out.println("Prime Numbers:");
8        for(int index = 0; index < primeNumbers.length; ++index) {
9            System.out.println(primeNumbers[index]);
10        }
11    }
12}
```

Here, primeNumbers.length returns the size of the array.

Getting Array Input

We use the Scanner class to take input values for an array.

```java
1import java.util.Scanner;
2
3class Main {
4    public static void main(String[] args) {
5        
6        Scanner input = new Scanner(System.in);
7        
8        // Create an array
9        int[] primeNumbers = new int[4];
10        
11        System.out.println("Enter 4 prime numbers:");
12        for (int index = 0; index < primeNumbers.length; ++index) {
13            primeNumbers[index] = input.nextInt();
14        }
15        
16        System.out.println("Prime Numbers:");
17        for(int index = 0; index < primeNumbers.length; ++index) {
18            System.out.println(primeNumbers[index]);
19        }
20
21        input.close();
22    }
23}
```
