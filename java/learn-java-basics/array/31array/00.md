## Array Introduction

So far, we have only used a variable to store a single data. As we begin writing more complex programs this becomes inefficient.

For example, if you need to store the age of 100 people, you'd need a hundred variables— a lengthy and tedious task.

Arrays solve this problem by allowing you to store multiple values of the same type in a single variable. So, instead of creating a hundred variables, we can create a single array and store the age of a hundred people together.

In this lesson, you'll learn to:

- Create an array
- Access elements of an array.
- Change the values of an array.

Let's start with creating an array.
