## Array Input Using for Loop

Here's how we can use a for loop to reduce redundancy in our previous code.

```java
1import java.util.Scanner;
2
3class Main {
4    public static void main(String[] args) {
5        
6        // Create object of Scanner
7        Scanner input = new Scanner(System.in);
8        
9        int[] numbers = new int[4];
10        
11        System.out.println("Enter Array Elements: ");
12        for (int index = 0; index < numbers.length; ++index) {
13            numbers[index] = input.nextInt();
14        }
15        
16        // Access array elements
17        System.out.println("Array Elements:");
18        for (int index = 0; index < numbers.length; ++index) {
19            System.out.println(numbers[index]);
20        }
21        
22        input.close();
23    }
24}
```

Output

```text
Enter Array Elements: 
21
22
23
24
Array Elements:
21
22
23
24
```

Here's how the code works in each iteration of the loop

| index | numbers[index] = input.nextInt(); |
| --- | --- |
| 0 | assigns 21 at index 0 |
| 1 | assigns 22 at index 1 |
| 2 | assigns 23 at index 2 |
| 3 | assigns 24 at index 3 |

When the value of index is 4, the condition index < numbers.length becomes 4 < 4, which is false. Hence, the loop terminates.
