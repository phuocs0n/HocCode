## Finding Sum of Array Elements

In this example, we/l create an array of size 5. Here, we/ll take input values for the array elements and find the sum of all the elements.

```java
1import java.util.Scanner;
2
3class Main {
4    public static void main(String[] args) {
5        
6        // Create object of Scanner
7        Scanner input = new Scanner(System.in);
8        
9        int[] numbers = new int[5];
10        
11        System.out.println("Enter Array Elements:");
12        for (int index = 0; index < numbers.length; ++index) {
13            numbers[index] = input.nextInt();
14        }
15        
16        int total = 0;
17        
18        // Add all array elements
19        for (int index = 0; index < numbers.length; ++index) {
20            total = total + numbers[index];
21        }
22        
23        System.out.println("Sum: " + total);
24        
25        input.close();
26    }
27}
```

Output

```text
Enter Array Elements:
10
20
30
40
50
Sum: 150
```

In the above example, we have created a for loop to take input values for the array.

```java
for (int index = 0; index < numbers.length; ++index) {
    numbers[index] = input.nextInt();
}
```

We then used a second for loop to find the sum of all the array elements.

```java
for (int index = 0; index < numbers.length; ++index) {
    total = total + numbers[index];
}
```
