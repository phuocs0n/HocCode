# Getting Array Input

#### Course: Learn Java Basics

## Getting Array Input

Like with variables, you can take input from the users to assign values to your array.

Like before, you must first import the scanner class.

```java
import java.util.Scanner;
```

Then, you must create a Scanner object as:

```java
Scanner input = new Scanner(System.in);
```

Then, we can also create input values for each array element using input.nextInt().

Let's see an example.

```java
1import java.util.Scanner;
2
3class Main {
4    public static void main(String[] args) {
5        
6        // Create object of Scanner
7        Scanner input = new Scanner(System.in);
8        
9        int[] numbers = new int[4];
10        
11        System.out.println("Enter the first element: ");
12        numbers[0] = input.nextInt();
13        
14        System.out.println("Enter the second element: ");
15        numbers[1] = input.nextInt();
16        
17        System.out.println("Enter the third element: ");
18        numbers[2] = input.nextInt();
19        
20        System.out.println("Enter the fourth element: ");
21        numbers[3] = input.nextInt();
22        
23        // Access array elements
24        System.out.println("Array Elements:");
25        for (int index = 0; index < numbers.length; ++index) {
26            System.out.println(numbers[index]);
27        }
28
29        input.close();
30    }
31}
```

Output

```text
Enter the first element:
21
Enter the second element: 
22
Enter the third element: 
23
Enter the fourth element: 
24
Array Elements:
21
22
23
24
```

Here, each array element, numbers[index], acts as an individual variable and we are getting input value for each of the array elements.

Also, we are repeating a similar code to take input value.

```java
numbers[index] = input.nextInt();
```

Naturally, we'll replace this with a for loop which we'll cover next.
