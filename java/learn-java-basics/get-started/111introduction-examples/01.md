# Convert Kilometers to Miles

#### Course: Learn Java Basics

## Convert Kilometers to Miles

The relation between a kilometer and miles is:

```java
1 kilometer = 0.621 miles
```

#### Example

```java
1// Program to convert distance in kilometer to miles
2// The distance will be entered by the user
3
4import java.util.Scanner;
5
6class Main {
7    public static void main(String[] args) {
8
9        Scanner input = new Scanner(System.in);
10
11        double conversionRatio = 0.621;
12
13        // Take distance input from the user
14        System.out.println("Enter distance in km: ");
15        double km = input.nextDouble();
16
17        // Compute distance in miles
18        double miles = km * conversionRatio;
19        System.out.println("Distance in Miles: " + miles);
20
21        input.close();
22    }
23}
```

Output

```text
Enter distance in km: 
33
Distance in Miles: 20.493
```

Here's how this program works.

In line 15: double km = input.nextDouble();

We are taking distance input in km from the user and storing it in the km variable.

In line 18: double miles = km * conversionRatio;

We then calculate the distance in miles by multiplying the distance in km by 0.621.
