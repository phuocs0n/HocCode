## Taking Input From the User

Now you can access the nextInt() property through the input object using the dot(.) operator. input.nextInt(). For example,

```java
1import java.util.Scanner;
2
3class Main {
4    public static void main(String[] args) {
5        
6        System.out.println("Enter your age: ");
7        
8        // Create a Scanner object
9        Scanner input = new Scanner(System.in);
10        
11        // Take user input 
12        int age = input.nextInt();
13        
14        System.out.println("Age is " + age);
15
16    }
17}
```

Now, the program prints Enter your age: and then waits for the user to enter data.

Let us type 25 and press the ENTER key.

Output

```text
Enter your age:
25
Age is 25
```

As you can see, 25 is assigned to the age variable and printed on the screen.

Go ahead and try different input values and see the output.
