#### Course: Learn Java Basics

## Importing Scanner Class

To take a user input, you must first import the Scanner class.

```java
import java.util.Scanner;
```

Let's see an example.

```java
1import java.util.Scanner;
2
3class Main {
4    public static void main(String[] args) {
5        
6        System.out.println("Enter your age: ");
7    }
8}
```

Output

```text
Enter your age:
```

As of now, the Scanner class contributes nothing to our code. This is because to use the properties within the class, we need to create an object first.
