# Creating an object of Scanner Class

#### Course: Learn Java Basics

## Creating an object of Scanner Class

The Scanner class contains properties like nextInt() that allow us to ask the user for an integer input.

Naturally, to use these properties, you must first create a Scanner object as:

```java
Scanner input = new Scanner(System.in);
```

Let's see an example.

```java
1import java.util.Scanner;
2
3class Main {
4    public static void main(String[] args) {
5        
6        System.out.println("Enter your age: ");
7        
8        // Create a Scanner object
9        Scanner input = new Scanner(System.in);
10                
11    }
12}
```

Output

```text
Enter your age:
```

Creating the object alone makes no change to our output, but now we can use this to access the actual property within the class that allows us to take user input.
