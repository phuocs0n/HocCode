# Closing the Scanner

#### Course: Learn Java Basics

## Closing the Scanner

Once we have completed the process of taking input, we close it using

input.close()

This is not mandatory, but it is a good practice to make your code more readable.

Let's combine all the steps.

```java
1import java.util.Scanner;
2
3class Main {
4    public static void main(String[] args) {
5        
6        System.out.println("Enter your age: ");
7        
8        // Create a Scanner object
9        Scanner input = new Scanner(System.in);
10        
11        // Take user input 
12        int age = input.nextInt();
13        
14        System.out.println("Age is " + age);
15
16       // Close the Scanner
17        input.close();
18    }
19}
```

Output

```text
Enter your age:
25
Age is 25
```
