## Printing Multiple Strings

We can print multiple strings together using the + operator. Let's see an example.

```java
1class Main {
2    public static void main(String[] args) {
3
4        System.out.println( "camel" + "Case" );
5    }
6}
```

Output

```text

```

Here, the + operator joins "camel" and "Case" and prints it.
