## Printing Spaces

When working with strings, we often need to add spaces in between two strings. This can be done by explicitly adding a space within quotation marks " " and joining the strings using the + operator.

```java
1class Main {
2    public static void main(String[] args) {
3
4        System.out.println("Hello," + " " + "How are you?");
5    }
6}
```

Output

```text
Hello, How are you?
```

In this example, the spaces are added explicitly between the strings using " ".

Alternatively, the same output can be achieved by incorporating the spaces directly within the string.

```java
1class Main {
2    public static void main(String[] args) {
3
4        System.out.println("Hello, " + "How are you?");
5    }
6}
```

Output

```text
Hello, How are you?
```

Here, we have added space at the end of Hello, eliminating the need to add extra " ".
