## Classes in OOP

In Object-Oriented Programming (OOP), a class is a container for all the logic we use in a program. It is a fundamental concept, and you've likely been using classes without realizing it.

In fact, every Java program you've written so far has included at least one class. Here's a quick look at how a typical Java program is structured using a class:

```java
class Main {
    public static void main(String[] args) {
        // Code goes here
    }
}
```

The first line, class Main, defines a class named Main.

We'll soon see more examples, but for now, remember that everything in Java revolves around classes. Now, let's learn about objects.
