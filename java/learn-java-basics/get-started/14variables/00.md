## Introduction to Variables

In our previous lessons, you learned about numbers and texts and how to print them.

As you begin working on more complex programs, you'll need to store and reuse this data, not just print it. That's where variables come in.

A variable acts as a container for storing data that you can use and modify throughout your program.

In this lesson, you'll learn to

- Create variables
- Assign data to variables
- Print variables

Let's start with creating variables.
