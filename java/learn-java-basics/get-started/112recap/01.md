## Recap (I)

Data types

We started by learning different types of data:

- Integers: 5, 100
- Doubles: 123.4, 0.9
- Characters: 'a', '+'
- Strings: "Hello", "123"

Variables

To reuse these data later in the program, you can store them in variables. A variable will store data of a specific type.

```java
1class Main {
2    public static void main(String[] args) {
3 
4        int age= 19;
5        double salary= 6300.0;
6
7        // Print the variables  
8        System.out.println(age);         // Output: 19
9        System.out.println(salary);    // Output: 6300.0 
10
11    }
12}
```

Operators

If you need to perform calculations on the values or variables, use operators.

```java
1class Main {
2    public static void main(String[] args) {
3 
4        int divisor = 4;
5        int dividend = 13;
6
7        int quotient = dividend / divisor;
8        int remainder = dividend % divisor;
9
10        System.out.println(quotient);       // Output: 3
11        System.out.println(remainder);   // Output: 1 
12    }
13}
```
