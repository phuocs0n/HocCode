## Recap (II)

Take input

Instead of hardcoding the values yourself, you can also take the input from the user. For this you need to import the Scanner class.

```java
1// Import Scanner Class
2import java.util.Scanner;
3
4class Main {
5    public static void main(String[] args) {
6        
7        System.out.println("Enter a number: ");
8
9        // Create a Scanner Object       
10        Scanner input = new Scanner(System.in);
11
12        // Take User Input
13        int number = input.nextInt();
14        
15        System.out.println("You entered " + number);
16
17        // Close the Scanner
18        input.close();
19    }
20}
```

Data conversion

The data you are trying to use may not always be in the required format. In such situations, you need to perform data conversion.

```java
1class Main {
2    public static void main(String[] args) {
3      
4        // Create an int type variable
5        int number;
6      
7        // Assign double value to int
8        number = (int) 43.87;
9        System.out.println(number);   // Output: 43
10    }
11}
```
