## Java Comments

In Java, we use // (two forward slashes) to create comments. For example,

```java
1class Main {
2    public static void main(String[] args) {
3        
4        // Display a number
5        System.out.println(25);
6    }
7}
```

Output

```text
25
```

Here, // Display a number is a comment. Java completely ignores this line while running the program.

Therefore, the above program is equivalent to:

```java
1class Main {
2
3    public static void main(String[] args) {
4        System.out.println(25);
5    }
6}
```

Output

```text
25
```

Comments not only assist others in understanding your code but also serve as a helpful reference when you revisit it in the future. So, always use comments to highlight key details.
