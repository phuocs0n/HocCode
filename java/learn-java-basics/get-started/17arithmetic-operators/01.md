## Arithmetic Operators

Let's look into operators that perform basic mathematical operations.

They are summarized in the table below:

| Operators | Syntax | Operations |
| --- | --- | --- |
| + | x + y | Addition |
| - | x - y | Subtraction |
| * | x * y | Multiplication |
| / | x / y | Division |
| % | x % y | Remainder after division (Modulo) |
