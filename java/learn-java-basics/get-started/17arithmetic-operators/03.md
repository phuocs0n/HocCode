## Perform Operations and Print

We can also perform the addition directly without using the extra variable. Let's see an example.

```java
1class Main {
2    public static void main(String[] args) {
3
4        int number1 = 10;
5        int number2 = 20;
6
7        // + adds values of two variables
8        System.out.println(number1 + number2); 
9    }
10}
```

Output

```text
30
```

Here, the System.out.println(number1 + number2) first computes the sum of number1 and number2. Then, the result is directly printed on the screen.
