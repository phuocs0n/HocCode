## + Operator

As we have seen from the last example, the + operator is used to add operands (values and variables).

```java
1class Main {
2    public static void main(String[] args) {
3
4        int number1 = 10;
5        int number2 = 20;
6
7        // + adds values of two variables
8        int sum = number1 + number2;
9        System.out.println(sum);
10    }
11}
```

Output

```text
30
```

Here, int sum = number1 + number2; first adds the values of number1 and number2. Then, the result is assigned to the sum variable.
