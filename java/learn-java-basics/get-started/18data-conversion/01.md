## Automatic Type Conversion

In Java, sometimes one data type is automatically converted to another type. Let's see an example.

```java
1class Main {
2    public static void main(String[] args) {
3        
4        // Create a double type variable
5        double number;
6        
7        // Assign int value to double
8        number = 9;
9        System.out.println(number);
10    }
11}
```

Output

```text
9.0
```

In the above example, we have created a double variable number. However, we have assigned an integer value 9 to it.

In this case, Java automatically converts the integer value 9 to a double value 9.0. That's why we get 9.0 as output.

This type of automatic type conversion is called Implicit Type Conversion.
