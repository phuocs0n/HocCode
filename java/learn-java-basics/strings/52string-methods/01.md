## String Methods

In programming, strings are one the most used data types. It's only natural then that Java comes with multiple inbuilt methods to handle them.

In this lesson, you'll learn about the following methods:

- length() - finds the length of the string
- charAt() - returns a character from the string
- concat() - joins two strings together
- equals() - compares two strings

Let's start with the length() method.
