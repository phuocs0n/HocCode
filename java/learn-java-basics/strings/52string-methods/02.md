## Finding the Length of a String

We use the length() method to find the length of a string. For example,

```java
1class Main {
2    
3    public static void main(String[] args) {
4        
5        String series = "Squid Game";
6        
7        // Find the length of string
8        int size = series.length();
9
10        System.out.println("String: " + series);
11        System.out.println("Length: " + size);
12    }
13}
```

Output

```text
String: Squid Game
Length: 10
```

Here, series.length() returns the length of the series string.
