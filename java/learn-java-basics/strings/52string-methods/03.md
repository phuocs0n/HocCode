## Finding the Longer String

Now, let's find out the longer string between the two strings.

```java
1class Main {
2    
3    public static void main(String[] args) {
4        
5        String first = "Learn Java";
6        String second = "Programiz Course";
7        
8        // Get length of both strings
9        int firstLength = first.length();
10        int secondLength = second.length();
11        
12        // Compare the length of strings
13        if (firstLength > secondLength) {
14            System.out.println(first);
15        }
16        else {
17            System.out.println(second);
18        }
19    }
20}
```

Output

```text
Programiz Course
```

In the above example, we have two strings: Learn Java and Programiz Course.

Here,

- we find the size of both strings using the length() method.
- we then use the if...else statement to compare the size of both strings and print the longer string.
