## Frequency of a Character

Problem Description

You are given a string and a character. You need to find the number of times this character is present in the string.

Thought Process

You need to access each character of the string using a for loop and charAt() method. Then, you need to compare those characters with the given character using if...else.

If there is a match, you need to record the number of matches.

Source Code

```java
1class Main {
2    public static void main(String[] args) {
3        
4        String text = "Java programming is interesting";
5        char ch = 'a';
6        
7        // Variable to store the number of matches
8        int match = 0;
9        
10        // Access each character of string
11        for (int i = 0; i < text.length(); ++i) {
12            
13            // Compare each character with the given character
14            // If match is found, increase the match variable
15            if (ch == text.charAt(i)) {
16                ++match;
17            }
18        }
19        
20        // Print the number of matches
21        System.out.println("Frequency: " + match);
22    }
23}
```

Output

```text
Frequency: 3
```
