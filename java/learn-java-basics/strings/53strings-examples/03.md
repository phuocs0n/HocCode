## Replacing Strings using replace()

Problem Description

You are given a string "Fool Mouse".

You need to change it into "Wool House".

Thought Process

You can use the replace() method to replace the characters/substring of the strings.

Syntax

```java
string.replace(char oldValue, char newValue)
```

The replace() method replaces each matching occurrence of the old value in the string with the new value.

Source Code

```java
1class Main {
2    public static void main(String[] args) {
3        String str1 = "Fool Mouse";
4        
5        System.out.println("Before: " + str1);
6        
7        // Replace F with W
8        String str2 = str1.replace('F', 'W');
9        
10        // Replace M with H
11        str2 = str2.replace('M', 'H');
12
13        System.out.println("After: " + str2);
14    }
15}
```

Output

```text
Before: Fool Mouse
After: Wool House
```

Similarly, you can also replace a substring with another substring. For example,

```java
1class Main {
2    public static void main(String[] args) {
3        String str1 = "Fool Mouse";
4        
5        System.out.println("Before: " + str1);
6        
7        // Replace "Fool Mouse" with "Wool House"
8        String str2 = str1.replace("Fool Mouse", "Wool House");
9  
10        System.out.println("After: " + str2);
11    }
12}
```

Output

```text
Before: Fool Mouse
After: Wool House
```
