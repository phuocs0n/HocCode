## Changing the Case of String

Problem Description

You are given a string in uppercase. You need to change all the characters of the string in lowercase. You'll again change the new strings (lowercase) to uppercase.

Thought Process

Java String provides two methods, toLowerCase() and toUpperCase(), to convert a string to lowercase and uppercase respectively.

Source Code

```java
1class Main {
2    public static void main(String[] args) {
3        
4        String text = "I LOVE JAVA PROGRAMMING";
5        
6        // Convert text string to lowercase
7        String lower = text.toLowerCase();
8        System.out.println(lower);
9        
10        // Convert lowercase string to uppercase
11        String upper = lower.toUpperCase();
12        System.out.println(upper);
13    }
14}
```

Output

```text
i love java programming
I LOVE JAVA PROGRAMMING
```
