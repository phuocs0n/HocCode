# Creating Strings

#### Course: Learn Java Basics

## Creating Strings

Remember this syntax of creating variables:

```java
int number = 5;
```

You can create strings in the same way.

```java
String greeting = "Hello";
```

Here,

- greeting - name of the variable
- String - data type of the variable
- "Hello" - value of the variable

Printing a String

Just like other variables, you can print strings by printing the name of the variable.

```java
1class Main {
2    public static void main(String[] args) {
3
4        // Create a string variable
5        String greeting1 = "Hello";
6        String greeting2 = "How are you?";
7
8        // Print the string
9        System.out.println(greeting1);
10        System.out.println(greeting2);
11    }
12}
```

Output

```text
Hello
How are you?
```

As you can see, we have successfully printed two strings.
