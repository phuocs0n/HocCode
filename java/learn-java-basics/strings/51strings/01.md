## Strings Introduction

So far in this course, we've used strings multiple times in our programs. Let's recall the Hello World program.

```java
1class Main {
2    public static void main(String[] args) {
3    
4        System.out.println("Hello World");
5    }
6}
```

Output

```text
Hello World
```

Here, "Hello World" is an example of a string. We use double quotes "" to represent strings.

Strings are a collection of characters that are used to represent textual data in programming. For example, the string "Hello World" consists of characters 'H', 'e', 'l', and so on.

Now that you have a basic understanding of strings, let's see how we can create them in Java.
