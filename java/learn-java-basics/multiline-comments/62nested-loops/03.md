## Example: Nested Loops

```java
1class Main {
2    public static void main(String[] args) {
3
4        // Outer loop iterates from i = 0 to 2
5        for (int i = 0; i <= 2; ++i) {
6
7            // Inner loop iterates from j = 0 to 1
8            for (int j = 0; j <= 1; ++j) {
9                System.out.println("i = " + i + ", j = " + j);
10            }
11        }
12    }
13}
```

Output

```text
i = 0, j = 0
i = 0, j = 1
i = 1, j = 0
i = 1, j = 1
i = 2, j = 0
i = 2, j = 1
```

In this program, the outer loop iterates from i equals 0 to 2. In each iteration of the outer loop, the inner loop iterates from j equals 0 to 1.
