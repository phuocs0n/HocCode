## Nested Loops

It is possible to put a loop inside another loop. This is known as a nested loop.

In a nested loop, the inner loop is executed for each iteration of the outer loop. Let's try to understand it with the help of an example.

```java
1class Main {
2    public static void main(String[] args) {
3        
4        String[] features = {"Electric", "Fast"};
5        String[] cars = {"Tesla", "Porsche", "Mercedes"};
6
7        // Outer loop
8        for (int i = 0; i < features.length; ++i) {
9
10            // Inner loop
11            for (int j = 0; j < cars.length; ++j) {
12                System.out.println(features[i] + " " + cars[j]);
13            }
14        }
15    }
16}
```

Output

```text
Electric Tesla
Electric Porsche
Electric Mercedes
Fast Tesla
Fast Porsche
Fast Mercedes
```

Here, the inner loop is iterated once for each item of the features array. Here's how this code works.

First iteration of the Outer Loop

| Inner Loop Iteration | feature | car |
| --- | --- | --- |
| 1 | 'Electric' | 'Tesla' |
| 2 | 'Electric' | 'Porsche' |
| 3 | 'Electric' | 'Mercedes' |

Second iteration of the Outer Loop

| Inner Loop Iteration | feature | car |
| --- | --- | --- |
| 1 | 'Fast' | 'Tesla' |
| 2 | 'Fast' | 'Porsche' |
| 3 | 'Fast' | 'Mercedes' |
