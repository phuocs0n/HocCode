## Example: Arithmetic Assignment Operators

Example 1

```java
1class Main {
2    public static void main(String[] args) {
3        
4        int total = 100;
5        
6        total += 10;  // total = total + 10
7        System.out.println(total);
8    }
9}
```

Output

```text
110
```

Here, total += 10 adds 10 to the total variable and assigns the result back to the total variable.

Example 2

```java
1class Main {
2    public static void main(String[] args) {
3        
4        int x = 100;
5        
6        x %= 9;  // x = x % 9
7        System.out.println(x);
8    }
9}
```

Output

```text
1
```

Here, x %= 9 computes the remainder when x is divided by 9 and assigns the result back to x.
