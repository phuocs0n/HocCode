## Example: Multiline Comments

```java
1/*
2Program to take age input from the user
3Assign the input to the age variable
4Print the variable
5*/
6
7import java.util.Scanner;
8
9class Main {
10    public static void main(String[] args) {
11        Scanner input = new Scanner(System.in);
12        
13        System.out.println("Enter your age: ");
14        int age = input.nextInt();
15        
16        System.out.println("Age: " + age);
17        input.close();
18    }
19}
```

Output

```text
Enter your age: 
25
Age: 25
```

Just like single-line comments, multiline comments are also ignored during the execution of the program.

Multiline comments are generally used to write long-form instructions and documentation.
