## Creating Multiline Comments

By now, you must be familiar with using comments in code.

```java
1class Main {
2    public static void main(String[] args) {
3        
4        // Create a variable
5        int age = 24;
6        
7        // Print the variable
8        System.out.println(age);
9    }
10}
```

Here, // Create a variable and // Print the variable are two comments.

These are called single-line comments.

However, suppose we have to add a comment that extends for multiple lines. For example,

```java
In this program, we will create an age variable.
We will assign the value 24 to the variable.
And finally, print the variable.
```

Here, adding // before every sentence doesn't make our code look good. So, instead, we can use a multi-line comment.

A multiline comment starts from /* and ends with */. For example,

```java
/*
In this program, we will create an age variable.
We will assign the value 24 to the variable.
And finally, print the variable.
*/
```
