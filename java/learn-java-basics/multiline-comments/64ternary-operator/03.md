## Checking Odd/Even Using Ternary Operator

In this example, we will use a ternary operator to check if a value is odd or even.

```java
1import java.util.Scanner;
2
3class Main {
4    public static void main(String[] args) {
5        
6        Scanner input = new Scanner(System.in);
7        
8        System.out.println("Enter a number: ");
9        int number = input.nextInt();
10        
11        String result = (number % 2 == 0) ? "Even" : "Odd";
12        System.out.println(number + " is " + result);
13        input.close();
14    }
15}
```

Sample Output 1

```text
Enter a number: 
5
5 is Odd
```

Sample Output 2

```text
Enter a number: 
36
36 is Even
```

Here, if the number is perfectly divisible by 2, "Even" is assigned to the result variable. Otherwise, "Odd" is assigned.
