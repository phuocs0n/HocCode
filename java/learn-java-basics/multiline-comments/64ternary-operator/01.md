## Introduction to Ternary Operator

In Java, we can use a ternary operator ? : as an alternative to an if...else statement. Let's see an example.

```java
1class Main {
2    public static void main(String[] args) {
3        
4        int marks = 76;
5        String result;
6        
7        if (marks >= 32) {
8            result = "Pass";
9        }
10        else {
11            result = "Fail";
12        }
13
14        System.out.println("Result: " + result);
15    }
16}
17
18// Output
19// Result: Pass
```

Here, we have used an if...else statement to check if a student passed the exam or not.

Now, let's implement this same program using a ternary operator.

```java
1class Main {
2    public static void main(String[] args) {
3        
4        int marks = 76;
5        
6        String result = (marks >= 32) ? "Pass" : "Fail";
7
8        System.out.println("Result: " + result);
9    }
10}
11
12// Output:
13// Result: Pass
```
