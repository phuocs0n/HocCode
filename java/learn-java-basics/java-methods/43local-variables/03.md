## Local Variables

Any variable that is created inside a method is local to it. Let's take our program from the previous page.

```java
1class Main {
2
3    void addNumbers(int n1, int n2) {
4        int result = n1 + n2;
5    }
6
7    public static void main(String[] args) {
8
9        Main obj = new Main();
10        obj.addNumbers(2, 5);
11        System.out.println(result);
12    }
13}
```

Here, when the execution of the addNumbers() method ends, all the variables inside it: n1, n2, and result are destroyed.

This is the reason why the above program throws an error because Java thinks the result variable is not defined.

If you remember, we can fix it by using a return statement.

```java
1class Main {
2
3    int addNumbers(int n1, int n2) {
4        int result = n1 + n2;
5        return result;
6    }
7
8    public static void main(String[] args) {
9
10        Main obj = new Main();
11
12        int output = obj.addNumbers(2, 5);
13        System.out.println(output);
14    }
15}
```

By using a return statement, we are not using the local variable directly; rather, we are returning its value to the calling method.

Next, we'll see why this concept of local variables is important.
