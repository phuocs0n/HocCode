#### Course: Learn Java Basics

## Why are Local Variables Important?

Local variables are important because they make methods independent.

As we discussed earlier, it doesn't matter what's inside a method and what variables are used in it. We can use that method if we know two things:

- arguments that the method takes
- return value from the method

Source Code

```java
1class Main {
2
3    int addNumbers(int n1, int n2) {
4        int result = n1 + n2;
5        return result;
6    }
7
8    public static void main(String[] args) {
9
10        Main obj = new Main();
11        
12        int n1 = 2;
13        int n2 = 5;
14
15        int result = obj.addNumbers(2, 5);
16        System.out.println("Sum: " + result);
17    }
18}
```

Output

```text
Sum: 7
```

In the program, it's important to understand that n1, n2, and result variables inside the method are local to the addNumbers() method.

They are different from n1, n2, and result variables that are outside of the method (even though names are the same).
