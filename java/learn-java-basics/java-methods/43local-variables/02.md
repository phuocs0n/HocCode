## Variables Inside Method

If we print the result after the method call, we'll get an error.

```java
1class Main {
2
3    void addNumbers(int n1, int n2) {
4        int result = n1 + n2;
5    }
6
7    public static void main(String[] args) {
8
9        Main obj = new Main();
10
11        obj.addNumbers(2, 5);
12        System.out.println(result);
13    }
14}
```

Output

```java
ERROR!Main.java:12: error: cannot find symbol
        System.out.println(result);
                           ^
  symbol:   variable result
  location: class Main
1 error
```

This is where the concept of local variables comes into play.
