## Creating a Method

Consider these two statements.

```java
System.out.println("Hello");
System.out.println("How do you do?");
```

Both of these statements serve a similar purpose i.e. they are both greetings. So, we can wrap them inside a method called greet.

```java
void greet() {
    System.out.println("Hello");
    System.out.println("How do you do?");
}
```

Terms like void and the parenthesis () might seem confusing. So, let's learn the syntax behind creating a method.
