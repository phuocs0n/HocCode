## Running Our Method

Let's use our previous method in a program.

Remember when we said in Chapter 1 that all properties must be included inside a class? Methods are one of such properties. So, we must place our method inside the class.

```java
1class Main {
2  
3    void greet() {
4        System.out.println("Hello");
5        System.out.println("How do you do?");
6    }
7  
8    public static void main(String[] args) {
9  
10    }
11}
```

However, if you run this code, you won't see any output. It's because creating a method doesn't mean we are executing the code inside it.

As per OOP in Java, we must use an object of the class to call the method. This is similar to how we created a scanner object before we took user input using the Scanner class.

Since, greet() is inside the Main class, we first need to create an object of the class.
