## Methods Introduction

In this chapter, you'll learn to organize your code using methods.

As the complexity of the program increases, huge portions of the code becomes repetitive making the code messy and hard to understand.

Consider this code that calculates the discount for a customer.

```java
1import java.util.Scanner;
2
3public class Main {
4    public static void main(String[] args) {
5        Scanner scanner = new Scanner(System.in);
6
7        System.out.print("Total? ");
8        double total = scanner.nextDouble();
9        double discountPercent = 10.0;
10
11        if (total > 100) {
12            double excess = total - 100;
13            double discount = (discountPercent / 100) * excess;
14            total = total - discount;
15        }
16
17        System.out.printf("The final amount to pay is: $%.2f\n", total);
18    }
19}
```

If you have multiple customers, you'd need to repeat the same code for each one. This would make your program long and difficult to manage.

In such cases, you can wrap the repetitive code inside a method and use it when needed.
