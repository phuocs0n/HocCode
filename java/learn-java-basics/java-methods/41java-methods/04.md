## Calling Method in Java

We can create an object of the Main class as follows:

```java
Main obj = new Main();
```

Here, we have created an object named obj of the Main class.

We use the object (obj) along with the dot operator (.) to call the greet() method.

```java
obj.greet();
```

Let's see an example.

```java
1class Main {
2  
3    void greet() {
4        System.out.println("Hello");
5        System.out.println("How do you do?");
6    }
7  
8    public static void main(String[] args) {
9        
10        // Create object of Main
11        Main obj = new Main();
12        
13        // Call the method
14        obj.greet();
15  
16    }
17}
```

Output

```text
Hello
How do you do?
```
