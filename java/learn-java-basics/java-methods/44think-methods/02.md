## Sum of Natural Numbers From 1 to n

Program Summary

Create a program to find the sum of first n natural numbers (where n is a positive integer) by creating a method. The method should work for any positive integer.

```java
total = 1 + 2 + 3 + ..... + n
```

Arguments

We are finding the sum from 1 to n. Our method will take only one argument, n. It's because the first number will always be the same value 1.

Return Value

The method should return the sum of numbers.

Source Code

```java
1class Main {
2    
3    int computeSum(int number) {
4        int total = 0;
5        
6        for (int i = 0; i <= number; i++) {
7            total = total + i;
8        }
9        
10        return total;
11  }

21  }
22}
```
