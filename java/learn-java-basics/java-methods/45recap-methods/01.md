## Recap (I)

Creating a Method

A method is a block of code put together that performs a specific task.

```java
// Method to greet
void greet() {
    System.out.println("Hello");
    System.out.println("How are you?");
}
```

Calling a Method

Defining a method won't do anything. We need to call the method to bring it into action. In Java, we use the object of the class to call a method.

```java
1class Main {
2
3    // Method to greet
4    void greet() {
5        System.out.println("Hello");
6        System.out.println("How are you?");
7    }
8
9    public static void main(String[] args) {
10
11        // Create object of Main class
12        Main obj = new Main();
13    
14        // Call greet method
15        obj.greet();
16    }
17}
```

Arguments are the inputs to the method and return value is the output from the method.

```java
1class Main {
2
3    // The method takes two arguments
4    // Returns the sum of numbers
5    int addNumbers(int n1, int n2) {
6        int result = n1 + n2;
7        return result;
8    }
9
10    public static void main(String[] args) {
11
12        // Create object of Main class
13        Main obj = new Main();
14
15        // Call method and print it
16        int result = obj.addNumbers(20, 30);
17        System.out.println(result);    // 50
18    }
19}
```
