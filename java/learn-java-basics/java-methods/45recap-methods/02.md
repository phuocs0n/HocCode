## Recap (II)

Local Variables

Variables defined inside a method are local to it. It doesn't exist outside the method.

```java
1class Main {
2
3    // The method takes two arguments
4    // Returns the sum of numbers
5    void sayHello() {
6        String greeting = "Hello";
7    }
8
9    public static void main(String[] args) {
10
11        // Create object of Main class
12        Main obj = new Main();
13
14        // Error!! greeting cannot be resolved to a variable
15        System.out.println(greeting);
16    }
17}
```

Standard Library Methods

Java provides various built-in methods that we can directly use in our program.

```java
1class Main {
2    public static void main(String[] args) {
3        
4        double squareRoot = Math.sqrt(81);
5        System.out.println(squareRoot);    // 9.0
6    }
7}
```
