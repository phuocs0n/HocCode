## Library Methods Introduction

In the last lesson, we learned to create our own methods. More specifically, we wrote the method definition ourselves. These are called user-defined methods.

In Java, there is another type of method called standard library methods.

They are built-in methods that are already defined in library files and we can directly use them in our program.

Let's see an example to print a text.

```java
1class Main {
2    public static void main(String[] args) {
3        System.out.println("Hello World");
4    }
5}
```

Output

```text
Hello World
```

Here, println() of System.out.println() is a standard library method that prints the text on the screen.

We haven't provided any definition for the System.out.println() but we are still able to use it in our program.

This is because the method definition of println() is already defined inside the Java library.

Similarly, the nextInt() method that we use to take int input is also a standard library method.
