## Finding the Square Root

The sqrt() method is used to find the square root of a number. Let's see an example.

```java
1class Main {
2    public static void main(String[] args) {
3        int number = 25;
4
5        // Find the square root
6        double squareRoot = Math.sqrt(number);
7
8        System.out.println("Square root of " + number + " is " + squareRoot);
9    }
10}
```

Output

```text
Square root of 25 is 5.0
```

As mentioned earlier, the sqrt() method is defined inside the Math class, that's why we are using Math.sqrt().

The sqrt() method returns a floating-point value, so we have assigned the result to a double variable.

As you can see, we don't have to worry about the definition of the sqrt() method. We can simply pass a number and get the square root of that number.

Similarly, we can use the cbrt() method to find the cube root of a number.
