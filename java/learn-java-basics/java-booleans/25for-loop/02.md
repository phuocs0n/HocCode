## Syntax of for Loop

The syntax of the for loop is:

```java
for (initialization; booleanExpresssion; update) {
    // statement(s)
}
```

Here's how this code works.

The initialization expression initializes a value of a variable. For example, count = 1, int i = 0, etc.

The loop then evaluates the boolean expression. If it's true, the body of the for loop is executed.

Then, the update expression is evaluated. It changes the value of a variable. For example, count = count + 1, ++i, etc.

The boolean expression is evaluated again. If it's true again, the body of the loop is executed and the variable is updated.

This process continues until the boolean expression is false. If the boolean expression is false, the loop terminates.
