## for Loop Introduction

In this lesson, we'll learn another type of loop: the for loop.

for loop is preferred when we know exactly how many times we want the loop to run. For example:

- Printing the same statement three times.
- Iterating through a range of numbers.

We'll go over each example later, but first, let's focus on understanding the syntax of the for loop.
