## Summary (II)

The break Statement

The break statement is used to terminate the loop immediately when it's encountered. It is usually used inside an if...else statement.

```java
1class Main {
2    public static void main(String[] args) {
3
4        for(int i = 1; i <=100; i++) {
5            if(i == 3) {
6                break;
7            }
8            System.out.println(i);
9        }
10    }
11}
```

The continue Statement

The continue statement skips the code inside the loop for that current iteration. The loop will not terminate but continues on with the next iteration. It's also usually used inside an if...else statement.

```java
1class Main {
2    public static void main(String[] args) {
3
4        for(int i = 1; i <=5; i++) {
5            if(i == 3) {
6                continue;
7            }
8            System.out.println(i);
9        }
10    }
11}
```

The switch Statement

The switch statement can be used as a replacement for if...else when we have to choose from multiple alternatives. For example,

```java
1class Main {
2    public static void main(String[] args) {
3        
4        int number = 3;
5        
6        switch(number) {
7            case 1:
8                System.out.println("One");
9                break;
10            
11            case 2:
12                System.out.println("Two");
13                break;
14            
15            case 3:
16                System.out.println("Three");
17                break;
18            
19            default:
20                System.out.println("Invalid Number");
21        }
22    }
23}
```
