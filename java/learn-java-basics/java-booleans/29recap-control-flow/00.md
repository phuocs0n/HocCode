## Control Flow Summary (I)

The if Statement

The if statement is used to create programs that can make a choice among two or more alternatives. For example,

```java
1class Main {
2    public static void main(String[] args) {
3
4        String car = "Tesla";
5
6        if (car == "Bugatti") {
7            System.out.println("You have Bugatti.");
8        } 
9        else {
10            System.out.println("You do not have a Bugatti.");
11        }
12
13    }
14}
```

The while Loop

The while loop is used to repeat a block of code until the boolean expression of the loop is false.

```java
1class Main {
2    public static void main(String[] args) {
3
4        // Declare variables
5        int i = 1;
6        int n = 5;
7
8        // while loop from 1 to 5
9        while(i <= n) {
10             System.out.println(i);
11             i++;
12        }
13    }
14}
```

The for Loop

The for loop is used to run a block of code for a certain number of times. For example,

```java
1class Main {
2    public static void main(String[] args) {
3
4        // loop iterates from 1 to 3
5        for(int i = 1; i <= 3 ; i++) {
6            System.out.println(i);  
7        }
8
9    }
10}
```
