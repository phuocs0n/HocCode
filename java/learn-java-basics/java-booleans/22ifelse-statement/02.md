## The if Statement

Let's start with a simple if statement first. Then, we'll learn about the if...else statement.

The syntax of the if statement is:

```java
if (booleanExpression) {
 statement(s)
}
```

Here is how it works.

The if statement evaluates booleanExpression that results in either true or false.

If booleanExpression is:

- true - statements inside if are executed.
- false - statements inside if are skipped from execution.
