## Introduction

In one of our earlier lessons, we learned that an if...else statement is used when we want to make a decision among two alternatives.

However, sometimes we might have to make a decision among multiple alternatives.

Suppose we are given a number between 1 to 7 and based on the number we have to print the day of a week. If the number is 1, day is Sunday and if the number is 2, day is Monday, and so on.

As there are multiple conditions, using if...else if will make our code messy. .

Instead, we can use a switch statement which performs better in such scenario.
