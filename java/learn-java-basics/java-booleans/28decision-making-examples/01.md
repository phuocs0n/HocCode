## Checking Leap Year

Every leap year follows a certain pattern.

- A leap year is perfectly divisible by 4 except for century years (years ending with 00).
- A century year is a leap year only if it is perfectly divisible by 400.

```java
2017 - Not a leap year. Not divisible by 4. 
2000 - Leap year. Century year that is divisible by 400.
1900 - Not a leap year. Century year but not divisible by 400.
2012 - Leap year. Divisible by 4 and not century year.
```

Let's try to implement this logic in our program.

Source Code 1

```java
1// Java program to find Leap Year
2// Using if...else if...else ladder
3
4class Main {
5    public static void main(String[] args) {
6
7        int year = 2000;
8
9        // If divisible by 400, it's a leap year
10        if (year % 400 == 0) {
11            System.out.println("leap year");
12        }
13
14        // At this point, we know it's not divisible by 400
15        // If it's divisible by 100, it's not a leap year
16        else if (year % 100 == 0) {
17            System.out.println("not a leap year");
18        }
19        // At this point we know it's not a century year
20        // If a non-century year is divisible by 4, it's a leap year
21        else if (year % 4 == 0) {
22            System.out.println("leap year");
23        }
24        // All other remaining years are not a leap year
25        else {
26            System.out.println("not a leap year");
27        }
28    }
29}
```

Source Code 2

```java
1// Java program to find Leap Year
2// Using && and || operators with if...else
3
4class Main {
5    public static void main(String[] args) {
6
7        int year = 2000;
8
9        // If year is divisible by 4 and not divisible by 100
10        // or if year is divisible by 400, it's a leap year
11        if ((year % 4 == 0) && (year % 100 != 0) || (year % 400 == 0)) {
12            System.out.println("leap year");
13        }
14
15        // All other remaining years are not a leap year
16        else {
17            System.out.println("not a leap year");
18        }
19    }
20}
```
