## Printing Multiplication Table

In this example, we'll create a multiplication table of a number (let's say 9) up to 5. Here's the output we are looking for.

```text
9 * 1 = 9
9 * 2 = 18
9 * 3 = 27
9 * 4 = 36
9 * 5 = 45
```

To solve this program, we need to iterate a loop five times from 1 to 5. And, in each iteration of the loop, we'll compute the product.

```java
1class Main {
2    public static void main(String[] args) {
3
4        int number = 9;
5        // Iterate a loop from 1 to 5
6        for (int i = 1; i <= 5; i++) {
7
8            // Compute product in each iteration of the loop
9            // Product will 9 * 1 in first iteration,
10            // 9 * 2 in second iteration and so on
11            int product = number * i;
12            System.out.println(product);
13        }
14    }
15}
```

Output

```text
9
18
27
36
45
```

The output we got is close to the desired output but not the same. Let's fix it.

```java
1class Main {
2    public static void main(String[] args) {
3
4        int number = 9;
5        // Iterate a loop from 1 to 5
6        for (int i = 1; i <= 5; i++) {
7
8            // Compute product in each iteration of the loop
9            // Product will 9 * 1 in first iteration,
10            // 9 * 2 in second iteration and so on
11            int product = number * i;
12            System.out.println(number + " * " + i + " = " + product);
13        }
14    }
15}
```

Now, we get the desired output.
