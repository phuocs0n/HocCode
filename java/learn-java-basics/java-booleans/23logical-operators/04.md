## Example: Eligible for Loan

We'll be using the results of the comparison to make decisions in the program using an if-else statement.

```java
1public class Main {
2    public static void main(String[] args) {
3      
4        int creditScore = 720; 
5        double annualSalary = 6500.00; 
6
7        // Check if the person qualifies for the loan
8        if (creditScore > 700 && annualSalary > 6000.00) {
9            System.out.println("Congratulations! You qualify for the loan.");
10        } else {
11            System.out.println("Sorry, you do not qualify for the loan.");
12        }
13    }
14}
```

Since our creditScore is 720 which is higher than 700, (creditScore > 700) evaluates to true. Likewise, (annualSalary > 6000.00) also evaluates to true as our annualSalary is 6500.

Since both conditions are true , the condition (creditScore > 700) && (annualSalary > 6000.00) becomes true and prints the text inside the if block.
