## Logical Operators

There are three logical operators in Java.

| Operator | Meaning | Example |
| --- | --- | --- |
| && (AND) | true if both expressions are true | (creditScore > 700) && (annualSalary > 6000.00) |
| || (OR) | true if either of the expressions is true | (purchaseAmount> 1000) || (hasMembership) |
| ! (NOT) | true if the expression is false | !(age > 18) |
