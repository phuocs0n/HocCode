## Logical Operator: && (AND)

The && "AND" operator is used with two boolean expressions. It returns:

- true - if both boolean expressions are true
- false - if either of the boolean expressions is false

Example

Suppose a bank offers a loan if the applicant's credit score is 700 or higher, and they have an annual income of $6000.

In this case, both conditions must be true for the applicant to qualify for the loan. This is where the && operator is applied.

Here's how we can write the condition:

(creditScore > 700) && (annualSalary > 6000.00)
