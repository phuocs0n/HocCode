## Introduction to Loops

As the complexity of programs increases, so do the number of repeated operations in our code. For example, you might need to display the same line of text 100 times.

So, do you type the same print statement 100 times as well?

Fortunately, you don't have to, as in programming, you can use loops to make the program perform these repeated operations instead of doing it yourself.

With clever logic, you can write some truly interesting programs using loops.

So let's get started.
