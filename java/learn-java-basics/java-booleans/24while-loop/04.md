## while Loop

Here's how we can increment the count inside the body of the loop so that our loop doen't run endlessly.

```java
1class Main {
2    public static void main(String[] args) {
3
4        // Declare variable
5        int count = 1;
6    
7        // Loop continues as long as count is 3 or less 
8        while(count <= 3) {
9            System.out.println("I am inside a loop");
10            System.out.println("Loop is interesting.");
11
12           // Increment count by 1 in each iteration
13
14            count = count + 1;
15
16        }
17
18
19        System.out.println("OUTSIDE THE LOOP");
20    }
21}
```

Output

```text
I am inside a loop
Loop is interesting.
I am inside a loop
Loop is interesting.
I am inside a loop
Loop is interesting.
OUTSIDE THE LOOP
```

In the program, we have added a statement, count = count + 1 to increase the value of count by 1 in each iteration of the loop.

Here's how this code works.

| Variable | count <= 3 | Body of loop |
| --- | --- | --- |
| count = 1 | true | Statements are printed.
count is increased to 2. |
| count = 2 | true | Statements are printed.
count is increased to 3. |
| count = 3 | true | Statements are printed.
count is increased to 4. |
| count = 4 | false | The loop terminates. |

After the loop ends, System.out.println("OUTSIDE THE LOOP"); is executed because it's outside the loop.
