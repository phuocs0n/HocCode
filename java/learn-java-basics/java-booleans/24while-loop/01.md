## The while Loop

In Java, there are three types of loops: while loop, do...while loop and for loop. Let's learn about the while and do…while loop in this lesson.

The syntax of the while loop is:

```java
while (booleanExpression) {
    // statement(s)
}
```

The while loop evaluates the boolean expression. If it's true, the body of the while loop is executed. At this point, it's similar to the if statement.

However, unlike the if statement, the boolean expression is checked again. If it's true, the body of the loop is executed again.

This process continues until the boolean expression is false. If the boolean expression becomes false, the loop terminates.
