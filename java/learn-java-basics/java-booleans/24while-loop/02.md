## Example: while Loop

```java
1class Main {
2    public static void main(String[] args) {
3
4        // Declare variable
5        int count = 1;
6    
7        // Loop continues as long as count is 3 or less 
8        while(count <= 3) {
9            System.out.println("I am inside a loop");
10            System.out.println("Loop is interesting");
11        }
12    }
13}
```

Here, the body of the loop contains two print statements. We know this because they are included inside the curly braces (which indicate the body of the loop).

If you run this program, the two statements inside the loop are executed again and again.

Output

```text
I am inside a loop
Loop is interesting
I am inside a loop
Loop is interesting
...
...
```

Let's analyze what this program is doing.

- Here, count is 1. Hence, the boolean expression count <= 3 evaluates to true and the loop body is executed.
- Then, count <= 3 is evaluated again. Once more, it evaluates to true and the loop body is executed.
- The boolean expression is evaluated again.
- In this program, count <= 3 never becomes false, hence the loop runs forever.

This is called an infinite loop because the boolean expression is never false; the loop runs forever and the code after the loop is never executed.

However, most of the time, rather than running a loop forever and ever, we want loops to end at some point.

Next, we'll create a loop that ends after running for a fixed number of times.
