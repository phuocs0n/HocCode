## Printing Numbers From 1 to 5

To solve this program, let's first create a loop that runs 5 times.

```java
int count = 1;

while (count <= 5) {
    count = count + 1;
}
```

Here, the loop will iterate for 5 times from count equals to 1 to 5. After that, count becomes 6 and the loop terminates.

Now, let's complete this program.

Since we know the value of count will be increased by 1 in each iteration, we can print count to get numbers from 1 to 5.
