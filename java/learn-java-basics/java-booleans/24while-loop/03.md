## while Loop

Here's the program from the last page:

```java
1class Main {
2    public static void main(String[] args) {
3
4        // Declare variable
5        int count = 1;
6    
7
8        while(count <= 3) {
9            System.out.println("I am inside a loop");
10            System.out.println("Loop is interesting.");
11        }
12    }
13}
```

Here, the boolean expression count <= 3 is never false because the value of count is always 1. So, this loop continues forever.

To run this loop only for a fixed number of times, we must update the value of count inside the loop so that count <= 3 eventually becomes false.
