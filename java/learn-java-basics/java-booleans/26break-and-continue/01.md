## Java break Statement

Sometimes, we may need to end a loop immediately in the middle. In such cases, the break statement is used.

The break statement terminates the loop immediately when it is encountered. Let's see an example of it.

```java
1class Main {
2    public static void main(String[] args) {
3
4        for (int i = 1; i <= 5; ++i) {
5            System.out.println(i);
6
7            break;
8
9        }
10        System.out.println("This is outside the loop.");
11    }
12}
```

Output

```text
1
This is outside the loop.
```

Here, the loop should iterate 5 times from i equals 1 to 5. However, after printing 1, the value of i, the break statement is encountered and the loop terminates.
