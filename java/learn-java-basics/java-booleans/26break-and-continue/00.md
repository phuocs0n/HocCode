## Introduction: break and continue

When working with loops, you often need more control over how the loop runs. For example,

- What if you want to stop a loop early based on a certain condition?
- What if you want to skip over some iterations without stopping the loop entirely?

To alter the flow of the loop like this, we use the break and continue statements.

Let's see why and how break is used first. Then, we'll move on to the continue statement.
