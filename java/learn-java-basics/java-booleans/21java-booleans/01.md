## Booleans

A boolean is a data type, like integers, floating-point numbers, and characters.

However, unlike the other data types we have studied so far, booleans can only have one of two possible values: true or false. Let's see an example.

```java
1class Main {
2    public static void main(String[] args) {
3        
4        boolean result1 = true;
5        boolean result2 = false;
6        
7        System.out.println(result1);
8        System.out.println(result2);
9    }
10}
```

Output

```text
true
false
```
