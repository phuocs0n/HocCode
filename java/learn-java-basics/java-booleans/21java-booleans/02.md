## Understanding Booleans

The boolean values, true and false, are fixed values, similar to numbers like 15, 2.5 or text like "Hello". This means:

1. Booleans aren't strings

"true" is a string (text). However, when you use true without quotation marks, it's a boolean value.

The boolean value true generally means yes and false means no. This property makes booleans essential for creating programs that make decisions.

2. Booleans aren't variables

Even though true and false might seem like variable names, they can't be used as variables because they are fixed values, like numbers and strings. For example,

```java
1class Main {
2    public static void main(String[] args) {
3        boolean true = 25; 
4        System.out.println(true);
5    }
6}
```

Output

```text
Main.java:3: error: not a statement
        boolean true = 25; 
Main.java:3: error: ';' expected
        ^
        boolean true = 25;
```

This error indicates that you can't assign a value to true. However, you can use True (uppercase) and False (uppercase) as variable names.
