## Introduction to Booleans

So far in this course, we have created programs that are executed step-by-step.

However, in many real-world scenarios, we need to make decisions based on conditions, rather than just executing the code sequentially. For example,

- Applying a discount only when the total amount exceeds a specified limit.
- Displaying "Congratulations!" if a student has passed or "Sorry!" if he has failed.

To create such decision-making programs, we first need to understand booleans.
