## Step 3: Prime Numbers Between 50 to 100

To find the numbers from 50 to 100, we'll need to create a loop that iterates from 50 to 100. In each iteration of the loop, we'll check if the number is prime or not.

```java
1class Main {
2
3    boolean checkPrime(int number) {
4
5        boolean isPrime = true;
6
7        // Iterate loop from 2 to number -1
8        for (int i = 2; i <= number - 1; i++) {
9
10            if (number % i == 0) {
11                isPrime = false;
12                break;
13            }
14        }
15        return isPrime;
16    }
17
18    public static void main(String[] args) {
19
20        int n1 = 50;
21        int n2 = 100;
22
23        // Create object of Main class
24        Main obj = new Main();
25
26        for (int i = n1; i <= n2; i++) {
27            boolean isPrime = obj.checkPrime(i);
28
29            if (isPrime) {
30                // Printing prime numbers
31                System.out.println(i);
32            }
33        }
34    }
35}
```
