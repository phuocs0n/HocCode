## Step 2: Creating a Method

We can make this program a bit easier to understand by creating a method. So, we'll create a method to check whether the number is prime or not.

Here's how the method will work:

- The method will take a single argument (the number we need to check is prime or not).
- The method will check if the number is prime or not. If the number is prime, the method will return true. If not, the method will return false.

```java
1import java.util.Scanner;
2
3class Main {
4
5    boolean checkPrime(int number) {
6
7        boolean isPrime = true;
8
9        // Iterate loop from 2 to number -1
10        for (int i = 2; i <= number - 1; i++) {
11
12            if (number % i == 0) {
13                isPrime = false;
14                break;
15            }
16        }
17        return isPrime;
18    }
19
20    public static void main(String[] args) {
21
22        Scanner input = new Scanner(System.in);
23
24        // Take input from the user
25        System.out.println("Enter a number: ");
26        int number = input.nextInt();
27
28        // Create object of Main class
29        Main obj = new Main();
30
31        boolean isPrime = obj.checkPrime(number);
32
33        if (isPrime) {
34            System.out.println(number + " is Prime");
35        }
36        else {
37            System.out.println(number + " is not Prime");
38        }
39        
40        input.close();
41    }
42}
```

Output

```text
Enter a number: 
83
83 is Prime
```

Here, the checkPrime() method takes a single argument (the number we need to check for prime).

Then, we have iterated the loop from 2 to number - 1. If number is divided by any of these numbers, we know it's not a prime number. In that case, we have returned false.

However, if number is not divisible by any number from 2 to number - 1, we know it's prime. So, outside of the loop, we have returned true.

The program will not reach this point if the number is not a prime number.
