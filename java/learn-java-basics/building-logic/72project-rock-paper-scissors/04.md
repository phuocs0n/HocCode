## Step1 : Generate Random Number

First, we need to generate a random number between 1 to 3 because the computer only has to choose between three options: rock, paper, and scissors.

To accomplish this, we'll be using the Math.random() method.

Let's revise the working of this method with the help of an example.

```java
1class Main {
2    public static void main(String[] args) {
3
4        // Random number from 1 to 3
5        int randomNumber = (int) (Math.random() * 3 + 1);
6
7        System.out.println(randomNumber);
8    }
9}
```

When you run this program, you'll get a random number between 1 to 3. Let's understand what's happening here.

- Math.random() - generates random numbers from from 0.0 to less than 1.0
- Math.random() * 3 - generates random numbers from 0.0 to less than 3.0
- Math.random() * 3 + 1 -  generates the random number from 1.0 to 3.0
- (int) - converts the random number to integer (i.e. 1 to 3)
