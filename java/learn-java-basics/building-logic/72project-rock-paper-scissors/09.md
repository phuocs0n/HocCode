## Handling Wrong User Input

Our code doesn't work as expected if the user enters values other than "rock", "paper", or "scissors".

To handle this problem, we will ask for user input until the user enters either "rock", "paper", or "scissors".

We can solve this problem by changing this code

```java
// Get users input
String userInput = obj.getUserInput();
```

to

```java
String userInput;

    // Get input until user enters "rock", "paper" or "scissors"
    while (true) {
        userInput = obj.getUserInput();
        if (userInput.equals("rock") || userInput.equals("paper") || userInput.equals("scissors")) {
            break;
        }
    }
```

Now the user will provide input until userInput is either "rock" or "paper" or "scissors".

Note: We have defined the userInput variable outside the loop. It's because just like local variables, variables declared inside the loop will be local to it, which we cannot access from outside the loop.

To avoid this, we have to declare the variable first outside the loop.

Here's the updated code:
