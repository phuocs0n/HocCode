## Step 3: Take User Input

Let's create a method to take user input among "rock", "paper", or "scissors".

```java
1import java.util.Scanner;
2
3class Main {
4
5    String getUserInput() {
6
7        Scanner input = new Scanner(System.in);
8
9        System.out.println("Enter rock, paper or scissors:");
10        String userInput = input.nextLine();
11
12        // Convert user input to lowercase
13        userInput = userInput.toLowerCase();
14
15        return userInput;
16    }
17
18    public static void main(String[] args) {
19
20        Main obj = new Main();
21
22        // get user input
23        String userInput = obj.getUserInput();
24        System.out.println(userInput);
25
26    }
27}
```

Sample Output 1

```text
Enter rock, paper or scissors:
rock
rock
```

Sample Output 2

```text
Enter rock, paper or scissors:
scissors
scissors
```

Sample Output 3

```text
Enter rock, paper or scissors:
Paper
paper
```

Here, the getUserInput() method returns the user's input and converts it to lowercase.

We are converting the user input to lowercase because the computer's choice will be in lowercase, and we want our program to work for both the uppercase and lowercase user inputs.
