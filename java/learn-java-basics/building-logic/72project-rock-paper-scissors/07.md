## Step 4: Decide Win, Lose, or Draw

Now let's create a method to decide whether the user won, lost or drew. This method will:

- take two arguments (the user input and computer's pick)
- return a string: either "win", "lose", or "draw"

```java
// Return either "win", "lose" or "draw"
String getResult(String userInput, String computerChoice) {

    // Condition for user to draw
    if (userInput.equals(computerChoice)) {
        return "draw";
    }

    // Condition for user to win
    else if (userInput.equals("paper") && computerChoice.equals("rock")) {
        return "win";
    }
    else if (userInput.equals("rock") && computerChoice.equals("scissors")) {
        return "win";
    }
    else if (userInput.equals("scissors") && computerChoice.equals("paper")) {
      return "win";
    }
    
    // All other conditions result in the user losing
    else {
        return "lose";
    }
}
```

Basically, this method returns

- "draw" if the computer's pick and the user's pick are the same
- "win" if the user wins using the rules we described earlier
- "lose" if none of the conditions for draw or win are met

Notice that we are using the equals() method to compare the string variable with the strings directly.

```java
userInput.equals("rock");
```
