## Check Even or Odd

### Problem Description

Create a program to check if a number is even or odd.

- Get an integer input for the number variable.
- Check if the number is exactly divisible by 2.
- If the number is divisible, print Even. Otherwise, print Odd.

#### Example

```text
Test Input21
```

