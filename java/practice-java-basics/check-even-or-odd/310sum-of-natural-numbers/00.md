## Sum of Natural Numbers

### Problem Description

Create a program to find the sum of N natural numbers.

- Get an integer input for a variable n.
- Run a loop from 1 to n.
- Inside the loop, find the sum of all numbers from 1 to n.
- Print the sum.

#### Example

```text
Test Input9
```

```text
Expected Output45
```
