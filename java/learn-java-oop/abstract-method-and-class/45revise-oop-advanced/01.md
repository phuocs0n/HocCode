# Braking Implementation of MotorBike

#### Course: Learn Java OOP

## Braking Implementation of MotorBike

In this section, we will see an example of abstraction. A practical example of abstraction can be motorbike brakes.

#### Thought Process

We know that the working of the brake is to stop the motorbike. However, the working of brakes is different for different types of bikes.

So, instead of providing a separate braking implementation, we can make it abstract (hide the implementation details).

Now, all other types of bikes will provide a separate implementation of brakes that suits their needs. However, the actual working of the brake will remain the same (to stop the bike).

#### Source Code

```java
1interface MotorBike {
2    // hide the implementation of brake
3    abstract void brake();
4}
5
6class SportsBike implements MotorBike {
7    
8    // provide an implementation of brake
9    public void brake() {
10        System.out.println("Stopping the Sports Bike.");
11    }
12}
13
14class MountainBike implements MotorBike {
15    
16    // provide an implementation of brake
17    public void brake() {
18        System.out.println("Stopping the Mountain Bike.");
19    }
20}
21
22class Main {
23    public static void main(String[] args) {
24        
25        SportsBike s1 = new SportsBike();
26        s1.brake();
27        
28        MountainBike m1 = new MountainBike();
29        m1.brake();
30    }
31}
```

Output

```text
Stopping the Sports Bike.
Stopping the Mountain Bike.
```

In the above example, we have created an interface MotorBike with an abstract method brake().

The classes SportsBike and MountainBike implement the MotorBike interface and provide the implementation for the abstract method brake().
