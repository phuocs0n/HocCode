## Encapsulation

Encapsulation is another key feature of object-oriented programming. It means bundling fields and methods together inside a class.

Let's understand this with the help of an example.

Suppose we need to compute the area of a rectangle. We know that to compute the area we need two data (fields) length and breadth and a method calculateArea().

Hence, we can bundle these fields and the method together inside a single class.

```java
class Rectangle {

    // fields to calculate area
    int length;
    int breadth;

    // method to calculate area
    public void calculateArea() {
        int area = length * breadth;
        System.out.println("Area: " + area);
    }
}
```

This is an example of encapsulation.

With this, we are now able to keep related fields and methods together and it makes our code clean and easy to understand.
