## Example: Java Encapsulation

```java
1class Rectangle {
2
3    // fields to calculate area
4    int length;
5    int breadth;
6
7    // constructor to initialize length/breadth
8    Rectangle(int length, int breadth) {
9        this.length = length;
10        this.breadth = breadth;
11    }
12
13    // method to calculate area
14    public void calculateArea() {
15        int area = length * breadth;
16        System.out.println("Area: " + area);
17    }
18}
19
20class Main {
21    public static void main(String[] args) {
22        
23        // initialize value of length and breadth
24        Rectangle obj = new Rectangle(12, 9);
25
26        // calculate the area
27        obj.calculateArea(); 
28    }
29}
30
31// Output:
32// Area: 108
```

In the above example, we have used a constructor to initialize the value of length and breadth.

```java
Rectangle(int length, int breadth) {
    this.length = length;
    this.breadth = breadth;
}
```

Remember this represents the current object, that is obj in this case.

You can see the calculateArea() method uses length and breadth fields to compute the area of the rectangle. Both these fields are also present inside the same class.

This is what encapsulation is all about, bundling the related data and method together.
