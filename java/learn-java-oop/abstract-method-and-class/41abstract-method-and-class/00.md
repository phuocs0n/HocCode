## Abstract Method

So far we have been creating methods like this:

```java
void makeSound() {
    System.out.println("Roar");
}
```

Here, the code inside the curly braces { } is the body of the method.

In Java, we can also create methods that don't have a body. These types of methods are known as abstract methods.

We use the abstract keyword to create abstract methods. For example,

```java
abstract void makeSound();
```

Here, makeSound() is an abstract method. The body of an abstract method is replaced by ;.

You might be wondering what is the use of methods if they don't have any code inside them.

Well, there are some uses of abstract methods in Java. Before learning about them, let's talk about abstract classes.
