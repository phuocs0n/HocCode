## Abstract Class

Normally, when we create a class, then we can create objects from the class. For example,

```java
class Animal {
    // class body
}

// object of Animal
Animal obj = new Animal();
```

Here, we are creating the object named obj of the Animal class.

In Java, we can also create abstract classes. Unlike the regular class, we cannot create objects of the abstract class. For example,

```java
1abstract class Polygon {
2    // code inside the class
3}
4
5class Main {
6    public static void main(String[] args) {
7        
8        // create object of Polygon
9        Polygon obj = new Polygon();
10    }
11}
```

Just like abstract methods, we have used the abstract keyword to create the abstract class Polygon.

When we run this code, we will get an error.

```java
error: Polygon is abstract; cannot be instantiated
Polygon obj = new Polygon();
                      ^
```

This is because we are trying to create an object of the abstract class which is not possible in Java.
