## Introduction to Polymorphism

Polymorphism is another important concept of object-oriented programming. It simply means more than one form. That is, the same entity (method or operator) can perform different operations in different scenarios.

Remember the working of the + operator. It can be used to perform numeric addition as well as string concatenation.

```java
1class Main {
2    public static void main(String[] args) {
3        
4        // use + to add two numbers
5        int result = 5 + 1;
6        System.out.println("Sum: " + result);
7
8        // use + to join two strings
9        String joinedString = "Hello " + "World";
10        System.out.println("Joined String: " + joinedString);
11    }
12}
```

Output

```text
Sum: 6
Joined String: Hello World
```

In the above example, we have used the same + operator to perform two different tasks:

- 5 + 1 - adds two numbers
- "Hello " + "World" - joins two strings

Here, the + operator has two different forms. It is an example of Polymorphism.
