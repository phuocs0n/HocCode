## Implement an Interface

Just like abstract classes, we cannot create objects of an interface. To use an interface, other classes must implement it.

We use the implements keyword to implement an interface. For example,

```java
interface Animal {

    abstract public void play(); 
    abstract public void makeSound();
}

class Dog implements Animal {

    // implement play()
    public void play() {
        System.out.println("I play ball fetch");
    }

    // implement makeSound()
    public void makeSound() {
        System.out.println("Woof Woof");
    }
}
```

Here, the Dog class implements the Animal interface. You can see the implementation of both the abstract methods play() and makeSound() are provided by the Dog class.

Now, we can access these methods using objects of Dog.


Output

```text

```

You can see we have successfully accessed the abstract methods of the interface by implementing them in the subclass Dog.
