## Interface Introduction

In the last lesson, we learned about abstract classes which can include both abstract and non-abstract methods.

In Java, we can also create a fully abstract class known as the interface. An interface contains all abstract methods.

Create an Interface

In Java, we use the interface keyword to create an interface.

```java
interface Animal {
    …
}
```

Here, we have created an interface named Animal.

As mentioned earlier, an interface contains only abstract methods. For example,

```java
interface Animal {

    abstract public void play(); 
    abstract public void makeSound();
}
```

Here, play() and makeSound() are two abstract methods inside the Animal interface.

Next, we will see how to use these methods of the interface.
