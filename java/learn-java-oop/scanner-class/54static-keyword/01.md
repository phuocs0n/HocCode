#### Course: Learn Java OOP

## Example: static Keyword

```java
1class Animal {
2
3    // method 
4    static void display() {
5        System.out.println("I am an animal.");
6    }
7    
8    // main method
9     public static void main(String[] args) {
10         
11         // access the method of Animal class
12         display();
13    }
14}
15
16// Output: I am an animal.
```

Here, you can see that we are able to directly access the method display() without using the object of the class. It's possible because we have created the method as static.

Similarly, we can access the static fields of the class. For example,

```java
1class Animal {
2    
3    static String type = "Mammal";
4    
5    // main method
6     public static void main(String[] args) {
7         
8         // access the method of Animal class
9         System.out.println("Animal Type: " + type);
10    }
11}
12
13// Output: Animal Type: Mammal
```
