## static Keyword

So far we have been using the object of the class to access fields and methods of a class. For example,

```java
1class Animal {
2
3    // method 
4    void display() {
5        System.out.println("I am an animal.");
6    }
7    
8    // main method
9     public static void main(String[] args) {
10        
11         // object of Animal class
12         Animal obj = new Animal();
13         
14         // access the method of Animal class
15         obj.display();
16    }
17}
```

Output

```text
I am an animal.
```

Here, we have used the object obj of the Animal class to access the method display() of the class.

However, there might be situations where we want to access fields and methods without creating the object. For this, we can use the static keyword.
