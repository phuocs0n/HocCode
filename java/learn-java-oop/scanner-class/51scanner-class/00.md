## Scanner class

Remember this code to take input from the user.

```java
1import java.util.Scanner;
2
3class Main {
4    public static void main(String[] args) {
5
6        Scanner input = new Scanner(System.in);
7
8        // take integer input from the user
9        System.out.print("Enter an integer: ");
10        int number = input.nextInt();
11
12        System.out.println("You entered " + number);
13
14        // closing the scanner object
15        input.close();
16    }
17}
```

Output

```text
Enter an integer: 3
You entered 3
```

Here, we have used Scanner to take input from the user. Notice the code,

```java
Scanner input = new Scanner(System.in);
```

This looks similar to the syntax of creating objects. It's because Scanner is a class that has various methods defined inside it and we are using the object to call those methods.

The System.in parameter is used to take input from the standard input (keyboard).

Also, the code import java.util.Scanner; is used to import the Scanner class in our program. Here, java.util is a package where Scanner is defined and the import keyword includes the package in our code.

We will explore this in our next course. For now, just remember that this code imports the Scanner class in our program.
