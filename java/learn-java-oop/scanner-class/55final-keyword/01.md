## final with Variable

Normally, we are allowed to change the value of a variable. For example,

```java
1class Main {
2    public static void main(String[] args) {
3        
4        // create final variable
5        int number = 34;
6        System.out.println("Number Value: " + number);
7        
8        // try to change the value of the final variable
9        number = 24;
10        System.out.println("Updated Number: " + number);
11    }
12}
```

Output

```text
Number Value: 34
Updated Number: 24
```

In the above example, you can see we have successfully changed the value of the number variable from 34 to 24.

Now, let's see what happens if we mark the number variable as final.

```java
1class Main {
2    public static void main(String[] args) {
3        
4        // create final variable
5        final int number = 34;
6        System.out.println("Number Value: " + number);
7        
8        // change the value of the final variable
9        number = 24;
10        System.out.println("Updated Number: " + number);
11    }
12}
```

Here, notice the code

```java
final int number = 34;
```

We have used the final keyword with the number variable.

Now, if we run the code, we will get an error.

```java
error: cannot assign a value to final variable number
number = 24;
^
```

As the error message says, we are not allowed to change the value of a final variable.

These types of variables whose values cannot be changed are known as constants. Hence, we use the final keyword to create constants in Java.
