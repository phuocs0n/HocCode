## super with Constructor

In Java, there is another variation of super that is used to call the constructor of superclass from the subclass. Let's see an example.

```java
1class Animal {
2
3    // constructor of class Animal
4    Animal() {
5        System.out.println("I am an animal");
6    }
7}
8
9class Dog extends Animal {
10
11    // constructor of class Dog
12    Dog() {
13        // calls the constructor of superclass
14        super();
15        System.out.println("I am a dog");
16    }
17}
18
19class Main {
20
21    public static void main(String[] args) {
22        Dog dog1 = new Dog();
23    }
24}
```

Output

```text
I am an animal
I am a dog
```

In the above example, notice the constructor of the Dog class.

```java
Dog() {
    super();
    System.out.println("I am a dog");
}
```

Here, super() calls the constructor of the Animal class. When we create the object of Dog, the subclass constructor is invoked which:

1. calls the constructor of the Animal class and prints I am an animal
2. then executes the statement to print I am a dog
