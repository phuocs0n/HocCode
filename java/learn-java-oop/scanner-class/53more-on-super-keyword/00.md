## Revise super

During method overriding, the super keyword allows us to access the method of the superclass from the subclass. Let's see an example.

```java
1class Person {
2    
3    void display() {
4        System.out.println("I am a person");
5    }
6}
7
8class Student extends Person {
9    
10    void display() {
11        
12        // call 
13        super.display();
14        System.out.println("I am a student");
15    }
16}
17
18class Main {
19    public static void main(String[] args) {
20
21        Student s1 = new Student();
22        s1.display();
23    }
24}
```

Output

```text
I am a person
I am a student
```

Here,

```java
super.display();
```

calls the overridden method of the superclass.

We can also use super with the constructor which we will see next.
