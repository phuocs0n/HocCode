## Introduction

In the previous lesson, we learned that during inheritance, the child class inherits methods and fields of the parent class. For example,

```java
1class Animal {
2    void makeSound() {
3        System.out.println("Animal Sound");
4    }
5}
6
7class Dog extends Animal {
8
9}
10
11class Main {
12    public static void main(String[] args) {
13
14        Dog dog1 = new Dog();
15        dog1.makeSound();
16    }
17}
18
19// Output: Animal Sound
```

Here, the Dog class doesn't have the makeSound() method, however, it is able to access it because of inheritance.
