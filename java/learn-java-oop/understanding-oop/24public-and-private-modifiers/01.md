## Access Modifiers

In the previous lesson, we learned to create more than one class in our Java program. We also see that one class can access fields and methods of other classes.

However, there might be situations where we wouldn't want our field and methods to be accessed from another class. To solve this, we use access modifiers in Java.

Access modifiers are used to set the visibility of fields, methods, and even classes. For example, if we don't want our fields/methods to be accessed from other classes, we can mark the field as private using the private access modifier.

```java
class Student {

    private int age;

    private void displayName() {
        ...   
    }
}
```

In this lesson, we will learn about two major types of access modifiers in Java.

- public - allows access from other classes
- private - prevents access from other classes
