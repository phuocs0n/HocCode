## Java Constructors

In Java, a constructor is similar to a method, but it doesn't have a return type and it has the same name as the class. For example,

```java
class Student {

    // constructor
    Student() {
        ...
    }

    // method
    void checkName() {
        ...
    }
}
```

In the above example, Student() is a constructor and checkName() is a method. You can see that the constructor doesn't have a return type and it has the same name as the class (Student).

Similar to methods, we need to call a constructor to execute code inside it.

In Java, when we create an object, the constructor is called automatically. Let's see an example,

```java
1class Student {
2
3    // constructor
4    Student() {
5        System.out.println("Calling Constructor");
6    }
7}
8
9class Main {
10    public static void main(String[] args) {
11        
12        // create an object of Student
13        // this calls the constructor
14        Student student1 = new Student();
15        
16    }
17}
```

Output

```text
Calling Constructor
```

Here, the code Student student1 = new Student(); calls the constructor. That's why we get the output.
