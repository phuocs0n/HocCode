## Understanding OOP

Java is an object-oriented programming language where we solve complex problems by dividing them into objects.

1. Create a class

```java
class Student {
  
}
```

Here, Student is the name of the class. A class can have fields (to store data) and methods (to perform operations).

```java
class Student {

    // field
    String name;

    void displayName() {
        ...
    }
}
```

2. Create Objects

Here's how we create objects in Java

```java
Student student1 = new Student();
```

Now we can use the student1 object to access the fields and methods of a class. For example,

```java
1class Student {
2    // field
3    String name;
4    
5    // method
6    void displayName() {
7        System.out.println("This method displays name.");
8    }
9    
10    public static void main(String[] args) {
11        
12        // create an object of Student
13        Student student1 = new Student();
14        
15        // access the field
16        student1.name = "Alex";
17        System.out.println("Name: " + student1.name);
18        
19        // access the method
20        student1.displayName();
21    }
22}
```

Output

```text
Name: Alex
This method displays name.
```
