# Compute the area of a rectangle

#### Course: Learn Java OOP

## Compute the area of a rectangle

As we are computing the area of the rectangle, we will create a class named Rectangle. Inside the class, we will create:

- fields - length and breadth
- constructor - assign values to length and breadth
- method - to compute the area of a rectangle

#### Source Code

```java
1class Rectangle {
2    // fields
3    int length;
4    int breadth;
5    
6    // constructor
7    Rectangle(int length, int breadth) {
8        this.length = length;
9        this.breadth = breadth;
10    }
11    
12    // method
13    int computeArea() {
14        int area = this.length * this.breadth;
15        return area;
16    }
17}
18
19class Main {
20    public static void main(String[] args) {
21        
22        // object of Rectangle
23        Rectangle rectangle1 = new Rectangle(12, 8);
24        
25        // call the method to compute area
26        int area = rectangle1.computeArea();
27        System.out.println("Area: " + area);
28    }
29}
```

Output

```text
Area: 96
```

In the above example, when we create the rectangle1 object, the value of length and breadth for rectangle1 is 12 and 8.

Here, we have called the computeArea() method with rectangle1, so inside the computeArea() method, this.length * this.breadth becomes 12 * 8. Hence, we get 96 as output.
