# Java Constructors

#### Course: Learn Java OOP

## Java Constructors

A constructor is similar to methods but doesn't have a return type. It has the same name as the class name.

```java
class Student {

    Student() {
        ...
    }
}
```

Here, Student() is the constructor.

1. parameterized Constructor

A constructor can also accept parameters. For example,

```java
1class Student {
2    
3    Student(String name) {
4        System.out.println("Name: " + name);
5    }
6    
7    public static void main(String[] args) {
8        
9        Student student1 = new Student("Thomas");
10
11    }
12}
```

Output

```text
Name: Thomas
```

2. this Keyword

We use the this keyword to refer to the current object. For example,

```java
1class Student {
2
3    String name;
4
5    Student(String name) {
6        // this.name refers to student1.name
7        this.name = name;
8    }
9
10    public static void main(String[] args) {
11
12        Student student1 = new Student("Thomas");
13
14        System.out.println("Name: " + student1.name);
15
16    }
17}
```

Output

```text
Name: Thomas
```
