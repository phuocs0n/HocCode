## Introduction

In the first part of this interactive Java course, we learned the fundamental concepts of Java and programming in general. If these concepts below don't ring a bell for you, we suggest taking the Java Basics Course first.

- The if...else statement
- Loops
- Methods
- Strings and Arrays
- Taking input from the user

However, if you are comfortable writing programs involving these topics, it's time to understand Java on a deeper level. That's what this course is about.

In this course, we will mainly focus on Object-oriented Programming (OOP).

After understanding these concepts, you will gain a better understanding of Java in terms of Object-oriented approach.
