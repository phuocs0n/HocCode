## Step 3: Get the User's Pick

### Project Changes

- added the getUserPick() method

```java
import java.util.Scanner;

class Game {

    String getComputerPick() {

        String computerPick;
        // get an integer from 1 to 3
        int randomNumber = (int) (Math.random() * 3) + 1;

        if (randomNumber == 1) {
            computerPick = "rock";
        }

        else if (randomNumber == 2) {
            computerPick = "paper";
        }

        else {
            computerPick = "scissors";
        }

        return computerPick;
    }

    String getUserPick() {

        Scanner input = new Scanner(System.in);

        System.out.println("Enter rock, paper or scissors:");

        String userPick = input.nextLine();

        return userPick;
    }
}
```

Inside the getUserPick() method

The user is asked to enter a string.

If the user enters any other strings other than "rock", "paper", or "scissors", we cannot compare it with the computer's pick.

To solve this issue, let's modify the getUserPick() method so that the user is asked to enter input again and again until the user enters a valid string.
