## Extending the Project

### Running the game n times

Suppose we want to run our game 5 times. We can do that using the for loop.

```java
Game game = new Game();
    
    for(int i =1; i <=5; i++) {
      
        String userPick = game.getUserPick();
        String computerPick = game.getComputerPick();
        String result = game.getResult(userPick, computerPick);

        System.out.println("User Pick: " + userPick);
        System.out.println("Computer Pick: " + computerPick);
        System.out.println("You " + result);
      
}
```

### Asking the user to play the game again

Suppose we want to ask the user if they want to play the game again after a game is completed. Here's how we can do it.

```java
while (true) {
    Game game = new Game();
    String userPick = game.getUserPick();
    String computerPick = game.getComputerPick();
    String result = game.getResult(userPick, computerPick);

    System.out.println("User Pick: " + userPick);
    System.out.println("Computer Pick: " + computerPick);
    System.out.println("You " + result);
      
    Scanner input = new Scanner(System.in);
      
    System.out.println("Do you want to play again? (y/n): ");
      
    String playAgain = input.nextLine();
      
    // if user enter any other character other than y, the game ends
    if (!(playAgain.equals("y"))) {
        break;
    }
}
```

Now, each time a game is completed, the user is asked whether they want to play the game again or not. If the user enters "y", the game will run again because of the infinite loop.
