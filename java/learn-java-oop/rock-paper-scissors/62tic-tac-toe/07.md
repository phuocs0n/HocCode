The checkWinner() method

This method checks if three same symbols (type) appear in a row. If that's the case, the player with that symbol won the game. In that case, we have returned true else we have returned false.

We will later call this method from inside the play() method of the Game class.

By the way, the if condition inside the class is very large. That's why we have written it in multiple lines.

The checkDraw() method

If all fields of the board are filled and still there is no winner, then it's a draw. To check if all the fields are filled, we have created a count variable.

Inside the updateBoard() method, we are increasing the value of count by 1, every time the board updates.

That means the value of count is 1 when one element of the board is filled. Similarly, when all 9 elements of the board are filled, the value of count will be 9.

This means the condition

(count == 9)

is met. So, the checkDraw() method will return true.

We will later call this method from inside the play() method of the Game class.
