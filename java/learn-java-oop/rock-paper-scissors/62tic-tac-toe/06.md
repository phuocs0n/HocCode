The updateBoard() method

This method takes two arguments:

- position - the position selected by the user (an integer)
- type - if the current player is player1, it will be "X" otherwise it will be "O".

This method checks if the position is already filled or not. If it's not filled, we will update the board and true is returned. However, if the position is already filled, a message is shown and false is returned.

By the way, we have used board[position - 1] to update the board. It's because a player selects position 2, which means we have to update index 1 of the list. Remember that the array index starts from 0.

The play() method

Inside the method, we have a while loop to run the game continuously; we will add logic to terminate the loop later.

Inside the loop, we asked the user to enter the position between 1 and 9.

Then, we called the updateBoard() method of the Board class. To call this method we have used board.updateBoard().

We have called the updateBoard() method with parameters position and the current player type.

If the position passed to updateBoard() is not already selected, true is returned. In that case, the currentPlayer is changed to the next player.
