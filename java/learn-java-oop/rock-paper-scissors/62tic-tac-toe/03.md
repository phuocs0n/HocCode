## Step 1: Creating the Board Class

```java
1class Board {
2
3    String board[] = { " ", " ", " ", " ", " ", " ", " ", " ", " " };
4
5    void printBoard() {
6
7        System.out.println(" " + board[0] + " | " + board[1] + " | " + board[2]);
8        System.out.println("-----------");
9        System.out.println(" " + board[3] + " | " + board[4] + " | " + board[5]);
10        System.out.println("-----------");
11        System.out.println(" " + board[6] + " | " + board[7] + " | " + board[8]);
12
13    }
14}
15
16class Main {
17    public static void main(String[] args) {
18
19        Board b1 = new Board();
20
21        b1.printBoard();
22    }
23}
```

Output

```text
|   |  
-----------
   |   |  
-----------
   |   |
```

Here, the Board class has a field named board which is an array of nine elements. Initially, the value of each element is a space. We will update these elements with either X or O symbols once the players start choosing the position.

And, the printBoard() method prints the board in a visually intuitive manner.

We have created an object of the Board class inside the Main class. Then, we have called the printBoard() method using the object of the Board class.

We will add other methods to the Board class later. Next, we will create the Player class.
