## Example: Decimal to Binary

In this example, we will create a program to convert decimal numbers to binary numbers.

For example, 6 in the decimal system is equal to 110 in binary.

Converting Decimal Numbers to Binary

We can convert a decimal number to binary by dividing the number by 2 and keeping track of the remainder at each step.

Here's the step-by-step process:

1. Divide the decimal number by 2.
2. Record the remainder. It will be either 0 or 1.
3. Use the quotient (the result of the division) from the previous step as the new number to divide by 2.
4. Repeat steps 1 through 3 until the quotient becomes 0.
5. The binary equivalent is the series of remainders read from bottom to top (or from the last remainder obtained to the first).

Let's see how we can convert the decimal number 6 to binary.

| Quotient | Remainder | Result |
| --- | --- | --- |
| 6 / 2 = 3 | 6 % 2 = 0 | 0 |
| 3 / 2 = 1 | 3 % 2 = 1 | 10 |
| 1 / 2 = 0 | 1 % 2 = 1 | 110 |
