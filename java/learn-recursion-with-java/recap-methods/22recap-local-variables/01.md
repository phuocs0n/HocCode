## Local Variables

Now, let's see how we can use the value returned by the method.

```java
1class Main {
2
3    // Method that returns a value
4    // Return type changed from 'void' to 'int'
5    public static int addNumbers(int n1, int n2) {
6
7        int result = n1 + n2;
8        return result;
9    }
10
11    public static void main(String[] args) {
12
13        // Call the method and store the returned value
14        int result = addNumbers(2, 5);
15        System.out.println(result);
16    }
17}
18
19// Output: 7
```

Here, we did not directly use the local variable. Instead, we returned the value to the method call and used the returned value by storing it in a variable.
