## Introduction

The concept of local variables is critical in recursion since each recursive call possesses a separate local variable.

Thus, we must revisit this topic here.

### Local Variables

Any variable that is created inside a method is local to it. For example,

```java
1class Main {
2
3    // Method that doesn't return a value
4    public static void addNumbers(int n1, int n2) {
5        int result = n1 + n2;
6    }
7
8    public static void main(String[] args) {
9
10        addNumbers(2, 5);
11
12        // Error: attempt to print result variable
13        System.out.println(result);
14    }
15}
```

Here, n1, n2, and result are local variables that are defined within the scope of addNumbers(). When the execution of addNumbers() ends, all of these variables are destroyed.

Thus, the above program throws an error when we try to access these variables from the main() method.

It's because the result variable only exists within addNumbers(); it doesn't exist inside main().
