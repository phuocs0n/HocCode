# Why Are Local Variables Important?

#### Course: Learn Recursion With Java

## Why Are Local Variables Important?

Local variables are important because they make methods independent. Variables local to a method cannot be modified from outside, thus making methods self-contained.

Hence, we don't need to know what's inside a method and what variables are used. We can simply use the method if we know two things:

1. Arguments that the method takes.
2. Return value from the method.

Source Code

```java
1class Main {
2
3    public static int addNumbers(int n1, int n2) {
4
5        int result = n1 + n2;
6        return result;
7    }
8
9    public static void main(String[] args) {
10
11        int n1 = 2;
12        int n2 = 5;
13
14        int result = addNumbers(n1, n2);
15
16        System.out.println(result);
17    }
18}
19
20// Output: 7
```

In the program, it's essential to understand that the n1, n2, and result variables inside the method are local to the addNumbers() method.

They are different from any n1, n2, and result variables that are outside of the method, even if their names and values are the same.

These outside variables can also be written using different variable names. Thus, the above program is equivalent to the one below:

```java
1class Main {
2
3    public static int addNumbers(int n1, int n2) {
4
5        int result = n1 + n2;
6        return result;
7    }
8

14        int result = addNumbers(num1, num2);

16        System.out.println(result);
17    }
18}

```
