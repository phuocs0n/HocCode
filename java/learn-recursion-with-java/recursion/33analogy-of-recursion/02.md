## Important Things to Focus On

To conclude this analogy, we need to focus on two things while programming recursion.

1. What should be done in each recursive call? (Recursive Call)

In each recursive call, we need to ask the person in front about their position.

Once they return their position, we need to add 1 to it.

2. When should the recursion stop? (Base Case)

The base case is the stopping condition for recursion.

The recursive call can stop when it reaches the first person. Thus, the base case here is when the question reaches the first person.

Emily, the first person, doesn't need to perform any calculations to know her position. So, Emily can simply return 1 as her position, making this our base case.

At every step, we're gradually simplifying our problem until we can't simplify it anymore, which is when we reach the base case.
