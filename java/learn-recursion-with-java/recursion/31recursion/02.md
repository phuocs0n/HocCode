## Infinite Recursion

Here's a slight modification to the program we previously wrote:

```java
1class Main {
2
3    public static void printNumbers(int n) {
4
5        System.out.println(n);
6        
7        // Argument is decreased by 1 in each recursive call
8        printNumbers(n - 1);
9    }
10
11    public static void main(String[] args) {
12
13        // Initial method call
14        printNumbers(100);
15    }
16}
```

Output

```text
100
99
98
97
96
...
```

Here, we have initially called the printNumbers() method with 100 as an argument. The method prints the value and calls itself recursively with n - 1 (which is 99) as the argument.

Now, let's look at what happens during each recursive call.

1. First Recursive Call

- n is 99, which is printed.
- printNumbers(98) is called.

1. Second Recursive Call

- n is 98, which is printed.
- printNumbers(97) is called.

Essentially, the value of the argument is reduced by one in each subsequent method call.
