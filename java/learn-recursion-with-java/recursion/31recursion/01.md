## Infinite Recursion

Here is an example of infinite recursion with arguments.

```java
1class Main {
2
3    public static void printNumbers(int n) {
4
5        System.out.println(n);
6
7        // Recursive call
8        printNumbers(n);
9    }
10
11    public static void main(String[] args) {
12
13        // Initial method call
14        printNumbers(100);
15    }
16}
```

Output

```text
100
100
100
100
...
```

Here, we have called the printNumbers() method with 100 as an argument. The method prints the value and calls itself recursively with the same value n as argument.

Now, let's look at what happens during each recursive call.

1. First Recursive Call

- n is 100, which is printed.
- The printNumbers() method is called again with 100 as an argument.

2. Second Recursive Call

- n is 100 again, which is printed.
- The printNumbers() method is called again with 100 as an argument.

Essentially, this program will run continuously with 100 as an argument in each method call.
