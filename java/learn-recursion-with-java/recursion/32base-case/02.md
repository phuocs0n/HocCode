## Base Case for Recursion

Consider the following program to print numbers:

```java
1class Main {
2
3    public static void printNumbers(int n) {
4
5        System.out.println(n);
6        printNumbers(n + 1);
7    }
8
9    public static void main(String[] args) {
10        printNumbers(1);
11    }
12}
```

Output

```text
1
2
3
...
```

This program displays numbers infinitely because it lacks a stopping condition.

Now, let's add a base case so that the program ends after displaying 2.

```java
1class Main {
2
3    public static void printNumbers(int n) {
4
5        // Base case to terminate recursion
6        if (n == 3) {
7            return;
8        }
9
10        // Execute code if base case is not met
11        System.out.println(n);
12
13        // Recursive call with increment
14        printNumbers(n + 1);
15    }
16
17    public static void main(String[] args) {
18        printNumbers(1);
19    }
20}
```

Output

```text
1
2
```

In the program, we have added the following base case:

```java
if (n == 3) {
    return;
}
```

If n is equal to 3, the method encounters the return statement, and the recursive calls end.

By the way, we can always use an object to call the method instead of using a static method.

Here's the equivalent code.

```java
1class Main {
2
3    public void printNumbers(int n) {
4
5        // Base case to terminate recursion
6        if (n == 3) {
7            return;
8        }
9
10        // Execute code if base case is not met
11        System.out.println(n);
12
13        // Recursive call with increment
14        printNumbers(n + 1);
15    }
16
17    public static void main(String[] args) {
18
19        Main obj = new Main();
20        obj.printNumbers(1);
21    }
22}
```
