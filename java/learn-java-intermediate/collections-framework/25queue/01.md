## LinkedList as Queue

LinkedList class in Java implements the Queue and the Deque interfaces. Hence, LinkedList can provide functionality queue and deque data structures as well.

In this section, we will learn how we can use LinkedList as a Queue data structure.

To use LinkedList as a queue, we use the following two methods:

- poll() - removes elements from the front
- offer() - adds elements from the back

Let's see an example:

```java
1import java.util.LinkedList;
2
3class Main {
4    public static void main(String[] args) {
5
6        // create a LinkedList
7        LinkedList<String> patient = new LinkedList<>();
8
9        // add elements
10        patient.add("1st Patient");
11        patient.add("2nd Patient");
12        patient.add("3rd Patient");
13
14        System.out.println("Original LinkedList: " + patient);
15
16        // removes element from the front
17        patient.poll();
18        System.out.println("Queue after poll(): " + patient);
19
20        // adds element at the back
21        patient.offer("4th Patient");
22        System.out.println("Queue after offer(): " + patient);
23    }
24}
```

Output

```text
Original LinkedList: [1st Patient, 2nd Patient, 3rd Patient]
Queue after poll(): [2nd Patient, 3rd Patient]
Queue after offer(): [2nd Patient, 3rd Patient, 4th Patient]
```

In the above example, we have removed an element from the front of the LinkedList, using the poll() method.

```java
patient.poll();
```

It removes the first element from the LinkedList.

To add elements to the end, we used the offer() method.

```java
patient.offer("4th Patient");
```

It adds 4th Patient to the end of the patient linkedlist.
