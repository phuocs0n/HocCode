## Duplicate Items in a Set

As mentioned earlier, we cannot store duplicate elements in a hashset. Let's see what happens if we add a duplicate element.

```java
1import java.util.HashSet;
2
3class Main {
4    public static void main(String[] args) {
5
6        // create HashSet 
7        HashSet<String> animals = new HashSet<>();
8
9        // add elements
10        animals.add("tiger");
11        animals.add("dog");
12        animals.add("elephant");
13        animals.add("elephant");
14
15        // print HashSet
16        System.out.println(animals);
17    }
18}
```

Output

```text
[tiger, dog, elephant]
```

In the above example, we have added elephant two times to the hashset. However, it is stored only once inside the hashset.
