# Create an ArrayList from another Arraylist

#### Course: Learn Java Intermediate

## Create an ArrayList from another Arraylist

We can create an ArrayList with elements from an existing ArrayList. We use addAll() method to add all the elements of an arraylist to another arraylist. Let's see an example:

```java
1import java.util.ArrayList;
2
3class Main {
4    public static void main(String[] args) {
5
6        // create an arraylist of asianCountries
7        ArrayList<String> asianCountries = new ArrayList<>();
8        asianCountries.add("Nepal");
9        asianCountries.add("China");
10        asianCountries.add("India");
11        System.out.println("Asian Countries: " + asianCountries);
12
13        // create another arraylist of countries
14        ArrayList<String> countries = new ArrayList<>();
15
16       // add all elements from asianCountries to countries
17       countries.addAll(asianCountries);
18
19        System.out.println("Countries: " + countries);
20    }
21}
```

Output

```text
Asian Countries: [Nepal, China, India]
Countries: [Nepal, China, India]
```

In the above example, we have created an arraylist with elements Nepal, China, and India. Then we created another arraylist countries.

Notice the line,

```java
countries.addAll(asianCountries);
```

Here, the addAll() method adds all the elements from asianCountries to countries arraylist.

Let's see one more example:

```java
1import java.util.ArrayList;
2
3class Main {
4    public static void main(String[] args) {
5
6        // create an arraylist of asianCountries
7        ArrayList<String> asianCountries = new ArrayList<>();
8
9        // add elements to asianCountries
10        asianCountries.add("Nepal");
11        asianCountries.add("China");
12        asianCountries.add("India");
13        System.out.println("Asian Countries: " + asianCountries);
14
15        // create another arraylist of countries
16        ArrayList<String> countries = new ArrayList<>();
17
18        // add elements to countries
19        countries.add("USA");
20        countries.add("Canada");
21
22        // add all elements from asianCountries to countries
23        countries.addAll(asianCountries);
24
25        System.out.println("Countries: " + countries);
26    }
27}
```

Output

```text
Asian Countries: [Nepal, China, India]
Countries: [USA, Canada, Nepal, China, India]
```

In the above program, the arraylist countries has elements USA and Canada.

Hence, the addAll() method adds all elements from the arraylist asianCountries at the end of the arraylist countries.
