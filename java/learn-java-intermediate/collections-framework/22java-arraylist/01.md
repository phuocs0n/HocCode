## Create ArrayList

The ArrayList class is defined inside the Java collections framework, so to use an arraylist, we first have to import the ArrayList package.

```java
import java.util.ArrayList;
```

Once we import the package, we can create an object of the ArrayList class.

```java
ArrayList<String> names = new ArrayList<>();
```

Here, we have created a String type arraylist, names.

Now, we can use this arraylist to store the names.
