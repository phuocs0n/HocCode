The updateBoard() method

This method takes two arguments:

- position - the position selected by the user (an integer)
- type - If the current player is player1, it will be X otherwise it will be O.

This method checks if the position is already filled or not. If it's not filled, we will update the board and true is assigned to returnValue. However, if the position is already filled, a message is shown and false is assigned to returnValue.

Inside the updateBoard() method.

```java
if (board.get(position - 1).equals(" ")) {

    board.set(position - 1, type);
    returnValue = true;
```

By the way, we have used,

- board.get(position - 1) - to access the element at position - 1. It's because a player selects position 2, which means we have to update index 1 of the list. Remember that the ArrayList index starts from 0.
- board.set(position - 1, type) - to update the board. It changes the element at position - 1 with the value of type. As the element is already filled, we are using the set method instead of add() method.

The play() method

Inside the method, we have added elements to the board arrayList. Then we have used a while loop to run the game continuously; we will add logic to terminate the loop later.

Inside the loop, we asked the user to enter the position between 1 and 9.

Then, we called the updateBoard() method of the Board class. To call this method we have used b1.updateBoard().

We have called the updateBoard() method with parameters position and the current player type.

If the position passed to updateBoard() is not already selected, true is returned. In that case, the currentPlayer is changed to the next player.
