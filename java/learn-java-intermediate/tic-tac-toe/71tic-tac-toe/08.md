## Step 7: Completing the Game

### Project Changes

- Added try catch block inside the play() method.
- Added try catch block inside the updateBoard() method.

There are two places in our code that may raise an exception.

- If a user enters an invalid position (like strings). So we need to wrap that code inside try catch.
- If the position - 1 (position is selected by the user) by the user is not in the ArrayList. For example, our board ArrayList has 9 elements. If the user selects 100 as a position, we cannot fill this position in the list and results in an exception.

Let's handle these situations:
