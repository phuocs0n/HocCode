Now, we have added the Player class.

The constructor is used to get the name of the players. It takes a parameter type. type is used for symbols either X or O.

We will assume that the first player will always take the X symbol and the second player will always take the O symbol.

Inside the Main class, we have created two objects player1 and player2 of the Player class.We have passed X and O to player1 and player2 respectively while creating their objects.
