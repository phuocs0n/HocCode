Here, in the Board class, we have created a board to play tic-tac-toe.

We have an arraylist board which can hold String data.

The addElements() method adds nine elements to the ArrayList.

```java
board.add(" ");
```

We have used the add() method to add elements in the ArrayList. Initially, the value of each element is a space. We will update these elements with either X or O symbols once the players start choosing the position.

And, the printBoard() method prints the board in a visually intuitive manner.

We have created an object of the Board class inside the Main class. Then, we have called the addElements() method to add elements in the ArrayList. Then, we have called the printBoard() method.
