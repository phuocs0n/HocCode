Here, we have added the returnBook() method.

We have removed the issueBook() method call from the main() method and added returnBook() method call.

In order to return the book, student must have issued the book. So first, we check if the issue HashMap contains the studentId.

```java
if (issue.containsKey(id)) {
    …

    …

}
```

Here, the containsKey() checks if the student id is present inside the issue hashmap. If so, we get the bookId.

```java
//get book id
 int bookId = 0;
// iterate each entry of hashmap
for (Entry<Integer, String> entry : b1.book.entrySet()) {

    // if give value is equal to value from entry
    // print the corresponding key
    if (entry.getValue().equals(bookName)) {
        bookId = entry.getKey();

 }
```

And remove it from the issue hashmap.

```java
// remove issue record form issue HashMap
issue.remove(id);
```

The remove() method removes the book with the key id from the issue hashmap.

After that, we put the record of the book inside a book hashmap.

```java
b1.book.put(bookId, bookName);
```

We use the value of bookId as the key and bookName as value.
