## Step 1: Creating the Student Class

```java
1import java.util.HashMap;
2import java.util.Scanner;
3
4class Student {
5
6    HashMap<Integer, String> student = new HashMap<>();

8
9    // add students
10    void add() {
11        student.put(101, "Niall");
12        student.put(102, "Anna");
13    }
14
15    // register student
16    void addStudent() {
17
18        System.out.println("Enter your name: ");
19        String name = input.next();

21        int id = input.nextInt();
22        student.put(id, name);
23    }
24
25}
26
27class Main {
28
29    public static void main(String[] args) {
30        Student s1 = new Student();

32        s1.addStudent();
33
34    }
35
36}
```

Output

```text
Enter your name: 
Harry
Enter your id: 
103
```

Here, in the Student class, we have created a HashMap named student.

```java
HashMap<Integer, String> student = new HashMap<>();
```

Here, we will store the id and name of the student.

Then, we have two methods:

- add() - we have added some students manually
- addStudent() - to add new students

We have created an object of the Student class inside the Main class. Then, we have called the add() and addStudent() method.
