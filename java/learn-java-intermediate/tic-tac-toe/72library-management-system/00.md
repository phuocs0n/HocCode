## Project Introduction

In this project, we will create a simple Library Management System. We will use HashMap in this project. So, be sure you revise the concept before you proceed.

### Working of the project

Here's how our project works:

- Registered Students can issue books from the library.
- Registered Students can return books to the library.
- Students can register themselves in the library.
