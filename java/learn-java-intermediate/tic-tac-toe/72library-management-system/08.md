A student can only use the library if they are a member of the library.

So, we have created the object of the Student class and called the add() method.

Then, we ask them to enter their id.

If the id is registered, that is if the student hashmap contains the item with that id, the getPurpose() method is called.

If the id is not registered then we ask the user if they would like to be a member. If they say yes, we register them using the addStudent() method of the Student class.
