We have updated the issueBook() method.

We can only issue the book that is in the library, so we will first check if the book is in the library.

```java
if (b1.book.containsValue(bookName)) {

    …
    … 
    …
}
```

Here, the containsValue() checks if the entered bookName is present inside the book HashMap.

If the book is present inside the book HashMap, we need to remove the book from the book HashMap and add it to the issue HashMap.

To remove the book from the book HashMap, we need to get its id.

```java
int bookId = 0;
       
for (Entry<Integer, String> entry : b1.book.entrySet()) {
         
    if (entry.getValue().equals(bookName)) {
        bookId = entry.getKey();
        break;
    }
}
```

Here, the entrySet() method returns a set view of all the entries.

- entry.getValue() - gets value from the entry
- entry.getKey() - gets key from the entry

To use the entrySet method we must import java.util.Map.Entry.

Inside the if statement we check if the value from the entry is the same as the bookName. And, for matching value, we get the corresponding key and store it in bookId.

Then, we have removed the book from the book HashMap.

```java
// remove book from the book hashmap
b1.book.remove(bookId);
```

Then, we finally issue the book to the user. To issue the book we put the id of the student as the key and bookName as the value inside the issue hashmap.

```java
issue.put(id, bookName);
```

Then, we also printed the name of the student and book issued.

However, if book is not there we simply print

```java
Book doesn't exist
```

And the list of books we have.
