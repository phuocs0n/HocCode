## Implementing Functional Interface

Let's see how our code looks without lambda expressions.

```java
1@FunctionalInterface
2interface AddNumber {
3    void add();
4}
5
6class Main {
7    public static void main(String[] args) {
8
9        AddNumber ref = new AddNumber() {
10
11            public void add() {
12                System.out.println(4 + 5);
13            }
14        };
15
16        ref.add();    // 9
17    }
18}
```

We have implemented the interface in a different way than before.

```java
AddNumber ref = new AddNumber() {
      
    public void add() {
        
        System.out.println(4 + 5);       
    }
};
```

As you know, we must implement an interface to use it.

This code creates an anonymous class (class without name) which implements the AddNumber interface. It provides the implementation of the add() method.

```java
ref.add();
```

We can access the add() method by using object ref of the anonymous class.
