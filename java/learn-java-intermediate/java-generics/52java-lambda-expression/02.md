## Lambda Expressions

Lambda expressions are just like regular methods but a lambda expression doesn't have a name. For example,

Here, we have a regular method from the earlier example

```java
public void add() {
    System.out.println(4 + 5)
}
```

We can replace this method using a lambda expression like this

```java
() -> System.out.println(4 + 5);
```

This is an example of a lambda expression that prints the sum of 4 and 5.

By looking at the above example, we can see that the syntax of lambda expression is:

```java
() -> lambda body
```

Here,

- -> - arrow operator or lambda operator
- lambda body - code present inside the body of a method is kept inside the lambda body
