## Introduction

Before you learn about lambda expressions in Java, you need to understand a few important concepts first.

Java Interface

You have learned about the interface in the previous tutorial. We will have a quick revision of the Java interface.

We use the interface keyword to create an interface in Java.

```java
interface Animal {

    void play(); 
    void makeSound();
}
```

Here, Animal is an interface. We can create abstract methods inside the interface.

```java
void play();
```

is an abstract method (method without body). To use the interface, we must implement it in a class.

Functional Interface

If a Java interface contains one and only one abstract method (method without a body) then it is a functional interface.

```java
interface AddNumber{  
  
    void add();
  
}
```

Here, the interface AddNumber has only one abstract method add(). Hence, it is a functional interface.

We can also use @FunctionalInterface annotation to indicate an interface as a functional interface.

```java
@FunctionalInterface  
interface AddNumber{  
 
    void add(); 
}
```

@FunctionalInterface annotation, allows one and only one abstract method.
