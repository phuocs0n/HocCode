## Example: Generics Methods

We use Generics methods to work with every type of data.

```java
public <T> void printAll(T[] numbers) {

    for (T number : numbers) {
        System.out.println(number);
    }
}
```

We have created a generics method named printAll(). It takes an array as a parameter. We can use this method to loop through and print the array of any type.

Let's see how this works:
