## Lambda Expressions

We use lambda expression to implement the method of functional interface.

```java
1@FunctionalInterface
2interface Greetings {
3
4    public void printGreeting();
5}
6
7class Main {
8
9    public static void main(String[] args) {
10
11        // lambda expression
12        Greetings ref = () -> System.out.println("Hey there! ");
13
14        ref.printGreeting();
15    }
16}
```

Output

```text
Hey there!
```
