## Generics Class

We can also create our own generics class that can be used with any type of data.

```java
// create a generics class
class MyClass<T> {

    public MyClass(T data) {
        System.out.println("Data: " + data);
    }
}
```

Here,

- MyClass - name of generics class
- T - type parameter that indicates the type of data

Now, we can use any type of data with MyClass.

1. Working with Integer data

```java
// create an object
MyClass<Integer> intObj = new MyClass<>(8);
```

When we create the object of class MyClass, the MyClass constructor will be called. In this case, the T type parameter is Integer. So, we can use only Integer data with intObj.

2. Working with String data

```java
MyClass<String> stringObj = new MyClass<>("Hello");
```

In this case, the T type parameter is String. So, we can use only String data with stringObject.
