## Example: Generics Class (I)

```java
1// create a generics class
2class MyClass<T> {
3
4    public MyClass(T data) {
5        System.out.println("Data: " + data);
6    }
7}
8
9class Main {
10    public static void main(String[] args) {
11
12        // MyClass object with Integer data
13        MyClass<Integer> intObj = new MyClass<>(8);
14
15    }
16}
```

Output

```text
Data: 8
```

The T type parameter is Integer. So, we can only work with Integer data with intObj object.
