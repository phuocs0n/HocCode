## Nested class

Generally, in Java we create a class and create fields and methods inside it.

```java
class CPU {

    // fields
    // methods
  
}
```

However, we can create a class inside a class inside a class.

```java
// outer class
class CPU {

    // nested class
    class Processor {

        void display() {
            System.out.println("Processor");
        }

    }
}
```

These types of classes are known as nested classes.
