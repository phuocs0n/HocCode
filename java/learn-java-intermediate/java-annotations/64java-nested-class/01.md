## Access inner / nested class

Suppose we have a class CPU with a nested class Processor.

```java
// outer class
class CPU {

    // nested class
    class Processor {

        void display() {
            System.out.println("Processor");
        }

    }
}
```

To access the fields and methods of nested class:

1. We must create an object of outer class

```java
CPU cpu = new CPU();
```

2. Create an object of inner class using the object of the outer class.

```java
CPU.Processor p1 = cpu.new Processor();
```

As the Processor is inside the CPU class the Processor class is referred to as CPU.Processor instead of just Processor.
