## Java Annotations

Java annotation additional information about the program that can be used by Java.

Annotations start with @. Its syntax is:

@AnnotationName

Before we learn about annotations, let's quickly revise Java Inheritance which we learned in the Java OOP Course.

Revise: Java Inheritance

The concept of inheritance is simple, the child class can inherit all the fields and methods of the parent class.

We use extends keyword to inherit from a parent class.

```java
class Animal {
    public void displayInfo() {
        System.out.println("I am an animal.");
    }
}

class Dog extends Animal {

    // override the display() method
    public void displayinfo() {
        System.out.println("I am a dog.");
    }
}
```

Here,

- Dog - child class (subclass)
- Animal - parent class (superclass)

Now, the Dog class can inherit all fields and methods of Animal class. The Dog class can have its own fields and class too.
