# Example: Enum

#### Course: Learn Java Intermediate

## Example: Enum

```java
1// create enum
2enum Size {
3
4    // enum constants
5    SMALL, MEDIUM, LARGE
6}
7
8class Main {
9    public static void main(String[] args) {
10
11        // access enum
12        System.out.println(Size.SMALL);
13        System.out.println(Size.MEDIUM);
14        System.out.println(Size.LARGE);
15    }
16}
```

Output

```text
SMALL
MEDIUM
LARGE
```

Here, we have created an enum of type Size.

We are using the name of enum along with . operator and constant value to access enum constants. That is, Size.SMALL will access the constant SMALL.
