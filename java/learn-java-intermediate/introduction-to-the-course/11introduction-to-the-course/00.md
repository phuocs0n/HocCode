## Introduction

So far, we have completed Java Basics where we covered the fundamental concepts of Java programming.

- Variables and Data Types
- if...else
- Loops
- Methods
- Arrays
- Strings

Then, in Java OOP Course, we covered object-oriented programming with Java where we learned about

- Class and Objects
- Inheritance
- Interfaces
- Polymorphism, Abstraction, and Encapsulation

If these concepts don't ring a bell for you, we suggest you revise the previous courses first.

However, if you are comfortable writing programs involving these topics, it's time to understand Java more deeply. That's what this course is about.

In this course, we will mainly focus on the following things:

- Java Collections: ArrayList, LinkedList, HashMap
- Exception Handling in Java
- Java File Handling

After understanding these concepts, you will gain an advanced understanding of Java and be ready to write more advanced programs in Java.

Let's get started.
