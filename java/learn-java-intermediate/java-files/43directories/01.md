## Create a New Directory

We can create a new directory using the mkdir() method of the File class. For example,

```java
import java.io.File;

class Main {
    public static void main(String[] args) {

        // create object of File
        File file = new File("movies");

        // try to create a new directory
        boolean value = file.mkdir();
        if (value) {
            System.out.println("The new directory is created.");
        } 
        else {
            System.out.println("The directory already exists.");
        }
    }
}
```

In the above program, we have created an object file of the File class.

```java
File file = new File("movies");
```

Here, movies is the name of the directory (folder) we want to create.

Then, we have created the directory using the code:

```java
boolean value = file.mkdir();
```

file.mkdir() creates a new directory named movies in the current directory.

By the way, the mkdir() method returns

- false if the directory is already present
- true if the directory is not present

By the way, mkdir means make directory.
