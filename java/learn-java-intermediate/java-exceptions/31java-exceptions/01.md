## Different Types of Exceptions

Let's see a few different types of exceptions.

ArithmeticException

This exception occurs when we divide a number by zero. For example,

```java
1class Main {
2
3    public static void main(String[] args) {
4        //   Arithmetic Exception
5        int result = 5 / 0;
6        System.out.println(result);
7    }
8}
```

Output

```text
Exception in thread "main" java.lang.ArithmeticException: / by zero
	at Main.main(Main.java:5)
```

When we divide a number by zero, the result is undefined. So, we get an ArithmeticException.

ArrayIndexOutOfBoundsException

This exception occurs when we are trying to access an array element with an index that is not present in the array. For example,

```java
1class Main {
2
3    public static void main(String[] args) {
4
5        int array[] = { 1, 2 };
6        System.out.println(array[2]);
7    }
8}
```

Output

```text
Exception in thread "main" java.lang.ArrayIndexOutOfBoundsException: Index 2 out of bounds for length 2
	at Main.main(Main.java:6)
```

As we are trying to access index 2, which is not present in the array, we get an ArrayIndexOutOfBoundsException.
