## Example II: Exception Handling

We can also print the exception directly, instead of our custom message.

```java
1import java.util.Scanner;
2
3class Main {
4
5    public static void main(String[] args) {
6
7        Scanner input = new Scanner(System.in);
8        try {
9
10            System.out.println("Enter numerator: ");
11            int numerator = input.nextInt();
12            System.out.println("Enter denominator: ");
13            int denominator = input.nextInt();
14
15            int result = numerator / denominator;
16
17            System.out.println(result);
18        }
19
20        catch (Exception e) {
21            System.out.println(e);
22        }
23    }
24}
```

Output

```text
Enter numerator: 
1
Enter denominator: 
0
java.lang.ArithmeticException: / by zero
```

Here, we have printed e instead of a custom message. It simply returns the exception.
