## Example: Exception Handling

```java
1import java.util.Scanner;
2
3class Main {
4
5    public static void main(String[] args) {
6
7        Scanner input = new Scanner(System.in);
8        try {
9
10            System.out.println("Enter numerator: ");
11            int numerator = input.nextInt();
12            System.out.println("Enter denominator: ");
13            int denominator = input.nextInt();
14
15            int result = numerator / denominator;
16
17            System.out.println("Result: " + result);
18        }
19
20        catch (Exception e) {
21            System.out.println("Denominator cannot be 0. Try again.");
22        }
23    }
24}
```

Here, the exception occurs if the denominator is 0. Let's see how this program works for different values of denominator.

Output when denominator is not 0

```text
Enter numerator: 
2
Enter denominator: 
1
Result: 2
```

In this case, exceptions do not occur. Hence, the catch block is skipped.

Output when denominator is 0

```text
Enter numerator: 
4
Enter denominator: 
0
Denominator cannot be 0. Try again.
```

In this case, an exception is raised because of this code int result = numerator / denominator;. When the exception occurs, code after it is ignored, and the catch block is executed.
