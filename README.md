## 📂 Cấu Trúc Kho Lưu Trữ

Dưới đây là sơ đồ tổ chức thư mục của dự án:

| Thư mục | Nội dung / Mục tiêu học tập |
| :--- | :--- |
| `c/` | Các bài tập kỹ thuật lập trình, thuật toán cơ bản bằng ngôn ngữ C. |
| `cpp/` | Lập trình hướng đối tượng (OOP), cấu trúc dữ liệu và giải thuật bằng C++. |
| `java/` | Các khái niệm Java core, OOP, Exception handling, Multi-threading. |
| `python/` | Các script tự động hóa, cấu trúc dữ liệu cơ bản và ứng dụng Python. |
| `sql/` | Các bài tập SQL, câu hỏi phỏng vấn truy vấn database (MySQL, PostgreSQL). |
| `html/` & `css/` | Giao diện web cơ bản, các bài tập layout, flexbox, grid. |
| `javascript/` | Logic xử lý DOM, ES6+, Asynchronous JS (Promise, Async/Await). |
| `react/` | Các component, ứng dụng Single Page App (SPA) thực tế sử dụng React.js. |

## 🚀 Công Cụ Tự Động Hóa

Dự án có đi kèm một script tự động hóa:
- **`push.bat`**: File batch chạy trên Windows giúp tự động thực hiện các bước kiểm tra thay đổi (`git status`), thêm file (`git add`), tạo commit (`git commit`) với thông điệp tùy chọn hoặc tự động tạo theo thời gian thực, và đẩy code lên GitHub (`git push`).

### Cách sử dụng script:
1. Nhấp đúp chuột vào file [push.bat](file:///e:/CODECUAEMT/push.bat) trong thư mục dự án.
2. Nhập nội dung commit (hoặc nhấn **Enter** để tự động tạo thông điệp theo thời gian hiện tại).
3. Đợi script tự động thực hiện tất cả công đoạn đẩy mã nguồn lên GitHub.

## 📖 Hướng Dẫn Chạy Cục Bản

Để clone và chạy thử các bài tập trong máy cá nhân:

```bash
# Clone repository này về máy
git clone https://github.com/phuocs0n/HocCode.git

# Di chuyển vào thư mục dự án
cd HocCode
```

Sau đó, bạn có thể mở thư mục bằng bất kỳ IDE nào (VS Code, CLion, IntelliJ, PyCharm, v.v.) để tiếp tục học tập.
