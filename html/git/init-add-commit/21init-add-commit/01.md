## Initialize Your Repository

Before Git can track anything, you need to initialize a repository. This tells Git to start tracking your project.

Open your terminal, go to your project folder, and run:

```python
$ git init
```

Output

```text
Initialized empty Git repository in /Users/you/myproject/.git/
```

Git creates a hidden i folder inside your project. This is where it stores the history of everything you save.

Note: Run git init once, at the root of your project. Not inside a subfolder.
