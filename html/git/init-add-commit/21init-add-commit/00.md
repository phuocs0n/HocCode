## Install Git

Before you begin, make sure Git is installed on your system. Open your terminal and run:

```python
git --version
```

If Git is installed, you will see a version number. If not, download and install it from the official website:

https://git-scm.com

After installing, run the command again to confirm.

Once this works, you're ready to continue.
