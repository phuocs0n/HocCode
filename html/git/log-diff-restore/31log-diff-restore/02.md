## Comparing Two Saves

To see what changed since your last save, run:

```python
$ git diff
```

Output

```text
diff --git a/index.html b/index.html index 3a4b5c6..7d8e9f0 100644 --- a/index.html +++ b/index.html @@ -12,7 +12,7 @@ -
```

Git shows the difference between your current files and the last commit.

- Lines that start with - are what was there before.
- Lines that start with + are what replaced them.

In this case, a line was accidentally removed. That single change explains why the page broke.

You can find the issue in seconds.
