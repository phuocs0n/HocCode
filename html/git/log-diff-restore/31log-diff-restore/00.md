## Something Just Broke

You made some changes, and now something is broken.

You're not sure which file caused it. You don't know which line is wrong. You don't even remember exactly what you changed.

This happens more often than you expect. This is the exact situation Git was built for.

Your save history is right there. Every version you created is recorded, labeled, and easy to explore.

The answer to "what changed?" is one command away.
