## Starting from Someone Else's Game

To download a full project from GitHub, use:

```python
$ git clone 
https://github.com/someone/project.git
```

Output

```text
Cloning into 'project'... remote: Enumerating objects: 42, done. remote: Total 42 (delta 0), reused 0 (delta 0) Receiving objects: 100% (42/42), 18.3 KiB | 4.57 MiB/s, done.
```

A new folder appears with the full project inside, already connected to the remote. You can start working immediately.

Any public repository on GitHub is one git clone command away. That includes every open source project you have ever used.
