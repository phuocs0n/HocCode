## Absolute Path

An absolute path provides the complete URL to a resource. For example,

```html
https://programiz.pro/learn/master-python
```

It includes

- Protocol (http:// or https://)
- Domain name (programiz.pro)
- Directory path (learn/master-python)

Let's see an example of using absolute path with the <a> tag.

```html
1<a href="https://programiz.pro/learn/master-python" title="Python Course" target="_blank">Python Course</a>
```
