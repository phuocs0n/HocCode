## Relative Path

A relative path specifies the location of a resource relative to the current path. For example,

```html
1<a href="/learn/master-python" target = "_blank">Python Course</a>
```

Here, if the current path is https://programiz.pro (which it is), the link redirects to https://programiz.pro/learn/master-python.

Relative paths can be tricky, that's why let's understand them with the help of examples.
