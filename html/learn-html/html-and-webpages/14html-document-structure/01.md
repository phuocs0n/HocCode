## Introduction

Here's the code from the last lesson:

```html
1<h1>This is a Heading</h1>
2<p>This is a paragraph.</p>
```

If you run this code, you will get the output without an issue.

However, it is not a complete and valid HTML code.

A valid HTML document looks like this:

```html
1<!DOCTYPE html>
2<html>
3
4    <head>
5    </head>
6
7    <body>
8        <p>This is a short paragraph.</p>
9    </body>
10
11</html>
```

Next, you will learn about this structure.
