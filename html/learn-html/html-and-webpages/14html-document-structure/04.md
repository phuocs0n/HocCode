## Example: A valid HTML code

Here's the code we previously wrote:

```html
1<h1>This is a Heading</h1>
2<p>This is a paragraph.</p>
```

Here's how you write the same code in a valid way.

```html
1<!DOCTYPE html>
2
3<html>
4    <head>
5    </head>
6
7    <body>
8        <h1>This is a Heading</h1>
9        <p>This is a paragraph.</p>
10    </body>
11</html>
```

#### Takeaway:

A valid HTML document includes

1. <!DOCTYPE html> declaration.
2. <html> section.
3. <head> and <body> sections inside the <html> section.

You write your code inside either the <head> section or the <body> section.
