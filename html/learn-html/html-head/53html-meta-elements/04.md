## Enhance Social Media Share Link

We can also use the <meta> tag to control how content appears when we share the webpage on social media platforms (Facebook, Twitter, LinkedIn, and others.

For example,

```html
<meta property="og:title" content="Learn HTML">
<meta property="og:description" content="A comprehensive guide to HTML for web development.">
<meta property="og:image" content="https://example.com/image.jpg">
```

This controls the title, image, and description that are shown when a URL is shared on social media.
