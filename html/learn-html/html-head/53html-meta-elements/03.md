## Viewport Meta Tag

The viewport meta tag is essential for responsive design (designing the website to adapt based on the user's device size).

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```

Here,

- content="width=device-width" sets the width of the viewport to be the same as the width of the device.
- initial-scale=1.0 sets the initial zoom.

This metadata makes the webpage fit the user's screen.

The viewport meta is more useful when working with CSS. We will return to it in the CSS course.
