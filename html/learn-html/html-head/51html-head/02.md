## HTML Head

The <head> section contains important metadata about the webpage. This metadata helps browsers and search engines to properly interpret and display the page.

The information within <head> is not directly visible to users; however, it plays an important role in how the page is displayed.

In this chapter, we will learn about the four important tags found inside <head>.

- <title>
- <meta>
- <link>
- <script>
