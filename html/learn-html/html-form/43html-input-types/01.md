## Commonly Used Input Types

The commonly used types are as follows:

| Input Type | Used for |
| --- | --- |
| <input type="text"> | A single-line text input. |
| <input type="password"> | A password field. |
| <input type="submit"> | A button for submitting a form. |
| <input type="radio"> | A radio button. |
| <input type="checkbox"> | A checkbox. |
| <input type="file"> | To upload files. |
| <input type="email"> | A text-like field for emails. |
| <input type="date"> | A field to enter a date. |
