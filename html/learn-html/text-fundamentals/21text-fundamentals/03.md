## Self-Closing Tags

HTML self-closing tags do not require an end tag. For example, the <br> tag we just used.

There are two ways to write self-closing tags.

We can either use <br> or <br /> to create a line break.

```html
1<p>Address</p>
2<br />
3<p>Contact us at:<br />
4123 Main Street<br />
5Cityville, State 12345<br />
6Phone: (123) 456-7890</p>
```

It's a matter of preference which one you choose to use.

However, don't use self-closing tags like this: <br></br>, as it's not correct.

Rewrite the above code on the html editor to your right replacing <br /> with <br> and see the output.
