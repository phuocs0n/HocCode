## Table: <table> Tag

We use the <table> tag to create an HTML table.

```html
1<table>
2</table>
```

This code creates a table; however, if you run the code, you will not see any output.

It is because we have not defined how many rows and columns it will have. Additionally, we haven't specified what data each row and column will contain.
