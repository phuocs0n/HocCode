# Unordered List vs. Ordered List

#### Course: Learn HTML

## Unordered List vs. Ordered List

As the name suggests, use an unordered list when the order of items doesn't matter.

For instance, unordered lists are good for listing grocery items, packing for a trip, or hobbies and interests.

Use an ordered list when the sequence of items is important, such as steps to cook a meal or organize a meeting.

Remember, you can use CSS to change the appearance of unordered lists to look like ordered lists and vice versa.

Therefore, choose the type of list based on the content, not for design purposes.
