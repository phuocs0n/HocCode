# Quick Plan of Action

#### Course: HTML Fundamentals for Your First Webpage

## Quick Plan of Action

We'll build the page in this order:

1. Set up the HTML document structure
2. Add the main layout of the page
3. Decide and list the major blog sections
4. Start with real headings and real paragraphs

Each step is important and cannot be skipped. Proper planning in the initial stages saves you a lot of headaches in the future.
