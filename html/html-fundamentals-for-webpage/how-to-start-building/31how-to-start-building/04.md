## Step 1: Setting Up the HTML Content Structure

Once you have basic html structure setup, most webpage content starts with the following skeleton:

```html
1<!DOCTYPE html>
2<html lang="en">
3  <head>
4    <meta charset="UTF-8">
5    <title>Learning HTML Blog</title>
6  </head>
7  <body>
8  </body>
9</html>
```

Why this matters

- <html> wraps the entire document
- <head> stores information about the page, including its title
- <body> is where all visible content lives

This is the base we'll build on — nothing more, nothing less.
