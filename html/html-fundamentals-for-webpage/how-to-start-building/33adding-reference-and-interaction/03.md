## But Why Use Tables?

"Why not just use lists to display the tag references?", you might ask.

After all, a list can also do the job:

```html
1<section>
2  <h2>Common HTML Tags</h2>
3  <ul>
4    <li>h1 — Main page heading</li>
5    <li>p — Paragraph of text</li>
6    <li>section — Groups related content</li>
7    <tr>
8  </ul>
9</section>
```

The HTML code for the list is much neater and less complicated than the one for the table.

But look at the actual output and ask yourself these questions:

Question 1: Does the list properly convey the information you're trying to convey?

Answer: Not really, because the way it's written feels a bit unclear.

Question 2: Does each bullet point in the list hold a single concept?

Answer: No! If you think about it, h1 as a tag is a separate item from its description (Main page heading). These are related concepts, but they're still separate.

Thus, we can conclude that a list is not suitable for displaying our HTML tag reference section. And the simplest yet most appropriate method is to use a table.
