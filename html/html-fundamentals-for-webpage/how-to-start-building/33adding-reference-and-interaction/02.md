## Section 1: Adding a Tag Reference Table

Developers use tables when information has:

- Categories
- Labels
- Repeating rows

#### Example

```html
1<section>
2  <h2>Common HTML Tags</h2>
3  <table>
4    <tr>
5      <th>Tag</th>
6      <th>Purpose</th>
7    </tr>
8    <tr>
9      <td>h1</td>
10      <td>Main page heading</td>
11    </tr>
12    <tr>
13      <td>p</td>
14      <td>Paragraph of text</td>
15    </tr>
16    <tr>
17      <td>section</td>
18      <td>Groups related content</td>
19    </tr>
20  </table>
21</section>
```

Developer thinking:

1. <th> defines meaning
2. <td> holds data
3. Tables are not for layout, only data
