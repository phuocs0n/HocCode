## How Developers Review a Finished HTML Page

Before touching CSS or JavaScript, developers review HTML with three lenses:

- Structural
- Semantic
- Readability

In case you've forgotten, CSS adds styling such as colors, font styles, decorations, etc. to your webpage.

On the other hand, JavaScript makes your webpage interactive by adding things such as click functions, popup messages, and more.

With that out of the way, let's start with a structural review.
