## Structural Review

Developers scan the page from top to bottom and ask:

- Is everything inside <header>, <main>, or <footer>?
- Does each <section> cover only one idea?
- Are headings used consistently?

If the structure is weak, styling the page will end up becoming very painful.

Connecting to this strongly is semantic review. Let's take a look at that before we look into some code.
