## Semantic Review

When developers look at code they should be able to visualize the UI. Semantic HTML makes it easier to visualize the UI. Writing tags that represent the meaning of the content is writing Semantic HTML.

They look for:

- <section> instead of random <div> blocks
- <strong> and <em> instead of just text.
- Tables used only for data, not layout

Semantic HTML is invisible — but it's what makes pages accessible and maintainable.
