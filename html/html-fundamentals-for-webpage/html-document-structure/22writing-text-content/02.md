## Headings and Paragraphs

#### Headings

HTML heading tags range from <h1> to <h6>. These headings define importance, not size.

1. <h1> - main title of the page
2. <h2> - major sections
3. <h3> - sub-sections

Developers use headings to create content hierarchy.

#### Paragraphs

The <p> tag is used to create paragraphs in HTML. Paragraphs are used for:

1. Explanations
2. Descriptions
3. Regular text content

They represent complete thoughts.
