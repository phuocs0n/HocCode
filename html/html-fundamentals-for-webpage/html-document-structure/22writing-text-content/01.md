## Every Webpage Starts with Text

Before images, layouts, or interactions, webpages start with text.

As a developer, I ask these simple questions first:

- What is the page about?
- What should the reader read first?
- What ideas matter most?

HTML gives us a small set of tags to answer these questions clearly.
