## Emphasizing Important Ideas

Sometimes, parts of a sentence matter more. HTML provides meaning-based tags for this:

- <strong> - important information
- <em> - emphasized ideas

Example

```html
1<p>
2  HTML is the main <strong>foundation</strong> of the web and
3  <em>every frontend developer</em> should understand it.
4</p>
```

These tags don't exist for styling; they exist to communicate importance and emphasis.
