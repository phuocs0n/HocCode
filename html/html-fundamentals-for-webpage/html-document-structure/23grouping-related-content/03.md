# The section Tag: A Meaningful Group

#### Course: HTML Fundamentals for Your First Webpage

## The section Tag: A Meaningful Group

When grouped content represents one clear idea or topic, developers use <section>.

Key Rule

A <section> usually has a heading.

Example

```html
1<section>
2  <h2>What You Will Learn</h2>
3  <p>
4    This blog teaches HTML fundamentals through simple, practical examples.
5  </p>
6</section>
```

Compared to <div>, <section> adds meaning to the group.

Developer's Note:

Personally, I didn't know <section> added meaning while <div> didn't when I started out as a junior developer (I thought they were interchangeable).

They didn't teach such stuff in my class 😔

It was only when my supervisor pointed out the difference that things finally clicked!
