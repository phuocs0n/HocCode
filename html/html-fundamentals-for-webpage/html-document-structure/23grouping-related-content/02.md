## The div Tag: A Simple Container

The <div> tag is a generic container.

It does not add meaning by itself; it simply groups content together.

Developers use <div> when:

- They want to group content
- The group doesn't yet have a clear purpose or meaning

Example

```html
1<div>
2  <h2>Why Learn HTML?</h2>
3  <p>
4    HTML helps you structure content clearly and understand how webpages are built.
5  </p>
6</div>
```

Here, <div> groups related content (the header and the paragraph) into one block.
