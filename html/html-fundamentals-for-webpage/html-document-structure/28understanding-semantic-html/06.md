## Semantic vs Non-Semantic: A Simple Comparison

Let's proceed by comparing semantic and non-semantic HTML.

Both of the codes below render content, but only one explains it.

Example: Non-Semantic HTML

```html
1<div>
2  <h2>Why Learn HTML?</h2>
3  <p>HTML is the foundation of the web.</p>
4</div>
```

Example: Semantic HTML

```html
1<section>
2  <h2>Why Learn HTML?</h2>
3  <p>HTML is the foundation of the web.</p>
4</section>
```

Run both codes and compare them. They're visually similar, but different when it comes to the meanings they convey.

Developers choose the second code when the content represents a real section of the page. So, ask yourself this question when writing HTML:

"If another developer opened this file, would they understand the structure and meaning without reading every line?"

If the answer is yes, you're using Semantic HTML well.
