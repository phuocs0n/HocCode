## Looking Back at What You've Already Used

Let's revisit tags you already know:

| Tag | What It Does |
| --- | --- |
| <h1> – <h3> | Define headers/titles in decreasing order of importance |
| <section> | Group related ideas |
| <article> | Standalone content |
| <strong> | Important information |
| <em> | Emphasize ideas |
| <form> | Take user input |
| <table> | Structured data for comparison |

None of these exist for styling; they exist to describe intent.

That's Semantic HTML.
