#### Course: HTML Fundamentals for Your First Webpage

## Adding Images with the img Tag

Images are added using the <img> tag (called the image tag).

Key things to know:

1. <img> does not have a closing tag
2. It displays an image file on the page

Example

```html
1<img src="https://programiz-pro-spaces.sfo3.digitaloceanspaces.com/course-images/html-fundamentals/html-structure.png" />
```

This works, but it's incomplete.

Developers always include these attributes inside the <img> tag:

1. src - the address of the image
2. alt - text that describes what the image represents

Example

```html
1<img src="https://programiz-pro-spaces.sfo3.digitaloceanspaces.com/course-images/html-fundamentals/html-structure.png"
2          alt="Diagram showing how HTML elements form a webpage structure"
3        />
```
