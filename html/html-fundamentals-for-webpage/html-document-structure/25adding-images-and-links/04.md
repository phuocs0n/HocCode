## Adding Links with the Anchor Tag

Links connect pages and resources, and we use the <a> tag to create links.

As discussed before, the a stands for "anchor" since other pages and resources get "anchored" to your webpage.

Thus, this tag is called the anchor tag.

Links are often used to:

- Reference documentation
- Navigate to related content
- Guide readers to next steps

Example

```html
1<a href="https://developer.mozilla.org">Learn more about HTML</a>
```

Notice the href attribute: it holds the address where the link points to.
