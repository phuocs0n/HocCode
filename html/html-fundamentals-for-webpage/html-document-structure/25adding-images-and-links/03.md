## Why alt Matters

Here's how we previously added an image:

```html
1<img src="https://programiz-pro-spaces.sfo3.digitaloceanspaces.com/course-images/html-fundamentals/html-structure.png"
2          alt="Diagram showing how HTML elements form a webpage structure"
3        />
```

You might be wondering why alt is required at all. Here's why you need it:

1. Screen readers rely on it
2. Images may fail to load, so some text needs to be displayed instead
3. It explains the image's purpose
