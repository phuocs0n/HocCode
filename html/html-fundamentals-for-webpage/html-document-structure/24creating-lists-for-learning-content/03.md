## Ordered Lists

We use the <ol> tag to create unordered lists. Use an ordered list when the sequence matters.

For example, here's a list of sequential steps needed to master the fundamentals of HTML:

```html
1<ol>
2  <li>Understand basic HTML tags</li>
3  <li>Practice writing content</li>
4  <li>Group related information</li>
5  <li>Build a complete page</li>
6</ol>
```

As you can see, the order communicates meaning: you must proceed sequentially from step 1 to step 4.
