## When Content Is Naturally a List

When content doesn't naturally feel like a paragraph, ask yourself following questions:

1. Is this a set of steps?
2. Is this a group of related items?
3. Does order matter?

If the answer to any one of these questions is yes, a list is usually the right choice.

HTML provides two types of lists:

- Unordered Lists: Used when the order of the items doesn't matter
- Ordered Lists: Used when the item order matters

Let's start with unordered lists.
