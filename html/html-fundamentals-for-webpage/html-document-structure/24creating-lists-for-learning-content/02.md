## Unordered Lists

We use the <ul> tag to create unordered lists. Use an unordered list when order doesn't matter.

For example, here's a list of topics covered on our blog:

```html
1<ul>
2  <li>HTML Basics</li>
3  <li>Text and Headings</li>
4  <li>Lists and Tables</li>
5  <li>Forms and User Input</li>
6</ul>
```

Here,

- <ul> - Creates an unordered list
- <li> - Stands for list item and specifies a single item in the list

In an unordered list, each item is equal in importance, i.e., the sequence of the items isn't important.
