## When Do Developers Reach for a Table?

Developers don't use tables often — but when they do, it's intentional.

A table makes sense when:

1. Data has rows and columns
2. Each item relates to the same kind of information
3. Readers want to compare or scan

For our blog, this fits perfectly for displaying a small HTML tag reference section.
