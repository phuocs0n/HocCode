## The Core Table Structure

Every table follows the same pattern:

- <table> - the container incorporating all table elements
- <tr> - specifies a row in the table
- <th> - header cell used for writing the header/title of a column in the table
- <td> - data cell that contains an individual piece of data

That's all you need to start.
