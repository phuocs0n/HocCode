## Introduction

Before writing any content for our blog, we need to understand how an HTML document is structured.

A valid HTML document looks like this:

```html
1<!DOCTYPE html>
2<html>
3
4    <head>
5    </head>
6
7    <body>
8        <p>This is a short paragraph.</p>
9    </body>
10
11</html>
```

Next, you'll learn about this structure.
