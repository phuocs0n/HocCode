## Scenario

Imagine you work as a data analyst for an e-commerce company. One day, your manager asks:

"We need a quick report on customer demographics—just their age and country. Can you extract that from our database?"

You check the Customers table, which contains many columns, including customer_id, name, email, phone_number, age, and country.

Since you only need age and country, you could write a query to select those columns every time.

But instead of repeating this query, you can create a view that stores just the required columns!
