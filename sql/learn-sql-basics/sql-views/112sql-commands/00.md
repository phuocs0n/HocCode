## SQL Commands

So, you have used SQL to perform many tasks, such as:

- Retrieving data
- Creating tables
- Inserting, updating, and deleting records
- Managing database permissions

Since SQL can handle many tasks, remembering all the commands might feel overwhelming.

SQL commands are categorized into different sub-languages to make learning easier, each serving a specific purpose.

In this lesson, you'll learn about these categories and explore a few SQL commands that haven't been covered yet.
