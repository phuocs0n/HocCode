## Data Manipulation Language (DML)

The Data Manipulation Language(DML) adds, updates, and deletes data from a table.

Commonly used DML commands include:

- INSERT -  rows into a database table
- UPDATE - edits data from a table
- DELETE - deletes rows from a table

You are already familiar with these from earlier chapters.
