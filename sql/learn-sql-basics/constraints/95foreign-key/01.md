## FOREIGN KEY

A foreign key is a column or set of columns in one table referencing the primary key in another table.

The FOREIGN KEY constraint establishes a relationship between the two tables, ensuring that data in one table (e.g., Books) is consistent with the data in another table (e.g., Authors).

Here's how you can implement the constraint:

```sql
1CREATE TABLE Authors (
2    id INTEGER PRIMARY KEY,
3    author_name VARCHAR(100) NOT NULL
4);
5
6CREATE TABLE Books (
7    id INTEGER PRIMARY KEY,
8    title VARCHAR(100) NOT NULL,
9    book_code VARCHAR(20) UNIQUE,
10    publisher VARCHAR(100),
11    author_id INT,
12    FOREIGN KEY (author_id) REFERENCES Authors(id)
13);
```

Notice the following statement in the code above:

```sql
FOREIGN KEY (author_id) REFERENCES Authors(id)
```

This statement:

- Makes author_id in the Books table a FOREIGN KEY
- References the id column of the Authors table
