## Manager's Requirement

The manager outlines the following requirements:

- Every concert must have a performer name; events without a listed performer cannot be scheduled.
- No two concerts can occur simultaneously to avoid conflict-free event planning.
- Each concert must have unique identifiers, such as IDs, to manage tickets and scheduling.
- Each concert should be linked to a specific genre, ensuring that promotional materials target the right audience.

Let's start with the first requirement.
