## The Final Outcome

Now that you've fulfilled all four of the manager's requirements let's take a look at how the database is structured:

```sql
1CREATE TABLE Concerts (
2    performer_name VARCHAR(255) NOT NULL,
3    concert_datetime DATETIME UNIQUE,
4    concert_id INTEGER PRIMARY KEY AUTOINCREMENT,
5    genre_id INTEGER,
6    FOREIGN KEY (genre_id) REFERENCES Genres(id)
7);
8
9CREATE TABLE Genres (
10    id INTEGER PRIMARY KEY AUTOINCREMENT,
11    genre_name VARCHAR(255) NOT NULL
12);
```

The Concerts table includes:

- A non-nullable performer_name,
- A unique concert_datetime,
- A unique identifier (concert_id), and
- A foreign key (genre_id) that links each concert to its corresponding genre in the Genres table.
