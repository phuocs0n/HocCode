## Concert must have performer's name: NOT NULL Constraint

To meet the requirement that the concert must have the performer's name, you can use the NOT NULL constraint in the performer_name column.

```sql
1CREATE TABLE Concerts (
2    performer_name VARCHAR(255) NOT NULL
3);
```

Applying the NOT NULL constraint to the performer_name column prevents the scheduling of concerts without a specified performer, thus ensuring all events are clearly defined.
