## Link each concert to specific genre: FOREIGN KEY

Suppose the Genres table is created, where id is the primary key.

```sql
1CREATE TABLE Genres (
2    id INTEGER PRIMARY KEY AUTOINCREMENT, 
3    genre_name VARCHAR(255) NOT NULL 
4);
```

To meet the last requirement, use the FOREIGN KEY constraint to link genre_id in the Concerts table to id in the Genres table.

```sql
1CREATE TABLE Concerts (
2    id INTEGER PRIMARY KEY AUTOINCREMENT,
3    genre_id INT,
4    FOREIGN KEY (genre_id) REFERENCES Genres(id) 
5);
```

The FOREIGN KEY constraint ensures that the genre_id in the Concerts table matches an existing id in the Genres table, linking each concert to a specific genre.
