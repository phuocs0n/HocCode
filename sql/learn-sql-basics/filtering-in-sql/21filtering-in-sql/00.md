## Introduction to Filtering in SQL

In the previous chapter, you learned how to use the SQL SELECT statement to retrieve data from a table.

As an analyst, you often don't need all the data in a table; you need to filter it to answer specific questions, such as:

- Which customers are from the USA?
- Who are the customers aged between 20 and 30?
- Which customers have names starting with 'J'?

Filtering in SQL allows you to focus on the data relevant to your queries, displaying only the rows that meet your criteria.
