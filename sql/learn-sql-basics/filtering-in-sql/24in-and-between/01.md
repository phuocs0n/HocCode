## IN Operator

The IN operator is used with the WHERE clause to match values within a list.

For example, if you want to find customers who live in either the USA or UK, you can use the IN operator:

```sql
1-- Select Customers from USA or UK
2
3SELECT first_name, country
4FROM Customers
5WHERE country IN ('USA', 'UK');
```

The above query is equivalent to:

```sql
1SELECT first_name, country
2FROM Customers
3WHERE country = 'USA' OR country = 'UK';
```

Here, the SQL query selects rows if the country is USA or UK.

By using IN, you can simplify queries requiring multiple OR conditions. This makes the query more concise and easier to read.

You can combine IN with NOT to get the NOT IN operator. Let's see that on the next page.
