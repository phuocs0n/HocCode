## Introduction to IN and BETWEEN

In the previous lesson, you learned how to filter data using logical operators like AND, OR, and NOT to refine your queries.

Building on that, what if you need to filter data based on multiple specific values or within a range? For example:

- Finding customers from the USA, Canada, or UK.
- Identifying customers aged between 20 and 30.

To handle such cases, SQL provides two powerful operators:

- IN and
- BETWEEN

Let's begin with the IN operator.
