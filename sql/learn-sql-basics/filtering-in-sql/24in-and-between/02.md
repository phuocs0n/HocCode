## NOT IN Operator

The NOT IN operator is similar to IN, but instead of selecting rows that match the list, it excludes rows that match any value.

For example, you want to exclude customers from the UK and UAE. You can write:

```sql
1-- Select a row if country is not in the ('UK', 'UAE')
2
3SELECT first_name, country
4FROM Customers
5WHERE country NOT IN ('UK', 'UAE');
```

The above query is equivalent to:

```sql
1-- Select a row if country is not UK
2-- and country is not UAE
3
4SELECT first_name, country
5FROM Customers
6WHERE country <> 'UK' AND country <> 'UAE';
```

You can use IN and NOT IN to select or exclude specific values from your result.

If you're working with ranges of continuous values (e.g., age, date, etc.), the BETWEEN operator is more appropriate, which we'll cover in the next lesson.
