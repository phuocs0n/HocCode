## _ Wildcard in SQL

The _ wildcard in SQL is used to represent a single character. For example,

| Expression | String | Matched? |
| --- | --- | --- |
| 'R_' | 'R' | no match |
| 'R_' | 'Ra' | match |
| 'R_' | 'Ran' | no match |
| 'R_' | 'Or' | no match |
| '_R' | 'Or' | match |
| '_R' | 'Number' | no match |
| '_R_' | 'Ran' | no match |
| '_R_' | 'Ara' | match |
| '__R_' | 'Dara' | match |
| '__R_' | 'Ara' | no match |

Example

```sql
1-- Select customers whose country contains -- only three letters
2
3SELECT *
4FROM Customers
5WHERE country LIKE '___';
```
