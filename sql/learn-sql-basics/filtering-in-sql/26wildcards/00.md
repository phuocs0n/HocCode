## Introducion to Wildcard Characters

In the previous lesson, we used % to match patterns in text using the LIKE operator. This character is also known as a wildcard.

A wildcard is a special character used with the LIKE operator to match patterns in text data.

In this lesson, you'll learn about the two common wildcards in SQL:

- %
- _

Let's start with % wildcard.
