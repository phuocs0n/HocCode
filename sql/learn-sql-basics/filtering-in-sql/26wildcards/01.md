## % Wildcard in SQL

The % wildcard in SQL is used to represent zero or more characters. For example,

| Expression | String | Matched? |
| --- | --- | --- |
| 'R%' | 'R' | match |
| 'R%' | 'Run' | match |
| 'R%' | 'Summer' | no match |
| '%R' | 'Aron' | no match |
| '%R' | 'Summer' | match |
| '%R%' | 'Aron' | match |
| '%R%' | 'Summer' | match |
| '%R%' | 'Alu' | no match |

Example

```sql
1-- Select customers whose country contains 's'
2-- '%s%' - zero or more characters before or after 's'
3
4SELECT *
5FROM Customers
6WHERE country LIKE '%s%';
```
