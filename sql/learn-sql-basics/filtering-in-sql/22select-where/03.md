## Examples: SQL SELECT WHERE

Example 3: Retrieve the age and country of customers whose age is Equal to 22.

```sql
1-- Select the age and country of customers
2-- Whose age is equal to 22
3
4SELECT age, country
5FROM Customers
6WHERE age = 22;
```

Example 4: Retrieve the age and country of customers whose age is not Equal to 22.

```sql
1-- Select the age and country of customers
2-- Whose age is not equal to 22
3
4SELECT age, country
5FROM Customers
6WHERE age <> 22;
```
