## SQL Comparison Operator

In SQL, you can use the following comparison operators in the WHERE clause to filter rows based on specific conditions:

| Operator | Description |
| --- | --- |
| < | Less than |
| <= | Less than or equal to |
| > | Greater than |
| >= | Greater than or equal to |
| = | Equal to |
| <> or != | Not equal to |
