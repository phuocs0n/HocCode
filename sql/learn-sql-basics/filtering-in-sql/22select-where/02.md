## Examples: SQL SELECT WHERE

Run each query and observe the results.

Example 1: Retrieve the age and country of customers aged 27 or younger.

```sql
1-- Select the age and country of customers
2-- Aged less than or equal to 27
3
4SELECT age, country
5FROM Customers
6WHERE age <= 27;
```

Example 2: Retrieve the age and country of customers older than 27.

```sql
1-- Select the age and country of customers
2-- Older than 27
3
4SELECT age, country
5FROM Customers
6WHERE age > 27;
```
