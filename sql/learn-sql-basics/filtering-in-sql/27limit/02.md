## More on LIMIT

While LIMIT is widely supported, some databases use alternative syntax.

For example,

SQL Server: Uses the TOP keyword.

```sql
SELECT TOP 3 *
FROM Products;
```

Oracle: Uses FETCH FIRST or ROWNUM to achieve the same result.

If you encounter an error while using LIMIT, we recommend reading the documentation of the database system you are using.
