## Introduction to Subqueries

On combining the two steps from the previous page into one efficient query, we get:

```sql
1SELECT id, name, GPA
2FROM Students
3WHERE GPA > (SELECT AVG(GPA) FROM Students);
```

This query uses a subquery – a query nested inside another query – to calculate the average score directly within the WHERE clause of the main query.

Do not worry if the main query and subquery are unclear—we'll explore that on the next page.
