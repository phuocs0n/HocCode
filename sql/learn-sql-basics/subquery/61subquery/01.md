## Identifying Students Above Average

To answer the question "How can you identify the students whose GPA are above average?" using your existing SQL skills, you can break it down into two queries.

First step: Find the average GPA:

```sql
1SELECT AVG(GPA) AS average_gpa
2FROM Students;
```

This gives you an average of 3.7.

Second Step: Filter the student list:

```sql
1SELECT id, name, GPA
2FROM Students 
3WHERE GPA > 3.7;
```

Notice that you have to manually insert the average GPA (3.7) into the second query. This isn't efficient if the data changes and the average needs recalculating.
