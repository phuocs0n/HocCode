## Your Existing SQL Skills

So far, you've learned the basics of SQL, including retrieving or sorting data.

But sometimes, your tasks can get more complex, where one query depends on the results of another.

For example, imagine you're a data analyst working with the Students table:

```sql
1SELECT * 
2FROM Students
```

You are asked, "How can you identify the students whose GPA are above average?"

Let's see how you can answer this using your existing SQL skills.
