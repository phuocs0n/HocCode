## Tracking Enrollments in Elective Courses

Now, let's answer the question posed by your team. Your goal is to identify the elective courses with at least one student enrolled using the Courses and Enrollments tables.

To achieve this, you can:

- Use a subquery to identify course IDs from the Enrollments table where students are actively enrolled.
- Utilize this information in the main query to filter and list elective courses from the Courses table with enrollments.

Let's execute with the following query:

```sql
1SELECT course_id, course_name
2FROM Courses
3WHERE course_type = 'Elective'
4AND course_id IN (
5    SELECT course_id
6    FROM Enrollments
7    WHERE student_id IS NOT NULL
8);
```
