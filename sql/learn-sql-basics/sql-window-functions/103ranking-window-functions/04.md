## RANK()

Your company runs a streaming platform, and your manager wants insights into user preferences. He comes to you and asks:

"Can you rank movies based on their IMDb ratings? If multiple movies have the same rating, they should share the same rank."

To achieve this, you can use the RANK() function, which assigns the same rank to tied values but skips the next rank in sequence.
