## Example: Ranking Products by Sales Using ROW_NUMBER()

Consider a table Product_sales that stores the products and their sales amounts:

```sql
1SELECT * 
2FROM Product_sales
```

To rank products by sales amount, we use the ROW_NUMBER() function.

For example,

```sql
1SELECT *, 
2ROW_NUMBER() OVER (ORDER BY sales_amount DESC) AS rank_by_sales 
3
4FROM Product_sales;
```

The above code displays the rank of the products on the basis of sales amount. Now, you can easily identify the top selling products.
