## DENSE_RANK()

Your streaming platform is analyzing movie rankings, and your manager notices something unusual:

"I see that movies with the same rating share a rank, but the next rank is skipped. Can we assign ranks without gaps?"

To fix this, you can use DENSE_RANK(), which works like RANK() but ensures that ranks increase sequentially, even for ties.
