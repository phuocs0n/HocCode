## Example: Ranking Movies by IMDb Rating

Suppose we have a Movies table that contains movies and their IMDb rating.

```sql
1SELECT * 
2FROM Movies
```

To rank movies based on IMDb ratings:

```sql
1SELECT *, 
2RANK() OVER (ORDER BY IMDb_rating DESC) AS rank 
3
4FROM Movies;
```

Here, you have ranked the movies based on IMDb rating.

RANK() returns the same rank for the entries with the same values and skips the next rank after the ties.

Notice that the ranking for Dune: Part Two and Oppenheimer is 2. Also, the ranking of Inside Out 2 is 4 because RANK() skips the next rank after ties.
