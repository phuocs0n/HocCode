## ROW_NUMBER()

Your manager wants to analyze product sales and asks:

"Can you show me a ranked list of our best-selling products? I need to see which products are performing well."

To generate this ranking, you can use the ROW_NUMBER() function. This function assigns a unique number to each row based on sales performance, ensuring each product is ranked individually.
