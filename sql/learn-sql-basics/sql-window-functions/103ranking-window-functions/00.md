## Ranking Window Functions

Previously, you used aggregate window functions to calculate averages and totals. Now, your manager has a new request:

"Can you show how employee salaries compare? I want to see who earns the most and their ranking within the company."

Sorting alone won't be enough—you need to assign a rank to each employee while keeping all data intact.

This is where ranking window functions come in.
