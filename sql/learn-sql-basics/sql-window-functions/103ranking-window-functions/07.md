## Example: DENSE_RANK() for Movie Rankings

Let's add DENSE_RANK() to rank the movies without skipping the rank.

```sql
1SELECT *, 
2RANK() OVER (ORDER BY IMDb_rating DESC) AS rank, 
3DENSE_RANK() OVER (ORDER BY IMDb_rating DESC) AS dense_rank 
4
5FROM Movies;
```

In the column dense_rank, you have displayed the rank of movies without skipping the rank after ties. For instance, the movies are ranked as 1, 2, 2, 3, 3, and 4. This is how DENSE_RANK() works.
