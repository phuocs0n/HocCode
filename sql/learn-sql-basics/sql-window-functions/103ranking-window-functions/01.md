## Chapter Overview

In this section, you'll learn how to assign a ranking to each row based on specific criteria using SQL window functions. These functions allow comparisons without modifying the original data structure.

We will cover three key ranking functions:

- ROW_NUMBER(): Assigns a unique number to each row, even if values are the same.
- RANK(): Assigns the same rank to tied values but skips numbers.
- DENSE_RANK(): Similar to RANK(), but without gaps in rankings.
