## LAG()

Suppose, your manager is reviewing daily sales and asks:

"Can we see how each day's sales compare to the previous day? I want to track increases and decreases over time."

To analyze this, we use LAG() , which retrieves the previous row's value in a dataset, allowing for direct comparisons.
