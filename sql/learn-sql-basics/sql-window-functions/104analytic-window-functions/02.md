## Analytic Window Functions

Your manager is reviewing sales data and asks:

"Can we see how each product's sales compare to the previous month? I want to identify trends and spot any sudden increases or drops."

Looking at total sales alone won't provide the full picture—you need a way to compare each month's sales with past and future months without modifying the dataset.

This is where analytic window functions come in. They help track trends by referencing other rows while preserving the original structure.
