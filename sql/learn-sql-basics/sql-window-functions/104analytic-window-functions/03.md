## Example: Analytic Window Functions

To spot trends and compare data over time, you need a way to reference previous or future values within a dataset. Analytic window functions make this possible without altering the original structure.

SQL provides two key functions for this:

- LAG(): Retrieves the previous row's value for comparisons.
- LEAD(): Retrieves the next row's value for forecasting.
