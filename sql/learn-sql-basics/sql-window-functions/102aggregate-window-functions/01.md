## MIN() and MAX()

Consider a table Employees with following data:

```sql
1SELECT * 
2FROM Employees
```

Now, let's calculate the minimum and maximum salary of each department. You can use the MAX() and MIN() window functions to do this.

```sql
1SELECT *,
2MIN(salary) OVER (PARTITION BY department) AS min_salary,
3MAX(salary) OVER (PARTITION BY department) AS max_salary
4FROM Employees;
```

With this query, you get the minimum and maximum salaries for each department, alongside the salary of each individual employee.
