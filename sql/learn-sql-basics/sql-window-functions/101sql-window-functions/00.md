## Introduction

In the previous chapter, you learned about aggregate functions like AVG(). For example, to calculate the average salary of all employees, you would use:

```sql
1SELECT AVG(salary) FROM Employees;
```

While this summarizes data, it has a limitation: it reduces results to a single row, losing individual details.

But what if you need to compare each employee's salary to their department's average? This is where SQL window functions come in. They allow you to calculate each row without collapsing the data, keeping everything intact.

In this chapter, you'll learn how SQL window functions let you perform complex calculations while preserving the original data.
