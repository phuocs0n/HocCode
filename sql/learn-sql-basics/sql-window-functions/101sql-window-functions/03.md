## Using the AVG() Aggregation Function

Let's start by trying to achieve the task using the AVG() aggregation function.

```sql
1-- Select all entries and get the average salary
2
3SELECT *, AVG(salary) AS average_salary
4FROM Employees;
```

This query calculates the average salary of all employees in the table. However, since aggregate functions return a single value, only the first row will be displayed with the average salary.

But the task requires comparing each employee's salary with the company's average salary.

This is where window functions come in. Unlike aggregate functions that summarize data into one row, window functions allow you to perform calculations for each row without collapsing the data.
