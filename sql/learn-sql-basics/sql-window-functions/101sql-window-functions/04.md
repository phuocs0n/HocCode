## Using a Window Function

When you use AVG(salary) , the result returns only a single value, collapsing all employee data into one row.

However, your goal is to compare each employee's salary while keeping all employees visible in the table.

Your manager reviews the report and says:

"This only gives me one number. I want to see every employee's salary along with the company average so I can compare them easily."

To achieve this, you can use a window function. Window functions allow you to calculate the average salary for each row without collapsing the data into a single result.
