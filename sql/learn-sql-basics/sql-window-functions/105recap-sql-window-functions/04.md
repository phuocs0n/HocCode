## First and Last Sales ( FIRST_VALUE and LAST_VALUE)

To retrieve the first and last sales amounts for each employee, you can use the FIRST_VALUE() and LAST_VALUE() functions to retrieve the first and last sale for each sales representative, ordered by transaction date.

```sql
1SELECT 
2    sales_rep_id, 
3    sales_rep_name, 
4    sales_amount, 
5    FIRST_VALUE(sales_amount) OVER (PARTITION BY sales_rep_id ORDER BY transaction_date) AS first_sale,
6    LAST_VALUE(sales_amount) OVER (PARTITION BY sales_rep_id ORDER BY transaction_date ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING) AS last_sale
7FROM Sales;
```

This query shows the first and last sales amount for each representative, giving insights into their performance over time.
