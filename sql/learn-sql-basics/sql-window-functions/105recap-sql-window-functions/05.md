## Moving Average (AVG)

Lastly, the requirement is to calculate the moving average of sales over a set of transactions.

To do this, you can use the AVG() window function to calculate a moving average of sales over the previous three transactions.

```sql
1SELECT 
2    sales_rep_id, 
3    sales_rep_name, 
4    sales_amount, 
5    AVG(sales_amount) OVER (PARTITION BY sales_rep_id ORDER BY transaction_date ROWS BETWEEN 2 PRECEDING AND CURRENT ROW) AS moving_avg
6FROM Sales;
```

This query calculates the moving average of the last three sales transactions for each representative.
