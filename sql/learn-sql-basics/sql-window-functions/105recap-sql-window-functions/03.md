## Calculating Running Total (SUM)

The next requirement is to calculate the running total of sales for each sales representative.

You can use the SUM() window function to calculate the cumulative total of sales, partitioned by the sales representative and ordered by the transaction date.

```sql
1SELECT 
2    sales_rep_id, 
3    sales_rep_name, 
4    sales_amount, 
5    SUM(sales_amount) OVER (PARTITION BY sales_rep_id ORDER BY transaction_date) AS running_total
6FROM Sales;
```

This query will give you the running total of sales for each representative as you move through their transactions.
