## Ranking Sales Representatives (RANK)

To rank employees based on their total sales performance, you can use the RANK() function because it assigns a unique rank to each row within a partition, with ties receiving the same rank.

Here's how you can rank the sales representatives:

```sql
1SELECT 
2    sales_rep_id, 
3    sales_rep_name, 
4    SUM(sales_amount) AS total_sales, 
5    RANK() OVER (ORDER BY SUM(sales_amount) DESC) AS rank
6FROM Sales
7GROUP BY sales_rep_id;
```

This query calculates the total sales for each sales representative and assigns a rank based on their sales performance.
