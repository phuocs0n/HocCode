## Finding Total Inventory Value

The total inventory value indicates the worth of your current stock, which is crucial for budgeting, restocking, and communicating with stakeholders.

Previously, you've used SUM() to add values to a single column. However, it can also calculate totals from expressions.

For instance, to determine the total inventory value, multiply the price of each product by its quantity and then sum the results.

```sql
1SELECT SUM(price * quantity) AS total_inventory_value
2FROM Products;
```

Here, SUM(price * quantity) calculates the total value of all products in stock.

Insights:

- Total inventory value: $21,175

This calculation provides you with the combined value of all your products, helping you decide whether to increase stock for high-value items.
