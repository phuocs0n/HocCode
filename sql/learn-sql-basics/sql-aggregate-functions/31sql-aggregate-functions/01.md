## Chapter Overview

In this chapter, you'll begin by exploring basic SQL aggregate functions to summarize data from the Employees table.

You'll learn how to perform simple calculations like identifying the youngest employee or the highest salary.

By the end of this chapter, you'll learn to use aggregate functions to perform such calculations and derive insights from data.

There are five commonly used aggregate functions:

- MIN()
- MAX()
- COUNT()
- SUM()
- AVG()

Let's start with the MIN() and MAX() functions.
