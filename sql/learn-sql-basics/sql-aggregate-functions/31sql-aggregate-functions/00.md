## Introduction to Aggregate Functions

In the previous chapter, we covered how to filter and extract specific data from a table. However, simply retrieving raw data isn't sufficient.

To derive insights from the data, you need to analyze and summarize this information.

For example, you're a data analyst working with your company's Employees table:

```sql
1-- Select all employees' data
2
3SELECT *
4FROM Employees;
```

Your manager asks for the following:

- What is the age of the youngest employee?
- What is the highest salary in the company?
- How many employees work in the Sales department?

To provide these insights, you'll need to use aggregate functions to summarize the data effectively.
