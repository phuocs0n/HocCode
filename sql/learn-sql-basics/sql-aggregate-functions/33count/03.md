## Example 2: Records Matching a Criteria

As a data analyst, you'll mostly use the COUNT() function to count the rows matching the specified criteria.

For example, your organization asks you to find the number of employees who are eligible for incentives, such as those aged between 22 and 26.

```sql
1-- Count the number of employees between 22 and 26
2
3SELECT COUNT(*)
4FROM Employees
5WHERE age BETWEEN 22 AND 26;
```
