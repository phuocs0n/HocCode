## SQL RIGHT JOIN

A RIGHT JOIN is similar to a LEFT JOIN, except it selects all the rows from the right table and any matching rows from the left table.

Let's see how we can use a RIGHT JOIN to combine data from the Customers and Orders tables.

```sql
1-- Right join the Customers and Orders tables
2-- and select all the columns from these tables
3
4SELECT *
5FROM Customers
6RIGHT JOIN Orders
7ON Customers.customer_id = Orders.customer_id;
```

Here, RIGHT JOIN ensures that all rows from the Orders table are included. If there is no matching customer_id in Customers, the result shows NULL for the Customers' columns.
