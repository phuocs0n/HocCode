## Example 2: Validating Customer-Order Connections

To ensure that orders are linked to the right customers, you need to identify cases where each order has a corresponding customer entry.

In this case, RIGHT JOIN is perfect because it includes all records from the Orders table and matches them with available records from the Customers table.

```sql
1-- Use RIGHT JOIN to ensure each order is 
2-- linked to a customer
3
4SELECT Orders.product_name, Customers.customer_name, Customers.city
5FROM Customers
6RIGHT JOIN Orders 
7ON Customers.customer_id = Orders.customer_id
8WHERE Customers.customer_id IS NULL;
```

Here, when a customer record exists, it confirms the link is correct; if it's NULL, it indicates an issue. This query returns all orders that have issues.
