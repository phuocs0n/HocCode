## Finding Courses Without Students: RIGHT JOIN

To answer the dean's question, "Are there courses that don't have any students?" you can check the Courses table and match it with the Enrollments table to identify courses without any student enrollments.

For this, a RIGHT JOIN is ideal, as it includes all rows from the right table (Courses) and fills unmatched rows from the left table (Enrollments) with NULL.

```sql
1-- Join the enrollments table with the
2-- students table, including all courses and
3-- showing NULL for courses without
4-- students.
5
6SELECT Courses.id, Courses.course_name
7FROM Enrollments
8RIGHT JOIN Courses
9ON Enrollments.course_id = Courses.id
10WHERE Enrollments.course_id IS NULL;
```

In this case, courses like Python Programming(C104) will appear with NULL values in the Enrollments table, indicating no students are enrolled.
