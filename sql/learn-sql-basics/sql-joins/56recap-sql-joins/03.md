## Finding Students Not Enrolled in Any Course: LEFT JOIN

To answer the dean's question, "Who hasn't enrolled in any course?" you need to check for students in the students table who don't have a corresponding record in the enrollments table.

For this, a LEFT JOIN is ideal, as it includes all rows from the left table (Students) and fills unmatched rows from the right table (Enrollments) with NULL.

```sql
1-- Join the students table with the
2-- enrollments table, including all students
3-- and showing NULL for those not enrolled
4-- any course.
5
6SELECT Students.id, Students.name
7FROM Students
8LEFT JOIN Enrollments
9ON Students.id = Enrollments.student_id
10WHERE Enrollments.student_id IS NULL;
```

From the result, you can see that Jack Miller hasn't enrolled in any course.
