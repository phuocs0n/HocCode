## Introduction to JOINs

In previous chapters, you learned how to retrieve, filter, and organize data from a single table.

However, in real-world databases, data is often spread across multiple tables. To make sense of this data, you need to combine data from these tables.

For example, imagine you have two tables:

- A Customers table with details like names and ages.
- An Orders table with items purchased and customers associated with each order.

Now, suppose your manager asks:

- Which customers made purchases?
- What did each customer buy?
- Are there customers who haven't placed any orders?

To answer these questions, you'll need to join the tables—linking rows from different tables based on a related column. This process is called a JOIN in SQL.
