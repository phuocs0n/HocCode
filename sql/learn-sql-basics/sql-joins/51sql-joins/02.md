## Chapter Overview

In SQL, you can use the JOIN statements to retrieve data stored in multiple tables. A JOIN combines records from two or more tables based on a matching condition between them.

There are four commonly used JOIN statements:

- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- FULL JOIN

In this chapter, you'll learn each of these JOINs in detail. Let's start with the most frequently used one: INNER JOIN.
