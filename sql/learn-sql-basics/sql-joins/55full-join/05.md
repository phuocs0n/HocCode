## Example 2: Identifying Unmatched Customers and Purchases

To find records where customers have no purchases or purchases have no customers, you need to combine all records from both tables and filter for unmatched entries.

For this, you can use a FULL JOIN and then check for NULL values in the relevant columns to identify the unmatched records.

```sql
1-- Use FULL JOIN to find unmatched
2-- customers or purchases
3
4SELECT Customers.customer_name, Orders.product_name
5FROM Customers
6FULL JOIN Orders 
7ON Customers.customer_id = Orders.customer_id
8WHERE Customers.customer_id IS NULL OR Orders.product_name IS NULL;
```
