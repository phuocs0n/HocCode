## SQL FULL JOIN

A FULL JOIN combines rows from both tables, returning all records from the left table and the right table.

Let's see how we can use a FULL JOIN to all the rows from the Customers and Orders tables.

```sql
1SELECT *
2FROM Customers
3FULL JOIN Orders
4ON Customers.customer_id = Orders.customer_id;
```
