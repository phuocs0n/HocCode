## Introduction to LEFT JOIN

In the previous lesson, you learned how to join tables using INNER JOIN, which retrieves only the rows with a match in both tables.

But what if you want to include all records from one table, even if there's no match in the other?

For example, you're analyzing customer data, and you want a list of all customers—even those who haven't placed an order yet.

To do this, you can use SQL LEFT JOIN. Let's explore how on the next page.
