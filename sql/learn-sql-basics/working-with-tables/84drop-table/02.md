## DROP TABLE IF EXISTS

While cleaning up old tables, you may accidentally try to delete a table that doesn't exist in the database. Normally, the database would return an error like "table does not exist."

For example, if your database only has the Products table, but you mistakenly try to delete Customers table:

```sql
1-- Delete the table
2
3DROP TABLE Customers;
```

Since the Customers table does not exist, this will result in an error.

To fix this error, you can add the IF EXISTS clause with the DROP TABLE statement.

```sql
1-- delete the table if it exists 
2
3DROP TABLE IF EXISTS Customers;
```

This ensures that the table is only deleted if it exists, preventing unnecessary errors.
