## Adding a Column

As the business expands, customers from different cities start purchasing the product. To keep track of where they are from, you need to store city-wise information.

Suppose this is the Customers table we have.

```sql
1SELECT *
2FROM CUSTOMERS
```

In order to store city information, you can add a city column using:

```sql
1-- Add a column
2
3ALTER TABLE Customers
4ADD COLUMN city VARCHAR(200);
```

Note: The ALTER TABLE syntax may differ among different database systems.

Since no data has been added, the city column contains NULL values.
