## ALTERING TABLE

Your manager has asked: "How can we add new details to the table later?"

To address this, you can modify the Customers table by adding a new column.

For example, to store customer location data for future marketing campaigns, you can add a city column to the table:

```sql
1ALTER TABLE Customers
2ADD COLUMN city VARCHAR(200);
```
