## DROPPING TABLE

To fulfill the requirement of safely removing a table when it is no longer needed, such as the Users table, you can use the following command:

With a single command, you can remove an entire table:

```sql
1DROP TABLE Users;
```

But what if the table doesn't exist? Running the command could result in an error. To prevent this, you can use:

```sql
1DROP TABLE IF EXISTS Users;
```
