## Introduction

Previously, you learned how to insert and update data in the Students table. As we continue managing this table, there may come a time when a student no longer needs to be part of the records.

For instance, imagine a situation where a student transfers to another institution. In such cases, you might need to delete that student's record from the database.

To handle this, you can use the DELETE FROM statement, which allows you to remove one or more records from a table.
