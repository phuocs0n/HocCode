## Removing Unavailable Books

The management team decided to clean the database and said, "We need to clean up our database by removing all books that are currently marked as unavailable. How can you do that?"

For this, you can use the DELETE FROM statement as:

```sql
1DELETE FROM Books
2WHERE availability = 'No';
```

The above query removes all the books that are unavailable from the Books table.
