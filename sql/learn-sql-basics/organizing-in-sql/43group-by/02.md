## Examples: GROUP BY

Example 1: Average Purchase Amount of Customers in Each Country

```sql
1-- Group data by different country
2-- Select country and average purchase amount
3
4SELECT country, AVG(purchase_amount) AS average_purchase
5FROM Customers
6GROUP BY country;
```

The above query groups customers by country and calculates the average purchase amount for each.

Example 2: Number of Customers in Each Country

```sql
1-- Group data by different country
2-- Select country and number of customers
3
4SELECT country, COUNT(name) AS number_of_customers
5FROM Customers
6GROUP BY country;
```

Example 3: Maximum and Minimum Purchase Amount of Customers in Each Country

```sql
1-- Group data by different country
2-- Select country, minimum and maximum purchase amount
3
4SELECT country, MIN(purchase_amount) AS min_purchase, 
5MAX(purchase_amount) AS max_purchase
6FROM Customers
7GROUP BY country;
```
