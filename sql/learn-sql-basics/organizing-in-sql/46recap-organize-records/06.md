## Selecting Employees with Name Containing Letter "J"

Your manager needs to contact an employee about a critical project but can't recall their full name. However, he remembers that their name contains the letter "J".

To assist, use wildcards to retrieve the list of employees whose names include the letter "J".

```sql
1-- Find employees with name containing "J"
2
3SELECT name, department
4FROM employees
5WHERE name LIKE '%J%';
```

This helps you retrieve employees' names from incomplete data in a company.
