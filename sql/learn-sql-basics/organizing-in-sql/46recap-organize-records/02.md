## Sorting Employees with Higher Salary

Suppose your manager asks you to find the top five highest-earning employees, sorted in descending order.

To accomplish this, you can use ORDER BY with the LIMIT clause.

For example,

```sql
1-- Select name and salary of top 5 highest-earning employees
2
3SELECT name, salary
4FROM Employees
5ORDER BY salary DESC
6LIMIT 5;
```

Now, the company can easily analyze the employees with higher salaries.
