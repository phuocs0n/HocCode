## Finding the Number of Employees in Each Department

You are asked to find the number of employees in each department of the company. This is necessary to ensure a balanced workforce.

To achieve this, use GROUP BY with COUNT() aggregate function.

```sql
1-- Group employees by departments
2-- Find the number of employees in each department
3
4SELECT department, COUNT(*) AS num_of_employees
5FROM Employees
6GROUP BY department;
```

These insights help the company ensure that the workforce is balanced.
