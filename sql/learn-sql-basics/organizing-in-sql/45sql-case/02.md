## Example: SQL CASE With Multiple WHEN

In the last example, we used a single WHEN clause in a CASE statement.

However, you can include multiple WHEN clauses to apply different conditions.

For example, to categorize customers based on their purchase amount:

- 'Low Spender' for purchases below 2000,
- 'Target Customer' for purchases between 2000 and 4999,
- 'High Spender' for purchases between 5000 and 5999.

Here's how you can implement this in SQL:

```sql
1SELECT *,
2    CASE 
3        WHEN purchase_amount < 2000 THEN 'Low Spender'
4        WHEN purchase_amount >= 2000 AND purchase_amount < 5000 THEN 'Target Customer'
5        WHEN purchase_amount >= 5000 AND purchase_amount < 6000 THEN 'High Spender'
6    END AS purchase_group
7FROM Customers;
```

This query selects all the columns from the Customers table and adds a new column named purchase_group, which categorizes customers based on their purchase amount:

- 'Low Spender' if purchase_amount is less than 2000,
- 'Target Customer' if purchase_amount is between 2000 and 4999,
- 'High Spender' if purchase_amount is between 5000 and 5999.

If purchase_group is 6000 or more, the purchase_group column remains empty (NULL).
