## Examples: SQL HAVING

Example 2

```sql
1-- Group data by country 
2-- Display the average purchase in each country 
3-- if the average purchase is greater than 3000
4
5SELECT country, AVG(purchase_amount) AS average_purchase
6FROM Customers
7GROUP BY country
8HAVING average_purchase > 3000;
```

Example 3

```sql
1-- Group data by country 
2-- Display the average purchase in each country 
3-- if the average purchase is greater than 3000
4-- and sort results in descending order by average_purchase
5
6SELECT country, AVG(purchase_amount) AS average_purchase
7FROM Customers
8GROUP BY country
9HAVING average_purchase > 3000
10ORDER BY average_purchase DESC;
```
