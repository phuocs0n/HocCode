## Introduction

In Chapter 2, you learned how to use the WHERE clause to filter rows.

However, when using GROUP BY with aggregate functions, the WHERE clause doesn't work, resulting in an error.

For example,

```sql
1-- Syntax error: the WHERE clause cannot be used in this SQL query
2
3SELECT country, AVG(purchase_amount) AS average_purchase
4FROM Customers
5GROUP BY country
6WHERE AVG(purchase_amount) > 4000;
```

To filter records in such situations, you must use the HAVING clause.

```sql
1-- Group customers by country
2-- Display records if the average purchase amount of
3-- customers in a country is more than 4000
4
5SELECT country, AVG(purchase_amount) AS average_purchase
6FROM Customers
7GROUP BY country
8HAVING AVG(purchase_amount) > 4000;
```

Next, we'll look at examples using HAVING.
