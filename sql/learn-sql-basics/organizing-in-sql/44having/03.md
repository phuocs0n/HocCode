## WHERE With GROUP BY

By the way, you can use WHERE in a GROUP BY clause like this:

```sql
1SELECT country, SUM(purchase_amount) AS total_purchase
2FROM Customers
3WHERE purchase_amount > 3000
4GROUP BY country;
```

Here, the SQL query first selects rows where the purchase amount exceeds 3000. Then, it groups the filtered results by country.

However, you cannot use WHERE in a GROUP BY clause like this:

```sql
1SELECT country, SUM(purchase_amount) AS total_purchase
2FROM Customers
3GROUP BY country
4WHERE purchase_amount > 3000;
```

In this case, we are trying to filter the results of GROUP BY using the WHERE clause. This results in an error.

You should use the HAVING clause to filter the results of a GROUP BY clause instead.
