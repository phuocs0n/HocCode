## Examples: SQL HAVING

Example 1

```sql
1-- Group data by country 
2-- Display the total sum of purchase in each country 
3-- if the number of customers is less than 3
4
5SELECT country, SUM(purchase_amount) AS total_purchase
6FROM Customers
7GROUP BY country
8HAVING COUNT(*) < 3;
```

This query selects the country and calculates the total purchase amount by grouping customers by country:

```sql
SELECT country, SUM(purchase_amount) AS total_purchase
FROM Customers
GROUP BY country ..
```

Then, it filters the results to only include countries with less than 3 customers using the HAVING clause.

```sql
HAVING COUNT(*) < 3
```
