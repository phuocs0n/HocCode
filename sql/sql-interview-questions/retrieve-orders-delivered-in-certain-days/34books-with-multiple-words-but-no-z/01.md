## Thought Process

We have a Books table with columns id, title, release_date, and publisher.

We need to check for book titles containing multiple words but without the alphabet, Z.

To perform this comparison, we can use the LIKE and NOT LIKE operators as below:

- Use LIKE with the % % wildcard characters to select books with more than one word. The % wildcard searches for any character or word. Using two of these characters with a space in between (% %) allows us to search for column values with two or more words (since words are separated by spaces).
- Use the NOT LIKE operator to filter out books with Z in their titles.
- Finally, we use the ORDER BY clause to arrange the book titles in ascending order.
