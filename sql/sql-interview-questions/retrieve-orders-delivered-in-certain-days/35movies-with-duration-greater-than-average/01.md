## Thought Process

We are given a Movies table with the columns id, title, and duration.

Here, we need to retrieve the movie titles with a duration greater than the average duration of all movies in the table.

We can solve this problem using a subquery. The inner query will calculate the average duration of all movies using the AVG() function.

The outer query selects those titles that match the condition of the inner query.

Here, the average duration is given by:

```sql
(193 + 126 + 144) / 3 = 154.33
```

The only entry in the table with duration greater than this average is (1, Pulp Fiction, 193).

Therefore, the resulting table will be:

| title |
| --- |
| Pulp Fiction |
