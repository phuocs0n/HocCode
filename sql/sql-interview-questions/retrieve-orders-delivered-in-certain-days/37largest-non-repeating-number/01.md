## Thought Process

We have a table named Numbers with a column number that contains a bunch of random numbers.

From this table, we need to fetch the largest non-repeating number. If there are no such numbers, we return NULL.

So, to solve this problem, we have to figure out two things:

- Eliminate all the repeating numbers in the Numbers table.
- Find the maximum number from the rest of the entries in the Numbers table.

To eliminate all the repeating numbers, we must group the number column by those numbers with a count of 1.

This will give us the following table:

| number |
| --- |
| 1 |
| 4 |
| 5 |
| 6 |

We can now use the MAX() function to filter out the largest number in this sub-table, i.e., 6.

Therefore, our result will be

| largest_single_number |
| --- |
| 6 |
