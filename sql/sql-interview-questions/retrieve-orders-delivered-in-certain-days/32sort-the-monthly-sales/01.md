## Thought Process

We are given a Sales table with columns sales_id, sales_date, and sales_amount.

And we need to find the monthly sales from the above table and sort them in descending order of sales_amount and sales_date.

The most challenging part about this particular question is that we need to extract the month from the exact date in the sales_date column.

Fortunately, we have the strftime() function in SQLite to convert the date to a particular format.

The function has the following structure:

```sql
strftime('%Y-%m-%d', column_name)
```

Here, the function takes in two parameters:

- %Y-%m-%d acts as a placeholder for year-month-date format (YYYY-MM-DD)
- column_name represents the column that contains the date value you want to format

For example, strftime('%m', sales_date) will reduce the full date into its respective month, i.e., the %m wildcard stands for month (01 for January, 12 for December and so on).

It will return the following table:

| sales_date |
| --- |
| 05 |
| 06 |
| 06 |
| 06 |
| 06 |

Then, we use the SUM() function to calculate the total sales amount.

After doing this, we simply need to group the results by the month column and then sort the resulting table's columns in descending order of sales_amount and sales_date.

Here's what the output would be:

| month | total_sales |
| --- | --- |
| 06 | 270800 |
| 05 | 50000 |
