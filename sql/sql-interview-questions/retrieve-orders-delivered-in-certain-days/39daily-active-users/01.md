## Thought Process

We have an Activity table with columns user_id, session_id, activity_date, and activity_type.

Our goal is to find the number of daily active users for a period of 4 days ending in 2023-04-18.

- In this problem, we first need to count the number of distinct users and label the result set with the alias daily_active_users.

- We then filter the dates between '2023-04-15' and '2023-04-18', i.e., 4 days.

- Finally, we group the result by activity_date.

The result will consist of the following table:

| activity_date | daily_active_users |
| --- | --- |
| 2023-04-15 | 2 |
| 2023-04-16 | 3 |
| 2023-04-17 | 1 |
| 2023-04-18 | 1 |
