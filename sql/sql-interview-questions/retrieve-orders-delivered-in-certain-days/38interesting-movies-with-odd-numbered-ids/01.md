## Thought Process

We have a Movies table with columns movie_id, title, description, and rating.

We need to retrieve movies that have an odd-numbered movie_id and a description that isn't Boring.

To solve this problem, we first need a method to check whether a number is odd or even:

- Odd numbers are numbers that aren't perfectly divisible by 2.
- Even numbers are numbers that are perfectly divisible by 2.

So, we now need to filter movie ids that aren't perfectly divisible by 2, which is given by the condition movie_id % 2 <> 0.

We then filter the rows by the description column, where the value is not equal to Boring.

Finally, we will need to sort the result in descending order by rating using the ORDER BY clause.
