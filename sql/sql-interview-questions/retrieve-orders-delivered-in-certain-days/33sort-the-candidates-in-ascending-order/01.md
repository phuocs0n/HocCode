## Thought Process

We have a Candidates table with the columns candidate_id, name, python, and SQL.

We need to find the candidates suitable for data science under the alias fit_candidate and sort the result in ascending order of candidate_id.

We assume a candidate is suitable for the job if they are Good at both python and SQL.

To solve this problem, we need to take the following approach:

- Select the rows with the value Good in both the python and SQL columns.
- Retrieve the candidate_id in ascending order.
- Return the names of the candidates as a column under the alias fit_candidate.

Therefore, our SQL query will use the WHERE condition along with the ORDER BY, AS, and ASC commands.
