## Thought Process

We are given the following tables:

- Orders table with columns order_id, customer_id, and order_date.
- Items table with columns order_id, product_id, and quantity.

Our goal is to write an SQL query to retrieve the ids of customers and the total quantity of products ordered by each customer.

We can solve this problem by using the INNER JOIN keyword and combining the information from both tables.

We must match the order_id column in the Orders table with the order_id column in the Items table to ensure proper association between the two tables.

We can then group the combined data based on customer_id i.e., gather all information related to each customer and treat them as separate groups.

Finally, we calculate the sum of the quantity of products ordered by each customer using the SUM() function. We will use the total_quantity alias to denote this quantity.

The result set will include customer_id and the corresponding total_quantity for each customer.
