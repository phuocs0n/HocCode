## Explain the order of execution in an SQL query involving multiple clauses with an example

In SQL, the order of execution is not as same as the query structure.

Here is the standard query structure in SQL:

```sql
SELECT column(s)
FROM table
WHERE condition;
```

Now, you might think the SELECT statement is executed first, the FROM statement second, and the WHERE clause last.

However, that's not the case. The execution order does not align with the apparent order of the statements in SQL.

Instead, SQL has the following order of execution:

1. FROM: Identify the table(s) from which to get the data.
2. WHERE: Apply any specified condition(s) to filter the data.
3. GROUP BY: Group the data based on the specified columns.
4. HAVING: Further filter the grouped data based on the given conditions.
5. SELECT: Choose the columns to include in the result set.
6. DISTINCT: Remove duplicate rows from the result set.
7. ORDER BY: Sort the result set based on the specified columns.
8. LIMIT/OFFSET: Restrict the number of rows returned or set a starting point.

Therefore, the code SELECT column(s) FROM table WHERE condition; has the following execution order:

1. FROM table
2. WHERE condition
3. SELECT column(s)
