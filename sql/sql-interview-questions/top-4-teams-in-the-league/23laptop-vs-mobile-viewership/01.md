## Thought Process

We are given the table Viewership with columns user_id, device_type, and view_time.

Our task is to retrieve the total views for laptops and mobile devices (categorized as laptop_views and mobile_views, respectively). Obviously, we will use the SUM() function for this task.

However, the caveat is that we must check whether the device_type is a laptop (for laptop_views) or a phone or tablet (for mobile_views).

To check the device type for laptop_views, we can use the CASE statement and assign a flag of 1 if the device_type is laptop and 0 if it's not.

We can do the same for mobile_views.

But since both the phone and tablet views fall under the mobile_views category, we use the IN statement to check if the device_type is a tablet or a phone.

We can then use CASE statements within the SUM() function to calculate the total count of laptop and phone views.
