#### Course: SQL Interview Questions

## What will happen if we execute the following query?

```sql
1SELECT AVG(salary)
2FROM Employees
3WHERE department = 'Development' AND salary < AVG(salary);
```

The query will not execute because you cannot refer to the calculated average in the WHERE clause directly.

To correct the query, you can use a subquery:

```sql
1SELECT AVG(salary)
2FROM Employees
3WHERE department = 'Development' AND salary < (
4  SELECT AVG(salary)
5  FROM Employees
6);
```
