# What's Wrong With This Code?

#### Course: SQL Interview Questions

## What's Wrong With This Code?

```sql
1UPDATE Movies 
2SET title = 'Inception';
```

The code above updates the values of the title column to Inception for all rows in the Movies table. However, we usually only update the values of specific rows.

To update specific values in the title column, we need a WHERE condition to specify the row to update. The above code has a missing WHERE clause, which gives undesirable results.

#### How to Fix It?

We can fix the above code by adding a WHERE condition to the UPDATE statement.

```sql
1UPDATE Movies 
2SET title = 'Inception'
3WHERE duration = 126;
```
