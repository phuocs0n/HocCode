#### Course: SQL Interview Questions

## What will happen if we execute the following query?

```sql
1SELECT *
2FROM Employees
3LIMIT -2;
```

The query will either throw an error or give an unexpected result because the LIMIT clause expects a positive integer value.

To retrieve the last 2 records, you can use a combination of ORDER BY and LIMIT as below:

```sql
1SELECT *
2FROM Employees
3ORDER BY emp_id DESC
4LIMIT 2;
```
