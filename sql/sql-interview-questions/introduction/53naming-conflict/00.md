# What's Wrong With This Code?

#### Course: SQL Interview Questions

## What's Wrong With This Code?

```sql
1CREATE TABLE Employees (
2  id INT PRIMARY KEY,
3  name VARCHAR(50),
4  name VARCHAR(50)
5);
```

The code above is syntactically correct, but it defines the name column twice, causing a naming conflict.

Naming conflicts can lead to confusion, errors, and unexpected behavior when executing SQL queries.

So, it is essential to understand and resolve naming conflicts and ensure the accuracy and reliability of database operations.

#### How to Fix It?

You need to use unique names for each column to fix this issue. Here's the corrected code:

```sql
1CREATE TABLE Employees (
2  id INT PRIMARY KEY,
3  first_name VARCHAR(50),
4  last_name VARCHAR(50)
5);
```
