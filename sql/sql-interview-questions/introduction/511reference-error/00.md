# What's Wrong With This Code?

#### Course: SQL Interview Questions

## What's Wrong With This Code?

```sql
1SELECT *
2FROM Books
3ORDER BY id DESC
4LIMIT 3;
```

The above code has a Reference Error.

In SQL, a reference error occurs when a reference to a non-existent or invalid object is made.

In the given query, we are trying to order the result by id, but the id column doesn't exist in our Books table.

#### How to Fix It?

We can fix the above code by simply ordering the results using a column that actually exists in the table.

In our case, the Books table has three columns: publisher, title, release_date. We can use any one of these columns to order our table.

```sql
1SELECT *
2FROM Books
3ORDER BY release_date DESC
4LIMIT 3;
```
