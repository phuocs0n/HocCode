## What's Wrong With This Code?

```sql
1SELECT department, SUM(salary) AS expense
2FROM Employees
3GROUP BY department
4HAVING expense > 30000;
```

While there's nothing wrong with the above code, the HAVING clause should not ideally reference the alias expense directly.

Instead, the aggregate function should be used in the HAVING clause.

#### How to Fix It?

We can re-write the above query by including the aggregate function in the HAVING clause to fix the mistake.

```sql
1SELECT department, SUM(salary) AS expense 
2FROM Employees
3GROUP BY department
4HAVING SUM(salary) > 30000
```
