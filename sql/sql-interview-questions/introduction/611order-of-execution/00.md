## What will happen if we execute the following query?

```sql
1SELECT item, quantity
2FROM Products
3WHERE quantity > 10
4ORDER BY quantity DESC;
```

The above code will filter the items with quantity greater than 10 from the Products table in descending order.

Since multiple operations are taking place in the above query, it is important to know about how SQL processes such queries.

SQL has a set order of execution to handle queries consistently.

The order of execution in SQL determines the sequence of operations in an SQL query.

In the above example, the order of execution is:

```sql
FROM > WHERE > SELECT > ORDER BY
```
