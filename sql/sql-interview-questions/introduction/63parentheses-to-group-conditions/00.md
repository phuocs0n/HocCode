# What will happen if we execute the following query?

#### Course: SQL Interview Questions

## What will happen if we execute the following query?

```sql
1SELECT name
2FROM Employees
3WHERE salary > 2000 AND salary < 5000
4  AND department = 'Sales' OR department = 'Development';
```

At first glance, it might seem the above query has no flaws.

But this query doesn't return the desired output. It should retrieve employees with salaries in the range of 2000 - 5000 (exclusive) belonging to either Sales or Development.

However, the query applies the salary filter only to employees in the Sales department. As a result, John from Development is also selected even though his salary is 6000 i.e., out of the defined salary range.

So, the problem lies in how the query is written. The industry standard urges us to group the conditions to make the results consistent.

To ensure correct grouping of conditions, parentheses should be used:

```sql
1SELECT name
2FROM Employees
3WHERE (salary > 2000 AND salary < 5000)
4  AND (department = 'Sales' OR  department = 'Development');
```

Similarly, our compiler interprets the first query (the one without any parentheses) in the following way:

```sql
1SELECT name
2FROM Employees
3WHERE (salary > 2000 AND salary < 5000 AND department = 'Sales')
4  OR  department = 'Development';
```
