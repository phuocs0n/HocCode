#### Course: SQL Interview Questions

## What will happen if we execute the following query?

```sql
1SELECT TOP 3 *
2FROM Customers;
```

The query will throw an error in our online compiler because the syntax for limiting the number of rows varies across different database systems.

More specifically, the TOP clause is used in MS SQL SERVER and MS Access. Here's some sample queries to get the desired result in various database systems:

MS SQL Server / MS Access:

```sql
SELECT TOP 3 *
FROM Customers;
```

Oracle

The Oracle DBMS uses the FETCH FIRST clause:

```sql
SELECT *
FROM Customers
FETCH FIRST 3 ROWS ONLY;
```

MySQL / PostgreSQL / SQLite

Our online compiler is based on SQLite. So, to run this query on our compiler, we use the LIMIT clause:

```sql
1SELECT *
2FROM Customers
3LIMIT 3;
```
