## What will happen if we execute the following query?

```sql
1SELECT name
2FROM Customers
3WHERE name LIKE '%_a_%';
```

The query will return those customer names that have the letter a anywhere between the first and the last characters.

So, if our table has names like Marcus, Harry, and Wayne, the above query will display them.

However, it won't display names like Andrew, Mira, Roma, Alex, etc. because there is no instance of the letter a between the first and last characters.
