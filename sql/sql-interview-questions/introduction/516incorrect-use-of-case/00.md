## What's Wrong With This Code?

```sql
1SELECT item,
2  CASE quantity
3    WHEN quantity < 10 THEN 'Low'
4    WHEN quantity < 20 THEN 'Medium'
5    ELSE 'High'
6  END AS category
7FROM Products;
```

The code in the CASE statement has a syntax error.

We can't write CASE quantity when the quantity column is already being compared in the WHEN condition.

SQL programmers often overlook this aspect of CASE statements, leading to errors.

#### How to Fix It?

We can fix the above code by removing quantity from the CASE quantity line.

```sql
1SELECT item,
2  CASE 
3    WHEN quantity < 10 THEN 'Low'
4    WHEN quantity < 20 THEN 'Medium'
5    ELSE 'High'
6  END AS category
7FROM Products;
```
