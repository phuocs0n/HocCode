# What's Wrong With This Code?

#### Course: SQL Interview Questions

## What's Wrong With This Code?

```sql
1SELECT *
2FROM EPL
3WHERE goals >= '50';
```

The code above uses a string comparison instead of a numeric comparison for the quantity, which may lead to unexpected results.

In other words, the condition is checking for goals greater than or equal to '50' in the EPL table (which houses soccer statistics).

However, using single quotation marks around the number 50 implies that it is being treated as a string instead of a numeric value.

This can lead to unexpected results when the data type of the goals column is not VARCHAR, which makes sense because goals are positive integers in real life.

#### How to Fix It?

To fix this mistake, you should remove the single quotation marks around the number 50 and treat it as a numeric value.

Here's the corrected code:

```sql
1SELECT *
2FROM EPL
3WHERE goals >= 50;
```
