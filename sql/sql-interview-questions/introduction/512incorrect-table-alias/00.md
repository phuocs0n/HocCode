# What's Wrong With This Code?

#### Course: SQL Interview Questions

## What's Wrong With This Code?

```sql
1SELECT SUM(salary) 
2FROM Employees AS salary_expense;
```

Here, the salary_expense alias is not specified in the SELECT clause.

While retrieving a column as an alias, we must use it on the same line as the SELECT clause.

#### How to Fix It?

Update the SELECT clause to include the correct alias:

```sql
1SELECT SUM(salary) AS salary_expense 
2FROM Employees;
```
