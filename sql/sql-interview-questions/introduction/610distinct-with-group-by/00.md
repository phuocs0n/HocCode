#### Course: SQL Interview Questions

## What will happen if we execute the following query?

```sql
1SELECT DISTINCT item, COUNT()
2FROM Products
3GROUP BY item
4HAVING COUNT() > 1;
```

The query will return the distinct items and their corresponding counts from the Products table, but only for those categories that have more than one product.

In our case, none of the distinct items on the table have more than one count.

Hence, we get an "SQL query successfully executed. However, the result set is empty." message.
