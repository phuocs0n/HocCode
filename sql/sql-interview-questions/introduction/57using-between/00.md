## What's Wrong With This Code?

```sql
1SELECT *
2FROM Employees
3WHERE salary BETWEEN 30000 AND 90000;
```

While nothing is wrong with the above code, the BETWEEN operator can result in wrong outputs.

For example, the above code fails if you only want to retrieve employees with salaries greater than 30000 and less than 90000.

Since the BETWEEN operator includes the upper and lower bounds, the salary filtering will be inclusive, meaning the SQL query will also retrieve employees with salaries of 30000 and 90000.

#### How to Fix It?

You can replace the BETWEEN operator with the greater than (>) and less than (<) operators if you don't want to include employees with salaries of 30000 and 90000 in your result set:

```sql
1SELECT *
2FROM Employees
3WHERE salary > 30000 AND salary < 90000;
```

If you do want to include those salaries, then you can use the original code with the BETWEEN operator. Or better yet, you can use the >= and <= operators to remove any ambiguity:

```sql
1SELECT * 
2FROM Employees 
3WHERE salary >= 30000 AND salary <= 90000;
```
