## What's Wrong With This Code?

```sql
1CREATE TABLE Books (
2    id INT PRIMARY KEY,
3    title VARCHAR(50) PRIMARY KEY,
4    category VARCHAR(100)
5);
6
```

A primary key uniquely identifies each row in a table. So, having multiple primary keys in the same table is not allowed.

So, the issue with the above code is that we have specified two primary keys in the Books table.

#### How to Fix It?

If you want to create a table with multiple columns as a primary key, you can use a composite key.

Here's an updated version of the code that defines a composite key:

```sql
1CREATE TABLE Books (
2    id INT,
3    title VARCHAR(50),
4    category VARCHAR(100),
5    PRIMARY KEY (id, title)
6);
```
