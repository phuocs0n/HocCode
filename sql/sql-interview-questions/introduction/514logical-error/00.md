# What's Wrong With The Code?

#### Course: SQL Interview Questions

## What's Wrong With The Code?

```sql
1SELECT *
2FROM Employees
3WHERE (type = 'Full-Time' AND salary > 3000)
4  OR (type = 'Part-Time' OR salary < 3000);
```

While there is nothing inherently wrong with the above code, it may cause an error when the problem statement is different.

Suppose you need to select employees with a salary more than 3000 and are Full-Time workers or select Part-Time workers with salary less than 3000.

The above code is bound to fail as the OR operator in the second condition is logically inconsistent. Such logical errors can be fixed with the correct use of operators.

#### How to Fix It?

We can simply replace the second OR condition with AND to ensure correct logic. Here is the updated code:

```sql
1SELECT *
2FROM Employees
3WHERE (type = 'Full-Time' AND salary > 3000)
4  OR (type = 'Part-Time' AND salary < 3000);
```
