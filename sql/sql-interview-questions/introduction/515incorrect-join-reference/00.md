# What's Wrong With The Code?

#### Course: SQL Interview Questions

## What's Wrong With The Code?

```sql
1SELECT *
2FROM Customers
3INNER JOIN Orders
4ON Customers.first_name = Orders.customer_id;
```

Here, the INNER JOIN condition references the wrong column name in the Customers table.

#### How to Fix It?

Update the join condition to reference the correct column name i.e., customer_id.

```sql
1SELECT *
2FROM Customers
3INNER JOIN Orders
4ON Customers.customer_id = Orders.customer_id;
```
