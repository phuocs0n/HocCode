## Thought Process

We have a table named Games with the columns player_id, device_id, event_date and games_played.

We now need to write an SQL query to retrieve the fraction of players that logged in again on the day after they first logged in, rounded to 2 decimal places.

This problem has a simple 3-step solution:

Step 1 - Determine the first login date for each player

The first step is to identify the first login date for each player. This can be achieved using the MIN() function and the GROUP BY clause.

Step 2 - Find the consecutive logins

We now need to identify the players who had consecutive logins, i.e., players who logged in on the day after their previous login.

To do this, we can use the LEAD() function and a subquery to get the next login date and compare it with the current one.

Step 3 - Calculate the Login Fraction

Finally, we can calculate the login fraction by dividing the number of distinct player IDs with consecutive logins by the total number of distinct player IDs.

We also use the ROUND() function to round the result to 2 decimal places.

Since the player with player_id 1 is the only one who logged back in after the first day he had logged in, the answer is 1/3 = 0.33.
