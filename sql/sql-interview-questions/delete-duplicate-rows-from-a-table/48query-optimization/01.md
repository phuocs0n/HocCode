## Thought Process

In SQL, Query Optimization is a process of using SQL queries in the best possible way to get accurate and fast database results.

For this problem, we must write an optimized query using CTE (Common Table Expressions) and Window Functions.

A CTE is a temporary table created from a simple SELECT statement that can be used in a subsequent SELECT statement.

Each SQL CTE is like a named query whose result is stored in a virtual table to be referenced later in the main query.

The problem requires us to write an optimized query to find the top 3 products (sales_id) with the highest total sales amount for each month, in descending order of the months.

So, here's how we can approach the problem:

CTE - 1

We first create a CTE (monthly_sales) to calculate the total sales amount for each sales_id in each month.

We use the strftime() function to extract the year and month from the sales_date column. This helps in grouping the sales data by month.

We also use the SUM() function to calculate the total sales amount for each combination of month and sales_id. The result is aliased into a total_sales_amount column.

The result set includes the month, sales_id, and total_sales_amount.

CTE - 2

The second CTE (ranked_sales) uses the monthly_sales CTE to assign a rank to each sales_id within each month based on the total sales amount.

We need to use the following code for this task:

```sql
ROW_NUMBER() OVER (
  PARTITION BY month
  ORDER BY total_sales_amount DESC
)
```

This code generates a rank for each sales_id within its corresponding month, ordering them based on the total sales amount in descending order.

The result set includes the month, sales_id, total_sales_amount, and rank.

Main Query

The main query selects the month, sales_id, and total_sales_amount from the ranked_sales CTE.

This query retrieves the corresponding month and total sales amount for each sales_id.

It excludes any sales with a rank greater than 3, limiting the results to the top 3 sales for each month.

The final result set is ordered by the month column in descending order, followed by the total_sales_amount column in descending order.

This ordering ensures that the results are sorted first by the most recent month and then by the highest total sales amount within each month.

The resulting table will be:

| month | sales_id | total_sales_amount |
| --- | --- | --- |

| 2023-06 | 4 | 90000 |
| 2023-06 | 2 | 80000 |
| 2023-05 | 1 | 50000 |
