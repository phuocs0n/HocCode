## Thought Process

We have been provided with the Students table containing the columns: student_id, subject, and grade.

Our goal is to create a new table where each student has their own row, and the grades for each subject are placed in separate columns.

In other words, we need to create the Grades table containing the columns: student_id, english, math, and science.

To achieve this, we can utilize the concept of conditional aggregation.

Conditional aggregation in SQL allows you to use aggregate functions, such as SUM(), COUNT(), AVG(), etc., based on specific conditions.

It allows you to include or exclude certain rows from the calculation based on the specified condition.

For this problem, we use the CASE statement within the SELECT clause to conditionally check the subject of each row and extract the corresponding grade.

We do this for each subject column we want to create.

We then select the student_id and the pivoted columns (i.e., english, math, and science) using the MAX() function.

The MAX() function is used here as a simple way to retrieve the grade for each subject.

It effectively extracts the grade since there is only one grade per subject per student i.e., the function can be used to conditionally aggregate rows into columns (with an alias).

Since we want one row per student, we must group the data based on the student_id column. This allows us to put the grades for each subject under the appropriate student.
