## Thought Process

We have a table named Travel with columns source, destination, and distance.

Here, we need to delete duplicate rows from this table where the distance from source to destination is the same as the distance from destination to source.

For example, the distance from Mumbai to Bangalore is the same as the distance from Bangalore to Mumbai. So, we need to remove one of the records.

This problem has a simple 5-step solution:

- Use the DELETE statement to remove rows from the Travel table that satisfy our condition.

- In the WHERE clause, we use ROWID to identify each row in the table. By default, every row in SQLite has a special column, usually called the "rowid", that uniquely identifies that row within the table.

- The subquery in the WHERE clause needs to select the minimum ROWID for each unique combination of values between source and destination.

- The NOT IN condition excludes these minimum ROWID values, resulting in the deletion of duplicate rows.

- After deleting the duplicate rows, the SELECT statement retrieves and displays all the remaining rows from the Travel table, which are those that have not been deleted.

The output will be:

| source | destination | distance |
| --- | --- | --- |
| Mumbai | Bangalore | 500 |
| Delhi | Mathura | 150 |
| Nagpur | Pune | 500 |
