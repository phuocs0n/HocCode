## Thought Process

We have a table named Shows with columns show_id, title, episode_name, air_date, and rating.

This problem requires us to retrieve all the details on the episode with the highest ratings that did not air on the weekends.

For this, we need to filter out two days - Sunday and Saturday from the air_date column.

We can do this by using the strftime() function with the %w placeholder, which stands for day of week (with values ranging from 0 to 6, where Sunday = 0). This function lets us filter out the days in a week when used with a NOT IN operator as below:

```sql
strftime('%w', air_date) NOT IN ('0', '6')
```

Here, 0 stands for Sunday and 6 for Saturday.

In a similar way, you can filter Monday to Thursday with 1, 2, 3, and so on.

After filtering out the weekend, we need to order the results by descending order of rating and limit the output to 1 using the LIMIT command.

The resulting table would be:

| show_id | title | episode_name | air_date | rating |
| --- | --- | --- | --- | --- |
| 3 | HIMYM | Slap Bet | 2023-05-11 | 9 |
