## Thought Process

We are given two tables: Employees and Salaries.

The Employees table has the columns emp_id, first_name, and last_name.

The Salaries table has the columns emp_id and salary.

We need to write an SQL query to retrieve the emp_id, first_name, last_name, and a column called salary_category which should display:

- High for salaries greater than or equal to 5000.
- Medium for salaries between 4000 and 4999.
- Low for salaries below 4000.

The above problem has an elegant solution.

We start by selecting the columns we want to retrieve: emp_id, first_name, and last_name, along with the new column with the alias salary_category.

To classify the salary category, we use a CASE statement:

- If the salary (s.salary) is greater than or equal to 5000, we label it High.

- If the salary is between 4000 and 4999 (inclusive), we label it Medium.

- For any salary below 4000, we label it Low.
- Finally, we give the resulting column the alias salary_category.

Since we need information from the Employees and Salaries tables, we use an INNER JOIN to combine the data.

The joining condition is based on the emp_id column, which is common to both tables.

The result set will include the selected columns as shown below:

| emp_id | first_name | last_name | salary_category |
| --- | --- | --- | --- |
| 1 | Jaden | Smith | Medium |
| 2 | Marshall | Mathers | High |
| 3 | Jermaine | Cole | Low |
