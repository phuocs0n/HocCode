## Thought Process

We are given the Users table with the columns user_id and name.

Our goal is to re-format the values in the name column i.e., aLicE should be changed to Alice and boB should be changed to Bob.

We can do this by updating the required data in the table using the UPDATE statement.

In the UPDATE statement, we can use the following string functions to capitalize the values in the name column:

- UPPER() to convert the first character of the name to uppercase.
- LOWER() to convert the remaining characters of the name to lowercase.
- substr() to extract the necessary portion of the name.

For instance, substr(name, 1, 1) extracts the first character from each value in the name column, i.e., a (from aLicE) and b from (boB).

Similarly, substr(name, 2) will extract the rest of the characters, i.e., LicE and oB.

We can then use the UPPER() and LOWER() functions with substr() to update the name in the table.

After we have broken down the strings and extracted their proper forms, we finally need to concatenate the strings using the concatenation operator ||.
