## Thought Process

We have been given 3 tables:

- Customers table with columns customer_id, first_name, and last_name.
- Orders table with columns order_id, customer_id, and order_date.
- Payments table with columns payment_id, order_id, and amount.

Our task is to join the 3 tables and retrieve the customer_id, first_name, last_name, and a new column called payment_status.

This column should display Paid if the total amount of payments for a customer is greater than or equal to 300, and Unpaid otherwise.

While this problem may seem super difficult, it is actually pretty intuitive if you break the problem down into smaller parts.

Here's how you should approach this problem:

- Start by selecting the columns you want to retrieve: customer_id, first_name, last_name, and payment_status (as alias).

- Use a CASE statement to calculate the payment status. If the total amount of payments for a customer is greater than or equal to 300, we label it as 'Paid'; otherwise, we label it as 'Unpaid'.

- We need to gather the required information from multiple tables. Therefore, we use the FROM clause to specify the primary table, which is Customers in this case.

- To link the relevant data, we utilize LEFT JOIN to join the Customers and the Orders tables on the matching customer_id columns.

- Similarly, we join the Payments table with the Orders table using the order_id columns as the joining condition.

- Since we want to calculate the payment status for each customer, we need to group the data. The GROUP BY clause groups the result set by customer_id, first_name, and last_name.

- Finally, the result set will include the selected columns (customer_id, first_name, and last_name) along with the calculated payment status.

The SQL code will produce the following output:

| customer_id | first_name | last_name | payment_status |
| --- | --- | --- | --- |
| 1 | Dwayne | Johnson | Unpaid |
| 2 | Randy | Orton | Paid |
| 3 | John | Cena | Paid |
