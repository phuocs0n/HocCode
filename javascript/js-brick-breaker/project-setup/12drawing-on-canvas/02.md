## Create the Ball Class 🏗️

Before we write the class, some variables that the project would require will look like these. We define all game constants here in one place so they are easy to find and change.

The ball constants are used right away. The paddle and brick constants will not be used until later chapters. You can ignore them for now but define these on top of your script file before you start writing the class for easier reference.

```javascriptDOM
"use strict";

// Canvas dimensions
const CANVAS_WIDTH = 500, CANVAS_HEIGHT = 360;

// Ball
const BALL_RADIUS = 9, BALL_BASE_SPEED = 4.5, BALL_MAX_SPEED = 9;

// Paddle
const PADDLE_WIDTH = 110, PADDLE_HEIGHT = 14, PADDLE_Y = CANVAS_HEIGHT - 40, PADDLE_KEYBOARD_SPEED = 6;

// Bricks
const BRICK_COLS = 6, BRICK_ROWS = 4, BRICK_WIDTH = 70, BRICK_HEIGHT = 22, BRICK_GAP = 6;
const BRICK_OFFSET_LEFT = 25, BRICK_OFFSET_TOP = 50;
const BRICK_ROW_COLORS = ["#E57373", "#F4A261", "#FFD166", "#95C77B"];
```

Time to write the first entity. The Ball class will live in entities.js and hold its position, size, and drawing logic.

Open entities.js and add all the game constants at the top.

- Create a Ball class with a constructor that sets radius, speed values, and isLaunched, then calls this.reset().
- Add a reset() method that sets x to CANVAS_WIDTH / 2 and y to PADDLE_Y - BALL_RADIUS.
- Add a draw(ctx) method that draws a filled dark circle using ctx.beginPath(), ctx.arc(), set fillStyle to "#444", and ctx.fill().
