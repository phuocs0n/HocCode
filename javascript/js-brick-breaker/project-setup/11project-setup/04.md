## Create the HTML File 📄

Time to lay down the structure. We will create a single index.html file that contains the HUD and the canvas.

Let's start by creating the basic structure of the game.

Create a file named index.html.

- Add a HUD container div with id hud and three spans: hud-score, hud-level, and hud-lives.
- Add a <canvas> with id gameCanvas and set its width to 500 and height to 360.
