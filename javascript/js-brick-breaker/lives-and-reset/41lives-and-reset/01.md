## Reset the Round 🔄

The ball falls out when its top edge passes the bottom of the canvas. You use the top edge rather than the center so the ball is fully off screen before anything happens:

```javascriptDOM
checkBallOutOfBounds() {
  if (this.ball.y - this.ball.radius > CANVAS_HEIGHT) this.loseLife();
}
```

When a life is lost the logic is simple. Decrement the counter, update the HUD, then either reset the round or end the game:

```javascriptDOM
loseLife() {

  this.lives--;
  this.updateHUD();
  this.lives <= 0 ? (this.state = STATE.GAME_OVER) : this.resetRound();
}
```

All the "what happens when you lose a life" logic lives in one place. That makes it easy to extend later without hunting through the codebase.
