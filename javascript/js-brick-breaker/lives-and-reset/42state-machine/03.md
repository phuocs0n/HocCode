## Handle State Transitions 🔀

Implement the logic that drives players through the game flow: from menu to playing to game over and back.

Implement handleAdvance():

- If MENU, reset score/lives, call buildBricks(), resetRound(), updateHUD(), then set state to PLAYING.
- If PLAYING, call this.ball.launch().
- If GAME_OVER, set state back to MENU.
- Add the state guard at the top of update(): if (this.state !== STATE.PLAYING) return.
- Remove the manual this.ball.ballSpeedX/Y/isLaunched test values from the constructor — the state machine handles starting the ball now.
- Move buildBricks() call out of the constructor — handleAdvance() calls it when starting a game.
