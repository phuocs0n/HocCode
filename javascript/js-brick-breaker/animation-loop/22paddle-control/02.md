## Wire Up Input Listeners 🎧

Before the paddle can move, Game needs to listen for keyboard and mouse events and store their state. Also we need to render the paddle just like the ball in our screen.

In game.js, add this.paddle.draw(ctx) inside Game.update()

- Add this.keys = {} and this.paddle = new Paddle() to the Game constructor.
- Add a bindInputListeners() method with four listeners: keydown, keyup, canvas mousemove, and canvas click.
- In keydown, set this.keys[e.key] = true, set paddle control keyboard and call this.handleKeyPress(e.key).
- In keyup, set this.keys[e.key] = false.
- In mousemove, set this.paddle.mouseX = e.clientX - this.canvas.getBoundingClientRect().left.
- Add stub methods handleKeyPress(key) and handleAdvance() (empty for now). Call this.bindInputListeners() from the constructor.

- entities.js
- game.js
- index.html
- style.css

Note: handleKeyPress will later handle the spacebar to launch the ball. handleAdvance will handle click-to-continue between game states. Leave both empty for now.
