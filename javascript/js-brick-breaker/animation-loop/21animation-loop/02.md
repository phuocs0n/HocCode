## Add Ball Movement and the Game Loop 🔄

Time to make things move. We will add an update() method to Ball and wire up the full animation loop in Game.

By default, ballSpeedX and ballSpeedY are 0 and isLaunched is false — the ball starts stationary. To see movement right away, we will temporarily set these values directly in the Game constructor with these values below.

```javascriptDOM
this.ball.ballSpeedX = 3;
this.ball.ballSpeedY = -4;
this.ball.isLaunched = true;
```

We temporarily force the ball to launch so we can see movement. In a later step, we will remove these lines and let the player launch the ball with a spacebar or click.

In entities.js, add an update() method to Ball that adds ballSpeedX to this.x and ballSpeedY to this.y (only when isLaunched is true).

In game.js, bind this.loop to the instance in the constructor.

- Add an update() method that calls this.ball.update().
- Add a loop() method that calls update(), draw(), and schedules the next frame with requestAnimationFrame(this.loop).
- Add a start() method and call game.start() at the bottom.
