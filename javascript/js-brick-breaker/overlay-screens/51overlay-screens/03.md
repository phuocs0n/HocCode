# Show the Launch Hint 💬

## Show the Launch Hint 💬

Add a small text prompt that appears at the bottom of the canvas while the ball is waiting on the paddle.

In game.js, add a drawLaunchHint(ctx) method that draws "Click or Space to launch" centered at the bottom of the canvas.

- Set textAlign = "center", textBaseline = "middle", fillStyle = "#aaa", font = "14px Segoe UI".
- Draw the text at (CANVAS_WIDTH / 2, CANVAS_HEIGHT - 10).

In draw(), call this.drawLaunchHint(ctx) when this.state === STATE.PLAYING && !this.ball.isLaunched.
