# Show Win or Game Over 🎊

## Show Win or Game Over 🎊

Update the game over overlay to tell the player whether they won or lost.

In drawGameOverOverlay(ctx), add const win = this.bricks.every(b => !b.isAlive).

- Set ctx.fillStyle to "#5a8a5a" if won or "#c0392b" if lost.
- Call ctx.fillText(win ? "You Win!" : "Game Over", CANVAS_WIDTH / 2, 105).

In checkBrickCollisions(), add a win check after the for loop: if (this.bricks.every(b => !b.isAlive)) this.state = STATE.GAME_OVER.
