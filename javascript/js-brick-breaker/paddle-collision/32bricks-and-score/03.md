## Build the Brick Grid 🏗️

Time to add bricks. The Brick class goes in entities.js and a buildBricks() method populates the array in Game.

In entities.js, create a Brick class with a constructor(col, row) that calculates x, y, width, height, color, points, and sets isAlive = true.

- Add a draw(ctx) method that returns early if !isAlive, then draws a rounded rectangle with ctx.roundRect() using the brick's color.

In game.js, add this.bricks = [], this.score = 0, and this.lives = 3 to the constructor.

- Add a buildBricks() method that fills this.bricks with new Brick(c, r) for each column and row.
- Call buildBricks() from the constructor (temporary — the state machine will handle this in Chapter 4).
- Render bricks in draw() with this.bricks.forEach(b => b.draw(ctx)).
