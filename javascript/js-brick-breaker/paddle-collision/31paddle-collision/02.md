# Detect the Paddle Hit 🏓

## Detect the Paddle Hit 🏓

Time to make the ball bounce off the paddle. Start with a simple version — detect the overlap and reverse the vertical velocity.

In game.js, add a checkPaddleCollision() method to the Game class.

- Return early if ballSpeedY <= 0 (ball is moving up).
- Return early if the ball bottom is above the paddle top, below the paddle bottom, or the ball center is outside the paddle sides.
- Set this.ball.ballSpeedY = -Math.abs(this.ball.ballSpeedY) and reposition the ball just above the paddle.
- Call this.checkPaddleCollision() in Game.update() after this.ball.update().
