## Add Sound and Polish ✨

The game is playable. These additions make it feel alive.

Sound

The browser has a built-in audio synthesizer. No files required:

```javascriptDOM
function playBounce(freq = 440, duration = 0.05) {

  const ctx = new AudioContext();
  const osc = ctx.createOscillator();
  const gain = ctx.createGain();

  osc.frequency.value = freq;
  gain.gain.setValueAtTime(0.15, ctx.currentTime);
  gain.gain.exponentialRampToValueAtTime(0.001, ctx.currentTime + duration);

  osc.connect(gain);

  gain.connect(ctx.destination);

  osc.start();
  osc.stop(ctx.currentTime + duration);
}
```

Call it with different frequencies: playBounce(300) for paddle, playBounce(600) for bricks, playBounce(150) for wall.

Screen Shake

Store a shakeDuration counter on Game. At the start of draw(), apply a canvas transform offset:

```javascriptDOM
draw() {
  const ctx = this.ctx;

  if (this.shakeDuration > 0) {
    const dx = (Math.random() - 0.5) * 6;
    const dy = (Math.random() - 0.5) * 6;
    ctx.save();
    ctx.translate(dx, dy);

    this.shakeDuration--;
  }

  ctx.clearRect(...);

  // ...draw everything...
  if (this.shakeDuration >= 0) ctx.restore();
}
```

Ball Trail

Keep an array of the last N ball positions. Draw them as fading circles before drawing the main ball:

```javascriptDOM
this.trail.push({ x: this.ball.x, y: this.ball.y });

if (this.trail.length > 8) this.trail.shift();

this.trail.forEach((p, i) => {
  ctx.globalAlpha = (i / this.trail.length) * 0.3;
  ctx.beginPath();
  ctx.arc(p.x, p.y, BALL_RADIUS, 0, Math.PI * 2);
  ctx.fill();
});

ctx.globalAlpha = 1;
```
