## Variable hoisting

In JavaScript, the behavior of hoisting varies depending on whether a variable is declared using var, let, or const.

Hoisting with var

When we declare a variable using var, it is hoisted to the top of its current scope.

For example,

```javascript
1function printMessage(){
2    message = "Hello";
3    
4    // use the message variable before declaration
5    console.log(message); // Output: Hello
6    
7    // variable declaration using var keyword
8    var message;
9 
10}
11
12printMessage();
```

Here, the variable message is hoisted to the top of its current scope, i.e., printMessage function. Thus, the above program is equivalent to:

```javascript
1function printMessage(){
2    
3    var message;
4    message = "Hello";
5    console.log(message);
6
7}
8
9printMessage();
```
