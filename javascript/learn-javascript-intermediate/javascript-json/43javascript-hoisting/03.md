## Hoisting with var

```javascript
1function printMessage(){
2    
3    // use the message variable before declaration
4    console.log(message);
5    
6    // variable declaration using var keyword
7    var message;
8
9}
10
11printMessage(); // Output: undefined
12
```

In this example, the message variable is hoisted with a default value of undefined.

Thus, the above program is equivalent to:

```javascript
1function printMessage(){
2    
3    var message;
4    console.log(message);
5
6}
7
8printMessage();
```

You might be confused when you see undefined. It is the default value when declaring a variable using var.
