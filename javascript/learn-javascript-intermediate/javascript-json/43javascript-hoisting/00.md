## Introduction

So far, we have used let and const for variable definition.

Just like let and const, var is also a keyword used to declare a variable in JavaScript.

For example,

```javascript
1// variable definition
2 var age = 18;
3
4// variable usage
5console.log(age);  //  Output: 18
```

So how is it different from let and const?

A variable defined using let and const can be used only after we have defined it first.

This is not the same case for var.

Let's look at an example:

Example

```javascript
1function printAge(){
2    
3    // initialization of age variable 
4    age = 18; 
5    
6    console.log(age);
7
8    var age; 
9}
10
11printAge(); // Output: 18
12
```

Here, age is assigned a value first, and then declared as a variable. This is possible in JavaScript because of a feature called hoisting.

Due to this feature, although variable declarations are done later than their usage, when running the code, this part is moved to the top of its scope.

In the above code, hoisting moves the declaration var age; to the top of its scope, so the code behaves as if the variable was declared at the beginning.

However, the initialization age = 18; remains where it is declared. So, when console.log(age); is executed, age has already been assigned the value 18, resulting in the output 18.

For better understanding, here's how JavaScript interprets the code due to hoisting:

```javascript
1function printAge(){
2    // declaration is hoisted to the top of the scope
3    var age;
4    
5    // initialization happens at the original line
6    age = 18;
7    
8    console.log(age); // Output: 18
9}
10
11printAge();
```
