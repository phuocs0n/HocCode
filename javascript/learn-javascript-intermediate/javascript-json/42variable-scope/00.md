## Introduction

In JavaScript, scope refers to the current context of code. Variable scope determines where it can be accessed within the code.

Variables can be declared in different scopes:

- Global Scope
- Local (Function) Scope
- Block-Level Scope

Let's see an example.

```javascript
function getName() {
    var name = "John";
}
```

Here, the name variable is created inside the getName() function.

So, it's accessible only within that function. This type of variable is known as a local variable.
