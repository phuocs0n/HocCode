## Local Variables

Local variables are the variables declared inside a function. They have a local scope and are accessible only within that function.

For example,

```javascript
1function getName() {
2    // local variable
3    var name = "John";
4
5    console.log(`Local: ${name}`);
6}
7
8// function call
9getName();
10
11// outside the getName() function
12console.log(`Global: ${name}`);
```

Output

```text
Local: John
ERROR!console.log(`Global: ${name}`);
... ... ...
ReferenceError: name is not defined
```

Here, the name variable is local to the getName() function. So, it can only be accessed within that function.

That's why we get an error when we try to access it outside the getName() function.

To fix this issue, we can make the name variable global.
