## Breaking down JSON structure

Let's look at the JSON object we created in the previous page.

```javascript
let person = {
    "name": "Beyoncé",
    "age": 42,
    "gender": "female"
}
```

Important Notes About JSON:

1. Keys in JSON are written inside double quotes.
2. A colon (:) is used to separate keys from values.
3. String values are enclosed in double quotes, while numeric values are not.
