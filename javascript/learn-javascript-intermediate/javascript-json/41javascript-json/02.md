Quiz: Which of the following is the correct syntax of JSON?

Tap an option below to answer:

```javascript
{
    "name": "John";
    "age": 22;
    "gender": "male"
}
```

##### Incorrect, give it another shot!

The key-value pairs are separated by a comma , not a semi-colon ;.

The key-value pairs are separated by a comma , not a semi-colon ;.

```javascript
(
    "name": "John",
    "age": 22,
    "gender": "male"
)
```

##### Incorrect, give it another shot!

JSON objects are written inside curly braces.

JSON objects are written inside curly braces.

```javascript
{
    "name": "John",
    "age": 22,
    "gender": "male"
}
```

##### Correct Answer!

JSON objects are written inside curly braces { } and contain multiple key-value pairs separated by a comma ,.

JSON objects are written inside curly braces { } and contain multiple key-value pairs separated by a comma ,.

```javascript
{
    "name" : "John",
    "gender" : "male",
    "age" : findAge()
}
```

##### Incorrect, give it another shot!

JSON data cannot contain functions as values.

JSON data cannot contain functions as values.
