## Putting All Together

```javascript
1function fetchMovieData(url) {
2    return fetch(url)
3        .then(response => {
4            return response.json();
5        })
6        .catch(error => {
7            console.error("There was a problem with the fetch operation:");
8            // return null in case of an error
9            return null;
10        });
11}
12
13function getHighRatedMovies(movies) {
14    return movies
15        .filter(movie => movie.rating >= 9)
16        .map(movie => movie.name);
17}
18
19async function main() {
20    const URL = "https://api.programiz.pro/api/Demo/javascript/movies";
21    const movieData = await fetchMovieData(URL);
22
23    // log the fetched movie data
24    console.log(movieData);
25
26    console.log("\nMovies Rated 9 or above:")
27    const highRatedMovies = getHighRatedMovies(movieData["movies"]);
28    console.log(highRatedMovies);
29}
30
31main();
```

Output

```text
{
  movies: [

    { name: 'Interstellar', rating: 8.6 },
    { name: 'The Dark Knight', rating: 9 },
    { name: 'The Shawshank Redemption', rating: 9.3 }
  ]
}

Movies Rated 9 or above:
[ 'The Dark Knight', 'The Shawshank Redemption' ]
```

Here, we have declared an async function to fetch, display the movie data, and get high-rated movie names.
