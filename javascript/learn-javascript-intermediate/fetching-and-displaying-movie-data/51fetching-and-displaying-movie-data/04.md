## Step 3: Display the JSON Data

To display the JSON data, we will:

- Make the main function asynchronous using the async keyword.
- Ensure movieData waits for the JSON data using the await keyword.

```javascript
1function fetchMovieData(url) {
2    return fetch(url)
3        .then(response => {
4            return response.json();
5        })
6        .catch(error => {
7            console.error("There was a problem with the fetch operation:");
8            // return null in case of an error
9            return null;
10        });
11}
12
13async function main() {
14    const URL = "https://api.programiz.pro/api/Demo/javascript/movies";
15    const movieData = await fetchMovieData(URL);
16
17    // log the fetched movie data
18    console.log(movieData);
19}
20
21main();
```

If you run this code, you will finally see the movie data.

}
