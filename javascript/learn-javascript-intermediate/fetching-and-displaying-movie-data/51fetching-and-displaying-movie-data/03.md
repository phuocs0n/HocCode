## Step 2: Handle Response and Check for Errors

To receive the movie list from the Promise object, we need to handle the response by extracting the JSON from the object.

To handle any errors occurred in this fetch() process, we'll also add catch().

```javascript
1function fetchMovieData(url) {
2    return fetch(url)
3        .then(response => {
4            return response.json();
5        })
6        .catch(error => {
7            console.error("There was a problem with the fetch operation:");
8            // return null in case of an error
9            return null;
10        });
11}
12
13function main() {
14    const URL = "https://api.programiz.pro/api/Demo/javascript/movies";
15    const movieData = fetchMovieData(URL);
16
17    // log the fetched movie data
18    console.log(movieData);
19}
20
21main();
```

Here, if the request returns a response, the .then() method is executed. However, if the request returns an error, the .catch() method is executed.

If we run this code, we will still get Promise response rather than the JSON we created. This is because fetch() is an asynchronous process whereas console.log() is a synchronous process.

When we call console.log() it skips the part where we created JSON in .then() and executes the console.log() which makes it print the Promise object.
