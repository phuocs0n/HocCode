## Step 4: Get High-rated Movies

To filter movies based on their rating, we implement the getHighRatedMovies() function.

```javascript
// function to get high-rated movie names
function getHighRatedMovies(movies){
     return movies
        .filter(movie => movie.rating >= 9)
}
```

Let's understand how this function works.

This function takes data as an argument, which is JSON data containing the list of movie names and their ratings.

Here, we filter the array to include only movies with a rating of 9 or higher using filter method.
