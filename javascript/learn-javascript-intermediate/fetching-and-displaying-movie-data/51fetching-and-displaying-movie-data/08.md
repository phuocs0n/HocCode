## Add Error Handling

The above code is a complete code. However, while working with fetch(), the data might not necessarily be what you want. Therefore, it is important to add various error handling in our code.

Let's take a look at our code after adding error handling parts.

```javascript
1// function to fetch movie data from the given url
2function fetchMovieData(url) {
3    return fetch(url)
4        .then(response => {
5            return response.json();
6        })
7        .catch(error => {
8            throw new Error("there was a problem with the fetch operation: " );
9        });
10}
11
12// function to get names of high-rated movies (rating >= 9)
13function getHighRatedMovies(movies) {
14    // check if movies is an array
15    if (!Array.isArray(movies)) {
16        throw new Error("invalid data format: movies should be an array.");
17    }
18    return movies
19        .filter(movie => movie.rating >= 9)
20        .map(movie => movie.name);
21}
22
23// main function to fetch, display, and get high-rated movie names
24async function main() {
25    const URL = "https://api.programiz.pro/api/Demo/javascript/movies";
26    try {
27        const movieData = await fetchMovieData(URL);
28
29        // check if movieData is null
30        if (!movieData) {
31            throw new Error("failed to fetch movie data.");
32        }
33
34        // check if movieData.movies is valid
35        if (!Array.isArray(movieData.movies)) {
36            throw new Error("invalid movie data format.");
37        }
38
39        console.log(movieData);
40
41        console.log("\nmovies rated 9 or above:");
42        const highRatedMovies = getHighRatedMovies(movieData.movies);
43        console.log(highRatedMovies);
44    } catch (error) {
45        // log any errors that occur in the main function
46        console.error("An error occurred");
47    }
48}
49
50main();
```

We've used try block in the main function to handle any error that might occur during execution.

Any errors during the process are caught in catch block. We print an error message indicating where the error happened.

This is our final code for the project.
