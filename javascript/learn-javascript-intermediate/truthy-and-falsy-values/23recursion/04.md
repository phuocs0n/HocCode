#### Course: Learn JavaScript Intermediate

## Example: Infinite Recursion

```javascript
1function printVariable(n) {
2    console.log(n);
3
4    // call printVariable() with the next number
5    printVariable(n + 1);
6}
7
8printVariable(1);
```

Output

```text
1
2
3
...
```

Here, we have first called the printVariable() function with 1 as an argument.

Inside the first printVariable():

- 1 (value of n) is printed.
- printVariable() is called again with 2, n + 1, as an argument.

Inside the second printVariable():

- 2 (value of n) is printed.
- printVariable() is called again with 3 as an argument.

This process goes on and on.

Again, remember that each n inside the printVariable() functions are different.

### End Infinite Recursion

To prevent infinite recursion, if...else statement or similar approach should be used where the recursive call ends if a certain condition is met.
