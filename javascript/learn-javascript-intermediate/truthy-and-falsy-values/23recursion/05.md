## Example: Finite Recursion

In this example, we will create a program to find the sum of natural numbers using recursion.

```javascript
// sum of natural numbers n
total = 1 + 2 + ... + n
```

### Source Code

```javascript
1function calculateSum(n) {
2    if (n !== 0) {
3        // Recursive call
4        n = n + calculateSum(n - 1);
5    }
6    return n;
7}
8
9let result = calculateSum(3);
10console.log(result);
```

Output

```text
6
```

Here, the recursive function call is made only when n is not equal to 0. To meet this condition, we have decreased the value of n by 1 in each function call using calculateSum(n-1). When n becomes 0, the recursive calls end.
