## Recursion Introduction

As we know, we call functions to use them. It's also possible to call the function itself from inside its body.

A function that calls itself is known as a recursive function. And, this process is known as recursion.

Recursion is not native to JavaScript and is also available in other programming languages. However, we decided to put this topic here because it's harder to create programs involving recursion.

Since it's a harder topic, we will take a step by step approach to understand recursion.
