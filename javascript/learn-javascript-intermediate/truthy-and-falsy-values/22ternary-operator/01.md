## Working: Ternary Operator

This is our code from earlier example:

```javascript
1function getResult() {
2    let marks = 76;
3    let result = (marks >= 32) ? "Pass" : "Fail";
4
5    console.log("Result: " + result);
6}
7getResult();
```

Notice the code,

```javascript
let result = (marks >= 32) ? "Pass" : "Fail";
```

Here, (marks >= 32) is a test expression that results in either true or false. If the test expression is

- true - "Pass" (string before the colon :) is assigned to the result variable
- false - "Fail" (string after the colon :) is assigned to the result variable

From the example, we can deduce the syntax of ternary operator as:

```javascript
(test condition) ? expression1 : expression2;
```

Here, when the test condition is true, expression1 is executed and when the test condition is false, expression2 is executed.

You can see there are 3 operands here, hence the name ternary operator.
