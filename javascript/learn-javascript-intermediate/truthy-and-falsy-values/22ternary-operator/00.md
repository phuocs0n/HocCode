## Introduction to Ternary Operator

In JavaScript, we can use a ternary operator ? : as an alternative to an if...else statement. Let's see an example,

```javascript
1function getResult() {
2    let marks = 76;
3    let result;
4
5    if (marks >= 32) {
6        result = "Pass";
7    } else {
8        result = "Fail";
9    }
10
11    console.log("Result: " + result);
12}
13
14getResult();
```

Output

```text
Result: Pass
```

Here, we have used an if...else statement to check if a student passed the exam or not.

Now, let's implement this same program using a ternary operator.

```javascript
1function getResult() {
2    let marks = 76;
3    let result = (marks >= 32) ? "Pass" : "Fail";
4
5    console.log("Result: " + result);
6}
7
8getResult();
```

Output

```text
Result: Pass
```
