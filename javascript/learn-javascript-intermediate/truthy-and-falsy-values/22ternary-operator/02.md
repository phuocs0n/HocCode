## Check Odd/Even Using Ternary Operator

In this example, we will use a ternary operator to check if a value is odd or even.

```javascript
1let number = 5;
2// let number = 36;
3
4let result = (number % 2 === 0) ? "Even" : "Odd"; 
5console.log(number + " is " + result);
```

Sample Output 1

```text
5 is Odd
```

Sample Output 2

```text
36 is Even
```

Here, if the number is perfectly divisible by 2, "Even" is assigned to the result variable. Otherwise, "Odd" is assigned.
