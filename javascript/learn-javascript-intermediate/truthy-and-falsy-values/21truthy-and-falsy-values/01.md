## Falsy values

Falsy values are those that are treated as false in a Boolean context.

This means that if a falsy value is converted to its Boolean equivalent, it returns false.

For example,

```javascript
1if(0){
2    console.log("Truthy");
3}
4else{
5    console.log("Falsy");
6};
```

Output

```text
Falsy
```

In the code above, 0 is not a boolean, but because the value is falsy, the else block is executed.

There are only six falsy values in JavaScript:

- false - The boolean value false
- 0 - The number zero
- "" or '' or `` - An empty string
- null - Represents the intentional absence of any object value
- undefined - A variable that has been declared but has not yet been assigned a value.
- NaN - Stands for "Not-a-Number".
