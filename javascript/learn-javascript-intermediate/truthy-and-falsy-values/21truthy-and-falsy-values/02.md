## Truthy values

All values other than the six falsy values are considered truthy in JavaScript. Here are some examples:

1. true - The boolean value is true.
2. Non-zero numbers - e.g., 1, -1, 3.14, etc.
3. Non-empty strings - e.g., "hello", '0', "false", etc.
4. Arrays - e.g., [], [1, 2, 3], etc..
5. Objects - e.g., {}, { a: 1 }, etc..
6. Functions - e.g., function() {}, () => {}, etc..

For example,

```javascript
1if([]){
2    console.log("Truthy");
3}
4else{
5    console.log("Falsy");
6};
```

Output

```text
Truthy
```

Since [] is a truthy, the if block statement is printed.
