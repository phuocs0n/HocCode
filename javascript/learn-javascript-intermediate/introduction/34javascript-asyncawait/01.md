## async/await

An async function is a function that returns a Promise.

Inside an async function, you can write asynchronous code that looks and behaves like synchronous code, making it easier to read and maintain.

Creating an async Function

To create an async function, simply add the async keyword before the function declaration.

```javascript
async function fetchData() {
  // code to fetch data
}
```

Inside an async function, you can use the await keyword to pause the process of the function until that Promise is resolved.

```javascript
1async function myAsync() {
2  let data = await fetch('https://api.programiz.pro/api/Demo/javascript/movies');
3  let text = await data.text();
4
5  console.log(text);
6};
7
8myAsync();
```

Return of async Function

async function returns a Promise. For example,

```javascript
1async function myAsync() {
2  let data = await fetch('https://api.programiz.pro/api/Demo/javascript/movies');
3  let text = await data.text();
4
5 return text;
6}
7
8console.log(myAsync()) // Output: Promise { <pending> }
9
10myAsync().then((data) => console.log(data))
```

In this code, the async keyword is used to define an asynchronous function. await is used to pause the execution of the myAsync function until the fetch promise is resolved.

This means, you can handle the return of an async function like Promise. We learned about it in the previous lesson.
