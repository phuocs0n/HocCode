## Asynchronous Nature of fetch()

When we fetch some data from a server, it takes some time for the server to respond back.

This creates an unwanted delay because the next operation in our code cannot be executed until fetch() has completed.

So instead of idle-waiting and blocking the execution of the rest of our code, JavaScript handles fetch() asynchronously: it executes the next code, and when the response from fetch() is back, it comes back to this task.
