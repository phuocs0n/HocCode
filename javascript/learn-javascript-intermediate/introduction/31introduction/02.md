## setTimeout()

Let's look at a JavaScript function called setTimeout().

The setTimeout() function lets you run a piece of code after a certain delay. You tell it what to do and how long to wait before doing it.

The syntax of the setTimeout() function is:

```javascript
setTimeout(function, milliseconds);
```

Here,

function: The code you want to run.

milliseconds: The delay before the code runs.

Let's see this in action.

```javascript
1setTimeout(function() {
2console.log("Task: Water the plants (delayed by 2 seconds).");
3}, 2000);
```

In this example, the message will appear after 2 seconds.

Let's use it with other functions.

```javascript
1console.log("Task: Sweep the floor");
2setTimeout(() => console.log("Task: Water the plants (delayed by 2 seconds)."), 2000);
3console.log("Task: Feed the cat");
```

In this case, Task: Sweep the floor is printed first, then Task: Feed the cat is printed, and finally, the delayed task is printed after 2 seconds.
