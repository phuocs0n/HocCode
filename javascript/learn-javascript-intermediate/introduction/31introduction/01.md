## Asynchronous JavaScript

Previously, we discussed how JavaScript handles idle-waiting tasks by running them asynchronously.

Most operations, like console.log(), are quick and do not block the execution of other tasks, so they are executed synchronously.

However, some tasks, such as those requiring a delay or waiting for a server response, block other operations from execution without much benefit. That's why they are handled asynchronously, allowing JavaScript to continue running other code.

For example, suppose we made a request to a server and had to wait synchronously for its response. Until the response comes back, the entire webpage would freeze and be unresponsive to any user interactions.

This is an undesirable scenario caused by synchronous execution. To handle such scenarios, JavaScript uses asynchronous execution. We'll explore how it does this further in this chapter.

Delays are one example of the codes that are handled asynchronously in JavaScript. There are two ways to add delays:

- setTimeout()
- setInterval()
