## Asynchronous JavaScript

In JavaScript, the code usually runs one line after the other. It waits for each step to finish before starting the next one. This is called synchronous execution.

However, for tasks that require idle waiting, JavaScript runs them asynchronously. This means JavaScript doesn't wait for these tasks to finish. Instead, it moves on to the next operations. Once the other tasks are done, it returns back to the previous one.

Let's understand this asynchronous nature with a real life example. Suppose you have some tasks to do:

1. Bake a cake
2. Clean the kitchen
3. Set the table

In a synchronous approach, you will perform each task one after another. You would first bake the cake. After the baking is complete, you'd clean the kitchen, and finally, set the table.

But baking the cake requires waiting.

Instead of waiting, you can clean the kitchen and set the table while the cake bakes in the oven.

This way, you use your time more efficiently. Once the cake is done, everything else is already taken care of.

Here, rather than waiting for each task to finish before starting the next, you begin the next task while the previous one is still running.

This is exactly how time-consuming tasks are handled in JavaScript, using asynchronous programming.
