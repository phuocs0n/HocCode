## Why JavaScript Promises

For example, consider a function getUsers() that returns a list of user objects:

```javascript
function getUsers() {
  return [
    { username: 'john', email: 'john@test.com' },
    { username: 'jane', email: 'jane@test.com' },
  ];
}
```

To find a user from the list returned by the getUsers() function, you can use the findUser() function as follows:

```javascript
1function getUsers() {
2  return [
3    { username: 'john', email: 'john@test.com' },
4    { username: 'jane', email: 'jane@test.com' },
5  ];
6}
7function findUser(username) {
8  const users = getUsers();
9  const user = users.find((user) => user.username === username);
10  return user;
11}
12
13console.log(findUser('john'));
```

Output

```text
{ username: 'john', email: 'john@test.com' }
```

However, in practice, the getUsers() function may access a database or call an API to get the user list. This introducing a delay when accessing data in real life.

For now, to simulate the delay, you can use the setTimeout() function:

```javascript
1function getUsers() {
2  let users = [];
3
4  setTimeout(() => {
5    users = [
6      { username: 'john', email: 'john@test.com' },
7      { username: 'jane', email: 'jane@test.com' },
8    ];
9  }, 1000);
10
11  return users;
12}
13function findUser(username) {
14  const users = getUsers();
15  const user = users.find((user) => user.username === username);
16  return user;
17}
18
19console.log(findUser('john'));
```

Output

```text
undefined
```

The getUsers() function won't work properly and always returns an empty array. To handle this, we can use Promises.
