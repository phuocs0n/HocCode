## Creating a Promise

To create a Promise, we use the new Promise() built-in object. You pass in a function with two parameters: resolve and reject.

Let's see the syntax to understand in,

```javascript
let promise = new Promise(function(resolve, reject) {
     // Write your code here  
});
```

Here,

- resolve(value) — If the job is finished successfully, with result value.
- reject(error) — If an error occurred, with error error.

Let's create a promise:

```javascript
1let myPromise = new Promise(function(resolve, reject) {
2    // change this to false to see the rejection    
3    let isPizzaAvailable = true;
4    if (isPizzaAvailable) {
5        // resolves the promise
6        resolve("Pizza is ready!");
7    } else {
8        // rejects the promise
9        reject("No pizza dough left!");
10    }
11});
```
