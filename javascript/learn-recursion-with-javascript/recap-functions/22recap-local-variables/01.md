## Introduction

The concept of local variables is critical in recursion since each recursive call possesses a separate local variable. Thus, we must revisit this topic here.

### Local Variables

Any variable that is created inside a function is local to it. For example,

```javascript
1function addNumbers(n1, n2) {
2    let result = n1 + n2;
3}
4
5// Call the function
6addNumbers(2, 5);
7
8// Error code
9// Attempt to print result variable
10console.log(result);
```

Here, n1, n2, and result are local variables that are defined within the scope of addNumbers(). When the execution of addNumbers() ends, all of these variables are destroyed.

As a result, the above program throws an error.

It's because the result variable is defined within addNumbers(), and we are trying to access it from the global scope. In other words, the result variable is local to addNumbers() and doesn't exist outside it.

Thus, we can only access a local variable indirectly by returning its value.
