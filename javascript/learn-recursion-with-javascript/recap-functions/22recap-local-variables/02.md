## Local Variables

Now, let's see how we can use the value returned by the function.

```javascript
1// Function that returns an integer value
2function addNumbers(n1, n2) {
3    let result = n1 + n2;
4    return result;
5}
6
7// Call the function and store the returned value
8let output = addNumbers(2, 5);
9console.log(output);
10
11// Output: 7
```

Here, we did not directly use the local variable. Instead, we returned the value to the function call and used the returned value by storing it in a variable.

Let's now see why this concept of local variables is important.
