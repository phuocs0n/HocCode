## Infinite Recursion With Changing Arguments

Here's a slight modification to the program we previously wrote:

```javascript
1function printNumbers(n) {
2
3    console.log(n);
4
5    // Argument is decreased by 1 in each recursive call
6    if (n > 0) {
7        printNumbers(n - 1);
8    }
9}
10
11printNumbers(100);
```

Output

```text
100
99
98
97
96
...
```

Here, we have initially called the printNumbers() function with 100 as an argument. The function prints the value and calls itself recursively with n - 1 (which is 99) as the argument.

Now, let's look at what happens during each recursive call.

1. First Recursive Call

- n is 99, which is printed.
- printNumbers(98) is called.

2. Second Recursive Call

- n is 98, which is printed.
- printNumbers(97) is called.

Essentially, the value of the argument is reduced by one in each subsequent function call.
