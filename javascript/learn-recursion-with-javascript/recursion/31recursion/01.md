## Infinite Recursion With Arguments

Here is an example of infinite recursion with arguments.

```javascript
1function printNumbers(n) {
2
3    console.log(n);
4
5    // Recursive call
6    printNumbers(n);
7}
8
9// Initial function call
10printNumbers(100);
```

Output

```text
100
100
100
100
...
```

Here, we have called the printNumbers() function with 100 as an argument. The function prints the value and calls itself recursively with the same value n as argument.

Now, let's look at what happens during each recursive call.

1. First Recursive Call

- n is 100, which is printed.
- The printNumbers() function is called again with n (100) as an argument.

2. Second Recursive Call

- n is 100 again, which is printed.
- The printNumbers() function is called again with n (100) as an argument.

Essentially, this program will run continuously with 100 as an argument in each function call.
