## Base Case for Recursion

Consider the following program to print numbers:

```javascript
1function printNumbers(n) {
2    console.log(n);
3    printNumbers(n + 1);
4}
5
6printNumbers(1);
```

Output

```text
1
2
3
...
```

This program displays numbers infinitely because it lacks a stopping condition.

Now, let's add a base case so that the program ends after displaying 2.

```javascript
1function printNumbers(n) {
2    // Base case to terminate recursion
3    if (n === 3) {
4        return;
5    }
6
7    // Execute code if base case is not met
8    console.log(n);
9
10    // Recursive call with increment
11    printNumbers(n + 1);
12}
13
14printNumbers(1);
```

Output

```text
1
2
```

In this program, we have added the following base case:

```javascript
if (n === 3) {
    return;
}
```

If n is equal to 3, the function encounters the return statement, and the recursive call ends.
