## Organizing Your Code 📂

Let's reorganize your JavaScript file to make it easier to read and understand.

Right now, your code is mixed together—functions, variables, and event listeners are scattered throughout. You'll group related code together in logical sections.

How professional developers organize code:

1. Variables at the top (game state)
2. Functions in the middle (what the code does)
3. Event listeners next (what responds to user actions)
4. Initialization at the bottom (what runs when the page loads)

You'll add comment headers to separate these sections clearly.

In script.js,

- Reorganize the entire code into four clear sections with comment headers.
- Group all variables at the top under "Game State Variables", all functions in the middle under "Functions", event listeners under "Event Listeners", and the game board initialization at the bottom under "Initialize Game Board".
