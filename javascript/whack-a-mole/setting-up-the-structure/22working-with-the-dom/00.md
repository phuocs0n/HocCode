## What is the DOM? 🌳

Great work on setting up the HTML structure! Now it's time to make your game come alive with JavaScript.

But before you start writing code, you need to understand one crucial concept: the DOM (Document Object Model).

Think of the DOM as a bridge between your HTML and JavaScript:

- Your HTML creates elements (divs, buttons, text)
- The DOM turns those elements into objects JavaScript can work with
- The browser builds a tree structure from your HTML. JavaScript can climb that tree, find branches, and add new ones.

For example, when you write <div id="game-board"></div> in HTML, the DOM lets JavaScript say "find that div and add stuff to it."

In this lesson, you'll learn three essential DOM skills:

- Find elements on the page
- Create new elements
- Add elements to the page

These three skills are the foundation of making interactive websites. Let's practice with your game board!
