## A Quick Look at Functions 🔧

Before you dive into DOM manipulation, let's quickly review JavaScript functions—you'll use them constantly while building your game.

A function is a reusable block of code that performs a specific task. Think of it like a recipe: write the steps once, then use them whenever you need.

For example, here's a simple function that greets a player:

```javascriptDOM
function greetPlayer(name) {
    console.log('Welcome to the game, ' + name + '!');
}

greetPlayer('Alex');
```

Output

```text
Welcome to the game, Alex!
```

In the code above, greetPlayer is the function name, name is a parameter (input), and the code inside the curly braces runs when you call the function.

Why functions matter for your game:

- You'll wrap your code in functions to keep it organized
- Functions let you reuse logic (like creating holes or checking scores)
- They make debugging easier—if something breaks, you know which function to check

In this project, we'll keep all game code inside a main() function.

Think of main() as the game's "start button" in code: when you call it, your game setup runs.
