## Create the HTML File 📄

Now it's time to write some code.

You'll create an HTML file with a basic document structure and three empty div elements to represent the screens.

These divs are just containers. Think of them as empty rooms in a house. Later, you will fill them with content.

- Create a new file named index.html in your File Explorer.
- Add the HTML5 document structure with <!DOCTYPE html>, <html>, <head>, and <body> tags.
- Inside the <body>, add three <div> elements with IDs: start-screen, play-screen, and end-screen.
- Inside the play-screen div, add another div with an id game-board
