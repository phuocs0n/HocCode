## The Three Screens 🎮

Before you start coding, let's visualize what you're building.

Your Whack-a-Mole game has three main parts:

Start Screen: This is the first thing the player sees. It welcomes them and includes a Start Game button.

Play Screen: This is where the game runs. It holds the holes, the moles, the score counter, and the timer.

End Screen: This screen shows the final score and gives the player a way to play again (and optionally exit).

The flow is simple: Start → Play → End.

Right now, you'll only create empty containers for these screens. They won't look like much yet, and that's expected. Right now, you're focused on structure.
