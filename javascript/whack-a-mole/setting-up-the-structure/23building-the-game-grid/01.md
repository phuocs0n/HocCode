## Create 9 Holes with a Loop 🔄

Time to level up your code! Instead of creating one hole, you'll create 9 using a for loop.

A loop repeats code multiple times. You'll tell it: "Do this 9 times"—and it will create 9 holes for you.

- In script.js remove your previous hole creation code (the part where you created a const hole and added it to the board).
- Write a for loop that runs 9 times (from i = 0 to i < 9).
- Inside the loop, create a div, add the class hole, and append it to the game board—just like you did before, but now it happens 9 times!
