## Planning the Layout 📐

Awesome progress. You created one hole with JavaScript, but Whack a Mole needs 9 holes in a 3 by 3 grid.

You could copy-paste your code 9 times... but that's exactly what developers try to avoid. Repetitive code is hard to maintain and easy to mess up.

Instead, you'll use a loop to create all 9 holes with just a few lines of code. This is what makes programming powerful—write once, repeat many times.

Here's the plan:

- Use a loop to create 9 holes
- Add each hole to the game board as it's created
- Style the holes with CSS to look like a real game board
- Arrange them in a 3x3 grid

By the end of this lesson, you'll have a complete game board that looks like the real thing!
