## Race Against Time! ⏰

Great job getting the game to start properly! But right now, it goes on forever. That's not very exciting—players need a challenge!

In this lesson, you'll add a countdown timer that gives players exactly 30 seconds to score as many points as possible.

By the end of this lesson:

- A timer will count down from 30 seconds
- The timer will display on screen
- Players will see exactly how much time they have left
- When the timer hits zero, the game will end (you'll finish that in the next lesson)

Let's add that time pressure!
