# Create Timer Variable ⏰

## Create Timer Variable ⏰

First, you need a variable to store how much time is left, and a place on screen to show it.

You'll add a timer display to the play screen, then create a variable in JavaScript to track the seconds remaining.

In index.html,

- Add a timer display to the #play-screen div after the score-display.
- Create a div with id "timer-display" containing "Time: " and a span with id "timer-value" showing 30.

In script.js,

- After the moleInterval variable, create variables: timeLeft set to 30, timerInterval (uninitialized), and timerDisplay that selects the #timer-value element.
