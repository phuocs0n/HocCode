## Planning the Countdown ⏳

Before you code, let's think about how a countdown timer works.

What you need:

1. A variable to store the remaining time (starts at 30)
2. A place on screen to display the time
3. Code that runs every second to:
		Decrease the time by 1Update the displayCheck if time reached zero
4. Decrease the time by 1
5. Update the display
6. Check if time reached zero

- Decrease the time by 1
- Update the display
- Check if time reached zero

How setInterval helps: Remember setInterval from spawning moles? You'll use it again here! But instead of spawning moles, it will decrease the timer every second (1000 milliseconds).

Think of it like a countdown on your phone—every second, the number gets smaller until it reaches zero.
