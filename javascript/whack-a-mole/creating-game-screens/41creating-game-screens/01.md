## Planning Three Screens 📺

Before you code, let's think about what screens your game needs and what goes on each one.

1. Start Screen (what players see first)

- Game title
- Instructions
- "Start Game" button

2. Play Screen (where the game happens)

- Game board with holes and moles
- Score display
- Timer countdown

3. End Screen (when time runs out)

- "Game Over" message
- Final score
- "Play Again" button

How screen switching works: You'll show one screen at a time by adding and removing CSS classes. When you want to show the play screen, you'll hide the start screen and show the play screen. It's like flipping between pages in a book—only one is visible at a time.

Right now, all three screen divs exist in your HTML, but they're empty. Let's fill them with content!
