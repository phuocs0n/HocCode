## From Mechanics to Structure! 🎮

You've accomplished something major—you built a fully playable game with working mechanics.

But right now, your game starts immediately when the page loads and never ends. That's not how real games work! Real games have:

- A start screen where you press "Play"
- The actual game
- An end screen showing your final score

This chapter is all about adding game flow—the structure that makes your game feel complete and professional.

By the end of this chapter, you'll have:

- Three screens that switch between each other
- A countdown timer that ends the game
- A proper game loop (start → play → end → restart)
- A polished, complete experience

Let's start by creating the three screens your game needs!
