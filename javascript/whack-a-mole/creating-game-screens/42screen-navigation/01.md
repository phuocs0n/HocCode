## Understanding Screen Switching 🔄

Before you code, let's understand how screen switching works.

The concept: You have three screens, but only one should be visible at a time. To switch screens, you:

1. Add the hidden class to the current screen (hide it)
2. Remove the hidden class from the new screen (show it)

Why this works: Remember, the hidden class sets display: none, which completely hides an element. When you remove that class, the element becomes visible again.

Think of it like a slideshow: you're just showing one slide at a time by hiding the others.

You'll write a function that handles this screen switching automatically!
