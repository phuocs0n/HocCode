## Write showScreen Function 🎬

Time to create a function that switches between screens!

This function will take a screen name as input, hide all screens, then show only the one you specified.

How this function works: The trick is simple:

1. First, hide ALL screens (add hidden class to everything)
2. Then, show ONLY the screen you want (remove hidden from that one)

This ensures only one screen is ever visible at a time, no matter which screen was showing before.

In script.js,

- Create a function called showScreen that accepts a screenName parameter.
- The function should select all three screen elements (start-screen, play-screen, end-screen), add the "hidden" class to all of them.
- Then use if statements to remove the "hidden" class from the screen matching the screenName parameter.
