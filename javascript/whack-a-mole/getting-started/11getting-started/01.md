# What You'll Learn 🚀

#### Course: Whack A Mole

## What You'll Learn 🚀

This project focuses on the skills that power most interactive websites and games.

You will learn how to:

- Build and update the game board using the DOM.
- Control the game flow with scoring, timers, and random mole spawns.
- Respond to player actions using click events.
- Debug issues as they come up and keep your code readable as the project grows.

These are the same building blocks you will reuse in many real web projects.
