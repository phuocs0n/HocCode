#### Course: Whack A Mole

## Ideas to Expand 🚀

Want to keep building? Here are some features you could add:

Add Difficulty Levels: Let players choose Easy, Medium, or Hard. Each level changes how fast moles appear and how long they stay visible.

Add Sound Effects: Play sounds when moles pop up, get hit, or when the game ends. Use HTML5 Audio: new Audio('hit.mp3').play()

Add High Score System: Save the best score using localStorage so it persists even after refreshing the page.

Add Multiple Moles: Make 2-3 moles appear at once for more chaos and challenge.

Add Combo Multiplier: Award bonus points for hitting multiple moles in a row quickly. Track time between hits with Date.now().

Try Your Own Ideas:

- Different themes (zombies, cookies, fruits)
- Power-ups (golden moles with special effects)
- Progressive difficulty (gets harder over time)
- Leaderboard or achievements

Remember: Start small, test often, and have fun experimenting!
