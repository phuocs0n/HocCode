## Understanding Random Selection 🎲

Before you code, let's understand how to make random things happen in JavaScript.

The problem: You have 9 holes (numbered 0 through 8 in your array). You need to pick one at random—different every time.

The solution: JavaScript has a built-in tool called Math.random() that picks a random decimal number between 0 and 1 (like 0.742 or 0.193).

Here's how you turn that into a random hole number from 0 to 8:

const randomIndex = Math.floor(Math.random() * 9);

Breaking it down step by step:

1. Math.random() gives you a decimal like 0.742
2. Multiply by 9 to get a number between 0 and 9: 0.742 × 9 = 6.678
3. Math.floor() rounds down to remove decimals: 6.678 becomes 6
4. Result: you get a whole number from 0 to 8 (perfect for picking a hole!)

Think of it like rolling a 9-sided die—you get a different number each time.

You'll use this pattern to pick a random hole.
