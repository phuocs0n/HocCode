## Pick a Random Hole 🎰

Time to write a function that picks a random hole from your array of holes!

First, you'll remove the testing code that hardcodes the first hole. Then you'll write a function that returns a random hole.

In script.js,

- Remove the lines that add the "active" class to holes[0].
- Then create a function called getRandomHole that uses Math.random() to select and return a random hole from the holes array.
