## Create a Mole Element 🏗️

Time to create your first mole! You'll add a mole div inside each hole using JavaScript.

For now, you'll just create moles for all 9 holes and make them visible so you can see what you're building.

In script.js,

- modify the for loop that creates holes.
- Inside the loop, after creating each hole, create a div element for the mole, add the class "mole" to it, and append the mole to the hole before appending the hole to the game board.
