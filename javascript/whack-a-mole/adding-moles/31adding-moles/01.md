## Planning Mole Behavior 🎯

Before you start coding, let's think about how moles should work in your game.

What a mole needs to do:

- Hide below the hole when not active
- Pop up when it's time to appear
- Disappear after a short time
- Look like a mole (with an image or color)

How you'll make this happen: You'll create a mole element inside each hole, position it below the hole with CSS, and use a CSS class to make it pop up when needed.

Think of it like a jack-in-the-box: the mole is always there, just hidden below. When you add the active class, it springs up!

Right now, you'll just focus on creating and styling one mole. Once that works, you'll add moles to all 9 holes.
