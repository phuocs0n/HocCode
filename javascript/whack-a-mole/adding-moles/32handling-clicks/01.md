## Understanding Events ⚡

Before you start coding, let's understand how games know when you click something.

What are events? Events are things that happen in the browser—clicks, key presses, mouse movements, etc. JavaScript lets you "listen" for these events and respond to them.

Think of it like a doorbell: when someone presses it (the event), you know to go answer the door (your response).

How you'll use events: You'll add an event listener to each mole that listens specifically for clicks. When a player clicks a mole, JavaScript will:

1. Detect the click
2. Find out which mole was clicked
3. Run your code to respond (remove the active class)

This pattern—listen for an event, then respond—is how all interactive websites work.
