## Planning Score System 📊

Before you code, let's think about how score tracking works in games.

What you need:

1. A variable to store the current score (starts at 0)
2. A display on the screen to show the score to the player
3. Logic that increases the score when a mole is clicked
4. Update code that changes the display when the score changes

How it flows:

1. Player clicks a mole
2. Your code increases the score variable by 1
3. Your code updates the screen to show the new score
4. The player sees their progress!

This is a common pattern in game development—store data in variables, respond to events, update the display.
