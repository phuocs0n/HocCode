## Ask user input

We get input from the player with a prompt("message").

In the console, the player types their answer at the prompt and presses Enter; prompt returns what they typed as a string.

We store it in a variable and use it in our conditions:

```javascript
1var userAnswer = prompt("Enter A, B, or C: ");
2
3if (userAnswer) {
4  userAnswer = userAnswer.trim().toUpperCase();
5}
6
7var correctAnswer = "A";
8var score = 0;
9
10if (userAnswer === correctAnswer) {
11  score = 1;
12  console.log("Correct!");
13} else {
14  console.log("Wrong.");
15}
16
17console.log("Score: " + score);
```

Here we ask once, store in userAnswer, trim and uppercase so "a" becomes "A", then use the same if/else pattern from earlier.
