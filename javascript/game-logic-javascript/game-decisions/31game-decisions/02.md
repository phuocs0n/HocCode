## Decide with if

We use if to check a condition.

If the condition is true, JavaScript runs the code inside the { } block.

```javascript
1var passMark = 40;
2var percentage = 60;
3
4if (percentage >= passMark) {
5  console.log("You passed!");
6}
```

Here, percentage >= passMark is the condition. When it's true, the message prints. When it's false, nothing happens.

#### Developer Mindset

When I write game logic, I try to make the condition read like the rule. percentage >= passMark is basically saying: did they reach the pass mark?

Clear variable names help too. When I come back later (or someone else reads it), it's obvious what the code is checking, and debugging becomes much easier.
