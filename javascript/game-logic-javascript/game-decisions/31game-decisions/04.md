## If/Else in Our Game

Now we'll use if and else the way our quiz game needs them: to decide whether the player passed or failed.

```javascript
1var passMark = 40;
2var passMessage = "You passed! Well done.";
3var failMessage = "You didn't reach the pass mark. Try again.";
4
5var score = 3;
6var total = 5;
7var percentage = (score / total) * 100;
8
9if (percentage >= passMark) {
10  console.log(passMessage);
11} else {
12  console.log(failMessage);
13}
```

Here, percentage >= passMark is the condition.

- If it's true, we print the pass message.
- If it's false, we print the fail message.

This is one of the main decisions in our game. Later, we'll calculate score and percentage from real answers — but the decision logic stays the same.
