## Adding else

But a game usually can't stay silent when the condition is false. We also need to handle what happens when the condition is not true. That's where else comes in.

```javascript
1var passMark = 40;
2var percentage = 30;
3
4if (percentage >= passMark) {
5  console.log("You passed!");
6} else {
7  console.log("You failed!");
8}
```

Now the program always prints one message:

- if the condition is true → it runs the if block
- if the condition is false → it runs the else block
