## How to decide

In JavaScript we make those decisions with if and else. We check a condition, and based on whether it's true or false, the game runs different code.

No loops or lists yet - just one decision at a time, using the variables we already have: score, total, passMark, passMessage, and failMessage.

#### Developer Mindset

When you build a game, treat every rule like a simple check.

- Pass or fail becomes: is the score high enough?
- Correct or wrong becomes: does the input match the answer?

Thinking this way helps you turn game rules into clear if/else logic without losing track of the design.
