## Track progress

In the quiz, we need to track two things:

- how many questions the player got right (score)
- how many questions there are in total (total)

We declare them, set their values, and use them when we show the result:

```javascript
1var score = 3;
2var total = 5;
3
4console.log("Your score is " + score + "/" + total);
```

We're not using a loop or a list of questions yet - we're just storing two numbers and printing them. Later the game will fill the score and total based on real answers.

For now, notice the pattern: progress in a game is usually just numbers stored in variables.
