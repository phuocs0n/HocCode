#### Course: Game Logic with JavaScript

## Pass fail variable

The quiz has fixed rules: a pass mark (40) and two messages - one for pass, one for fail.

We put these at the top of the game so the rules are easy to see and easy to change:

```javascript
1var passMark = 40;
2var passMessage = "You passed! Well done.";
3var failMessage = "You didn't reach the pass mark. Try again.";
4
5console.log("Pass mark: " + passMark);
6console.log("If you pass: " + passMessage);
7console.log("If you fail: " + failMessage);
```

We're not deciding pass or fail here yet — we'll need conditionals for that. Right now we're just storing the rules so we can use them later.

#### Developer Mindset

I keep game rules like the pass mark and messages at the top, in variables, so they're easy to see and easy to change.

That way the rest of the code uses passMark, passMessage, and failMessage instead of hard-coded numbers or strings scattered everywhere. If the pass mark or the wording changes later, I update it in one place.
