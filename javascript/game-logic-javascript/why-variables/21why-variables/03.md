## Resetting variable

A variable can hold a new value later. We say we reset or reassign it.

In the quiz, we start the score at 0, then add points when the player gets a question right.

```javascript
1var score = 0;
2console.log("Score: " + score);
3score = 1;
4console.log("Score: " + score);
5score = 2;
6console.log("Score: " + score)
```

The same variable score is used three times with different values. Later we'll update it automatically using a loop. For now, the key idea is simple: variables can change, and that's how games track progress.

#### Developer Mindset

Values like score change over time. That's how we track progress in the game.

So I always make sure they're updated in the right place. If I forget to increase the score when the player is correct, the game result is wrong. If I increase it in the wrong branch, the logic breaks.

That's why I think: Where should this value change?

In a loop, it usually means inside the loop, in the branch where the condition is met.
