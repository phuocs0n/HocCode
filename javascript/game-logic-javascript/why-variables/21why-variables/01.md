## Introduction

Our quiz game needs to remember things:

- the pass mark (40)
- the messages for pass and fail
- the player's score.

We could type those values everywhere we need them, but that would be messy and hard to change.

A variable is a named place in memory where we store a value so we can use it again.

In the quiz we'll use variables like passMark, passMessage, failMessage, and score. Every example in this chapter uses these same names so you see exactly how they fit into the game.
