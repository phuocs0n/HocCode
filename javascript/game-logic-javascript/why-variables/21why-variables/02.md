## First Variable

We create a variable with var, then the name, then =, then the value.

For the quiz, we need a pass mark. We store it once and use it whenever we need it:

```javascript
1var passMark = 40;
2console.log("The passing mark is " + passMark);
```

Here, passMark holds the number 40. We use it inside console.log() so the player sees the rule.
