#### Course: Game Logic with JavaScript

## What you'll build

By the end of this course, you'll build a mini quiz that:

- asks multiple-choice questions
- keeps track of score
- decides pass or fail
- allows replay or quit

It runs in the console, but it behaves like a real game. Every line of code you write will move you closer to that goal.

For now, just click on the Run Code button. You can see what the final code looks like. Don't worry about understanding it yet - we'll build up to it piece by piece.

```javascript
1// Ask each quiz question one by one and check the user's answer
2// Keep track of the score and remember which questions were wrong
3// At the end, decide pass or fail and ask if the user wants to replay
```

You'll understand each part by the end. Let's get there together.
