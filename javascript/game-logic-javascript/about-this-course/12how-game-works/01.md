# Your first tool

#### Course: Game Logic with JavaScript

## Your first tool

The first tool we use is the console. In the browser (or in Node), the console is where your program can print messages.

For a quiz, we'll use it to show questions, options, and results. The function that prints text to the console is console.log(). Try this:

```javascript
1console.log("Welcome to the Quiz Game");
2console.log("You will be asked 5 questions");
```

Here, each console.log() sends one line to the console. That's our main way to communicate with the player until we add fancier UI later.

#### Developer Mindset

As a developer, I use console.log for every message the player must see so there's one clear rule: no guessing where output comes from.

When I come back to the code later, I know that anything the player sees went through console.log().
