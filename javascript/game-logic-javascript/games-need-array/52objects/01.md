## Group related data (first object)

We create an object with curly braces. Inside we write property names and values separated by colons, and properties separated by commas. We read a property with dot notation: objectName.propertyName.

```javascript
1var q = {
2  question: "Which of these is a programming language?",
3  options: ["A: Python", "B: Pizza", "C: Pencil"],
4  answer: "A"
5};
6
7console.log(q.question);
8console.log(q.answer);
9console.log(q.options[0]);
```

Here, q is one question object.

- q.question is the text
- q.answer is the correct choice
- q.options is the array of option strings.

We use q.options[0] to get the first option.

#### Developer Mindset

I use one object per question so everything stays together: the text, the options, and the answer.

That way q.question, q.options, q.answer always belong to the same question. It's easier to read, harder to mess up, and adding a new question means adding one object, not updating multiple places.
