# Why objects

#### Course: Game Logic with JavaScript

## Why objects

Each question in the quiz has several related pieces:

- the question text
- the list of options
- the correct answer

We could store these in separate variables, but then we'd end up with question1Text, question1Options, question1Answer, and so on for every question.

An object groups related data under one name. One question becomes one object with properties like question, options, answer.

We'll put those objects inside the questions array so we have a list of question objects.
