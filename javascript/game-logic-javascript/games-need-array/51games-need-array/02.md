## Using array with loops

We combine the array with a while loop: run while the counter is less than the array's length, and use the counter as the index to get each item.

```javascript
1var options = ["A: Python", "B: Pizza", "C: Pencil"];
2var i = 0;
3
4while (i < options.length) {
5  console.log(options[i]);
6  i++;
7}
```

The condition i < options.length means we stop when we've reached the end of the array. Each time we use options[i] to get the current item.

In the quiz we'll do the same with questions.length and questions[i] to get each question.
