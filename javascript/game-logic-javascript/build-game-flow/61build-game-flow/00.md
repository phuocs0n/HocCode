## How the Game is Organized

Before we write the final version, we set up the game in a simple way:

- Rules at the top: passMark, passMessage, failMessage
- Questions in one list: questions (an array)

Each question is one object, so everything stays together:

- question (text)
- options (choices)
- answer (correct letter)

That's the setup. Next we run the game using loops.
