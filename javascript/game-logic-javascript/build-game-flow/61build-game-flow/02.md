## Game loop

Here is the complete quiz game in one place. Every part comes from the chapters we've built: variables, conditionals, user input, loops, arrays, and objects.

```javascript
1var passMark = 40;
2var passMessage = "You passed! Well done.";
3var failMessage = "You didn't reach the pass mark. Try again.";
4
5var questions = [
6  { question: "What does HTML stand for?", options: ["A: Hyper Text Markup Language", "B: High Tech Machine Learning", "C: Home Tool Markup Link"], answer: "A" },
7  { question: "Which of these is a programming language?", options: ["A: Python", "B: Pizza", "C: Pencil"], answer: "A" },
8  { question: "What does JS stand for?", options: ["A: Java Source", "B: JavaScript", "C: Just Script"], answer: "B" },
9  { question: "What does CPU stand for?", options: ["A: Central Processing Unit", "B: Computer Personal Use", "C: Code Program Update"], answer: "A" },
10  { question: "In a game loop, what does a variable often track?", options: ["A: The weather", "B: Score or lives", "C: The player's name only"], answer: "B" }
11];
12
13while (true) {
14  var score = 0;
15  var wrongAnswers = [];
16  var i = 0;
17
18  console.log("Welcome to the Quiz Game");
19  console.log("You will be asked " + questions.length + " questions");
20  console.log("The passing marks is " + passMark);
21
22  while (i < questions.length) {
23    var num = i + 1;
24    var q = questions[i];
25
26    console.log("\nQ" + num + ". " + q.question);
27    console.log(q.options.join("\n"));
28
29    var userAnswer = prompt("\nEnter A, B, or C: ");
30    if (userAnswer) {
31      userAnswer = userAnswer.trim().toUpperCase();
32    }
33
34    while (userAnswer !== "A" && userAnswer !== "B" && userAnswer !== "C") {
35      userAnswer = prompt("Invalid. Enter A, B, or C only: ");
36
37      if (userAnswer) {
38        userAnswer = userAnswer.trim().toUpperCase();
39      }
40    }
41
42    if (userAnswer === q.answer) {
43      score++;
44    } else {
45      wrongAnswers.push(num + ". " + q.question + "\n");
46    }
47    i++;
48  }
49
50  var total = questions.length;
51  var percentage = total === 0 ? 0 : Math.round((score / total) * 100);
52  var passed = percentage >= passMark;
53  var message = passed ? passMessage : failMessage;
54
55  console.log("Your score is " + score + "/" + total);
56  console.log(message);
57
58  if (wrongAnswers.length > 0) {
59    console.log("Wrong:\n" + wrongAnswers.join(""));
60  }
61
62  var again = prompt("Replay? (yes / no)");
63  if (again !== "yes" && again !== "y") {
64    console.log("Bye! Thanks for playing.");
65    break;
66  }
67}
```

Run it in your console environment.

We've brought it all together: one game loop that welcomes, asks each question, validates input, tracks score and wrong answers, shows the summary, and lets the player replay or quit.
