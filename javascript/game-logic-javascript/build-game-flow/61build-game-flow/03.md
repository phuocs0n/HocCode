# Try it yourself

#### Course: Game Logic with JavaScript

## Try it yourself

You've built the full game. Now the fun part is making it yours.

Run it once from start to finish so you can feel the flow: questions, score, pass/fail, replay.

Then change one small thing and run it again. That's how you start seeing the structure:

- The rules live at the top (passMark, passMessage, failMessage)
- The content lives in questions (each question has question, options, answer)
- The loop ties it together using questions.length

One small edit is enough to see how the pieces connect.
