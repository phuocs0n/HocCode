## What's next

Congratulations - you've built the full quiz game and brought everything together.

Next step: take the same game logic into a graphical interface.

Learn the DOM (Document Object Model) so you can show the quiz in a web page - questions and options as text and buttons instead of console and prompt.

The flow (ask, validate, score, replay) stays the same; you'll use the browser (clicks, forms, CSS) instead of the console.

That's the natural next step after Thinking in Games.
