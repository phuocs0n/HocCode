# Things to try

#### Course: Game Logic with JavaScript

## Things to try

Try any one of these, then run the game again:

- Change passMark

Set passMark from 40 to 60. Play a round and notice how the same score can now fail.

- Change the messages

Rewrite passMessage or failMessage in your own words. Finish a round and see your version appear.

- Add a question

Add one more question object to the questions array. Keep the same shape (question, options, answer). The loop uses questions.length, so the new question gets picked up automatically.

- Remove a question

Delete one question object from the array and run again. Everything still works — the quiz just becomes shorter.

Small edits like these are how you build confidence: you change one thing, run it, and you can predict what will happen next.
