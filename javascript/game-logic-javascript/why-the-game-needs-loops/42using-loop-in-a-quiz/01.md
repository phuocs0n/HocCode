## Validate the input

Inside the question loop, we can re-ask until the player types a valid choice. We use a second while loop: keep asking while the answer is not A, B, or C.

```javascript
1var userAnswer = prompt("Enter A, B, or C: ");
2
3if (userAnswer) {
4  userAnswer = userAnswer.trim().toUpperCase();
5}
6
7while (userAnswer !== "A" && userAnswer !== "B" && userAnswer !== "C") {
8  userAnswer = prompt("Invalid. Enter A, B, or C only: ");
9
10  if (userAnswer) {
11    userAnswer = userAnswer.trim().toUpperCase();
12  }
13}
```

The inner loop runs until userAnswer is one of A, B, or C. Then we use userAnswer to check whether it is correct or wrong.

#### Developer Mindset

I keep the same trim() and toUpperCase inside the validation loop so every re-prompt is handled the same way. If I normalize only the first input and not the re-typed one, someone could enter a or A on the second try and still fail the check even though they meant A.

So the rule is simple: whatever cleanup I do for the first answer, I do for every answer inside that loop. That consistency makes the game feel fair and predictable, whether it's the first try or the fifth.
