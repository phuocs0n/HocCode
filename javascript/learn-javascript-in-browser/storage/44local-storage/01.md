## Methods in Local Storage

Just like sessionStorage, the localStorage object provides different methods to manage data.

In fact, localStorage uses the same methods as sessionStorage.

| Method | Purpose |
| --- | --- |
| setItem(key, value) | Stores data in localStorage as key-value pairs. |
| getItem(key) | Retrieves the value associated with a specific key. |
| removeItem(key) | Deletes a specific item from localStorage. |
| clear() | Removes all items from localStorage. |
