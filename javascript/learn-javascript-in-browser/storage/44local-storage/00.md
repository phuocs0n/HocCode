## Introduction

Unlike session storage, which clears data when the tab is closed, local storage allows data to persist even after the browser is closed.

For example, remember the to-do list you made in the previous chapter? You can use local storage to keep your tasks accessible even after reopening the browser.

In this lesson, you'll learn about local storage and use it to save tasks in your to-do list application.
