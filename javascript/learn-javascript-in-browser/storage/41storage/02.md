## Types of Storage

There are three types of browser storage you can use based on your needs:

- Cookies
- Session storage
- Local storage

These methods allow websites to perform various tasks, such as retaining user preferences, managing login states, or storing data for future use.

In the next lesson, you'll start with cookies.
