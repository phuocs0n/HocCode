#### Course: JavaScript in Browser

## Introduction

A cookie is a small piece of data websites stored on the user's browser.

For example, when you select the dark theme, this preference is stored in a cookie. On subsequent visits, the website reads the cookie and automatically applies the dark theme.

In this lesson, you'll learn how to create, read and manage cookies.
