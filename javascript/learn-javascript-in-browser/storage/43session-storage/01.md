## Introduction

Unlike cookies, session storage temporarily stores data for the duration of a session, which lasts as long as the browser tab is open.

For example, consider the simple sign-up form from the previous chapter, where you enter details like email, password, and gender.

Without session storage, refreshing the page erases all inputs, forcing you to start over.

In this lesson, you'll learn about session storage and how to use it to retain form data during a session.
