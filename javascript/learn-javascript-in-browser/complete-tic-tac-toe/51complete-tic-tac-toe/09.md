```javascript
1// Check for player names input and update UI elements
2startGame.addEventListener('click', (event) => {
3    // Retrieve input values for player names or set default names
4    player1Name = document.querySelector(".player1-name").value || "Player 1";
5    player2Name = document.querySelector(".player2-name").value || "Player 2";
6
7    // Update the player name in the turn info
8    const turnInfoPlayerName = document.querySelector("#turnInfo .player1-name");
9    if (turnInfoPlayerName) {
10        turnInfoPlayerName.textContent = player1Name;
11    }
12
13    // Update the player names in the score panel
14    const player1ScorePanel = document.querySelector("#player1Score .player1-name");
15    if (player1ScorePanel) {
16        player1ScorePanel.textContent = player1Name;
17    }
18
19    const player2ScorePanel = document.querySelector("#player2Score .player2-name");
20    if (player2ScorePanel) {
21        player2ScorePanel.textContent = player2Name;
22    }
23
24    // Switch to the game screen
25    switchScreen();
26});
```

Run the above code to see the setup screen.

Notice how the display property of gameScreen is initially set to none; this ensures the setup screen is shown first.

Now, switch to script.js. In the code, we've collected player names from input fields when the "Start Game" button is clicked, defaulting to "Player 1" and "Player 2" if no input is provided.

Once the game begins, the screen is switched from the setup page to the game screen using switchScreen().

Throughout the game, the names are dynamically updated in the player turn and score panels using the respective class with the player names.
