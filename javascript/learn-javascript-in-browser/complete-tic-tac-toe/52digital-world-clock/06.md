1// Function to get the current time for a timezone.

4        timeZone,
5        hour12: true,
6        hour: "2-digit",
7        minute: "2-digit",
8        second: "2-digit",
9    });

Run the above code and use the dropdown to create clocks for different cities.

You'll see that the clocks now show the correct time for the respective city.

This is possible because of toLocaleTimeString(). This method allows you to retrieve time for a given timezone.
