```javascript
1const updateClocks = () => {
2  const clockElements = document.querySelectorAll(".time");
3
4  // Update time for each clock
5  clockElements.forEach((clockElement) => {
6      const timezone = clockElement.getAttribute("data-timezone");    // Get the timezone
7      clockElement.textContent = getTime(timezone);    // Update the time
8  });
9};
10
11// Call updateClocks every second to ensure real-time updates
12setInterval(updateClocks, 1000);
```

Here, the updateClocks() function retrieves the current time for each clock and updates them.

Since we want the clocks to update continuously, we use setInterval() to call updateClocks() every second.
