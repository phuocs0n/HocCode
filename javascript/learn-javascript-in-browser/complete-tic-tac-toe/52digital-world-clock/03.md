```javascript
1const clocksContainer = document.querySelector("#clocks-container");
2
3// Function to create a clock element.
4const createClockElement = (container, city, timezone, time) => {
5    const clock = document.createElement("div");
6    clock.classList.add("clock");
7
8    clock.innerHTML = `<div class="city">${city}</div><div class="time" data-timezone=${timezone}>${time}</div>`;
9
10    container.appendChild(clock);
11};
12
13// Pass City, timezone, and appropriate time to create a clock
14createClockElement(clocksContainer, "City", "TimeZone", "00:00:00");
```

Here, the createClockElement() function creates and appends new clocks to the container.

Now, you can create as many clocks as you want by calling createClockElement() with the required parameters.
