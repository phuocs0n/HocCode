## Managing City Data

To add clocks for different cities and their time zones, we can create an array of objects, where each object represents a city with its name and corresponding time zone.

The array might look like this:

```javascriptDOM
const clocks = [
    { city: "NEW YORK", timeZone: "America/New_York" },
    { city: "PARIS", timeZone: "Europe/Paris" },
    { city: "TOKYO", timeZone: "Asia/Tokyo" },
    { city: "SYDNEY", timeZone: "Australia/Sydney" },
];
```

Now, let's see how you can use this array to create clocks based on the city selected by the user.

In the above code, we've used the selected dropdown value to choose the respective timeZone from clocks array.
