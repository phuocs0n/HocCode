## Selecting Elements

We'll use querySelector to select the game board.

```javascriptDOM
const gameBoard = document.querySelector(".game-board");
```

Now, we want certain tasks to happen when a cell is clicked.

Instead of attaching an eventListener to each cell, let's attach it to the parent, gameBoard. When a cell is clicked, we'll get its data-index and write it into the cell using textContent.

```javascriptDOM
// Add click event listener to parent
gameBoard.addEventListener('click', (event) => {
    const cellIndex = event.target.getAttribute('data-index');
    event.target.textContent = cellIndex;
});
```

1. event.target retrieves the specific cell that was clicked.
