## Adding Event Tasks

Now, we will modify the code so that when a player clicks on a grid cell, the cell gets filled with either 'X' or 'O', and the player's turn is switched.

Let's first store the cell triggering the event as:

```javascriptDOM
const cell = event.target;
```

We'll also select set the currentPlayer and select #turnInfo in order to update it:

```javascriptDOM
// Start with Player 1 (X)
let currentPlayer = "X"; 
const turnInfo = document.querySelector("#turnInfo");
```

To do this, we need to:

1. Add 'X' or 'O' to the clicked cell depending on the current player.
2. Change which player's turn it is.
3. Switch to the next player after each click.

```javascript
1const gameBoard = document.querySelector(".game-board");
2
3// Start with Player 1 (X)
4let currentPlayer = "X"; 
5const turnInfo = document.querySelector("#turnInfo");
6
7
8// Add click event listener to parent (game board)
9gameBoard.addEventListener('click', (event) => {
10    const cell = event.target;
11
12    // Ensure the cell is empty before marking it
13    if (cell.textContent === "") {
14        // Mark the cell with the current player's symbol
15        cell.textContent = currentPlayer;
16
17        // Change turn info
18        turnInfo.textContent = currentPlayer === "X" ? "Player 2's Turn" : "Player 1's Turn";
19
20        // Switch players
21        currentPlayer = currentPlayer === "X" ? "O" : "X";
22    }
23});
```

This code manages the turn-taking logic for a Tic Tac Toe game.

It starts by setting Player 1's symbol to "X". When a cell in the game board is clicked, it checks if the cell is empty. If it is, the current player's symbol ("X" or "O") is placed in that cell.

The text displaying whose turn it is (turnInfo) is updated to indicate the next player's turn.

After that, the current player is switched between "X" and "O" to alternate turns. This ensures players take turns marking the board while preventing overwriting of already marked cells.
