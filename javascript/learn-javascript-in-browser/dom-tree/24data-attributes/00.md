## Introduction

Consider the HTML below:

```javascriptDOM
<div class="product" data-product-id="123"></div>
```

So far, you've modified content inside elements. But what if you need to change custom data attributes like data-product-id like in the example above?

Attributes like href for links and src for images, as well as custom data-* attributes, store extra information:

```javascriptDOM
<a href="https://example.com" data-link-id="1">Visit Example</a>
<img src="image.jpg" alt="Sample Image"/>
```

In this lesson, you'll learn how to read and update these attributes using JS. Let's get started.
