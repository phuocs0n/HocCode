## get/setAttribute for Other Attributes

The concept of using getAttribute() and setAttribute() can be extended to manipulate other attributes, such as class, id, style, and more.

For example, we've used classList.add and classList.remove for adding a class to an element so far:

```html
1<h1>Change Page Background Color</h1>
2<p>Select a background color for the page:</p>
3
4<button class="light-bg">Light Yellow</button>
5<button class="dark-bg">Dark Gray</button>
6<button class="blue-bg">Light Blue</button>
```

```javascript
1const buttons = document.querySelectorAll("button");
2
3buttons.forEach(button => {
4    button.addEventListener("click", () => {
5        // Remove all background-related classes from the body
6        document.body.classList.remove("light-bg", "dark-bg", "blue-bg");
7        
8        // Add the class of the clicked button to the body
9        const colorClass = button.getAttribute('class');
10        document.body.classList.add(colorClass);
11    });
12});
```

Now, let's use this property to add a specific class using these functions to change the background color of the page:

```html
1<h1>Change Page Background Color</h1>
2<p>Select a background color for the page:</p>
3
4<button class="light-bg">Light Yellow</button>
5<button class="dark-bg">Dark Gray</button>
6<button class="blue-bg">Light Blue</button>
```


```javascript
1// Select all buttons using querySelectorAll
2const buttons = document.querySelectorAll("button");
3
4// Add event listeners to each button
5buttons.forEach(button => {
6    button.addEventListener("click", () => {
7        // Get the class of the button 
8        const colorClass = button.getAttribute('class'); 
9        
10        // Apply the class to the body element
11        document.body.setAttribute('class', colorClass);
12    });
13});
```

In the above code, when a button is clicked, the button's class attribute is retrieved using getAttribute('class').

Using this, now we apply that class to the body element using setAttribute('class', colorClass), which changes the page's background color.
