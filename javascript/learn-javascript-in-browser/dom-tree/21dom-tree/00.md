## Introduction

Imagine you have a list of products and need to apply a discount to all of them during a sale.

Selecting each product individually and applying a discount would be time-consuming and impractical.

This is where the Document Object Model (DOM) comes in. It allows you to select the list itself and make changes to all products at once.

In this chapter, you'll learn about DOM and how you can use it to create, navigate, and delete elements on a webpage.

In later lessons, you'll explore the event object and use the concepts from this chapter to lay the foundation for a Tic-Tac-Toe game.

Let's get started.
