## Event Object

The Event Object contains important information about the event, like the type of event, which element triggered the event, and even the position of the mouse when the event happened.

Let's print it out to explore its contents:

```html
1<h1>Click the Button to Log Event</h1>
2<button id="logButton">Click Me</button>
```

```javascript
1const button = document.querySelector("#logButton");
2
```

When you click the button, you'll see the Event Object logged to the console.
