## Introduction

You've worked with quite a number of user interactions by now, like clicking a button or hovering over an element.

Every such interaction with the webpage creates an Event Object.

In this lesson, you'll learn how to work with Event Objects to handle user interactions more effectively by using the data Event Object provides.
