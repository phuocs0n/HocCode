```javascript
1addListBtn.addEventListener("click", () => {
2    // Gather all text fields from list.
3    const existingInputs = document.querySelectorAll("#todo-lists input[type='text']");
4
5    // Check for empty text field.
6    for (const input of existingInputs) {
7        if (input.value.trim() === "") {
8            window.alert("Please fill in the current task before adding a new one!");
9            input.focus();
10            return;
11        }
12    }
13
14    ...
15});
```

Run the above code and click the "+ List Item" button multiple times.

Notice you'll get an alert prompting you to fill the current task before adding a new one.

This ensures each task is properly filled out before adding new tasks.
