## Accessing Page Elements

There are three elements you need to access:

- The "+ List Item" button, which adds new tasks when clicked.
- The element with the id todo-lists, which is the actual list itself.
- The "Clear All" button, which clears the entire list.

```html
1<div id="container">
2    <h1 id="title">To-do List</h1>
3    <button id="add-list-btn">List Item</button>
4    <div id="todo-lists"></div>
5</div>
6<button id="clear-all-btn">Clear All</button>
```

In the above code, we've accessed all three elements and also attached event listeners to the buttons, listening for the click event.

When you run the code and click the buttons, you'll notice that placeholder message for the clicked button is displayed.
