## Clearing All Fields

The "Clear All" button should remove all tasks in the list at once.

However, as this is a significant action, it's best to ask for user confirmation before proceeding.

4    <div id="todo-lists"></div>
5</div>
6<button id="clear-all-btn">Clear All</button>

```javascript
1clearAllBtn.addEventListener("click", () => {
2    // Ask user for confirmation.
3    let clearAllConfirmation = window.confirm("Are you sure you want to clear all tasks?");
4
5    // Take action based on user confirmation.
6    if (clearAllConfirmation) {
7        todoListsContainer.innerHTML = '';
8    } else {
9        window.alert("Clear action canceled.");
10    }
11});
```

Run the above code, add multiple tasks, and click the "Clear All" button.

You'll see a pop-up with two options: OK and Cancel. Clicking OK clears the list, while Cancel shows a message saying the action was canceled.

This behavior is made possible by the window.confirm() method, which is useful for capturing yes/no responses from users.
