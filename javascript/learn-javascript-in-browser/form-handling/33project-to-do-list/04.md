## Adding Tasks

First, you'll work on the "+ List Item" button to add new tasks.

```html
1<div id="container">
2    <h1 id="title">To-do List</h1>
3    <button id="add-list-btn">List Item</button>
4    <div id="todo-lists"></div>
5</div>
6<button id="clear-all-btn">Clear All</button>
```

```css
1li {
2    display: flex;
3    align-items: center;
4    margin: 0;

7    border-top: none;
8}
9

```

```javascript
1addListBtn.addEventListener("click", () => {
2    // Create list item.
3    const todoItem = document.createElement("li");
4
5    // Create checkbox.
6    const checkbox = document.createElement("input");
7    checkbox.type = "checkbox";
8
9    // Create textfield.
10    const inputField = document.createElement("input");
11    inputField.type = "text";
12    inputField.placeholder = "Enter Task";
13
14    // Create delete button.
15    const deleteBtn = document.createElement("button");
16    deleteBtn.classList.add("delete");
17    deleteBtn.textContent = "X";
18
19    // Add checkbox, textfield, and delete buton to list item.
20    todoItem.append(checkbox, inputField, deleteBtn);
21
22    // Add list item to list.
23    todoListsContainer.appendChild(todoItem);
24});
```

Run the code above and click the "+ List Item" button.

You'll notice that each click adds a new list item containing a checkbox, a text field, and a delete (X) button.

While the items are being added, the checkbox and delete button are not functional yet.

Let's make them functional on the next page.
