## Using Alert

The alert() method of the window object allows you to display text in a simple alert box.

Example

```html
1<button id="btn">Greet</button>
```

```javascript
1const btn = document.querySelector("#btn");
2
3btn.addEventListener("click", () => {
4    window.alert("Hello!");
5});
```

Run the above code and click the button.

You'll see the text "Hello!" appear in an alert box.

Notice alert() and console.log() are quite similar, as both simply display the text specified inside them.
