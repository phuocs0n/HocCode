## Introduction

Up until now, you used the document object to access and manipulate a webpage's components.

At times, you'll need to interact directly with the browser, which requires using the window object.

For example, run the code below to see how window can create a browser popup.

```javascript
1window.alert("This a popup!");
```

In this lesson, you'll explore different features of window and see how you can use it to control the browser environment.
