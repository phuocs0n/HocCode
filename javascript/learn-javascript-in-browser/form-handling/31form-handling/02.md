## Accessing Form Values

Let's see how to access the values entered in the input fields.

Consider this code.

```html
1<form id="signup-form" action="/html-form-submit" method="post">
2    <div class="form-group">
3        <label for="email" class="signup-label">Email:</label>
4        <input type="email" class="signup-input" id="email-input">
5    </div>
6
7    <div class="form-group">
8        <label for="password" class="signup-label">Password:</label>
9        <input type="password" class="signup-input" id="password-input">
10    </div>
11
12    <button type="submit" id="submit-btn">Sign-Up</button>
13</form>
```

```javascript
1const signupForm = document.querySelector("#signup-form");
2
3// Accessing input fields.
4const emailInput = document.querySelector('#email-input');
5const passwordInput = document.querySelector('#password-input');
6
7signupForm.addEventListener("submit", (event) => {
8    event.preventDefault();
9
10    // Accessing values from input fields.
11    console.log(emailInput.value);
12    console.log(passwordInput.value);
13});
```

Run the above code, fill in the input fields, and click on the "Sign-Up" button.

If you check the console, you can see the values you entered. You can get the values of input fields using the value property.
