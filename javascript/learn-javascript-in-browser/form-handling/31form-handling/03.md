## Handling Input Field Focus

To make the form interactive, you can highlight the input field visually whenever a user clicks on it. This will also help users identify which field they are currently interacting with.

You can do so by using the focus and blur (unfocus) event.

```html
1<form id="signup-form" action="/html-form-submit" method="post">
2    <div class="form-group">
3        <label for="email" class="signup-label">Email:</label>
4        <input type="email" class="signup-input" id="email-input">
5    </div>
6
7    <div class="form-group">
8        <label for="password" class="signup-label">Password:</label>
9        <input type="password" class="signup-input" id="password-input">
10    </div>
11
12    <button type="submit" id="submit-btn">Sign-Up</button>
13</form>
```

```css
1.focused {
2    outline: none;
3    border-color: #007bff;
4    box-shadow: 0 0 0 5px #007bff40;
5}
```

```javascript
1emailInput.addEventListener("focus", () => {
2    emailInput.classList.add("focused");
3});
4
5emailInput.addEventListener("blur", () => {
6    emailInput.classList.remove("focused");
7});
```

Run the above code and click the email input field. You'll see it highlighted when focused and the highlight removed when blurred.

Now, try a quick practice exercise to apply this concept to the password field.
