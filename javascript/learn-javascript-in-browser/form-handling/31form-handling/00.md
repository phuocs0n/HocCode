## Introduction

You've likely interacted with forms, whether to create accounts, log in to a service, or submit applications.

However, you might have noticed that certain forms are not submitted unless all fields meet specific criteria. For example,

```html
1<form id="signup-form" action="/html-form-submit" method="post">
2        <div class="form-group">
3            ...
```

```css
1#signup-form {
2    background-color: #f9f9f9;
3    ...
```

```javascript
1const signupForm = document.querySelector("#signup-form");
2...
```

Run the above code, fill in the input fields, and click the "Sign-Up" button.

You'll notice that the form isn't submitted unless you fill it out with valid values. This is made possible through form handling.

In this lesson, you'll learn to handle forms, validate inputs, and also enhance user experience.
