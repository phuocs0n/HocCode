# Basic Sign-Up Form

#### Course: JavaScript in Browser

## Basic Sign-Up Form

```html
1<form id="signup-form" action="/html-form-submit" method="post">
2    <div class="form-group">
3        ...
```

```css
1#signup-form {
2    background-color: #f9f9f9;
3    ...
```

Run the above code to see a basic form created using only HTML and CSS.

Click the "Sign-Up" button and you'll be redirected to another page. This is the default behavior of forms with an action attribute.

However, to handle the form with JS, such as validating the input fields, you need to prevent this behavior. You can do it this way:

```html
1<form id="signup-form" action="/html-form-submit" method="post">
2    <div class="form-group">
3        ...
```

```css
1#signup-form {
2    background-color: #f9f9f9;
3    ...
```

```javascript
1const signupForm = document.querySelector("#signup-form");
2
3signupForm.addEventListener("submit", (event) => {
4    // Prevent form from redirecting.
5    event.preventDefault();
6});
```
