## Accessing Text Content

The textContent property allows you to access the text content inside an element.

Example

```html
1<header id="header">
2    <div id="logo">E-Commerce</div>
3    <nav>
4        <ul class="nav-links">
5            <li><a href="#home">Home</a></li>
6            <li><a href="#products">Products</a></li>
7            <li><a href="#contact">Contact</a></li>
8        </ul>
9    </nav>
10</header>
11

13    <h1>Welcome to our store</h1>

16</div>
```
