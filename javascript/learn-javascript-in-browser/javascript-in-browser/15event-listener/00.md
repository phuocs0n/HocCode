## Introduction

Until now, you've been modifying HTML and CSS using JS.

You might be wondering, "Why use JS to change HTML and CSS when you can simply edit them directly in the code?" And you're right—editing HTML and CSS directly is perfectly fine for static content.

However, we typically use JS to make webpages interactive. This means using JS to dynamically update content, styles, and layout based on user actions.

In this lesson, you'll learn to modify HTML and CSS dynamically with JS.

Let's get started.
