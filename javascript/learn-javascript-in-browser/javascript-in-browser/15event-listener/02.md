## Using Event Listeners

JS event listeners allow you to trigger functions based on user actions.

Example


```javascript
1const hero = document.querySelector(".hero");
2const shopNowBtn = document.querySelector("button");
3
4const updateButton = () => {
5    shopNowBtn.textContent = "Thank you for shopping with us!";
6    shopNowBtn.style.backgroundColor = "#b0b0b0";
7}
8
9// Using event listener.
10shopNowBtn.addEventListener("click", updateButton);
```

Run the above code, and click the button.

Notice the button's text and appearance change right as you click it.

That's because shopNowBtn.addEventListener("click", updateButton) attaches an event listener to the button, which will execute updateButton() when clicked.

This is how JS can perform different actions based on user interactions.
