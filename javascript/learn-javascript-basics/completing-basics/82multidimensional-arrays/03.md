## Accessing Elements

Consider this code:

```javascript
1const data = [
2    [2, 3, 5],
3    [7, 14, 21],
4    [1, 3, 5]
5];
6
7// Access element in row 0, column 1
8console.log(data[0][1]);    // Output: 3
9
10// Access element in row 2, column 2
11console.log(data[2][2]);    // Output: 5
```

Here,

- data[0][1] accesses the element at row 0 and column 1, which is 3.
- data[2][2] accesses the element at row 2 and column 2, which is 5.
