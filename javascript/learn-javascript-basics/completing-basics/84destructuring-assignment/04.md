## How Destructuring Works

The destructuring assignment allows you to unpack (or "destructure") values from arrays or objects directly into separate variables.

Let's focus on destructuring arrays first. The syntax might look like this:

```javascript
let [var1, var2, ..., varN] = array;
```

Here,

- array is the array being destructured.
- var1 stores the first element of the array.
- var2 stores the second element of the array.
- varN stores the nth element of the array.

Example

```javascript
const fruits = ["apple", "banana", "kiwi"];

// Destructure fruits array
let [fruit1, fruit2, fruit3] = fruits;
```

Here,

- fruit1 stores "apple" (the first element of fruits).
- fruit2 stores "banana" (the second element of fruits).
- fruit3 stores "kiwi" (the third element of fruits).

This way, you don't need to access each element individually, making it much easier to extract values from arrays.
