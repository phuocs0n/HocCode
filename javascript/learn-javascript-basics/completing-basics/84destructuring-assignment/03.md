## Destructuring Assignment

Consider this code:

```javascript
1const fruits = ["apple", "banana", "kiwi"];
2
3// Use destructuring assignment
4let [fruit1, fruit2, fruit3] = fruits;
5
6console.log(fruit1);    // Output: apple
7console.log(fruit2);    // Output: banana
8console.log(fruit3);    // Output: kiwi
```

Here, we used the destructuring assignment to extract values from the fruits array without manually accessing each index.

The destructuring assignment is useful for breaking down collections like arrays and objects into distinct variables.
