## Introduction

In the previous lesson, you learned to unpack arrays and objects using the spread operator.

However, suppose you have an array:

```javascript
const fruits = ["apple", "banana", "kiwi"];
```

You want to store each element of the fruits array in individual variables:

- fruit1 should store "apple".
- fruit2 should store "banana".
- fruit3 should store "kiwi".

While you could access each element individually and store them in variables like this:

```javascript
let fruit1 = fruits[0];
let fruit2 = fruits[1];
let fruit3 = fruits[2];
```

This approach works, but it can be repetitive and less readable, especially for larger arrays.JavaScript provides a simpler way to achieve this using the destructuring assignment.

Let's see how on the next page.
