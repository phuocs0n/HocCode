## Spread Operator

Consider this code:

```javascript
1const fruits1 = ["apple", "banana", "kiwi"];
2
3// Use spread operator
4const fruits2 = ["orange", "mango", ...fruits1, "apricot", "papaya"];
5
6console.log(fruits2);
```

Output

```text
[
  'orange', 'mango',
  'apple',  'banana',
  'kiwi',   'apricot',
  'papaya'
]
```

As you can see, we achieved the result with just one line of code and without multiple method calls.

The spread operator makes adding elements simpler, more readable, and easier to maintain.

In this lesson, you'll learn how the spread operator works and how you can use it to perform different operations.
