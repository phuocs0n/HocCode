## Example: The for...in Loop

Consider this code:

```javascript
1const book = {
2    title: "The Hobbit",
3    author: "J.R.R. Tolkien",
4    pages: 295,
5    year: 1937
6};
7
8// Loop through the object
9for (let key in book) {
10    console.log(`${key}: ${book[key]}`);
11}
```

Output

```text
title: The Hobbit
author: J.R.R. Tolkien
pages: 295
year: 1937
```

Here's the step-by-step breakdown of the above program:

| Iteration | Value of key | Value of book[key] | Output |
| --- | --- | --- | --- |
| 1 | title | The Hobbit | title: The Hobbit |
| 2 | author | J.R.R Tolkien | author: J.R.R. Tolkien |
| 3 | pages | 295 | pages: 295 |
| 4 | year | 1937 | year: 1937 |
