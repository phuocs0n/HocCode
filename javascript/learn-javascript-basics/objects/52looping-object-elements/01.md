## Accessing All Object Properties

When working with arrays, you used the for and for...of loop to easily access each element. However, these loops aren't designed for working with objects.

To loop through an object's properties, JavaScript provides the for...in loop. This loop allows you to go through each key in an object.

Here's the syntax:

```javascript
for (let key in object) {
    // statement(s)
}
```

Here, key is a variable that holds the current property name in each iteration. Looping through the keys also means you can use object[key] to get the value linked to that key.
