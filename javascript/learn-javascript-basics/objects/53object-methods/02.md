## Introduction

Remember the library help desk example from the previous lesson?

Now, as a library help desk assistant, you often need to check what information is available for each book in the library.

One way to do this is by using a for...in loop to list all the properties in the student object:

```javascript
for (let key in book) {
    console.log(key);
}
```

Output

```text
title
author
pages
year
```

This works, but what if you need to check many books? Manually looping through each one can be time-consuming.

Wouldn't it be better if there was a quick and easy built-in way to retrieve all the keys at once?

Good news—JavaScript provides the Object.keys() method, which exactly does this. Let's explore it on the next page.
