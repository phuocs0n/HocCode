## The Object.keys() Method

The Object.keys() method retrieves all the keys from an object in one step.

Example

```javascript
1const book = {
2    title: "The Hobbit",
3    author: "J.R.R. Tolkien",
4    pages: 295,
5    year: 1937
6};
7
8// Retrieve and store keys of book object
9let bookKeys = Object.keys(book);
10
11console.log(bookKeys);
```

Output

```text
[ 'title', 'author', 'pages', 'year' ]
```

Here,

```javascript
Object.keys(book)
```

- retrieves all the keys in the book object.
- returns them as an array.

This makes it much easier to see what information is available in an object.

But there's more—you can even use this method to count how many properties an object has. Let's explore that next.
