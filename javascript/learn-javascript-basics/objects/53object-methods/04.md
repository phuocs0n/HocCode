## Counting Object Properties

Consider this code:

```javascript
1const book = {
2    title: "The Hobbit",
3    author: "J.R.R. Tolkien",
4    pages: 295,
5    year: 1937
6};
7
8// Retrieve and store keys of book object
9let bookKeys = Object.keys(book);
10
11// Display length of bookKeys
12console.log(bookKeys.length);    // Output: 4
```

Here, after retrieving all the keys of the book object, we use the length property to find the number of keys in the resulting array.

This way, you can find the total number of properties (keys) in an object.
