#### Looping Through Objects

You can use the for...in loop to iterate through all the keys of an object. During each iteration, you can access the corresponding value using the current key.

Example

```javascript
1const book = {
2    title: "The Hobbit",
3    author: "J.R.R. Tolkien",
4    pages: 295,
5    year: 1937
6};
7
8// Loop through the object
9for (let key in book) {
10    console.log(`${key}: ${book[key]}`);
11}
```
