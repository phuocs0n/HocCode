## Recap (V)

JavaScript provides built-in methods to work with object keys, values, and entries:

- Object.keys() – Retrieve all keys of the object as an array.
- Object.values() – Retrieve all values of the object as an array.
- Object.entries() – Retrieve all key-value pairs as an array of arrays.

Example

```javascript
1const book = {
2    title: "The Hobbit",
3    author: "J.R.R. Tolkien",
4    pages: 295,
5    year: 1937
6};
7
8// Use Object.keys()
9const keys = Object.keys(book);
10console.log("Keys:", keys);
11
12// Use Object.values()
13const values = Object.values(book);
14console.log("Values:", values);
15
16// Use Object.entries()
17const entries = Object.entries(book);
18console.log("Entries:", entries);
```
