## Recap (II)

#### Adding Properties

You can also add new properties to an existing object dynamically.

```javascript
1const book = {
2    title: "The Hobbit",
3    author: "J.R.R. Tolkien",
4    pages: 295,
5    year: 1937
6};
7
8// Add a new property
9book.genre = "Fantasy";
10
11console.log(book.genre);    // Output: Fantasy
```

#### Updating Properties

To update the value of an existing property, you can access the property and assign a new value.

```javascript
1const book = {
2    title: "The Hobbit",
3    author: "J.R.R. Tolkien",
4    pages: 295,
5    year: 1937
6};
7
8// Update a property
9book.pages = 310;
10
11console.log(book.pages);    // Output: 310
```
