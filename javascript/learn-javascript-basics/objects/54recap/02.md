#### Deleting Properties

You can remove a property from an object using the delete operator when it's no longer needed.

```javascript
1const book = {
2    title: "The Hobbit",
3    author: "J.R.R. Tolkien",
4    pages: 295,
5    year: 1937
6};
7
8// Delete a property
9delete book.year;
10
11console.log(book.year);    // Output: undefined
```

#### Object Methods

You can also add functions as properties in objects, which are then referred to as methods.

```javascript
1const book = {
2    title: "The Hobbit",
3    author: "J.R.R. Tolkien",
4    pages: 295,
5    year: 1937,
6
7    // Add a method
8    displayInfo: function () {
9        console.log("This book is a classic!");
10    }
11};
12
13// Call the method
14book.displayInfo();    // Output: This book is a classic!
```

To invoke a method, simply access the function as you would with any object property, followed by parentheses.
