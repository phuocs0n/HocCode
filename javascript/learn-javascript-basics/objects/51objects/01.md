## Creating Objects

The syntax of an object looks like this:

```javascript
const objectName = {
    key1: value1,
    key2: value2,
    ...
    keyN: valueN
};
```

Each key along with its associated value form a "key-value pair" or "property".

In the above example, key1: value1, key2: value2, and so on are the key-value pairs. Key-value pairs are separated by commas (,), and the entire object is enclosed in curly braces { }.
