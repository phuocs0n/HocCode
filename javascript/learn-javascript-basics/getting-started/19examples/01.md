## Example: Convert Kilometers to Miles

You can convert distance in kilometers to miles using this formula:

```javascript
1 kilometer = 0.621 miles
```

#### Example

```javascript
1// Program to convert distance in kilometers to miles
2
3// Get distance in kilometers
4let km = parseFloat(prompt("Enter distance in km: "));
5
6// Conversion ratio
7const ratio = 0.621;
8
9// Compute distance in miles
10let miles = km * ratio;
11console.log(`Distance in miles: ${miles}`);
```

Output

```text
Enter distance in km: 10
Distance in miles: 6.21
```

Here's how this program works:

1. We use prompt() to get input from the user and convert it to a number using parseFloat().
2. We calculate the distance in miles by multiplying the kilometers by 0.621.
