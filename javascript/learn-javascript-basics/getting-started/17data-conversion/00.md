## Different Types of Data

So far in this course, you've worked with three different types of data:

1. Integer: Whole numbers without decimal parts (e.g., 5, -6, 17, 0).
2. Float: Numbers with decimal parts (e.g., 5.6, 0.0, -7.84, 16.0).
3. String: A sequence of characters enclosed in quotes (e.g., "hello there", "5", "Number is 5.0").

In real-world projects, data isn't always in the format you need.

For instance, numbers might be stored as text, such as "5.3". This makes data manipulation tricky unless you can transform it into the right format.

In this lesson, you'll explore how to perform data conversions in JavaScript, enabling you to seamlessly handle these scenarios in your projects.
