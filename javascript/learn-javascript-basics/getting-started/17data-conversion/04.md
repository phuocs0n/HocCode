## Converting to Float

#### Convert Integer to Float

If you have an integer and need to turn it into a floating-point number, you can use the parseFloat() function:

```javascript
1let integerNumber = -15;
2
3// Convert integer to float
4let floatNumber = parseFloat(integerNumber);
5
6console.log(floatNumber);    // Output: -15
```

#### Convert String to Float

You can also convert strings to floating-point numbers using parseFloat():

```javascript
1let stringNumber = "-15.65";
2
3// Convert string to float
4let floatNumber = parseFloat(stringNumber);
5
6console.log(floatNumber);    // Output: -15.65
```
