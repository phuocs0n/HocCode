## Error Converting String to Number

Not all strings can be converted to integers. For example:

```javascript
1let stringNumber = "Howdy!";
2
3// Try to convert string to integer
4let integerNumber = parseInt(stringNumber);
5
6console.log(integerNumber);
```

Output

```text
NaN
```

Here, JavaScript gives you NaN (short for "Not a Number") because "Howdy!" is a string, which can't be converted into an integer.

To learn more about NaN, you can read this article.
