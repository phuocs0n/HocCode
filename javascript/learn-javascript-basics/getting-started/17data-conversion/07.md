## Implicit Type Conversion

JavaScript sometimes automatically (implicitly) converts data from one type to another. For example:

```javascript
1let integerNumber = 123;
2let floatNumber = 1.23;
3
4// Add an integer and a float
5let result = integerNumber + floatNumber;
6
7console.log(result);    // Output: 124.23
```

Here, JavaScript converts the integer (123) to a floating-point number (123.0) before performing the addition, resulting in a floating-point number.
