## Converting to Integer

#### Convert Float to Integer

If you have a floating-point number and need to turn it into an integer, you can use the parseInt() function. Here's an example:

```javascript
1let floatNumber = 15.0;
2
3// Convert float to integer
4let integerNumber = parseInt(floatNumber);
5
6console.log(integerNumber);    // Output: 15
```

#### Convert String to Integer

You can also convert strings to integers using parseInt():

```javascript
1let stringNumber = "15";
2
3// Convert string to integer
4let integerNumber = parseInt(stringNumber);
5
6console.log(integerNumber);    // Output: 15
```

Pretty simple, right?
