## Converting to Number

To convert data from other types to numbers, you can use the Number() function. Here's an example:

```javascript
1let stringNumber = "15";
2
3// Convert string to number
4let number = Number(stringNumber);
5
6console.log(number);    // Output: 15
```

In this code, the Number() function takes a string and converts it into its numeric equivalent.
