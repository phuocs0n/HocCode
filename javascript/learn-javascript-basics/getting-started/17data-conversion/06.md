## Converting to String

To convert a number to a string, you can use the toString() method.

```javascript
1let number = 5.5;
2
3// Convert number to string
4let numberString = number.toString();
5
6console.log(numberString);   
7
8// You can verify the type of data using the typeof operator:
9
10console.log(typeof numberString);
```

Output

```text
5.5
string
```
