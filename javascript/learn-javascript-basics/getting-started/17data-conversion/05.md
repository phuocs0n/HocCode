## typeof Operator

To verify the data type of a variable or value, you can use the typeof operator. This helps ensure your data is in the expected format before performing operations.

Lets see examples:

```javascript
1console.log(typeof 123);    // Output: number
2console.log(typeof 10.5);    // Output: number
3console.log(typeof "Hello");    // Output: string
4console.log(typeof "-15.65");    // Output: string
```

As shown above,

- Numbers (integers or floats) return "number".
- Strings return "string".

Using typeof ensures you are working with the correct data type, preventing unexpected results.
