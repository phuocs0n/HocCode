## Introduction

You've already learned about numbers, strings, and how to print them.

However, as you begin working on more complex programs, you'll need to use these values, not just display them. That's where variables come in.

A variable is a container used for storing data.

In this lesson, you'll learn to:

- Create variables
- Print variables
- Change variables' values

Let's start with creating variables.
