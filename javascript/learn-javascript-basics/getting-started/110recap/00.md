To store and use these data later in the program, you can store them in variables:

```javascript

3
```

#### Operators

In programming, you often need to perform calculations on values and variables, not just print them. To handle mathematical calculations, you use operators:

```javascript
1let x = 7;
2let y = 3;
3
4let remainder = x % y;
5let power = x ** y;
6
7console.log(`Remainder: ${remainder}`);
8console.log(`Power: ${power}`);
```
