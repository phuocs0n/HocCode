## Recap(II)

#### Take Input

You can receive input from the user with the prompt() function:

```javascript
1let x = prompt("Enter the first number:");
2let y = prompt("Enter the second number:");
3
4console.log(`You entered: x = ${x}, y = ${y}`);
```

#### Data Conversion

The data you're trying to use may not always be in the required format. In such situations, you need to perform data conversions:

```javascript
1// Convert strings to integers
2let x = parseInt(prompt("Enter the first number:"));
3let y = parseInt(prompt("Enter the second number:"));
4
5// Perform addition
6let sum = x + y;
7
8console.log(`Sum: ${sum}`);
```
