## Receiving User Input

You can ask the user for input and assign it to a variable using the prompt() function. Here's an example:

```javascript
1let firstName = prompt("Enter your name: ");
2console.log("Your name is " + firstName);
```

Here's what happens:

1. The program displays the text "Enter your name:".
2. It waits for the user to type something and press Enter.
3. The input is then assigned to the variable firstName.

Sample Output 1

```text
Enter your name: James
Your name is James
```

Sample Output 2

```text
Enter your name: Emily
Your name is Emily
```
