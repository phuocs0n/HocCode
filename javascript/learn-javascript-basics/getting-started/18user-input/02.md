## User Input Without Prompt Message

Here's another way to take user input using the prompt() function:

```javascript
1let fullName = prompt();
2console.log("Full Name:", fullName);
```

Sample Output

```text
Micheal Smith
Full Name: Micheal Smith
```

Here's what happens:

1. The prompt() function is called without any text inside it (no prompt message).
2. The program doesn't display any message but waits for the user to type something and press Enter.
3. After the user types their input and presses Enter, the input is assigned to the variable fullName.
