## Introduction

You have used console.log() to display a single value or variable. Here's a quick recap:

```javascript
1// Display a number
2console.log(34);    // Output: 34
3
4// Display a string
5console.log("Squid Game");    // Output: Squid Game
6
7// Create a variable
8let city = "London";
9
10// Display the city variable
11console.log(city);     // Output: London
```

Now, you'll learn to print multiple values and variables with a single console.log() statement.
