## Comments

In JavaScript, you can use the // symbol to create comments. For example:

Example

```javascript
1// Display Hello
2console.log("Hello");
```

Here, // Display Hello is a comment. JavaScript completely ignores this line while running the program.

Thus, the above program is equivalent to:

```javascript
1console.log("Hello");
```
