## Introduction

So far in this course, you've focused on printing values and variables to keep things simple.

However, solving real-world problems often requires performing calculations, not just displaying data. For this, you use operators.

An operator is a special symbol that performs an operation on values or variables. For example:

```javascript
1let total = 5 + 10;
2
3console.log(total);    // Output: 15
```

Here, + is an operator used for addition.

In this lesson, you'll explore JavaScript operators and how to use them.
