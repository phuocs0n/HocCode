## The + Operator

As you saw in the last example, the + operator is used to add operands (values or variables).

```javascript
1let x = 10;
2let y = 20;
3
4// Perform addition
5let total = x + y + 30;
6
7console.log(total);    // Output: 60
```

Here, total = x + y + 30 computes the sum of x, y, and 30, then assigns the result to the total variable.

You can also perform addition directly without storing it in a variable:

```javascript
1let x = 12.5;
2let y = 10;
3
4console.log(x + y);    // Output: 22.5
```

In this example, the sum of x and y is computed and displayed directly.
