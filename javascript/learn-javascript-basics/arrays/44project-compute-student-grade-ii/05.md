## Calculating Total Score

To calculate the total score, we'll use the reduce() method. This approach is concise, efficient, and a great practice.

To calculate the total score using reduce(), we'll define a function to add scores:

```javascript
const addScore = (sum, score) => {
    return sum + score;
};
```

Here,

- sum: Keeps track of the total score so far.
- score: Represents the current element in the array.

Next, we use this function with reduce() and store the result:

```javascript
let total = scores.reduce(addScore, 0);
```
