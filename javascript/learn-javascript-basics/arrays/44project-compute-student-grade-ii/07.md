## Final Code

Here's the final project:

```javascript
1// Function to add scores
2const addScore = (sum, score) => {
3    return sum + score;
4};
5
6// Find the average score and return it
7const getAverageScore = (scores) => {
8
9    // Calculate total score
10    let total = scores.reduce(addScore, 0);
11    
12    // Compute average score
13    let averageScore = total / scores.length;
14    
15    return averageScore;
16}
17
18// Returns the grade based on the average score
19const computeGrade = (averageScore) => {
20    let grade;
21
22    if (averageScore >= 80) {
23        grade = "A";
24    } else if (averageScore >= 60) {
25        grade = "B";
26    } else if (averageScore >= 50) {
27        grade = "C";
28    } else {
29        grade = "F";
30    }
31
32    return grade;
33};
34
35// Using array with ten values
36const scores = [55, 64, 75, 80, 65, 40, 90, 85, 68, 78]
37
38const averageScore = getAverageScore(scores);
39
40console.log(`Average Score: ${averageScore}`);
41
42let grade = computeGrade(averageScore);
43
44console.log(`Grade: ${grade}`);
```

Output

```text
Average Score: 70
Grade: B
```

Here, the scores array contains ten values, and the code works perfectly.

Since the average score is calculated dynamically based on the array's length, the project is now adaptable to arrays of any size.
