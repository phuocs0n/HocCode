## Introduction

Remember we created a project to calculate a student's average score and their grade?

To calculate the average score, you used the following function:

```javascript
// Find the average score and return it
const getAverageScore = (s1, s2, s3, s4, s5) => {

    // Variable for storing total sum
    let total = s1 + s2 + s3 + s4 + s5;
    
    // Compute average score
    let averageScore = total / 5;
    
    return averageScore;
}
```

This function works but accepts five individual scores as arguments, which isn't practical for real-world applications.

Now that you've learned about arrays and array manipulation, you can improve this project by:

- Storing scores in an array.
- Using array methods to calculate the average score.
