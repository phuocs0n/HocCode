## Storing Numbers in Array

Here's how you can store numbers in an array:

```javascript
1// Array storing only numbers
2const numbers = [10, 20, 30, 40, 50];
3
4console.log(numbers);
```

Output

```text
[ 10, 20, 30, 40, 50 ]
```

Storing strings and numbers in an array is similar. However, you don't need to enclose numbers within quotation marks.
