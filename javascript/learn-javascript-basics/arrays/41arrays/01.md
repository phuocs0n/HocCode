## Creating an Array

An array is a data type that can store multiple values in a single variable.

Here's an example of an array of fruits:

```javascript
1// Create array storing list of fruits
2const fruits = ["Apple", "Banana", "Orange"];
3
4// Display array
5console.log(fruits);
```

Output

```text
[ 'Apple', 'Banana', 'Orange' ]
```

In the above code,

- fruits is the array's name.
- [] defines the array and encloses its elements.
- "Apple", "Banana", and "Orange" are elements of the array, which are separated by commas (,).

Here, the fruits array stores only strings. Next, let's see how to store numbers in an array.
