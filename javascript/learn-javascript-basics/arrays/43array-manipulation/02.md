## Why Use map()?

Suppose you have an array of item prices:

```javascript
const prices = [200, 300, 400];
```

To increase each item price by $20, you might use a for...of loop like this:

```javascript
1// Item prices
2const prices = [200, 300, 400];
3
4// Array to hold new prices
5const newPrices = [];
6
7// Add $20 to each price
8for (let price of prices) {
9    newPrices.push(price + 20);
10
11}
12
13// Print the new prices
14console.log(newPrices);    // [220, 320, 420]
```

This works, but it can be simplified. The map() method provides a cleaner and more efficient way to achieve the same result.

Let's start with why you should use map() and how it simplifies transforming arrays.
