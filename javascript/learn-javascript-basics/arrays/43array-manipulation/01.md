## Introduction

In this lesson, you'll learn various array methods.

Array methods are array-specific functions that make working with arrays easier and more efficient.

Instead of using the for and for...of loop every time, you can use the following methods to simplify common tasks:

- map(): Transforms each element in an array (e.g., increasing every item price by $20).
- filter(): Selects elements based on a condition (e.g., keeping only item prices greater than $250).
- reduce(): Processes the entire array to produce a single value (e.g., calculating the total price of all items).

You'll explore each method in detail throughout this lesson.
