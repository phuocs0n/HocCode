## Example: Using The map() Method

Here's the complete code:

```javascript
1// Array of prices
2const prices = [200, 300, 400];
3
4// Function to increase the price by $20
5const increasePrice = (price) => {
6    return price + 20;
7};
8
9// Store the new array returned by map()
10const newPrices = prices.map(increasePrice);
11
12console.log(newPrices);
```

Output

```text
[ 220, 320, 420 ]
```

As you can see, each price in the prices array is increased by $20 in the newPrices array.
