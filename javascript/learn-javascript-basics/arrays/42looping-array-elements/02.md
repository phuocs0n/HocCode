## Accessing Last Element

The length property gives the total number of elements in the array.

However, since indexes start from 0, the last element's index is one less than the array length. For example,

```javascript
1const scores = [40, 85, 60, 70, 30];
2
3// Find last element's index
4let lastIndex = scores.length - 1;
5
6// Access last element
7console.log(scores[lastIndex]);    // Output: 30
```

Here, lastIndex stores the index of the last element (scores.length - 1), which is 4.

So, scores[lastIndex] retrieves 30, the last element of the array.
