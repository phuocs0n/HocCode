## Finding Array Length

To loop through an array, you must know the positions of the first and last elements.

- The first element is always at index 0.
- The last element's index depends on the array's size.

To determine an array's size, you can use the length property.

Example

```javascript
1const scores = [40, 85, 60, 70, 30];
2
3// Display array length
4console.log(scores.length);    // Output: 5
```

Here, the scores array contains five elements. Thus, scores.length returns 5.
