#### Array Manipulation

1. The map() method

The map() method creates a new array by applying a function to each element of the original array.

```javascript
1// Array of prices
2const prices = [100, 200, 300];
3
4// Use map() to create a new array with updated prices
5const updatedPrices = prices.map((price) => {
6
7    return price + 10;
8});
9
10console.log(updatedPrices);    // Output: [110, 210, 310]
```

2. The filter() method

The filter() method creates a new array by selecting elements from the original array that satisfy a given condition.

```javascript
1// Array of numbers
2const numbers = [1, 2, 3, 4, 5, 6];
3
4// Use filter() to extract even numbers
5const evenNumbers = numbers.filter((number) => {
6
7    return number % 2 === 0;
8});
9
10console.log(evenNumbers);    // Output: [2, 4, 6]
```

3. The reduce() method

The reduce() method combines all elements of an array to produce a single value, such as a total sum or product.

```javascript
1// Array of numbers
2const numbers = [10, 20, 30, 40];
3
4// Use reduce() to calculate the total
5const totalSum = numbers.reduce((sum, number) => {
6    return sum + number;
7}, 0);
8
9console.log(totalSum);    // Output: 100
```
