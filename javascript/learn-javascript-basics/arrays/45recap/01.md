#### Looping Through Arrays

1. Using for loop

You can use a for loop to iterate through each element in an array

```javascript
1const fruits = ["Apple", "Banana", "Orange"];
2
3for (let i = 0; i < fruits.length; i++) {
4    console.log(fruits[i]);
5}
```

The length property determines how many elements the array has, and you use it as the stopping condition for the loop.

2. Using for...of loop

The for...of loop simplifies iterating through arrays by directly accessing each element.

```javascript
1const fruits = ["Apple", "Banana", "Orange"];
2
3for (let fruit of fruits) {
4    console.log(fruit);
5}
```

Here, the fruit variable represents each element of the array during each iteration, making the code cleaner and easier to read.
