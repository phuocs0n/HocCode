## Step 2: Taking user input

Let's create a function to take user input among "rock", "paper" or "scissors".

```javascript
1const getUserChoice = () => {
2    let choice = prompt("Enter your choice: ");
3    return choice;
4};
5
6let userChoice = getUserChoice();
7console.log(userChoice);
```

Here, the getUserChoice() function takes user input and stores it in the userChoice variable.

We need to convert the user's choice to lowercase using choice.toLowerCase(). This is because we need to compare this value with the computer's value (which is in lowercase).

```javascript
1const getUserChoice = () => {
2    let choice = prompt("Enter your choice: ");
3    choice = choice.toLowerCase();
4    return choice;
5};
6
7let userChoice = getUserChoice();
8console.log(userChoice);
```

Sample Output

```text
Enter your choice: ROCK
rock
```
