## Step 3: Deciding Win, Lose, or Draw

Now, let's create a function to decide whether the user won, lost, or the game ended in a draw. This function will:

- take two arguments (the user's pick and the computer's pick)
- return a string: either "Win", "Lose" or "Draw"

```javascript
const determineOutcome = (computerChoice, userChoice) => {
    // If both the computer and user choose the same option, it's a draw
    if (computerChoice === userChoice) {
        return "Draw";
    }

    // User wins if they choose paper against rock
    else if (computerChoice === "rock" && userChoice === "paper") {
        return "Win";
    }
    // User wins if they choose scissors against paper
    else if (computerChoice === "paper" && userChoice === "scissors") {
        return "Win";
    }   
    // User wins if they choose rock against scissors
    else if (computerChoice === "scissors" && userChoice === "rock") {
        return "Win";
    } 

    // If none of the above conditions are met, the user loses
    else {
        return "Lose";
    }
};
```

Basically, this function returns:

- "draw" if the computer pick and the user pick is the same
- "win" if the user wins using the rule we described earlier
- "lose" if neither condition for draw and win is met
