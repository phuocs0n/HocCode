## Step 1: Making Computer Randomly Choose a Value

In the first step, we'll make the computer randomly choose between either rock, paper or scissors.

To make the computer choose, let's first generate a random number between 0 and 2:

- 0 represents rock
- 1 represents paper
- 2 represents scissors

To generate random numbers, you can use the Math.random() function, which gives a number between 0 and 1:

```javascript
1let choice = Math.random();
2console.log(choice);
```

Run this code a few times. You'll see a different result each time. Next, let's make this code so that it only generates 0, 1, 2 randomly.
