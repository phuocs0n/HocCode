#### Course: Learn JavaScript Basics

## Generating 0, 1, and 2 Randomly

To get a number between 0 and 3, multiply the random number by 3:

```javascript
1let choice = Math.random() * 3;
2console.log(choice);
```

Run this code again, and you'll notice the output now ranges between 0 and 3 (not inclusive of 3).

To get whole numbers (0, 1, or 2), use Math.floor(), which rounds a number down to the nearest integer:

```javascript
1let choice = Math.floor(Math.random() * 3);
2console.log(choice);
```

Now, the output will always be one of 0, 1, or 2. Now next, we'll assign these numbers to rock, paper, and scissors.
