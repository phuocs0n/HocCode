In this project, you'll create a simple yet engaging game called Rock, Paper, Scissors.

### Game Rules

If you're unfamiliar with the rules, here's how the game works:

- This game is played between two players.
- Each player chooses one of the following options: rock, paper, or scissors.
- If both players choose the same option, it's a draw.

If the players choose different options, one will win, and the other will lose. Next, let's see the winning rules.
