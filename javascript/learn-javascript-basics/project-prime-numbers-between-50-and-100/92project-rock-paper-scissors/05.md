## Assigning Values to Numbers

Let's assign these numbers to rock, paper, and scissors as follows:

- 0 represents rock
- 1 represents paper
- 2 represents scissors

Here's the logic:

```javascript
1let options = ["rock", "paper", "scissors"];
2let choice = Math.floor(Math.random() * 3);
3console.log(options[choice]);
```

This will randomly output "rock", "paper", or "scissors".

Let's implement this logic inside a function.

```javascript
1const getComputerChoice = () => {
2    const options = ["rock", "paper", "scissors"];
3    let choice = Math.floor(Math.random() * 3);
4    return options[choice];
5};
6
7let computerChoice = getComputerChoice();
8console.log(computerChoice);
```

This function randomly returns either "rock", "paper", or "scissors". Now, let's take user input to get their choice.
