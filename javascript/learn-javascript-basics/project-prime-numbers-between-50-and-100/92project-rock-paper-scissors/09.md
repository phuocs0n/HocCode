## Step 4:Handling Wrong User Input

Our code doesn't work if the user enters values other than "rock", "paper" or "scissors".

To handle this problem, we'll ask for user input until the user enters either "rock", "paper" or "scissors".

We can solve this problem by changing the getUserChoice() function.

```javascript
const getUserChoice = () => {
    while (true) {
        let choice = prompt("Enter your choice: ");
        choice = choice.toLowerCase();
        if (["rock", "paper", "scissors"].includes(choice)) {
            return choice;
        } else {
            console.log("Invalid choice, please try again.");
        }
    }
};
```
