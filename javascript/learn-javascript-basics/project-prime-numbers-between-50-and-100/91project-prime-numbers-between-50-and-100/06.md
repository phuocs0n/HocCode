## Using the Function in the Program

Here's how you can use the checkPrime function in the program:

```javascript
1const checkPrime = (number) => {
2    if (number <= 1) {
3        return false;
4    }
5
6    if (number > 1) {
7        for (let i = 2; i < number; i++) {
8            if (number % i === 0) {
9                return false;
10            }
11        }
12        return true;
13    }
14}
15
16const number = parseInt(prompt("Enter a number: "));
17
18// Call the checkPrime function
19let isPrime = checkPrime(number);
20
21if (isPrime) {
22    console.log(`${number} is prime`);
23} else {
24    console.log(`${number} is not prime`);
25}
```

```text
Enter a number: 17
17 is prime
```
