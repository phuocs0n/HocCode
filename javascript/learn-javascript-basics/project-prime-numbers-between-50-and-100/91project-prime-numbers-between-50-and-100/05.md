## Handling Remaining Numbers

Let's handle the case for numbers less than or equal to 1. For these, we'll return false since numbers less than 1 are not prime.

```javascript
if (number <= 1) {
    return false;
}
```

We'll use this logic inside the function to determine whether a number is prime. The complete function will include additional checks and will look like this:

```javascript
const checkPrime = (number) => {
    // If number is less than 2, it's not a prime number
    if (number <= 1) {
        return false;
    }

    if (number > 1) {
        for (let i = 2; i < number; i++) {
            if (number % i === 0) {
                return false;
            }
        }
        return true;
    }
}
```
