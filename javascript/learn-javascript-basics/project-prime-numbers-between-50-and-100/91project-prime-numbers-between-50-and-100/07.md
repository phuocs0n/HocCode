## Step 3: Prime Numbers Between 50 to 100

To find prime numbers between 50 and 100, we'll use a loop that iterates through each number in this range. For each number, we'll check if it's prime using the checkPrime() function.

```javascript
for (let i = 50; i <= 100; i++) {
    let isPrime = checkPrime(i);
    if (isPrime) {
        console.log(`${i} is prime`);
    }
}
```

In each iteration, the loop calls the checkPrime() function to determine if i is prime. If it is, the number is printed to the console.
