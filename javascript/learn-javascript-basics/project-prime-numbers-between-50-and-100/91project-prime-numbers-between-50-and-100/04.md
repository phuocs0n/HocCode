## Step 2: Creating a Function

We can make this program reusable and easier to manage by creating a function.

Here's how the function will work:

- The function will take a single argument number (the number we need to check for prime).
- The function will check if the number is prime or not.
- If the number is prime, the function will return true. If not, the function will return false.

```javascript
const checkPrime = (number) => {
    // Only check if number is greater than 1
    if (number > 1) {
        for (let i = 2; i < number; i++) {
            if (number % i === 0) {
                return false;
            }
        }
        return true;
    }
}
```

This function only works for numbers greater than 1. We know any number less than or equal to 1 is not a prime number. Next, let's handle that.
