## Complete Program: Prime Numbers Between 50 and 100

Let's take a look at the complete program.

```javascript
1const checkPrime = (number) => {
2    if (number <= 1) {
3        return false;
4    }
5    
6    if (number > 1) {
7        for (let i = 2; i < number; i++) {
8            if (number % i === 0) {
9                return false;
10            }
11        }
12        return true;
13    }
14}
15
16// Iterate loop from 50 to 100
17for (let i = 50; i <= 100; i++) {
18    let isPrime = checkPrime(i);
19    if (isPrime) {
20        console.log(`${i} is prime`);
21    }
22}
```
