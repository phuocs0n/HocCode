## Example: Check if a Number is Prime

Here's a program that checks whether a user-provided number is prime:

```javascript
1// Get user input and check if it's prime
2let number = parseInt(prompt("Enter a number: "));
3
4let isPrime = true;
5
6// Only check if number is greater than 1
7if (number > 1) {
8    for (let i = 2; i < number; i++) {
9        if (number % i === 0) {
10            isPrime = false;
11        }
12    }
13}
14
15if (isPrime) {
16    console.log(`${number} is prime`);
17} else {
18    console.log(`${number} is not prime`);
19}
```

Output

```text
Enter a number: 17
17 is prime
```

Output

```text
Enter a number: 12
12 is not prime
```
