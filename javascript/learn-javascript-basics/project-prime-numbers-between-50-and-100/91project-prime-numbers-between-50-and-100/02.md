## Step 1: Check Prime Number

A prime number is a number that is only divisible by 1 and itself.

For example, 17 is a prime number because it is only divisible by 1 and 17.

#### How to Check if a Number is Prime

To determine if a number is prime, follow these steps:

Step 1: Assume the number is prime.

```javascript
let isPrime = true;
```

Step 2: Check divisibility.

Iterate through numbers from 2 to number - 1. If the number is divisible by any of these, it's not prime.

```javascript
let isPrime = true;

// Only check if number is greater than 1
if (number > 1) {
    for (let i = 2; i < number; i++) {
        if (number % i === 0) {
            isPrime = false;
        }
    }
}
```

If isPrime remains true after the loop, the number is prime. Next, let's use this logic to write code that checks if a number provided by the user is prime.
