## The try...catch Statement

The syntax of the try...catch statement is:

```javascript
try {
    // Code that might cause an exception
} catch (error) {
    // Code to handle the exception
}
```

Here,

- Inside the try block, you write code that might cause an exception.
- The catch block handles any exception that occurs inside try. If there's no exception, the catch block is skipped.
