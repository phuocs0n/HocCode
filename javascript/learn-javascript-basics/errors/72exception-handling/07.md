## Example: try...catch...finally without Error

Consider this code:

```javascript
1// Declare result
2let result = "Passed";
3
4try {
5    // Access result
6    console.log(result);
7
8} catch (error) {
9    console.log(`Error caught: ${error}`);
10
11} finally {
12
13    // Code that runs regardless of error
14    console.log("Finally executed");
15}
```

Output

```text
Passed
Finally executed
```

Here, no exception occurs because the result variable is properly declared and accessed.

However, the finally block still executes, displaying the message "Finally executed".
