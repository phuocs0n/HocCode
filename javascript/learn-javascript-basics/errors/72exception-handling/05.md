## The try...catch...finally Statement

The try...catch...finally statement enhances exception handling by adding a finally block.

The finally block always runs, regardless of whether an exception occurs. It's useful for cleanup tasks, logging, or any operation that should execute regardless of success or failure.

The syntax is:

```javascript
try {
    // Code that might cause an exception
} catch (error) {
    // Code to handle the exception
} finally {
    // Code that always runs
}
```
