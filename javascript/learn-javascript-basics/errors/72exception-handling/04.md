## The Error Object

The error variable (commonly named error or err) holds an object with details about the exception. This helps with diagnosing and handling issues effectively.

The error object typically has these properties:

- name: Specifies the type of exception that occurred.
- message: Provides a description of what went wrong, offering helpful context about the issue.

Example

```javascript
1try {
2    console.log(result);
3
4} catch (error) {
5
6    // Access error name
7    console.log(`Error name: ${error.name}`);
8
9    // Access error message
10    console.log(`Error message: ${error.message}`);
11}
```

Output

```text
Error name: ReferenceError
Error message: result is not defined
```

Here,

- error.name gives the type of error (ReferenceError).
- error.message provides a description of the error (result is not defined).

This way, you can access different information about the exception.
