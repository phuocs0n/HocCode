## Example: Exception

Consider this code:

```javascript
1let age = 42;
2
3age.toUpperCase();
```

Output

```text
age.toUpperCase();
    ^
TypeError: age.toUpperCase is not a function
```

Here, the age variable is a number, but toUpperCase() is a method designed for strings. Trying to use it on a number causes a TypeError, which is a type of runtime error.

However, you might wonder why errors are categorized as syntax and runtime errors. Let's understand the difference on the next page.
