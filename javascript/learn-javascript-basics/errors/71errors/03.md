## Syntax Errors

Syntax errors occur when the code violates JavaScript's syntax rules.

Example

```javascript
1console.log("Programiz";
```

Output

```text
console.log("Programiz";
            ^^^^^^^^^^^
SyntaxError: missing ) after argument list
```

Here, the error occurs because of the missing ending parenthesis.

Syntax errors must be fixed before the program can run.
