## Runtime Errors

Runtime errors occur when the code follows JavaScript's syntax rules but fails during execution. These errors are also called exceptions.

Example

```javascript
1console.log(userName);
```

Output

```text
console.log(userName);
            ^
ReferenceError: userName is not defined
```

Here, the syntax is correct. However, we're trying to access and display the userName variable, which isn't defined.

This raises ReferenceError, which is a runtime error.
