## Recap (I)

Errors prevent code from executing properly. Types of errors:

- Syntax error: Occurs when the code violates JavaScript's syntax rules.
- Runtime error (exceptions): Occurs when the code follows JavaScript's syntax rules but fails during execution.

Example

```javascript
1// Syntax error
2// "Log" is incorrect
3console.Log("Hello");
```

```javascript
1// Runtime error
2// y is not defined
3let x = y;
```
