## Recap (IV)

#### The throw Statement

You can generate and throw custom errors using the throw statement. For example,

```javascript
1let num = -5;
2if (num < 0) {
3    throw new Error("Negative numbers are not allowed");
4}
```

#### throw With try...catch

You can handle custom errors using the try...catch block. For example,

```javascript
1try {
2    let num = -5;
3    if (num < 0) {
4        throw new Error("Negative numbers not allowed");
5    }
6} catch (error) {
7    console.log(`Error caught: ${error.message}`);
8}
9
10// Output: Error caught: Negative numbers not allowed
```
