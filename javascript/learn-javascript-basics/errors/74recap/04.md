#### The try...catch...finally Statement

The finally block always runs, regardless of an exception occurring. For example,

```javascript
1try {
2    console.log("Try block executed");
3} catch (error) {
4    console.log("Catch block executed");
5} finally {
6    console.log("Finally block executed");
7}
```

Output

```text
Try block executed
Finally block executed
```
