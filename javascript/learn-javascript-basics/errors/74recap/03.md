## Recap (II)

#### The try...catch Statement

The try...catch block allows you to handle exceptions gracefully. For example,

```javascript
1try {
2    console.log(address);
3} catch (error) {
4    console.log(`Error caught: ${error.message}`);
5}
6
7// Output: Error caught: address is not defined
```

#### The error Object

Exceptions caught in the catch block contain useful information. For example,

```javascript
1try {
2    // y is not defined
3    let x = y;
4} catch (error) {
5    // Display error name
6    console.log(error.name);    // Output: ReferenceError
7
8    // Display error message
9    console.log(error.message);    // Output: y is not defined
10}
```
