## The throw Statement

Here's how throw was used to create a custom error in the previous example:

```javascript
throw new Error("Cannot divide by zero");
```

Here,

- new Error() creates a custom error.
- "Cannot divide by zero" is the message that's displayed when the error occurs.
- throw generates the custom error.

Like other errors, you can also handle custom errors using try...catch. Let's explore it next.
