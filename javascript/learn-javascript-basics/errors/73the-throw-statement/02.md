## Example: The throw Statement

The throw statement allows you to generate a custom error that crashes the program.

Example

```javascript
1let numerator = 5; // Corrected from 'nominator'
2let denominator = 0;
3
4// Check if denominator is 0
5if (denominator === 0) {
6    // Generate error
7    throw new Error("Cannot divide by zero");
8}
9
10let result = numerator / denominator;
11console.log(result);
```

Output

```text
throw new Error("Cannot divide by zero");
    ^
Error: Cannot divide by zero
```

Here, we've used the if block to conditionally throw the error only if denominator is 0.

This way, rather than getting Infinity as a result, we'll get a custom error with the message "Cannot divide by zero", which also halts the program.
