## Example: throw With try...catch

Consider this code:

```javascript
1const numerator = 5;
2const denominator = 0;
3
4try {
5    // Check if denominator is 0
6    if (denominator === 0) {
7
8        // Generate error
9        throw new Error("Cannot divide by zero");
10    }
11
12    let result = numerator / denominator;
13    console.log(result);
14
15} catch (error) {
16    console.log(`Error caught: ${error.message}`);
17}
```

Output

```text
Error caught: Cannot divide by zero
```

Here,

- The try block first checks if denominator is 0. Then, attempts to perform the division.
- If denominator is 0, we get the custom error with the message "Cannot divide by zero".
- If error occurs, the catch block catches it and logs a custom error message that includes the error's description.
