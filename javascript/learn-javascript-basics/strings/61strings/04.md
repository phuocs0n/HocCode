## Creating Strings with Template Literals

You've already used template literals (backticks ` `) to format output.

Similarly, you can use template literals to create strings and embed variables directly into the string.

Example

```javascript
1let firstName = "Emma";
2let event = "weekly team meeting";
3let time = "Thursday at 10 AM";
4
5// Use template literals
6let message = `Hi ${firstName}, you are invited to our ${event} on ${time}.`;
7
8console.log(message);
```

This way, it's much easier to read and work with dynamic strings.
