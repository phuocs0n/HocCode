## Creating Strings

You've defined string in two ways:

1. Using single quotes ('):

```javascript
let message = 'Hi John, you are invited to our weekly team meeting on Thursday at 10 AM.';
```

2. Using double quotes ("):

```javascript
let message = "Hi John, you are invited to our weekly team meeting on Thursday at 10 AM.";
```

Both methods work, but these strings are static—they always display the same text.

Let's see how you might make these strings dynamic on the next page.
