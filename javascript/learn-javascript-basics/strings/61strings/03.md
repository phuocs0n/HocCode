# Example: Creating Personalized Email

#### Course: Learn JavaScript Basics

## Example: Creating Personalized Email

```javascript
1let firstName = "Emma";
2let event = "weekly team meeting";
3let time = "Thursday at 10 AM";
4
5let message = "Hi " + firstName + ", you are invited to our " + event + " on " + time + ".";
6
7console.log(message);
```

Output

```text
Hi Emma, you are invited to our weekly team meeting on Thursday at 10 AM.
```

Here, we've used string concatenation (join with +) to create a dynamic string.

Now, the firstName, event, and time variables can be changed to generate customized messages.

However, as you can see, using string concatenation makes it harder to read the code. So, let's see a cleaner way to do this next.
