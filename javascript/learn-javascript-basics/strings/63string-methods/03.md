## Using The slice() Method

If you omit the second parameter in slice(), it will extract the substring from the start index to the end of the string.

```javascript
1let movie = "Snowpiercer";
2
3let slicedText = movie.slice(5);
4
5console.log(slicedText);    // Output: iercer
```

Here, movie.slice(5) extracts the substring starting from index 5 to the end of the string, resulting in "iercer".

#### Using Negative Value

You can also use negative values to count from the end of the string.

```javascript
1let movie = "Snowpiercer";
2
3let slicedText = movie.slice(-3);
4
5console.log(slicedText);    // Output: cer
```

Here, movie.slice(-3) starts extracting from 3 characters from the end, giving you "cer".
