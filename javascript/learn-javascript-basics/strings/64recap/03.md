#### Accessing String Characters

You can access characters in a string using bracket notation ([ ]) along with their index. For example,

```javascript
1let word = "Hello";
2
3console.log(word[0]);    // Output: H
4
5console.log(word[10]);    // Output: undefined
```

When using [ ], if the character doesn't exist, the output is undefined.

#### The charAt() Method

You can also access characters in a string using the charAt() method. For example,

```javascript
1let word = "Hello";
2
3console.log(word.charAt(1));    // Output: e
4
5console.log(word[10]);    // Output:
```

When using charAt(), if the character doesn't exist, the output is an empty string.
