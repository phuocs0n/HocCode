#### The for Loop

You can loop through string characters using a for loop. For example,

```javascript
1let word = "Hello";
2
3for (let i = 0; i < word.length; i++) {
4  console.log(word[i]);
5}
```

Here, word.length gives the length of the word string, which is used for determining the termination condition of the loop.

#### The for...of Loop

The for...of loop makes looping through string characters very simple. For example,

```javascript
1let word = "Hello";
2
3for (let ch of word) {
4  console.log(ch);
5}
```
