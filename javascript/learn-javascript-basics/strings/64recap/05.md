## Recap (VI)

JavaScript offers a variety of methods to manipulate and perform operations on strings.

In this chapter, you've learned several key methods, including:

- slice()
- concat()
- toUpperCase() and toLowerCase()
- trim()
- replace()
- split()

Example

```javascript
1let sentence = "   Let's learn JavaScript!   ";
2
3let trimmedSentence = sentence.trim()
4console.log(trimmedSentence);
5// Output: Let's learn JavaScript!
6
7console.log(trimmedSentence.slice(0, 5));
8// Output: Let's
9
10console.log(trimmedSentence.concat(" Enjoy!"));
11// Output: Let's learn JavaScript! Enjoy!
12
13console.log(trimmedSentence.toUpperCase());
14// Output: LET'S LEARN JAVASCRIPT!
15
16console.log(trimmedSentence.toLowerCase());
17// Output: let's learn javascript!
18
19console.log(trimmedSentence.replace("javascript", "programming"));
20// Output: let's learn programming.
21
22console.log(trimmedSentence.split(" "));
23// Output: [ "Let's", 'learn', 'JavaScript!' ]
```
