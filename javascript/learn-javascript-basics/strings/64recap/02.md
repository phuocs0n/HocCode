#### Escape Character and Sequences

Escape sequences allow you to perform special operations on strings. Common escape sequences include:

- \n - Newline
- \t - Tab
- \' - Single quote
- \" - Double quote
- \\ - Backslash

Example

```javascript
1console.log("Hello\tWorld");    // Output: Hello    World
2
3let speech = "John said, \"Hello!\"";
4console.log(speech);    // Output: John said, "Hello!"
```
