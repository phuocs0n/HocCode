## The break Statement

The break statement is used to terminate a loop immediately when it is encountered. Here's an example:

```javascript
1// Iterate from 1 to 5
2for (let i = 1; i <= 5; i++) {
3    console.log(i);
4
5    // Stop the loop
6    break;
7}
8
9console.log("This is outside the loop.");
```

Output

```text
1
This is outside the loop.
```

Here's how the code works:

1. The loop starts at i = 1.
2. The value 1 is displayed.
3. The break statement is executed, which terminates the loop immediately.
4. The program then proceeds to the next line outside the loop, printing "This is outside the loop."

Why Use break?

You might wonder why you'd use break since it terminates the loop immediately.

The answer is to stop a loop when a specific condition is met. This is particularly useful when you don't need to continue the loop after achieving a desired result or detecting an error.
