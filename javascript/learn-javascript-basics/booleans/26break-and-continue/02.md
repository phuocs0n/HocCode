## Break with Condition

You can use the break statement in combination with an if condition to terminate a loop when a specific condition is met. Here's an example:

```javascript
1for (let number = 1; number <= 10; number++) {
2    // Stop the loop if the number is 5
3    if (number === 5) {
4        break;
5    }
6    console.log(number);
7}
```

Output

```text
1
2
3
4
```

Here's how the above code works:

1. The loop starts at number = 1 and iterates up to number <= 10.
2. Each number is displayed until the condition number === 5 is met.
3. When number equals 5, the break statement is executed, and the loop terminates.
4. Numbers 1 to 4 are displayed, but the loop stops before printing 5 or continuing further.
