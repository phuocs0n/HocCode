## The if Statement

The syntax for the if statement is:

```javascript
if (boolean_expression) {
    // statement(s)
}
```

Here, the if statement executes the code inside { } based on boolean_expression.

If boolean_expression evaluates to:

- true, the code inside { } is executed.
- false, the code inside { } is skipped.
