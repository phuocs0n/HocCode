## Logical Operators

There are three logical operators in JavaScript:

| Operator | Meaning | Example |
| --- | --- | --- |
| AND (&&) | true if both the expressions are true. | weight > 60 && height > 5.5; |
| OR (||) | true if one of the expressions is true. | weight > 60 || height > 5.5; |
| NOT (!) | true if the expression is false. | !(weight > 60); |
