## The && Operator

The && (AND) operator evaluates to:

- true if both boolean expressions are true
- false if either of the expressions is false

Example

Suppose a bank offers a loan only if the applicant meets both of the following conditions:

- Their credit score is 700 or higher.
- They have a stable income.

In this case, both conditions must be true for the applicant to qualify for the loan. This is where the && operator is applied.

Here's what this condition looks like:

```javascript
let condition = (creditScore >= 700) && (stableIncome == "yes");
```

By the way, it's not necessary to use parentheses. The above code is equivalent to:

```javascript
let condition = creditScore >= 700 && stableIncome == "yes";
```
