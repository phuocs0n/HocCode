## Largest of Three Numbers

Given three numbers n1, n2, and n3, n1 will be the largest number if:

- n1 is greater than n2, and
- n1 is greater than n3

Similarly, you can check if n2 or n3 is largest using the same logic. To solve this problem, you can use the && operator.

Here's the complete code:

```javascript
1// User input
2let n1 = parseInt(prompt("Enter the first number: "));
3let n2 = parseInt(prompt("Enter the second number: "));
4let n3 = parseInt(prompt("Enter the third number: "));
5
6let largest;
7
8// Check if n1 is the largest
9if (n1 >= n2 && n1 >= n3) {
10    largest = n1;
11}
12// Check if n2 is the largest
13else if (n2 >= n1 && n2 >= n3) {
14    largest = n2;
15} else {
16    largest = n3;
17}
18
19console.log("The largest number is:", largest);
```

Sample Output 1

```text
Enter the first number: 10  
Enter the second number: 20  
Enter the third number: 5  
The largest number is: 20
```

Sample Output 2

```text
Enter the first number: 15  
Enter the second number: 15  
Enter the third number: 10  
The largest number is: 15
```
