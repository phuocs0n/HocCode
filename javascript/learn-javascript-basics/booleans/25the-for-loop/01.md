## The for loop

Here's the code we wrote earlier to print numbers from 1 to 5 using a while loop:

```javascript
1// Using a while loop to print numbers from 1 to 5
2let i = 1;
3while (i <= 5) {
4    console.log(i);
5    i++;    // Increment the counter
6}
```

Now, let's rewrite the same code using a for loop:

```javascript
1// Using a for loop to print numbers from 1 to 5
2for (let i = 1; i <= 5; i++) {
3    console.log(i);
4}
```

As you can see, the for loop is more concise and easier to manage when iterating a fixed number of times.
