## Logic to Find Sum of Natural Numbers

Here's how this problem can be solved:

1. Take an integer input: Prompt the user to enter an integer value for n.

```javascript
let n = parseInt(prompt("Enter an integer: "));
```

2. Generate numbers from 1 to n: Use a for loop with the syntax for (let i = 1; i <= n; i++) to generate integers from 1 to n.

```javascript
let n = parseInt(prompt("Enter an integer: "));

for (let i = 1; i <= n; i++) {
    console.log(i);
}
```

3. Initialize the total variable to 0: Before adding up the numbers, initialize the total variable to 0 outside the loop.

```javascript
let n = parseInt(prompt("Enter an integer: "));

let total = 0;

for (let i = 1; i <= n; i++) {
    console.log(i);
}
```

4. Add numbers from the sequence to total: Iterate through the numbers sequence and add each one to the total.

```javascript
let n = parseInt(prompt("Enter an integer: "));

let total = 0;

for (let i = 1; i <= n; i++) {
    // Add each number to the total
    total += i;
}
```

5. Display the total outside the loop: Print the final total only once after the loop completes.

