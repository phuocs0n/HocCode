## Introduction

Just like the while loop, you'll explore another type of loop in this lesson: the for loop.

While both loops execute code repeatedly, the for loop is particularly useful when the number of iterations is known in advance.

Consider a scenario where you need to print numbers from 1 to 5. You know:

- The loop starts at 1
- It stops at 5
- The value increments by 1 in each iteration

In such cases, the for loop is the ideal choice because it allows you to define all these conditions in a single statement.
