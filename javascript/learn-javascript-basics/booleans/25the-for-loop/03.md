## Working of for Loop

Here is the code from the previous page.

```javascript
1// Using a for loop to print numbers from 1 to 5
2for (let i = 1; i <= 5; i++) {
3    console.log(i);
4}
```

Output

```text
1
2
3
4
5
```

Here's how it works:

1. The value of i starts at 1.
2. The loop checks if i <= 5. If true, the loop body executes.
3. The current value of i is displayed.
4. The value of i is updated (incremented by 1).
5. Steps 2–4 repeat until i becomes greater than 5.
6. Once i > 5, the loop stops.

Let's now see the step-by-step execution:

| Variable (i) | i <= 5 | Body of Loop |
| --- | --- | --- |
| i = 1 | true | 1 is displayed. i is increased to 2. |
| i = 2 | true | 2 is displayed. i is increased to 3. |
| i = 3 | true | 3 is displayed. i is increased to 4. |
| i = 4 | true | 4 is displayed. i is increased to 5. |
| i = 5 | true | 5 is displayed. i is increased to 6. |
| i = 6 | false | The loop terminates. |
