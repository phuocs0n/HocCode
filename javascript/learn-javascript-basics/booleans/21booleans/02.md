## Understanding Booleans

Boolean values, true and false, are fixed values similar to numbers like 25 or text like "Hello". Here's what you need to know:

1. Booleans aren't strings

"true" and "false" are strings, but true and false (without quotation marks) are boolean values.

2. Booleans aren't variables

Even though true and false might seem like variable names, they can't be used as variables. For example:

```javascript
1let true = 25;
2console.log(true);
```

Output

```text
SyntaxError: Unexpected token 'true'
```

This error indicates that you can't assign a value to true.

3. Used for decision-making

Computers understand true as yes and false as no. So, programs can decide which action to take based on boolean values.
