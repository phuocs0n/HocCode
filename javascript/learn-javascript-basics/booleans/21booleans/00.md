## Introduction

So far, you've written programs that run step by step in order.

However, in real-world scenarios, programs often need to make decisions and act based on conditions. For example:

- Applying a certain discount when the total amount exceeds a specified limit.
- Reminding to carry an umbrella if it's raining.

In this chapter, you'll learn how to create programs that can make decisions and repeat tasks based on conditions.

To do this, the first step is to understand booleans.
