## Booleans

Booleans are a data type, just like numbers and strings.

However, unlike numbers and strings, which can represent many values, booleans can only have one of two possible values: true or false.

Example

```javascript
1let result1 = true;
2let result2 = false;
3
4console.log(result1);
5console.log(result2);
```

Output

```text
true
false
```

Here, result1 and result2 are variables storing the true and false boolean value, respectively.
