## Example: Multiplication Table

Let's write a program to display the multiplication table for a number up to its 5th multiple. For instance, the multiplication table for 9 would look like this:

```text
9 * 1 = 9
9 * 2 = 18
9 * 3 = 27
9 * 4 = 36
9 * 5 = 45
```

In this table, the multiplier increases by 1 in each step. To achieve this, we'll use a for loop.

Here's the code:

```javascript
1let number = 9;
2
3// Iterate loop from 1 to 5
4for (let multiplier = 1; multiplier <= 5; multiplier++) {
5    // Compute product in each iteration
6    let product = number * multiplier;
7    console.log(`${number} * ${multiplier} = ${product}`);
8}
```

If you execute this program, you'll get the exact output as shown above.
