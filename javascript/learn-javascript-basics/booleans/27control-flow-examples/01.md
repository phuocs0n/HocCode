## Example: Categorize Integer

Let's write a program to categorize an integer into one of the following categories:

1. Negative and odd
2. Negative and even
3. Positive and odd
4. Positive and even
5. Zero

Here's the code:

```javascript
1// Input: Ask the user to enter an integer
2let number = parseInt(prompt("Enter an integer: "));
3
4// Check if the number is positive and even
5if (number > 0 && number % 2 === 0) {
6    console.log("Positive and even");
7}
8// Check if the number is positive and odd
9else if (number > 0 && number % 2 !== 0) {
10    console.log("Positive and odd");
11}
12// Check if the number is negative and even
13else if (number < 0 && number % 2 === 0) {
14    console.log("Negative and even");
15}
16// Check if the number is negative and odd
17else if (number < 0 && number % 2 !== 0) {
18    console.log("Negative and odd");
19}
20// If the number is zero
21else {
22    console.log("The number is zero");
23}
```

Sample Output 1

```text
Enter an integer: -23
Negative and odd
```

Sample Output 2

```text
Enter an integer: 23
Positive and odd
```

Sample Output 3

```text
Enter an integer: 0
The number is zero
```
