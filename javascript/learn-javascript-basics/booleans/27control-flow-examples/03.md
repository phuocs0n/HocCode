## Example: Sum of Odd Numbers

Let's write a program to calculate the sum of odd numbers entered by the user.

Rules:

- Skip even numbers using the continue statement.
- Terminate the program when the user enters 0 using the break statement.

Since we don't know in advance when the user wants to stop, we'll use a while loop to allow repeated inputs.

```javascript
1// Initialize total to 0
2let total = 0;
3
4while (true) {
5    // Get input from the user
6    let number = Number(prompt("Enter a number: "));
7
8    // If the number is 0, terminate the loop
9    if (number === 0) {
10        break;
11    }
12
13    // If the number is even, skip it
14    if (number % 2 === 0) {
15        continue;
16    }
17
18    // Add odd numbers to the total
19    total += number;
20}
21
22console.log(`Total sum of odd numbers: ${total}`);
```

Output

```text
Enter a number: 11
Enter a number: 24
Enter a number: 7
Enter a number: -12
Enter a number: 0
Total sum of odd numbers: 18
```
