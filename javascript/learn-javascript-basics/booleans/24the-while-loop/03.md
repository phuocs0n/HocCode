## Analyzing the While Loop

This is the code from the previous page:

```javascript
1let count = 1;
2
3// Loop continues as long as count is 3 or less
4while (count <= 3) {
5    console.log("I am inside a loop.");
6    console.log("Looping is interesting.");
7}
```

Let's analyze what this program is doing.

- Initially, count is 1. The condition count <= 3 evaluates to true and the loop body is executed.
- Again, count <= 3 is evaluated. As it's still true, the loop body is executed.
- In this program, count <= 3 never becomes false, hence the loop runs forever.

This is called an infinite loop as the condition is never false and the loop runs forever. It also means that the end of the program is never reached.
