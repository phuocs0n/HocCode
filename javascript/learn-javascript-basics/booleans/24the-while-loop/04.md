## Infinite Loops

An infinite loop's condition never evaluates to false. Thus, the previous code is equivalent to:

```javascript
1while (true) {
2    console.log("I am inside a loop.");
3    console.log("Looping is interesting.");
4}
```

However, in most cases, you want the loop to stop after fulfilling its purpose. Ending the loop requires modifying the condition or introducing logic to stop the repetition.

Next, you'll learn how to create loops that terminate properly.
