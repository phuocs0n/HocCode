## The while Loop

The syntax of the while loop is:

```javascript
while (condition) {
    // statement(s)
}
```

The while loop runs the code inside it as long as the condition (a boolean expression) evaluates to true.

Unlike an if statement that only executes once, the while loop repeatedly checks the condition and continues execution until the condition evaluates to false.
