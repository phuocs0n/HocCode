## Example: The while Loop

```javascript
1let count = 1;
2
3// Loop continues as long as count is 3 or less
4while (count <= 3) {
5    console.log("I am inside a loop.");
6    console.log("Looping is interesting.");
7}
```

Here, the body of the loop contains two console.log() statements. We know this because they are enclosed within the braces { } and executed as part of the loop.

If you run this program, the two statements inside the loop are executed again and again.

Output

```text
I am inside a loop.  
Looping is interesting.  
I am inside a loop.  
Looping is interesting.  
...
```
