## Terminating The while Loop

To run the loop only a fixed number of times, you need to update the value of the count variable inside the loop so that count <= 3 eventually evaluates to false. Here's how:

```javascript
1let count = 1;
2
3// Loop continues as long as count is 3 or less
4while (count <= 3) {
5    console.log("I am inside a loop.");
6    console.log("Looping is interesting.");
7
8    // Increment count by 1 in each iteration
9    // Equivalent to: count = count + 1
10    count += 1;
11}
12
13console.log("OUTSIDE THE LOOP");
```

Output

```text
I am inside a loop.
Looping is interesting.
I am inside a loop.
Looping is interesting.
I am inside a loop.
Looping is interesting.
OUTSIDE THE LOOP
```

In this program, count = count + 1 increases the value of count by 1 in each iteration of the loop.

The value of count changes as follows:

- 1 in the first iteration
- 2 in the second iteration
- 3 in the third iteration

When count is updated to 4, the condition count <= 3 evaluates to false, and the loop terminates.

After the loop terminates, the code outside the while loop runs normally.
