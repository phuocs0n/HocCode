## Introduction

You might've seen a rocket launch countdown. When the rocket is about to take off, the countdown goes:

```javascript
100, 99, 98,..., 2, 1, Liftoff!
```

Imagine writing every number manually in your program—sounds tedious, right?

That's where loops come in. Loops automate repetitive tasks, like counting down for a rocket launch, without writing the same code repeatedly. With just a few lines, you can run code multiple times—whether it's 10, 100, or even a million iterations.

JavaScript offers two major types of loops: while and for.

In this lesson, you'll learn to use the while loop to write more efficient and powerful programs.
