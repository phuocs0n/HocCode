## Recap (II)

When working with loops, you often need more control over how the loop runs. This is where the break and continue statements come in handy.

The break Statement

The break statement terminates the loop immediately when it is encountered.

```javascript
1// Print numbers till sum is less than 50
2let sum = 0;
3
4for (let i = 1; i <= 100; i++) {
5
6    sum += i;
7
8    // Terminate loop if sum is greater than 50
9    if (sum >= 50) {
10        break;
11    }
12
13    console.log(i);
14}
```

The continue Statement

The continue statement skips the current iteration and moves directly to the next iteration of the loop.

```javascript
1// Sum of odd numbers till 100
2
3let sum = 0;
4
5for (let i = 1; i <= 100; i++) {
6
7    // Skip even numbers
8    if (i % 2 == 0) {
9        continue;
10    }
11
12    sum += i;
13}
14
15console.log(`Sum of odd numbers till 100: ${sum}`);
```
