## Recap (I)

The if Statement

Instead of simply executing code sequentially, you can use the if statement to perform different tasks based on specified conditions.

```javascript
1let carColor = "black";
2
3if (carColor == "white") {
4    console.log("You have a white car.");
5} else {
6    console.log("You do not have a white car.");
7}
```

The while Loop

You can use loops to execute code repeatedly. The while loop repeats a block of code as long as its condition evaluates to true.

```javascript
1// Program to take input until user enters a positive integer
2let number = parseInt(prompt("Enter an integer:"));
3
4while (number <= 0) {
5    number = parseInt(prompt("Enter an integer:"));
6}
7
8console.log(`Positive number you entered: ${number}`);
```

The for Loop

The for loop is especially handy when the number of iterations is known in advance or iterating through arrays.

```javascript
1// Loop through numbers from 1 to 5
2for (let i = 1; i <= 5; i++) {
3    console.log(i);
4}
```
