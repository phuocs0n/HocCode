#### Local Variables

Variables declared inside a function are local to that function and can't be accessed outside of it.

```javascript
1function addNumbers(n1, n2) {
2    let total = n1 + n2;    // local variable `total`
3}
4
5addNumbers(10, 20);
6
7console.log(total);    // Output: ReferenceError: total is not defined
```

Here, the variable total is local to the addNumbers() function, and while its value is returned, the variable itself cannot be accessed directly outside the function. Attempting to do so results in a ReferenceError.

To use the result, you need to store the returned value in another variable:

```javascript
1function addNumbers(n1, n2) {
2    let total = n1 + n2; 
3    return total;
4}
5
6// Using the returned value outside the function
7let result = addNumbers(10, 20); 
8console.log(result);    // Output: 30
```

#### Arrow Functions

Arrow functions are a concise way to write functions in JavaScript, offering shorter syntax while maintaining the same functionality as regular functions. Let's rewrite addNumbers() using an arrow function:

```javascript
1const addNumbers = (n1, n2) => n1 + n2;
2
3let result = addNumbers(2, 5);
4console.log(result);    // Output: 7
```

You can also write arrow functions like regular functions:

```javascript
1const addNumbers = (n1, n2) => {
2    let total = n1 + n2; 
3    return total; 
4};
5
6let result = addNumbers(2, 5);
7console.log(result);    // Output: 7
```
