#### Arguments and Return Value

Functions can take arguments (inputs) and return values (outputs). These allow functions to be dynamic and reusable.

#### Using Arguments

Arguments are the values you pass into the function when calling it. For example:

```javascript
1function addNumbers(n1, n2) {
2    console.log(n1 + n2);
3}
4
5addNumbers(10, 20);    // Output: 30
```

Here, n1 and n2 are the arguments. The function uses these to calculate the sum.

#### Returning Values

The function returns a value using the return statement. You can store this value in a variable for further use.

```javascript
1function addNumbers(n1, n2) {
2    return n1 + n2;
3}
4
5let result = addNumbers(10, 20);
6
7console.log(result);    // Output: 30
```

In this example, the value 30 is returned from the addNumbers() function and stored in the result variable.
