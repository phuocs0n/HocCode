## Returning Values

Arrow functions don't require the return statement to return values.

Example

```javascript
1// Arrow function to add two numbers
2const addNumbers = (n1, n2) => n1 + n2;
3
4// Call addNumbers()
5let result = addNumbers(2, 5);
6console.log(result);    // Output: 7
```

Here, addNumbers() automatically returns the result of n1 + n2 when called.

This makes arrow functions concise and easier to read, especially for simple operations.
