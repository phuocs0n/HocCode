## Arrow Functions

Here's the previous function:

```javascript
1// Function to add two numbers
2function addNumbers(n1, n2) {
3    return n1 + n2;
4}
5
6let result = addNumbers(2, 5);
7
8console.log(result);    // Output: 7
```

Now the same function will look like this if we use the arrow function:

```javascript
1// Arrow function to add two numbers
2const addNumbers = (n1, n2) => n1 + n2;
3
4let result = addNumbers(2, 5);
5
6console.log(result);    // Output: 7
```

This way, the function fits within a single line.
