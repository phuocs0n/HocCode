## Introduction

Consider this code:

```javascript
1function greet() {
2    console.log("Hello");
3    console.log("How do you do?");
4}
```

Every time you call the above function, it performs the same action–displaying a fixed message. But, wouldn't it be more useful if you could greet different people each time you call greet()?

In JavaScript, you can make functions take input, process it, and return different results based on that input. This makes functions dynamic and enhances their reusability.

In this lesson, you'll learn how to create dynamic functions.

Let's start by making the greet() function dynamic.
