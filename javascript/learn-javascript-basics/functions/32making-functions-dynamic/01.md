## Function Arguments

Here's a slight modification to the greet() function we previously created:

```javascript
1// Function definition
2function greet(name) {
3    console.log(`Hello ${name}`);
4    console.log("How do you do?");
5}
6
7// Function call
8greet("Emma");
```

Output

```text
Hello Emma  
How do you do?
```

When you define the function as function greet(name), two important things happen:

- A function named greet() is created.
- A placeholder variable name is set up inside the function to accept a value (called an argument).

When you call the function using greet("Emma"), the following happens:

- The string "Emma" is passed as an argument to the function.
- This value is assigned to the name variable inside the function.
