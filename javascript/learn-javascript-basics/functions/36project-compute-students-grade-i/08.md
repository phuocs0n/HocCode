## Project: Compute a Student's Grade

The complete code looks like this:

```javascript
1// Find the average score and return it
2const getAverageScore = (s1, s2, s3, s4, s5) => {
3    // Variable for storing total sum
4    let total = s1 + s2 + s3 + s4 + s5;
5    
6    // Compute average score
7    let averageScore = total / 5;
8    
9    return averageScore;
10}
11
12// Returns the grade based on the average score
13const computeGrade = (averageScore) => {
14    let grade;
15
16    if (averageScore >= 80) {
17        grade = "A";
18    } else if (averageScore >= 60) {
19        grade = "B";
20    } else if (averageScore >= 50) {
21        grade = "C";
22    } else {
23        grade = "F";
24    }
25
26    return grade;
27};
28
29// Call function and store result
30let averageScore = getAverageScore(55, 64, 75, 80, 65);
31console.log(`Average Score: ${averageScore}`);
32
33let grade = computeGrade(averageScore);
34console.log(`Grade: ${grade}`);
```

Output

```text
Average Score: 67.8
Grade: B
```

Here,

- The getAverageScore() function first calculates the average score.
- Then, the computeGrade() function uses the average score to compute the grade.
