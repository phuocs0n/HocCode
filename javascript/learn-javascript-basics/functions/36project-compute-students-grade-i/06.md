## Getting Average Score

```javascript
1// Find the average score and return it
2const getAverageScore = (s1, s2, s3, s4, s5) => {
3    // Variable for storing total sum
4    let total = s1 + s2 + s3 + s4 + s5;
5    
6    // Compute average score
7    let averageScore = total / 5;
8    
9    return averageScore;
10}
11
12// Call function and store result
13let averageScore = getAverageScore(55, 64, 75, 80, 65);
14
15console.log(averageScore);    // Output: 67.8
```

Here, the getAverageScore() function

1. Takes five arguments (s1, s2, s3, s4, and s5), which are the student's scores for five different subjects.
2. Calculates total by adding the marks together.
3. Calculated the averageScore by dividing the total marks by 5.
4. Return the averageScore.

Now, let's use the average score to compute the student's grade.
