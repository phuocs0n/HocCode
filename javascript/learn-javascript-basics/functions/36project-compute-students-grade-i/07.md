## Computing Student's Grade

Here's the code to calculate a student's grade based on their score.

```javascript
1const computeGrade = (averageScore) => {
2    let grade;
3
4    if (averageScore >= 80) {
5        grade = "A";
6    } else if (averageScore >= 60) {
7        grade = "B";
8    } else if (averageScore >= 50) {
9        grade = "C";
10    } else {
11        grade = "F";
12    }
13
14    return grade;
15}
16
17let averageScore = 67.8;
18let grade = computeGrade(averageScore);
19console.log(grade);    // Output: B
```

Here, the computeGrade() function computes the student's grade based on the average score.

In the program, we've directly assigned a fixed average score to a variable. However, you want the average score to be computed based on the student's scores.

To fix this problem, you need to put the functions in a single program.
