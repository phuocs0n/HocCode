## Example: Sum of Natural Numbers From 1 to n

In this program, we want to calculate the sum of the first n natural numbers. So, if we take n = 5, for example, the sum would be:

```javascript
total = 1 + 2 + 3 + 4 + 5
```

Now, let's think about how we can do this. We'll need to pass in the number n to our function, which will calculate the sum. Once we get the result, we can return it for use elsewhere in the program.

#### Arguments and Return Value

Argument: The function will take one argument, n, which represents the number up to which we want to calculate the sum.

Return Value: The function will return the total sum of the numbers from 1 to n.

Now that we have a clear idea, let's write the program:

```javascript
1function computeSum(n) {
2    let total = 0;
3
4    // Loop from 1 to n
5    for (let i = 1; i <= n; i++) {
6        total += i;
7    }
8
9    return total;
10}
11
12// Example calls to the function
13let sum1 = computeSum(10);
14console.log(sum1);    // Output: 55
15
16let sum2 = computeSum(100);
17console.log(sum2);    // Output: 5050
```
