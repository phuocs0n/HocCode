## Introduction

Here's a function we previously created:

```javascript
1function addNumbers(n1, n2) {
2    let result = n1 + n2;
3    console.log(result);
4}
5
6addNumbers(2, 5);
```

You might guess the output of the above program is 7 and you're correct. But, can you guess the output for the below program?

```javascript
1function addNumbers(n1, n2) {
2    let result = n1 + n2;
3}
4
5addNumbers(2, 5);
6
7console.log(result);
```

Here, the output is an error because the result variable is defined inside the function. However, we're trying to access and display result outside the function, where it doesn't exist.

This example highlights the importance of understanding variable scope—where a variable is declared and where it can be accessed.
