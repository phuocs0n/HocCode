## Local Variables

Any variable created inside a function is local to that function. This means the variable only exists within the function and is inaccessible outside it.

```javascript
1function addNumbers(n1, n2) {
2    let result = n1 + n2;
3}
4
5addNumbers(2, 5);
6
7console.log(result);    
8// Output: ReferenceError: result is not defined
```

When the execution of the addNumbers() function ends, all variables inside it (n1, n2, and result) are destroyed.

This is why the program throws an error—JavaScript cannot find the result variable since it's local to the function.

If you remember, you can fix it by using a return statement.

```javascript
1function addNumbers(n1, n2) {
2    let result = n1 + n2;
3    return result;
4}
5
6let output = addNumbers(2, 5);
7console.log(output);    // Output: 7
```

Here, the return statement allows you to send the value of the local variable (result) to the function call. Instead of directly accessing the local variable, you use its value.
