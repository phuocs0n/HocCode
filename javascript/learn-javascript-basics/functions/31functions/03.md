## Calling a Function

Creating a function only makes the code available for use whenever needed.

To execute this function, you need to call (or invoke) it. Here's how:

```javascript
1// Function definition
2function greet() {
3    console.log("Hello");
4    console.log("How do you do?");
5}
6
7// Function call
8greet();
9
10console.log("Next statement");
```

Output

```text
Hello
How do you do?
Next statement
```

In this program, we call the function using its name followed by parentheses: greet().
