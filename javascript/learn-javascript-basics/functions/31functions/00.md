## Introduction

Consider this program to calculate the total for a customer after applying a 10% discount:

```javascript
1let total = parseFloat(prompt("Total? "));
2let discountPercent = 10;
3
4if (total > 100) {
5    let excess = total - 100;  
6    let discount = (discountPercent / 100) * excess;  
7    total -= discount;  
8}
9
10console.log(`The final amount to pay is: $${total}`);
```

Now, suppose you needed to do this for multiple customers. You'd need to repeat the same code for each one, making your program repetitive, longer, and inefficient.

Wouldn't it be better if you could write the code once and reuse it for every customer?

That's where functions come in. They make code reusable, modular, and easier to maintain.

In this lesson, you'll learn what functions are, how to create them, and how to use them.

Let's start by exploring how to create a function.
