## Creating a Class

As programs grow, you need a clean way to bundle data and behavior together. ES6 classes give you a blueprint for creating objects that share the same structure and methods. Here is the basic syntax:

```javascript
class ClassName {
    constructor(param1, param2) {
        this.property1 = param1;
        this.property2 = param2;
    }

    methodName() {
        // operates on this instance
    }
}

const instance = new ClassName(value1, value2);
```

A class starts with the class keyword, followed by a name. Inside, a special constructor method runs when you create a new instance with new. You define methods directly inside the class body - no commas, no function keyword.

For example,

```javascript
1class Ball {
2    constructor(x, y, radius) {
3        this.x = x;
4        this.y = y;
5        this.radius = radius;
6        this.speed = 3;
7    }
8
9    move(dx, dy) {
10        this.x += dx;
11        this.y += dy;
12    }
13
14    describe() {
15        return `Ball at (${this.x}, ${this.y}) with radius ${this.radius}`;
16    }
17}
18
19const ball = new Ball(400, 300, 10);
20console.log(ball.describe());
21
22ball.move(5, -2);
23console.log(ball.describe());
```

Here, Ball is a class with a constructor that sets up initial properties and two methods - move and describe. Notice the template literal from Chapter 1 at work inside describe(). Calling new Ball(400, 300, 10) creates an object with those properties, and the methods operate on that specific instance. It is good practice to capitalize class names so they stand out as blueprints, not regular functions.
