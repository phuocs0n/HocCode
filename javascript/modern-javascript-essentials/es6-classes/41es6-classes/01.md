## Multiple Instances

The real power of a class shows up when you create multiple instances from the same blueprint. Each instance gets its own copy of the properties set in the constructor, but they all share the same methods.

For example,

```javascript
1class Task {
2    constructor(title, priority, category) {
3        this.title = title;
4        this.priority = priority;
5        this.category = category;
6        this.done = false;
7    }
8
9    complete() {
10        this.done = true;
11    }
12
13    describe() {
14        return `${this.category}: ${this.title} [${this.priority}] - ${this.done ? "done" : "pending"}`;
15    }
16}
17
18const task1 = new Task("Fix login bug", "high", "dev");
19const task2 = new Task("Update docs", "low", "docs");
20
21task1.complete();
22
23console.log(task1.describe());
24console.log(task2.describe());
```

Here, task1 and task2 are separate instances of the same Task class. Calling complete() on task1 sets its done property to true, but task2 is unaffected. Each instance tracks its own state independently. Remember Array.from from Chapter 3? That is exactly how you would generate a full list of tasks in a single expression - Array.from({ length: 5 }, (_, i) => new Task(...)) builds an entire collection from one class.
