## Welcome to Modern JavaScript

Hi there! 👋

Welcome to Modern JavaScript Essentials.

If you've written JavaScript before, you've probably noticed something confusing: code examples online look very different from each other. Some use var, others use let and const. Some have function everywhere, others have these => arrow things. Some loop with for, others use methods like .map() and .filter().

This isn't because developers can't agree on how to write code. It's because JavaScript evolved dramatically in 2015 with a major update called ES6 (ECMAScript 2015). This update introduced modern features that make code cleaner, safer, and easier to maintain.
