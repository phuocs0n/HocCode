## Template Literals

Building strings by joining variables with + gets messy fast. Template literals use backticks instead of quotes and let you embed expressions directly with ${}. Here is the syntax:

```javascript
`text ${expression} more text`
```

Anything inside ${} is evaluated as JavaScript - variables, math, even function calls. The result is inserted into the string automatically.

Let's see template literals in action.

For example,

```javascript
1const name = "Abidit"; 
2const role = "instructor"; 
3const message = `Hi, I am ${name} and I am your ${role}.`;
4
5console.log(message);
```

Here, ${name} and ${role} are replaced with their values when the string is evaluated. You can put any valid JavaScript expression inside ${}, including math and function calls. It is good practice to use template literals over string concatenation in modern codebases.

They are easier to read, less error-prone, and support multiline strings without escape characters.

For example,

```javascript
1const message = `Welcome to Modern JavaScript.
2This message spans
3multiple lines without using \n.`;
4
5console.log(message);
```
