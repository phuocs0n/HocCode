## Cloning Arrays with Spread

Spread also creates genuine copies of arrays. Modifying the copy will not affect the original.

For example,

```javascript
1 const original = [1, 2, 3]; 
2const copy = [...original];
3
4copy.push(4);
5
6console.log(original); 
7console.log(copy);
```

Here, pushing to copy does not change the original because spread creates a shallow copy. Use spread whenever you need to copy and combine arrays. It is shorter and easier to read than the older ways of doing it like concat or slice.
