## forEach

Arrays become truly powerful when you can run logic across every element without writing a manual loop. forEach runs a function on each element but returns nothing.

To simplify, we use it when we want to do something with each element like printing it or saving it, but do not need a new array back.

Notice how the function inside uses the arrow syntax you learned in Chapter 1.

```javascript
1const scores = [80, 45, 92, 67];
2
3scores.forEach(score => console.log(score));
```

Here, forEach walks through scores one item at a time and logs each value. It does not produce a new array - it simply performs an action on each element.
