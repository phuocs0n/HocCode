## Object Destructuring

Destructuring lets you extract properties from an object and assign them to variables in a single statement. Instead of accessing each property with dot notation one by one, you list the names you need inside curly braces on the left side of the assignment.

```javascript
const { property1, property2 } = sourceObject;
```

The variable names must match the property names on the object. Let's see it in action.

For example,

```javascript
1const user = { name: "Abidit", age: 25, role: "developer" };
2
3const { name, age, role } = user;
4
5console.log(name);
6console.log(age);
7console.log(role);
```

You can also set default values during destructuring in case a property is missing. If a property does not exist and you do not provide a default value, the destructured variable becomes undefined.

For example,

```javascript
1const settings = { fontSize: 16 };
2
3const { fontSize, theme = "dark" } = settings;
4
5console.log(fontSize);
6console.log(theme);
```

Here, theme does not exist on the settings object, so the default value "dark" is used instead. I reach for destructuring whenever I need more than one property from the same object.

It makes function parameters clearer and keeps the code flat instead of nesting dot-notation chains. In any real application where objects carry configuration, user data, or API responses, destructuring cuts down on repetitive dot-notation references throughout your code.
