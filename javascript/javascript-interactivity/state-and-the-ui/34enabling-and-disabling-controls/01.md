# Disabling Slider Buttons

#### Course: Make Your Website Interactive with JavaScript

## Disabling Slider Buttons

This example adds boundary control to the slider.

When the first slide is active, Prev is disabled. When the last slide is active, Next is disabled.

The disabled state updates every time showSlide() runs.

```html
1<!DOCTYPE html>
2<html lang="en">
3<head>
4 <meta charset="UTF-8" />
5 <title>Slider Controls</title>
6 <link rel="stylesheet" href="style.css" />
7</head>
8<body>
9
10 <div class="slider">
11   <div class="slider-track">
12     <div class="slide">Slide 1</div>
13     <div class="slide">Slide 2</div>
14     <div class="slide">Slide 3</div>
15   </div>
16 </div>
17
18 <button id="prev">Prev</button>
19 <button id="next">Next</button>
20
21 <script src="script.js"></script>
22</body>
23</html>
```

```javascript
1var currentSlideIndex = 0;
2var track = document.querySelector('.slider-track');
3var slides = document.querySelectorAll('.slide');
4var prevBtn = document.querySelector('#prev');
5var nextBtn = document.querySelector('#next');
6
7function showSlide(index) {
8  if (!track) return;
9
10  // Clamp index
11  currentSlideIndex = Math.max(0, Math.min(index, slides.length - 1));
12
13  // Move track
14  track.style.marginLeft = -(currentSlideIndex * 100) + '%';
15
16  // Update disabled state
17  if (prevBtn) {
18    prevBtn.disabled = currentSlideIndex === 0;
19  }
20
21  if (nextBtn) {
22    nextBtn.disabled = currentSlideIndex === slides.length - 1;
23  }
24}
25
26if (prevBtn) {
27  prevBtn.addEventListener('click', function () {
28    showSlide(currentSlideIndex - 1);
29  });
30}
31
32if (nextBtn) {
33  nextBtn.addEventListener('click', function () {
34    showSlide(currentSlideIndex + 1);
35  });
36}
37
38// Initialize
39showSlide(0);
```

Click Run Code. Click through the slides and watch the buttons.

At the first slide, Prev goes quiet. At the last slide, Next does the same.

One function controls it all. The state decides:

- Which slide is visible
- Which buttons are enabled
