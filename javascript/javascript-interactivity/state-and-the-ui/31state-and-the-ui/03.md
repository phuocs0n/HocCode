## A Simple Counter

Before building a full slider, let's start small.

In this example, we keep track of a number. Every time you click the button, the number increases. That number is the state.

```html
1<!DOCTYPE html>
2<html lang="en">
3<head>
4  <meta charset="UTF-8" />
5  <title>State Example</title>
6</head>
7<body>
8
9  <p>Count: <span id="count">0</span></p>
10  <button id="increase">Increase</button>
11
12  <script src="script.js"></script>
13</body>
14</html>
```

```css
1body {
2  font-family: sans-serif;
3  padding: 20px;
4}
5
6button {
7  padding: 8px 12px;
8  cursor: pointer;
9}
```

```javascript
1var count = 0;
2
3var display = document.querySelector('#count');
4var button = document.querySelector('#increase');
5
6if (button && display) {
7  button.addEventListener('click', function () {
8    count += 1;
9    display.textContent = count;
10  });
11}
```

Click Run Code. Each click increases the number.

Notice what is happening:

- The variable count  stores the state
- The page only shows whatever count is
- We update the variable first.
- Then we update the DOM

The variable leads. The page follows.
