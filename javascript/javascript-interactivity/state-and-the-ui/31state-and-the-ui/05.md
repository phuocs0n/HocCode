## Controlling Which Section Is Visible

Now let's apply state to work on something real.

Three panels, but only one should be visible at a time. When the user clicks Next or Prev, the visible panel changes.

Instead of guessing which panel to show, we store that information in a variable. That variable becomes the state.

Here's a complete example.

```html
1<!DOCTYPE html>
2<html lang="en">
3<head>
4  <meta charset="UTF-8" />
5  <title>State — tabs</title>
6  <link rel="stylesheet" href="style.css" />
7</head>
8<body>
9
10  <button id="prev">Prev</button>
11  <button id="next">Next</button>
12
13  <div class="panel">Panel 1</div>
14  <div class="panel">Panel 2</div>
15  <div class="panel">Panel 3</div>
16
17  <script src="script.js"></script>
18</body>
19</html>
```

```css
1body {
2  font-family: sans-serif;
3  padding: 20px;
4}
5
6.panel {
7  display: none;
8  padding: 16px;
9  border: 1px solid #E2E8F0;
10  margin-top: 8px;
11}
12
13.panel:first-of-type {
14  display: block;
15}
```

```javascript
1var currentIndex = 0;
2var panels = document.querySelectorAll('.panel');
3
4function showPanel(index) {
5  currentIndex = Math.max(0, Math.min(index, panels.length - 1));
6
7  for (var i = 0; i < panels.length; i++) {
8    panels[i].style.display = i === currentIndex ? 'block' : 'none';
9  }
10}
11
12document.querySelector('#prev').addEventListener('click', function () {
13  showPanel(currentIndex - 1);
14});
15
16document.querySelector('#next').addEventListener('click', function () {
17  showPanel(currentIndex + 1);
18});
19
20showPanel(0);
```

Click Run Code.

When you click Next or Prev, only one panel remains visible.

Here's what's happening:

- currentIndex stores which panel is active.
- showPanel updates that value and ensures it stays within range.
- Then it updates the DOM so only the correct panel is visible.

The variable holds the state. The UI reflects it.
