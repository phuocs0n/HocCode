## The Toggle Pattern

You have seen this before. Now let's name it properly.Many interface elements have only two states:

- Open / closed
- Visible / hidden
- Expanded / collapsed

To switch between these states, we toggle a class.

You can use:

```javascriptDOM
element.classList.toggle('is-open');
```

If the class is missing, it gets added. If it already exists, it gets removed.

One click changes the state. The next click switches it back.

JavaScript decides which state is active. CSS reflects that state visually.

Simple, Predictable, and Reusable. That is what makes this pattern worth knowing by heart.

Next, you'll see how to make this interaction feel smooth using CSS transitions.
