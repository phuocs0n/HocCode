## Classes vs Inline Styles for Visibility

In the previous lesson, you learned that state controls what the user sees.

Now let's talk about how to apply that state cleanly.

You could change styles directly in JavaScript:

```javascriptDOM
element.style.display = 'none';
```

That works.

But a cleaner approach is to use CSS classes instead. Add or remove a class like is-open and let CSS decides how that class looks.

JavaScript controls the state.CSS controls the appearance.

As a rule:

- Use classes for named states like open or closed.
- Use inline styles only when a value is calculated dynamically.

That separation keeps your code predictable and easy to maintain.
