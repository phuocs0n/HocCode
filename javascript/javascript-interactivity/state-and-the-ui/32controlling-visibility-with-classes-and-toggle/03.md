## Smooth Expand with CSS

Toggling a class changes the state. But right now that change is instant

Let's make that state change feel smooth.

For something like a "Read more" section, you don't need to animate anything in JavaScript. CSS can handle it entirely on its own.

For example:

```javascriptDOM
.expand-wrap {
  overflow: hidden;
  max-height: 0;
  transition: max-height 0.3s ease;
}

.expand-wrap.is-expanded {
  max-height: 200px;
}
```

When the class is-expanded is added, the element expands smoothly. When it is removed, it collapses back.

JavaScript only toggles the class. CSS handles the animation.

That is the separation working exactly as it should. Your code stays simple. Your interface feels polished.
