## Smooth Expand in Action

Let's see it all come together.

```html
1<!-- index.html -->
2<!DOCTYPE html>
3<html lang="en">
4<head>
5  <meta charset="UTF-8" />
6  <title>Read more — smooth expand</title>
7  <link rel="stylesheet" href="style.css" />
8</head>
9<body>
10  <p>Short teaser text here.</p>
11
12  <div class="expand-wrap">
13    <p>Full content that appears when you click Read more. CSS handles the smooth transition.</p>
14  </div>
15
16  <button class="read-more-btn">Read more</button>
17
18  <script src="script.js"></script>
19</body>
20</html>
```

```css
1body {
2  font-family: sans-serif;
3  padding: 20px;
4  max-width: 400px;
5}
6
7.expand-wrap {
8  overflow: hidden;
9  max-height: 0;
10  transition: max-height 0.3s ease;
11}
12
13.expand-wrap.is-expanded {
14  max-height: 200px;
15}
16
17.read-more-btn {
18  margin-top: 8px;
19  padding: 6px 12px;
20  cursor: pointer;
21}
```

```javascript
1// script.js
2var btn = document.querySelector('.read-more-btn');
3var wrap = document.querySelector('.expand-wrap');
4
5if (btn && wrap) {
6  btn.addEventListener('click', function () {
7    var isExpanded = wrap.classList.toggle('is-expanded');
8    btn.textContent = isExpanded ? 'Show less' : 'Read more';
9  });
10}
```

Click Run Code.

When you click the button, watch the section expand smoothly. Click again, and it collapses back.

JavaScript changes the state. CSS handles the animation.

Notice the button text changed too. That is state working on two things at once, the section and the label, from a single toggle.

Next, you'll answer a quick quiz to reinforce why this approach is cleaner than setting height directly in JavaScript.
