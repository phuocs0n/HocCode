## Navigating Slides with Prev and Next

The slider moves. Now let's give the user control.

A slider becomes interactive when users can move forward and backward through the slides.

The buttons do not move the track directly.

They update the state.

When the user clicks:

- Prev → decrease the index
- Next → increase the index

Both buttons call the same function: showSlide().

That function:

- Keeps the index within a valid range
- Updates currentSlideIndex
- Moves the track so the correct slide appears

State changes first. Then the DOM reflects it.

Developer Insight

Clamping the index inside showSlide() instead of inside each button handler keeps your logic centralized.

This means:

- You cannot forget to clamp later
- Keyboard controls or swipe gestures can reuse the same function
- All state control stays in one predictable place

That makes your slider easier to extend and maintain.
