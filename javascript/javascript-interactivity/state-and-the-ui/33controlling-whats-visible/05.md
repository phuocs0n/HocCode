## Interactive Slider Controls

Let's see it all come together.

This example connects the slider to the Prev and Next buttons.

```html
1<!DOCTYPE html>
2<html lang="en">
3<head>
4  <meta charset="UTF-8" />
5  <title>Interactive Slider</title>
6  <link rel="stylesheet" href="style.css" />
7</head>
8<body>
9
10  <div class="slider">
11    <div class="slider-track">
12      <div class="slide">Slide 1</div>
13      <div class="slide">Slide 2</div>
14      <div class="slide">Slide 3</div>
15    </div>
16  </div>
17
18  <button id="prev">Prev</button>
19  <button id="next">Next</button>
20
21  <script src="script.js"></script>
22</body>
23</html>
```

```css
1body {
2  margin: 0;
3  font-family: sans-serif;
4  padding: 20px;
5}
6
7.slider {
8  overflow: hidden;
9  width: 100%;
10}
11
12.slider-track {
13  display: flex;
14  width: 300%;
15  transition: margin-left 0.3s ease;
16}
17
18.slide {
19  flex: 0 0 33.333%;
20  padding: 40px 20px;
21  text-align: center;
22  border: 1px solid #E2E8F0;
23  box-sizing: border-box;
24}
25
26button {
27  margin-top: 12px;
28  margin-right: 8px;
29  padding: 8px 16px;
30  cursor: pointer;
31}
```

```javascript
1var currentSlideIndex = 0;
2var track = document.querySelector('.slider-track');
3var slides = document.querySelectorAll('.slide');
4var prevBtn = document.querySelector('#prev');
5var nextBtn = document.querySelector('#next');
6
7function showSlide(index) {
8  if (!track) return;
9
10  currentSlideIndex = Math.max(0, Math.min(index, slides.length - 1));
11  track.style.marginLeft = -(currentSlideIndex * 100) + '%';
12}
13
14if (prevBtn) {
15  prevBtn.addEventListener('click', function () {
16    showSlide(currentSlideIndex - 1);
17  });
18}
19
20if (nextBtn) {
21  nextBtn.addEventListener('click', function () {
22    showSlide(currentSlideIndex + 1);
23  });
24}
25
26showSlide(0);
```

Click Run Code. Click Prev and Next.

When a button is clicked, the index changes. When the index changes, the track moves. Only one slide remains visible at a time.

The buttons do not touch the track. They only change a number. showSlide() does the rest.
