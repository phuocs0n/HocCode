## How the Slider Layout Works

Before the slider can move, it needs to be built correctly.

A basic slider has three parts:

- A container
- A track
- Slides inside the track

The container hides overflow. The track holds all slides in a row. Each slide takes up one full visible width.

```html
1<!DOCTYPE html>
2<html lang="en">
3<head>
4 <meta charset="UTF-8" />
5 <title>Slider — one visible</title>
6 <link rel="stylesheet" href="style.css" />
7</head>
8<body>
9 <div class="slider">
10   <div class="slider-track">
11     <div class="slide">Slide 1</div>
12     <div class="slide">Slide 2</div>
13     <div class="slide">Slide 3</div>
14   </div>
15 </div>
16 <script src="script.js"></script>
17</body>
18</html>
```

```css
1.slider {
2  overflow: hidden;
3  width: 100%;
4}
5
6.slider-track {
7  display: flex;
8  width: 300%;
9  transition: margin-left 0.3s ease;
10}
11
12.slide {
13  flex: 0 0 33.333%;
14}
```

```javascript
1// script.js
```

In this layout:

- The track is 300% wide because there are three slides.
- Each slide takes up one third of the track.
- The container hides anything outside its visible area.

Right now, nothing moves. The structure is in place.

Next, you will connect state to movement so the track shifts and different slides come into view.
