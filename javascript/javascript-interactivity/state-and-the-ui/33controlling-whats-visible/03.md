## Displaying One Project at a Time

Now apply the state pattern to the project slider.

Keep a variable called currentSlideIndex. 0 represents the first card.

Create a showSlide(index) function that does three things:

- Keeps the index within a valid range.
- Updates currentSlideIndex.
- Updates the DOM so the correct slide is visible.

If each slide takes up 100% of the visible width, you can move the track like this:

```javascriptDOM
(currentSlideIndex * 100) + '%'
```

```html
1<!DOCTYPE html>
2<html lang="en">
```

```css
1body { margin: 0; font-family: sans-serif; }
2
3.slider { 
4  overflow: hidden; 
5  width: 100%; 
6}
7
8.slider-track { 
9  display: flex; 
10  transition: margin-left 0.3s ease; 
11  width: 300%; 
12}
13
14.slide { 
15  flex: 0 0 33.333%; 
16  padding: 40px 20px; 
17  text-align: center; 
18  border: 1px solid #E2E8F0; 
19  box-sizing: border-box; 
20}
```

```javascript
1var currentSlideIndex = 0;
2var track = document.querySelector('.slider-track');
3var slides = document.querySelectorAll('.slide');
4
5function showSlide(index) {
6  if (!track) return;
7
8  // Keep index within range
9  currentSlideIndex = Math.max(0, Math.min(index, slides.length - 1));
10
11  // Move track so correct slide appears
12  track.style.marginLeft = -(currentSlideIndex * 100) + '%';
13}
14
15// Show first slide on load
16showSlide(0);
```

Call showSlide(0) once when the page loads so the first slide is visible.

The variable holds the state. The DOM reflects it.
