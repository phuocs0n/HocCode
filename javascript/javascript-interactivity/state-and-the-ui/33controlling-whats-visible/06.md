#### Course: Make Your Website Interactive with JavaScript

## Expand Details in Project Card

The slider controls which project card is visible.

Now each card needs its own interaction.

Every project card includes:

- A short teaser
- A Read more button
- A full description hidden by default

When the button is clicked, the full description should expand smoothly.

The interaction follows the same toggle pattern used earlier. When clicked:

- Toggle the class  .is-expanded on .project-description-wrap
- Change the button text "Read more" when collapsed and "Show less" when expanded
- Update the aria-expanded attribute to match the state

JavaScript only changes the state. CSS handles the smooth max-height transition.

The Case Study and Live Demo links remain normal links. There is no modal and no navigation change.

This behavior should work independently for each project card.

You can either:

- Loop over all cards and attach listeners
- Or attach one listener per button

Next, you will implement this interaction on the project cards.
