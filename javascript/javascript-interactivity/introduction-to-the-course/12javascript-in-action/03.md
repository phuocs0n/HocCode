## Connecting JS to Your Site

Your portfolio is built. Now it is time to plug JavaScript in.

To use JavaScript, you need to connect a JavaScript file to your HTML. You do that with the <script> tag.

We add it just before the closing </body> tag.

```html
1<!DOCTYPE html>
2<html lang="en">
3<head>
4  <meta charset="UTF-8" />
5  <title>Connecting JavaScript</title>
6  <link rel="stylesheet" href="style.css" />
7</head>
8<body>
9
10  <h1>Hello</h1>
11
12  <script src="script.js"></script>
13</body>
14</html>
```

```javascript
1console.log("JavaScript is connected.");
```

We add the script before </body> because the browser reads the page from top to bottom.

First, the HTML loads.

Then JavaScript runs.

If the script runs before the elements are created, JavaScript cannot find them. Placing it at the bottom makes sure everything already exists when the code runs.

The src attribute tells the browser which file to load and run.

Now, click on the script.js tab and click Run Code. You will not see anything change on the page yet, and that is fine.

Click the Console tab. You should see the message:

```text
JavaScript is connected.
```

That confirms your file is properly linked. Your portfolio and JavaScript are now talking to each other.
