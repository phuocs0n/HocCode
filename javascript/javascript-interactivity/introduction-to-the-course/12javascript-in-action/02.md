## What Can JavaScript Do?

So far, you have built pages that look good.

But looking good is only half the job.

JavaScript handles the other half. It is what makes a page respond to the person using it. When they click, something reacts. When they scroll, something follows. When they type, something listens.

With JavaScript, you can:

1. Respond to user actions like clicks, scrolling, and typing
2. Change content without reloading the page
3. Show or hide elements
4. Update text dynamically

This is where your website stops being a poster and starts being a product.
