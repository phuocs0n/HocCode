## Selecting Elements

Before you can change something, you have to find it.

That is the first step of the pattern. Let's look at a small example.

```html
1<!DOCTYPE html>
2<html lang="en">
3<head>
4  <meta charset="UTF-8" />
5  <title>Selecting Elements</title>
6  <link rel="stylesheet" href="style.css" />
7</head>
8<body>
9
10  <p id="main">Main paragraph</p>
11  <p class="item">Item 1</p>
12  <p class="item">Item 2</p>
13  <p class="item">Item 3</p>
14
15  <script src="script.js"></script>
16</body>
17</html>
```

```css
1body {
2  font-family: sans-serif;
3  padding: 20px;
4}
```

```javascript
1var firstItem = document.querySelector('.item');
2var allItems = document.querySelectorAll('.item');
3var main = document.getElementById('main');
4
5if (firstItem) {
6  firstItem.textContent = 'First item updated';
7}
8
9if (main) {
10  main.textContent = 'Main updated by id';
11}
```

Click Run Code. You'll notice two things:

The paragraph with id main changes to "Main updated by id". Only the first .item changes to "First item updated". The other two items stay the same.

Here's why. Switch to the script.js tab.

- querySelector('.item') selects only the first matching element. Even though there are three .item elements, it stops at the first one.
- querySelectorAll('.item') selects all matching elements and returns a list. We're not using that list yet, but we will soon.
- getElementById('main') selects the element with that specific id. Since ids are unique, it returns just one element.

You select exactly what you need. Then you update it.

That is the pattern holding steady.
