## Dark Mode with a Class Toggle

Dark mode is just a theme.

Instead of changing styles one-by-one in JavaScript, you flip the page into a different state using a single class.

- Light theme is the default.
- Dark theme is the same page, but with one extra class on the body.

That's why this feels so clean.

JavaScript only does one job: It toggles a class.

CSS does the real work: It defines what the dark theme looks like when that class exists.

Next, you'll see a runnable example where a button toggles a dark class on the page, and the colors change instantly.
