# Example Filtering by Category

#### Course: Make Your Website Interactive with JavaScript

## Example Filtering by Category

Let's see it work.

When a button is clicked, the active category changes. The cards update automatically to match it.

```html
1<!DOCTYPE html>
2<html lang="en">
3<head>
4  <meta charset="UTF-8" />
5  <title>Filter</title>
6  <link rel="stylesheet" href="style.css" />
7</head>
8<body>
9
10  <div class="filters">
11    <button type="button" class="filter-btn" data-filter="all">All</button>
12    <button type="button" class="filter-btn" data-filter="web">Web</button>
13  </div>
14
15  <div class="card" data-category="web">Web</div>
16  <div class="card" data-category="other">Other</div>
17
18  <script src="script.js"></script>
19</body>
20</html>
```

```css
1body {
2  font-family: sans-serif;
3  padding: 16px;
4}
5
6.filters {
7  margin-bottom: 12px;
8}
9
10.card {
11  padding: 12px;
12  margin: 8px 0;
13  border: 1px solid #E2E8F0;
14}
15
16.card.hidden {
17  display: none;
18}
```

```javascript
1var activeFilter = 'all';
2var cards = document.querySelectorAll('.card');
3var buttons = document.querySelectorAll('.filter-btn');
4
5function applyFilter() {
6  cards.forEach(function (card) {
7    var category = card.dataset.category;
8    var show = activeFilter === 'all' || category === activeFilter;
9    card.classList.toggle('hidden', !show);
10  });
11}
12
13buttons.forEach(function (btn) {
14  btn.addEventListener('click', function () {
15    activeFilter = btn.dataset.filter;
16    applyFilter();
17  });
18});
19
20// Initialize on load
21applyFilter();
```

Click Run Code first. Then click All and Web and watch the cards update.

Here is what is happening under the surface.

In the CSS, this rule controls visibility:

```javascriptDOM
.card.hidden {
  display: none;
}
```

Nothing else hides the card. JavaScript only adds or removes this hidden class.

In JavaScript, this line stores the current filter:

```javascriptDOM
var activeFilter = 'all';
```

That variable represents the current state. When a button is clicked, this line updates that state:

```javascriptDOM
activeFilter = btn.dataset.filter;
```

And this line inside applyFilter() does the work:

```javascriptDOM
card.classList.toggle('hidden', !show);
```

This is the key part.

- If show is false, the hidden class is added.
- If show is true, the hidden class is removed.

The browser handles how it looks. JavaScript only decides which class should be present.

So the flow is simple:

- Update the state.
- Then update the UI.

Next, you'll see the same idea used to switch the entire page theme to dark mode.
