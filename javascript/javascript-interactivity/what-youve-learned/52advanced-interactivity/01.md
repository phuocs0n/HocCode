## Filtering and Showing/Hiding by Category

Imagine clicking a button and instantly seeing only the projects that match a category like Web or Mobile.

That's filtering. And even though it feels like a new feature, the logic behind it isn't new at all.

There's simply one value that represents the selected category. When that value changes, the page updates to reflect it.

Each project card stores its own category. When a filter button is clicked, the active category changes. Then the cards update so only the matching ones remain visible.

The browser handles how things look. JavaScript just decides what should be shown.

Same pattern. Change the state. Update the UI.
