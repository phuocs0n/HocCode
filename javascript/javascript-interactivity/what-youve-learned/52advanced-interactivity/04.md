#### Course: Make Your Website Interactive with JavaScript

## Runnable Example Dark Mode Toggle

In this example, one button switches the entire page between light and dark.

There is no complex logic. One click changes the state.

```html
1<!DOCTYPE html>
2<html lang="en">
3<head>
4  <meta charset="UTF-8" />
5  <title>Dark mode</title>
6  <link rel="stylesheet" href="style.css" />
7</head>
8<body>
9
10  <p>Page content.</p>
11  <button type="button" class="dark-toggle">Dark mode</button>
12
13  <script src="script.js"></script>
14</body>
15</html>
```

```css
1body {
2  font-family: sans-serif;
3  padding: 20px;
4  background: #ffffff;
5  color: #1e293b;
6  transition: background 0.2s ease, color 0.2s ease;
7}
8
9body.dark {
10  background: #1e293b;
11  color: #f1f5f9;
12}
```

```javascript
1var toggle = document.querySelector('.dark-toggle');
2
3if (toggle) {
4  toggle.addEventListener('click', function () {
5    document.body.classList.toggle('dark');
6  });
7}
```

Click Run Code. Then click the Dark mode button. The page switches to dark. Click again. It switches back.

In the CSS, this part defines the dark theme:

```javascriptDOM
body.dark {
  background: #1e293b;
  color: #f1f5f9;
}
```

When the dark class exists on the body, these styles apply. Nothing in JavaScript changes colors directly.

In JavaScript, this single line controls everything:

```javascriptDOM
document.body.classList.toggle('dark');
```

It adds the class if it's missing. It removes the class if it's already there. One class controls the entire theme.

Same pattern. One toggle. The whole page responds.
