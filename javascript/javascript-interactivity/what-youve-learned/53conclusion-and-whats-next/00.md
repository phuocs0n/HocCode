# Summarizing What You've Learned

#### Course: Make Your Website Interactive with JavaScript

## Summarizing What You've Learned

You've completed the course.

From adding your first script tag to building modals and handling forms, you've transformed a static page into an interactive one. That's not a small thing.

Before we close, do you remember everything you covered?

- Connecting JavaScript: Linking a script to a page and responding to events like clicks and scroll
- Selecting and updating: Finding elements and changing their text, attributes, or classes
- Visibility with classList: Controlling what appears using classes instead of inline styles
- State: Using one variable as the source of truth and updating the UI from it
- Slider: Building navigation with boundaries and synced controls
- Modal: Opening and closing properly, including overlay clicks and Escape
- Forms: Reading values, validating input, preventing reload, and showing feedback

Overall, the pattern remained the same.

Update the state. Update the UI.

That's the core idea behind interactive web apps.
