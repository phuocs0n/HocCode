## Reading Form Values

The modal opens. The modal closes. Now let's make the form inside it actually work.

Form elements like input, textarea, and select store their current value in .value. To handle a form with JavaScript:

- Select the form
- Select the input fields you need
- Listen for the submit event
- Call event.preventDefault() so the page does not reload
- Read values using .value

Values come in as strings. You can trim them, validate them, or use them to show feedback.

Developer Insight

If you forget preventDefault(), the browser will reload the page on submit. That reload removes your messages and breaks your validation flow.
