## Validation and Feedback

Reading values is only the start.

Before treating a form as submitted, you should validate the input.

Validation means:

- Check required fields.
- Check format when needed.
- Show clear errors when something is missing.

A good form flow usually looks like this:

- Clear old messages.
- Validate fields.
- If invalid, show errors and stop.
- If valid, show a loading state.
- Then show success feedback and reset the form.

Each step has a job. None of them overlaps.

Developer Insight

Show errors next to the field and clear them on every submit attempt. Reusing the same error elements keeps your UI clean and predictable.

Next, you will see a runnable example that validates a field, shows an error, disables the button while "sending," and then shows a success message.
