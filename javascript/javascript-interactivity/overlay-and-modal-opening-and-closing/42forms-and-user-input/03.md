## Example Validation and Feedback

Let's see the full flow in action.

This example validates one required field.

- If the field is empty, it shows an error message.
- If the field is valid, it disables the button briefly and then shows a success message.

```html
1<!DOCTYPE html>
2<html lang="en">
3<head>
4  <meta charset="UTF-8" />
5  <title>Validation and Feedback</title>
6  <link rel="stylesheet" href="style.css" />
7</head>
8<body>
9
10  <form id="contact-form">
11    <label for="name">Name</label>
12    <input type="text" id="name" name="name" />
13    <span id="error-name" class="error"></span>
14
15    <button type="submit" id="submit-btn">Send</button>
16  </form>
17
18  <p id="success" class="success"></p>
19
20  <script src="script.js"></script>
21</body>
22</html>
```

```css
1body {
2  font-family: sans-serif;
3  padding: 20px;
4}
5
6.error {
7  display: block;
8  color: #dc2626;
9  font-size: 12px;
10  margin-bottom: 8px;
11}
12
13.success {
14  margin-top: 12px;
15  color: #14B8A5;
16}
```

```javascript
1var form = document.querySelector('#contact-form');
2var nameInput = document.querySelector('#name');
3var errorEl = document.querySelector('#error-name');
4var submitBtn = document.querySelector('#submit-btn');
5var successEl = document.querySelector('#success');
6
7if (form) {
8  form.addEventListener('submit', function (e) {
9    e.preventDefault();
10
11    if (errorEl) errorEl.textContent = '';
12    if (successEl) successEl.textContent = '';
13
14    var name = nameInput ? nameInput.value.trim() : '';
15    var valid = true;
16
17    if (!name) {
18      if (errorEl) errorEl.textContent = 'Name is required.';
19      valid = false;
20    }
21
22    if (!valid) return;
23
24    if (submitBtn) submitBtn.disabled = true;
25
26    setTimeout(function () {
27      if (submitBtn) submitBtn.disabled = false;
28      if (successEl) successEl.textContent = 'Thanks. Message sent.';
29      form.reset();
30    }, 1000);
31  });
32}
```

Click Run Code. Try submitting with an empty field. Then fill it in and submit again.

Watch what happens at each step. The error appears when something is missing. The button disables while sending. The success message appears, and the form resets.

This example shows the full flow:

- Prevent reload
- Validate
- Show error or success
- Disable button during loading
- Reset the form
