# Reading Form Values

#### Course: Make Your Website Interactive with JavaScript

## Reading Form Values

Let's see it work.

This example reads a value from an input when the form is submitted. Instead of reloading the page, it shows a message underneath.

```html
1<!DOCTYPE html>
2<html lang="en">
3<head>
4  <meta charset="UTF-8" />
5  <title>Form Values</title>
6  <link rel="stylesheet" href="style.css" />
7</head>
8<body>
9
10  <form id="demo-form">
11    <label for="name">Name</label>
12    <input type="text" id="name" name="name" />
13    <button type="submit">Submit</button>
14  </form>
15
16  <p id="output">(submit to see value)</p>
17
18  <script src="script.js"></script>
19</body>
20</html>
```

```css
1body {
2  font-family: sans-serif;
3  padding: 20px;
4}
5
6form label,
7form input {
8  display: block;
9  margin-bottom: 8px;
10}
```

```javascript
1var form = document.querySelector('#demo-form');
2var nameInput = document.querySelector('#name');
3var out = document.querySelector('#output');
4
5if (form) {
6  form.addEventListener('submit', function (e) {
7    e.preventDefault();
8
9    var name = nameInput ? nameInput.value : '';
10    var cleanName = name.trim();
11
12    if (out) {
13      out.textContent = cleanName ? 'Hello, ' + cleanName : 'Please enter a name.';
14    }
15  });
16}
```

Click Run Code. Type a name and submit the form.

The page does not reload. The value is read, trimmed, and used to update what the user sees.

This is the core form pattern:

- Stop the reload with preventDefault()
- Read the value with .value
- Update the page using textContent

Next, you will add validation, loading, and success feedback.
