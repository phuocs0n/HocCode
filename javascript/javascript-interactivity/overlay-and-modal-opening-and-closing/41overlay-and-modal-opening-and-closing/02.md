# Basic Overlay and Modal

#### Course: Make Your Website Interactive with JavaScript

## Basic Overlay and Modal

Let's start simple.

This example shows a modal that opens and closes using a class. The button opens the modal. The close button hides it. Nothing else yet.

```html
1<!DOCTYPE html>
2<html lang="en">
3<head>
4  <meta charset="UTF-8" />
5  <title>Overlay and Modal</title>
6  <link rel="stylesheet" href="style.css" />
7</head>
8<body>
9
10  <button id="open-modal">Open modal</button>
11
12  <div id="modal-overlay" class="overlay">
13    <div class="modal">
14      <p>Modal content</p>
15      <button class="modal-close">Close</button>
16    </div>
17  </div>
18
19  <script src="script.js"></script>
20</body>
21</html>
```

```css
1body {
2  font-family: sans-serif;
3  padding: 20px;
4}
5
6.overlay {
7  position: fixed;
8  inset: 0;
9  background: rgba(0,0,0,0.5);
10  display: flex;
11  align-items: center;
12  justify-content: center;
13  opacity: 0;
14  visibility: hidden;
15  transition: opacity 0.2s, visibility 0.2s;
16}
17
18.overlay.modal-open {
19  opacity: 1;
20  visibility: visible;
21}
22
23.modal {
24  background: #fff;
25  padding: 24px;
26  border-radius: 8px;
27}
```

```javascript
1var overlay = document.getElementById('modal-overlay');
2var openBtn = document.getElementById('open-modal');
3var closeBtn = overlay ? overlay.querySelector('.modal-close') : null;
4
5function openModal() {
6  if (overlay) {
7    overlay.classList.add('modal-open');
8  }
9}
10
11function closeModal() {
12  if (overlay) {
13    overlay.classList.remove('modal-open');
14  }
15}
16
17if (openBtn) {
18  openBtn.addEventListener('click', openModal);
19}
20
21if (closeBtn) {
22  closeBtn.addEventListener('click', closeModal);
23}
```

Click Run Code.This example only handles:

- Open with the button
- Close with the close button

Two functions. Two listeners. That is the foundation.

Next, you will extend it to close when clicking the overlay or pressing Escape.
