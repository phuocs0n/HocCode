## Opening and Closing a Modal

The basic open and close work. Now let's make it complete.

Opening the modal is simple. When the user clicks the CTA button, add a class like modal-open to the overlay. Your CSS already knows how to display the modal when that class exists.

Closing needs one clean function.

Create a single closeModal() function that removes the class, then call it from three places:

- The close button click
- The overlay click
- The Escape key

For the overlay click, only close when the click happens on the overlay itself. Clicks inside the modal box should not close it.

For Escape, add a keydown listener when the modal opens, and remove it when the modal closes. This prevents Escape logic from running after the modal is already closed.

Developer Insight

If you do not remove the Escape listener, pressing Escape later can still trigger modal logic. Always clean up listeners when the modal closes.
