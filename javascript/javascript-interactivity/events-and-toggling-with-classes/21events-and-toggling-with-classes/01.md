## Understanding State

Every interface element you have ever used has two sides.

A navigation menu is either open or closed. A dropdown is either expanded or collapsed. A panel is either visible or hidden.

That is state. And it is everywhere.

- Open / Closed
- Visible / Hidden
- Active / Inactive

So instead of asking how to change styles directly, we ask a better question. How do we switch between two states?

Here is how the work is divided:

- JavaScript decides which state is active
- CSS controls how that state looks
- The separation keeps your code clean

JavaScript handles behavior. CSS handles appearance. Each one does its job and nothing more.
