## Understanding Events

You've already used events before.

When you changed a button's text after a click, that was an event in action.

An event is simply something the user does.

- Clicking
- Scrolling
- Pressing a key

When that action happens, JavaScript runs a function.

We attach that function using addEventListener.

The pattern stays simple:

- Select the element
- Listen for an event
- Update something

That's it.
