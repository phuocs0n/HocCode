# Toggle Panel

#### Course: Make Your Website Interactive with JavaScript

## Toggle Panel

Now let's see class toggling in action.

In this example, a panel will open and close when you click a button. The panel's appearance is controlled by CSS. JavaScript only toggles a class.

```html
1<!DOCTYPE html>
2<html lang="en">
3<head>
4  <meta charset="UTF-8" />
5  <title>Toggle Panel</title>
6  <link rel="stylesheet" href="style.css" />
7</head>
8<body>
9
10  <button id="toggle-panel">Toggle panel</button>
11
12  <div class="panel">
13    Panel content. Click the button to show or hide.
14  </div>
15
16  <script src="script.js"></script>
17</body>
18</html>
```

```css
1body {
2  font-family: sans-serif;
3  padding: 20px;
4}
5
6.panel {
7  max-height: 0;
8  overflow: hidden;
9  transition: max-height 0.3s ease;
10}
11
12.panel.is-open {
13  max-height: 200px;
14}
15
16button {
17  padding: 10px 20px;
18  cursor: pointer;
19}
```

```javascript
1var btn = document.querySelector('#toggle-panel');
2var panel = document.querySelector('.panel');
3
4if (btn && panel) {
5  btn.addEventListener('click', function () {
6    panel.classList.toggle('is-open');
7  });
8}
```

Click Run Code, then click the button and watch the panel open. Click again, and it closes.

Notice what happened:

- We did not change styles directly.
- We toggled a class.
- CSS handled the animation and appearance.

JavaScript did one thing. CSS did the rest. That is the clean way to manage state.
