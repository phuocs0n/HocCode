## Adding/Removing Classes

Now that you understand state, let's see how we move between them.

Instead of changing styles directly in JavaScript, we add or remove a class. CSS handles how it looks. JavaScript decides which class is active.

There are three main methods:

- classList.add('className') adds a class
- classList.remove('className') removes a class
- classList.toggle('className') switches it on or off

toggle is the one you'll use most.

If the class exists, it removes it. If it doesn't exist, it adds it. One click changes the state.The next click switches it back.

That's exactly what we need for menus and panels.
