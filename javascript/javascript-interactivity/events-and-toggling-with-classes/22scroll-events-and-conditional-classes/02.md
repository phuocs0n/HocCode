# Scroll Threshold Example

#### Course: Make Your Website Interactive with JavaScript

## Scroll Threshold Example

Let's see this in action.

In this example, the indicator changes once you scroll past 100 pixels. The logic is the same one you just read. Now watch it happen.

```html
1<!DOCTYPE html>
2<html lang="en">
3<head>
4  <meta charset="UTF-8" />
5  <title>Scroll and threshold</title>
6  <link rel="stylesheet" href="style.css" />
7</head>
8<body>
9
10  <div class="scroll-indicator">
11    Scroll down 100px
12  </div>
13
14  <div class="spacer"></div>
15
16  <script src="script.js"></script>
17</body>
18</html>
```

```css
1body {
2  margin: 0;
3  font-family: sans-serif;
4}
5
6.scroll-indicator {
7  position: fixed;
8  top: 10px;
9  left: 50%;
10  transform: translateX(-50%);
11  padding: 8px 16px;
12  background: #F1F5F9;
13  border-radius: 8px;
14  transition: background 0.2s;
15}
16
17.scroll-indicator.scrolled {
18  background: #14B8A5;
19  color: #fff;
20}
21
22.spacer {
23  height: 120vh;
24}
```

```javascript
1var bar = document.querySelector('.scroll-indicator');
2var threshold = 100;
3
4window.addEventListener('scroll', function () {
5  var isPast = window.scrollY > threshold;
6  if (bar) {
7    bar.classList.toggle('scrolled', isPast);
8  }
9});
```

Click Run Code. Now scroll down.

Once you pass 100 pixels, the indicator changes.

We read the scroll position. We compared it to a threshold. We toggled a class.

That is the pattern running exactly as it should.
