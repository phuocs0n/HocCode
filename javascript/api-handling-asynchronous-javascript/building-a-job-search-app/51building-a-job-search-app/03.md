## Step 2a: Building the URL Safely

The first thing our API function does is construct the request URL.

```javascript
const url = `https://api.programiz.pro/api/demo/javascript/jobs?title=${encodeURIComponent(keyword)}`;
```

We use a template literal to build the URL dynamically. The encodeURIComponent() function is critical here.

For instance, if someone searches for "C++ developer", the + and space characters need special encoding to work in a URL.

Without encoding:

```javascript
https://api.programiz.pro/api/demo/javascript/jobs?title=C++ developer
```

With encoding:

```javascript
https://api.programiz.pro/api/demo/javascript/jobs?title=C%2B%2B%20developer
```

The second URL is valid. The first would break. encodeURIComponent() ensures we get the second URL.
