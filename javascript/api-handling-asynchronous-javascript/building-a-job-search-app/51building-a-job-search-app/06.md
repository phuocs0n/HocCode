## Putting It All Together

Now that we understand each component, here is the complete application. Every function we examined works together as a single system.

```javascript
1// ============ Main ============
2async function main() {
3    let rawKeyword = prompt("> What job are you looking for?");
4
5    const validation = validateKeyword(rawKeyword); 
6    if (!validation.valid) { 
7        console.log("Error:", validation.error); 
8        return; 
9    }
10
11    console.log("Searching...");
12
13    try { 
14        const jobs = await fetchJobs(validation.keyword); 
15        displayJobs(jobs, validation.keyword); 
16    } 
17    catch (error) { 
18        console.log("Error:", error.message); 
19    }
20}
21
22main();
```

When you run this code:

1. main() is called.
2. The user is prompted for a search term.
3. validateKeyword() checks the input.
4. If valid, fetchJobs() contacts the API.
5. If successful, displayJobs() shows the results.
6. Any errors along the way are caught and displayed.

Each function has a single job. Each edge case has a handler. The code is readable, maintainable, and robust.

This is how professional applications are built!
