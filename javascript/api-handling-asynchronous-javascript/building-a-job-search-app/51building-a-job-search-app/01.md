## Step 1: Validation

User input cannot be trusted. Someone might submit an empty form; type a single character; or paste some random text.

If we send bad input to an API, we're wasting a network request and might get useless results in return.

So, we'll write a validateKeyword() function that:

- Trims whitespace from the input
- Rejects empty strings
- Requires a minimum length
- Returns both a status and the cleaned data

```javascript
function validateKeyword(keyword) {
    const trimmed = keyword.trim();

    if (trimmed === "") {
        return { valid: false, error: "Please enter a search term." };
    }

    if (trimmed.length < 2) {
        return { valid: false, error: "Search term must be at least 2 characters." };
    }

    return { valid: true, keyword: trimmed };
}
```

This pattern of validating before processing is something you'll use in every application you build.
