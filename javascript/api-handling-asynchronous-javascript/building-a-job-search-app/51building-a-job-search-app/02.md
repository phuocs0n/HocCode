## Step 2: API Communication

We'll fetch job listings from Remotive, a real remote job board API. Our fetchJobs() function will:

- Build the URL safely using encodeURIComponent() so special characters don't break the request
- Use async/await to handle the asynchronous fetch operation
- Parse the JSON response and return the jobs array
- Wrap everything in a try...catch block to handle any errors that occur

```javascript
async function fetchJobs(keyword) {
    const url = `https://api.programiz.pro/api/demo/javascript/jobs?title=${encodeURIComponent(keyword)}`;

    try {

        const response = await fetch(url);

        const data = await response.json();

        return data.jobs;
    }
    catch (error) {
        throw new Error(error.message);
    }
}
```

This function handles the core workflow: build the URL, fetch the data, parse the response, and return the jobs.
