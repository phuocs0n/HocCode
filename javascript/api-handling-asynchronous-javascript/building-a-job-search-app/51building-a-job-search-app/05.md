## Step 4: Creating the main() Function

Finally, we'll connect all the pieces. A single main() function will coordinate everything in the correct order:

```javascript
async function main() {
    let rawKeyword = prompt("What job are you looking for? ");

    const validation = validateKeyword(rawKeyword); 
    if (!validation.valid) { 
        console.log("Error:", validation.error); 
        return;
    }

    console.log("Searching...");

    try { 
        const jobs = await fetchJobs(validation.keyword); 
        displayJobs(jobs, validation.keyword); 
    } 
    catch (error) { 
        console.log("Error:", error.message); 
    }
}

main();
```

The main() function is the conductor — it doesn't do the actual work. Instead, it coordinates the other functions in the correct order:

1. Get input: We use prompt() to ask the user what they want to search for.
2. Validate: We call validateKeyword() and check the result. If invalid, we show the error and exit early with return.
3. Provide Feedback: We log "Searching..." to the console so the user knows something is happening. Network requests can take time, and silence feels like broken software.
4. Fetch and Display: We call fetchJobs() with await because it is async. If successful, we pass the jobs to displayJobs().
5. Handle errors. The try...catch block catches any errors thrown by fetchJobs(). We display the error message without crashing.
