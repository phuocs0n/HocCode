## Step 3: Display the Data Neatly

Raw API data is not user-friendly. Job listings come as JavaScript objects with technical field names like candidate_required_location. Some fields might be missing entirely.

So, our displayJobs() function will:

- Handle the case when zero jobs are found
- Limit output to five results so users are not overwhelmed
- Provide fallback values when job fields are missing
- Format the data in a readable way
- Tell users how many additional results exist

```javascript
function displayJobs(jobs, keyword) { 
    if (jobs.length === 0) { 
        console.log(`\nNo jobs found for "${keyword}".`); 
        return; 
    }

    console.log(`\n=== Found ${jobs.length} jobs for "${keyword}" ===\n`);

    const limit = Math.min(jobs.length, 5);

    for (let i = 0; i < limit; i++) { 
        const job = jobs[i]; 
        
        console.log(`${i + 1}. ${job.title || "Untitled"}`); 
        console.log(`Company: ${job.company || "Unknown"}`); 
        console.log(`Location: ${job.location || "Not specified"}`); 
        console.log(""); 
    }

    if (jobs.length > limit) { 
        console.log(`... and ${jobs.length - limit} more.`); 
    }
}
```

Good display code respects the user. It never shows "undefined" or crashes on missing data.
