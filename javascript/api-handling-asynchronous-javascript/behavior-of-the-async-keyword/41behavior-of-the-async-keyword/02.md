## Example: Returning a Plain Value to async

Take a good look at this simple async function I've written:

```javascript
1async function getNumber() {
2    return 42;
3}
4
5getNumber().then(num => console.log(num));
6
7// Output: 42
```

As you can see, I've returned a plain integer (42) to this function. But since I've marked it as async, JavaScript actually returns Promise.resolve(42).

This automatic wrapping is why async functions work seamlessly with .then() and other promise-based code.
