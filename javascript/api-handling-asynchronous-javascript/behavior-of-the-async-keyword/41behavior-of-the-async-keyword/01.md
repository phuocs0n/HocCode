## How async works

When a function is marked as async, two rules apply:

- The function always returns a promise
- Any value returned becomes the resolved value of that promise

Example

```javascript
async function getMessage() {
    return "Hello";
}
```

The above code behaves the same as:

```javascript
function getMessage() {
    return Promise.resolve("Hello");
}
```

An async function always returns a promise. Even if you return a plain value, JavaScript wraps it in a Promise for you.
