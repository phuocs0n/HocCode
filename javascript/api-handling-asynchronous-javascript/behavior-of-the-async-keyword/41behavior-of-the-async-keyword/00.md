## Introduction to async / await

By now, you've seen how promises work and how chaining connects various asynchronous steps.

To make the logic easier to read, JavaScript introduced async and await.

In other words, async / await is built on top of promises — it neither replaces promises nor introduces a new asynchronous model.

Instead, it simply provides an alternate syntax for writing promise-based logic in a clearer, more linear way.

In this chapter, the focus is on what async / await is doing behind the scenes, so the syntax feels predictable rather than magical.

So without further ado, let's dive straight into what async does.
