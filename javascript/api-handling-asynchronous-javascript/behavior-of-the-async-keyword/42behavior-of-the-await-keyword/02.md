# await vs .then()

#### Course: API Handling with Asynchronous Javascript

## await vs .then()

Functionally, await and .then() do the exact same things. But the way they read is totally different.

You can verify it by examining the two equivalent codes below:

Code 1: Asynchronous Code with .then()

```javascript
1// Function to load user posts 
2function loadUserPosts(userId) {
3  // Fetch user data
4  return simulateFetchUser(`https://api.programiz.pro/demo/javascript/users/${userId}`)
5    .then(user => {
6      console.log("User name is:", user.name);
7      // Fetch posts data for the user
8      return simulateFetchPosts(`https://api.programiz.pro/demo/javascript/posts?userId=${userId}`);
9    })
10    .then(posts => {
11      console.log("The posts length is:", posts.length);
12      return posts;
13    })
14    .catch(error => {
15      console.error(error);
16    });
17}
```

Code 2: Asynchronous Code with async / await

```javascript
1// Function to load user posts using async/await
2async function loadUserPosts(userId) {
3  try {
4    // Fetch user data using await
5    const user = await simulateFetchUser(`https://jsonplaceholder.typicode.com/users/${userId}`);
6    console.log("User name is:", user.name);
7
8    // Fetch posts data for the user using await
9    const posts = await simulateFetchPosts(`https://jsonplaceholder.typicode.com/posts?userId=${userId}`);
10    console.log("The posts length is:", posts.length);
11
12    return posts;
13  }
14  catch (error) {
15    console.error(error);
16  }
17}
```

Both fetch the user, display their name, fetch their posts, and display the count.

But the await version reads like a story: you see the sequence; you see the dependencies.

This is why await exists: not for new functionality but for clarity.
