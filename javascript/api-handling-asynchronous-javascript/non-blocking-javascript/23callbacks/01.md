## Example: JavaScript Callback

Here's a simple example of a callback function in JavaScript:

```javascript
1const greet = (name, callback) => {
2  console.log("Hello", name);
3  callback();
4};
5
6greet("Alex", () => {
7  console.log("Welcome!");
8});
```

Output

```text
Hello Alex
Welcome!
```

Here,

- greet() takes a variable and a callback function as arguments.
- So, we call the greet() function and pass "Alex" and a callback function as arguments.
- The callback function gets executed only after console.log("Hello", name).

In this way, we can control the order of execution using callbacks.
