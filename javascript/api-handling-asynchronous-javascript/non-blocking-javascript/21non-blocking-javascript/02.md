## The setTimout() Function

At first glance, setTimeout() looks like a JavaScript feature — it is not!

setTimeout() is a Web API provided by the runtime environment (browser or Node.js), and is not part of the JavaScript language itself.

JavaScript only knows how to call it, so the waiting is handled outside JavaScript.

What is setTimeout()?

The setTimeout() function lets you execute a piece of code after the timer has expired. Basically, you tell it what to do and how long to wait before doing it.

Its syntax is:

```javascript
setTimeout(function, milliseconds);
```

Here,

- function - The code you want to run. It's also known as the callback function.
- milliseconds - The delay before the code runs (in milliseconds).
