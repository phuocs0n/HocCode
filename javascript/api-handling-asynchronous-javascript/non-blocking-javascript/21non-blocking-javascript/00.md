## Introduction to Asynchronous Code

In the previous chapter, we found that synchronized JavaScript has a problem: it freezes when it pauses and "waits" for slow tasks.

Obviously, JavaScript has a solution to this problem: instead of waiting for slow tasks, JavaScript delegates them and says, "Run this later. I'll continue for now."

How does JavaScript accomplish this?

Well, JavaScript by itself only handles synchronous code execution. Modern asynchronous behavior is powered by the runtime environment.

The runtime environment is provided by the browser and includes tools that help JavaScript handle slow tasks.

These components are needed to enable asynchronous execution.
