## Web APIs

Web APIs are features provided by the browser (or runtime) that handle tasks JavaScript is bad at. Examples include:

- Timers (such as setTimeout())
- Network requests (such as fetch())
- DOM events (clicks, scrolls)
- Browser storage
- Media access

These are not parts of the JavaScript language itself.

JavaScript hands over the responsibilities to the environment that runs the script. Meanwhile, it keeps running other codes.

Below are the main JavaScript runtime environments, explained from a developer's perspective:

- Browser Runtime Environment
- Nodejs Environment
