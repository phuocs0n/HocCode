## Example: The setTimeout() Function

Before learning about how setTimeout() works, here's a simple working example of the function:

```javascript
1console.log("Start");
2
3setTimeout( () => {
4  console.log("Inside timeout");
5}, 0);
6
7console.log("End");
```

Output

```text
Start
End
Inside timeout
```

As you can see, the code inside setTimeout() is delayed and executed last. This might look like it's breaking the rules of JavaScript, but that's not really the case.
