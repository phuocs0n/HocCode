## Simulating the Blog Page

Let me show you what happens when your code doesn't account for the waiting.

I'm going to simulate the process of fetching articles using a function that takes some time to complete. This represents what happens when you ask a server for data.

Take a look at the code from our playground.

Here, https://programiz.pro/ide/html/LL1RWTJQVU

It simulates how our blog might wait for articles to load.

Now try to interact with the page while it's "loading". Try to click the button again. Try to select some text.

You can't! The entire page is frozen for 3 seconds.

This is extremely inconvenient for our users. But it's easy to see why this is happening once you understand what's happening behind the scenes.
