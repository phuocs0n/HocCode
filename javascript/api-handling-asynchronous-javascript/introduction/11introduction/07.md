## Why JavaScript Blocks

So you've experienced first-hand what blocking looks like and why it hurts the user experience. You faced such problems because JavaScript:

- Runs code from top to bottom
- Executes one line at a time
- Finishes one task before it starts the next

Moreover, JavaScript is built on the following pillars:

- JavaScript doesn't multitask.
- It doesn't run code in parallel.
- It finishes one task before starting the next.

This way of executing code is called single threaded execution, and the typical behavior exhibited by JavaScript is called synchronous behavior.
