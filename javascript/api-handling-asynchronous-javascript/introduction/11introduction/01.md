# What You'll Learn

#### Course: API Handling with Asynchronous Javascript

## What You'll Learn

I've structured this course to take you from fundamentals to modern async patterns gradually.

You'll learn why asynchronous behavior exists, how JavaScript stays responsive, and how developers write async code that is easier to reason about. Talk about some concepts like promises, event loop, call stack and task queues.

These topics might seem confusing and complex. But don't worry, we'll tackle each of them step by step.

More importantly, you'll learn how to think about asynchronous code, not just how to write it.
