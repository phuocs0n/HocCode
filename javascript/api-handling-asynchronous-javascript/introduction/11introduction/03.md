## A Simple Example

Imagine you're building a blog, and it needs to show a list of articles for people to read and interact with. Those articles are somewhere on a server, and you need to display them.

Let's visualize what the steps would be:

1. Someone comes to your site
2. The JS requests the server for the articles
3. The server gives you the articles
4. The JS shows the articles with HTML and CSS

Sounds straightforward right? But there's a problem: step 2 involves sending a request to the server.

How long do you think you'll be waiting for the server to respond?

The truth is, you never know: it all depends on the server.
