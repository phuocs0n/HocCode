## Example: The Call Stack

Let's analyze the call stack through the following example:

```javascript
1function washHands() {
2  dryHands();
3}
4
5function dryHands() {
6  console.log("Hands are dry");
7}
8
9washHands();
10
11// Output: Hands are dry
```

Here's how the code executes:

1. JavaScript starts running the program.
2. It reaches washHands() and JavaScript pushes it onto the call stack.
3. Inside washHands(), it sees a call to dryHands().
4. So, it pushes dryHands() to the top of the call stack.
5. Now, dryHands() runs console.log() and prints the message.
6. After dryHands() finishes, JavaScript pops it off from the call stack.
7. With dryHands() gone, washHands() is now at the top of the call stack.
8. But there is nothing inside washHands(), so JavaScript also pops it off the stack.
9. Now, the stack is empty, so the program ends.

That's it. Sounds simple enough, doesn't it?

Of course, there's more to this process. But you'll learn about it in a future JavaScript course that deals with more advanced concepts.
