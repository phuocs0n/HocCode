## Demonstration: A Simple JavaScript Code

Let's look at this code:

```javascript
1console.log("Start");
2console.log("Middle");
3console.log("End");
```

Before you run it, think for a while and ask yourself:

"In what order will the messages appear?"

When you run the code, the output will be:

```text
Start
Middle
End
```

You probably already guessed the output. After all, JavaScript executes the codes line by line, one after the other.

JS can't execute the next line before completing the first one.
