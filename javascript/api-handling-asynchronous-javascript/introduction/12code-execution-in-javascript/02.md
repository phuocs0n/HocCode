## Real Life Analogy

Let's compare the working of JavaScript with a real life example. Imagine JavaScript as a single developer

- with one keyboard,
- and a single task list.

That developer cannot:

- Type two files at once
- Fix a bug and attend a meeting at the same time
- Jump between tasks midway without finishing the current one

JavaScript works the same way.

We'll clarify this even further by learning the essential basics of the call stack.
