## Step 3: Parsing the Data

```javascript
1return response.json();
```

Here, we're converting the response to JSON, which obviously takes some time. It thus follows that response.json() is also asynchronous, and so it returns another promise.

By returning the promise, JavaScript automatically waits before moving to the next .then().

This is one of the biggest advantages of promises: you don't have to manage the timing by yourself.
