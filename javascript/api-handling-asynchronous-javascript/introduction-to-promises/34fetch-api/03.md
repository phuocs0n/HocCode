#### Course: API Handling with Asynchronous Javascript

## Step 2: Receiving the Response

```javascript
1.then(response => {
2    return response.json();
3})
```

When the server responds, the above .then() block gets executed.

If something goes wrong, the promise chain immediately jumps to .catch().

This keeps all error handling in one place instead of spreading it everywhere.
