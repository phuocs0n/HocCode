## Step 5: Handling Errors in One Place

```javascript
1.catch(error => {
2    console.error("Could not load movie details:", error.message);
3});
```

The execution jumps straight to .catch() if anything goes wrong at any step. These mishaps can include:

- Network failure
- HTTP error
- JSON parsing error

Instead of asking "Where might this fail?", you always know: "If it fails, it'll end up here."

That predictability is one of the main reasons promises are preferred over deeply nested callbacks.
