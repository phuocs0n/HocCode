#### Course: API Handling with Asynchronous Javascript

## Step 1: Making the Request

```javascript
1fetch("https://api.programiz.pro/api/demo/javascript/movies")
```

When this line runs, the request is sent immediately, and JavaScript does not wait for the response. That's because fetch() returns a promise right away.

A very common beginner mistake is expecting the user data to be available immediately after calling fetch().

It doesn't work that way!

At this moment, all you have is a promise that says: "I'll give you the result later."
