## Return Value of a Promise

JavaScript returns a promise the moment you call an asynchronous function. But it does not return the final value.

Instead, it returns a placeholder in the form of a promise object. This has a few important advantages:

- Asynchronous operations can now be treated like data
- Multiple async steps can be connected cleanly
- Control stays with the code that uses the result, not the code that produces it

A promise lets you describe what should happen later without stopping the program.
