## Why Do Promises Fail?

As I just said, it isn't always your fault that your promise failed; there are other, external reasons for failing as well.

You might see a promise fail when:

- the internet disconnects
- the server returns an error (500 / 404)
- the data is invalid (missing fields, wrong type)
- your code throws an error inside .then()

Then keep your mindset line:

Always assume your promise can fail.

This assumption will make you a better developer!

With that out of the way, let's move on to learning how to actually handle promise errors in JavaScript.
