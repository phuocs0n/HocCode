## Example: Reasons for Promise Failing

Let's look at a modified version of a previous example:

```javascript
1// Create a new Promise that simulates an asynchronous operation
2const promise = new Promise((resolve, reject) => {
3    // Simulate a condition that determines success or failure
4    const success = false;
5    
6    // If the operation is successful, resolve the promise with a success message
7    if (success) {
8        resolve("Operation successful");
9    }
10    // Otherwise, reject the promise with an error message
11    else {
12        reject("Operation failed");
13    }
14});
15
16// Consuming a promise
17promise.then(result => {
18  console.log(result);
19});
```

You should see a scary error.

Previously, we had set success to true but now we've set it to false.

There might be various reasons for this change. For now, let's imagine the server is not responding and the value got set to false.

As a result, Javascript now calls reject("Operation failed").

However, .then() does not handle failures. If the promise is rejected, you need .catch() to handle the failure.
