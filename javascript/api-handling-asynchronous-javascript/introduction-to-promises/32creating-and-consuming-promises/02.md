## Example: A Simple Promise

Let's look at the example code here:

```javascript
// Create a new Promise that simulates an asynchronous operation
const promise = new Promise((resolve, reject) => {
    // Simulate a condition that determines success or failure
    const success = true;
    
    // If the operation is successful, resolve the promise with a success message
    if (success) {
        resolve("Operation successful");
    }
    // Otherwise, reject the promise with an error message
    else {
        reject("Operation failed");
    }
});
```

This code demonstrates a JavaScript promise. The promise is created but not "consumed" here.
