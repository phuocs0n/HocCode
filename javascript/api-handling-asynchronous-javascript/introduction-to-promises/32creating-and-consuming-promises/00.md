## From Promise States to Code

In the previous lesson, you learned that a promise represents an asynchronous operation and moves through defined states.

In practice, developers rarely think about promise states explicitly while writing code. Instead, they work with functions that return promises and flows built from them.

This lesson focuses on:

- how promises are created
- how promises are consumed
- how multiple asynchronous steps form a clear, readable chain
