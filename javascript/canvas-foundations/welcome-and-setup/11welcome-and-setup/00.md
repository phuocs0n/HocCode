## Welcome to Canvas Basics

Hi there! 👋

Welcome to Canvas Basics. I'm Abidit, and I'll be guiding you through this course.

If you just finished Modern JavaScript Essentials, you already have a strong foundation. You know about classes, arrow functions, destructuring, and composition. Those tools help you organize logic.

Now we take things a step further.

Instead of writing code that only produces numbers or text, you are about to start creating visual experiences.

Canvas is where JavaScript becomes something you can see. Shapes appear on the screen. Objects move. Interactions start to feel like a real game.

I still remember the first time I made a circle move across a canvas. It was just a small dot moving from left to right, but seeing it respond to my code felt completely different from anything I had built before.

That moment is what this course is designed to give you.

You will go from drawing simple shapes to building the pieces of a real browser game.
