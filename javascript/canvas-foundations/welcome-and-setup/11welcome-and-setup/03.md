## What You Need

Before we start building, let's make sure you have the right foundation.

Here is what you should already know coming in:

- JavaScript basics like variables, functions, loops, conditionals, arrays, and objects
- DOM manipulation like selecting elements and adding event listeners
- Modern JavaScript features like classes, arrow functions, and destructuring

If you finished Modern JavaScript Essentials, you are honestly already good to go.

If classes or composition still feel a little wobbly, a quick review of Chapter 4 from that course is worth it before continuing. We use those patterns a lot in Brick Breaker.

And one more thing. You do not need any canvas experience at all. That is exactly what this course is here for.

Next, you will write your first canvas code, learn how the coordinate system works, and draw your very first shape on screen. That is where things start getting fun.

See you there! 👋
