# Why the Header Is a Perfect Example

#### Course: CSS Fundamentals for Your First Webpage

## Why the Header Is a Perfect Example

Headers often contain:

1. A title
2. Navigation
3. Lists that should not look like normal content lists

So instead of asking:

"How do I style <li>?"

Developers ask:

"How do I style the list items inside the header?"

That question leads directly to practical selectors.

#### Typical Header Menu Structure (Conceptual)

```html
1<header>
2  <h1>Learning HTML & CSS</h1>
3  <nav>
4    <ul>
5      <li>Home</li>
6      <li>Lessons</li>
7      <li>Resources</li>
8    </ul>
9  </nav>
10</header>
```

We won't change this HTML. All control comes from selectors.
