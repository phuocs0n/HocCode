## Selectors Are About Context, Not Just Tags

Early on, it's tempting to write CSS like this:

```html
1<ul class="menu">
2  <li>Home</li>
3  <li>About</li>
4  <li>Contact</li>
5</ul>
```

```css
1li {
2  list-style: none;
3}
```

This works — but it affects every list on the page.

Real projects need control, not shortcuts. That's why developers rarely style elements in isolation. They style elements based on where they live.
