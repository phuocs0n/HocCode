## When Multiple Things Need the Same Style

Another moment that comes up constantly:

"These elements belong to the same visual group. I don't want to repeat myself."

Instead of writing multiple rules, developers group selectors.

```html
1<header>
2  <h1>Learning HTML & CSS</h1>
3  <nav>
4    <ul>
5      <li>Home</li>
6      <li>Lessons</li>
7      <li>Resources</li>
8    </ul>
9  </nav>
10</header>
```

```css
1header h1,
2header li {
3  color: white;
4}
```

Same style. One place. If the design changes later, there's only one rule to update.

That's not just cleaner — it's how CSS stays maintainable.
