## Styling by Location (Descendant Selector)

A very common situation is this:

"I want to style something only when it appears inside a specific section."

For example, menu items inside the header shouldn't look like content lists.

```html
1<header>
2  <h1>Learning HTML & CSS</h1>
3  <nav>
4    <ul>
5      <li>Home</li>
6      <li>Lessons</li>
7      <li>Resources</li>
8    </ul>
9  </nav>
10</header>
```

```css
1header li {
2  list-style: none;
3}
```

This reads almost like English:

"Select list items that live inside the header."

Nothing outside the header is touched. That's the power here — context without complexity.

#### Being Intentional About Depth (Child Selector)

Sometimes location alone isn't enough.

Imagine adding a nested list later — suddenly your styles apply in places you didn't expect. Developers avoid that by being explicit.

```python
1<header>
2  <h1>Learning HTML & CSS</h1>
3  <nav>
4    <ul>
5      <li>Home</li>
6      <li>Lessons</li>
7      <li>Resources</li>
8    </ul>
9  </nav>
10</header>
```

```python
1nav > ul {
2  padding: 0;
3}
```

This doesn't mean "any <ul> in the nav".

It means:

"Only the <ul> that sits directly inside <nav>."

This kind of precision keeps CSS predictable as pages grow. It's not about being strict — it's about staying safe.
