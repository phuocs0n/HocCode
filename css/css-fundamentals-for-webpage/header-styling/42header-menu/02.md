## What is a Selector (In Practice)?

Before writing any CSS rule, developers answer one simple question:

"Which part of the page am I trying to change?"

A selector is the part of CSS that answers that question. It tells the browser:

1. What to look for in the HTML
2. Where that element lives
3. When a style should apply

Every CSS rule follows this structure:

```html
1<div class="selector">
2  This element is targeted by the <code>.selector</code> rule.
3</div>
```

```css
1.selector {
2  property: value;
3}
```

If the selector is unclear, the CSS becomes hard to control —especially as pages grow.
