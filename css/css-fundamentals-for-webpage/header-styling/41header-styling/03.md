# Example CSS

#### Course: CSS Fundamentals for Your First Webpage

## Example CSS

```html
1<header>
2  <h1>Site Header</h1>
3  <p>Welcome back! Here's what's new today.</p>
4</header>
```

```css
1header {
2  background-color: #1f2933;
3  color: #ffffff;
4  padding: 24px;
5}
```

#### What to Observe

1. Text becomes readable against the background
2. Header feels like a defined section
3. Page starts to look intentional

No gradients. No images yet. Just clarity.
