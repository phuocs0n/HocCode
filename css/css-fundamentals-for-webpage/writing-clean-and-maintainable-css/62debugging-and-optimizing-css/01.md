#### Course: CSS Fundamentals for Your First Webpage

## Using DevTools to Inspect and Debug Styles

The major goal of this lesson is to teach you how developers debug CSS when things don't look right — not by guessing, but by using tools and a clear process.

This is one of the most transferable skills you'll use in real jobs and React projects.

When CSS doesn't behave as expected, developers don't rewrite everything.

They inspect.

#### The First Rule of CSS Debugging

Never guess. Inspect first. Browser DevTools show you:

1. Which styles are applied
2. Which ones are overridden
3. Where each rule comes from
