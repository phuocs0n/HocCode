## Understanding Specificity and Overrides (Practically)

CSS doesn't apply styles randomly. It follows rules.

The most important one for debugging: More specific selectors win.

Example:

```html
1<main class="container">
2  <p>This paragraph is outside <code>.article</code>, so it becomes black.</p>
3
4  <article class="article">
5    <h2>Inside Article</h2>
6    <p>This paragraph is inside <code>.article</code>, so it becomes gray.</p>
7    <p>This one is also gray due to the more specific selector.</p>
8  </article>
9</main>
```

```css
1p {
2  color: black;
3}
4
5.article p {
6  color: gray;
7}
```

Paragraphs inside .article will be gray.

#### Developer Insight

When a style "doesn't work", it usually means:

1. Another rule is winning
2. Or your selector isn't specific enough
