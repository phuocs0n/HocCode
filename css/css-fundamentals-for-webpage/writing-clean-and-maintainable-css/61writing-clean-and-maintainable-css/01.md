## Using Layout System in HTML

Instead of styling each section separately, add .container class on each section for the same layout throughout.

```css
<header>
  <div class="container">
    <h1>Learning HTML Blog</h1>
  </div>
</header>

<main class="container">
  ...
</main>

<section class="form-wrapper">
  <div class="container">
    ...
  </div>
</section>
```

Lets also add a card layout system to our project.

```css
<main class="container">
  ...
</main>
```

Now:

1. layout rules live in one place
2. spacing feels consistent
3. changes are easy and safe

This is CSS as a system, not stitched parts.
