## Responsive Typography and Spacing

Responsiveness isn't just layout. Text must remain readable.

#### Simple Adjustment Example

```html
1<div class="page">
2  <h1>Responsive Heading</h1>
3  <p>Resize the viewport: the heading gets larger at 768px and up.</p>
4</div>
```

```css
1h1 {
2  font-size: 24px;
3}
4
5@media (min-width: 768px) {
6  h1 {
7    font-size: 32px;
8  }
9}
```
