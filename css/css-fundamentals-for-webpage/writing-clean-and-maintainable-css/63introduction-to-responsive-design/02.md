## Using Media Queries (Only What You Need)

Let's see the previous media query in action. You need to resize your window to the width value in the media query to see the changes. This width is called breakpoints.

```html
1<div class="main-layout-container">
2  <aside class="sidebar">
3    <h2>Sidebar</h2>
4    <p>On small screens, this stacks. On 768px+, it becomes a flex layout.</p>
5  </aside>
6
7  <main class="content">
8    <h1>Responsive Layout</h1>
9    <p>Resize the viewport to see the media query kick in.</p>
10  </main>
11</div>
```

```css
1.main-layout-container {
2  display: block;
3}
4
5@media (min-width: 768px) {
6  .main-layout-container {
7    display: flex;
8    gap: 24px;
9  }
10}
```

#### Developer Insight

Most real projects use:

1. 1–3 breakpoints
2. Not dozens

If you need many breakpoints, your layout is probably too rigid.
