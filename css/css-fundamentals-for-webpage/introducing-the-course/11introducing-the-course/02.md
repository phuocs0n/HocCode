# What is CSS?

#### Course: CSS Fundamentals for Your First Webpage

## What is CSS?

CSS, or Cascading Style Sheets, is a language used to style webpages.

With CSS, you can change colors, fonts, and layouts to make your webpage visually appealing and easier to use.

Basically, HTML defines what content is on the page, CSS defines how it looks.

At first, CSS can feel confusing. It may seem like a collection of mysterious rules. But once you understand what each of these rules does, you can bring your HTML to life.

You can control how your content looks, feels, and behaves!

I want learners to feel this power as early as possible, which is why I've structured this course so that you will share my enthusiasm for CSS.

Next, we'll explore the dramatic difference CSS can make by comparing two webpages: one built with HTML alone, and another that incorporates both HTML and CSS.
