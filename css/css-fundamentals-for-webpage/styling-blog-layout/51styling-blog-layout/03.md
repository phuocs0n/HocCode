## Creating Flex Containers for Main Content

Now we reach the modern layout tool developers actually use.

Flexbox answers:

How do I place things next to each other?

#### Basic Flex Setup

```html
1<div class="main-layout-container">
2  <aside class="sidebar">Sidebar</aside>
3  <main class="content">
4    <h1>Main Content</h1>
5    <p>This layout uses flexbox to place the sidebar and content side by side.</p>
6  </main>
7</div>
```

```css
1.main-layout-container {
2  display: flex;
3}
```

That's it.Children now align horizontally by default.

#### Typical Blog Use Case

1. Main article
2. Sidebar or table of contents

Flexbox makes this trivial.
