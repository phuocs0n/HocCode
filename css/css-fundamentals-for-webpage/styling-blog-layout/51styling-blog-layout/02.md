# Position Property – static, relative, absolute, fixed

#### Course: CSS Fundamentals for Your First Webpage

## Position Property – static, relative, absolute, fixed

Once layout starts, developers eventually ask: Can I move this element slightly?

That's where position comes in.

#### The Default

```html
1<div class="wrapper">
2  <div class="element">I am positioned statically (default).</div>
3</div>
```

```css
1.element {
2  position: static;
3}
```

This means:

1. The element follows normal flow
2. You cannot move it manually

#### Relative Positioning

```html
1<article>
2  <h2>Article Title</h2>
3
4  <div class="article-meta">
5    <span>By Alex</span> • <span>Jan 20, 2026</span> • <span>5 min read</span>
6  </div>
7
8  <p>
9    This is the article content. The meta section above is nudged down by 8px
10    using relative positioning.
11  </p>
12</article>
```

```css
1.article-meta {
2  position: relative;
3  top: 8px;
4}
```

1. Moves element relative to itself
2. Does not break layout

#### Fixed Positioning (Preview)

```html
1<div class="page">
2  <h1>Fixed Notice Example</h1>
3  <p>Scroll the page to see the notice stay in the bottom-right corner.</p>
4
5  <div class="spacer"></div>
6
7  <div class="notice">🔔 This is a fixed notice</div>
8</div>
```

```css
1.notice {
2  position: fixed;
3  bottom: 16px;
4  right: 16px;
5}
6
7.spacer {
8  height: 140vh;
9}
```

1. Stays in place on scroll
2. Used sparingly
