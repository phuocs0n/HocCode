# Display Properties – block, inline, inline-block

#### Course: CSS Fundamentals for Your First Webpage

## Display Properties – block, inline, inline-block

Before layouts, developers ask:

Why is this element taking full width? Why is this one not?

The answer usually starts with a display.

#### What You're Already Seeing

1. <div>, <section>, <p> → block
2. <span>, <a> → inline

You didn't choose this — HTML did.

#### Practical Example

```html
1<article>
2  <h2>Understanding Display</h2>
3  <p>
4    <span>Spans stay inline</span>
5    and flow with text.
6  </p>
7
8  <div class="tag">HTML</div>
9  <div class="tag">CSS</div>
10  <div class="tag">Layout</div>
11</article>
```

```css
1article {
2  display: block;
3}
4
5span {
6  display: inline;
7}
8
9.tag {
10  display: inline-block;
11  padding: 6px 12px;
12}
```

#### Developer Intuition

1. block → full width, stacks vertically
2. inline → flows with text
3. inline-block → inline, but can have size

That's enough for now.
