## Element Selector (What You've Already Used)

An element selector targets all HTML elements of a specific type.

```html
1<p>
2  If HTML is the <strong>skeleton</strong>, then <em>CSS is the paintbrush</em>
3  for the browser. This blog helps you understand the building blocks of the web.
4</p>
```

```css
1p {
2  color: #333;
3}
```

What this really means: "Style every <p> element on the page

1. Simple
2. Predictable
3. Great for base styles

This is usually where developers start:

- Body text
- Headings
- Lists

Think of element selectors as default rules for your page.
