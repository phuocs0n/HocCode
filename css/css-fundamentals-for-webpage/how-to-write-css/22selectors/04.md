## Class Selector (For Reusable Styling)

A class selector lets you style only the elements you choose.

```html
1<p class="highlight">This paragraph stands out.</p>
2<p>But not this paragraph.</p>
3<p class="highlight">Another paragraph that stands out.</p>
```

```css
1.highlight {
2  background-color: #fff3cd;
3}
```

#### How developers think about classes:

1. "I might reuse this"
2. "This is a pattern, not a one-off"
3. "This feels like a component"

Classes are the most commonly used selector in real projects.
