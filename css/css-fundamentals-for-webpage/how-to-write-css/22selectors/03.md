## Why Element Selectors Aren't Always Enough

As your page grows, not all paragraphs should look the same. For example,

1. A paragraph in the introduction
2. A paragraph inside a highlighted section
3. A paragraph inside a footer

They may all be <p> tags, but they don't serve the same purpose. That's where class selectors come in.
