## Element, Class, and ID Selectors

In the previous lesson, you wrote CSS like this:

```html
1<p>
2  If HTML is the <strong>skeleton</strong>, then <em>CSS is the paintbrush</em>
3  for the browser. This blog helps you understand the building blocks of the web.
4</p>
```

```css
1p {
2  color: #333;
3  font-size: 16px;
4}
```

You might not have realized it yet, but you were already using a selector. Specifically, this is called an element selector.

So instead of introducing something completely new, let's name and build on what you've already practiced.
