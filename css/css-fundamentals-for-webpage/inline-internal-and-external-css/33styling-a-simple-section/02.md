# What We'll Style First

#### Course: CSS Fundamentals for Your First Webpage

## What We'll Style First

We'll focus only on:

1. <h1>
2. <p>

These elements exist in almost every webpage and set the tone for everything else.

#### Example

```html
1<div class="page">
2  <h1>Welcome to My Page</h1>
3  <p>This is a simple paragraph styled with CSS.</p>
4</div>
```

```css
1h1 {
2  color: #2c3e50;
3  font-size: 32px;
4  font-family: Arial, sans-serif;
5}
6
7p {
8  color: #555;
9  font-size: 16px;
10  font-family: Arial, sans-serif;
11}
```

#### What's Happening

1. color → controls text color
2. font-size → controls size
3. font-family → controls typography

That's enough for now.
