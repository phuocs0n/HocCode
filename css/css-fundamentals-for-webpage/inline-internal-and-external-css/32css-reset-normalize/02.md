## Why Developers Care About This

When you start building layouts, these default styles cause confusion:

1. "Why is there space here?"
2. "Why won't this align properly?"
3. "Why does this look different in another browser?"

That's when developers realize:

I'm fighting the browser instead of styling my page.

So the first step is simple:

Reset or normalize browser styles.

Let's do an observation task (Very Important, No Code Yet)

1. Open your blog without writing any CSS
2. Look carefully at:
		Space around headingsIndentation of listsDefault font sizes
3. Space around headings
4. Indentation of lists
5. Default font sizes
6. Ask yourself: "Did I add this styling?"

1. Space around headings
2. Indentation of lists
3. Default font sizes

If the answer is no — that's the browser.
