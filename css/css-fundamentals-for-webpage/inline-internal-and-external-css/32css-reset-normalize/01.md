#### Course: CSS Fundamentals for Your First Webpage

## Default Browser Styles

Do you know what the first thing developers usually do before writing any CSS?

They remove the browser's CSS.

Not because the browser is wrong —but because developers want control.

#### What's Going On Before You Write Any CSS?

Before you touch CSS, the browser already applies styles:

1. Headings come with spacing
2. Paragraphs have margins
3. Lists are indented
4. Buttons look styled

You didn't write this CSS. The browser did.
