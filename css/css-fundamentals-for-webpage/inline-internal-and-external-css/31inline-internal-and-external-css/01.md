## Inline CSS — Styling a Single Element

Let's start with the most direct (and least scalable) option.

What it is: Inline CSS is written directly inside an HTML tag. It styles one element only.

Where it lives: Inside the HTML element itself.

```html
1<p style="color: red;">This text is red</p>
```

What to notice:

1. The style is tied to the element
2. There's no separation between HTML and CSS

#### Developer take:

Inline CSS is useful for quick testing or debugging. In real projects, it becomes messy fast — so we avoid it.
