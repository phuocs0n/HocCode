## Internal CSS — Styling Inside the HTML File

Next is internal CSS.

What it is:CSS written inside a <style> tag within the HTML file.

Where it lives: Inside the <head> section of the HTML.

```html
1<head>
2  <style>
3    p {
4      color: blue;
5    }
6  </style>
7</head>
```

What to notice:

1. Styles apply to the entire page
2. CSS is still locked to a single HTML file

#### Developer take:

Okay for small demos or learning experiments. Not ideal once a project has multiple pages or components.
