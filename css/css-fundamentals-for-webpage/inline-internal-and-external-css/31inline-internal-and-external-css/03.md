## External CSS — Styling with a Separate File

This is the approach used in real-world frontend projects.

What it is:CSS written in a separate .css file and linked to HTML.

Where it connects:Using a <link> tag inside the <head>.

```html
1<head>
2  <link rel="stylesheet" href="style.css">
3</head>
```

```css
1p {
2  color: #333;
3}
```

What to notice:

1. HTML stays clean
2. CSS is reusable
3. Styles scale across pages

#### Developer take:

This is the professional standard. Clean, maintainable, and flexible.
