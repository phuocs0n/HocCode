## The calc() Function

The calc() function lets you perform calculations directly in your CSS code. It's useful for mixing units like percentages with pixels or viewport widths with rem.

Example

```html
1<div class="container">
2    <div class="box1">box1</div>
3    <div class="box2">box2</div>
4</div>
```

```css
1.container {
2    width: 50%;
3    height: 200px;
4    background-color: lightblue;
5}
6
7.box1 {
8    /* Calculate width of box1
9    such that box2 can fit next to it */
10    width: calc(100% - 54px);
11
12    /* Convert to inline-block element
13    for side-by-side placement */
14    display: inline-block;
15
16    height: 100px;
17    color: white;
18    background-color: green;
19}
20
21.box2 {
22    /* Fixed width */
23    width: 50px;
24
25    /* Convert to inline-block element
26    for side-by-side placement */
27    display: inline-block;
28
29    height: 100px;
30    color: white;
31    background-color: purple;
32}
```

Run the above code and drag the resize tool to see how box2 maintains its size while box1 resizes responsively within the parent container.
