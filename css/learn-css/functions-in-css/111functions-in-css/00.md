## Introduction

Up to this point, you've used a variety of CSS functions, such as rgb() for defining colors and url() for linking external resources.

In this chapter, you'll learn how to use mathematical and logical functions like calc(), min(), max(), and clamp(). These functions let you perform calculations directly in your CSS and make style decisions based on specific conditions.

You'll also explore advanced color functions like linear-gradient() and radial-gradient().

By the end of this chapter, you'll be able to control responsive layouts and adaptable designs more precisely and incorporate gradients into your designs.
