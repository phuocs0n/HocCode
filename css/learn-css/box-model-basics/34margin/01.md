## inline-block

We've seen that inline elements (like text links) can't have vertical margins, and block elements can.

But what if you want something in between? For example, consider you're building a navigation menu. You want the links on the menu on the same line, but also separated by a margin.

That's where the inline-block comes in.

With inline-block, you get the best of both:

- Inline behavior: Elements stay on the same line.
- Block behavior: You can control the element's width and height, and yes—add vertical margins.

Let's explore this with an example:

```html
1<nav>
2    <ul>
3        <li><a href="#home">Home</a></li>
4        <li><a href="#about">About</a></li>
5        <li><a href="#contact">Contact</a></li>
6        <li><a href="#services">Service</a></li>
7    </ul>
8</nav>
```

```css
1nav li {
2    background-color: pink;
3    
4    display: inline-block;
5
6    /* Accepts block behavior while remaining inline */
7    width: 150px;
8    height: 50px;
9    margin: 10px; 
10}
```

With this covered, let's get back to margins.
