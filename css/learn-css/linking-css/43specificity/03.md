## Handling CSS Rules with the Same Specificity

When two CSS rules have the same specificity, which rule do you think gets applied?

Let's explore this with an example:

```html
1<p>This is a paragraph.</p>
```

```css
1/* First Rule */
2p {
3    color: red;
4}
5
6/* Second Rule */
7p {
8    color: blue;
9}
```

In this case, both rules target all <p> elements and have the same specificity.

In such cases, the rule that comes last in your CSS file is applied.

This is because CSS stands for Cascading Style Sheets. Rules "cascade," meaning they are applied in layers, with the last rule overriding any earlier ones when they have the same specificity.
