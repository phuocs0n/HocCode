## Example 1: Element and Class Selectors

Element selectors target all instances of a tag type.

Class selectors are more specific, targeting only elements with a particular class. Hence, they override element selectors.

Run the code below to see this in action.

```html
1<p class="my-class">This is a paragraph.</p>
```

```css
1/* Element selector */
2p {
3    color: red;
4}
5
6/* Class selector */
7.my-class {
8    color: green;
9}
```

In this example, the class selector .my-class overrides the element selector p. So, the paragraph text is green.
