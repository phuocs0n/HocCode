## Introduction

In CSS, it's possible for multiple rules to apply to the same element.

When multiple CSS rules target the same element, the rule that gets applied is determined by its specificity. More specific rules override less specific ones.

The order of selectors from least to most specific is:

1. Element selectors
2. Class selectors
3. ID selectors
