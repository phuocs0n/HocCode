## Linking CSS with HTML

You can link a .css file with a .html file using the <link> tag. Simply put it in the <head> tag of the HTML document as follows:

```css
<head>
    <link rel="stylesheet" href="style.css">
</head>
```

All the styling rules you write in style.css will be applied to the HTML document.

This way of linking a CSS file with HTML is also known as external linking.
