## Linking Multiple CSS Files

When working on real-world projects, your CSS code can get long. In such cases, you may need to organize your code in multiple files.

That's when external linking comes in handy, as you can link multiple CSS files to an HTML document.

Here's what linking multiple CSS files may look like:

```css
<head>
    <link rel="stylesheet" href="style1.css">
    <link rel="stylesheet" href="style2.css">
    <link rel="stylesheet" href="style3.css">
</head>
```

This way, all the styling rules in style1.css, style2.css, and style3.css will be applied to the HTML document.
