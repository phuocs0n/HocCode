## Revision: Selectors

Element Selectors

The element selector applies styles to all HTML elements of a given type (e.g., <h1>, <p>).

For example, h1 { color: red; } will style all <h1> elements with red text.

Class Selectors

Class selectors apply styles to elements with a specific class attribute.

For example, .first-paragraph { background-color: orange; } will style all elements with the class first-paragraph.

Universal Selector

The universal selector (*) targets all HTML elements.

For example, * { color: red; } applies the red text color to every element.

It's mostly used to reset default styles, such as setting margin: 0 and padding: 0, to ensure consistency across browsers.
