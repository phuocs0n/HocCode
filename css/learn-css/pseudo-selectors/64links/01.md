## Important Note about CSS Order

The order of CSS rules for link states matters. If you place :visited last, it will override any :hover or :active styles you set for links that have been visited, meaning :hover and :active effects won't show up on links you've clicked on before.

Here's an easy rule to follow:

- Always write your CSS rules in this order for links: :link, :visited, :hover, :active.
- This way, :hover and :active will work correctly for all links—even after they've been clicked on.
