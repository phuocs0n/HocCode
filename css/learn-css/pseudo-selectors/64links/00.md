## Links (Anchor Tags <a>)

Links allow users to navigate from one page to another. You can style these links to change their appearance based on how the user interacts with them.

Let's look at how to change the color of a link in different states: normal, visited, hovered, and active.

Use pseudo-classes such as visited, hover, and active to apply CSS to different states.

Example

```html
1<a href="https://programiz.pro" target="_blank">Welcome to Programiz Pro</a>
```

```css
1/* Normal state:
2 how the link looks when 
3it's not clicked */
4a {
5    color: blue;
6}
7
8/* Visited state: 
9how the link looks after the user 
10has visited it */
11a:visited {
12    color: purple;
13}
14
15/* Hover state: 
16how the link looks when the user 
17hovers their mouse over it */
18a:hover {
19    color: red;
20}
21
22/* Active state: 
23how the link looks when the 
24user clicks and holds the mouse button */
25a:active {
26    color: green;
27}
```

Hit run code and try it out.

The link will change colors as you interact with it:

- You can see the link in its default blue state.
- When you hover over it, notice how the color changes to red.
- As you click and hold the link, it turns green, indicating the active state.
- Once you visit the link and return to this page, you'll see it's purple, showing that you've already visited it.
