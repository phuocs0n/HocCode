## Applying Animation

Applying animation to an element is similar to applying transitions. The syntax is:

```css
animation: animation-name duration timing-function;
```

Then, this is how it looks like to apply box-animation, along with duration and timing-function:

```css
animation: box-animation 3s linear;
```

Here's how it works:

- box-animation is the animation name we defined with @keyframes.
- 3s sets the total duration of the animation to 3 seconds.
- linear makes the animation progress at a constant speed from start to finish.

This setup causes the box element to follow the path defined in the keyframes smoothly over 3 seconds.

Thus, our final code looks like this:

```html
1<div class="box">Click and Hold Me!</div>
```

```css
1.box {
2    height: 120px;
3    width: 120px;
4    background-color: #50e3c2;
5    border-radius: 15px;
6
7    /* Centering the text */
8    display: flex;
9    align-items: center;
10    justify-content: center;
11}
12
13/* Define custom animation */
14@keyframes box-animation {
15    0% {
16        translate: 0px 0px;
17    }
18
19    25% {
20        translate: 100px 0px;
21    }
22
23    50% {
24        translate: 100px 100px;
25    }
26
27    75% {
28        translate: 0px 100px;
29    }
30
31    100% {
32        translate: 0px 0px;
33    }
34}
35
36/* Apply animation when clicked */
37.box:active {
38    animation: box-animation 3s linear;
39}
```
