## Infinite Animation

You can make any animation run infinitely by adding the infinite value in the animation property.

Example

```html
1<div class="box"></div>
```

```css
1.box {
2    /* Run animation infinitely */
3    animation: box-animation 3s linear infinite;
4}
```

Run the above code to see the box element animate infinitely.
