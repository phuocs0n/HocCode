## Creating Animations

The @keyframes keyword allows you to define an animation and keyframes for the animation.

In the previous example, we created an animation called box-animation, which looks like this:

```css
@keyframes box-animation {
    0% {
        translate: 0px 0px;
    }

    25% {
        translate: 100px 0px;
    }

    50% {
        translate: 100px 100px;
    }

    75% {
        translate: 0px 100px;
    }

    100% {
        translate: 0px 0px;
    }
}
```

Here, the percentages (0%, 25%, 50%, etc.) represent different points in the animation's timeline, each with its own style settings. Here's how it works:

| Stage | Action |
| --- | --- |
| 0% | Element is at its original position. |
| 25% | Element moves 100px to the right. |
| 50% | Element moves 100px down while staying 100px to the right. |
| 75% | Element moves 100px to the left while staying 100px down. |
| 100% | Element returns to its starting position. |

The keyframe percentages give you control over an animation's flow, letting you create complex movement or style changes at precise points.
