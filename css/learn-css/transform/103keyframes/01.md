## Example: Basic Moving Animation

First, let's see a simple animation we've created using keyframes. After that, we'll break down the animation and see how it works.

```html
1<div class="box">Click and Hold Me!</div>
```

```css
1.box {
2    height: 120px;
3    width: 120px;
4    background-color: #50e3c2;
5    border-radius: 15px;
6
7    /* Centering the text */
8    display: flex;
9    align-items: center;
10    justify-content: center;
11}
12
13/* Define custom animation */
14@keyframes box-animation {
15    0% {
16        translate: 0px 0px;
17    }
18
19    25% {
20        translate: 100px 0px;
21    }
22
23    50% {
24        translate: 100px 100px;
25    }
26
27    75% {
28        translate: 0px 100px;
29    }
30
31    100% {
32        translate: 0px 0px;
33    }
34}
35
36/* Apply animation when clicked */
37.box:active {
38    animation: box-animation 3s linear;
39}
```

Run the above code and click (and hold) the box element to see it animate.

As you can see, the box moves in a square movement pattern.

Now, you'll learn how this code works.
