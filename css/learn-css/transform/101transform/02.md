# The translate Property

#### Course: Learn CSS

## The translate Property

The translate property allows you to move an element.

Let's use it to move a box when clicked on it:

```html
1<h1>Translate 300px to the right and 50px down.</h1>
2<p>Click the box to see the change.</p>
3<div class="box">Click Me!</div>
```

```css
1.box:active {
2    /* Moves box 300px to the right and 50px down */
3    translate: 300px 50px;
4}
```

Run the above code and click the box element to see how its position changes. The box moves 300px to the right and 50px down from its original position.
