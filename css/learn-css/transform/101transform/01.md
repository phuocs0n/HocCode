## Transform in CSS

An animation is a combination of transform and transition.

In our progress bar example, as the bar fills, its width changes—this change is a transform.

To make this change happen smoothly over time, you use a transition.

The combination of the transform and the transition creates the animation effect.

In this chapter, you'll learn the following CSS transformations:

- translate
- rotate
- scale
