## Change Multiple Property Values

Now, let's add a transition to scale the "No" button.

Since we already have a transition for rotate, here's how you can add another transition for scale:

```css
transition: rotate 1s linear, scale 1s ease;
```

This is what our code looks like after the addition:

```html
1<div id="container">
2    <h1>In your opinion, is it fair for CSS to be overlooked as a non-programming language?</h1>
3    <button class="yes">Yes</button>
4    <button class="no">No</button>
5</div>
```

```css
1button {
2    transition: rotate 1s linear, scale 1s ease;
3}
4
5.yes:hover {
6    rotate: 360deg;
7}
8
9.no:hover {
10    scale: 1.5;
11}
```

Run the above code to see how the "Yes" and "No" buttons animate.
