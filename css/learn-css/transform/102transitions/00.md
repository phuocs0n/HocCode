## CSS Transitions

CSS transitions allow you to create smooth animations by changing the values of CSS properties over a specified duration when an element's state changes, such as on hover or focus.

Let's look at an example:

```html
1<h1>CSS Transitions</h1>
2<p>Click the boxes to see the difference that transitions make.</p>
3<div class="box box1">Box1</div>
4<div class="box box2">Box2</div>
```

```css
1.box1 {
2    background-color: #50e3c2;
3
4    /* No transition */
5}
6
7.box2 {
8    background-color: #3a8106;
9
10    /* Simple transition for smooth effect */
11    transition: 1.5s ease;
12}
```

Run the code above and click the boxes to observe how box1 and box2 transform, with and without transitions, respectively.

In this example, we've applied a simple transition to box2, making its transformation appear smoothly over time. On the other hand, box1's transformation occurs instantly, without any smooth transition.

Adding transitions to your transformations helps create smooth animations, enhancing the user experience and making your website more visually engaging.
