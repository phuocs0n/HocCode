# Transition Property

#### Course: Learn CSS

## Transition Property

The syntax of the transition property is:

```css
transition: property duration timing-function;
```

Here,

- property specifies the CSS property to animate.
- duration sets the time it takes for the transition to complete.
- timing-function defines how the speed is controlled throughout the transition.

Now, let's look at an example.

```html
1<div id="container">
2    <h1>In your opinion, is it fair for CSS to be overlooked as a non-programming language?</h1>
3    <button class="yes">Yes</button>
4    <button class="no">No</button>
5    <p class="message">Isn't it crazy? CSS is more powerful than what most people think!</p>
6</div>
```

```css
1button {
2     transition: rotate 1s ease;
3}
```

Here, the "Yes" button rotates over a period of 1s when hovered over.

Notice how we haven't added any transitions for scaling the "No" button. That's why the change in scale is instantaneous.
