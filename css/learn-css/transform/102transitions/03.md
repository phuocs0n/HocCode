## Example: Timing Functions

Let's now use the linear timing function for the "Yes" button in our previous yes/no animation:

```html
1<div id="container">
2    <h1>In your opinion, is it fair for CSS to be overlooked as a non-programming language?</h1>
3    <button class="yes">Yes</button>
4    <button class="no">No</button>
5</div>
```

```css
1button {
2    transition: rotate 1s linear;
3}
4
5.yes:hover {
6    rotate: 360deg;
7}
8
9.no:hover {
10    scale: 1.5;
11}
```

Run the above code to see how the linear timing function affects the previous animation.

Also, make sure to check the other timing functions like ease-out, ease-in, ease-in-out, and cubic-bezier.
