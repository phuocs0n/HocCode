## Timing Functions

The previous example used ease for the timing function.

Let's explore what other values can be used for the timing function.

Example

```html
1<body>
2    <h1> Hover over the container to see the animation. </h1>
3
4    <div class="container">
5        <div class="box box-1">ease</div>
6        <div class="box box-2">ease-in</div>
7        <div class="box box-3">ease-out</div>
8        <div class="box box-4">ease-in-out</div>
9        <div class="box box-5">linear</div>
10        <div class="box box-6">cubic-bezier</div>
11    </div>
12</body>
```

```css
1.container:hover .box {
2    translate: 55vw 0px;
3}
4
5.box-1 {
6    transition: translate 2s ease;
7}
8
9.box-2 {
10    transition: translate 2s ease-in;
11}
12
13.box-3 {
14    transition: translate 2s ease-out;
15}
16
17.box-4 {
18    transition: translate 2s ease-in-out;
19}
20
21.box-5 {
22    transition: translate 2s linear;
23}
24
25.box-6 {
26    transition: translate 2s cubic-bezier(0.075, 0.82, 0.165, 1);
27}
```

Run the code and observe the output.

Notice how their speeds change throughout the phases of the animation.

This can be summarized by the table below:

| Timing Function | Description |
| --- | --- |
| ease | Starts slow, speeds up, then slows down. |
| linear | Constant speed from start to finish. |
| ease-out | Starts quickly, and then slows down. |
| ease-in | Starts slowly, and then speeds up. |
| ease-in-out | Starts slowly, speeds up, then slows down. |
| cubic-bezier | Follows the speed curve as defined. |
