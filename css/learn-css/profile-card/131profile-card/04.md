## Step 3: Resetting Browser Styles

You can reset the browser's default styles by setting

- padding and margin to 0.
- box-sizing to border-box.

Source Code

```html
1<div class="container">
2    <div class="card">
3        <div class="background">
4            <div class="image-wrapper">
5                <img src="/images/learn-css/jane-austen.jpg" alt="Jane Austen's profile picture">
6            </div>
7        </div>
8
9        <div class="content">
10            <h2>Jane Austen</h2>
11
12            <p>
13                Frontend Developer
14                <br>
15                <a href="#" class="link" title="Programiz">Programiz</a>
16            </p>
17
18            <ul class="chips">
19                <li class="chip">Figma</li>
20                <li class="chip">ReactJS</li>
21                <li class="chip">NodeJS</li>
22            </ul>
23            <div class="action-button">
24                <a href="#contact-me" title="Contact Me">Contact Me</a>
25                <a href="#portfolio" title="View Portfolio" class="secondary">View Portfolio</a>
26            </div>
27        </div>
28    </div>
29</div>
```

```css
1* {
2    padding: 0;
3    margin: 0;
4    box-sizing: border-box;
5    line-height: 1.5;
6}
```

Run the above code to see how everything is tightened up, unlike how they were spaced before. This means the default padding and margin values provided by the browser have been reset.

Here, notice line-height is set to 1.5, which has become a commonly accepted value across modern websites. This is to create enough vertical spacing between lines.
