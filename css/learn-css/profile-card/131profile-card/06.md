## Step 5: Container and Card Layout

Use flexbox to center the card both vertically and horizontally within the viewport.

```css
.container {
    display: flex;
    justify-content: center;
}
```

Then, create a responsive layout for the card with flexbox and add rounded corners.

```html
1<div class="container">
2    <div class="card">
3        <div class="background">
4            <div class="image-wrapper">
5                <img src="/images/learn-css/jane-austen.jpg" alt="Jane Austen's profile picture">
6            </div>
7        </div>
8
9        <div class="content">
10            <h2>Jane Austen</h2>
11
12            <p>
13                Frontend Developer
14                <br>
15                <a href="#" class="link" title="Programiz">Programiz</a>
16            </p>
17
18            <ul class="chips">
19                <li class="chip">Figma</li>
20                <li class="chip">ReactJS</li>
21                <li class="chip">NodeJS</li>
22            </ul>
23            <div class="action-button">
24                <a href="#contact-me" title="Contact Me">Contact Me</a>
25                <a href="#portfolio" title="View Portfolio" class="secondary">View Portfolio</a>
26            </div>
27        </div>
28    </div>
29</div>
```

```css
1.container {
2    display: flex;
3    justify-content: center;
4}
5
6.card {
7    display: flex;
8    border-radius: 24px;
9    background-color: white;
10    box-shadow: 0 10px 15px rgba(0, 0, 0, 0.1);
11    max-width: clamp(320px, 70vw, 740px);
12    min-width: min(320px, 100vw);
13    flex-direction: column;
14}
```

Here, the element's maximum width will be 70% of the viewport width, but it will never be smaller than 320px or larger than 740px.
