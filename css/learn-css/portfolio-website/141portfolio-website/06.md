## Basic HTML Structure

HTML offers a variety of semantic tags that enhance accessibility and improve SEO by helping search engines understand the content structure.

It's good practice to use semantic tags whenever possible.

Here are some semantic tags that can be used in the portfolio website:

- <header> - Holds introductory or navigational content, such as logos and menus.
- <main> - Encloses the main content of the webpage
- <section> - Defines standalone sections within the page, like Hero, About, Blogs, etc.
- <footer> - Contains footer information, such as copyright details, links, or contact information.

The basic HTML structure for the portfolio website might look like this:

```html
1<header class="header">HEADER</header>
2
3<main class="main">
4    <section class="hero">HERO</section>
5    <section class="about">ABOUT</section>
6    <section class="blogs">BLOGS</section>
7    <section class="projects">PROJECTS</section>
8    <section class="contact">CONTACT</section>
9</main>
10
11<footer class="footer">FOOTER</footer>
```

```css
1/* Import Fonts */

3@import url("https://fonts.googleapis.com/css2?family=Galdeano&display=swap");
4
5/* Reset browser defaults */

7    padding: 0;
8    margin: 0;
9    box-sizing: border-box;
10    font-family: 'Euclid Circular A', sans-serif;

12
13/* Contain image */
14img {

16    height: auto;
17}
18
19/* Style header and footer */
20.header,
21.footer {
22    background-color: #2c2e48;
23    color: white;

25    display: flex;

29
30/* Style sections */

32    display: flex;
33    flex-direction: column;
34    align-items: center;
35    justify-content: center;

39}

44}

48}
```

Run the above code to see how the basic structure of the portfolio website looks.

Notice each section has a specified height with alternating background colors to make the layout visually clear and organized.
