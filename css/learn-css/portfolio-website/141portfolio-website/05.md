## Basic Setup

For this project, the primary font is Euclid Circular A, with Galdeano as the secondary font. Here's the code to import these fonts:

```css
@import url("https://fonts.googleapis.com/css2?family=Euclid+Circular+A:wght@400;500&display=swap");
@import url('https://fonts.googleapis.com/css2?family=Galdeano&display=swap');
```

Since images have inherent dimensions that might not align with their containers, the style below is an easy way to ensure they resize proportionally to fit within their containers:

```css
img {
    max-width: 100%;
    height: auto;
}
```
