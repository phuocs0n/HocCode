## Common Styles

To maintain readability and consistency, let's use a unified text color (#25265e) across all headings and paragraphs.

1. Headings (<h2>): A larger font size of 32px with bold weight (600) to stand out, centered for emphasis and balance.
2. Paragraphs (<p>): A smaller font size of 18px with lighter weight (300) for readability without overwhelming the user.

```html
1<section class="about" id="about">
2    <h2>About Me</h2>
3    <p>
4        I'm a frontend developer with a passion for creating clean, responsive web experiences. 
5        Currently working at Programiz, I specialize in HTML, CSS, JavaScript, and React. 
6        I also have a strong background in UI/UX design, working with tools like Figma to bring intuitive 
7        and visually appealing interfaces to life.
8    </p>
9</section>
```

```css
1section h2 {
2    color: #25265e;
3    font-size: 32px; 
4    font-weight: 600; 
5    text-align: center; 
6}
7
8section p {
9    color: #25265e;
10    font-size: 18px;
11    font-weight: 300;
12}
```

This standardized CSS ensures that all section headings and paragraphs maintain a cohesive design throughout the site, as shown in the image.

The layout also looks great on mobile, so no additional adjustments are needed for smaller screens.
