## Individual Card Design

We won't go in-depth on individual card designs as we have covered them already.

```html
1<div class="projects-card">
2    <img src="/images/learn-css/e-commerce.png" alt="Project Image" />
3    <h3>ShopEase</h3>
4    <p class="project-summary">
5        ShopEase is a responsive e-commerce platform offering product
6        listings, cart, checkout, filtering, reviews, and secure
7        payments using modern technologies.
8    </p>
9    <p>
10        ShopEase is a fully responsive and interactive e-commerce
11        platform that offers a seamless shopping experience. It features
12        product listings, shopping cart functionality, secure checkout,
13        product filtering, and user reviews. With an integrated payment
14        gateway, it provides users with a secure and efficient way to
15        shop online. Built using modern web technologies and best
16        practices.
17    </p>
18    <div class="projects-tech-stack">
19        <span>HTML</span>
20        <span>CSS</span>
21        <span>JavaScript</span>
22        <span>API Integration</span>
23        <span>Payment Gateway</span>
24    </div>
25    <a href="#" class="visit-link">Visit Site</a>
26</div>
```

```css
1.projects-card {
2    background-color: #ffffff;
3    border-radius: 10px;
4    box-shadow: 0 4px 8px rgba(0, 0, 0, 0.1);
5    text-align: left;
6    padding: 12px;
7    display: flex;
8    flex-direction: column;
9    gap: 8px;
10    width: min(600px, 100vw);
11}
12
13.projects-card img {
14    width: 100%;
15    height: 50%;
16    border-radius: 10px;
17}
18
19.projects-card h3 {
20    font-size: clamp(12px, 8vw, 24px);
21    color: #25265e;
22    font-weight: 550;
23}
24
25.projects-card p {
26    font-size: 16px;
27}
28
29.projects-card a {
30    text-decoration: none;
31    color: #0556f3;
32    font-weight: medium;
33}
34
35.projects-tech-stack {
36    display: flex;
37    gap: 10px;
38}
39
40.projects-tech-stack span {
41    background-color: #f3f3f3;
42    color: #49497e;
43    padding: 5px 10px;
44    border-radius: 5px;
45    font-size: 0.8rem;
46}
```

Here,

1. .projects-card creates a card layout with a white background, shadow, and rounded corners for a clean, professional look. The flexible width keeps it responsive.
2. The project image has rounded corners to match the card style and fills the card width.
3. The <h3> title uses a responsive font size (clamp) to ensure readability on different screens.
4. a.visit-link is styles as a clickable link to the project.
5. .projects-tech-stack, a flex container, contains tags for the technologies used in each project.

This setup organizes each project as a card element with a consistent design and ensures responsiveness across devices.
