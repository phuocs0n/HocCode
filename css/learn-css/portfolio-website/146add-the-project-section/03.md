## Making the Layout Responsive

Currently, the layout isn't responsive and doesn't display well on mobile devices. Let's use media queries to make adjustments for screens that are 768px or narrower.

Here's what you'll do:

1. Stack the cards vertically on smaller screens.
2. Remove the tech stack and descriptions on mobile to reduce clutter.
3. Center-align all items within each card on mobile for a consistent look.

In the above code,

1. .projects-grid: On screens 768px or narrower, the grid switches to a flex layout to stack each card vertically. The gap property adds space between the stacked cards.
2. .tech-tag-list and .projects-card p: The tech stack and description paragraph are hidden to make the cards more compact on mobile screens.
3. .projects-card Alignment: On mobile, items in each project card are center-aligned for a consistent look.

This setup ensures the project section remains visually appealing and accessible across various screen sizes, especially on mobile.
