## Style Logo

Here's the CSS to style the logo:

```html
1<header class="header">
2    <div class="logo">Jane</div>
3    <div class="nav">
4        <a href="#projects">Projects</a>
5        <a href="#contact">Contact</a>
6    </div>
7</header>
```

```css
1.logo {
2    font-size: 32px;
3    font-weight: 400;
4    font-family: Galdeano, sans-serif;
5    color: white;
6}
```

In this code,

- font-size: 32px makes the logo text prominent and easy to notice.
- font-weight: 400 keeps the text from being too bold, giving it a clean, professional look.
- font-family: Galdeano, sans-serif applies the imported Galdeano font, giving it a modern, professional style that pairs well with the rest of the header.
- color: white keeps the logo text white to standout against the header background, enhancing readability.
