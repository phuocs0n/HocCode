## Style Navigation Links

Here's how you can space the links apart:

```html
1<header class="header">
2    <div class="logo">Jane</div>
3    <div class="nav">
4        <a href="#projects">Projects</a>
5        <a href="#contact">Contact</a>
6    </div>
7</header>
```

```css
1.nav {
2    display: flex;
3    gap: 24px;
4}
5
6.nav a {
7    text-decoration: none;
8    color: white;
9    font-size: 16px;
10    letter-spacing: 1px;
11}
```

In the .nav bar,

1. display: flex arranges the links in a horizontal row.
2. gap: 24px creates space between each link.

For each .nav a link,

1. text-decoration: none removes the underline.
2. color: white matches the header color.
3. font-size: 16px and letter-spacing: 1px  increases the font size and spacing between each letter, improving readability.

Since you have used flexbox for the most part, the layout should be responsive. Check how the website looks on a mobile device by resizing the output browser.
