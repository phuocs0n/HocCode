## Card Layout Design

Add this code to your index.html file to display multiple cards in a responsive grid:

```html
1<div class="card-row">
2    <div class="card">
3        <img src="/images/learn-css/flexbox.png" alt="Understanding Flexbox in CSS" />
4        <h3>Understanding Flexbox in CSS</h3>
5        <p>freeCodeCamp</p>
6        <button>Read</button>
7    </div>
8    <div class="card">
9        <img src="/images/learn-css/responsive-design.png" alt="Mastering Responsive Design" />
10        <h3>Mastering Responsive Design</h3>
11        <p>Medium</p>
12        <button>Read</button>
13    </div>
14    <div class="card">
15        <img src="/images/learn-css/advanced-grid.png" alt="Advanced CSS Grid Techniques" />
16        <h3>Advanced CSS Grid Techniques</h3>
17        <p>Programiz Blogs</p>
18        <button>Read</button>
19    </div>
20</div>
```

```css
1/* Card Container */
2.card-row {
3    display: flex;
4    flex-wrap: wrap;   
5    justify-content: center;   
6    gap: 20px;   
7    margin: 40px auto;    /* Center the container */
8    padding: 0 20px;    
9    max-width: 1200px;
10}
```

In .card-row,

1. display: flex and flex-wrap: wrap make the cards responsive, wrapping to the next line on smaller screens.
2. justify-content: center aligns the cards in the center, and gap: 20px provides space between them.
3. max-width: 1200px keeps the layout contained on larger screens.

In .card, consistent styles (background, shadow, and rounded corners) for an elegant and cohesive look.

This setup displays each blog card in a responsive, centered grid layout that looks good on both desktop and mobile screens.
