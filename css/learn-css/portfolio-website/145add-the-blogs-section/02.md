## Code for Individual Card

Here's the HTML for a single blog card:

```html
1<div class="card">
2    <img src="/images/learn-css/flexbox.png" alt="Understanding Flexbox in CSS" />
3    <h3>Understanding Flexbox in CSS</h3>
4    <p>freeCodeCamp</p>
5    <button>Read</button>
6</div>
```

The CSS that styles the card:

```html
1<div class="card">
2    <img src="/images/learn-css/flexbox.png" alt="Understanding Flexbox in CSS" />
3    <h3>Understanding Flexbox in CSS</h3>
4    <p>freeCodeCamp</p>
5    <button>Read</button>
6</div>
```

```css
1/* Blog card styling */
2.card {
3    background-color: white;
4    border-radius: 8px;    /* Rounded corners */
5    box-shadow: 0 3px 4px rgba(0, 0, 0, 0.1);    /* Subtle shadow */
6    width: 300px;    /* Fixed width */
7    text-align: center;
8    display: flex;
9    flex-direction: column;    /* Stack content vertically */
10    gap: 4px;    /* Small gap between content */
11    align-items: center;
12    padding: 24px 0;    /* Adds padding */
13}
14
15/* Blog card image */
16.card img {
17    border-radius: 50%;    /* Circular image */
18    width: 192px;
19    height: 192px;
20    object-fit: cover;    /* Ensures image fits the circle */
21    margin-bottom: 16px;    /* Space below the image */
22}
23
24/* Blog card title */
25.card h3 {
26    color: #25265e;
27    font-weight: 700;
28    font-size: max(1vw, 18px);
29    text-decoration: none;
30}
31
32/* Blog card source */
33.card p {
34    font-size: 1rem;
35    color: #444576;
36}
37
38/* Read button */
39.card button {
40    padding: 8px 30px;
41    background-color: #0556f3;    /* Button background color */
42    color: white;    /* Button text color */
43    border: none;
44    border-radius: 4px;
45    cursor: pointer;
46    margin-top: 24px;
47}
48
49/* Button hover effect */
50.card button:hover {
51    background-color: #6c6ce5;    /* Button color on hover */
52}
```

Here,

1. Card Container: The .card class provides structure and styling for each blog card, using a shadow for depth and rounded corners for a modern look.
2. Image: Circular styling (border-radius: 50%) and object-fit: cover ensures the image fits well within its frame.
3. Title and Source: The heading (h3) and source (p) text are styled with clear, contrasting colors for readability.
4. Read Button: Styled with a bold color, rounded corners, and hover effect for interaction.

With these styles, each blog card will look neat and professional, effectively showcasing individual blog posts. Now, let's create the layout to display multiple cards.
