## Style Heading and Subtitle

```html
1<section class="hero" id="hero">
2    <img src="/images/learn-css/jane-austen.jpg" alt="Profile Picture" />
3    <h1>Hi, I'm Jane Austen</h1>
4    <p>Frontend Developer</p>
5</section>
```

```css
1/* ---------- Hero section ---------- */
2section.hero {
3    display: flex;
4    flex-direction: column;
5    align-items: center;
6    justify-content: center;
7    gap: 8px;
8    min-height: 500px;
9    text-align: center;
10}
11
12section.hero img {
13    width: 200px;
14    height: 200px;
15    border-radius: 50%;    /* Creates a circular image */
16    object-fit: cover;    /* Ensures image covers the circle */
17    margin-bottom: 20px;
18    border: 2px solid white;    /* Adds a clean white border */
19}
20
21section.hero h1 {
22    font-size: 32px;
23    font-weight: 600;
24    color: #25265e;    /* Dark color for emphasis */
25}
26
27section.hero p {
28    font-size: 18px;
29    letter-spacing: 1px;
30    margin-bottom: 10px;
31    font-weight: 400;
32    color: #25265e;
33    text-transform: uppercase;    /* Makes the subtitle all caps */
34}
```

In this code:

1. align-items: center and justify-content: center center the child elements vertically and horizontally.
2. border-radius: 50% gives the profile picture a circular shape.

Similarly, the greeting and job title are styled to complement the overall aesthetic.
