## Relative Measurements

So far, you have only worked with pixels (px), which is a static unit of measurement.

However, CSS offers a wide range of measurement units that size elements based on the size of other elements or viewports. Such units are known as relative measurements.

By understanding and using relative measurements, you can create more adaptable and accessible web designs.

In this lesson, you will learn the following relative measurements:

- em and rem
- % (percentage)
- vh and vw

Use percentages (%), em, rem, viewport width (vw), and viewport height (vh) instead of fixed units like pixels (px) to easily change values throughout your CSS rules.
