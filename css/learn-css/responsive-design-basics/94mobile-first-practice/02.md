# Implementing Mobile-First Design

#### Course: Learn CSS

## Implementing Mobile-First Design

To apply mobile-first design:

1. Write Base Styles: Create CSS for mobile (smallest screen size) without media queries.
2. Add Media Queries with min-width: Use media queries to enhance the design for tablets, desktops, and larger screens.

Example

```html
1<body>
2    <p>Responsive CSS is fun!</p>
3</body>
```

```css
1/* Default style for mobile devices */
2body {
3    font-size: 16px;
4    padding: 4px 8px;
5}
6
7/* Style for larger mobile devices (480px and wider) */
8@media (min-width: 480px) {
9    body {
10        font-size: 18px;
11        padding: 8px 12px;
12    }
13}
14
15/* Style for small desktop devices (768px and wider) */
16@media (min-width: 768px) {
17    body {
18        font-size: 20px;
19        padding: 12px 14px;
20    }
21}
22
23/* Style for desktop devices (1024px and wider) */
24@media (min-width: 1024px) {
25    body {
26        font-size: 22px;
27        padding: 14px 16px;
28    }
29}
```

This setup starts with a simple design for mobile and progressively adds styles for larger screens.
