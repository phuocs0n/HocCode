# The gap Property

#### Course: Learn CSS

## The gap Property

You can add space between all flex items at once using the gap property, which removes the need for individual margins.

Example

```html
1<div class="container">
2    <div class="box box1">First Item</div>
3    <div class="box box2">Second Item</div>
4    <div class="box box3">Third Item</div>
5</div>
```

```css
1.container {
2    display: flex;
3    gap: 10px;
4}
```
