## Example: Flexbox

You can make any element a flexbox by applying display: flex; to it.

Example

```html
1<div class="container">
2    <div class="box box1">First Item</div>
3    <div class="box box2">Second Item</div>
4    <div class="box box3">Third Item</div>
5</div>
```

```css
1.container {
2    display: flex;
3}
```

In this example, you won't notice much visual change yet. The real power of flexbox will now become clear as you start using its flex properties.
