## Limitations of Flexbox

Congrats! You're now proficient with flexboxes.

As you can see, flexbox is perfect for one-dimensional layouts, such as displaying an application's components.

However, it loses its flexibility when working with larger, two-dimensional layouts.

In such scenarios, grids can come in handy. You'll learn about grids in the next chapter.
