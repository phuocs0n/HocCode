## How to Use It?

The following steps will guide you on how to check if a CSS property is compatible across different browsers:

1. Visit the Website

Go to caniuse.com.

2. Search for a Property

Type the CSS property name you want to check (e.g., grid, flexbox, clamp(), etc.).

3. Review the Results

The tool displays a chart showing browser support for the property and some additional information.

Example

Suppose you want to use the clamp() function in your design, which is a relatively newer CSS feature.

Before using it, search for clamp() on "Can I Use?" to check if your audience's browsers support it.

This will tell you which browsers and versions support clamp(), helping you decide whether to use it in your design.
