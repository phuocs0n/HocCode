# Use Class Selectors Instead of Tag Selectors

#### Course: Learn CSS

## Use Class Selectors Instead of Tag Selectors

Using a tag selector (div, p, a, etc.) applies styling to every instance of that tag, which can lead to unintended styling across your site.

Additionally, you can't reuse the same styles across different tags with a tag selector, limiting your code's flexibility and reusability.

The class selector resolves these issues by allowing you to apply styles only to specific elements, making it easier to reuse styles across multiple tags.

Good Example

```html
1<h1 class="styled-text">Heading</h1>
2<h2 class="styled-text">Subheading 1</h2>
3<p class="styled-text">Paragraph 1</p>
4
5<h2>Subheading 2</h2>
6<p>Paragraph 2</p>
```

```css
1.styled-text {
2    font-family: Arial, sans-serif;
3    color: #feb012;
4}
```

Here, the styled-text class is applied to multiple tags—<h1>, <h2>, and <p>. However, not all occurrences of <h2> and <p> are styled.

Bad Example

```html
1<h1>Heading</h1>
2<h2>Subheading 1</h2>
3<p>Paragraph 1</p>
4<h2>Subheading 2</h2>
5<p>Paragraph 2</p>
```

```css
1h1 {
2    font-family: Arial, sans-serif;
3    color: #feb012;
4}
5
6h2 {
7    font-family: Arial, sans-serif;
8    color: #feb012;
9}
10
11p {
12    font-family: Arial, sans-serif;
13    color: #feb012;
14}
```

In this example, each tag requires its own selector for styling, even though the same style is being applied to each tag.

Additionally, the h2 and p selectors style every instance of <h2> and <p>, leading to unintended styling effects.
