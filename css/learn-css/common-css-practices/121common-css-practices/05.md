## Use Consistent Naming Conventions

You should follow the practices below to maintain a good and consistent naming convention:

i. Choose Clear, Descriptive Names

Pick names for classes and IDs that describe the purpose or appearance of the element. This makes your code intuitive, even at a glance.

| Good Name | Bad Name |
| --- | --- |
| primary-button | btn1 |
| error-message | error |
| header-container | hc |
