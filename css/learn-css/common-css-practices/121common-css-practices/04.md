## Keep Your CSS Organized

When your styles are arranged logically, it's much easier to understand and update code—especially in larger projects or when working with others.

Group related styles together into sections, such as

- Typography
- Layout
- Color schemes

Use comments to label these sections or describe their purpose.

This makes locating and modifying specific CSS parts quicker, improving both efficiency and clarity.

Good Example

```css
/* Typography */
h1, h2 {
    font-family: Arial, sans-serif;
    color: #333333;
}

/* Layout */
.container {
    width: 100%;
    max-width: 1200px;
    margin: 0 auto;
}

/* Color Scheme */
.primary-button {
    background-color: #3498db;
    color: white;
}
```

In this example, related styles are grouped by category, making the code clear and easy to navigate.

Bad Example

```css
.container {
    width: 100%;
    max-width: 1200px;
    margin: 0 auto;
}

h1 {
    font-family: Arial, sans-serif;
    color: #333333;
}

.primary-button {
    background-color: #3498db;
    color: white;
}

h2 {
    font-family: Arial, sans-serif;
    color: #333333;
}
```

In this version, styles are scattered randomly, making it harder to locate specific sections.
