## Auto Placement

Until now, you have only created grid layouts and allowed grid items to fill the grid areas automatically.

However, you can also assign specific areas to specific grid items. This gives you greater control over the layout.

In this lesson, you will learn to control the positioning of grid items.

Additionally, you will learn to manage complex grid layouts more effectively using named areas.
