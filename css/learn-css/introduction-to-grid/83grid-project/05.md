## Styling Cards

It's time to style the cards to look as beautiful as shown in the design.

Since each card has a similar structure, we can use the .projects-grid > div selector to style all of them at once.

```css
1/* Import custom font */
2@import url("https://fonts.googleapis.com/css2?family=Euclid+Circular+A:wght@400;500&display=swap");
3
4* {
5    font-family: 'Euclid Circular A', sans-serif;
6    line-height: 1.5;
7}
8
9.projects-grid {
10    display: grid;
11    grid-template-columns: 2fr 1fr 1fr;

14}
15
16/* Style cards */

26}
27

32}
33
34/* Style headings */
```
