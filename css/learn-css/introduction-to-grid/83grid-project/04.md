```css

10

12    background-color: gray;
13}
14
15.primary-card {
16    grid-area: 1 / 1 / 3 / 2;
17}
```

After filling in the content, run the above code to see how the grid layout looks.

The images might be overflowing the grid items due to unmatched sizes. You can use the code below to fix this issue:

```css
img {
    width: 100%;
}
```

The width: 100%; rule ensures the images occupy the exact available width—neither less nor more. You will learn about the % unit in greater detail in the next chapter.

Also, notice that the row height is set to auto. This allows the rows to expand based on their content.
