## Float Right

Now, change the box class to float: right and observe the difference.

```html
1<div class="box"></div>
2<p class="content">This is some sample text.</p>
```

```css
1.box {
2    height: 200px;
3    width: 200px;
4    border-radius: 20px;
5    background: #ddd;
6
7    float: right;
8}
```

Run the code and observe the output.

By using float: right, the box is pushed to the right, and the text flows around it on the left. The content behaves similarly but adapts to the new float position.
