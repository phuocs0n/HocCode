## Introduction

In this chapter, you'll learn how to position any HTML element on a webpage using CSS.

The position property is used to precisely control where elements appear on a page, helping you make a pixel-perfect layout.

By default, this property is set to static. To use this property, you'll have to set it to one of the following values:

- relative
- absolute
- fixed
- sticky

Let's learn about these values one by one.
