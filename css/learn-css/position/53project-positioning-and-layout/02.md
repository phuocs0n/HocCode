## Step 2: Positioning the Navbar

Now, let's add these basic CSS to style our navbar:

- Set the background color and height of the navbar.
- Change the navbar's position to sticky so it stays at the top when we scroll.
- Set the color of the text.

```html
1<body>
2    <nav class="navbar">
3        <div class="logo">GreatBrand</div>
4        <div class="navbar-items">
5            <div class="navbar-item">About</div>
6            <div class="navbar-item offer">
7                Special Offers
8                <span class="offer-badge">New!</span>
9            </div>
10        </div>
11    </nav>
12    <main>
13        <p>This is a sample navbar.</p>
14    </main>
15</body>
```

```css
1.navbar {
2    color: white;
3    background: #111111;
4    height: 70px;
5
6    /* Sticky position added */
7    position: sticky;
8    top: 0;
9}
```
