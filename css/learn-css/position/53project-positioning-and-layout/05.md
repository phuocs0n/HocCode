## Step 5: Highlighting Special Offers

Finally, let's style the "Special Offers" navigation item using relative positioning. This will allow us to position the badge relative to this item, making it stand out.

```html
1<body>
2    <nav class="navbar">
3        <div class="logo">GreatBrand</div>
4        <div class="navbar-items">
5            <div class="navbar-item">About</div>
6            <div class="navbar-item offer">
7                Special Offers
8                <span class="offer-badge">New!</span>
9            </div>
10        </div>
11    </nav>
12    <main>
13        <p>This is a sample navbar.</p>
14    </main>
15</body>
```

```css
1.offer {
2    /* Positioning parent */
3    position: relative;
4}
5
6.offer-badge {
7    background-color: red;
8    border-radius: 15px;
9    padding: 5px 8px;
10    font-size: 12px;
11
12    /* Positioning badge */
13    position: absolute;
14    top: -20px;
15    right: -25px;
16}
```
