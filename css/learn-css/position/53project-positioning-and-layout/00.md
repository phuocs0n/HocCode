## Create a Navbar

In this chapter, we learned about the position, z-index, and float properties in CSS. Let's create a navbar using our understanding of these properties.

This is what our final navbar will look like:

```html
1<body>
2    <nav class="navbar">
3        <div class="logo">GreatBrand</div>
4        <div class="navbar-items">
5            <div class="navbar-item">About</div>
6            <div class="navbar-item offer">
7                Special Offers
8                <span class="offer-badge">New!</span>
9            </div>
10        </div>
11    </nav>
12    <main>
13        <p>This is a sample navbar.</p>
14    </main>
15</body>
```

```css
1* {
2    box-sizing: border-box;
3    margin: 0;
4}
5
6body {
7    height: 200vh;
8}
9
10.navbar {
11    background: #111;
12    height: 70px;
13    color: white;
14    padding: 20px;
15    position: sticky;
16    top: 0;
17}
18
19.navbar-item {
20    display: inline-block;
21    margin: 4px 10px;
22}
23
24.logo {
25    font-size: 20px;
26    float: left;
27}
28
29.navbar-items {
30    float: right;
31}
32
33.offer {
34    position: relative;
35}
36
37.offer-badge {
38    background-color: red;
39    border-radius: 15px;
40    padding: 5px 8px;
41    font-size: 12px;
42    position: absolute;
43    top: -20px;
44    right: -25px;
45}
```

Let's begin.
