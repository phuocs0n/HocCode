## Step 4: Aligning Navbar Items

Now, we'll work on the navigation items with these steps:

- Float the items in the navbar-items container to the right.
- Space the items using margin.

```html
1<body>
2    <nav class="navbar">
3        <div class="logo">GreatBrand</div>
4        <div class="navbar-items">
5            <div class="navbar-item">About</div>
6            <div class="navbar-item offer">
7                Special Offers
8                <span class="offer-badge">New!</span>
9            </div>
10        </div>
11    </nav>
12    <main>
13        <p>This is a sample navbar.</p>
14    </main>
15</body>
```

```css
1.navbar-item {
2    /* Stop line breaks between items */
3    display: inline-block;
4
5    /* Margin added */
6    margin: 4px 10px;
7}
8
9.navbar-items {
10    /* Nav items floated right */
11    float: right;
12}
```
