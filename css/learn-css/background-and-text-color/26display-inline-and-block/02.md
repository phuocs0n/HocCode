## Common Block and Inline Elements

Commonly used block-level elements: <p>, <div>, <ul>, <ol>, <h1>, <h2>, and <div>.

Commonly used inline elements: <span>, <strong>, <img>, and <a>.

You don't need to remember whether every element is block-level or inline. Just keep in mind that if certain elements don't behave as expected, it might be due to their display property.
