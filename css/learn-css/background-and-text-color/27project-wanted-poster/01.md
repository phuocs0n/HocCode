## Adding Background and Width

First, let's style the main container (<div>) that wraps all the elements.

```html
1<!DOCTYPE html>
2<html lang="en">
3
4<head>
5    <!-- Load the font -->
6    <link rel="preconnect" href="https://fonts.googleapis.com">
7    <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
8    <link href="https://fonts.googleapis.com/css2?family=Old+Standard+TT:ital,wght@0,400;0,700;1,400&display=swap"
9        rel="stylesheet">
10</head>
11
12<body>
13
14    <!-- Covers all the visible HTML elements -->
15    <div>
16        <h1>wanted</h1>
17        <img src="/images/learn-css/jack-sparrow.png">
18        <h2>jack sparrow</h2>
19        <p>the notorious pirate</p>
20        <h3>reward</h3>
21        <h4><span>$5000</span> $20000</h4>
22    </div>
23    
24</body>
25
26</html>
```

```css
1div {
2    font-family: "Old Standard TT", serif;
3    text-align: center;
4    width: 550px;
5    background: url('/images/learn-css/paper-background.png');
6}
```

We have added these properties to the <div> element:

1. font-family

The font-family property adds the Old Standard TT font to all the text in the poster and sets Serif as the fallback font.

By using font-family on <div>, you don't need to apply it to individual elements, as the <div> element wraps all the content within it.

2. text-align

In the poster, all the text is aligned to the center. Therefore, we have applied text-align: center; to ensure all the text aligns accordingly.

3. width

The poster's width is set to 550 pixels.

4. background

By default, the background image repeats, which fits our needs in this case. Right now, the image is larger than the <div>, but if we use a smaller image or a larger <div>, the repeating will be useful.
