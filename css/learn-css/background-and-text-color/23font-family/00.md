## Font Family

The font-family property is used to specify the font.

```html
1<h2>Web development</h2>
2
3<p>Web development is fun!</p>
4
5<ul>
6    <li>HTML for structure.</li>
7    <li>CSS for styling.</li>
8    <li>JavaScript for interactivity.</li>
9</ul>
```

```css
1ul {
2    font-family: Arial;
3}
```

This code changes the font family of the unordered list to Arial.
