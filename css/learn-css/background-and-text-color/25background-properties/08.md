#### Course: Learn CSS

## Example: background-position

1. Positioning the background image to the right edge of the container and centering it vertically.

```html
1<div>
2    <h1>Welcome to Programiz!</h1>
3    <p>Dive into CSS and start turning boring web pages into something that actually looks good.</p>
4    <h2>Why Learn with Us?</h2>
5    <ul>
6        <li>Code in Your Browser!</li>
7        <li>Create real-world projects.</li>
8        <li>Get Certified for on-demand skills.</li>
9    </ul>
10</div>
```

```css
1div {
2    background-image: url('/images/learn-css/bg1.png');
3    background-repeat: no-repeat; 
4
5    /* Sets the background image to align to the right and vertically center.  */
6    background-position: right center;
7}
```
