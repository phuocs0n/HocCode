# Background Shorthand

#### Course: Learn CSS

## Background Shorthand

Instead of background-color or background-image, it is common to use the shorthand background.

In the example below, the code specifies a background image with a fallback background color on two separate lines:

```html
1<div>
2    <h1>Welcome to Programiz!</h1>
3    <p>Dive into CSS and start turning boring web pages into something that actually looks good.</p>
4
5    <h2>Why Learn with Us?</h2>
6    <ul>
7        <li>Code in your browser.</li>
8        <li>Create real-world projects.</li>
9        <li>Get certified for in-demand skills.</li>
10    </ul>
11</div>
```

```css
1div {
2    background-image: url('/images/learn-css/bg1.png');
3    background-color: #eeeeee;
4    background-size: cover;
5}
```

You can instead combine them using the shorthand property background:

```html
1<body>
2    <div>
3        <h1>Welcome to Programiz!</h1>
4        <p>Dive into CSS and start turning boring web pages into something that actually looks good.</p>
5
6        <h2>Why Learn with Us?</h2>
7        <ul>
8            <li>Code in your browser.</li>
9            <li>Create real-world projects.</li>
10            <li>Get certified for in-demand skills.</li>
11        </ul>
12    </div>
13</body>
```

```css
1body {
2
3    /* background image followed by background color */
4
5    background: url('/images/learn-css/bg1.png') #eeeeee;
6    background-size: cover;
7}
```
