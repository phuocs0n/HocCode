## Background Repeat

You can use the background-repeat property to control how a background image is repeated, whether horizontally, vertically, or not at all.

| Value | Description |
| --- | --- |
| repeat | The image repeats both horizontally and vertically. This is the default value. |
| repeat-x | The image repeats horizontally (left to right). |
| repeat-y | The image repeats vertically (top to bottom). |
| no-repeat | The image does not repeat. |

We'll use no-repeat value to prevent our background from repeating.
