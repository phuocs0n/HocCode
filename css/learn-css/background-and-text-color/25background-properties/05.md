#### Course: Learn CSS

## Background Size

You can specify the width and height of the background image using background-size. For example,

```html
1<div>
2    <h1>Welcome to Programiz!</h1>
3    <p>Dive into CSS and start turning boring web pages into something that actually looks good.</p>
4
5    <h2>Why Learn with Us?</h2>
6    <ul>
7        <li>Code in your browser.</li>
8        <li>Create real-world projects.</li>
9        <li>Get certified for in-demand skills.</li>
10    </ul>
11
12    <p>
13        At Programiz, we are committed to providing a unique learning experience that empowers you to master CSS and web development. Our interactive platform allows you to code directly in your browser, making it easy to learn without the need for complex setups. You'll gain hands-on experience by working on real-world projects, allowing you to apply what you learn in practical scenarios.
14    </p>
15</div>
```

```css
1div {
2    background-image: url('/images/learn-css/bg.png');
3    background-repeat: no-repeat;
4
5    /* 
6    Width is 600px. 
7    Height is 300px.
8     */
9    background-size: 600px 300px;
10}
```

Specifying width and height allows you to set exact dimensions for the background image.

However, if the image's width-to-height ratio doesn't match the specified size, the image will be distorted.

A better way to accomplish this task is by setting the background-size property to cover.
