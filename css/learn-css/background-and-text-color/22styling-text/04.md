## Font Style

The font-style property can be used to make the text appear in italics.

```html
1<p>The term <span>algorithm</span> refers to a set of instructions for solving a problem.</p>
```

```css
1span {
2    /* The default font-style value is normal. */
3    font-style: italic;
4}
```

The span element is changed to italic in the code.
