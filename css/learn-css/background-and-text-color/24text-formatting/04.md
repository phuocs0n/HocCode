## Text Decoration: None

The none value removes text decoration.

Browsers underline links by default. Run the code below to view this.

```html
1<p>To learn more, visit <a href="https://programiz.pro">programiz pro</a></p>
```

Let's remove this underline using text-decoration: none;.

```html
1<p>To learn more, visit <a href="https://programiz.pro">programiz pro</a></p>
```

```css
1/* Remove underline formatting from the link */
2a {
3    text-decoration: none;
4}
```
