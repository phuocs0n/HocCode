## Hero Section

In the previous lesson, you built the full HTML structure for the hero section. Now it's time to style it so it starts matching the Figma design.

In this lesson, you'll focus on:

- laying out the text and image side by side
- setting clear text hierarchy
- matching spacing from Figma

You're not adding interactions or responsiveness yet. The goal is to match the static desktop design first. Once that foundation looks right, the rest becomes much easier to build on.
