# What You'll Learn

#### Course: Figma to Code

## What You'll Learn

In this course, you'll build a complete portfolio page from a design, section by section, the same way you'd do it on a real team.

By the end, you'll be able to:

- read a design and extract what actually matters
- plan the HTML structure before you touch CSS
- match spacing, typography, and layout without guessing
- spot and fix mismatches between the design and the browser
- make changes confidently without breaking the page

Requirement: You should already know the basics of HTML and CSS.

Next, we'll do a quick Figma warm-up, only what you need as a developer.
