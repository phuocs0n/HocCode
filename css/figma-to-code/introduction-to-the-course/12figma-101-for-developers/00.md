## What Is Figma 🧠

Figma is where the design lives. Designers use it to define how the page should look and behave.

You'll use it differently. Your job is to read the design and turn it into clean HTML and CSS that matches what's intended.

Any time you feel unsure while coding, come back to Figma. Click the element, check the values, and translate that into code. That's how you stop guessing and start moving fast with confidence.

This lesson isn't about learning design. It's about getting comfortable reading a design the way a developer does.
