# Linking Fonts and Stylesheet

## Linking Fonts and Stylesheet

Before you can style anything, you need a CSS file and you need to connect it to your HTML.

Once the link is in place, any CSS you write will immediately affect the page.

In your project

- Create a new file named style.css

In index.html, inside the head

- Link the style.css file

- index.html
- script.js
- style.css

Fonts carry a lot of the design, so we'll load them early.

If you skip this step, your spacing and typography will feel slightly off the whole time. Then you'll waste effort tweaking CSS to fix something that isn't a CSS problem.

Load the fonts first. That way, everything you build after this matches the design from the start. To know which fonts to load, inspect the design texts and see which fonts are used.

In index.html, inside the head

- Add the Google Fonts links for the Inter and Crimson Pro fonts

Use following links inside head tag:

```css
<link
  href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700;800&display=swap"
  rel="stylesheet"
/>

<link
  href="https://fonts.googleapis.com/css2?family=Crimson+Pro:ital,wght@0,200..900;1,200..900&display=swap"
  rel="stylesheet"
/>
```

- index.html
- script.js
- style.css
