## Laying Out the Header with CSS

In the last lesson, you built the header structure in HTML. Everything is in place, but it looks stacked and plain because the browser is applying its default styles.

Now we'll start shaping the layout with CSS. The goal here is simple:

- keep the header content centered
- place the items on a single horizontal row
- match the overall header layout from the Figma design

You're not polishing yet. You're getting the layout right so the rest of the styling work feels easy instead of fragile.
