# Creating the Basic Document 🆕

## Creating the Basic Document 🆕

Every website starts with a basic HTML document.

It's not exciting, but it matters more than people think. A clean document structure makes everything else predictable and easier to reason about as the project grows.

At this stage, we're not thinking about layout or styling. We're just setting up the foundation so the rest of the work has something solid to sit on.

Create a new HTML file named index.html for this project.

- index.html
- style.css

Add a valid HTML5 document structure to index.html.

Your file must include:

- the <!DOCTYPE html> declaration
- the <html> element with lang="en"
- a <head> section with a <title> set to My Portfolio.
- a <body> section (can be empty for now)

- index.html
- script.js
- style.css
