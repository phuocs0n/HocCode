## Your Toolkit

Here's everything you've learned in this course.

fluid width — width relative to the available space. It stretches and shrinks as the screen changes.

rem units — relative to the root font size. Use for font sizes, spacing, and breakpoints so values scale with user preferences.

Media queries — @media (min-width: 48rem) to change layout at breakpoints.

Mobile-first CSS — base styles for the smallest screen. Only min-width queries add layout for larger viewports.

Flexbox — for nav that stacks or goes horizontal, and for cards that wrap instead of overflow.

Hamburger menu — button, wrapper, body.nav-open class toggle, and a breakpoint where the button hides.

Fluid images — max-width: 100%; height: auto; display: block so images scale with their container.
