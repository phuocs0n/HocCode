## Container Queries

Media queries look at the viewport width. But what if the same component lives in a narrow sidebar on one page and a wide main column on another?

Container queries look at the width of the parent element instead of the viewport. The component responds to its own context, not the screen size.

It's a newer feature but browser support is solid now. Worth knowing about.
