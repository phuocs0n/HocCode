## CSS Grid for Complex Layouts

Flexbox handles one dimension at a time. Rows or columns. Grid handles both at once.

You already used Grid in your portfolio. grid-template-columns: 220px auto for the hero, repeat(4, 1fr) for the stat cards, 180px 1fr for the journey items. Those were all fixed though.

When you're ready to go further, look at auto-fill and minmax(). A grid that reflows without any media queries at all.

```css
.hero-stats {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(12rem, 1fr));
}
```
