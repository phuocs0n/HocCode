# Fixed Width vs Fluid Width

#### Course: Make Your Code Work on Every Screen

## Fixed Width vs Fluid Width

You just saw the portfolio break at 320px. The nav spilled off the edge, the hero got crushed, the cards were squeezed. But what's actually causing that?

Look at your .container CSS.

```css
.container {
  width: 900px;
}
```

That's a fixed width. Always 900px no matter what screen it's on. On a desktop that's fine. On a 360px phone 900px is more than twice the viewport. The browser has no choice but to let it overflow.

The fix is writing widths that respond to the available space instead of ignoring it. That's the difference between fixed and fluid.

Fixed means a hard pixel value. Always that wide, always that problem on narrow screens.

Fluid means the size is relative to the available space. It stretches and shrinks as the screen changes.

```css
.container {
  width: 100%;
  max-width: 64rem;
}
```

width: 100% fills whatever space is available. max-width: 64rem stops it from getting too wide on large screens. Narrow screen? It fills it. Wide screen? It caps and centers.

```html
1.fixed {
2
3  width: 900px;
4  background: #FEE2E2;
5  padding: 1rem;
6  margin-bottom: 1rem;
7}
8
9.fluid {
10
11  width: 100%;
12  max-width: 64rem;
13  background: #DCFCE7;
14  padding: 1rem;
15}
```

```css
1*, *::before, *::after {
2  box-sizing: border-box;
3}
4
5body {
6  font-family: sans-serif;
7  margin: 0;
8  padding: 1rem;
9}
10
11.label {
12  font-size: 0.875rem;
13  color: #64748B;
14  margin: 0 0 0.5rem;
15}
16
17.fixed {
18  width: 900px;
19  background: #FEE2E2;
20  padding: 1rem;
21  margin-bottom: 1.5rem;
22  border-radius: 0.5rem;
23}
24
25.fluid {
26  width: 100%;
27  max-width: 64rem;
28  background: #DCFCE7;
29  padding: 1rem;
30  border-radius: 0.5rem;
31}
```

Hit Run Code and narrow the window. You can see the red fixed box overflowing while the green fluid box adjusts perfectly.
