## The Fluid Container Pattern

Almost every production website uses this on its outermost wrapper.

```css
.container {
  width: 100%;
  max-width: 64rem;
  margin: 0 auto;
  padding: 0 1.5rem;
}
```

At 320px the container is 320px wide, fits the phone. At 768px it fills the tablet. At 1440px it caps at 64rem and centers. One pattern, every screen size covered.

Your portfolio has width: 900px on .container right now. That's what's causing the overflow you saw. The fix is one swap and the whole page becomes fluid.

```css
container {
  width: 100%;
  max-width: 64rem;
}
```
