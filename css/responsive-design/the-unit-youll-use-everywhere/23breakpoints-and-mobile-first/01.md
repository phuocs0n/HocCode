# Breakpoints in rem

#### Course: Make Your Code Work on Every Screen

## Breakpoints in rem

You already know why we use rem for font sizes and spacing. The same reason applies to breakpoints.

```css
/* Fixed. Ignores the user's font size setting */
@media (min-width: 768px) { ... }

/* Scales with the user */
@media (min-width: 48rem) { ... }
```

At the default 16px root they look identical. But if a user bumps their browser font size to 20px, the rem breakpoint shifts naturally to keep the layout comfortable. The px breakpoint stays locked at 768px and may switch too early.

For your portfolio we'll use two breakpoints throughout this course. 48rem for tablet and up, and 64rem for desktop and up. Notice that 64rem is 1024px, the same width your container maxes out at. The layout was designed for that width so it's a natural fit.

Try it in the editor. Resize the window and watch the layout switch at each breakpoint. Single column below 48rem, a row at 48rem, green columns at 64rem.The runnable below uses a much smaller breakpoint — 20rem (320px) — so you can see the layout change without needing a wide browser window. The concept is identical: pick the rem value where your content needs to change, and write the @media (min-width: ...) block there.

```html
1/* At 20rem (320px): side by side */
2@media (min-width: 20rem) {
3  .layout {
4    flex-direction: row;
5  }
6
7  .col {
8    flex: 1;
9  }
10}
```

```css
1body {
2  font-family: sans-serif;
3  margin: 0;
4  padding: 1rem;
5}
6
7/* Base: stacked (mobile) */
8.layout {
9  display: flex;
10  flex-direction: column;
11  gap: 0.5rem;
12}
13
14.col {
15  padding: 2rem 1rem;
16  background: #f0f0f0;
17  border-radius: 4px;
18  text-align: center;
19}
20
21/* At 20rem (320px): side by side */
22@media (min-width: 20rem) {
23  .layout {
24    flex-direction: row;
25  }
26
27  .col {
28    flex: 1;
29  }
30}
31
32/* At 32rem (512px): wider layout with more breathing room */
33@media (min-width: 32rem) {
34  .col {
35    padding: 2rem;
36    background: #d1fae5;
37  }
38}
```
