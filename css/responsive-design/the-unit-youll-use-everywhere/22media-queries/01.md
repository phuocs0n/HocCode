# What Are Media Queries?

#### Course: Make Your Code Work on Every Screen

## What Are Media Queries?

A media query is a CSS rule that only switches on when a certain condition is met.

But what about a tablet or desktop?

On those screens there's plenty of room. So what if we could say "if the screen is a tablet or bigger, go back to two columns"?

That's exactly what a media query does. A media query is for viewport width, the actual width of the browser window, not the device, not the font size, just how wide the screen is at that moment.
