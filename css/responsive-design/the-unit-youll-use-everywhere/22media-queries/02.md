#### Course: Make Your Code Work on Every Screen

## Media Query Syntax

You just saw the hero stack on mobile. But right now that stacking happens for every screen size.

What if you only want it to stack on narrow screens and show two columns on wider ones?

That's what a media query does. It's a CSS block that only switches on when a condition is met.

```css
@media (max-width: 48rem) {
  .hero-content {
    display: flex;
    flex-direction: column;
  }
}
```

@media opens the block. The condition (max-width: 48rem) is the test. If the viewport is 48rem or narrower the styles inside apply. If not the whole block is skipped. Everything inside targets the same selectors as your regular CSS, just scoped to that width.

Here it is on your actual portfolio hero. The base styles set up two columns for desktop. The media query collapses it to one column on narrow screens.

```html
1/* Desktop layout — the base */
2.hero-content {
3
4  display: grid;
5  grid-template-columns: 14rem 1fr;
6}
7
8/* On screens 48rem or narrower: collapse to one column */
9@media (max-width: 48rem) {
10
11  .hero-content {
12    display: flex;
13    flex-direction: column;
14  }
15}
```
