## Converting Your Portfolio to rem

Now look at your portfolio CSS. These are the values you wrote in the Figma to Code course.

```css
.hero-text h1 { font-size: 60px; }
.container { padding: 0 24px; }
nav ul { gap: 32px; }
```

Swap those out for rem and you get this.

```css
.hero-text h1 {
  font-size: 3.75rem;
}

.container {
  padding: 0 1.5rem;
}

nav ul {
  gap: 2rem;
}
```

Looks the same on desktop. But now it scales with the user instead of staying locked in place.

You won't convert everything right now. We'll do it piece by piece as we fix each part of the layout. Just get comfortable with the pattern and the rest will feel natural.
