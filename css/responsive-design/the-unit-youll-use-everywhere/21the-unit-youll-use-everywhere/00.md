## From the Figma Course to This One

You put in a lot of work to build that portfolio. The spacing, the typography, the layout. And it looked great.

But do you remember all those pixel values you wrote?

font-size: 60px, gap: 32px, max-width: 1024px.

Here's the thing about px. It's a fixed unit. 60px is 60px everywhere, on every screen, for every user, no matter what. It doesn't adapt. It doesn't scale.

That's where rem comes in.

▶️ Next, let's see what rem actually is and why it's better.
