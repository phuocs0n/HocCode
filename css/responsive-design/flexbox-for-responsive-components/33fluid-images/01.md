## One Rule, Every Image

The fix is three lines. Add this to your base CSS and every image on the page becomes fluid. Not just the portrait. Every image, including ones you add later.

```css
img {
  max-width: 100%;
  height: auto;
  display: block;
}
```

max-width: 100% means the image never exceeds its container. height: auto lets the browser calculate the height proportionally so the image never distorts. display: block removes a small gap below inline images caused by the text baseline.

Three properties. You never have to think about responsive image CSS again.

```html
1img {
2  max-width: 100%;
3  height: auto;
4  display: block;
5  border-radius: 1.5rem;
6}
```
