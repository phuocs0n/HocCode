## How It Works

The nav menu is hidden by default. When a checkbox is checked the nav becomes visible. A label styled as a button is what the user actually taps.

The :checked selector is what makes this work. When the checkbox is checked the ~ selector reaches the nav menu and shows it. The label is what the user sees and taps.

```html
1.nav-toggle {
2  display: none;
3}
4
5.nav-menu {
6  display: none;
7}
8
9.nav-toggle:checked ~ .nav-menu {
10  display: flex;
11  flex-direction: column;
12  gap: 1rem;
13}
14
15@media (min-width: 48rem) {
16  .nav-label { display: none; }
17
18  .nav-menu {
19    display: flex;
20    flex-direction: row;
21    align-items: center;
22    gap: 2rem;
23  }
24}
```
