## Using Flexbox for the Nav and Stat Cards

The nav is a horizontal row at every width right now. On a 320px phone there's just no room for that.

You've already solved something like this.

Remember how the hero was a two-column grid at every width and you moved the grid into a media query? Same thinking here. On a phone the nav should stack vertically. On a wider screen it goes back to a row. That's all we're doing.

```html
1nav ul {
2  display: flex;
3  flex-direction: column;
4  gap: 0.5rem;
5}
6
7@media (min-width: 48rem) {
8  nav ul {
9    flex-direction: row;
10    gap: 2rem;
11  }
12}
```

```css
1*, *::before, *::after {
2  box-sizing: border-box;
3}
4
5body, p, h1, h2, h3 {
6  margin: 0;
7}
8
9body {
10  font-family: 'Inter';
11  background-color: white;
12}
13

15  max-width: 64rem;
16  margin: 0 auto;

18}
```

Hit Run Code and you'll see the nav links stacked vertically on the left side. Widen the browser past 48rem and watch them snap into a horizontal row.
