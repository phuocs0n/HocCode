## Meet flex-wrap: wrap

You already know display: flex. But there's one flex property that makes components like cards responsive without a single media query.

```css
flex-wrap: wrap
```

By default flex items stay on one line no matter what. No room? They overflow. You've seen this with the stat cards.

flex-wrap: wrap changes that. When items run out of space they move to the next row instead of spilling out.

Now here's the interesting part. What if each card also knew how wide it wanted to be? That's where flex: 1 1 8rem comes in.

The 8rem is the base size, roughly 128px at the default font size, comfortable enough for a stat card to be readable without feeling cramped. Cards grow if there's extra space and wrap when there isn't enough room for all of them. No breakpoints, no media queries. They just figure it out.

```html
1.card-row {
2  display: flex;
3  flex-wrap: wrap;
4  gap: 1rem;
5}
6
7.card {
8  flex: 1 1 8rem;
9  padding: 1rem;
10  background: #F1F5F9;
11  border-radius: 0.5rem;
12  text-align: center;
13}
```

```css
1body {
2  font-family: sans-serif;
3  margin: 0;
4  padding: 1rem;
5}
6
7.wrapper {
8  max-width: 90%;
9}
10
11.heading {
12  font-size: 2rem;
13  margin: 0 0 0.5rem;
14}
15
16.body-text {
17  font-size: 1rem;
18  margin: 0 0 1.5rem;
19  color: #475569;
20}
21
22.card-row {
23  display: flex;
24  flex-wrap: wrap;
25  gap: 1rem;
26}
27
28.card {
29  flex: 1 1 8rem;
30  padding: 1rem;
31  background: #F1F5F9;
32  border-radius: 0.5rem;
33  text-align: center;
34}
```

Hit Run Code and narrow the window. You can see the cards wrapping into two rows when there isn't enough space. Widen it and they all sit in one row again.
