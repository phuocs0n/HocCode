## Your Stat Cards

That was a simple example. Now look at your actual stat cards.

.hero-stats is a fixed four-column grid right now. Four columns at every width, even 320px. You already know how that goes.

What if you just replaced that grid with flex-wrap: wrap? Same idea as before, just your real portfolio data this time.

```html
1.hero-stats {
2  display: flex;
3  flex-wrap: wrap;
4  gap: 1rem;
5}
6
7.stat-card {
8  flex: 1 1 8rem;
9}
```

```css
1body {
```
