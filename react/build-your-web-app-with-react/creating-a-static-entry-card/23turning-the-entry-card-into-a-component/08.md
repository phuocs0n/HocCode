## File Organization

Here's what your src folder should look like now:

```text
src/

├── App.jsx

├── EntryCard.jsx

├── index.jsx

└── ...
```

Later, as you add more components, you might want to create a components folder:

```text
src/

├── components/

│   ├── EntryCard.jsx

│   ├── JournalForm.jsx

│   └── ...

├── App.jsx

└── index.jsx
```

For now, keeping everything in src is fine. Don't over-organize early.
