## How It Works

When React sees <EntryCard />, it calls the EntryCard() function and renders whatever JSX it returns.

Right now, EntryCard() always returns the same thing: "Entry Title", "Date", etc. That's not useful yet. You need to pass data to it. You'll do that with props in the next lesson.

For now, focus on the structure:

1. You create a function that returns JSX
2. You export it from the file
3. You import it in another file
4. You use it like an HTML tag

That's all a component is.
