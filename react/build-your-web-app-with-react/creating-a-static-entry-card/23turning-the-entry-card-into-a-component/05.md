## Component Naming Rules

Here's some naming rules and conventions you should follow to ensure your components run smoothly:

- Component names must start with a capital letter. For example, write EntryCard() instead of entryCard().
- File names should match the component name: EntryCard.jsx for the EntryCard() component.
- If the name starts with lowercase (such as <entryCard />), React thinks it's a regular HTML tag, not a component.

This is a React convention. Follow it, and your components will work as expected.
