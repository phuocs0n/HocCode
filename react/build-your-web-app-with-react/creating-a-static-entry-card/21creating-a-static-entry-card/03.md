#### Course: Build your First Web App with React

## Add a Date

Journal entries need dates. So let's add another <div> tag to show when the entry was written:

```undefined
1function App() {
2  return (
3    <div>
4      <header>
5        <h2>My Daily Journal</h2>
6        <p>Capture your thoughts, one entry at a time</p>
7      </header>
8      <div>
9        <div>February 10, 2026</div>
10        <h2>First Day at the Job</h2>
11        <p>Today was my first day at the new job. Everyone was welcoming and helpful. I'm excited to learn more about the team and start contributing.</p>
12      </div>
13    </div>
14  );
15}
16
17export default App;
```

Click Run Code. The date will be added automatically and you should see the date above the entry title.
