## What Just Happened?

Just now, you added more JSX code to render the entry card. The structure is simple:

- The outer <div> wraps everything (remember: JSX needs one root element).
- Inside, you have the <header> and its contents from before.
- Below the header, another <div> represents one journal entry.

This journal entry (the inner <div>) has:

- An <h2> for the title
- A <p> for the content

This is all static right now. The text is hardcoded directly in JSX. That's fine for now; you'll make it dynamic later.

Instead, let's focus on adding some more features to our entry card.
