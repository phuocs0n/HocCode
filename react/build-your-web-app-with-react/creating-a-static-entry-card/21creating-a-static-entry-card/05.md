# Why Use 'className' Instead of 'class'?

#### Course: Build your First Web App with React

## Why Use 'className' Instead of 'class'?

JSX looks just like HTML, but always remember that it's actually JavaScript.

When you write <div class="card">, React tries to interpret class as a JavaScript property. That's because class is a reserved word in JS (used for classes like class User {...}).

So, React uses className instead. This is one of the small differences between HTML and JSX.

HTML Code:

```react
<div class="card">
```

JSX Code:

```react
<div className="card">
```

Same result, different syntax. You'll get used to it fast.
