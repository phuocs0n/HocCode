## Using className for Styling

Right now, your entry card has minimal styling. If you want to add some CSS, you'll need to give class names to the elements.

In regular HTML, you use the class attribute to give an element its class name.

In JSX, you use className instead Why? Because class is a reserved word in JavaScript.

So let's add a class name to each element in our app:

```undefined
1function App() {
2  return (
3   <div className="main-container">
4      <header className="header">
5        <h2 className="title-primary">My Daily Journal</h2>
6        <p className="subtitle">Capture your thoughts, one day at a time.</p>
7      </header>
8      
9      <div className="entry-item">
10        <div className="entry-date">FEBRUARY 10, 2026</div>
11        <h2 className="entry-title">First Day at the Job</h2>
12        <p className="entry-content">Today was my first day at the new job. Everyone was welcoming and helpful. I'm excited to learn more about the team and start contributing.</p>
13      </div>
14    </div>
15  );
16}
17
18export default App;
```
