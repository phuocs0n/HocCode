## Pass Props to EntryCard

In App.jsx, we'll pass title, date, and content to EntryCard:

```react
import Header from "./Header";
import EntryCard from "./EntryCard";

function App() {
  return (
    <div>
      <Header />      

      <EntryCard 
        title="First Day at the Job"
        date="February 10, 2026"
        content="Today was my first day at the new job. Everyone was welcoming and helpful."
      />

    </div>
  );
}

export default App;
```

You're passing three props: title, date, and content. These are like function arguments, but written as attributes.
