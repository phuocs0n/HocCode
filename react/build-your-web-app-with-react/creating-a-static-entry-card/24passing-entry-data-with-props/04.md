# How Props Work

#### Course: Build your First Web App with React

## How Props Work

When you write:

```react
<EntryCard title="First Day" date="Feb 10" />
```

React collects all the attributes into an object:

```react
{
  title: "First Day",
  date: "Feb 10"
}
```

This object is passed to the EntryCard() function as the props parameter. Inside the component, you access the values with props.title, props.date, etc.

Props are read-only. You can read them, but you can't change them. If you need to modify data, you'll use state, which we'll cover later.
