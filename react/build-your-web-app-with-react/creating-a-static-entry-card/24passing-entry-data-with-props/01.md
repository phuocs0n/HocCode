#### Course: Build your First Web App with React

## What Are Props?

Props (short for "properties") are how you pass data from a parent component to a child component.

Think of props like function arguments in JavaScript. When you call a function, you pass it data:

```react
// Pass "Alice" as an argument
greet("Alice");
```

With components, you do the same thing, but the syntax looks like HTML attributes:

```react
<EntryCard title="First Day" />
```

Here, title is a prop, so you're passing the value "First Day" to the EntryCard component.
