## Embed Variables with {}

To put a JavaScript expression inside JSX, you wrap it in curly braces: {}.

For now, let's replace only the hardcoded title with {entryTitle} (you'll replace the date and content yourself on the next page):

```undefined
1function App() {
2  const entryTitle = "First Day at the Job";
3  const entryDate = "FEBRUARY 10, 2026";
4  const entryContent = "Today was my first day at the new job. Everyone was welcoming and helpful. I'm excited to learn more about the team and start contributing.";
5
6  return (
7    <div className="main-container">
8      <header className="header">
9        <h2 className="title-primary">My Daily Journal</h2>
10        <p className="subtitle">Capture your thoughts, one day at a time.</p>
11      </header>
12      
13      <div className="entry-item">
14        <div className="entry-date">FEBRUARY 10, 2026</div>
15        <h2 className="entry-title">{entryTitle}</h2>
16        <p className="entry-content">Today was my first day at the new job...</p>
17      </div>
18    </div>
19  );
20}
21
22export default App;
```

Click Run Code. Nothing changed visually in the output. But now the title is coming from the entryTitle variable.

You can confirm this by changing the value of entryTitle to something else:

```react
const entryTitle = "Learning React";
```

Then, click Run Code again. The output updates with the new title.

That's the power of dynamic content. You change the data once, run your code, and the UI updates.
