#### Course: Build your First Web App with React

## Create the JournalForm Component

So it's time to finally build our form, which will obviously be done in a completely new file. We'll create this file (named JournalForm.jsx) inside the src folder.

Here's the full path of the file:

```react
src/components/JournalForm.jsx
```

The component will consist of a simple form with three elements:

- An <input> for the title
- A <textarea> for the content
- A <button> to submit

The entire form will be wrapped inside a <section>, with a <form> tag inside the section for proper form semantics.
