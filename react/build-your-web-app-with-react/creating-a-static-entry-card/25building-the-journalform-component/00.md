#### Course: Build your First Web App with React

## What You're Building

So you've added your header and entry cards. Now you need a way for users to add new entries.

In this lesson, you'll build a form component with:

- A text input for the title
- A textarea for the content
- A button to submit the entry

The form won't work yet (you'll do that in the next chapter). For now, let's just focus on building the UI.

We'll start by creating a separate component for the form, and then proceed to add it to our main React app.
