# When to Use Fragments

#### Course: Build your First Web App with React

## When to Use Fragments

Use fragments when:

- You don't need a wrapper element for styling.
- You're returning multiple elements from a component.
- Adding a <div> would break your layout or CSS.

For JournalForm, using a <section className="card"> is better because it provides structure for styling. But knowing about fragments is still a bonus in my opinion, which is why I introduced it to you.
