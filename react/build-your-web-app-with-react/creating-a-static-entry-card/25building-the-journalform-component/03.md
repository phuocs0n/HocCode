#### Course: Build your First Web App with React

## Step 2: Move Components to the New folder

Currently, our platform doesn't support directly moving files into other folders. So, you'll have to resort to a roundabout method:

1. Create new Header.jsx and EntryCard.jsx files inside components.
2. Copy the respective contents from the original files into these new files.
3. Delete the original Header.jsx and EntryCard.jsx files that are outside the components folder.

Next, you'll update App.jsx so these changes are properly implemented in your code.
