## Form Elements in JSX

Form elements work the same in JSX as in HTML, with a few small differences:

1. 'class' becomes 'className'

You already know this one:

```react
<input className="title-input" />
```

2. Self-closing tags need a slash

In HTML, you can write <input> or <input />. In JSX, you must close it like this: <input />.

3. camelCase for attributes

Some HTML attributes combine two words without camelCasing (eg: tabindex, maxlength). In JSX, they become camelCase:

- tabindex → tabIndex
- maxlength → maxLength
- readonly → readOnly

For example:

```react
<input type="text" maxLength={100} />
```

4. 'for' becomes 'htmlFor'

If you use <label>, the for attribute becomes htmlFor:

```react
<label htmlFor="title">Title</label>

<input id="title" />
```

Why? Because for is a reserved word in JavaScript (used in for loops).
