# Why Use Draft State in the Card?

#### Course: Build your First Web App with React

## Why Use Draft State in the Card?

The edited title and content are only "real" after they're saved. Until then, they are a draft.

Keeping draftTitle and draftContent in the card lets the user type without changing the parent's state on every keystroke.

When they click Save, you send the final values to the parent with onEdit(id, draftTitle, draftContent).

This way, you won't unintentionally change the original state if the user decides to click Cancel on the edits they've made.
