## Updating A Single Object

Entries are an array of objects. To "edit" one entry you replace it with a new object that has the updated fields. You do not change the old object in place.

So here's what you'll do: modify setEntries() by building a new array with map. If an entry:

- Matches the id - Return a new object with the updated title and content.
- Doesn't match the id - Return the same entry.

```react
setEntries(
  entries.map((entry) =>

    entry.id === id
      ? { ...entry, title: newTitle, content: newContent }
      : entry
  )
);
```

Here's how the code works:

- ...entry copies all properties (id, date, author, etc.).
- You override title and content with the new values.
- For other ids, you return the same entry unchanged.

The result is a new array, so React re-renders regardless.
