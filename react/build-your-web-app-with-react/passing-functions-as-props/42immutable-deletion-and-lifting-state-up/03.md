## Lifting State Up: The State Lives in the Parent

You know that the list of entries lives in App, not in each EntryCard. Here are its implications:

1. One source of truth.

The only place that holds the list is entries, which is stored in the parent component App.

2. Children cannot change it directly.

EntryCard does not have setEntries. It only receives data and a callback.

3. Parent updates state.

When the user clicks Delete, the card calls onDelete(id). This runs handleDelete() inside App(), which in turn calls setEntries(...). The list updates and React re-renders all cards.

Conclusion

Keeping the list state in the parent (and passing down callbacks so children can request changes) is often called lifting the state up.

In other words, the state is "up" inside the common ancestor that needs it.
