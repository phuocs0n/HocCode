## Revisiting What You've Done

In the previous lesson, you added a Delete button and passed handleDelete from App to EntryCard.

When the user clicks Delete, the card calls onDelete(id) and the parent runs:

```react
setEntries(entries.filter((entry) => entry.id !== id));
```

As a result, the entry disappears.

In this lesson, we'll look at why this method is correct: filter gives you a new array instead of modifying the existing one.

Thus, the list itself is stored in the parent App — not in each card. The cards just call a function to ask the parent to update it.

So, let's start exploring deletion in greater detail, and hopefully you'll appreciate why filter is so important!
