## Removing an Item Immutably with filter

You already know that you mustn't mutate the existing array when removing an entry. That means you're not allowed to use splice or change entries in place.

Instead, React expects the state to be updated with a new value so it can detect the change.

filter returns a new array with only the items that pass a test. In our case, the test for being included in the new array is

```text
All entries whose id isn't the one we're deleting
```

Translating to React, the code is:r

```react
entries.filter((entry) => entry.id !== id)
```

You pass the generated array to setEntries, and React re-renders. The deleted entry is no longer in the array, so it no longer appears in the list.

Thus, filter is essential for fulfilling React's expectations of immutability.
