## Important: Always Follow This JSX Rule!

JSX must only return a single parent element. For instance, this code works:

```undefined
1// Return a single parent
2return (
3  <div>
4    <h1>My Daily Journal</h1>
5    <p>Welcome back</p>
6  </div>
7);
```

But this doesn't work:

```undefined
1// Return multiple parents
2return (
3  <h1>My Daily Journal</h1>
4  <p>Welcome back</p>
5);
```

Why? Because React needs one root element to attach everything else to.

Just wrap multiple elements in a <div> or a React fragment (you'll learn about them later) and you're set!
