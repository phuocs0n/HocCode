## What Just Happened?

Here's the code you saw in the previous page:

```undefined
1function App() {
2  return (
3    <div>
4      <h1>My Daily Journal</h1>
5    </div>
6  );
7}
8
9export default App;
```

Let's break down what just happened here:

1. You wrote a function called App().

This function returns what looks like HTML, but it's not! In fact, it's JSX, which is JavaScript that looks like HTML. React turns it into real HTML for the browser.

2. The function returns the UI.

The JSX you return from this function is what React will show on the screen. Right now, it's a <div> with an <h1> inside it.

3. React renders the component.

Whenever you execute a complete Run Code, the platform runs your app and shows the result. The code you wrote is executed and React renders your component to the screen.

Basically, a component is just a function that returns UI.
