## Try It: Add More Content

So far, your React app has a heading and nothing else. Let's change this by adding a paragraph below it:

```undefined
1function App() {
2  return (
3    <div>
4      <h1>My Daily Journal</h1>
5      <p>Track your thoughts and ideas</p>
6    </div>
7  );
8}
9
10export default App;
```

Click Run Code. You should see the heading and the paragraph in the output.

Pretty neat, right? You just wrote the JSX and poof, React rendered the UI to your screen!

I don't know about you, but this marriage between JavaScript and (what seems to be) HTML got me pretty excited and starry-eyed when I was just starting out with React.

I hope you feel the same! But it's okay if you don't; that's fine too 😉
