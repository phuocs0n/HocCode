## What is JSX?

Now you might be wondering: "Why does HTML work inside JavaScript?"

It doesn't, actually. What you're writing is JSX. It looks like HTML, but it's actually JavaScript.

When you write:

```react
<h1>My Daily Journal</h1>
```

React turns it into:

```react
React.createElement("h1", null, "My Daily Journal");
```

You don't need to write createElement() yourself since JSX does it for you.

That's why it feels natural: you write what the UI should look like, and React builds it.
