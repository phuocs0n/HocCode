## Try It: Change the Text

You now know the basic working principle of React. So let's look at another example where you'll change your React component.

Try modifying the text in your page. To do this, run this code first:

```undefined
1function App() {
2  return (
3    <div>
4      <h1>My Daily Journal</h1>
5      <p>Track your thoughts and ideas</p>
6    </div>
7  );
8}
9
10export default App;
```

Now, replace the header My Daily Journal with something else, maybe with My Thoughts or Daily Notes.

Then, click the Run button on the editor. You'll see the changes immediately: "My Daily Journal" is now changed to the text you replaced it with.

This is your app now. The header you see is the start of the journal app you'll build throughout this course.
