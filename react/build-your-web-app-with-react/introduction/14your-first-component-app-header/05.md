# How I First Reacted to JSX

#### Course: Build your First Web App with React

## How I First Reacted to JSX

The first time I opened a React file, I nearly closed it forever. Here's

```react
function App() {
  return <h1>Hello, World!</h1>;
}
```

HTML? Inside a JavaScript function? I stared at it for a good five minutes. This looked like a violation of everything I'd been taught about keeping concerns separate.

Who approved this? Why did everyone seem okay with it? I begrudgingly kept reading.

Here's what nobody told me upfront: that's not HTML. Not even close.

What you're actually writing is this:

```react
function App() {
  return React.createElement('h1', null, 'Hello, World!');
}
```

JSX is just a more readable way to write React.createElement() calls. Your browser never sees JSX — it's compiled away before anything runs. The angle brackets are a gift to your eyes, not a concession to HTML.

Once I understood that, JSX stopped feeling like a mistake and started feeling like the cleverest trick in the room.
