#### Course: Build your First Web App with React

## Open Your App

The editor and playground are already set up for you. You'll see some default code in the editor — a button and some text. That's not our journal app. Your job is to replace it with the code below and run it.

In the editor, replace the default code with this:

```undefined
1function App() {
2  return (
3    <div>
4      <h1>My Daily Journal</h1>
5    </div>
6  );
7}
8
9export default App;
```

In fact, just clicking the Run Code button will automatically replace the default code for you.

Once you do that, our platform will run your app and you should see "My Daily Journal" as a heading on the page.

That's it. You just wrote your first React component!
