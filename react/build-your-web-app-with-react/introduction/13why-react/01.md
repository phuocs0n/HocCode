#### Course: Build your First Web App with React

## React is a JavaScript Library

React isn't a new language — it's a JavaScript library. You're still writing JavaScript. React just gives you extra tools on top.

Library vs. Framework

| Library | Framework |
| --- | --- |
| You call the library when you want | The framework calls your code |
| You decide the structure | The framework decides the structure for you |
| Example: React | Example: Angular, Next.js |

React is a library — you decide when to use it, how to structure your files, and how to fetch data. Frameworks make those decisions for you.

This is why "React is JavaScript" is accurate. Your existing JS knowledge — functions, arrays, conditionals, objects — works exactly the same inside React.

It layers on top of what you already know, not beside it.
