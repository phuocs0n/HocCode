## Example: Shopping List with React

Let's continue where we left off, and build the same shopping list using React (you don't need to understand this code yet):

```undefined
1import React from 'react';
2
3function ShoppingList() {
4  const [items, setItems] = React.useState([]);
5  const [input, setInput] = React.useState("");
6  
7  function addItem() {
8    if (input === "") return;
9    setItems([...items, input]);
10    setInput("");
11  }
12  
13  return (
14    <div>
15      <h1>My Shopping List</h1>
16      <input 
17        value={input} 
18        onChange={(e) => setInput(e.target.value)} 
19        placeholder="Add an item"
20      />
21      <button onClick={addItem}>Add</button>
22      <ul>
23        {items.map((item, index) => (
24          <li key={index}>{item}</li>
25        ))}
26      </ul>
27    </div>
28  );
29}
30export default ShoppingList;
```

Take a peek at the code, and you'll notice the following:

- There's no document.getElementById
- No createElement or appendChild either
- You write what the UI should show, not how to manipulate the DOM

This is React's core idea: UI is a function of state. When the state (your data) changes, React re-renders the UI automatically.
