## The Problem: Building a List in Plain JavaScript

Let's say you want to build a simple shopping list. You want users to type an item and add it to the list.

Here's how you'd do it in plain JavaScript:

```html
1<!DOCTYPE html>
2<html lang="en">
3<head>
4  <meta charset="UTF-8">
5  <meta name="viewport" content="width=device-width, initial-scale=1.0">
6  <title>Shopping List</title>
7</head>
8<body>
9  <h1>My Shopping List</h1>
10  <input type="text" id="item-input" placeholder="Add an item">
11  <button id="add-button">Add</button>
12  <ul id="item-list"></ul>
13  
14  <script src="script.js"></script>
15</body>
16</html>
```

```javascript
1const input = document.getElementById("item-input");
2const button = document.getElementById("add-button");
3const list = document.getElementById("item-list");
4
5button.addEventListener("click", function() {
6  const itemText = input.value;
7  
8  if (itemText === "") return;
9  
10  const li = document.createElement("li");
11  li.textContent = itemText;
12  list.appendChild(li);
13  
14  input.value = "";
15});
```

This works. But what if you want to delete an item? Or edit one? Or mark it as bought? Each feature means more code that does some of the following:

- Find the element
- Create new elements
- Append or remove from the DOM
- Keep track of what's on screen vs what's in your data

The result is that you end up managing everything manually. The more features you add, the more fragile it gets.

That's a huge weakness of vanilla JavaScript.
