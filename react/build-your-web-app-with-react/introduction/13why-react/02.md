## When Should You Use React?

Even after all this, you may still have some misconceptions about React, and when (or if) you should use it.

Here's what you need to know:

The Misconception

React is just a fancy template engine for rendering HTML.

The Truth

React is a state-driven UI system — you describe what the UI should be, and React figures out how to get there.

The Golden Rule

If you find yourself manually selecting DOM elements in a React app, stop. You're fighting React, not using it.
