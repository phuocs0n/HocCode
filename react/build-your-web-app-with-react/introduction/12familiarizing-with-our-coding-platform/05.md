## A Note on index.jsx

Finally, I need to talk about an important file that'll always be there in our React app, and that's index.jsx.

This file is the entry point of your React app, i.e., it's the first file that runs. When the browser loads your app, it executes index.jsx and configures your app.

Obviously, you won't touch index.jsx in this course, but here's what it does:

```react
import React from 'react';
import { createRoot } from 'react-dom/client';
import App from './App';
import './style.css';

const root = createRoot(document.getElementById('root'));
root.render(<App />);
```

What This Code Does

- Imports the React library and other necessary components.
- Locates the <div id="root"> in index.html, and mounts your <App /> component into it.
- Loads style.css. Since it is imported at this root level, its styles are loaded globally. Therefore, you don't need to import the CSS file again in each component.

Think of index.jsx as the ignition: it starts the app so React can take over the page. That's all there is to it.
