# What You Need For This Course

#### Course: Build your First Web App with React

## What You Need For This Course

You don't need any React experience! This course is designed to be your very first entry point to React. But here's what you do need:

1. Basic HTML and CSS

You must know about tags, nesting, classes, selectors. You'll write JSX, which looks like HTML, so knowing HTML first makes it feel familiar.

2. JavaScript Fundamentals

You must be proficient in the following:

- Variables (const, let)
- Functions and return values
- Arrays and .map()
- Objects and property access
- Arrow functions
- Events and addEventListener()

If you don't know these things, spend a little time with JS arrays and functions first. It'll make everything in this course much easier.

What You Don't Need

- Node.js
- Terminal experience
- Advanced JavaScript (Promises, classes, async/await)

In short, you don't need any backend knowledge. Just the front end.
