## Controlled Inputs

A controlled input is an HTML input whose value is managed by React state rather than the browser.

Normally, the browser tracks what a user types internally.

With a controlled input, you store that value in state and feed it back to the input yourself, thus keeping React as the single source of truth.

To wire this up, you add two attributes: value and onChange:

```react
<input
  type="text"
  placeholder="Entry title"
  value={title}
  onChange={(e) => setTitle(e.target.value)}
/>
```
