## Explaining the Code

Go back and revisit the previous code and notice value={title} and value={content}. This enables the fields to show the current state based on user input.

Also notice the code here:

```react
onChange={(e) => setTitle(e.target.value)}
```

Here, the onChange handler receives an event object e, which describes what happened with the input, i.e., it describes how the user changed the input.

The input element that changed is given by e.target, and its current text is e.target.value.

So you read the user's input from e.target.value and store it in the state.

If you run the code and type in the title and content, you'll see that the fields update as you type. That's because React is re-rendering your UI with the new state.
