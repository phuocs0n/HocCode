## Important! Never Use Array Indexes as Keys!

As I've hinted before, I found out the hard way not to use array indexes as keys when I was a graduate fresh out of college, building a React project for my portfolio.

I had a list of three items in my array, let's say something like the one below:

```react
entries = { ItemA, ItemB, ItemC }
```

I had set the array indexes as the keys, so ItemA had key === 0, ItemB had key === 1, and so on.

At some point, I needed to delete ItemA and modify ItemB. In other words, I needed to

1. Delete the entry with key === 0.
2. Then, modify the entry with key === 1.

Well, things didn't go as planned. What happened? You'll find that on the next page.
