## What map Returns

Take a look at the previous program again, and notice the code entries.map((entry) => (...)) in App.jsx. This code returns an array that looks something like this:

```react
[
  <EntryCard key={1} title="..." ... />,
  <EntryCard key={2} title="..." ... />,
  ...
]
```

React renders this array as a list of siblings inside the parent. The key is not passed as a prop to your component; it is only used by React internally.
