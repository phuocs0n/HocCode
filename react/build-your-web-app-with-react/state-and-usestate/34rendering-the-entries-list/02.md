# Why Use a Key?

#### Course: Build your First Web App with React

## Why Use a Key?

When you render a list, React needs a way to tell items apart.

If you add, remove, or reorder entries, React uses the key to match old and new items. That keeps the component state and the DOM correct.

You should use a key that's unique and stable for each item.

For instance, our entry.id is perfect for this task because we've assigned Date.now() to it (you can check the code to verify). This ensures the key is a unique id based on the date and time of the entry's creation.

But no matter what, do not use the array index as the key if the list can change (add/remove/reorder). That's because the index of an item can change.
