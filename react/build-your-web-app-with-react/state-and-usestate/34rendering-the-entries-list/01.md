## Turning an Array into JSX with map

JavaScript's array.map() returns a new array by calling a function on each item.

You can use it to turn each entry into a piece of JSX.

```react
entries.map((entry) => (
  <EntryCard
    key={entry.id}
    title={entry.title}
    date={entry.date}
    content={entry.content}
    author={entry.author}
  />
));
```

This returns an array of EntryCard components. React can render arrays of elements, so you can put this inside your JSX.

You may have noticed the key prop; it's not a normal prop you define on EntryCard.

Instead, it's something React requires whenever you render a list, and the next section explains why.
