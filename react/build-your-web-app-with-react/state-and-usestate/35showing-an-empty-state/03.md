And this is how it works:

- entries.length === 0 is a boolean condition. The ternary chooses one branch or the other based on its result.
- React only renders the branch you choose. So you either render the message or the array of cards, but never both.
- When the user adds the first entry, the entries array is updated. React thus re-renders the entry, and the condition becomes false. So, the list finally appears.

That's all there is to it (or at least, all there is for you to know at this point).
