## Important: Update the State Immutably!

When you add an entry, don't modify the existing array. Instead, replace the state value with a new array so React can detect the change and re-render.

Wrong Code:

```react
entries.push(newEntry)
```

Doing this mutates the array. Do not do that with state.

Correct Code:

```react
setEntries([...entries, newEntry])
```

Here, ...entries copies the old items, and you add newEntry to the end. You pass a new array to setEntries, so React sees a change and updates the UI.
