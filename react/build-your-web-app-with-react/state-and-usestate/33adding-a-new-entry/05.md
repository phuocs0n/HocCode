# Creating the handleSubmit() Function

#### Course: Build your First Web App with React

## Creating the handleSubmit() Function

Before fully handling the form submission, we first need to code the foundations that'll deal with this task.

This "foundation" is a helper function we'll code inside the JournalForm() function. Let's name it handleSubmit():

```react
function handleSubmit(e) {
  e.preventDefault();

  if (title.trim() === "" || content.trim() === "") return;

  onAddEntry(title, content);

  setTitle("");
  setContent("");
}
```

Here,

- handleSubmit(e) is the function that runs when the user clicks Add Entry, and it receives the event object e as an argument.
- This function is attached to the form via onSubmit={handleSubmit}.
- Inside this function, e.preventDefault() stops the browser from reloading the page on submit.
- We only add an entry if both title and content have some non-whitespace text.
- After adding, we clear the form with setTitle("") and setContent("").

With the foundation now set, let's move on to fully processing the form submissions.
