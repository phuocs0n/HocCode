## Personal Story: The Variable That React Ignored

My first attempt at a dynamic list looked like this:

```react
function App() {
  let entries = [];

  function handleAdd() {
    entries.push({ title: "New Entry" });
    console.log(entries); // [{ title: "New Entry" }] — it's there!
  }

return (
    <>
      <button onClick={handleAdd}>Add</button>
      {entries.map(e => <p>{e.title}</p>)}
    </>
  );
}
```

I clicked the button. The console showed the entry was added but the screen showed nothing!

I clicked again:

- Console: two entries
- Screen: blank

I had a variable that was being updated, a console that confirmed it, and a UI that simply did not care.

What was happening here? I'll explain this on the next page, so go there to find out more!
