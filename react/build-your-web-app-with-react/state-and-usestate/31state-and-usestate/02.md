# Why React Ignored My Variable

#### Course: Build your First Web App with React

## Why React Ignored My Variable

Here's the thing: React doesn't watch your variables and cannot detect their change. It re-renders a component when the state changes — and a variable created with let is not considered a "state".

Every time the component re-renders, let entries = [] runs again and wipes everything. Your updates between renders? Gone.

This is what useState() solves. It stores your data outside the component's execution cycle and tells React: "When this changes, re-render."

```react
const [entries, setEntries] = useState([]);
```

Only now will React watch for changes, and updates finally trigger UI re-renders.

Summary

- The Misconception: Any variable I update will cause the UI to refresh.
- The Truth: React only re-renders when the state (managed by useState()) changes. Regular variables are invisible to React.
- The Golden Rule: If a value changes over time and the UI needs to reflect it — it's a state. So you should put it in useState.
