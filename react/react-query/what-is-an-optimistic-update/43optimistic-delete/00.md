## Making Delete Feel Instant

Same pattern, just applied to delete. In src/TaskList.jsx we update the deleteMutation:

```react
const deleteMutation = useMutation({
  mutationFn: deleteTask,
  onMutate: async (id) => {
    await queryClient.cancelQueries({ queryKey: taskKeys.list({ status }) })
    const previousTasks = queryClient.getQueryData(taskKeys.list({ status }))
    queryClient.setQueryData(taskKeys.list({ status }), (old) =>
      old.filter(task => task.id !== id)
    )
    return { previousTasks }
  },
  onError: (error, id, context) => {
    queryClient.setQueryData(taskKeys.list({ status }), context.previousTasks)
  },
  onSettled: () => {
    queryClient.invalidateQueries({ queryKey: taskKeys.all })
  }
})
```

The task disappears instantly when the user clicks Delete. If the server fails it reappears.
