## How Optimistic Updates Work

React Query gives us three callbacks on useMutation to handle optimistic updates:

- onMutate runs before the mutation fires. This is where we update the cache immediately.
- onError runs if the mutation fails. This is where we roll back to what it was before.
- onSettled runs after the mutation either succeeds or fails. This is where we sync with the server.
