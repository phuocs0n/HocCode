## What is a Race Condition?

Here's something that can go wrong with optimistic updates that a lot of beginners miss.

Imagine the user changes a task status really quickly. They click open, then immediately click done, then immediately click in progress. Three mutations fire almost at the same time.

Each one is optimistically updating the cache. But the server might respond to them in a different order than they were sent. The cache ends up in a weird state that doesn't match what the user actually wanted.

That's a race condition. Multiple things are happening at the same time and stepping on each other.
