## Setting Up onMutate

In src/TaskList.jsx let's update the updateMutation to use optimistic updates:

```react
const updateMutation = useMutation({
  mutationFn: updateTask,
  onMutate: async (updatedTask) => {
 
    // Step 1: Cancel any outgoing refetches
    await queryClient.cancelQueries({ queryKey: taskKeys.list({ status }) })
 
    // Step 2: Snapshot the current cache
    const previousTasks = queryClient.getQueryData(taskKeys.list({ status }))
 
    // Step 3: Optimistically update the cache
    queryClient.setQueryData(taskKeys.list({ status }), (old) =>
      old.map(t => t.id === updatedTask.id ? { ...t, ...updatedTask } : t)
    )
 
    // Step 4: Return the snapshot for rollback
    return { previousTasks }
  },
})
```

First we call cancelQueries. This stops any in-flight refetches that might overwrite our optimistic update.

Then we call getQueryData to take a snapshot of what's currently in the cache. We store this in previousTasks so we can restore it if something goes wrong.

Then we call setQueryData to immediately update the cache with the new task data.

Finally we return { previousTasks } so React Query passes it to onError if needed.
