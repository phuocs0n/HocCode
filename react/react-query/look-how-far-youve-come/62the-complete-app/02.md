## Course Recap

Here's everything you learned across this course:

- useQuery replaces useEffect data fetching and handles loading, errors, and caching automatically
- queryKey is the label React Query uses to store and retrieve data from the cache
- Anything you use inside queryFn must also be in queryKey or you'll get stale data silently
- staleTime controls how long data stays fresh before React Query considers refetching
- useMutation is how you send changes to the server — create, update, or delete
- onSuccess runs after a mutation succeeds and is where you update the cache
- A query key factory in src/queryKeys.js keeps all your keys in one place
- Optimistic updates use onMutate, onError, and onSettled to make changes feel instant
- prefetchQuery fetches data before the user clicks so navigation feels instant
- enabled pauses a query until a condition is met
- select transforms data inside useQuery so your component only gets what it needs

You built a real app. You know how production React Query looks. Now go build something.
