## Using prefetchQuery on Hover

React Query gives us a method called prefetchQuery on the queryClient. We call it on mouse enter to start fetching before the user clicks.

First we need a function in src/api.js to fetch a single task:

```react
export function fetchTask(id) {
  return fetch(`https://dummyjson.com/todos/${id}`)
    .then(res => res.json())
}
```

Then in src/TaskList.jsx we add a prefetch on each task:

```react
function handleMouseEnter(taskId) {
  queryClient.prefetchQuery({
    queryKey: taskKeys.detail(taskId),
    queryFn: () => fetchTask(taskId),
  })
}
```

And on each list item:

```react
<li
  key={task.id}
  onMouseEnter={() => handleMouseEnter(task.id)}
>
```

React Query checks if the data is already fresh in the cache. If it is it does nothing. If it isn't it quietly fetches it in the background.
