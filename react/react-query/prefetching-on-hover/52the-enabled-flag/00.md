# What is a Dependent Query?

#### Course: React Query: The Practical Guide

## What is a Dependent Query?

Sometimes one query depends on the result of another. You can't fetch the second thing until the first one comes back.

React Query handles this with a simple option called enabled. When enabled is false the query just sits and waits. When it becomes true the query fires.

Here's an example. We only want to search tasks when the user has typed at least 3 characters:

```react
const [search, setSearch] = useState('')
 
const { data } = useQuery({
  queryKey: taskKeys.list({ search }),
  queryFn: () => fetchTasks({ search }),
  enabled: search.length > 2
})
```

No fetch happens until the user types 3 characters. No point hitting the server for every single keystroke.
