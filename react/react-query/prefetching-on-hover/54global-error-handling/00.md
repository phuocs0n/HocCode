## Handling Errors in One Place

Right now every useQuery call has its own isError check. That works but it means writing error handling in every component.

In src/index.jsx we can set defaults that apply to every query in the app:

```react
const queryClient = new QueryClient({
  defaultOptions: {
    queries: {
      staleTime: 1000 * 60,
      retry: 1,
      throwOnError: true,
    },
    mutations: {
      onError: (error) => {
        console.error('Something went wrong:', error.message)
      }
    }
  }
})
```

- throwOnError: true tells React Query to throw errors up to the nearest Error Boundary instead of returning them in isError.
- retry: 1 means React Query retries a failed query once before giving up. The default is 3 which can feel slow on a bad connection.
- mutations.onError runs every time any mutation in the app fails. A good place to log the error.
