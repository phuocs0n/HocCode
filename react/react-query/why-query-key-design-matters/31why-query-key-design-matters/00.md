## Your App is Growing

TaskFlow is working. You can fetch tasks, create them, update them, delete them. That's solid.

But here's something that happens in every real app as it grows. You start having more and more queries and managing all those query keys starts feeling messy.

You end up with keys scattered across different files. Someone writes ['tasks'] in one place and ['task'] in another. Typos happen. Invalidations stop working. Data goes stale without you realizing.

This is a query key problem and it's one of the most common sources of bugs in React Query apps.
