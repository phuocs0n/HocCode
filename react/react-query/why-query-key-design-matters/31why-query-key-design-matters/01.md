## The Problem With Scattered Keys

Right now in TaskFlow we have keys written directly inside the component. As the app grows it starts looking like this:

```react
// fetching all tasks
useQuery({ queryKey: ['tasks'] })
 
// fetching filtered tasks
useQuery({ queryKey: ['tasks', { status }] })
```

Now when we want to update the cache after a mutation we have to remember every variation. If we typo even one of them, that query never updates.

There's a much cleaner way to handle this.
