## Adding a Detail Key

Sometimes we want to fetch a single task by id. We need a separate key for that. Open src/queryKeys.js and add one more line:

```react
export const taskKeys = {
  all: ['tasks'],
  lists: () => [...taskKeys.all, 'list'],
  list: (filters) => [...taskKeys.lists(), { filters }],
  detail: (id) => [...taskKeys.all, 'detail', id],
}
```

detail takes an id and returns ['tasks', 'detail', id]. This represents one specific task.

Now if we ever fetch a single task we use taskKeys.detail(taskId) as the key. Clean and consistent.
