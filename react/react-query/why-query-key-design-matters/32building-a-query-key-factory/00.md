# What is a Query Key Factory?

#### Course: React Query: The Practical Guide

## What is a Query Key Factory?

A query key factory is just an object that holds all your query keys in one place. Instead of writing ['tasks'] everywhere you define it once and import it wherever you need it.

Open src/queryKeys.js. Here's what it looks like:

```react
export const taskKeys = {
  all: ['tasks'],
  lists: () => [...taskKeys.all, 'list'],
  list: (filters) => [...taskKeys.lists(), { filters }],
}
```

all is the base key for everything task related. Just ['tasks'].

lists builds on all and adds 'list' to it. This represents any list of tasks.

list takes a filters object and adds it. So taskKeys.list({ status: 'open' }) returns ['tasks', 'list', { filters: { status: 'open' } }].
