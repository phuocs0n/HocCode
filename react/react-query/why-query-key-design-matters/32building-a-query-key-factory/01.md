## Using the Factory in TaskList.jsx

Now in src/TaskList.jsx instead of hardcoding keys we import and use taskKeys:

```react
import { taskKeys } from './queryKeys'
 
const { data: tasks } = useQuery({
  queryKey: taskKeys.list({ status }),
  queryFn: () => fetchTasks({ status }),
})
```

And in every mutation we use the same factory:

```react
const createMutation = useMutation({
  mutationFn: createTask,
  onSuccess: (data) => {
    queryClient.setQueryData(taskKeys.list({ status }), (old) => [
      ...old,
      { id: data.id, title: data.todo, status: 'open' }
    ])
  }
})
```

Everything lives in one place. If you ever need to change the key structure you change it in queryKeys.js and it updates everywhere automatically.
