## Wiring Up the Update Mutation

In src/TaskList.jsx we add the update mutation:

```react
const updateMutation = useMutation({
  mutationFn: updateTask,
  onSuccess: (_, updatedTask) => {
    queryClient.setQueryData(taskKeys.list({ status }), (old) =>
      old.map(t => t.id === updatedTask.id ? { ...t, ...updatedTask } : t)
    )
  }
})
```

And for each task we add a status dropdown:

```react
<select
  value={task.status}
  onChange={e => updateMutation.mutate({ ...task, status: e.target.value })}
>
  <option value='open'>Open</option>
  <option value='inProgress'>In progress</option>
  <option value='done'>Done</option>
</select>
```

When the user picks a new status we spread the existing task in and just replace the status with the new value.
