## What We Built

Let's take a step back and look at what we added in this chapter.

We added createTask, updateTask, and deleteTask to src/api.js. Each one does exactly one job.

In src/TaskList.jsx we wired up three mutations with useMutation. Each one updates the cache directly in onSuccess so the UI responds instantly.

No page refresh. No extra logic. Just clean mutations and a cache that always reflects what the user just did.
