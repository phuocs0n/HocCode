## Wiring Up the Delete Mutation

In src/TaskList.jsx we add the delete mutation:

```react
const deleteMutation = useMutation({
  mutationFn: deleteTask,
  onSuccess: (_, id) => {
    queryClient.setQueryData(taskKeys.list({ status }), (old) =>
      old.filter(task => task.id !== id)
    )
  }
})
```

In onSuccess we filter that task out of the cache directly so it disappears from the screen immediately.

And for each task we add a Delete button:

```react
<button onClick={() => deleteMutation.mutate(task.id)}>
  Delete
</button>
```
