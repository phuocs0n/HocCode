## So Far We've Only Been Reading Data

So far in TaskFlow we've been fetching tasks. We ask the server for tasks and it sends them back.

But in a real app users don't just read data. They create new tasks, mark things as done, delete stuff. All of that means sending data to the server, not just receiving it.

In React Query that's called a mutation. Any time you're changing data on the server, whether it's creating, updating, or deleting, you're doing a mutation.
