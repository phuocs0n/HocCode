## Meet useMutation

React Query gives us a hook called useMutation. It works a little differently from useQuery.

With useQuery the fetch happens automatically when the component loads. With useMutation nothing happens until you actually trigger it. That makes sense because you don't want tasks randomly creating or deleting themselves.

Here's what it looks like:

```react
const mutation = useMutation({
  mutationFn: createTask
})
```

You pass it one thing called mutationFn. That's the function that talks to the server.

Then when the user does something like clicking a button, you call mutation.mutate() to fire it.
