#### Course: React Query: The Practical Guide

## What is a Query Key?

Imagine React Query has a big storage room where it keeps all the data it fetches. Every piece of data in that room needs a label so React Query knows where to find it later. That label is the query key.

When you write queryKey: ['tasks'], you're saying 'store this data under the name tasks.' Next time any component needs tasks, React Query checks that storage room first before touching the network. If it finds something fresh, it returns it instantly.

In TaskFlow you'll have different views of tasks. Each one needs its own key:

```react
// All tasks
queryKey: ['tasks']
 
// Just the open ones
queryKey: ['tasks', { status: 'open' }]
 
// One specific task
queryKey: ['tasks', taskId]
```

You just add more to the array to make it more specific. React Query knows these are all related to tasks but treats them as different pieces of data.
