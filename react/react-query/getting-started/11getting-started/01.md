# What You'll Build 🛠️

#### Course: React Query: The Practical Guide

## What You'll Build 🛠️

In this course, you'll learn React Query by building a real application from scratch.

The project is called TaskFlow — a task manager for teams to create work, track progress, and stay in sync.

Have you ever used something like Trello or Notion? TaskFlow is that, but lighter. Just the core of what makes those tools useful, stripped down so the code stays clear and the concepts stay front and center.

By the time you're done, it will:

- Show a live list of tasks fetched from a server
- Let you create, update, and delete tasks
- Filter tasks by status: open, in progress, or done
- Update the screen instantly when something changes

Every React Query concept you learn gets added directly to TaskFlow. Nothing will feel random or out of place.
