## Hi there! 👋

So you've learned React. You know what a component is, you've played with useState, and you've probably written something like useEffect(() => { fetch(...) }) to grab some data.

That's great.

But here's the thing. Every time you fetch data that way, you have to manually track whether it's loading, whether it errored, whether the data is outdated. You end up writing the same chunk of code in every single component. It gets old fast.

React Query solves exactly that problem. It handles all of that for you automatically. You just tell it what to fetch and it takes care of the rest.
