## Adding React Query to the Project

When you use an external library in React, it needs to be listed in your project's dependencies.

Think of dependencies as a list of all the extra tools your project uses.

For React Query you need two packages:

- @tanstack/react-query — React Query itself
- @tanstack/react-query-devtools — a panel that shows you what's happening inside the cache

In package.json you should add these two packages inside dependencies:

```react
"@tanstack/react-query": "^5.0.0",
"@tanstack/react-query-devtools": "^5.0.0"
```

Now your package.json will look like this:

```react
{
  "dependencies": {
    "react": "^18.2.0",
    "react-dom": "^18.2.0",
    "react-router-dom": "^6.22.3",
    "axios": "^1.4.0",
    "@tanstack/react-query": "^5.0.0",
    "@tanstack/react-query-devtools": "^5.0.0"
  }
}
```

Both are already installed so you don't need to do anything here. Just good to know where they live.
