In index.jsx we added three things:

- QueryClient — creates the cache where React Query stores all your data
- QueryClientProvider — wraps your whole app so every component can use that cache
- ReactQueryDevtools — adds a floating panel in the corner so you can see what is cached and when things are refetching

From this point on, every component in your app can talk to React Query.
