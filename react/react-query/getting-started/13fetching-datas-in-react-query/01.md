## The React Query Way

React Query gives you a single hook called useQuery. Pull it in like this:

```react
import { useQuery } from '@tanstack/react-query'
```

Now instead of all that setup, you call useQuery with two things:

```react
const { data: tasks, isLoading, isError } = useQuery({
  queryKey: ['tasks', { status }],
  queryFn: () => fetchTasks({ status })
})
```

- queryKey is like a label on a jar. React Query uses it to store and find this data in the cache. queryFn is the function that actually goes and fetches the data.
- Back you get three things. data holds the tasks, isLoading is true while they're coming in, and isError is true if something went wrong.
