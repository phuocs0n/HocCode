## Putting It All Together

Before updating the component, let's create a home for all your fetch functions. Open src/api.js and add this:

```react
const BASE = 'https://dummyjson.com/todos'
 
export function fetchTasks({ status } = {}) {
  return fetch(`${BASE}?limit=10`)
    .then(r => r.json())
    .then(d => d.todos.map((t, i) => ({
      id: t.id, title: t.todo,
      status: t.completed ? 'done' : (i % 3 === 1 ? 'inProgress' : 'open')
    })))
    .then(tasks => status ? tasks.filter(t => t.status === status) : tasks)
}
```

fetchTasks takes an optional status. If one is passed it filters the results. Keeping fetch functions in one file makes things a lot easier to manage as the app grows.
