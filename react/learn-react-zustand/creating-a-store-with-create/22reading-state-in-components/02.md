## Why the Selector Matters

You might wonder — why pass a function? Why not just do this?

```react
const store = useJournalStore()
```

You could. But then your component would re-render every time anything in the store changes. Even things it does not care about.

With a selector your component only re-renders when the exact piece of state it selected changes.

```react
const entries = useJournalStore((state) => state.entries)
```

This component only re-renders when entries changes. Not when theme changes. Not when searchQuery changes. Just entries.

That keeps your app fast as it grows.
