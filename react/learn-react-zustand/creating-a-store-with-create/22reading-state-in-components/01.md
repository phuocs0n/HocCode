## Connecting a Component to the Store

The store is ready. Now how does a component actually read from it?

To read from the store you use useJournalStore and pass it a selector function. The selector tells Zustand exactly which piece of state you want.

Now, in src/components/EntryList.jsx you do this.

```javascript
1import { create } from 'zustand'
2 
3const useJournalStore = create((set) => ({
4  entries: [],
5  theme: 'light',
6}))
7 
8export default useJournalStore
```

Go ahead and run it and open the console.

Here is what is happening. EntryList asks the store for entries. Zustand returns the empty array and logs it. No props. No lifting state. The component just reached into the store and took what it needed.

Right now entries is empty. In Chapter 3 you will fetch real entries from the API and the list will fill up.
