## Writing Your First Action

To update state in Zustand you use set. Now, in src/store/useJournalStore.js you add addEntry right alongside your state.

```react
addEntry: (title, content) => set((state) => ({
  entries: [
    ...state.entries,
    {
      id: Date.now(),
      title,
      content,
      date: new Date().toLocaleDateString()
    }
  ]
}))
```

set receives the current state and returns what should change.

...state.entries keeps all the existing entries. Then you add the new one at the end.

Date.now() gives each entry a unique id. Simple and it works.
