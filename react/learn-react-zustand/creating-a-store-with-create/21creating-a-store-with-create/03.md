## Your First Store

To create a store in Zustand you use create. Now, in src/store/useJournalStore.js you do this.

```javascript
1import { create } from 'zustand'
2
3const useJournalStore = create((set) => ({
4  entries: [],
5  theme: 'light',
6}))
7
8export default useJournalStore
```

Here is what is happening, piece by piece.

create takes a function, and that function returns a plain object — that object is your store.

Inside it, you put your data. Here we have two things: entries, which starts as an empty array ready to hold your journal entries, and theme which starts as 'light' — we will use this later to switch between light and dark mode.

create gives you back a hook called useJournalStore. Any component in your app can call that hook to read from the store.

You also see set being passed in — that is how you will update state later. Zustand handles that for you automatically.
