## Adding persist Middleware

Zustand has a built-in middleware called persist that saves chosen parts of your store to localStorage automatically.

In src/store/useJournalStore.js you wrap your store with persist.

```react
import { create } from 'zustand'
import { persist } from 'zustand/middleware'

const useJournalStore = create(
  persist(
    (set) => ({
      // ... your state and actions
    }),
    {
      name: 'journal-store',
      partialize: (state) => ({
        theme: state.theme,
        searchQuery: state.searchQuery,
      }),
    }
  )
)
```

name is the key used in localStorage. partialize tells Zustand which parts of the store to save.

Notice you only save theme and searchQuery. Not entries. Not loading state. Entries come from the API fresh on every load so saving them locally makes no sense.
