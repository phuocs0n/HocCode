#### Course: Learn React Zustand: The Smarter Way to Handle Data

## What Survives a Refresh?

Right now when you refresh the page two things happen.

The entries are fetched fresh from the API — same as always. They live on the server so there is no need to save them locally.

But the theme and search query are different. Those are your preferences. They only live in the store. Without persistence they reset to their defaults on every reload.

Have you ever set an app to dark mode and come back the next day to find it back to light? That is exactly this problem.

Next, you will see how to fix it. Click Next Lesson to continue.
