## Updating Objects Inside Arrays

When you update an entry you do not want to lose the other fields. You only want to change the ones that actually changed.

That is what the spread operator is for. You already used it in editEntry in src/store/useJournalStore.js.

```react
entries: state.entries.map((entry) =>
  entry.id === id ? { ...entry, title, content } : entry
)
```

{ ...entry, title, content } copies all the existing fields from the entry, then overwrites just title and content. The id and the date stay exactly the same.

This is the correct pattern any time you need to update one object inside an array.
