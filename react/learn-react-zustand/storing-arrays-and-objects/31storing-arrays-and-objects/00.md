## Beyond Simple Values

So far your store has two things — an array of entries and a string for theme.

But look at what an entry actually is. It is not just a string. It is an object with multiple fields.

```react
{
  id: 1,
  title: 'First Day at the New Job',
  content: 'Today was my first day.',
  date: '2026-02-27',
}
```

And you have a list of them. So your store is holding an array of objects.

Zustand handles this exactly the same way it handles anything else. The shape of the data does not change how Zustand works.

But updating objects inside arrays correctly is something worth knowing.

Next, you will see how updates work with nested data. Click Next Lesson to continue.
