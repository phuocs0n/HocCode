## Loading and Error State

When you fetch data from a server three things can happen. The data is loading. The data arrives. Something goes wrong.

Your store should be ready for all three. In src/store/useJournalStore.js you add two more pieces of state.

```react
isLoading: false, error: null,
```

isLoading starts as false. When a fetch begins you set it to true. When it finishes you set it back to false.

error starts as null. If something goes wrong you put the error message there.

Your components can then read these and show the right thing.

```react
if (isLoading) return Loading entries...
if (error) return Something went wrong: {error}
```

Simple. And the whole app knows about it because it lives in the store.
