## Fetching Data the Old Way

You have used useEffect to fetch data before. It looked something like this.

```react
useEffect(() => {
  fetch('https://api.programiz.pro/api/Demo/v1/journal-entries')
    .then((res) => res.json())
    .then((data) => setEntries(data))
}, [])
```

This works. But the fetch logic lives inside the component. The component is doing everything — loading the data, handling errors, updating state.

That is a lot for one component. And if two components need the same data you have a problem.

There is a better way.

Next, you will see how to move the fetch into the store. Click Next Lesson to continue.
