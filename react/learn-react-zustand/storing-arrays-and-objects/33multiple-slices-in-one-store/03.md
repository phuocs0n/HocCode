## Adding the UI Slice

In src/store/useJournalStore.js you add searchQuery, toggleTheme and setSearchQuery alongside your entries state.

```react
theme: 'light',
searchQuery: '',

toggleTheme: () => set((state) => ({
  theme: state.theme === 'light' ? 'dark' : 'light'
})),

setSearchQuery: (query) => set({ searchQuery: query }),
```

toggleTheme checks the current theme and switches it. setSearchQuery just updates the search string in the store.
