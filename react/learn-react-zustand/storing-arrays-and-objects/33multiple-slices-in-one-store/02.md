## Thinking in Slices

Your journal store has two natural groups.

The entries slice handles everything about journal entries.

```react
entries: [],
isLoading: false,
error: null,
fetchEntries: async () => { ... },
addEntry: (title, content) => { ... },
editEntry: (id, title, content) => { ... },
deleteEntry: (id) => { ... },
```

The UI slice handles everything about the interface.

```react
theme: 'light',
searchQuery: '',
toggleTheme: () => { ... },
setSearchQuery: (query) => { ... },
```

Same store. Same create() call. Just organized so you can see what belongs together.
