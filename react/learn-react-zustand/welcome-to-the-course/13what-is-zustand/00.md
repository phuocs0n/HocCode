## A Tool You Add to Your Project

Zustand is a state management library for React.

A library is just a tool someone else built that you can drop into your project and use. You have already used libraries before. React itself is a library.

Zustand gives you one thing. A simple way to create a store, put your state in it, and read from or update it from any component.

That is it. That is all it does.

But before you use it, a fair question is worth asking. There are other state management libraries out there. Why Zustand?
