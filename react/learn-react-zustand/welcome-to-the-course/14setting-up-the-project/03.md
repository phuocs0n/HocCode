## Zustand Is Already Installed

When you use an external library in React, it needs to be listed in your project's dependencies. Think of dependencies as a list of all the extra tools your project uses.

For this project you need one package: zustand.

In package.json it lives inside dependencies.

```react
{
  "dependencies": {
    "react": "^18.2.0",
    "react-dom": "^18.2.0",
    "zustand": "^5.0.0"
  }
}
```

It is already installed so you do not need to do anything here. Just good to know where it lives.
