## This Is a State Management Course

Before any code, let us be clear about what you are actually learning here.

This is not just a course about one library.

Think of it like learning to drive. You are not learning one specific car. You are learning how to drive. The car is just what you practice with.

The same idea applies here. State management is the skill. The tool you use is just the vehicle.

By the end you will understand what global state is and why it exists. When to keep state local and when to make it global. How to handle async data, loading states, and errors. And how to persist data across page refreshes.

These ideas carry over to every React project you build from here.
