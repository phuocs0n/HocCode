# Keep Building

#### Course: Learn React Zustand: The Smarter Way to Handle Data

## Keep Building

The best way to get better at state management is to build things.

Take what you learned here and apply it to your own projects. Start small. Add a store to something you are already building. Move some prop drilling into a store and feel the difference.

Here are some ideas to keep going:

- Add user authentication to the journal app — store the user in Zustand
- Build a shopping cart — a classic state management exercise
- Explore Zustand devtools — they let you inspect your store in the browser

You have everything you need. Keep going.
