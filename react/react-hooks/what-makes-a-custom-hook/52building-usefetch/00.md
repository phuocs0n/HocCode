## The Problem: Fetch Logic Copied Everywhere

The fetch logic in App.jsx is tangled directly into the component:

- A useEffect() with a loadEntries() inner function
- Three state variables (isLoading, error, and entries)
- A try...catch block.

Any other component that needs to fetch a different URL will have to duplicate all of it.

It'd be great if we could build a useFetch() hook that extracts this pattern into one reusable place. Every component that needs to fetch can call useFetch(url) and get back { data, isLoading, error }.

So let's start building it.
