## Possible Improvements to the App

Let's continue with the improvements:

| Feature | Description |
| --- | --- |
| Performance | React.memo() prevents a child from re-rendering when its props have not changed. It pairs with

useCallback() to keep function props stable, and
useMemo() (to keep object props stable). |
| Fullstack | Frameworks like Next.js and Remix bring React to the server.

Server components fetch data without any hooks at all. They run once on the server and send HTML to the browser.
Client components use hooks exactly as we have covered here.

The hooks we've covered (useState(), useEffect(), useRef(), useMemo(), useCallback()) work in every one of these environments without change. |

Everything we built here transfers directly.
