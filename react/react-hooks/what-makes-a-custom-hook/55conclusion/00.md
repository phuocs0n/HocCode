## What You Built

You started with a form and a hardcoded list. And now, you end with a fully connected journal app that has:

- Live data fetched from an API
- Search and pagination
- A detail drawer for reading entries
- All logic cleanly separated into composable hooks

Here's the full journey:

| Hook | Feature | What Changed |
| --- | --- | --- |
| useEffect() | Live data | Removed the form. Fetched entries from JSONPlaceholder. Added loading, error, and empty states. |
| useRef() | Entry detail drawer | Autofocused the search input. Built a drawer that closes on outside click or Escape key. |
| useMemo(), useCallback() | Search + pagination | Lifted search state. Filtered and paginated entries with derived state. Stabilised function references. |
| Custom hooks | Code reuse | Extracted useFetch(), useSearch(), usePagination(). App composes them in a handful of lines. |
