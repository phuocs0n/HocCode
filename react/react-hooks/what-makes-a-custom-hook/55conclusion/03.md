## Mental Model: When to Extract a Custom Hook

The four questions help you understand what a component owns. When the answers cluster, that's the signal to extract.

Here are a couple of scenarios:

| Mental Model: Custom Hook Scenarios |
| --- |
| Scenario 1: The same state always travels with the same effect.

If isLoading, error, and data always appear alongside the same useEffect(), they belong in one hook.

Reason: A component that renders data always needs to know if it's still loading or if an error occurred — you can't have one without the other two. |
| Scenario 2: The same derived values always sit next to the same handler.

If filteredEntries from useMemo() always appears next to the query setter, they belong together.

Reason: The filtered list is meaningless without the query that drives it. |

The Million-Dollar Question

In such scenarios, ask:

```text
"Which of these hooks belong together?"
```

The answer names your next custom hook.
