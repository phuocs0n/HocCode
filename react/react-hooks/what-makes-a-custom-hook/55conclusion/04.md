## The Big Picture

Everything in a React app can be reduced to one line:

```text
UI = components (state + hooks + render)
```

Here's what each term maps to:

- State: Values that change over time, owned and managed by hooks
- Hooks: Where logic lives: fetching, filtering, paginating, stabilising references
- Render: The JSX a component returns, driven by the current state
- Components: The wrappers that compose hooks and produce the render

That's the complete picture. Components don't manage logic directly; they delegate to hooks and describe what to show.
