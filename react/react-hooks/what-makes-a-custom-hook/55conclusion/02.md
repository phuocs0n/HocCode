## Hooks Mental Model: Component Analysis

Every React component can be understood with four questions:

| Mental Model: React Components |
| --- |
| Question 1: What state does this component own?

Any value that changes over time and cannot be derived from another state. Store it with useState(). |
| Question 2: What derived values can be computed from that state?

Any value that can be calculated from an existing state. Compute it with useMemo() rather than storing it separately. Storing it separately creates two sources of truth. |
| Question 3: What side effects run when state changes?

Any operation that reaches outside React — fetching data, setting up subscriptions, writing to the DOM. Run them with useEffect() and always clean up listeners and subscriptions. |
| Question 4: What function references need to stay stable?

Functions passed to child components or listed in a useEffect() dependency array. Stabilise them with useCallback() to prevent unnecessary re-renders or effect re-runs. |

These four questions help you analyze what a component owns and does. The next section covers what to do when the analysis reveals too much.
