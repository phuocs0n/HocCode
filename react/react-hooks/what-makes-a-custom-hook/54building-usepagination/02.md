#### Course: React Hooks: Level Up Your First Web App

## How App is Modified

What moved out of App:

- useState() for currentPage
- useMemo() for totalPages
- useMemo() for pagedEntries
- handleNext() and handlePrev() handlers

What stays in App:

- useMemo() for entries (journal-specific mapping of raw API data)
- useState() for selectedEntry (drawer state)
- handleQueryChange() — it calls setQuery() from useSearch() and reset() from usePagination(), coordinating both hooks

With the hook extracted, we can write the final version of App.jsx.
