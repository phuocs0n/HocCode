# Summary of the Changes to App

#### Course: React Hooks: Level Up Your First Web App

## Summary of the Changes to App

Compare the latest App.jsx to what it was at the start of this chapter. You'll notice the following changes:

- The seven state variables became one (selectedEntry).
- Fetch state lives inside useFetch().
- The three standalone useMemo() calls became part of hooks.
- The useEffect() moved into useFetch().

What remains in App is only what is unique to this component:

- The entry mapping
- The drawer
- The coordination between hooks

That's basically it. You're now approaching the end of this course.

But there still are a few things left to do, including the important task of testing yourself with what you've learned.
