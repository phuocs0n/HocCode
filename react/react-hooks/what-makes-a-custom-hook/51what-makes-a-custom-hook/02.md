## Example: A Simple Custom Hook

Here's a hook that tracks the browser window's width:

```react
import { useState, useEffect } from "react";

// Custom hook
function useWindowWidth() {
  const [width, setWidth] = useState(window.innerWidth);

  useEffect(function () {
    function handleResize() {
      setWidth(window.innerWidth);
    }

    window.addEventListener("resize", handleResize);

    return function () {
      window.removeEventListener("resize", handleResize);
    };
  }, []);

  return width;
}

export default useWindowWidth;
```

A component that calls it gets the current width in a single line:

```react
const width = useWindowWidth();
```

Notice These Important Points:

- The state and effect live in the hook.
- The component calls one line and gets a value.
