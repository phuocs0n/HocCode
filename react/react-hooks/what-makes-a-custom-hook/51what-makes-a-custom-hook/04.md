# What Can a Custom Hook Return?

#### Course: React Hooks: Level Up Your First Web App

## What Can a Custom Hook Return?

A custom hook can return anything the caller needs:

| Return Value | Example |
| --- | --- |
| A primitive | return width; |
| An object | return { data, isLoading, error }; |
| An array | return [value, toggle]; |
| A function | return function () { ... }; |

Deciding the Return Value

- Objects work well when there are several values to return.
- Arrays work well when the caller wants to rename the values (the same way useState() does).

The real motivation for custom hooks becomes clear when you see them solving a problem you've already faced.
