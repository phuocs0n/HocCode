This component has:

- seven state variables,
- three useMemo() calls,
- a useEffect(),
- and several handlers.

If a second component anywhere in the app needed to fetch data, we'd need to copy that entire useEffect() block, paste it in, and maintain two identical copies forever.

This is the problem custom hooks solve.

They let us extract hook-based logic out of a component and into a reusable function. Any component can then call that function to get the same behavior.
