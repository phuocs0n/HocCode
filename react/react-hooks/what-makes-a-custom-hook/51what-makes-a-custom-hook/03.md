# The Two Rules of Custom Hooks

#### Course: React Hooks: Level Up Your First Web App

## The Two Rules of Custom Hooks

Custom hooks follow the same rules as built-in hooks:

Rule 1: Only call hooks at the top level.

Never call a hook inside a loop, condition, or nested function. React tracks hooks by call order, and it must be stable on every render.

Rule 2: Only call hooks from React functions.

Call hooks from function components or from other custom hooks. Never call them from regular JavaScript functions, class components, or event handlers.

Rule Applications and Restrictions

These rules apply equally to useState(), useEffect(), and any custom hook you write.

Custom hooks are also flexible in what they can return — there are no restrictions.
