## How App is Modified

What moved out of App:

- useState() for query
- useMemo() for filteredEntries

What stays in App:

- Resetting currentPage when the query changes. This coordination between hooks belongs in the component, not inside either hook.

With the hook extracted, we can update App.jsx to call it.
