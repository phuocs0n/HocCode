24        setError(err.message);

26      }

If you go through the code, you'll notice the following:

- handleQueryChange() still calls setQuery() (from the hook's return) and resets currentPage. This coordination is App's job, not the hook's.
- query and filteredEntries are gone from App as standalone declarations. They come from useSearch().
- The Refresh button is back: useFetch() now returns a refetch() function. This was added in the practice exercise at the end of the previous lesson.

If you click Run Code, you'll see the app behaves exactly as before.
