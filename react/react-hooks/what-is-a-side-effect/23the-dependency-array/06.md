## Adding a Refresh Button

We can use Form 3 to make the fetch re-run on demand.

So, let's add a counter state called refreshKey that starts at 0 and list it in the dependency array:

```react
const [refreshKey, setRefreshKey] = useState(0);

useEffect(function () {
  // ...
}, [refreshKey]);
```

The Refresh button increments the counter:

```react
<button onClick={() => setRefreshKey((k) => k + 1)}>
  Refresh
</button>
```

Each click changes refreshKey. React sees the dependency has changed and re-runs the effect, triggering a fresh fetch.
