# The Three Forms

#### Course: React Hooks: Level Up Your First Web App

## The Three Forms

There are three ways to write the second argument of useEffect(), and each produces different behavior:

```react
// Form 1: No array
// Runs after every render. Rarely what you want for a fetch
useEffect(function () {
  // ...
});

// Form 2: Empty array
// Runs only once, when the component first mounts.
useEffect(function () {
  // ...
}, []);

// Form 3: With dependencies
// Runs on mount AND whenever any listed value changes.
useEffect(function () {
  // ...
}, [query]);
```

Form 3 is what makes an effect respond to changes.

You can see that the dependency array in Form 3 has the query state. This means that useEffect() will re-run every time query changes.

Please note that the dependency array can hold any number of values: state variables, props, or context values. We'll see how to do that next.
