## A Filter That Never Updated

So I was building an admin panel. A dropdown let admins switch between user accounts and see each user's journal entries.

Naturally, the effect fetched entries filtered by userId:

```react
useEffect(function () {
  async function loadEntries() {
    const res = await fetch("/api/entries?userId=" + userId);
    const data = await res.json();
    setEntries(data);
  }

  loadEntries();
}, []);
```

It worked on the first load. Switch to a different user — the entries did not change. Refresh the page manually — entries updated. No errors, no warnings.

The dropdown clearly set a new userId in state and the component re-rendered, but the fetch always came back with the first user's data.

I spent two hours convinced the bug was in the dropdown. It wasn't.

You've probably already guessed what was happening. If not, the next section will explain it.
