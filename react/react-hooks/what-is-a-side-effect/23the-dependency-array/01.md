## The Problem: When Should the Effect Re-run?

Right now, the app fetches entries once when it mounts. That is all it ever does.

If the fetch fails, or if the user wants to reload the list, they have to refresh the browser tab. There's no way to trigger the fetch again from inside the app.

We need a "Refresh" button. When the user clicks it, the fetch should run again.

The answer to "how do we tell useEffect() to re-run?" is in the dependency array: the second argument we have been passing as [].
