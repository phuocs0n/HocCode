## Why the Effect Never Re-Ran

The effect had captured userId from the first render and never let go.

The function closed over the value at the moment it was created and held that snapshot even after userId changed in state.

The empty [] told React "this effect has no dependencies," so React never re-ran it.

The fix was simple — remove userId from await fetch() and shift it inside the dependency array:

```react
useEffect(function () {
  // Code
}, [userId]);
```

Now React compares userId after every render. When it changes, the effect re-runs with the fresh value.
