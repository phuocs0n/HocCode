## Adding Multiple Dependencies

Previously, our dependency array checked only a single value: query.

```react
useEffect(function () {
  // ...
}, [query]);
```

But what if you need to re-render based on other values as well? For instance, you might also need to re-render when you go to the next page of journal entries.

In this case, you'll need to add both query and page to the array:

```react
useEffect(function () {
  // ...
}, [query, page]);
```

Basically, React watches every value in the list. If any of them change between renders, the effect re-runs.
