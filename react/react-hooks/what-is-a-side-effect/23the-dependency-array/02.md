## What Is the Dependency Array?

The dependency array is the second argument to useEffect():

```react
useEffect(function () {
  // Side effect
}, []); // ← This is the dependency array
```

It's a list of values that React watches after every render.

After each render, React compares each value in the list to what it was during the previous render. If any value changed, React re-runs the effect.

So far, we've been passing an empty list: []. That tells React to watch nothing. So the effect runs once on mount and never again.

To make the effect re-run, we add a value to the list. When that value changes, the effect runs again.
