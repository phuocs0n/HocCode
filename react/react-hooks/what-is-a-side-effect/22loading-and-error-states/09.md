## The Reason Behind the Silence

Here's what was happening in my dashboard:

When the browser reaches the server and the server sends back a response ("Data not found" response included), fetch() considers that a success.

The Promise resolves, and your try block keeps running.

fetch() only rejects when the network itself fails: no connection, DNS error, request timeout. Any HTTP response — 200, 404, or 500 — resolves the Promise.
