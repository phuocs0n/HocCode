## Learning From My Mistake

Here are the key takeaways from my blunder:

The Misconception

"If my catch block did not run, the request must have succeeded."

The Truth

fetch() only rejects on network failures. HTTP error codes (200, 403, 404, 500) still resolve the Promise. Without the res.ok check, your error state is never set.

The Golden Rule

After every await fetch(), check res.ok before touching the response body. Make it a reflex.
