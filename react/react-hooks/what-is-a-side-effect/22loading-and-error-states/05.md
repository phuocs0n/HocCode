## Handling the Error

Both the errors we previously discussed land in the same catch block. Therefore, try...catch is cleaner here than chaining .then() and .catch():

```react
// Inside App()

useEffect(function () {
  async function loadEntries() {

    // Handle the error
    try {
      const res = await fetch("https://api.programiz.pro/api/Demo/v1/journal-entries");
      if (!res.ok) {
        throw new Error("Could not load entries. Status: " + res.status);
      }
      const data = await res.json();
      const mapped = data.map((post) => ({ ... }));
      setEntries(mapped);
      setIsLoading(false);
    }

    catch (err) {
      setError(err.message);
      setIsLoading(false);
    }
  }

  loadEntries();
}, []);
```

Notice that setIsLoading(false) appears in both the try and catch blocks. That's because loading always ends, whether the fetch succeeded or failed.
