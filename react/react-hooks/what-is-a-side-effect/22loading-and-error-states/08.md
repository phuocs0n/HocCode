## Why fetch() Doesn't Throw for 404 and 500

Here's a tale of sorrows from my early days:

I was building a dashboard that fetched data from a staging API. The server was up, the network was fine.

But one afternoon the data just disappeared. The app showed "No entries found." and I assumed the API had returned an empty list.

I spent thirty minutes checking my mapping logic, my state updates, everything.

Then I opened the Network tab in DevTools. Every request was returning 404 Not Found.

The staging URL had changed, but the app's UI was completely calm — no error banner, no warning, just silence.
