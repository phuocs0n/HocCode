## Adding a Loading State

We'll start by adding an isLoading state to App.jsx:

- It starts as true since the app is always loading when it first mounts.
- It flips to false once the fetch completes.

```react
const [isLoading, setIsLoading] = useState(true);
```

Inside useEffect(), we call setIsLoading(false) right after the entries are stored:

```react
// Inside App()

useEffect(function () {
  async function loadEntries() {
    const res = await fetch("https://api.programiz.pro/api/Demo/v1/journal-entries");
    const data = await res.json();
    const mapped = data.map((post) => ({ ... }));
    setEntries(mapped);

    // Change isLoading to false
    setIsLoading(false);
  }

  loadEntries();
}, []);
```
