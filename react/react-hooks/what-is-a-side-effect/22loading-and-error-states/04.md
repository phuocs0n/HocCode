## Adding an Error State

In App.jsx, we need one more piece of state — error — to hold the message if something goes wrong. It starts as null, meaning no error yet.

```react
const [error, setError] = useState(null);
```

Two things can go wrong inside loadEntries():

1. A Bad HTTP Status

The request completed, but the server returned an error code (404, 500, etc.).

fetch() does not throw errors for these. Instead, we have to check res.ok ourselves and throw the error manually.

2. A Network Failure

The request never completed at all. This throws automatically, so the catch block handles it.
