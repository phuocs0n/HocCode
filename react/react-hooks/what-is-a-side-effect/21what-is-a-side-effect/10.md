## Summarizing useEffect()

Here are a few things you need to remember:

The Misconception

"I can fetch data anywhere in the component as long as I put the result in state."

The Truth

Calling setEntries() causes a re-render. If fetch() is inside the component body, every re-render starts another fetch.

useEffect() with [] is the designated safe zone for code that should only run once.

The Golden Rule

Never fetch data — or do anything that updates state — directly inside the component body. Always put it inside useEffect().

Keep these things in mind, and you'll be able to utilize useEffect() properly.

The Constraint

Mind you, there's one constraint to be aware of: the function you pass to useEffect() cannot be async.

The next section explains why, and shows the correct pattern to use instead.
