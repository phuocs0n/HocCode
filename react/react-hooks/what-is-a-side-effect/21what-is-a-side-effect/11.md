## Constraint: The Effect Function Cannot Be async

As a rookie, you might often be tempted to try this with useEffect():

```react
// Do NOT do this
useEffect(async function () {
  const res = await fetch("https://api.programiz.pro/api/Demo/v1/journal-entries");
  const data = await res.json();
  setEntries(data);
}, []);
```

React will not throw an error, but this silently breaks the code because an async function always returns a Promise.

But React expects the effect function to return either nothing or a cleanup function, not a Promise.

So the fetch will still run, but React loses control over the effect lifecycle. Next, we'll see how to correct this issue.
