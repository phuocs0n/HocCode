## Thinking About a Solution

Obviously, we need a way to prevent the infinite loop caused by fetch(). But how might we do this?

The fix is not about what you fetch — it's about where you put it.

Right now, fetch() sits directly inside the component body, so React runs it on every render. Instead, it needs to live in a place where you can tell React exactly when to run it.

That raises a question: why does putting fetch() inside the component body cause problems at all?

The answer lies in understanding what side effects are when it comes to React.
