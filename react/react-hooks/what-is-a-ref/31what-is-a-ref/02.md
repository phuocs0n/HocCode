## Attaching a Ref to an Element

You attach a ref to a JSX element using the ref attribute. From that point on, myRef.current gives you direct access to the DOM node.

The pattern is always the same: create the ref → attach it → use it.

```react
import { useRef } from "react";

function SearchBar() {

  // Step 1: create the ref
  const inputRef = useRef(null);

  return (

    {/* Step 2: Attach using ref attribute */}
    <input
      ref={inputRef}
      type="text"
      placeholder="Search..."
    />
  );
}
```

After this component renders, inputRef.current points to the actual <input> DOM element. We can now call browser methods on it:

```react
inputRef.current.focus();
inputRef.current.value = "";
inputRef.current.scrollIntoView();
```
