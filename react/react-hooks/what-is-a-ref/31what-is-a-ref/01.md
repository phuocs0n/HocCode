## What Is a Ref?

A ref is an object with a single property: current. It's React's way of giving you a stable handle to a DOM element.

In order to use a ref, you first need to import it:

```react
import { useRef } from "react";
```

Creating a ref

You create a ref by calling useRef():

```react
const myRef = useRef(null); // { current: null }

// After render: { current: <the actual DOM node> }
```

The null is the starting value of current — it's null because no DOM element has been rendered yet.

Once the component renders and React attaches the ref to an element, current automatically updates to point to that element.
