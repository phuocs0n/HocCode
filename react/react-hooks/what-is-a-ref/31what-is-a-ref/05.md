## Choosing Between State and Ref

When to use state?

If a change should update the screen. For example:

- Displaying a live character count below a text input
- Toggling a dropdown open or closed
- Showing or hiding an error message after form validation
- Updating a list of items when the user adds or removes one

When to use ref?

If you just need to remember a value or access a DOM element without affecting the render. For example:

- Focusing an input field on page load
- Storing a timer ID so you can clear it later
- Keeping track of a previous scroll position
- Holding a reference to a third-party library instance (like a chart or map)
