## The Problem: You Need to Talk to the DOM Directly

The journal app fetches and displays entries. But there are some things the browser needs us to handle manually. For that, we need direct access to a DOM element.

As such, two features are coming in this chapter:

1. The search input should receive focus automatically when the page loads. There is no React prop for "focus this input on mount," so we have to call the browser's .focus() method directly.
2. An entry detail drawer should close when the user clicks outside it. That requires checking whether a click landed inside or outside the drawer element.

Both require a reference to a real DOM node — not the React description of the element, but the actual browser element underneath it.

That's what a ref gives us. Let's see what one actually is.
