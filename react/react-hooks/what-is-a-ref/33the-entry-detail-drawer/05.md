## How the Changes Work

Here's the basic working of our modified App.jsx code:

1. selectedEntry starts as null, so Drawer renders nothing on load.
2. When a card is clicked, handleSelectEntry() sets selectedEntry to that entry.
3. Closing the drawer calls setSelectedEntry(null), which resets it.
