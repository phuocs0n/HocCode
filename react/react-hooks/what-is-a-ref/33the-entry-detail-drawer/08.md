## Coding the Click Detection

The key check for detecting the click is:

```react
ref.current.contains(event.target)
```

It asks: "does the drawer contain the element that was clicked?"

If it doesn't contain the element, the click was outside. In that case, we'll call the onClose() function.

Here's what this looks like in Drawer:
