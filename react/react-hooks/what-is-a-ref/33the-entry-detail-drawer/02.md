## Update App.jsx

Now, App needs to track which entry is selected and pass it to Drawer. Here's what we'll change:

1. Add a 'selectedEntry' state.

```react
const [selectedEntry, setSelectedEntry] = useState(null);
```

2. Add a 'handleSelectEntry()' function to set the newly-created state.

We'll add this right below the return statement for App():

```react
function handleSelectEntry(entry) {
  setSelectedEntry(entry);
}
```

3. Pass 'onSelect' down to each 'EntryCard'.

```react
<EntryCard
  key={entry.id}
  id={entry.id}
  title={entry.title}
  date={entry.date}
  content={entry.content}
  author={entry.author}

  {/* Pass onSelect to each entry card */}
  onSelect={handleSelectEntry}
/>
```
