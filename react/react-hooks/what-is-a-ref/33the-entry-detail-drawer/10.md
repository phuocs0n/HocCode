## The Click That Wouldn't Stop Firing

I once built a modal that closed on outside-click. It seemed to work — until I opened it a few times.

With each open/close cycle, the drawer became harder and harder to close.

Eventually, clicking anywhere — even inside the drawer — closed it instantly.

I opened the DevTools event listener panel: there were 14 mousedown listeners attached to the document 😮

Each time the drawer opened, useEffect() added a new listener. Each close removed none.

After four open/close cycles, four listeners were running simultaneously. Each one fired on every click, and one of them always decided the click was "outside".
