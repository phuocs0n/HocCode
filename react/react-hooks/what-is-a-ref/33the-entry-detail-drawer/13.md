## Summary: Misconceptions and Best Practices

The piling-listener bug is easy to miss. Here's the takeaway:

The Misconception

"Event listeners added inside useEffect() only need cleanup if they do something drastic, like timers or subscriptions."

The Truth

Any time we add an event listener to document (or window, or any element outside the component), we must clean it up.

React does not track external listeners. Only we can remove what we added.

The Golden Rule

Every addEventListener() inside useEffect() needs a matching removeEventListener() in the cleanup function.
