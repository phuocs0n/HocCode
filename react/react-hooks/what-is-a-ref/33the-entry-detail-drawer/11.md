## The Cleanup Function

useEffect() lets us return a function. That returned function is called the cleanup function.

React calls it in two situations:

1. When the component unmounts from the DOM.
2. Just before the effect re-runs.

Here's the syntax:

```react
useEffect(function () {

  // Setup — runs after render

  return function () {
    // Cleanup (runs before next effect or on unmount)
  };
}, [dependency_array]);
```
