## Why the Input Didn't Focus

Well, the problem was that I was reaching outside React to find the element.

React had no guarantee the element had the class I expected, or even that it existed when my code ran.

Solution: Ref Saves the Day!

Fortunately, I discovered useRef() not long after.

Instead of hunting for the element by its CSS class, I attached the ref directly to the element in JSX:

```react
const searchRef = useRef(null);

// ...

<input ref={searchRef} className="search-input" ... />
```

Here, React sets searchRef.current to the DOM node automatically, the moment the element is rendered. No query. No guessing. No class names.

Just a direct, stable reference that is always in sync with what is on screen.
