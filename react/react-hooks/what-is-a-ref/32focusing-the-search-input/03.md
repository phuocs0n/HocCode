## The Input That Wouldn't Focus

The first time I needed to autofocus a search input, I did it the obvious way:

```react
useEffect(function () {
  document.querySelector(".search-input").focus();
}, []);
```

It worked...sometimes 😢

Half the time the element was there; half the time the query came back null and threw a TypeError.

I added a setTimeout to delay the focus call. That fixed the crash but felt wrong. Then the autofocus broke again after a refactor changed the class name.
