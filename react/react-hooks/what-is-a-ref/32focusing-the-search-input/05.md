## Summary: Misconceptions and Best Practices

Here's what that experience taught me:

The Misconception

document.querySelector() is fine for accessing elements in a React app.

The Truth

document.querySelector() can fail if the element is not yet mounted, and it breaks when class names change.

Refs give React-managed, always-accurate access to the DOM node.

The Golden Rule

Never use document.querySelector() to access elements that React controls. Attach a ref in JSX and read ref.current instead.
