# How This Course Is Structured

#### Course: React Hooks: Level Up Your First Web App

## How This Course Is Structured

Now, let's talk about the structure of this course. Here are its most salient features:

1. One hook per chapter

Each chapter introduces one new hook through a problem it solves and applies it to the app. No hook is introduced before you can feel why you need it.

2. One concept per lesson

Each lesson has one job. You'll not be asked to understand useEffect() and its dependency array at the same time — those are two separate lessons.

3. The same app, all the way through

Every lesson adds to the Daily Journal App you already know. And every change you make is visible on the screen. There's no switching projects or wholesale discarding of code.

4. Practice is not optional

Each major lesson has a practice problem. They're very specific, achievable, and slightly different from the lesson example.

You have to think in order to solve them, not just copy code from somewhere else. Do not skip them!
