## Update App.jsx

Now, let's make all the necessary updates to App:

1. Wrap three handler functions in useCallback()
2. Replace the inline arrow in the Drawer JSX with handleCloseDrawer().
3. Everything else stays the same.

Thus, handleRefresh(), handleSelectEntry(), and handleCloseDrawer() are now stable references.

The Drawer's useEffect() will only re-run when onClose() actually changes, not on every keystroke.
