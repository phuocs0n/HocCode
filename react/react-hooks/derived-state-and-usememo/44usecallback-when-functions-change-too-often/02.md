## Introducing useCallback()

useCallback() wraps a function and returns a stable reference that only changes when its dependencies change:

```react
import { useState, useEffect, useMemo, useCallback } from "react";

const handleCloseDrawer = useCallback(function () {
  setSelectedEntry(null);
}, []);
```

Notice the const assignment: useCallback() is a hook that returns a value, so we assign it to a variable rather than using a function declaration.

The function passed inside still uses the function keyword; only the outer form changes.

With an empty dependency array, handleCloseDrawer() is created once and stays the same reference across all renders. The Drawer's useEffect() no longer sees a changed onClose() — it stops re-running.

Now, let's pass it in place of the inline arrow:

```react
<Drawer entry={selectedEntry} onClose={handleCloseDrawer} />
```

Thus, handleCloseDrawer() solves the Drawer problem. But it isn't the only function in App that could cause the same issue.
