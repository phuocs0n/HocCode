## Apply to handleRefresh() and handleSelectEntry()

useCallback() is worth applying to any function we pass as a prop to a component that uses it inside a useEffect().

Therefore, we'll wrap handleRefresh() and handleSelectEntry() for the same reason:

```react
const handleRefresh = useCallback(function () {
  setRefreshKey(function (k) { return k + 1; });
}, []);

const handleSelectEntry = useCallback(function (entry) {
  setSelectedEntry(entry);
}, []);
```

Both have empty dependency arrays because they only call stable setter functions, which React guarantees never change.
