## The Problem: A New Function on Every Render

Every time App renders, every function declared inside it is recreated:

```react
function handleSelectEntry(entry) {
  setSelectedEntry(entry);
}
```

On the next render, handleSelectEntry() is a brand new function — it has a different identity in memory, even though the code is identical.

Usually, this is harmless. But it becomes a problem when a function ends up in a useEffect() dependency array.

For instance, the useEffect() in Drawer.jsx has onClose() in the dependency array:
