## Revisiting the Changes

Here are the changes we've made in this lesson:

- handleCloseDrawer() replaces the inline arrow passed to Drawer's onClose prop, giving it a stable reference across renders.
- handleRefresh() and handleSelectEntry() are wrapped for the same reason: they could flow into a useEffect() dependency array.
- handleQueryChange(), handleNext(), and handlePrev() are left as plain functions — no useEffect() depends on them.
- useCallback() with an empty dependency array creates the function once and reuses it for the lifetime of the component.
