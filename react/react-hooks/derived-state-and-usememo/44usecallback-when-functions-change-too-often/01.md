## When a Function is a useEffect() Dependency

We just revisited the useEffect() inside Drawer and saw that it has onClose() in the dependency array.

In App, we pass this onClose() as an inline arrow:

```react
<Drawer entry={selectedEntry} onClose={() => setSelectedEntry(null)} />
```

That inline arrow is a new function on every render of App. Every time App re-renders, the Drawer's useEffect()

1. sees a changed onClose(),
2. removes the old listener,
3. and adds a new one.

The effect runs on every keystroke.

We need a way to keep onClose() stable across renders. That's where useCallback() comes in.
