## The Problem: Storing a Copy That Gets Out of Sync

The next feature is filtering the entries through search. When the user types in the header, only matching entries should appear.

A natural first instinct is to add a second state variable for the filtered results:

```react
const [entries, setEntries] = useState([]);

// Add a new state
const [filteredEntries, setFilteredEntries] = useState([]);
```

But you have to keep them in sync:

- Every time entries changes — after a refresh, or after a fetch — you must also update filteredEntries.
- Every time the query changes, you must update filteredEntries again.

Miss one place and the two variables diverge: old data shows up where new data should be.

This is the derived state trap: you stored a value that could have been computed. Let's learn about derived states next.
