## useMemo() vs useEffect()

Before proceeding, let's compare and contrast useMemo() and useEffect() and see what distinguishes them.

After all, these two hooks look similar (both take a function and a dependency array). But they serve completely different purposes:

| useMemo() | useEffect() |
| --- | --- |
| Computes and caches a value. | Runs code for its side effects. |
| Returns the computed value. | Returns nothing (optionally returns a cleanup function). |
| Used for filtering, counting, and transforming data. | Used for fetching, subscriptions, and DOM manipulation. |

Important Notes:

- Never use useEffect() to compute a derived value.
- Never use useMemo() instead of useEffect() for a fetch or event listener.
