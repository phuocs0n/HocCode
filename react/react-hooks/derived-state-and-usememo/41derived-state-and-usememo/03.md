## Introducing useMemo()

React gives you a hook to help escape the derived state trap, and that hook is useMemo().

It computes a derived value and caches the result — so React doesn't recompute it on every single render.

Here's its syntax:

```react
const cachedValue = useMemo(function () {
  // Return the value to cache
}, [value1, value2, ...]);
```

Notice that useMemo() has two arguments:

- A function that returns the computed value.
- A dependency array — same concept as useEffect().

React calls the function when any dependency changes, then caches the result.

Naturally, you'll store the cached result in a variable. This syntax uses cachedValue as the variable name, but you can use any suitable name of your choice.
