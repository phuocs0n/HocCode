## Revisiting the Changes

Here's what changed from the previous lesson:

- query state moved from Header to App, which now owns the value it needs for filtering.
- Header became a controlled component: it receives query and onQueryChange as props instead of managing local state.
- App now computes filteredEntries with useMemo() and renders that instead of the raw entries array.
- The entry count badge ({entries.length}) still uses the full entries array, so it always shows the total count regardless of the search.
