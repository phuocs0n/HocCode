## Lifting 'query' out of Header

We're lifting query out of Header so that App can use it to filter entries.

Header will stop managing its own state and instead receive the current value and a setter as props.

Thus, we'll make three changes from the previous version of Header.jsx:

1. The useState import will be removed.
2. query and onQueryChange will come from props instead of local state.
3. onChange will call onQueryChange(e.target.value) instead of the local setter.

We'll also retain the Clear button that we added in a practice challenge from the previous chapter. I recommend you complete that challenge if you haven't already.

Finally, the ref and the autofocus effect will stay exactly as they were.

So let's implement these changes next.
