## Update App.jsx

App now owns query and is responsible for filtering. So let's make the following changes:

1. Import 'useMemo'.

```react
import { useState, useEffect, useMemo } from "react";
```

2. Add the 'query' state declaration.

```react
const [query, setQuery] = useState("");
```

3. Compute 'filteredEntries' directly in the component with 'useMemo()'.

```react
const filteredEntries = useMemo(function () {
  if (!query.trim()) return entries;
  const lower = query.toLowerCase();

  return entries.filter(function (entry) {
    return (
      entry.title.toLowerCase().includes(lower) ||
      entry.content.toLowerCase().includes(lower)
    );
  });
}, [entries, query]);
```

4. Pass 'query' and 'onQueryChange' as props to the Header component.

```react
<Header query={query} onQueryChange={setQuery} />
```

How It Works

- When query is empty, filteredEntries is the full entries array: no allocation, no loop.
- When the user types, React recomputes once and caches the result until entries or query changes again.
