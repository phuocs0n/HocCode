## Resetting the Page on Search

When the user types a new query, currentPage should reset to 1. Otherwise, whatever page the user was on would carry over into the new search.

The fix is to wrap setQuery() in a handler that also resets currentPage. Here's the modification you need to make in App.jsx:

```react
function handleQueryChange(newQuery) {
  setQuery(newQuery);
  setCurrentPage(1);
}
```

We pass handleQueryChange() to Header in place of the raw setQuery():

```react
<Header query={query} onQueryChange={handleQueryChange} />
```
