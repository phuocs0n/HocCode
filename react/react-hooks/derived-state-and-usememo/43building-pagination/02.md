## Computing the Page Slice

With both the constant and the state variable in place, we can compute the page slice:

```react
const pagedEntries = useMemo(function () {
  const start = (currentPage - 1) * ENTRIES_PER_PAGE;
  return filteredEntries.slice(start, start + ENTRIES_PER_PAGE);
}, [filteredEntries, currentPage]);
```

How It Works

Here, pagedEntries depends on filteredEntries and currentPage:

- When either changes, React recomputes the slice.
- When both are unchanged, React returns the cached result.

There is one more thing to handle: when the user types a new query, the page should reset.
