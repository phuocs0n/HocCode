## Page State and the Paginated Slice

We need two things for this task:

1. A constant for the page size

This constant goes outside the component, since it never changes:

```react
const ENTRIES_PER_PAGE = 5;
```

2. A state variable to track the current page

Let's call this state variable currentPage, and it goes inside the App component:

```react
const [currentPage, setCurrentPage] = useState(1);
```
