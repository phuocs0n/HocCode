## Pagination Controls

We need two handler functions for the Previous and Next buttons.

Each one clamps the page number within valid bounds:

- handleNext() won't go past the last page
- handlePrev() won't go below page 1

```react
function handleNext() {
  setCurrentPage(function (p) {
    return Math.min(p + 1, Math.ceil(filteredEntries.length / ENTRIES_PER_PAGE));
  });
}

function handlePrev() {
  setCurrentPage(function (p) {
    return Math.max(p - 1, 1);
  });
}
```
