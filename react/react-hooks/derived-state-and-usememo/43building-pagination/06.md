## Adding the Previous and Next Buttons

We'll add the buttons below the entry list in App.jsx. These buttons/controls only appear when there is more than one page of results.

```react
{!isLoading && !error && filteredEntries.length > ENTRIES_PER_PAGE && (
  <div className="pagination">

    <button
      className="btn btn-secondary"
      onClick={handlePrev}
      disabled={currentPage === 1}
    >
      Previous
    </button>

    <button
      className="btn btn-secondary"
      onClick={handleNext}
      disabled={currentPage === Math.ceil(filteredEntries.length / ENTRIES_PER_PAGE)}
    >
      Next
    </button>

  </div>
)}
```
