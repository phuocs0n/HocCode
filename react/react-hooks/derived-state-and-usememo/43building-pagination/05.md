## Rendering the Page Slice

In the previous lesson, the entry list rendered filteredEntries. Now that we have pagedEntries, we swap it in:

```react
{isLoading ? (

  ... ... ...

) : error ? (

  ... ... ...

) : pagedEntries.length === 0 ? (
  <p className="empty-state">No entries found.</p>
) : (
  pagedEntries.map((entry) => (
    <EntryCard
      key={entry.id}
      id={entry.id}
      title={entry.title}
      date={entry.date}
      content={entry.content}
      author={entry.author}
      onSelect={handleSelectEntry}
    />
  ))
)}
```

Two things change here:

- The empty check uses pagedEntries.length instead of filteredEntries.length.
- The .map() iterates over pagedEntries instead of filteredEntries.

Everything else in the ternary chain (the loading and error branches) stays the same.
