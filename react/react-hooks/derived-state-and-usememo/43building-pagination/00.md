A real journal could have hundreds. Loading and rendering the full list is not only wasteful, but also overwhelming for the user.

Pagination solves this by showing a fixed number of entries per page. The user navigates with Previous and Next buttons.

The page slice is derived state: it is always computable from filteredEntries and currentPage. So they both go into useMemo().
