## Final Fixes and Edge Cases

The final polish phase addressed four issues that only appeared after all pages were built and wired together:

- Navigation linking - Some in-app links used <a href> instead of React Router's <Link to>. Hard reloads replaced seamless client-side navigation. Fix: replace all <a href> with <Link to> in app routes.

- Chart gaps - The History page chart showed blank gaps when test results were spread hours apart. Fix: use Recharts' connectNulls={true} prop on the <Line> component to draw continuous lines across missing time periods.

- Sidebar flicker - The sidebar flashed between expanded and collapsed state on initial render. Fix: use CSS inline styles + willChange: 'width' (covered earlier in this chapter, Lesson 1) and read the persisted collapse preference from localStorage synchronously before first render.

- Run test button - The "Run Test Now" button stayed disabled after a test completed. Fix: ensure setIsRunning(false) was called in both the success and timeout paths of the worker message handler.

Each of these was caught by the production verification step - testing the live Netlify URL after Chunk 7 deployed, not just the local dev server.
