## Framer Motion for Route Transitions

Without animation, navigating between SpeedBlip's pages is an instant swap - the Dashboard disappears and the History page appears in the same frame. With Framer Motion, each page fades in from a slight vertical offset, creating a smooth visual handoff.

The setup: wrap the router's <Outlet /> with Framer Motion's <AnimatePresence> and add <motion.div> to each page:

```react
// In AppLayout
import { AnimatePresence } from 'framer-motion';
import { useLocation } from 'react-router-dom';
import { Outlet } from 'react-router-dom';

const location = useLocation();

// Wrap the Outlet with AnimatePresence in your AppLayout JSX:
<AnimatePresence mode="wait">
  <Outlet key={location.pathname} />
</AnimatePresence>

// In each page component
import { motion } from 'framer-motion';

export const Dashboard = () => (
  <motion.div
    initial={{ opacity: 0, y: 12 }}
    animate={{ opacity: 1, y: 0 }}
    exit={{ opacity: 0, y: -8 }}
    transition={{ duration: 0.2 }}
  >
    {/* page content */}
  </motion.div>
);
```

The key={location.pathname} on <Outlet /> tells AnimatePresence that each route change is a new component mount. Without it, AnimatePresence cannot detect the change and the transitions do not trigger.
