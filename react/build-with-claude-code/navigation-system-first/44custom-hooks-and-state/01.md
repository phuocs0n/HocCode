## localStorage for Persistence

SpeedBlip stores all user data in localStorage with no backend. This is a deliberate constraint that makes the app:

- Zero-cost to run - No server, no database, no monthly infrastructure bill
- Fully private - Data never leaves the user's browser
- Instantly available - No auth, no loading state on first visit

The data stored in SpeedBlip's localStorage:

```react
speedblip-history    // SpeedTestResult[] — full test history speedblip-settings   // UserSettings — thresholds, interval, notification toggle
```

The useSpeedTest hook persists the results array every time a new result arrives. The useSettings hook reads preferences on mount and writes on every change. Both hooks initialize from localStorage on first render, so the data survives page refreshes and browser restarts.

One trade-off to be aware of: localStorage is scoped to a single origin on a single device. If the user clears their browser data, their history is gone. SpeedBlip addresses this with a CSV export feature on the History page - users can download their data at any time.
