## Typography and UI Style

Typography and UI Style

SpeedBlip uses Inter from Google Fonts for all text. Inter is the right choice for a data dashboard because it is designed for screen legibility, handles tabular numbers cleanly, and looks sharp at both small label sizes and large display headings.

The Glassmorphism Style

The UI style is glassmorphism - a design pattern that makes surfaces look like frosted glass. Elements appear semi-transparent with a soft blur behind them, giving depth without heavy shadows. It became a popular dashboard aesthetic because it feels modern and light without sacrificing readability.

In CSS, glassmorphism is achieved with four properties working together:

1. Background opacity - the surface is translucent, not solid
2. Backdrop blur - everything behind the surface is blurred
3. Subtle border - a faint white edge defines the glass boundary
4. Soft shadow - lifts the card off the background without harshness
