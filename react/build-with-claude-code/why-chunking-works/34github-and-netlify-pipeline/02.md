# The Pre-Build Checklist

#### Course: Rapid Build With Claude Code

## The Pre-Build Checklist

Before Chunk 1 of the SpeedBlip Claude Code build ran, every item on this list was confirmed:

- GitHub repository created and initial Vite scaffold committed
- Netlify site created and connected to the GitHub repository
- Build command (yarn build) and publish directory (dist) configured in Netlify
- Claude Code installed and authenticated
- Repository cloned locally with git clone
- yarn install run to install initial dependencies
- tailwind.config.ts configured with full brand token extension
- tsconfig.json set to TypeScript strict mode
- Path aliases (@/) configured in both vite.config.ts and tsconfig.json
- ESLint and Prettier installed and configured
- Folder structure (src/components/ui/, src/hooks/, etc.) created manually
- First test deploy: git push origin main confirmed a successful Netlify deploy

Only after this checklist was complete did Chunk 1 run.
