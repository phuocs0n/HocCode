## The Final File Structure

Here's the full file structure of the app at the end of the course.

```text
Daily-Journal-App/
  |-- index.html
  |-- package.json
  |
  |-- src/ 
    |-- index.jsx
    |-- App.jsx
    |-- styles.css
    |
    |-- context/
    |  |-- ThemeContext.jsx
    |  |-- JournalContext.jsx
    |
    |-- components/
    |  |-- Header.jsx
    |  |-- EntryCard.jsx
    |  |-- SkeletonPage.jsx
    |
    |-- pages/
    |  |-- HomePage.jsx
    |  |-- EntryDetailPage.jsx
    |  |-- NotFoundPage.jsx
    |
    |-- hooks/
      |-- useFetch.js
      |-- useSearch.js
      |-- usePagination.js
```

That is a real-world React project structure. Context, pages, components, hooks — each in their own folder, each with a clear responsibility.

Every file in that tree exists because of one of the four patterns we learned:

1. React Router
2. Context
3. useReducer()
4. lazy() + Suspense

Let's step back and see how they fit together.
