## How a Reducer Processes Actions

The reducer reads the action type and decides what to do. Every possible state change is a case in one switch statement.

```react
function journalReducer(state, action) {
  switch (action.type) {
    case 'SET_ENTRIES':
      return action.payload
    case 'BOOKMARK_ENTRY':
      return state.map(function (entry) {
        return entry.id === action.payload.id
          ? { ...entry, bookmarked: !entry.bookmarked }
          : entry
      })
    default:
      return state
  }
}
```

Two Things to Notice

- First, the reducer never modifies the state directly; it returns a new value.
- Second, the default case returns state unchanged, so unknown actions are safely ignored.
