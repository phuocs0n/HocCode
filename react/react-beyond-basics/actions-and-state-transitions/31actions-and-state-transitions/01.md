## Why useState() Doesn't Scale

With two actions that each modify entries differently, the natural useState() approach is to write a separate handler for each case.

```react
const [entries, setEntries] = useState([]);

// Modifies entries by replacing
// its value with 'data'
function handleSetEntries(data) {
  setEntries(data);
}

// Also modifies entries
// by adding bookmark
function handleBookmark(id) {
  setEntries(prev =>
    prev.map(entry =>
      entry.id === id ? { ...entry, bookmarked: !entry.bookmarked } : entry
    )
  );
}
```

This compiles and works. But notice something: the logic for how state changes is now scattered across separate functions.

That might seem fine with two handlers, but it doesn't stay fine for long.
