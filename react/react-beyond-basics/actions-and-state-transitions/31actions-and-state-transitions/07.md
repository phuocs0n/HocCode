## The useReducer() Hook

useReducer() is the React hook that connects a reducer to a component.

```react
const [state, dispatch] = useReducer(reducer, initialState);
```

Here, state is the current state value, exactly like what useState() returns.

And dispatch() is a function you call to send an action to the reducer:

```react
dispatch({ type: "SET_ENTRIES", payload: data });
```

Here's what happens when you call dispatch():

1. React passes the current state and your action object to the reducer.
2. The reducer returns a new state.
3. React re-renders the component.
