## Writing the Journal Reducer

Let's define the reducer that handles the entries state.

Initially, there was only one action needed: SET_ENTRIES. However, one more action is added: BOOKMARK_ENTRY.

```react
function journalReducer(state, action) {
  switch (action.type) {
    case 'SET_ENTRIES':
      return action.payload;
    case 'BOOKMARK_ENTRY':
      return state.map(function (entry) {
        return entry.id === action.payload.id
          ? { ...entry, bookmarked: !entry.bookmarked }
          : entry
      });
    default:
      return state;
  }
}
```
