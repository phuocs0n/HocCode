## A Minimal Example

This counter component shows the full useReducer() cycle in the simplest possible form.

```react
import { useReducer } from "react";

function counterReducer(state, action) {
  switch (action.type) {
    case "INCREMENT":
      return state + 1;
    case "RESET":
      return 0;
    default:
      return state;
  }
}

function Counter() {
  const [count, dispatch] = useReducer(counterReducer, 0);
  return (
    <div>
      <p>{count}</p>
      <button onClick={() => dispatch({ type: "INCREMENT" })}>+1</button>
      <button onClick={() => dispatch({ type: "RESET" })}>Reset</button>
    </div>
  );
}
```

Here's what happens when the user clicks the +1 button:

1. dispatch({ type: "INCREMENT" }) fires
2. counterReducer() runs with the current state
3. It returns state + 1
4. React re-renders with the new count

The component itself never touches the state update logic. It just dispatches an action and lets the reducer handle the rest.
