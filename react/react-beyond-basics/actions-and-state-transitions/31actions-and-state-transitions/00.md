But as the app grows, entries won't just be loaded — they'll be bookmarked, deleted, and shared across pages.

Each of those is a different operation on the same state, and managing them all with useState() gets messy fast.

We can solve this with useReducer(), a React hook that gives every state change a name and keeps all the logic in one place. This hook is thus the main focus of this chapter.

But for now, let's see what handling multiple operations looks like with useState().
