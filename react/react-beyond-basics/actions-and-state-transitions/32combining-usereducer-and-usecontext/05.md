## Add JournalProvider to the Entry Point

JournalProvider goes in index.jsx alongside ThemeProvider and BrowserRouter. All global wrappers live in one place.

```react
import { createRoot } from "react-dom/client"
import { BrowserRouter } from "react-router-dom"
import { ThemeProvider } from "./context/ThemeContext"
import { JournalProvider } from "./context/JournalContext"
import App from "./App.jsx"

createRoot(document.getElementById("root")).render(
  <BrowserRouter>
    <ThemeProvider>
      <JournalProvider>
        <App />
      </JournalProvider>
    </ThemeProvider>
  </BrowserRouter>
  )
```

JournalProvider wraps App so the reducer state persists across route changes. Navigating from / to /entries/7 no longer destroys the entries.
