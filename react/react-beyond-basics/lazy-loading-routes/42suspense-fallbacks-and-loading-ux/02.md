## Where to Put the Suspense Boundary

In the last lesson, we wrapped the entire <Routes> block in a single <Suspense>.

```react
<Suspense fallback={<p>Loading...</p>}>
  <Routes>
    <Route path="/" element={<HomePage />} />
    <Route path="/entries/:id" element={<EntryDetailPage />} />
    <Route path="*" element={<NotFoundPage />} />
  </Routes>
</Suspense>
```

This works, but it means every route uses the same fallback. Whether HomePage or EntryDetailPage is loading, the user always sees the same Loading... text.

The experience is generic, and we can obviously do better! And that's by using boundaries.
