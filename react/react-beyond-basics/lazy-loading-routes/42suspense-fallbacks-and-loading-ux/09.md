## Add the Skeleton Styles

We'll add a shimmer animation that pulses the opacity gently. This is a common pattern that communicates activity without being visually aggressive.

Add this to the existing styles in styles.css:

```react
.skeleton-page {
  padding: 20px;
  max-width: 600px;
  margin: 0 auto;
}
.skeleton-title {
  background: #e0e0e0;
  border-radius: 8px;
  height: 32px;
  width: 60%;
  margin-bottom: 16px;
  animation: shimmer 1.2s ease-in-out infinite;
}
.skeleton-line {
  background: #e0e0e0;
  border-radius: 4px;
  height: 16px;
  margin-bottom: 10px;
  animation: shimmer 1.2s ease-in-out infinite;
}
.skeleton-line.short {
  width: 40%;
}
@keyframes shimmer {
  0%   { opacity: 1; }
  50%  { opacity: 0.5; }
  100% { opacity: 1; }
}
```

The shimmer keyframe cycles through full and half opacity on a loop. Now let's wire SkeletonPage into our routes.
