## Create the SkeletonPage Component

We need a simple component that renders placeholder blocks matching our page layout.

```react
function SkeletonPage() {
  return (
    <div className="skeleton-page">
      <div className="skeleton-title" />
      <div className="skeleton-line" />
      <div className="skeleton-line short" />
      <div className="skeleton-line" />
      <div className="skeleton-line short" />
    </div>
  );
}

export default SkeletonPage;
```

Five placeholder blocks: one title bar and four content lines. No text, no data. Just shape.

Next, we need CSS to style these blocks and give them a subtle loading animation.
