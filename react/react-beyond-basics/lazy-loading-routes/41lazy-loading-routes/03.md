## How lazy() Works

As you know, lazy() loads a component only when it's needed. It takes one argument: a callback that returns a dynamic import().

```react
const EntryDetailPage = lazy(() => import("./pages/EntryDetailPage"));
```

There are three parts to notice here:

1. The lazy() Wrapper

lazy() wraps the import() and tells React to treat this component as lazily loaded.

2. The Dynamic Import

() => import() is the dynamic import syntax. Unlike a static import at the top of a file, a dynamic import is a function call.

It returns a Promise that resolves to the module. The bundler sees this and automatically splits the file into its own chunk.

3. The Result

The result is assigned to EntryDetailPage exactly like any other component. We use it in JSX the same way.

```react
<Route path="/entries/:id" element={<EntryDetailPage />} />
```

Nothing changes in the route definition. React handles the rest. Let's see what this looks like in practice.
