## Wrap Routes in Suspense

While the chunk is downloading, React needs to know what to render in the meantime. Without guidance, React throws an error:

```text
A React component suspended while rendering,
but no fallback UI was specified.
```

The solution is Suspense — a component provided by React.

Basically, we wrap any lazy component (or the section of the tree that contains lazy components) in a Suspense boundary.

We then give it a fallback prop, which is what renders while the chunk loads.

```react
<Suspense fallback={<p>Loading...</p>}>
  <Routes>...</Routes>
</Suspense>
```

Next, we'll see how this works.
