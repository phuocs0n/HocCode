## Wrapping a Named Export for lazy()

Let's suppose our EntryDetailPage isn't a default export. This will obviously create problems with lazy().

To solve this, we can reshape the module ourselves to match the { default: Component } format that lazy() expects:

```react
const EntryDetailPage = lazy(() =>
  import("./pages/EntryDetailPage").then(module => ({ default: module.EntryDetailPage }))
)
```

Here's the generic syntax:

```react
const Component = lazy(() =>
  import("./path").then(module => ({ default: module.ComponentName }))
)
```

For our own files, it's simpler to just use export default. This workaround is mainly useful when lazy-loading from libraries we don't control.
