## What lazy() Actually Solves

The Misconception

A lot of developers assume that because React Router handles navigation, the code for each route loads separately by default.

The Truth

React Router only controls which component renders at a given URL. It has no effect on how files are bundled.

Without lazy(), every page is still bundled together and downloaded on the first load.

lazy() is what creates the split. Router decides what to render, lazy() decides when to download it.

The Golden Rule

Wrap lazy components in Suspense. Always.

React will throw an error without it, and the fallback is the only way users get visual feedback while the chunk loads.
