## Solution: Load on Demand!

So the fix to this big bundle issue is to load components on demand, i.e., only when the user actually navigates to that route.

A user who lands on / should not have to load the code for /entries/7 until they go there.

React gives us the lazy() function to do exactly that. Instead of loading a component at startup, lazy() defers it until React needs to render it:

- The user lands on / — only HomePage loads.
- They click through to /entries/7 — now EntryDetailPage loads.
- They never hit a bad URL — NotFoundPage never loads.

That's the idea. So let's look at React lazy() in greater detail.
