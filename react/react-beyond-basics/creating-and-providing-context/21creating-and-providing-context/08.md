## How ThemeContext Works

3. useTheme()

```react
export function useTheme() {
  return useContext(ThemeContext);
}
```

useTheme() is a custom hook that wraps useContext(ThemeContext).

Consumers import useTheme() instead of importing both useContext() and ThemeContext. One import instead of two.

4. {children}

{children} is how we render whatever is nested inside <ThemeProvider>.

In React, when you write <ThemeProvider><App /></ThemeProvider>, the <App /> part becomes children. It is automatically passed as a prop.

This is the standard wrapper component pattern: the Provider wraps everything without knowing or caring what is inside it.
