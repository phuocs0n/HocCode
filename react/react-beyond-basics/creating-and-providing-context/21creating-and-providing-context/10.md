## Clearing Misconceptions About Context

The Misconception

"I'll just pass theme as a prop through every component. It's only one value."

The Truth

Props don't scale across routing boundaries, and deep trees become unmanageable fast. Each new consumer requires updating every layer between App and that consumer.

With React Router, you are already writing element={<HomePage theme={theme} />} for every route, and that list only grows.

The Golden Rule

When a piece of data needs to cross multiple component boundaries, especially across routing layers, lift it into Context.

The Provider holds the data once; any consumer reads it directly.
