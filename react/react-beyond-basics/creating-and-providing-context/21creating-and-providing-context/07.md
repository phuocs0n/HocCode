## How ThemeContext Works

1. createContext()

```react
const ThemeContext = createContext(null);
```

createContext(null) creates the context object. The null is just the default value. It only applies if a component tries to read context without a Provider above it.

We'll always have a Provider, so this default rarely matters in practice.

2. ThemeProvider

```react
export function ThemeProvider({ children }) {
  const [theme, setTheme] = useState("light");

  function toggleTheme() {
    setTheme(function (t) { return t === "light" ? "dark" : "light"; });
  }
  return (
    <ThemeContext.Provider value={{ theme, toggleTheme }}>
      {children}
    </ThemeContext.Provider>
  );
}
```

ThemeProvider is a regular React component. It manages theme state and exposes a toggleTheme() function.

Then it renders ThemeContext.Provider with a value prop. That value is what any component deeper in the tree will receive when it reads from context.

If we ever want to share more data (like a font size), we just add it to this object.
