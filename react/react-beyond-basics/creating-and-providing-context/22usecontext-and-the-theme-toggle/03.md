## Applying the Theme with CSS

Toggling the theme changes the theme state in ThemeContext, but no element in the DOM is actually responding to it yet.

The standard approach is to set a data-theme attribute on document.documentElement (the <html> element).

We use the <html> element because CSS variables cascade down from it to every element on the page, including things outside the React tree like browser scrollbars.

Setting it on a specific <div> would limit the theme to only elements inside that <div>.

CSS can then target the attribute globally.

```react
[data-theme="dark"] {
  background: #1a1a1a;
  color: #eee;
}

[data-theme="light"] {
  background: #ffffff;
  color: #111;
}
```
