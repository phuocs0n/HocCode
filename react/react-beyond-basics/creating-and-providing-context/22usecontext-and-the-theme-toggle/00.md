## Consuming Context with useTheme()

In the previous lesson, we created ThemeProvider and wrapped the app with it. Now we need to actually read that context inside a component.

useTheme() is the hook that reads from the nearest Provider above it in the tree.

It returns whatever is currently in the Provider's value prop. In our case, that is { theme, toggleTheme }.

```react
import { useTheme } from "../context/ThemeContext";

const { theme, toggleTheme } = useTheme();
```

That is the full setup for a consumer. One import and one line.

The hook re-runs automatically whenever the Provider's value changes.

So if the user clicks the toggle button and theme flips from "light" to "dark", every component calling useTheme() re-renders with the new value.
