## Where Theme Logic Really Belongs

The Misconception

"I just need the toggle to work in the Header. I'll apply data-theme in each page individually."

The Truth

Per-page application works, but it creates duplication. Every new page needs the same boilerplate.

Setting data-theme on document.documentElement inside ThemeProvider's useEffect() puts the logic in exactly one place, and all pages get the theme for free.

The Golden Rule

Logic that affects the entire page, like a theme attribute on <html>, belongs in the Provider's side effect, not scattered across individual components.
