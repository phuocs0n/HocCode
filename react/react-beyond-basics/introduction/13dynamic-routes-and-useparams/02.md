## Dynamic Route Segments

A dynamic segment is a placeholder in a route path that matches any value.

When we write path="/entries/:id", the :id part is the dynamic segment. It doesn't literally mean the URL must say :id — it means "match anything here and call it id."

All of these URLs match /entries/:id:

- /entries/1 — id is "1"
- /entries/42 — id is "42"
- /entries/abc — id is "abc"

You define the route the same way as a static route, just with a colon prefix on the dynamic part.

```react
import { Routes, Route } from 'react-router-dom'
import HomePage from './pages/HomePage'
import EntryDetailPage from './pages/EntryDetailPage'

function App() {
  return (
      <Routes>
        <Route path="/" element={<HomePage />} />
        <Route path="/entries/:id" element={<EntryDetailPage />} />
      </Routes>
  )
}

export default App;
```

React Router will now match any URL that looks like /entries/something and render EntryDetailPage. The value of something is captured and made available to the component.
