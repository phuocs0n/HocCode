## A Side-Note on EntryDetailPage

So we just coded EntryDetailPage.jsx. But there's a cost worth noticing: HomePage also fetches the same entries list.

Every time a user opens a detail page, the entire list is fetched a second time — even though HomePage already loaded it.

That's fine for now. In Chapter 3, we'll move the fetch into a shared context so entries are loaded once and both pages read from the same data.
