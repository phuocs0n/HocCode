## Reading Params with useParams()

The captured value from a dynamic segment is called a "param." React Router makes all params available through the useParams() hook.

useParams() returns an object. The keys of that object match the dynamic segment names you defined in your route path.

```react
import { useParams } from 'react-router-dom'

function EntryDetailPage() {
  const { id } = useParams();
  // if the URL is /entries/42 the id becomes "42"
}
```
