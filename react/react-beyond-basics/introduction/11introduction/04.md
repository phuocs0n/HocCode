## What You Will Build

We'll keep working on the Daily Journal App. The same project, the same data, the same components. But we'll add four new layers to it:

1. Multi-page navigation with React Router

We'll split the app into real pages. Each page gets its own URL. The browser's "back" button will work. Links will feel native.

2. A light/dark theme toggle with useContext()

We'll use React's Context API for this feature. One ThemeContext will make the theme available anywhere in the tree without prop drilling.

3. Journal entries managed by useReducer() and JournalContext

We'll replace local useState() calls with a proper reducer. All state changes will go through named actions — ADD_ENTRY, DELETE_ENTRY, SET_ENTRIES.

Any component will be able to read or update journal state without receiving props.

4. Lazy-loaded routes with React.lazy and Suspense

We'll split the bundle so each page only loads its code when visited. We'll add a skeleton fallback so users see something while the code loads.

Each chapter covers one of these patterns. Each lesson covers one concept inside that pattern.
