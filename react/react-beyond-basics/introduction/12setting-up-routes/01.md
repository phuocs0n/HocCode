## How React Router Works

React Router is the standard routing library for React. We'll use version 6 for this course.

The core idea is simple: the URL is the source of truth. Here's how it works:

- When the URL is /, show the home page.
- When the URL is /entries/7, show that entry's detail page.

React Router reads the URL and decides which component to render — no page reload, no server round-trip.

Next, let's explore the various pieces of the router library that make all of this possible.
