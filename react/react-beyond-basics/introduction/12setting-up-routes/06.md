#### Course: React Beyond Basics

## What is react-router-dom?

react-router-dom is the browser-specific package for React Router v6. It contains everything you need to add routing to a React web app:

- BrowserRouter
- Routes
- Route
- Link
- NavLink
- useParams
- useNavigate
- and more
