## Random Access Iterator Using end()

### Problem Description

Write a program to access vector elements using iterators and the end() function.

- Initialize an integer vector called num with the elements 1, 2, 3, and 4.
- Initialize a vector iterator itr that points to the final element of the vector using the num.end() - 1.
- Print that element by dereferencing itr.
- Change the value of itr to num.end() - 2.
- Print the element by dereferencing itr.
- Then, subtract 1 from itr and print the element.
- Finally, decrement itr by 1 and print the element.

#### Example

```text
Expected Output4
3
2
1
```
