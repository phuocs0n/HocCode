## Random Access Iterator Using begin()

### Problem Description

Write a program to access vector elements using iterators and the begin() function.

- Initialize an integer vector called num with the elements 1, 2, 3, and 4.
- Initialize a vector iterator itr that points to the first element of the vector using the begin() function.
- Print the first element by dereferencing itr.
- Change the value of itr to num.begin() + 1.
- Print the element by dereferencing itr.
- Then, add 1 to itr and print the element.
- Finally, increment itr by 1 and print the element.

#### Example

```text
Expected Output1
2
3
4
```
