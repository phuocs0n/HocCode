## Random Access Iterator Using begin()

### Problem Description

Write a program to access list elements using iterators and the begin() function.

- Initialize an integer list called num with the elements 1, 2, 3, and 4.
- Initialize a list iterator itr that points to the first list element using the begin() function.
- Print that element by dereferencing itr.
- Print the next element by incrementing itr by 1 and dereferencing it.
- Continue this process until all the elements are printed.

#### Example

```text
Expected Output1
2
3
4
```
