## Random Access Iterator Using end()

### Problem Description

Write a program to access list elements using iterators and the end() function.

- Initialize an integer list called num with the elements 1, 2, 3, and 4.
- Initialize a list iterator itr that points to the end element using the end() function.
- Print the final element of the list by decrementing itr by 1 and dereferencing it.
- Continue this process until all the elements are printed.

#### Example

```text
Expected Output4
3
2
1
```
