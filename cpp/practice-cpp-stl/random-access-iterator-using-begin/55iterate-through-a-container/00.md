## Iterate Through a Container

### Problem Description

Write a program to iterate through a vector using loops.

- Initialize an integer vector called num with the elements 1, 2, 3, and 4.
- Create a vector iterator itr.
- Using a for loop, iterate from itr = num.begin() to itr = num.end() - 1.
- Inside the loop, print the vector element by dereferencing itr.
- Outside the loop, assign num.end() - 1 to itr.
- Iterate the vector in reverse order.
- Inside the loop, print the vector element by dereferencing itr, then decrement itr by 1.

Note: It is preferable to use the rbegin() and rend() functions to iterate through a container in reverse order.

#### Example

```text
Expected Output1, 2, 3, 4, 
4, 3, 2, 1,
```
