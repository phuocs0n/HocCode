## Modify Elements of a Vector

### Problem Description

Write a program to modify elements of a vector.

- Get integer inputs from the user and store them in the index and value variables.
- Declare an integer vector marks and initialize it with the values 12, 24, and 36.
- Print the vector.
- Change the element at the index position of the vector.
- Print the updated vector in a new line.

Assumption: The user will only enter the numbers 0, 1, and 2 for index.

Hint: Use the at() function to insert value to the vector.

#### Example

```text
Test Inputindex = 0
value = 48
```

```text
Expected Output12, 24, 36, 
48, 24, 36,
```
