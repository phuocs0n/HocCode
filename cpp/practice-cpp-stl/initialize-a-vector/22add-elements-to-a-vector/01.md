## Add Elements to a Vector

### Problem Description

Write a program to add elements to a vector.

- Get three integer inputs from the user and store them in the input1, input2, input3 variables.
- Declare an integer vector called marks.
- Add the input values to the vector.
- Print the vector.

Hint: Use the push_back() function to add input values to the vector.

#### Example

```text
Test Inputinput1 = 33
input2 = 44
input3 = 55
```

```text
Expected Output33
44
55
```
