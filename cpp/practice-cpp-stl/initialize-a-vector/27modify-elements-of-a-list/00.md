## Modify Elements of a List

### Problem Description

Write a program to modify elements of a list.

- Get string input for the song1 variable.
- Declare a string list called songs with the elements Fear of the Dark, Paranoid, Smoke on the Water, and Breaking the Law.
- Replace Smoke on the Water with song1.
- Print the list.

#### Example

```text
Test Inputsong1 = Perfect
```

```text
Expected OutputFear of the Dark
Paranoid
Perfect
Breaking the Law
```
