###### Practice:

## Add Elements to a List

### Problem Description

Write a program to add elements to a list.

- Get three string inputs for the variables input1, input2, input3.
- Declare a string list called musicians.
- Add input1 and input2 to the back of the list.
- Then, add input3 to the front of the list.
- Print the list.

Hint: Use push_back() to add elements to the end and push_front() functions to add them to the start of the list.

#### Example

```text
Test Inputinput1 = Neil
input2 = John
input3 = Keith
```

```text
Expected OutputKeith
Neil
John
```
