## Remove List Elements

### Problem Description

Write a program to remove the front and back elements of a list.

- Get four integer inputs from the users and store them in input1, input2, input3, and input4 variables.
- Declare an integer list called numbers.
- Add each input value to the back of the list.
- Then, print the list.
- Remove the front and back elements from the list.
- Print the updated list in a separate line.

Hint: Use pop_front() and pop_back() to remove the front and back elements from the list.

#### Example

```text
Test Inputinput1 = 1
input2 = 2
input3 = 3
input4 = 4
```

```text
Expected Output1, 2, 3, 4,
2, 3,
```
