## Add Elements to a std::array

### Problem Description

Write a program to add elements to a std::array.

- Get three integer inputs from the user and store them in the variables input1, input2, and input3.
- Declare an integer array called marks of size 3.
- Add the input values to the marks array using the [] operator.
- Then, print the array.

#### Example

```text
Test Inputinput1 = 33
input2 = 44
input3 = 55
```

```text
Expected Output33
44
55
```
