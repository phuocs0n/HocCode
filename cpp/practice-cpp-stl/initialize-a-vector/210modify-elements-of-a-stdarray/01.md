## Modify Elements of a std::array

### Problem Description

Write a program to modify elements of a std::array.

- Get integer inputs for index and value variables.
- Declare an integer array called marks and initialize it with the values 12, 24, and 36.
- Print the array.
- Change the element at the index position of the array.
- Print the updated array in a new line.

Assumption: The user will only enter the numbers 0, 1, and 2 for index.

Hint: Use the at() function to change the element at the specified index.

#### Example

```text
Test Inputindex = 0
value = 48
```

```text
Expected Output12, 24, 36, 
48, 24, 36,
```
