## Sort Age of Players in Ascending Order

### Problem Description

Write a program to sort the age of players in ascending order.

- Get three integer inputs from the user and store them in the input1, input2, and input3 variables.
- Create an integer vector called age.
- Add input1, input2, and input3 to the vector.
- Print the vector.
- Use the sort() algorithm to sort the vector in ascending order.
- Print the sorted vector.

Hint: Use the begin() and end() iterators in sort() algorithm.

#### Example

```text
Test Inputinput1 = 18
input2 = 22
input3 = 21
```

```text
Expected Output18, 22, 21,
18, 21, 22,
```
