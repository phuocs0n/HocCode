## Finding Nemo

### Problem Description

Write a program to find Nemo.

- Get three string inputs from the user and store them in the input1, input2, and input3 variables.
- Create a string vector called fish.
- Add input1, input2, and input3 to the vector.
- Search element Nemo in the vector using the find() algorithm.
- Store returned value of the algorithm in the itr iterator.
- Check if Nemo is present in the vector
- If yes, print Nemo Found!.
- Else, print Couldn't Find Nemo.

Hint: To check if an element is present in the vector, check if the value of itr is not equal to the end() iterator.

#### Example

```text
Test InputDory
Gill
Nemo
```

```text
Expected OutputNemo Found!
```
