## Reverse the Order of Elements

### Problem Description

Write a program to reverse the order of elements in a list.

- Get four string inputs from the user and store them in the input1, input2, input3, and input4 variables.
- Initialize a string list called countries.
- Add input1, input2, input3, and input4 to the back of the list.
- Print the list.
- Reverse the order of the list.
- Then, print the updated list.

Hint: Use the reverse() algorithm to reverse a list.

#### Example

```text
Test Inputinput1 = Nepal
input2 = Canada
input3 = Australia
input4 = India
```

```text
Expected OutputNepal, Canada, Australia, India, 
India, Australia, Canada, Nepal,
```
