## Reverse the Order For a Specific Range of Elements

### Problem Description

Write a program to reverse the order of the 4th, 5th, 6th, and 7th elements of a list.

- Initialize a character list called vowels with the elements 'A', 'E', 'I', 'O', 'U', 'a', 'e', 'i', 'o', 'u'.
- Print the list.
- Initialize a list iterator named initial to point to the first element of vowels list.
- Use the advance() function to point to the 4th element of initial.
- Initialize another iterator final to point to the end of the vowels list using end().
- Then point final to the 8th element.
- Reverse the elements in the range given by initial and final.
- Print the rearranged list elements.

#### Example

```text
Expected OutputA, E, I, O, U, a, e, i, o, u, 
A, E, I, e, a, U, O, i, o, u,
```
