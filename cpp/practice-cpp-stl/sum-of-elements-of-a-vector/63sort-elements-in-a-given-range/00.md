## Sort Elements in a Given Range

### Problem Description

Write a program to sort vector elements in a given range.

- Get two integer inputs from the user and store them in the index1 and index2 variables.
- Initialize an integer vector called score with the elements 66, 32, 89, 100, 97, 54, 21, and 15.
- Print the vector.
- Use the sort() algorithm to sort the vector in the range of index1 and index2 (inclusive).
- Print the vector again.

Hint: The user input is assumed to be 1-based.

#### Example

```text
Test Input2
5
```

```text
Expected Output66, 32, 89, 100, 97, 54, 21, 15, 
66, 32, 89, 97, 100, 54, 21, 15,
```
