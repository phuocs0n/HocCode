## Minimum and Maximum Elements in a Range

### Problem Description

Write a program to find minimum and maximum elements of a vector within a given range.

- Get two integer inputs from the user and store them in the index1 and index2 variables.
- Initialize an integer vector called score with the elements 66, 32, 89, 100, 97, 54, 21, and 15.
- Print the minimum score in the range of index1 and index2.
- Print the minimum score in the range of index1 and index2.

Hints: Use min_element() and max_element() algorithms with,

- First Argument - index1 + begin()
- Second Argument - index2 + 1 + begin().

Assumption: The user will enter only valid indexes.

#### Example

```text
Test Input2
6
```

```text
Expected Output21
100
```
