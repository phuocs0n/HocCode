## Iterate Through a Queue

### Problem Description

Write a program to iterate through a queue and perform pop operation as well.

1. Declare a string queue called fast_food.
2. Add the strings Burger, Pizza, and Hot Dog to the queue.
3. Print and remove the front element as long as the queue is not empty.

Note: Use empty() function to check if a queue is empty.

#### Example

```text
Expected OutputBurger
Pizza
Hot Dog
```
