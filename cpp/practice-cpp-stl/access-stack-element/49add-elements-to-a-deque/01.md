## Add Elements to a Deque

### Problem Description

Write a program to add elements to a deque.

- Get three double inputs from the user and store them in the input1, input2, and input3 variables.
- Declare a double deque called marks.
- Add input1 and input2 to the back of the deque.
- Add input3 to the front of the deque.
- Print the deque.

#### Example

```text
Test Inputinput1 = 33.33
input2 = 44.44
input3 = 55.55
```

```text
Expected Output55.55
33.33
44.44
```
