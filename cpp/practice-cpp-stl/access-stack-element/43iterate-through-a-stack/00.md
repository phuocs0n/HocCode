## Iterate Through a Stack

### Problem Description

Write a program to iterate through a stack. Also, print and pop the top element in each loop iteration.

1. Declare a string stack called fast_food.
2. Add the strings Burger, Pizza, and Hot Dog to the stack.
3. Create a while loop that runs while the stack is not empty by using the empty() function.
4. Inside the loop, print the top element using top() and then remove it using pop().

Burger
