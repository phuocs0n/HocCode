## Remove Elements From a Deque

### Problem Description

Write a program to remove elements from deque.

- Initialize a string deque called languages with the elements C++, Python, Swift, and Java.
- Print the deque.
- Remove the front element from the deque, then print the deque.
- Also, remove the back element from the deque, then print the deque.

Expected OutputC++, Python, Swift, Java, 
Python, Swift, Java, 
Python, Swift,
