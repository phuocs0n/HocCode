## Remove Queue Elements

### Problem Description

Write a program to remove elements of a queue.

1. Declare a string queue called subjects.
2. Add the strings Mathematics, Physics, Chemistry, and Biology to the queue.
3. Print the front element of the queue, then remove it.
4. Print the new front element.

#### Example

```text
Expected OutputMathematics
Physics
```
