## Access Queue Elements

### Problem Description

Write a program to access queue elements.

1. Get three integer inputs from the user and store them in the input1, input2, and input3 variables.
2. Declare an integer queue called numbers.
3. Add input1, input2, and input3 to the queue.
4. Print the front and back elements of the queue.

#### Example

```text
Test Inputinput1 = 1
input2 = 2
input3 = 3
```

```text
Expected Output1
3
```
