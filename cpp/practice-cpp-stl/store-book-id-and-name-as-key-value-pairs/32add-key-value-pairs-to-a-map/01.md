## Add Key-Value Pairs to a Map

### Problem Description

Write a program to get the id and name of books from the user.

- Get two string inputs from the user and store them in the book1 and book2 variables.
- Get two integer inputs from the user and store them in the id1 and id2 variables.
- Declare a map called book of integer key and string value.
- Add an element with key id1 and value book1 using [].
- Add an element with key id2 and value book2 using insert() and make_pair() functions.
- Print the map.

#### Example

```text
Test Inputbook1 = Saya
book2 = Euphoria
id1 = 101
id2 = 102
```

```text
Expected Output101 - Saya
102 - Euphoria
```
