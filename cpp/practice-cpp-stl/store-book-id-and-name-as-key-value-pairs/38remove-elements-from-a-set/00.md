## Remove Elements From a Set

### Problem Description

Write a program to remove elements from a set.

- Get string input and store it in the key variable.
- Initialize a string set called languages with the elements C++, Python, Swift, and Java.
- Print the set.
- Use the erase() function to remove the key from the set.
- Print languages again in a new line.

Assumption: The user will only enter valid keys.
