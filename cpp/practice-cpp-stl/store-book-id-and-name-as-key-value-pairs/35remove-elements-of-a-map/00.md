## Remove Elements of a Map

### Problem Description

Write a program to remove the element of a map.

- Get integer input for the key variable.
- Initialize a map called songs of integer key and string value with the key-value pairs {1, "Smells Like Teen Spirit"}, {2, "Last Kiss"}, and {3, "Keep On Rockin In The Free World"}.
- Remove the element given by the key variable using erase().
- Print the modified map.

#### Example

```text
Test Inputkey = 1
```

```text
Expected Output2 - Last Kiss
3 - Keep On Rockin In The Free World
```
