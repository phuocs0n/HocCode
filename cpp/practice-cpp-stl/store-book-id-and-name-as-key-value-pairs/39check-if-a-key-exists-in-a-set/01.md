## Check if a Key Exists in a Set

### Problem Description

Write a program to check if a key exists in a set.

- Get string input and store it in the key variable.
- Initialize a string set called languages with the elements C++, Python, Swift, and Java.
- Check if key exists in the set using count().
- If it does, print "key exists in the set".
- Else, print "key doesn't exist in the set".
