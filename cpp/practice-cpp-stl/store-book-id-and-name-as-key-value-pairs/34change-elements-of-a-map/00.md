## Change Elements of a Map

### Problem Description

Write a program to change elements of a map.

- Initialize a map called name of string type key and integer type value with the elements {"Jimmy", 1} and {"Chandler", 2}.
- Print the map.
- Change the value of the element with key Jimmy to 100 using [].
- Change the value of the element with key Chandler to 200 using at().
- Print the map again.

#### Example

```text
Expected OutputChandler = 2, Jimmy = 1,
Chandler = 200, Jimmy = 100,
```
