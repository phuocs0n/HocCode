## Sort a Set in Descending Order

### Problem Description

Write a program to create a set that sorts its keys in descending order.

- Get character inputs from the user and store them in the c1, c2, and c3 variables.
- Create a char set called characters that is sorted in descending order.
- Add c1, c2, and c3 to the set.
- Print the set.

Hint: Use greater<int> as the second argument to create a set sorted in descending order.

#### Example

```text
Test Inputc1 = A
c2 = a
c3 = B
```

```text
Expected Outputa
B
A
```
