## Access Elements of a Map

### Problem Description

Write a program to access elements of a map.

- Initialize a map called songs of integer key and string value with the key-value pairs {1, "Smells Like Teen Spirit"}, {2, "Last Kiss"}, and {3, "Keep On Rockin In The Free World"}.
- Print the value of the element with key 2 using at().
- Print the value of the element with key 1 using [].
