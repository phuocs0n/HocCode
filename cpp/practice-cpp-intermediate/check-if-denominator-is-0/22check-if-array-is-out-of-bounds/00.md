## Check if Array is Out of Bounds

### Problem Description

Create a program to print an element of an array based on user input (array index). If the index doesn't exist in the array, print a custom error message.

- Initialize an integer array numbers with the elements {10, 20, 30}.
- Use the sizeof() function to get the array length.
- Take an integer input and assign it to the index variable.
- Print the element at that given index.
- However, if the index is not in the array (index < 0 or index >= array_length), throw a custom error message Array is out of bounds!.
- Catch this exception in the catch block with the parameter char const* msg.
- Inside the catch block, print the thrown error message by printing the msg parameter.

Use exception handling to solve this problem.
