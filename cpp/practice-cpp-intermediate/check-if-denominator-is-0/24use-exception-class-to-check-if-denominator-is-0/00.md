## Use exception Class to Check if Denominator is 0

### Problem Description

We can catch a non-standard exception (such as floating pont exception) by using the exception class.

We do this by throwing the exception() function in the try block.

```text
try {
    ... .. ...
        if (condition)
        throw exception();
    ... .. ...
}
```

So, write a program to catch a floating point exception using the exception class.

Inside the try Block

- Get double input for numerator and denominator.
- If denominator is 0.0, throw the exception() function.
- Otherwise, divide numerator and denominator and store the result in the double variable result .

Inside the catch Block

- Use the exception object e as the catch parameter.
- Print a custom error message Error! Denominator cannot be 0.
- Then, print the return value of the what() function.
