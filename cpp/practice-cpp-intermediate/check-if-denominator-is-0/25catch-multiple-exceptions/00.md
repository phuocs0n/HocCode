## Catch Multiple Exceptions

### Problem Description

Create a program to change an array element based on user input (index). Change the element at index to 100 / index.

Throw an exception if the index is 0. Throw another exception if the index doesn't exist in the array.

Step 1

- Declare an integer array called numbers with the elements 0, 1, 2, 3, and 4.
- Get integer input for index variable.
- Inside the try block, use an if statement to check if index == 0.
- If true, throw the integer 0 as an exception using the throw keyword.
- Else, if index > 4 or if index < 0, then throw the sting literal "Array index out of bounds!".
- After the if...else if statement, try to change the array element at index to 100 / index.
- Also, print the item at index.

Step 2

- Inside the first catch block, catch the exception thrown with an int parameter and print "Division by 0".
- In the second catch block, catch the array out of bounds exception with the parameter char const* message.
- Then, print the message parameter.
