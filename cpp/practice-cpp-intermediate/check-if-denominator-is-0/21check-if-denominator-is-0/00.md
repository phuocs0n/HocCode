## Check if Denominator is 0

### Problem Description

Create a program to divide a number by another number. Use exception handling in case the denominator is 0.

- Get double inputs for the numerator and denominator variables.
- In the try block, check if denominator is 0.
- If it is, throw an exception with the error message Cannot divide by 0.
- Otherwise, divide the two numbers and store the result in the double variable result.
- Then, print result.
- Catch the exception in the catch block with the parameter char const* msg.
- Inside the catch block, print the thrown error message by printing the msg parameter.

#### Example

```text
Test Input5
0
```

```text
Expected OutputCannot divide by 0
```
