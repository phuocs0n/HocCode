## Subtract Two Numbers

### Problem Description

Create a program to return the difference of two integers through a lambda.

- Create a lambda expression that takes two integer parameters num1 and num2.
- Using the auto keyword, store the lambda in the subtract_numbers variable.
- Inside the lambda, return the difference of num1 and num2.
- Outside the lambda, get integer input for num1 and num2 variables.
- Then, call the subtract_numbers() lambda by passing num1 and num2 as arguments.
- Store the return value of the lambda in the difference variable.
- Print difference.

#### Example

```text
Test Input5
2
```

```text
Expected Output3
```
