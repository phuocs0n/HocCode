## BMI Calculator

### Problem Description

Write a program to calculate your Body-Mass Index (BMI) with the help of a lambda function and its capture clause.

The formula for calculating BMI is:

```text
BMI = weight / (height * height)
```

Here, weight is a person's weight in kg, while height is in meters.

- Create double variables weight, height, and bmi.
- Get user input for weight and height.
- Create a lambda expression calculate_bmi() that captures weight and height by value and bmi by reference.
- Calculate the BMI inside the lambda and store the result in the bmi variable.
- Outside the lambda, call the calculate_bmi() lambda.
- Finally, print the bmi variable.

#### Example

```text
Test Input85
1.82
```

```text
Expected Output25.6612
```
