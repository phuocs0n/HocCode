## Lambda Calculator

### Problem Description

Create a calculator using a lambda function. Capture all variables using implicit capture by value.

- Get integer inputs for num1 and num2.
- Get character input for op.
- Create a lambda expression calculate() with explicit return type double. [Hint: Use the code -> double after parentheses]
- Capture all the variables with implicit return by value using the code [=].
- Inside the lambda, use switch...case to check the value of op.
- If op == '+', return the sum of num1 and num2.
- If op == '-', return the difference of num1 and num2.
- If op == '*', return the product of num1 and num2.
- If op == '/', check if num2 is 0. If yes, return -1. Else, return the division of num1 and num2.
- Otherwise, return -1 if the operator is invalid.
- Then, call the calculate() lambda and store its return value in a double variable named result.
- Finally, print the result.

Tip: When dividing the numbers. make sure you use static_cast to convert either num1 or num2 to double. Otherwise, the division will be carried out as integers, and that result will be converted to double. This will give the wrong output since the division should be carried out with at lease one double operand for accuracy.

#### Example

```text
Test Input5
2
/
```

```text
Expected Output2.5
```
