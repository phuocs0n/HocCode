## The using Directive

### Problem Description

Write a program to utilize the using directive for a user-defined namespace.

Step1

- Create a namespace namespace1.
- Inside the namespace, create a function add_numbers() that takes two parameters: num1 and num2.
- Inside the function, return the value num1 + num2 + 10.

Step 2

- Create another namespace namespace2.
- Inside the namespace, create another add_numbers() function that takes two parameters: num1 and num2.
- Inside the function, return the value num1 + num2.

Step 3

- In main(), get integer inputs for num1 and num2.
- Use namespace1 with the code using namespace1;.
- Then, print the return value of the add_numbers() function of namespace1.
- Finally, print the return value of the add_numbers() function of namespace2.
- Make sure you pass num1 and num2 as arguments for both functions.

#### Example

```text
Test Input5
7
```

```text
Expected Output22
12
```
