## Create an enum

### Problem Description

Write a program to print an enum variable.

- Create an enum called meat with the values Chicken, Beef, Pork, and Lamb.
- Declare a variable meat1 while defining the enum.
- In main(), create another meat variable called meat2.
- Assign Beef to meat1 and Pork to meat2.
- Print the values of meat1 and meat2.

#### Example

```text
Expected Output1
2
```
