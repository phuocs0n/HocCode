## Redefine a Macro

### Problem Description

Write a program to redefine a macro. Solve Einstein's famous equation using two different values of the speed of light:

```text
E = mc2
```

where,

E = energy (in Joules)

m = mass (in grams)

c = speed of light (in meters/second2)

The speed of light is given by:

```text
c = 2.988 x 108 m/s2
```

This can be rounded off to:

```text
c = 3 x 108 m/s2
```

Step 1

- Use #define to set the value of the speed of light macro C to 2.988e8.
- Create a function-like macro calculate_energy() that takes an argument m and returns the value m * C * C.

Step 2

- In main(), get user input for the double variable mass.
- Call the calculate_energy() macro by passing mass as its parameter.
- Store the return value in the energy variable.
- Print energy.

Step 3

- Use #undef to undefine the C macro.
- Then, redefine the C macro to 3e8.
- Call the calculate_energy() macro again and store its return value in energy.
- Print energy.

#### Example

```text
Test Input5
```

```text
Expected Output4.46407e+17

```
