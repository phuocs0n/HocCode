## Volume of Sphere

### Problem Description

Write a program to calculate the volume of a sphere, which is given by the formula:

```text
Volume = (4 / 3) * pi * radius3
```

Step 1

- Import the <cmath> header file.
- Use #define to set the value of PI to 3.1415.

Step 2

- In main(), get user input for the double variable radius.
- Calculate the volume of the sphere by using the formula. [Hint: use the pow() function to get the cube of radius.]
- Store the return value in the volume variable.
- Print volume.

#### Example

```text
Test Input5
```

```text
Expected Output523.583
```
