## Multiple Namespaces

### Problem Description

Write a program to use multiple namespaces.

- Create 3 namespaces: namespace1, namespace2, and namespace3, each with a variable var of char, int, and double types respectively.
- In main(), get input values for the var variables of the 3 namespaces in serial order i.e. take input for var of namespace1 followed by var of namespace2 and namespace3.
- Then, print the variables in the reverse order of the input.

#### Example

```text
Test InputR
25
66.6
```

```text
Expected Output66.6
25
R
```
