## Change Default Value of enum Elements

### Problem Description

Write a program to assign custom integral values to an enum.

- Create an enum called seasons with the values spring, summer, autumn, and winter.
- Assign the integer -2 to summer.
- Declare an enum variable season1 while defining the enum.
- In main(), assign spring to the season1 variable and print it.
- Then, change the value of season1 to summer and print it.
- Repeat the same process and print the next two enum values.

#### Example

```text
Expected Output0
-2
-1
0
```
