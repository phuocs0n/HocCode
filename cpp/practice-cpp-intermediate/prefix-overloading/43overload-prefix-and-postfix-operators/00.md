## Overload Prefix and Postfix -- Operators

### Problem Description

Create a program to overload the -- operator as both prefix and postfix.

Step 1

- Create a Rectangle class with integer variables length and breadth.
- Overload the -- operator as both prefix and postfix using the operator() function.

Step 2

- In main(), create two Rectangle objects rect1 and rect2.
- Get integer inputs for rect1.length and rect1.breadth.
- Use the overloaded prefix -- operator on rect1 and store its return value in the rect2 object.
- Print the length and breadth variables of rect2.
- Again, use the overloaded postfix -- operator on rect1 and store its return value in the rect2 object.
- Print the length and breadth variables of rect2 again.
- Finally, print the length and breadth variables of rect1.

#### Example

```text
Test Input6
4
```

```text
Expected Output5
3
5
3
4
2
```
