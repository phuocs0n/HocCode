## Complex Division

### Problem Description

Create a program to overload the / operator to divide two complex numbers.

Suppose the result of dividing the complex number a + bi by another complex number c + di is x + yi. Then, the formula for complex division will be:

```text
x = (ac + bd) / (c2 + d2)
y = (bc - ad) / (c2 + d2)
```

Here, c^2 + d^2 can be written as denominator. So, the formula now becomes:

```text
x = (ac + bd) / denominator
y = (bc - ad) / denominator
```

Step 1

- Import the <cmath> header file.
- Create a Complex class with double variables real and imag.
- Overload the / operator using an operator() function that takes a Complex object obj as its parameter.
- Inside the function, create a Complex object result.
- Then, create a double variable denominator with the value pow(obj.real, 2) + pow(obj.imag, 2).
- In the try block, throw 0.0 if denominator is 0.
- Otherwise, use the complex division formula given above and store the respective results in result.real and result.imag.
- In the catch block, take double num as a parameter.
- Then, assign the value of num to both result.real and result.imag.
- Finally, return the result object outside the try...catch block.

Step 2

- In main(), create Complex objects complex1 and complex2.
- Get input for the real and imag variables of complex1 and complex2.
- Divide complex1 by complex2 using the overloaded / operator and store the return value in the result object.
- Print the result in the format real + imagi.

Tip: Use the this pointer to distinguish the members of the calling object from those of the function parameter obj.
