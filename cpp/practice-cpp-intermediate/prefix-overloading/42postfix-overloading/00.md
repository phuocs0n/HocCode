## Postfix ++ Overloading

### Problem Description

Create a program to overload the ++ operator as a postfix.

Step 1

- Create a Rectangle class with integer variables length and breadth.
- Overload the ++ operator as a postfix using the operator() function. Make sure the function returns a Rectangle object.
- Inside this function, create a Rectangle object temp.
- Then, use the postfix ++ to increment the length and breadth variables.
- Store the values in temp.length and temp.breadth, respectively.
- Finally, return the temp object.

Step 2

- In main(), create two Rectangle objects rect1 and rect2.
- Get integer inputs for rect1.length and rect1.breadth.
- Use the overloaded postfix ++ operator on rect1 and store its return value in the rect2 object.
- Print the length and breadth variables of rect1 and rect2 in separate lines.

#### Example

```text
Test Input6
4
```

```text
Expected Output7
5
6
4
```
