## Complex Calculator

### Problem Description

Create a program to overload the +, -, *, and / operators to perform complex calculation.

Suppose we have two complex numbers a + bi and c + di. And suppose the result of the complex arithmetic is x + yi.

Then, the formulae for complex arithmetic will be:

1. Complex Addition:

```text
x = a + c
y = b + d
```

2. Complex Subtraction:

```text
x = a - c
y = b - d
```

3. Complex Multiplication:

```text
x = ac - bd
y = ad + bc
```

4. Complex Division:

```text
x = (ac + bd) / (c2 + d2)
y = (bc - ad) / (c2 + d2)
```

Step 1

- Import the <cmath> header file.
- Create a Complex class with double variables real and imag.
- Initialize these variables using a constructor initializer list.
- Then, overload the +, -, *, and / operators and perform the respective calculations inside.

Hint: Make a temporary object result inside each operator() function to store the results of the calculation. Also, use the this pointer to distinguish the member variables of the calling object.

Note: Don't use exception handling when overloading the / operator.

Step 2

- In main(), create complex1 object and pass 20.0 and 30.0 as arguments to its constructor.
- Create complex2 object and pass 10.0 and 15.0 as constructor arguments.
- Create result object and pass 0.0 and 0.0 as constructor arguments.
- Get character input for op variable.
- Using switch...case, perform the appropriate complex arithmetic based on the value of op.
- If the value of op is invalid i.e. if it isn't '+', '-', '*', or '/' then print the message Invalid Operator! and exit the program using the code exit(0).
- Outside the switch...case, print the result in the format real + imagi.
