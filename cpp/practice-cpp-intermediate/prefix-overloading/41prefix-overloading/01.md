## Prefix ++ Overloading

### Problem Description

Create a program to overload the ++ operator as a prefix.

Step 1

- Create a Complex class with integer variables real and imag.
- Initialize the member variables using a constructor initializer list.
- Overload the ++ operator as a prefix using the operator() function. Make sure the function returns a Complex object.
- Inside this function, create a Complex object temp by passing (0, 0) as constructor parameters.
- Then, increment the real and imag variables with the prefix ++ operator.
- Store the values in temp.real and temp.imag, respectively.
- Finally, return the temp object.

Step 2

- In main(), get integer inputs for real and imag.
- Create a complex object and pass real and imag as arguments to the constructor.
- Create another object result and pass (0, 0) as constructor parameters.
- Use the overloaded ++ operator on complex and store its return value in the result object.
- Using an if...else statement, print the real and imag variables of result in the format real-imagi if imag is negative.
- Else, print them in the format real+imagi.

#### Example

```text
Test Input25
-12
```

```text
Expected Output26-11i
```
