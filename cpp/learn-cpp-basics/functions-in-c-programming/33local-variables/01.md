## Local Variables

Any variable that is created inside a function is local to it. For example,

```cpp
1#include <iostream>
2using namespace std;
3
4void add_numbers(int n1, int n2) {
5    int result = n1 + n2;
6}
7
8int main() {
9
10    add_numbers(3, 9);
11    cout << result;
12
13    return 0;
14}
```

Here, when the execution of the add_numbers() function ends, all the variables inside it: n1, n2 and result are destroyed.

This is the reason why the above program throws an error because C++ thinks the result variable is not defined.

If you remember, we can fix it by using a return statement.

```cpp
1#include <iostream>
2using namespace std;
3
4int add_numbers(int n1, int n2) {
5    int result = n1 + n2;
6    return result;
7}
8
9int main() {
10
11    int output = add_numbers(3, 9);
12    cout << output;
13
14    return 0;
15}
```

By using a return statement, we are not using the local variable directly. Rather, we are returning its value to the function call.

Next, we will see why this concept of local variables is important.
