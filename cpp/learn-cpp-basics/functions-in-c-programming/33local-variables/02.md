## Why Local Variables Are Important?

Local variables are important because they make functions independent.

As we discussed earlier, it doesn't matter what's inside a function and what variables are used in it. We can use that function if we know two things:

- arguments that the function takes
- return value from the function

Source Code

```cpp
1#include <iostream>
2using namespace std;
3
4int add_numbers(int n1, int n2) {
5    int result = n1 + n2;
6    return result;
7}
8
9int main() {
10
11    int n1, n2;
12    cout << "Enter two values: ";
13    cin >> n1 >> n2;
14
15    int result = add_numbers(n1, n2);
16    cout << "Sum: " << result;
17  
18    return 0;
19}
```

Output

```text
Enter two value: 90
23
Sum: 113
```

In the program, it's important to understand that n1, n2, and result variables inside the add_numbers() function are local to that function.

They are different from n1, n2, and result variables that are outside of the function (even though names are the same).
