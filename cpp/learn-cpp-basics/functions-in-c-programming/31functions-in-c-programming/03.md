## Using a Function Multiple Times

After we create a function, we can use it any number of times as we want. Let's take a look at it.

```cpp
1#include <iostream>
2using namespace std;
3
4void greet() {
5    cout << "Hello" << endl;
6    cout << "How do you do?" << endl;
7}
8
9int main() {
10
11    // call greet()
12    greet();
13
14    // run another code
15    cout << "Between two function calls" << endl;
16
17    // call greet() again
18    greet();
19
20    return 0;
21}
```

Output

```text
Hello
How do you do?
Between two function calls
Hello
How do you do?
```

Here, we have called the greet() function two times.

This brings us to the next important point. If we need to perform a repetitive task, we can wrap the code inside a function and use that function as many times as we want.
