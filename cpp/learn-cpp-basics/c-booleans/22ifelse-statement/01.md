## The if statement

Let's start with a simple if statement first. Then, we will learn about the if...else statement.

The syntax of the if statement is:

```cpp
if (boolean_expression) {
    // body of if statement
}
```

Here's how it works.

The if statement evaluates boolean_expression that results in either true or false.

If boolean_expression is:

- 1 (true) - the statements inside if are executed
- 0 (false) - the statements inside if are skipped from execution
