## while Loop

Here's the program from the last page:

```cpp
1#include <iostream>
2using namespace std;
3
4int main() {
5
6    int count = 1;
7
8    while (count <= 3) {
9
10        // code inside the loop
11        cout << "I am inside a loop." << endl;
12        cout << "Looping is interesting." << endl;
13    }
14  
15    return 0;
16}
```

Here, the loop continues forever because the boolean expression, count <= 3, is never false because the value of count is always 1.

To run this loop only for a fixed number of times, we must increase the value of count inside the loop so that count <= 3 eventually becomes false. Here's how:

```cpp
1#include <iostream>
2using namespace std;
3
4int main() {
5
6    int count = 1;
7
8    while (count <= 3) {
9
10        // code inside the loop
11        cout << "I am inside a loop." << endl;
12        cout << "Looping is interesting." << endl;
13
14
15        // increase count by 1
16        count = count + 1;
17
18    }
19
20    // code outside loop
21    cout << "OUTSIDE THE LOOP";
22  
23    return 0;
24}
```

Output

```text
I am inside a loop.
Looping is interesting.
I am inside a loop.
Looping is interesting.
I am inside a loop.
Looping is interesting.
OUTSIDE THE LOOP
```

In the program, we have added the statement count = count + 1; to increase the value of count by 1 in each iteration of the loop.

Here's how this code works.

| Iteration | Variable | count <= 3 | Body of loop |
| --- | --- | --- | --- |
| 1st | count = 1 | true | Print statements are executed.
count is increased to 2. |
| 2nd | count = 2 | true | Print statements are executed.
count is increased to 3. |
| 3rd | count = 3 | true | Print statements are executed.
count is increased to 4. |
| 4th | count = 4 | false | The loop terminates. |

After the loop ends, cout << "OUTSIDE THE LOOP"; is executed once because it's outside of the loop.
