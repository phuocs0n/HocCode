## The while Loop

The syntax of of the while loop is:

```cpp
while (boolean_expression) {
    // statement(s)
}
```

Here's how this code works.

The while loop evaluates the boolean expression. If it's true, the body of the while loop is executed. Up until this point, it's similar to the if statement.

However, unlike the if statement, the boolean expression is checked again once the body of the loop has been executed. If it's true, the body of the loop is executed again.

This process continues until the boolean expression is false. If the boolean expression becomes false, the loop terminates.
