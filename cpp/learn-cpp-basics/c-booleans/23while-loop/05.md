## Print Numbers From 1 to 5

To solve this program, let's first create a loop that runs 5 times.

```cpp
int count = 1;

while (count <= 5) {
    count = count + 1;
}
```

Here, the loop will iterate 5 times from count = 1 to count = 5. After that, count becomes 6, and the loop terminates.
