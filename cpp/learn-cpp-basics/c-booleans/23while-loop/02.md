## Example: while Loop

```cpp
1#include <iostream>
2using namespace std;
3
4int main() {
5
6    int count = 1;
7
8    while (count <= 3) {
9
10        // code inside the loop
11        cout << "I am inside a loop." << endl;
12        cout << "Looping is interesting." << endl;
13    }
14  
15    return 0;
16}
```

Here, the body of the loop contains two print statements. We know this because they are included inside the curly braces {} (which indicates the body of the loop).

If you run this program, the two statements inside the loop are executed again and again.

Output

```text
I am inside a loop.
Looping is interesting.
I am inside a loop.
Looping is interesting.
...
...
```

Let's analyze what this program is doing.

- Here, count is 1. Hence, the boolean expression count <= 3 evaluates to true, and the loop body is executed.
- Again, count <= 3 is evaluated. Again, it's true. The loop body is executed, and the boolean expression is evaluated.
- In this program, count <= 3 never becomes false. Hence, the loop runs forever.

This is called an infinite loop because the boolean expression is never false and the loop runs forever, and the code after the loop is never executed.

However, most of the time, rather than running a loop forever and ever, we want loops to end at some point.

Next, we will create a loop that ends after running a fixed number of times.
