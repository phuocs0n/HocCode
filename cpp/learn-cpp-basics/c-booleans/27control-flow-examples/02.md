## Print Multiplication Table

In this example, we will create a multiplication table of a number (let's say 9) up to 5. Here's the output we are looking for.

```text
9 * 1 = 9
9 * 2 = 18
9 * 3 = 27
9 * 4 = 36
9 * 5 = 45
```

To solve this program, we need to iterate a loop five times from 1 to 5. And, in each iteration of the loop, we will compute the product.

```cpp
1#include <iostream>
2using namespace std;
3
4int main() {
5
6    int number = 9;
7    int product;
8
9    // iterate loop from 1 to 5
10    for (int i = 1; i <= 5; ++i) {
11
12        // compute product in each iteration
13        // product will be 9 * 1 in first iteration
14        // 9 * 2 in second iteration and so on
15        product = number * i;
16
17        cout << product << endl;
18    }
19
20    return 0;
21}
```

Output

```text
9
18
27
36
45
```

The output we got is close to the desired output but not the same. Let's fix it.

```cpp
1#include <iostream>
2using namespace std;
3
4int main() {
5
6    int number = 9;
7    int product;
8
9    // iterate a loop from 1 to 5
10    for (int i = 1; i <= 5; ++i) {
11
12        // compute the product in each iteration of the loop
13        product = number * i;
14        cout << number << " * " << i;
15        cout << " = " << product << endl;
16    }
17
18    return 0;
19}
```

Now, we will get the desired output.
