## Booleans Introduction

Before we learn about decision-making and loops, we need to understand booleans and boolean expressions. Let's discuss them in this lesson.

#### Booleans

Booleans represent one of two possible values: true or false, and are essential to decision-making in programming.

Just like int and char, boolean is a data type in C++ programming, and we use the bool keyword to represent boolean. Let's see an example,

```cpp
1#include <iostream>
2using namespace std;
3
4int main() {
5
6    bool result1 = true;
7    bool result2 = false;
8
9    cout << result1;    // 1
10    cout << endl;
11    cout << result2;    // 0
12
13    return 0;
14}
```

In C++, boolean values are represented in terms of integer values:

- false is represented by 0
- true is represented by 1 or all other values except 0

There are a few things we need to understand about booleans:

- true is a boolean value. However, if we use true inside double quotes ("true") it is a string. It is the same for "false".
- true and false are not variables. In fact, we cannot create variables named true and false.
- true and false must always be written in lowercase.
