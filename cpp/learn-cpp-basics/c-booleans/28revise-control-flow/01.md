### 4. The break Statement

The break statement is used to terminate the loop immediately when it's encountered. It is usually used inside an if...else statement.

```cpp
1#include <iostream>
2using namespace std;
3
4int main() {
5
6    for (int i = 1; i <= 100; ++i) {
7
8        if (i == 3) {
9            break;
10        }
11        cout << i << endl;
12    }
13
14    return 0;
15}
16
17// Output: 
18// 1
19// 2
```

### 5. The continue Statement

The continue statement skips the code inside the loop for the current iteration. The loop will not terminate but continues on with the next iteration. It's also usually used inside an if...else statement.

```cpp
1#include <iostream>
2using namespace std;
3
4int main() {
5
6    for (int i = 1; i <= 5; ++i) {
7
8        if (i == 3 || i == 4) {
9            continue;
10        }
11        cout << i << endl;
12    }
13
14    return 0;
15}
16
17// Output:
18// 1
19// 2
20// 5
```

### 6. The switch Statement

The switch statement can be used as a replacement for if...else when we have to choose from multiple alternatives. For example,

```cpp
1#include <iostream>
2using namespace std;
3
4int main() {
5
6    int number = 3;
7
8    switch (number) {
9        case 1:
10            cout << "One";
11            break;
12    
13        case 2:
14            cout << "Two";
15            break;
16
17        case 3:
18            cout << "Three";
19            break;
20    
21        default:
22            cout << "Invalid Number";
23    }
24
25    return 0;
26}
27
28// Output:
29// Three
```
