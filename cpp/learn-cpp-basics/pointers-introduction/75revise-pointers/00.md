## Pointers Summary

Let's revise what we have learned in this chapter:

1. Memory Address

&number gives the address of the number variable. For example,

```cpp
1#include <iostream>
2using namespace std;
3
4int main() {
5
6    int number = 32;
7
8    // print the address of number variable
9    cout <<  &number;
10
11    return 0;
12}
13
14// Output: 0x7ffeb9e74a54
```

2. Pointer Variables

A pointer variable is used to store the memory address of a variable. For example,

```cpp
1#include <iostream>
2using namespace std;
3
4int main() {
5
6    int number = 32;
7  
8    // pt is a pointer variable that stores
9    // memory address of number
10    int* pt = &number;
11    cout << pt;
12
13    return 0;
14}
15
16// Output: 0x7ffc89fa4bfc
```

3. Access Value Using Pointers

*pt accesses the value pointed by the address stored in the pt pointer. This process is known as dereferencing a pointer. For example,

```cpp
1#include <iostream>
2using namespace std;
3
4int main() {
5
6    int number = 32;
7  
8    // pt is a pointer variable that stores
9    // memory address of number
10    int* pt = &number;
11  
12
13    // value stored in the address pointed by pt
14    cout << *pt;
15
16
17    return 0;
18}
19
20// Output: 32
```

4. Dynamic Memory Allocation

In C++, we can allocate memory during run-time. We use the following operators to manage memory in C++:

- new - dynamically allocates memory during run-time
- delete - clears the dynamically allocated memory after it is of no use to us

For example,

```cpp
1#include <iostream>
2using namespace std;
3
4int main() {
5
6
7    // dynamically allocate memory
8    int* number = new int;
9
10    // assign value to the memory
11    *number = 256;
12
13    cout << *number;
14
15    // deallocate the memory
16    delete number;
17
18
19  return 0;
20}
21
22// Output: 256
```
