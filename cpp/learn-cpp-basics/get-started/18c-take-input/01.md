## cin Statement

Here's the syntax of the cin statement from our previous program

```cpp
// take input for age
cin >> age;
```

The >> operator along with cin takes input from a standard input device (keyboard) and assigns it to the age variable.

Similarly, we can use the same statement to take double and char input from the user.

Note: If you look carefully, it looks just the opposite of the cout statement.

```cpp
// get age input
cin >> age;

// print age
cout << age;
```
