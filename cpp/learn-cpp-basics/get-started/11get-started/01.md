## Introduction to C++

C++ is a popular and versatile programming language that can be used to create operating systems, web browsers, video games, and so on.

Being one of the older programming languages, it is also taught as the first programming language for many beginners. This is because C++ allows you to understand how the software and hardware interact with each other.

This course is a great introduction to C++ programming, and that too in the most interactive way possible. Here's how the learning process works:

1. Learn a concept.
2. Edit and run code related to it.
3. Practice what you have learned in real-time.

By the end of this course, you'll write hundreds of programs and become comfortable programming in C++.
