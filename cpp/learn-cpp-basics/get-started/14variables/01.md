## Declare Variables

The syntax to declare variables in C++ is:

```cpp
int age;
```

Here,

- age - a variable
- int - data type of age (we will learn about data types in another lesson)

The age variable can only store integer values. We know this because we have used the data type int to declare it.

By the way, we can also use other data types to create variables. However, for ease, let's just create int type variables for now.
