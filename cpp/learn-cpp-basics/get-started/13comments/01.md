## Comments Example

Let's take a look at another example.

```cpp
1#include <iostream>
2using namespace std;
3
4int main() {
5
6    // print a string
7    cout << "Age = ";
8
9    // print an integer
10    cout << 25;
11
12    return 0;
13}
```

Output

```text
Age = 25
```

Here, these two lines are comments:

- // print a string
- // print an integer

#### Comments at Statement End

We can also add comments in the same line as the code.

```cpp
1#include <iostream>
2using namespace std;
3
4int main() {
5
6    cout << 36.5;    // Output: 36.5 
7
8    return 0;
9}
```

Here, // Output: 36.5 is a comment. The C++ compiler ignores this code.
