## Automatic Type Conversion

In C++, sometimes one data type is automatically converted to another type. Let's see an example.

```cpp
1#include <iostream>
2using namespace std;
3
4int main() {
5
6    int number = 18;
7    double sum;
8
9    // convert number to double
10    sum = number + 4.5;
11
12    cout << "Sum: " << sum;
13
14    return 0;
15}
```

Output

```text
Sum: 22.5
```

Consider this statement:

```cpp
sum = num + 4.5;
```

Here, we are adding an integer value (18) and a double value (4.5). In this case,

- the integer value is first converted to a double value (18.0),
- then, it is added to 4.5,
- finally, we get 22.5 as output.

This type of conversion is known as implicit type conversion, where one data type is automatically converted to another data type.
