## Type Conversion

Up to this point, we have worked with three different types of data:

- int - Numbers without decimal parts. For example, 45, -9, 0, etc.
- double - Numbers with decimal parts. For example, 45.87, -32.50, 12.0, etc.
- char - Single characters wrapped inside single quotations. For example, 'a', '5', 'c', etc.

In programming, there might be situations when you have to convert one data to another. For example, double to int, int to char, and so on.

This process of converting the value of one data type to another is known as type conversion.

In this lesson, we will learn to perform type conversion in C++. So let's get started.
