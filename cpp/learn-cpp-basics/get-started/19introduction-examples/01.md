## Convert Kilometers to Miles

We can easily convert distance in kilometers to miles using this formula:

```cpp
1 kilometer = 0.621 miles
```

Source Code

```cpp
1// Program to convert distance in kilometer to miles
2// The distance will be entered by the user.
3
4#include <iostream>
5using namespace std;
6
7int main() {
8
9    // create variables for kilometers and miles
10    double km, miles;
11
12    // take input for kilometers
13    cout << "Enter distance in km: ";
14    cin >> km;
15
16    // conversion ratio of km to miles
17    double conversion_ratio = 0.621;
18
19    // computing distance in miles
20    miles = km * conversion_ratio;
21
22    // print the distance in miles
23    cout << "Distance in miles: " << miles;
24
25    return 0;
26}
```

Output

```text
Enter distance in km: 10
Distance in miles: 6.21
```

Here's how this program works.

- cin >> km; - takes distance input in km from the user and stores it in the km variable.
- miles = km * conversion_ratio; - computes the distance in miles by multiplying the distance in km by 0.621.
