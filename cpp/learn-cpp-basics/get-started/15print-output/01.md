## Print Strings and Variables

We can also print a string and a variable using a single print statement. For example,

```cpp
1#include <iostream>
2using namespace std;
3
4int main() {
5    
6    int age = 25;
7    cout << "Age: " << age;
8    
9    return 0;
10}
```

Output

```text
Age: 25
```

Notice the line,

```cpp
cout << "Age: " << age;
```

Here, cout first prints the string "Age: " and then it prints the value of the age variable, 25. Finally, the result Age: 25 is printed.

By the way, we can also print multiple strings together separating them by <<. Let's see an example.

```cpp
1#include <iostream>
2using namespace std;
3
4int main() {
5    
6    cout << "Hello, " << "How are you? " << "I love C++";
7    
8    return 0;
9}
```

Output

```text
Hello, How are you? I love C++
```
