## + Operator

The + (addition) operator is used to add two values or variables. Let's see an example.

```cpp
1#include <iostream>
2using namespace std;
3 
4int main() {
5 
6    int number1 = 34;
7    int number2 = 12;
8 
9    // + adds values of two variables
10    int sum = number1 + number2;
11    cout << "Sum: " << sum;
12 
13    return 0;
14}
```

Output

```text
Sum: 46
```

Here, int sum = number1 + number2; first adds the value of number1 and number2. Then, the result is assigned to the sum variable.

We can also perform the addition directly inside the print statement. Let's see an example.

```cpp
1#include <iostream>
2using namespace std;
3
4int main() {
5
6    int number1 = 34;
7    int number2 = 12;
8
9    // print sum of int variables
10    cout << number1 + number2;
11
12    return 0;
13}
```

Consider this line in the above program:

```cpp
cout << number1 + number2;
```

This first computes the sum of number1 and number2. Then, the result is directly printed on the screen.
