## Introduction to Operators

Till now, we have learned about values, variables and how to print them. However, in real-world projects, we may need to perform operations on these values and variables.

In this lesson, we will learn about operators that will allow us to perform operations on these data (values and variables).

So, what is an operator?

An operator is a special symbol that performs operations on values and variables.

In fact, we have already used one operator many times in our program without even realizing it. It's the = operator.

```cpp
int age = 25;
```

Here, the = operator assigns the value on the right (25) to the variable on the left (age). This is known as an assignment operator.

For simplicity, we will be focusing on different arithmetic operators in this lesson. So let's get started.
