## Example: Truthy and Falsy

Suppose we need to find the largest number among three numbers.

```cpp
1#include <iostream>
2using namespace std;
3
4int main() {
5
6    int n1 = 20;
7    int n2 = 10;
8    int n3 = 30;
9
10    // print the largest number
11    if (n1 > n2 && n3) {
12        cout << n1;
13    }
14    else if (n2 > n1 && n3) {
15        cout << n2;
16    }
17    else {
18        cout << n3;
19    }
20
21    return 0;
22}
```

Output

```text
20
```

Here, we are getting 20 as the largest number.

Can you find out where the error is?

Take a look at this code:

```cpp
if (n1 > n2 && n3) {
    cout << n1;
}
```

Here, n1 > n2 evaluates to true and n3 also evaluates to true because 30 is considered true.

Instead here's what we should have written:

```cpp
if (n1 > n2 && n1 > n3) {
    cout << n1;
}
```

In the code above, n1 > n2 evaluates to true and n1 > n3 evaluates to false. Hence, n1 > n2 && n1 > n3 evaluates to false.

As a result, the statements inside the if block are skipped, and the control flow moves to the else if block, and so on.
