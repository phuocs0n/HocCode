## Truthy and Falsy

Let's take an example to understand this concept:

```cpp
1#include <iostream>
2using namespace std;
3
4int main() {
5
6    int x = 8;
7
8    if (x) {
9        cout << x; 
10    }
11
12    return 0;
13}
14
15// Output: 8
```

Here, the code inside the if statement is executed. It's because 8 evaluates to true.

Now, let's take another example,

```cpp
1#include <iostream>
2using namespace std;
3
4int main() {
5
6    int x = 0;
7
8    if (x) {
9        cout << x; 
10    }
11
12    return 0;
13}
14
15// No Output
```

Here, the program doesn't print any output. It's because 0 evaluates to false.

The values that evaluate to true are known as truthy values. Similarly, values that evaluate to false are called falsy values.

In C++, these values are considered falsy.

- false
- 0
- 0.0

All other values are considered truthy.

Next, we will see why this concept is important.
