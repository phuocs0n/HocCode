## Introduction to Ternary Operator

In C++, we can use a ternary operator ? : as an alternative to an if...else statement. Let's see an example,

```cpp
1#include <iostream>
2using namespace std;
3
4int main() {
5
6    int marks = 76;
7
8    string result;
9  
10    if (marks >= 32) {
11        result = "pass";
12    }
13    else {
14        result = "fail";
15    }
16
17    cout << result;
18
19    return 0;
20}
21
22// Output
23// pass
```

Here, we have used an if...else statement to check if a student passed the exam or not.

Now, let's implement this same program using a ternary operator.

```cpp
1#include <iostream>
2using namespace std;
3
4int main() {
5
6    int marks = 76;
7
8    string result = (marks >= 32) ? "pass" : "fail";
9  
10    cout << result;
11
12    return 0;
13}
14
15// Output:
16// pass
```

Next, we will see the working of ternary operators.
