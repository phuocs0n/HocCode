## Check Odd/Even Using Ternary Operator

In this example, we will use a ternary operator to check if a number is odd or even.

```cpp
1#include <iostream>
2using namespace std;
3
4int main() {
5
6    cout << "Enter a number: " << endl;
7    
8    int number;
9    cin >> number;
10
11    string result = (number % 2 == 0) ? "Even" : "Odd";
12  
13    cout << result;
14
15    return 0;
16}
```

Sample Output 1

```text
Enter a number: 
5
Odd
```

Sample Output 2

```text
Enter a number: 
36
Even
```

Here, if the number is perfectly divisible by 2, "Even" is assigned to the result variable. Otherwise, "Odd" is assigned.
