## Create a Multiline Comments

By now, you must be familiar with using comments in code.

```cpp
1#include <iostream>
2using namespace std;
3
4int main() {
5
6    // create a variable
7    int age = 24;
8
9    // print variable
10    cout << age;
11
12    return 0;
13}
```

Here, // create a variable and // print variable are two comments.

These are called single line comments.

However, suppose we have to add a comment that extends for multiple lines. For example,

```cpp
In this program, we will create a variable named age.
We assign the value 24 to the variable.
And we then use a print statement to print the variable.
```

Here, adding // before every sentence doesn't make our code look good. So instead, we can use a multi-line comment.

A multi line comment starts from /* and ends with */. For example,

```cpp
/*
In this program, we will create a variable named age.
We will assign 24 to the variable.
And we then use a print statement to print the variable.
*/
```
