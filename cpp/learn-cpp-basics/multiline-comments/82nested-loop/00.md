## Nested Loops

It's possible to put a loop inside another loop. This is known as a nested loop.

In a nested loop, the inner loop is executed for each iteration of the outer loop. Let's try to understand it with the help of an example.

```cpp
1#include <iostream>
2using namespace std;
3
4int main() {
5
6    int floors[2] = {1, 2};
7    char apartments[3] = {'A', 'B', 'C'};
8
9    // outer loop to iterate through floors
10    for (int i = 0; i < 2; ++i) {
11
12        /*
13        inner loop to iterate apartments.
14        runs from 0 to 2 for each iteration of the outer loop.
15        prints apartment value.
16        */
17
18        for (int j = 0; j < 3; ++j) {
19            cout << floors[i] << apartments[j] << endl;
20        }
21    }
22
23    return 0;
24}
```

Output

```text
1A
1B
1C
2A
2B
2C
```

Here, the inner loop is iterated once for each iteration of the outer loop. Here's how the code works:

First Iteration of the Outer Loop

- floors is 1, apartment is 'A'
- floors is 1, apartment is 'B'
- floors is 1, apartment is 'C'

Second Iteration of the Outer Loop

- floors is 2, apartment is 'A'
- floors is 2, apartment is 'B'
- floors is 2, apartment is 'C'
