## Example: Nested Loops

```cpp
1#include <iostream>
2using namespace std;
3
4int main() {
5
6    // outer loop iterates from i = 0 to 2
7    for (int i = 0; i <= 2; ++i) {
8
9        // inner loop iterates from j = 0 to 1
10        for (int j = 0; j <= 1; ++j) {
11            cout << "i = " << i << ", j = " << j << endl;
12        }
13    }
14
15    return 0;
16}
```

Output

```text
i = 0, j = 0
i = 0, j = 1
i = 1, j = 0
i = 1, j = 1
i = 2, j = 0
i = 2, j = 1
```

In this program, the outer loop iterates from i equals 0 to 2. In each iteration of the outer loop, the inner loop iterates from j equals 0 to 1.
