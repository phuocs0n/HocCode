## C++ Strings

We have already used strings many times in our program. Remember the "Hello World" program?

```cpp
1#include <iostream>
2using namespace std;
3
4int main() {
5
6    cout << "Hello World";
7
8    return 0;
9}
10
11// Output: Hello World
```

Here, "Hello World" is an example of a string. We use double quotes to represent strings.

Strings are a collection of characters that are used to represent textual data in programming. For example, the string "Hello World" consists of the characters: 'H', 'e', 'l', ...
