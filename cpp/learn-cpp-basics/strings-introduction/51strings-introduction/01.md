## Create Strings

In C++, we use the string keyword to create string variables. Here's how we create strings in C++:

```cpp
string text = "Programiz";
```

In the above code, text is a string and we have assigned "Programiz" to it.

Print a String

Like with everything else so far, we print strings using cout.

```cpp
1#include <iostream>
2using namespace std;
3
4int main() {
5    
6    // create a string
7    string text = "Programiz";
```
