## Escape Sequences

Previously, we encountered an error when we tried to use the following string in our program:

```cpp
// error
string text = "Roose says, "The Lannisters send their regards!"";
```

Since there are quotation marks in it, we have to use \" to indicate ". For example,

```cpp
1#include <iostream>
2using namespace std;
3
4int main() {
5    
6    // notice the use of the escape sequence
7    string text = "Roose says, \"The Lannisters send their regards!\"";
8
9    cout << text;
10
11    return 0;
12}
```

Output

```text
Roose says, "The Lannisters send their regards!"
```

Here, \" is called an escape sequence. It allows us to include special characters in strings.

Remember \n? It is also an escape sequence that we use for newline (next line).

```cpp
1#include <iostream>
2using namespace std;
3
4int main() {
5
6    string text = "Hey\nHello\nHowdy?";
7    cout << text;
8
9    return 0;
10}
```

Output

```text
Hey
Hello
Howdy?
```

As you can see, when \n is encountered, it's treated as a newline.
