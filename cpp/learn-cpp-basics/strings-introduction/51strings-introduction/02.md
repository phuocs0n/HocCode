## Special Characters in Strings

Suppose we want to use the following string in our program:

```cpp
Roose says, "The Lannisters send their regards!"
```

Let's see what happens when we try to print this string:

```cpp
1#include <iostream>
2using namespace std;
3
4int main() {
5    
6    string text = "Roose says, "The Lannisters send their regards!"";
7    cout << text;
8
9    return 0;
10}
11
12// Output: 6:19: error: unable to find string literal operator.
```

As you can see, this program produces an error. This is because we have used double quotes inside the string.

However, double quotes are used to enclose a string, so we can't use them inside it.

But there are times when we need to use these types of special characters in our string. How can we use them if they give us an error? Let's find out!
