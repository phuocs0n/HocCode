## Compare Two Strings Using == Operator

We know that the equals to operator == is used to check if two numbers are equal or not. In this example, we will use this operator to check whether two strings are identical or not.

### Thought Process

First, we take two string inputs from the user. Then, we use an if...else statement to check whether the two strings are identical or not with the help of the == operator.

### Source Code

```cpp
1#include <iostream>
2using namespace std;
3
4int main() {
5
6    string text1, text2;
7
8    cout << "Enter first string: ";
9    getline(cin, text1);
10
11    cout << "Enter second string: ";
12    getline(cin, text2);
13
14    // compare the strings
15    if (text1 == text2) {
16        cout << "The strings are identical.";
17    }
18    else {
19        cout << "The strings are not identical.";
20    }
21
22    return 0;
23}
```

Output

```text
Enter first string: Hulk smash!
Enter second string: Hulk SMASH!
The strings are not identical.
```

Here, if (text1 == text2) checks if two strings are identical. If they are, the if block is executed. Otherwise the else block is executed.
