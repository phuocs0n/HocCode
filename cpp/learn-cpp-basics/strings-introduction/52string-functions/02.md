## Find the Length of a String

We use the length() function to find the length of the string. For example,

```cpp
1#include <iostream>
2#include <string>
3using namespace std;
4
5int main() {
6
7    string text = "C++ Programming";
8    cout << "string = " << text << endl;
9
10    // text.length() returns the length of text
11    cout << "string length = " << text.length();
12    return 0;
13}
```

Output

```text
string = C++ Programming
string length = 15
```

In the above example,

- #include <string> - imports the header file in our program
- text.length() - finds the length of the string text
