## Introduction to String Functions

Strings are one of the most frequently used data types in programming. There are several string functions to make working with strings easier. For example, the length() function allows us to find the length of a string.

To use these functions, we must first import the string header file in our program. This is because the definition of these functions is provided inside this file.

In this lesson, we will learn about these commonly used functions.

- length() - finds the length of a string
- insert() - inserts characters into an existing string
- substr() - generates a substring from a string
- swap() - swaps values of two string variables
