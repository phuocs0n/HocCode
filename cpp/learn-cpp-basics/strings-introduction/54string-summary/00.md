## Summary (I)

Let's now quickly revise what we have learned so far in this chapter:

1. Create a String

In C++, the syntax to create a string is similar to that of a variable.

```cpp
string text = "Programiz";
```

2. Print a String

We use the cout object to print a string.

```cpp
1#include <iostream>
2using namespace std;
3
4int main() {
5
6    string text = "Programiz";
7
8    cout << text;    // Programiz
9  
10    return 0;
11}
```

3. Change a String

We can change the character of a string by assigning a new character at that position.

```cpp
1#include <iostream>
2using namespace std;
3
4int main() {
5
6    string text = "Car";
7
8    // change value at position 2 to 't'
9    text[2] = 't';
10
11    cout << text;    // Cat
12
13    return 0;
14}
```
