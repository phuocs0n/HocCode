## Array Element as Function Argument

Remember how we access array elements?

```cpp
1#include <iostream>
2using namespace std;
3
4int main() {
5
6    int ages[5] = {25, 31, 30, 17, 39};
7
8    // access first element
9    cout << ages[0] << endl;  // 25
10  
11    // access third element
12    cout << ages[2];  // 30
13  
14    return 0;
15}
```

Here, each individual element of an array acts like a regular variable. And we can pass these elements to a function in a similar way we pass variables/values to functions.

Let's see an example

```cpp
1#include <iostream>
2using namespace std;
3
4// function to return the larger value
5int find_larger(int age1, int age2) {
6
7    // compare two ages and return the larger age
8    if (age1 > age2) {
9        return age1;
10    }
11    else {
12        return age2;
13    }
14}
15
16int main() {
17
18    int ages[5] = {25, 31, 30, 17, 39};
19
20    // call the function with second and fifth array element
21    int result = find_larger(ages[1], ages[4]);
22    cout << result;
23 
24    return 0;
25}
26
27// Output: 39
```

Here, we have passed two array elements to the find_larger() function.

- age1 argument takes the value ages[1] (31)
- age2 parameter takes the value ages[4] (39)

The function then compares the two ages and returns the larger age. In our case, it's 39.

As you can see, the program works similar to passing variables to a function.
