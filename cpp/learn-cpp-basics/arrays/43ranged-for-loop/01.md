## Sum of Array Elements

Remember this code to find the sum of array elements.

```cpp
1#include <iostream>
2using namespace std;
3
4int main() {
5
6    int numbers[5] = {32, 14, 25, 61, 72};
7
8    // initial value of total is 0
9    int total = 0;
10
11    for (int i = 0; i < 5; ++i) {
12        total = total + numbers[i];
13    }
14
15    cout << "Total: " << total;
16
17    return 0;
18}
19
20// Output:
21// Total: 204
```

Now let's use the ranged for loop instead of the for loop.

```cpp
1#include <iostream>
2using namespace std;
3
4int main() {
5
6    int numbers[5] = {32, 14, 25, 61, 72};
7
8    // initial value of total is 0
9    int total = 0;
10
11    for (int number : numbers) {
12        total = total + number;
13    }
14
15    cout << "Total: " << total;
16
17    return 0;
18}
19
20// Output:
21// Total: 204
```

Here, you can see we get the same output. However, the code using the ranged for loop looks much cleaner.
