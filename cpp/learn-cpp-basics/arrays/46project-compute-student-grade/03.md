## Compute Student Grade

```cpp
1#include <iostream>
2using namespace std;
3
4// compute grade and return it
5char compute_grade(double average_score) {
6
7    char grade;
8  
9    if (average_score >= 80.0) {
10        grade = 'A';
11    }
12    else if (average_score >= 60.0) {
13        grade = 'B';
14    }
15    else if (average_score >= 50.0) {
16        grade = 'C';
17    }
18    else {
19        grade = 'F';
20    }
21
22    return grade;
23}
24
25int main() {
26
27    double average_score = 67.8;
28
29    char grade = compute_grade(average_score);
30    cout << grade;
31
32    return 0;
33}
34
35// Output: B
```

Here, the compute_grade() function computes the student's grade based on the average score and returns it.

In the program, we have directly assigned a fixed average score to a variable. However, we want the average score to be computed based on the student's scores.

To fix this problem, we need to put the two functions we created in a single program.
