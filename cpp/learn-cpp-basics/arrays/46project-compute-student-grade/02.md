## Get Average Score

```cpp
1#include <iostream>
2using namespace std;
3
4// find the average score and return it
5double get_average_score(double scores[5]) {
6
7    double sum = 0.0;
8
9    // find the sum
10    for (int i = 0; i < 5; ++i) {
11        sum = sum + scores[i];
12    }
13
14
15    double average = sum / 5.0;
16
17
18    return average;
19}
20
21int main() {
22
23    // an array of scores
24    double scores[5] = {55, 64, 75, 80, 65};
25
26
27    double average_score = get_average_score(scores);
28
29    cout << average_score;
30
31    return 0;
32}
33
34// Output: 67.8
```

Here, the get_average_score() function takes an array as an argument.

Inside this function, we have used a for loop to find the sum of all scores.

Then, we have computed the average by dividing the sum by 5.0 (number of array elements).

Next, we will use the average score to compute the student's grade.
