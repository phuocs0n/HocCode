## Project: Compute a Student's Grade

```cpp
1#include <iostream>
2using namespace std;
3
4// find the average score and return it
5double get_average_score(double scores[5]) {
6
7    double sum = 0.0;
8
9    // find the sum
10    for (int i = 0; i < 5; ++i) {
11        sum = sum + scores[i];
12    }
13
14    double average = sum / 5.0;
15
16    return average;
17}
18
19// compute grade and return it
20char compute_grade(double average_score) {
21
22    char grade;
23  
24    if (average_score >= 80.0) {
25        grade = 'A';
26    }
27    else if (average_score >= 60.0) {
28        grade = 'B';
29    }
30    else if (average_score >= 50.0) {
31        grade = 'C';
32    }
33    else {
34        grade = 'F';
35    }
36
37    return grade;
38}
39
40int main() {
41
42    // an array of scores
43    double scores[5] = {55, 64, 75, 80, 65};
44
45    // get average score
46    double average_score = get_average_score(scores);
47
48    // get grade
49    char grade = compute_grade(average_score);
50
51    cout << "Average Score: " << average_score << endl;
52    cout << "Grade: " << grade;
53
54    return 0;
55}
```

Output

```text
Average Score: 67.8
Grade: B
```

Here,

- We have used the get_average_score() function to first calculate the average score.
- Then, we passed the average score as an argument to the compute_grade() function to compute the grade.

In this program, we have provided student scores directly at the beginning.

We can make this program dynamic by getting marks input from the user.
