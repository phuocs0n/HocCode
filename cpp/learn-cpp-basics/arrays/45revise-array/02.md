## Find the Largest Element in an Array

In this example, we will print the largest element of the array.

```cpp
1#include <iostream>
2using namespace std;
3
4int main() {
5
6    // an array of numbers
7    int numbers[5];
8
9    cout << "Enter array elements:" << endl;
10
11    // get input for array elements
12    for (int i = 0; i < 5; ++i) {
13        cin >> numbers[i];
14    }
15  
16    // assign the first value of the array to the largest variable
17    int largest = numbers[0];
18
19    // iterate each element of the array
20    for (int i = 1; i < 5; ++i) {
21        if (largest < numbers[i]) {
22            largest = numbers[i];
23        }
24    }
25
26    cout << "Largest: " << largest;
27
28    return 0;
29}
```

Output

```text
Enter array elements:
55
64
75
80
65
Largest: 80
```

Initially, the first element of the array is assigned to the largest variable.

```cpp
int largest = numbers[0];
```

Then, we have used a for loop to iterate from the second element of the array to the last element.

In each iteration, if the largest variable is less than any element of the array, that element is assigned to the largest variable.

```cpp
// inside the for loop
if (largest < numbers[i] {
    largest = numbers[i];
}
```

Here's how this code works in each iteration of the loop.

| Iteration | numbers[i] | largest < numbers[i] | largest |
| --- | --- | --- | --- |
| 1st (i == 1) | 64 | true | 64 |
| 2nd (i == 2) | 75 | true | 75 |
| 3rd (i == 3) | 80 | true | 80 |
| 4th (i == 4) | 65 | false | 80 |
