## Array Input Using for Loop

```cpp
1#include <iostream>
2using namespace std;
3
4int main() {
5
6    // declare an array
7    int ages[5];
8
9    cout << "Enter array elements:" << endl;
10
11    for (int index = 0; index < 5; ++index) {
12        cin >> ages[index];
13    }
14
15    cout << "Array Elements:" << endl;
16
17    // access array using loop
18    for (int index = 0; index < 5; ++index) {
19        cout << ages[index] << endl;
20    }
21
22    return 0;
23}
```

Output

```text
Enter array elements:
15
25
35
45
55
Array Elements:
15
25
35
45
55
```

Here's how the code works in each iteration of the loop.

| index | cin >> ages[index]; |
| --- | --- |
| 0 | assigns 15 at index 0 |
| 1 | assigns 25 at index 1 |
| 2 | assigns 35 at index 2 |
| 3 | assigns 45 at index 3 |
| 4 | assigns 55 at index 4 |

When the value of index is 5, the condition index < 5 becomes false, hence the loop terminates.
