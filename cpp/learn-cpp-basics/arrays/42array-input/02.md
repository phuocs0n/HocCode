## Example: Find Sum of Array Elements

In this example, we will create an array of size 5. Here, we will take input values for the array elements and find the sum of all the elements.

### Source Code 1

```cpp
1#include <iostream>
2using namespace std;
3
4int main() {
5    
6    // declare an array
7    int numbers[5]; 
8    
9    cout << "Enter array elements: " << endl;
10
11    // get input value for array
12    for (int index = 0; index < 5; ++index) {
13        cin >> numbers[index];
14    }
15    
16    // add all array elements
17    int sum = 0;
18    for (int index = 0; index < 5; ++index) {
19        sum = sum + numbers[index];
20    }
21
22    cout << "Sum: " << sum;
23    
24    return 0;
25}
```

Output

```text
Enter array elements: 
11
22
33
44
55
Sum: 165
```

In the above example, we have created a for loop to take input values for the array.

```cpp
for (int index = 0; index < 5; ++index) {
    cin >> numbers[index];
}
```

We then used a second for loop to find the sum of all the array elements.

```cpp
for (int index = 0; index < 5; ++index) {
    sum = sum + numbers[index];
}
```

We can also use a single for loop to both get the array input and calculate the sum of the elements. Let's see how.

### Source Code 2

```cpp
1#include <iostream>
2using namespace std;
3
4int main() {
5    
6    // declare an array
7    int numbers[5]; 
8    
9    // variable to store sum of array elements
10    int sum = 0;
11
12    cout << "Enter array elements: " << endl;
13
14    // loop to get input and find sum
15    for (int index = 0; index < 5; ++index) {
16
17        // get array input
18        cin >> numbers[index];
19
20        // add all array elements
21        sum = sum + numbers[index];
22    }
23
24    cout << "Sum: " << sum;
25    
26    return 0;
27}
```

This program gives the same output as the previous one. We are able to use a single loop because we can add the array element to the sum variable immediately after getting the input for the array element.
