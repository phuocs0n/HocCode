## Get Array Input

Let's revise the process of taking an input value.

```cpp
1#include <iostream>
2using namespace std;
3
4int main() {
5    
6    // create integer variable
7    int number;
8    
9    // take input value for number
10    cout << "Enter the number: ";
11    cin >> number;
12    
13    cout << "Input Value: " << number;
14
15    return 0;
16}
```

Output

```text
Enter the number: 21
Input Value: 21
```

Just like this, we can also create input values for each array element.

Let's see an example.

```cpp
1#include <iostream>
2using namespace std;
3
4int main() {
5
6    // declare an array
7    int ages[5];
8
9    cout << "Enter the first element: ";
10    cin >> ages[0];
11
12    cout << "Enter the second element: ";
13    cin >> ages[1];
14  
15    cout << "Enter the third element: ";
16    cin >> ages[2];
17
18    cout << "Enter the fourth element: ";
19    cin >> ages[3];
20
21    cout << "Enter the fifth element: ";
22    cin >> ages[4];
23  
24    cout << "Array Elements:" << endl;
25
26    // access array using loop
27    for (int i = 0; i < 5; ++i) {
28        cout << ages[i] << endl;
29    }
30
31    return 0;
32}
```

Output

```text
Enter the first element: 15
Enter the second element: 25
Enter the third element: 35
Enter the fourth element: 45
Enter the fifth element: 55
Array Elements:
15
25
35
45
55
```

Here, each array element, ages[index] acts as an individual variable and we are getting input value for each of the array elements.

Also, we are repeating a similar code to take input value.

```cpp
cin >> ages[index];
```

In this case also, we can use a for loop.
