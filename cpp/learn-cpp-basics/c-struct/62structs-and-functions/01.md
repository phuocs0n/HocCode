# Create a Function Inside a Struct

#### Course: Learn C++ Basics

## Create a Function Inside a Struct

We can create a function inside a struct in the same way we create variables inside a struct. For example,

```cpp
struct Student {
    int marks_math;
    int marks_science;

    int total_marks() {
        return marks_math + marks_science;
    }
};
```

Here, we have created a function total_marks() inside the Student struct. Like with variables inside a struct, we can access this function using the dot operator ..

### Example

```cpp
1#include <iostream>
2using namespace std;
3
4struct Student {
5    int marks_math;
6    int marks_science;
7
8    int total_marks() {
9        return marks_math + marks_science;
10    }
11} student1;
12
13int main() {
14
15    // initialize struct variables
16    student1.marks_math = 79;
17    student1.marks_science = 94;
18
19    // call struct function
20    cout << "Total Marks: " << student1.total_marks();
21
22    return 0;
23}
24
25// Output:
26// Total Marks: 173
```

As you can see, we have called the function inside the Student struct with the code:

```cpp
student1.total_marks()
```
