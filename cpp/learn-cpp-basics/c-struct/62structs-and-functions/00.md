## Revise Function

Let's first revise the working of a function with an example.

```cpp
1#include <iostream>
2using namespace std;
3
4// function to add two numbers
5int add_numbers(int n1, int n2) {
6    int sum = n1 + n2;
7    return sum;
8}
9
10int main() {
11  
12    int number1 = 32;
13    int number2 = 44;
14
15    // function call
16    int result = add_numbers(number1, number2);
17    cout << "Result: " << result;
18  
19    return 0;
20}
21
22// Output:
23// Result: 76
```

In the above program, we have created an add_numbers() function that

- takes two parameters, n1 and n2 (input)
- add n1 and n2
- and return the sum (output)

Like regular variables (n1 and n2), we can also pass structs as arguments to functions.

In this lesson, we will learn to

- create a function inside a struct
- pass a struct to a function
- return a struct from a function
