## Store Information of a Student using Struct

In this example, we will learn to store information about students by using structures.

```cpp
1#include <iostream>
2using namespace std;
3
4struct Student {
5    string name;
6    int roll;
7    double marks;
8} student1;
9
10int main() {
11
12    // get information of for the student
13    cout << "Enter name: ";
14    getline(cin, student1.name);
15
16    cout << "Enter roll no: ";
17    cin >> student1.roll;
18
19    cout << "Enter marks: ";
20    cin >> student1.marks;
21
22
23    // print student info
24    cout << "Name: " << student1.name << endl;
25    cout << "Roll: " << student1.roll << endl;
26    cout << "Marks: " << student1.marks;
27
28    return 0;
29}
```

Output

```text
Enter name: John Connor
Enter roll: 213
Enter marks: 83
Name: John
Roll: 213
Marks: 83
```
