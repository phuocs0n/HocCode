## Example: C++ struct

```cpp
1#include <iostream>
2using namespace std;
3
4// create Person struct
5struct Person {
6    int age;
7    double salary;
8};
9
10int main() {
11
12    // create struct variable
13    struct Person person1;
14
15
16    // assign values to struct members
17    person1.age = 25;
18    person1.salary = 3465.78;
19
20    // print struct members
21    cout << "Age: " << person1.age << endl;
22    cout << "Salary: " << person1.salary;
23
24
25    return 0;
26}
```

Output

```text
Age: 25
Salary: 3465.78
```

Here, you can see that we have used

- person1.age - to assign and access the age member of person1
- person1.salary - to assign and access the salary member of person1
