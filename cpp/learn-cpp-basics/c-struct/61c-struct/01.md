## Create struct Variables

Suppose we have a struct like this,

```cpp
struct Person {
    int age;
    double salary;
};
```

Now, let's create a variable of the struct Person type.

```cpp
int main() {

    // create struct variables
    struct Person person1;
    struct Person person2;
}
```

If you look carefully, the syntax looks similar to creating regular variables.

```cpp
data_type variable_name;
```

where

- struct Person - represents data type
- person1/person2 - represents variable names

Now, we can use these struct variables to access members of the struct.

### Access struct Members

We use the . operator to access members of a struct.

Let's say we want to assign 25 to the age member using the person1 variable. Here's how we can do that

```cpp
// assign 25 to the person1's age
person1.age = 25;
```
