## Source Code: Insert Elements in a Doubly Linked List

```cpp
1 // Method to insert at any given position
2 void insert_at_position(T data, int position){
3    // Create a new node to append
4    Node<T>* new_node = new Node<T>({data});
5
6    // If the list is empty
7    // new_node is the head
8   if (head == nullptr){
9      head = new_node;
10      return;
11   }
12
13   // Call the helper method
14   // to insert at beginning 
15   if (position == 1) {
16       insert_at_beginning(data);
17   } 
18   // Append if invalid position is provided
19   else if (!position || position < 0 || position > get_length()){
20        append(data);
21   }
22   else {
23     int i = 1;
24     // Start from the head
25     Node<T>* current = head;
26
27     while (i < position - 1){
28        // Move to next node
29        current = current -> next;
30
31        ++i;
32     }
33     // Get a pointer to next node
34     Node<T>* next_node = current->next;
35
36     // new_node is next to current_node.
37     current->next = new_node;
38
39     // new_node is prev to next_node
40     next_node->prev = new_node;
41
42     // prev of new_node is current
43     new_node->prev = current;
44
45     // next of new_node is
46     // next of current node
47     new_node->next = next_node;
48   }
49 }
```

Output

```text
Original Linked List:
nullptr<->nullptr
Linked List After appending 80:
nullptr<->80<->nullptr
Linked List After Inserting 9 at the beginning:
nullptr<->9<->80<->nullptr
Linked List After Inserting 13 at the position 2:
nullptr<->9<->13<->80<->nullptr
```

In this example, we forward traversed to our desired node. If necessary, you can perform backward traversal to achieve the same thing.

In large doubly linked lists, you may choose whether to perform forward or backward traversal depending on the position.

We leave that up to you.
