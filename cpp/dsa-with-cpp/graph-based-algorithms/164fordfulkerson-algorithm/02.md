## Key Concepts

Let's get familiar with some common terms we will be using to solve the given problem with the Ford–Fulkerson algorithm.

- Flow Network: A directed graph where each edge has a capacity and each edge receives a flow. The amount of flow on an edge cannot exceed its capacity.
- Source and Sink: The source is the starting point where the flow originates, and the sink is the endpoint where the flow is collected.
- Residual Graph: This graph represents the remaining capacities of the network after considering the current flow. It is used to find augmenting paths.
- Augmenting Path: A path from the source to the sink in the residual graph where the capacity on all edges in the path is greater than zero.
