## Introduction

Counting sort is a way to arrange the items in a vector by counting how many times each item appears. We then put the elements in order based on those counts.

Here's how the algorithm works:

- Create a counting vector whose size is one more than the largest element in the unsorted vector.
- Fill each index of the counting vector with the number of occurrences of the corresponding value in the unsorted vector.
- Create a sorted vector using the value of each index in the counting vector.
