## Time Complexity

In a queue, operations like enqueue (adding an element to the rear), dequeue (removing an element from the front), and peek (peeking the element at front) take constant time. The size of the queue does not affect the time taken for these operations.

Therefore, all queue operations take constant time.

Time Complexity: O(1)
