## Thought Process

Like we did with stack, we'll be using a linked list to implement our queue as well.

Here's how we can do it.

1. Create the Queue.

First, we'll create a class to handle our queue.

```cpp
template< typename T>
class Queue {
  public:
    Queue() = default; // Defaulted constructor
    ~Queue() = default; // Defaulted destructor
```

Since, we'll be using a linked list to implement our queue, we'll add our LinkedList calls as a member variable.

```cpp
private:
    // Underlying linked list to store queue elements
    LinkedList<T> linked_list; };
```

2. Check if the Queue is empty.

Before we perform any operation in a queue, we must ensure it's not empty.

To check, if the queue is empty, we can simply check if the count of elements of the linked list is zero.

```cpp
bool is_empty() {
    return (linked_list.count_elements() == 0);
}
```

3. Implement a method to enqueue an element to the Queue.

To enqueue an element, we can use the insert_node_at_end() method of the linked list.

```cpp
// Enqueue an element to the queue
void enqueue(T item) {
    linked_list.insert_node_at_end(item);
}
```

4. Implement a method to dequeue an element from the Queue.

To dequeue an element, we can use the delete_first_node() method of the linked list.

However, attempting to dequeue an element from an empty queue will result in an error. So, we'll dequeue an element only if the queue is not empty.

```cpp
void dequeue() {
    if(!is_empty())
        linked_list.delete_first_node();
}
```

5. Implement a method to peek at the front element of the Queue.

To peek at the front element on the queue, we can use the get_first_element() method of the linked list.

```cpp
T peek() {
    return linked_list.get_first_element();
}
```

6. Implement a method to display all the elements of the queue.

To display all the elements of the queue, we can invoke the display() method of the linked list.

```cpp
void print_queue() {
    linked_list.display();
}
```
