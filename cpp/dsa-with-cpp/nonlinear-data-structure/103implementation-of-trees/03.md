## Thought Process: Implementation of Trees

Let's see how we can implement a tree data structure using C++.

As trees are a collection of nodes, we'll start with handling the operations of a single node.

1. Create a class to handle nodes.

A node contains:

- The value of the node.
- Information of children derived from that node.

So, we will create a class that includes:

- The value of the node.
- A vector to store pointers to its children.

```cpp
template <typename T>
class TreeNode {
public:

    TreeNode(T val): data(val) {}
        
    T data;
    vector<TreeNode<T>*> children;
};
```

2. Add children to a node.

After creating a node, we'll define a method to add children to it.

```cpp
void add_child(vector<TreeNode<T>*> child_arr) {
    children = child_arr;
}
```

3. Create a class to handle nodes in a tree.

Our TreeNode class will only handle operations related to a single node.

To handle all tree-related operations, we will create another Tree class. The class will:

- Store information of all the nodes in the tree.
- Establish the relations and hierarchies between them.

```cpp
template <typename T>
class Tree {
public:

    Tree(TreeNode<T>* root_node): root(root_node) {}

    TreeNode<T>* root {nullptr};
};
```
