## Working of Huffman Coding

Suppose we have the string BCAADDDCCACACAC.

To encode this string to contain only numeric values like 1000111110110110100110110110, we'll follow the given steps:

1. Create a Huffman Tree
2. Use the Huffman Tree to get the equivalent Huffman code to represent each character.
3. Replace each character in the string with its Huffman code.

We'll start by creating our Huffman tree.
