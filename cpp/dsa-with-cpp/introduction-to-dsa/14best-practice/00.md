## Best Practice

1. Use of std namespace

To avoid the repetitive std:: prefix, we have included using namespace std; in our code to make the code concise and easier to read.

However, you should not do that. Instead, use the std:: prefix to access the standard library component.

For example, we have followed the following style in our code:

```cpp
1#include <iostream>
2
3using namespace std;
4
5int main() {
6    cout << "Hello World!\n";
7    return 0;
8}
```

However, you should use the following style in your code.

```cpp
1#include <iostream>
2
3int main() {
4    std::cout << "Hello World!\n";
5    return 0;
6}
```

2. Use of Templates

To make sure our code runs equally regardless of the data types used, we will be using templates. Make sure you are comfortable with templates in C++.

3. Use of raw pointers

Though smart pointers are used instead of raw pointers in real-world projects, we have exclusively used raw pointers in this course. This is done to avoid the added layer of abstraction provided by smart pointers, so you can focus on the core principles of DSA.
