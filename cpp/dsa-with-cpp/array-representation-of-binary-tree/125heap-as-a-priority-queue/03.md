## Thought Process: Priority Queue

1. Create a priority queue.

We create the PriorityQueue class as a child of the MinHeap class.

```cpp
class PriorityQueue : public MinHeap {
    // Code
}
```

2. Insert, peek, and extract min in the priority queue.

We have already defined these methods in the min-heap implementation. So, we can simply use them in our PriorityQueue class.

```cpp
// Insert into priority queue
void insert(string task, int priority) {
    MinHeap::insert(make_pair(priority, task));
}

// Extract min from priority queue
pair<int, string> extract_min() {
    return MinHeap::extract_min();
}

// Peek at the highest priority task
pair<int, string> peek() {
    return MinHeap::peek();
}
```

Note: The elements of priority queues comprise of pairs (priority, task). So, to access the priority of the ith node, we use heap[i].first, since priority is the first item in the tuple.

Similarly, to access the ith task, we use self.heap[i].second.
