## Example: Priority Queue

```cpp
1// Change the priority (key) of an element
2// already in the priority queue
3void change_key(string value, int new_priority) {
4    for (int i = 0; i < size(); i++) {
5        if (heap[i].second == value) {
6            int old_priority = heap[i].first;
7            heap[i] = {new_priority, value};
8            if (new_priority < old_priority) {
9                heapify_up(i);
10            }
11            else {
12                heapify_down(i);
13            }
14            return;
15        }
16    }
17}
```
