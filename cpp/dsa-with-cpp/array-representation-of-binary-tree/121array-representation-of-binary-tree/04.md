## Thought Process: Array Representation

Let's see how array representation is implemented.

1. Find the parent index.

For any node at index in the array, the parent is located at index (index - 1) / 2.

```cpp
int parent(int index) {
    return (index - 1) / 2;
}
```

2. Find the child indices.

For any node at index i in the array:

- The left child is located at index 2i + 1.
- The right child is located at index 2i + 2.

```cpp
// Calculate the index of a node's left child
int left_child(int index) {
    return 2 * index + 1;
}

// Calculate the index of a node's right child
int right_child(int index) {
    return 2 * index + 2;
}
```

3. Check if the parent exists.

Since array indices start at 0, the root node (index 0) doesn't have a valid parent index. And, any other node with a positive index will have a non-negative parent index.

```cpp
bool has_parent(int index) {
    return parent(index) >= 0;
}
```

4. Check if a child exists.

In a binary tree represented as an array, a node's children are present if their indices are within the bounds of the array's length.

```cpp
// Check if a node at a given index has a left child
bool has_left_child(int index) {
    return left_child(index) < arr.size();
}

// Check if a node at a given index has a right child
bool has_right_child(int index) {
    return right_child(index) < arr.size();
}
```
