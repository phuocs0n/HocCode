## Source Code: Heap Sort

```cpp
1// Heap sort function
2vector<int> heap_sort(vector<int>& vec) {
3    vector<int> sorted_vector;
4    MinHeap heap;
5
6    for (int i : vec) {
7        heap.insert(i);
8    }
9
10    while (!heap.is_empty()) {
11        sorted_vector.push_back(heap.extract_min());
12    }
13
14    return sorted_vector;
15}
```

Output

```text
Sorted Array: 5 12 15 16 25
```

### Things to Remember

1. If you want to sort the vector in descending order, you can simply reverse the sorted vector using the following code:

```cpp
std::reverse(sorted_vector.begin(), sorted_vector.end());
```

2. If you use a max-heap instead of a min-heap, the normal sort would give the vector in descending order.

So, using std::reverse() will give the vector in ascending order.
