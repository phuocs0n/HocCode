## Thought Process: Heap Sort

We can sort a given vector using heap sort using the following steps.

1. Insert elements into a heap.

We'll first insert the elements of the vector into a heap so that the root contains the smallest element.

```cpp
for (int i : vec) {
    heap.insert(i);
}
```

2. Add root to the sorted vector.

Now we'll extract the root from the heap repeatedly and add it to sorted_vector.

```cpp
sorted_vector.push_back(heap.extract_min());
```

3. Repeat the previous step until the heap is empty.

After removing the current root, the new heap will have the smallest remaining element as the new root.

If we keep on removing the root until there are no elements left in the heap, our vector will be filled in sorted order.

```cpp
while (!heap.is_empty()) {
    sorted_vector.push_back(heap.extract_min());
}
```
