## Source Code: Append a Node

Here's the method to append a node:

```cpp

2void append(T data) {
3    Node<T>* new_node = new Node<T>({data});  // Create a new node
4    
5    // If list is empty, 
6    // new node is the head
7    if (head == nullptr) {  
8        head = new_node;
9        return;

12    
13    // Traverse to the end of the list
14    while (current->next != nullptr) {
15        current = current->next;

18    // Link the last node to the new node
19    current->next = new_node;
20}
```
