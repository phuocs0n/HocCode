## Find the Largest Number in a Linked List

To find the largest number in a linked list, we can follow these steps:

1. Assume head has the largest value

We start by Initializing a variable to store the maximum value.

Initially we assume that the head has the largest value.

```cpp
int largest = head->data;
```

2. Compare node value with the current largest value.

We then check to see if the current node value is greater than the largest value. If it is, assign the largest with the current node value.

```cpp
if (current->data > largest){
    // Set the current node value as the largest value
    largest = current->data;
}
```

3. Repeat step 2 until we reach the last node.

We traverse through the entire list and perform step 2 for every node we visit.

```cpp
while(current != nullptr){
    // Step 2
    if (current->data > largest){
        largest = current->data;
    }
    // Change the current position
    current = current->next;
}
```
