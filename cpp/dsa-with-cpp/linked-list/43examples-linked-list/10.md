## Thought Process: Reverse Elements of a Linked List

To reverse the elements of a linked list we can perform the following steps:

1. Create a vector to store the values of the node

To reverse the elements in a linked list, we first need to get all the values of the list.

So, let's create a vector to store the values of the list elements.

```cpp
vector<int> list_data;
```

2. Insert the node values into the vector

We traverse through the entire list and insert the node values into the vector.

```cpp
Node<T>* current = head;
while (current != nullptr){
    list_data.emplace_back(current -> data);
    current = current -> next;
}
```

3. Reverse the vector

Now that we have the values, we need to reverse their order. For this, we'll be using STL's reverse function.

```cpp
reverse(list_data.begin(), list_data.end());
```

4. Assign the reversed values to the nodes of the linked list.

We now need to update the node values on the linked list in the order they appear in the vector.

So, we'll start at the head node and change the value of each node.

```cpp
// Start from the head node
current = head;
// Iterate through the vector
for(int val: list_data){
    // Change the value of current node
    current->data = val;
    // Move to the next node
    current = current->next;
}
```
