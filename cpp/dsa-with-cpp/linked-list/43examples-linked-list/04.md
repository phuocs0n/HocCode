## Thought Process: Check if a Linked List is Sorted

We can perform the following steps to check if a linked list is sorted or not.

1. Create a pointer to track our position.

We start by creating a pointer current which keeps track of our position in the list. Initially, we'll set it to point at the head node.

```cpp
Node<T>* current = head;
```

2. Compare adjacent nodes.

We'll now compare the value of the current node with its next node.

If the current node value is greater than the next node value, the list is not sorted and we return from the function.

```cpp
if (current -> data > current -> next -> data) return false;
```

3. Repeat Step 2 until we reach the last node.

Now, we'll perform this comparison for every element in the list. For this we'll use a while loop.

```cpp
while(current->next != nullptr){    
     if (current->data > current->next->data) return false;
     // Move to the next node in the list
     current = current->next;
}
```
