## Thought Process: Remove Duplicates

To remove duplicates from a sorted linked list we can perform following steps:

1. Create a pointer to track our position.

To keep track of our current position in the list, we create a pointer that initially points to the head.

```cpp
Node<T>* current = head;
```

2. Check if the current node and next node have the same value.

We then check to see if the value at the current and the next node are the same. If they are, we simply delete the next node.

```cpp
// Check if the current node and the next node contain the same data
if(current->data == current->next->data) {
    // If they do, prepare to delete the next node
    Node<T>* node_to_delete = current->next;
    // Bypass the node to be deleted by pointing to the next of next
    current->next = node_to_delete->next;
    // Delete the duplicate node
    delete node_to_delete;
}
```

3. Repeat step 2 until we reach the last node.

Now we need to repeat the comparison for every element in the list. We'll do this using a while loop.

```cpp
while(current->next != nullptr)
```
