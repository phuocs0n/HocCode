## Source Code: Remove Duplicates From a Sorted Linked List

```cpp
1// Member function to remove duplicates from a sorted linked list
2void remove_duplicates(){
3    // If the list is empty, there is nothing to do
4    if (head == nullptr) return;
5    
6    // Start from the head of the list
7    Node<T>* current = head;
8    
9    // Continue to traverse the list until you reach the end
10    while(current->next != nullptr){
11        // Check if the current node and the next node contain the same data
12        if(current->data == current->next->data) {
13            // If they do, prepare to delete the next node
14            Node<T>* node_to_delete = current->next;
15            
16            // Bypass the node to be deleted by pointing to the next of next
17            current->next = node_to_delete->next;
18            
19            // Delete the duplicate node
20            delete node_to_delete;
21        } 
22        else {
23            // Move to the next node if there is no duplication
24            current = current->next;
25        }
26    }
27}
```
