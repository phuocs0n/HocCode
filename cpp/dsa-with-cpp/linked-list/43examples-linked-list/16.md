## Source Code: Reverse Linked List

```cpp
1// Reverse the entire linked list
2void reverse_linked_list() {
3    Node<T>* prev_node = nullptr;
4    Node<T>* current = head;
5    Node<T>* next_node = nullptr;
6    
7    // Continue the reversal until you reach the end of the list
8    while (current != nullptr) {
9            
10        next_node = current->next;  
11        // Reverse current node's pointer
12        current->next = prev_node;  
13        // Move prev_node and current one step forward
14        prev_node = current;        
15        current = next_node;
16    }
17    // Reset head to the new first element
18    head = prev_node;
19}
```

```text
After reversing:

```
