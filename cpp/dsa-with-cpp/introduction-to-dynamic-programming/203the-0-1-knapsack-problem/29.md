## Thought Process: DP Table

Now that we are all set, let's implement our DP table logic in C++.

1. Initialize the required variables.

First, we'll store our item weights and values in vectors and also define the capacity of the knapsack.

```cpp
// Initialize variables
vector<int> w = {2, 3, 6};
vector<int> v = {60, 100, 150};
int capacity = 5;
```

Here, w is a vector of item weights and v is a vector of their corresponding values.

2. Initialize the DP table.

Then, we create a table with the following dimensions:

```text
(number of items + 1) x (capacity + 1)
```

Each cell in this table is initialized to 0.

```cpp
vector<vector<int>> DP(w.size() + 1, vector<int>(capacity + 1, 0));
```
