## Introduction

Similar to linear search, binary search is used to find an element within a vector.

However, binary search can only be implemented in a sorted vector. If vector elements are unsorted, we need to sort them first.

Binary search works by repeatedly dividing the vector in half until the possible location of the item is narrowed down to just one.
