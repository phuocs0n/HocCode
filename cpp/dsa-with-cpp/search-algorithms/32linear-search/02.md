## Thought Process to Implement Linear Search

Now that we know how linear search works, let's see how we can implement it in C++.

1. Access all vector elements

In linear search, we need to compare the target value with every element in a vector.

To access every vector elements, we can use a for loop that runs up to the end of the vector:

```cpp
for (int i = 0; i < arr.size(); ++i) {
}
```

2. Compare target value with vector elements

If the target element matches with any vector element, we return the index of that element.

```cpp
for (int i = 0; i < arr.size(); ++i) {
    if (arr[i] == target) 
        return i;
}
```

3. Hand unsuccessful search.

If the target element doesn't exist in the vector, we return -1 to signify an unsuccessful search.

```cpp
for (int i = 0; i < arr.size(); ++i) {
    if (arr[i] == target) 
        return i;
}

return -1;
```
