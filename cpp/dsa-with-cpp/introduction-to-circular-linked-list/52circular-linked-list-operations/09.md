## Code: Insert at Given Position

The function to insert nodes at a given position will look like this:

```cpp
// Insert node at any given position(1-based index)
void insert_node_at_position(T data, int position){
    if (position == 1) {
        insert_at_beginning(data);
        return;
    }
    // Check if the position is valid
    if (!position || position < 0 || position > count_elements()){
        // Append the node if position is invalid.
        append_node(data);
        return;
    }
    // Create a new_node with the given data
    Node<T>* new_node = new Node<T>({data});
    // Currently we are at head.
    Node<T>* current = head;
    int i = 1;
    // Move to the position just before the given position
    while (i < position - 1){
           // Move to next node.
           current = current->next;
           ++i;
    }
    // Update pointers
    new_node->next = current->next;
    current->next = new_node;
}
```
