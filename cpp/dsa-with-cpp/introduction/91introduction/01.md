## String Matching

Strings are collections of characters used to represent textual data in programming.

They are typically enclosed within quotation marks, such as "Hello World" and "Data Structure".

A common operation with strings is string matching, also known as string searching, which involves finding a specific string, substring, or pattern within a text string.

For example, finding the "WO" sub-string within the "HELLO WORLD" string.
