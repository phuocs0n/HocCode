## Local Variables

Let's see how we can use the value returned by the function.

```cpp
1#include <iostream>
2using namespace std;
3
4int add_numbers(int n1, int n2) {
5
6    int result = n1 + n2;
7    return result;
8}
9
10int main() {
11
12    // call the function and store the returned value
13    int output = add_numbers(2, 5);
14    cout << output;
15
16    return 0;
17}
18
19// Output: 7
```

By using a return statement, we are not using the local variable directly. Instead, we are returning its value to the calling function.

Next, we will see why this concept of local variables is important.
