## Example: Fibonacci Series Using Recursion

In this example, we will create a program to find the number in the nth position of the Fibonacci series.

The Fibonacci series is a sequence where the next term is the sum of the previous two terms. The first two terms of the Fibonacci sequence are 0 and 1.

```cpp
Fibonacci sequence: 0, 1, 1, 2, 3, 5, 8, ...
```

A Fibonacci series of n numbers is:

```cpp
0, 1, 1, ... value at (n - 2), value at (n - 1), value at (n -1) + value at (n -2)
```

So,

```cpp
nth element = (n - 2)th element + (n - 1)th element
```

Now, let's try to think about this in a recursive way.
