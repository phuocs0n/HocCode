## Infinite Recursion With Arguments

Here is an example of infinite recursion with arguments.

```cpp
1#include <iostream>
2using namespace std;
3
4void print_numbers(int n) {
5    
6    cout << n << endl;
7
8    // recursive call
9    print_numbers(n);
10}
11
12int main() {
13
14    // initial function call
15    print_numbers(100);
16
17    return 0;
18}
```

Output

```text
100
100
100
100
...
```

Here, we have called the print_numbers() function with 100 as an argument.

In the first function call (original call):

- n is 100, which is printed.
- The print_numbers() function is called again with 100 as an argument.

In the function second call (first recursive call):

- n is 100 again, which is printed.
- The print_numbers() function is called again with 100 as an argument.

Essentially, this program will run continuously with 100 as an argument in each function call.
