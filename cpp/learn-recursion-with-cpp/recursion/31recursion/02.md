## Infinite Recursion With Changing Arguments

Here's a slight modification to the program we previously wrote:

```cpp
1#include <iostream>
2using namespace std;
3
4void print_numbers(int n) {
5
6    cout << n << endl;
7    
8    // argument is decreased by 1 in each recursive call
9    print_numbers(n - 1);
10}
11
12int main() {
13
14    print_numbers(100);
15    return 0;
16}
```

Output

```text
100
99
98
97
96
...
```

Here, we initially called the print_numbers() function with 100 as an argument.

In the first function call (original call):

- n is 100, which is printed.
- print_numbers(99) is called.

In the second function call (first recursive call):

- n is 99, which is printed.
- print_numbers(98) is called.

Essentially, the value of the argument is reduced by one in each subsequent function call.
