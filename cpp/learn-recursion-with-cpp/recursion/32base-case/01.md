## Base Case for Recursion

Consider the following program to print numbers:

```cpp
1#include <iostream>
2using namespace std;
3
4void print_numbers(int n) {
5
6    cout << n << endl;
7    print_numbers(n + 1);
8}
9
10int main() {
11
12    print_numbers(1);
13    return 0;
14}
```

Output

```text
1
2
3
...
```

This program displays numbers infinitely because it lacks a stopping condition.

Let's add a base case so that the program ends after displaying 2.

```cpp
1#include <iostream>
2using namespace std;
3
4void print_numbers(int n) {
5
6    // base case to terminate recursion
7    if (n == 3) {
8        return;
9    }
10
11    // execute code if base case is not met
12    cout << n << endl;
13    
14    // recursive call with increment
15    print_numbers(n + 1);
16}
17
18int main() {
19
20    print_numbers(1);
21    return 0;
22}
```

Output

```text
1
2
```

In this program, we have added the following base case:

```cpp
if (n == 3) {
    return;
}
```

If n is equal to 3, the function encounters the return statement, and the recursive call ends.
