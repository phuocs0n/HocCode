## Override Function of Parent Class

### Problem Description

Create a program to override the function of parent class.

Step 1

- Create a class named Vehicle with a display_info() function.
- Inside the function, print Four Wheeler or Two Wheeler.
- Create another class named Car that inherits from Vehicle.
- Inside the class, override the display_info() function and print Cars are Four Wheeler.

Step 2

- Inside main(), create an object of Car and call the display_info() function.

#### Example

```text
Expected OutputCars are Four Wheeler
```
