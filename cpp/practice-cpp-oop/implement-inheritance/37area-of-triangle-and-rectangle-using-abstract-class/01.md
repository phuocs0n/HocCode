## Area of Triangle and Rectangle Using Abstract Class

### Problem Description

Create a program to find the area of a triangle and a rectangle by creating an abstract class. The formulas to calculate the areas are:

```text
Area of Triangle = 0.5 * base * height
Area of Rectangle = length * breadth
```

Step 1

- Create a class named Polygon with a pure virtual function calculate_area().
- Derive the Triangle class from Polygon.
- Inside the class, create double variables base and height.
- Initialize these variables using a constructor initializer list.
- Then, create a double function calculate_area() that returns the area of the triangle.

Step 2

- Derive the Rectangle class from Polygon.
- Inside the class, create double variables length and breadth.
- Initialize these variables using a parameterized constructor.
- Then, create a double function calculate_area() that returns the area of the rectangle.

Step 3

- In main(), get double inputs for base, height, length, and breadth.
- Create an object of Triangle and pass base and height to its constructor.
- Create an object of Rectangle and pass length and breadth to its constructor.
- Call the calculate_area() functions of both objects and store their return values in the area_triangle and area_rectangle variables, respectively.
- Print area_triangle and area_rectangle.

#### Example

```text
Test Input5
2
6
3
```

```text
Expected Output5
18
```
