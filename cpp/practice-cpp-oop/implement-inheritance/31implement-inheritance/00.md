###### Practice:

## Implement Inheritance

### Problem Description

Create a program to implement inheritance.

Step 1

- Create a class named Animal with the eat() function.
- Inside the function, print I can eat.
- Create another class named Dog that inherits from the Animal class.
- Inside the class, create a function named dance() that prints Dancing Dog.

Step 2

- Inside the main() function, create an object of the Dog class.
- Using the object of Dog class, call eat() and dance() functions.

#### Example

```text
Expected OutputI can eat.
Dancing Dog.
```
