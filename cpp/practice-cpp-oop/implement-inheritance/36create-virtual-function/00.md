# Create Virtual Function

#### Course: Practice: C++ OOP

###### Practice:

## Create Virtual Function

### Problem Description

Create a program to create a virtual function.

Step 1

- Create a class named Animal with a virtual function introduce().
- Inside the function, print I am an animal..
- Create another class named Mammal that inherits from Animal.
- Inside the class, create a function named introduce() that prints I possess mammary glands..
- This function should override the virtual function in Animal. (Hint: use the override keyword in function definition).

Step 2

- In main(), create an object of the Mammal class named mammal.
- Then, create a pointer of Animal class named animal that points to the address of the mammal object.
- Call the introduce() function using the mammal object.

#### Example

```text
Expected OutputI possess mammary glands.
```
