## Override Function in Multiple Classes

### Problem Description

Create a program to override the same function in multiple classes.

Step 1

- Create a class named Animal with a function named display().
- Inside the function, print I am an animal.
- Inherit two classes named Dog and Cat from the same Animal class.
- Inside Dog, override display() to print I am a dog.
- Inside Cat, override display() to print I am a cat.

Step 2

- Inside the main(), create objects of both Dog and Cat classes.
- Call the display() function using the objects of both classes.

#### Example

```text
Expected OutputI am a dog
I am a cat
```
