## Areas of Triangle and Rectangle Using Friend Class

### Problem Description

Create a program to find the areas of a triangle and a rectangle using a friend class. The formulas to calculate the areas are:

```text
Area of Triangle = 0.5 * base * height
Area of Rectangle = length * breadth
```

Step 1

- Create a class named Triangle with two double variables base and height.
- Initialize these variables with a constructor initializer list.
- Finally, declare a friend class named Area.

Step 2

- Create a class named Rectangle with two double variables length and breadth.
- Initialize these variables with a constructor initializer list.
- Finally, declare a friend class named Area.

Step 3

- Create a class named Area.
- Inside the class, create a function named get_triangle_area() that takes a Triangle object and returns the area of the triangle.
- Create another function named get_rectangle_area() that takes a Rectangle object and returns the area of the rectangle.

Step 4

- In main(), get double inputs for base, height, length, and breadth.
- Create an object of Triangle and pass base and height to its constructor.
- Create an object of Rectangle and pass length and breadth to its constructor.
- Then, create an object of the Area class called area.
- Call the get_triangle_area() function of area by passing the Triangle object as its argument.
- Call the get_rectangle_area() function of area by passing the Rectangle object as its argument.
- Print both areas.

#### Example

```text
Test Input5
2
6
3
```

```text
Expected Output5
18
```
