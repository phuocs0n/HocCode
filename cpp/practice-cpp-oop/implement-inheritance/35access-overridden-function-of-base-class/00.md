## Access Overridden Function Base Class

### Problem Description

Create a program to access the overridden function of the Parent Class.

Step 1

- Create a class named Animal with a display() function.
- Inside the function, print I am an animal.
- Create another class named Dog that inherits from Animal.
- Inside the class, override the display() function to print I am a dog.
- Inside display() of Dog, call the display() function of Animal class using the :: operator.

Step 2

- Inside main(), create an object of the Dog class.
- Call display() using the object.

#### Example

```text
Expected OutputI am an animal
I am a dog
```
