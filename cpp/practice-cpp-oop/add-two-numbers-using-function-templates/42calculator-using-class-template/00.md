## Calculator Using Class Template

### Problem Description

Create a program to calculate two numbers using a class template.

Step 1

- Create a class template Calculator with two variables of T type: num1 and num2.
- Initialize these variables with a constructor initializer list.
- Inside the class, create a calculate() function that returns a T value and accepts a char variable op as an argument.
- If op = '+', return num1 + num2.
- If op = '*', return num1 * num2.
- Return 0.0 for any other operator.

Step 2

- In main(), create two integer variables n1 and n2, along with two double variables n3 and n4.
- Get inputs for the n1, n2, n3, and n4.
- Create a Calculator object called obj1 for integer type by passing n1 and n2 as arguments.
- Call the calculate() function of obj1 by passing '*' as an argument and storing the return value in the result1 variable.
- Then, create another Calculator object called obj2 for double type by passing n3 and n4 as arguments.
- Call the calculate() function of obj2 by passing '+' as an argument and storing the return value in the result2 variable.
- Print result1 and result2.

#### Example

```text
Test Input5
6
5.5
6.6
```

```text
Expected Output30
12.1
```
