## Implement Protected Inheritance

### Problem Description

Create a program to implement protected inheritance.

Step 1

- Create a class named Person with public string variables name and address.
- Derive an Employee class from Person in protected mode.
- Inside the Employee class, initialize name and address with the help of a constructor.
- Finally, create getter functions get_name() and get_address() to return the values of the variables.

Step 2

- In main(), get string input for name and address variables.
- Create an Employee object employee1 by passing name and address as arguments to its constructor.
- Print the name and address of employee1 by calling the getter functions.

#### Example

```text
Test InputPeter Parker
New York
```

```text
Expected OutputPeter Parker
New York
```
