## Area of Rectangle Using Constructor Overloading

### Problem Description

Create a program to calculate the area of rectangles using constructor overloading.

Step 1

- Create a class named Rectangle with integer variables length and breadth.
- Using a default constructor, set the length variable to 8.
- Create another constructor with two integer parameters and initialize length and breadth with those parameters.
- Create the calculate_area() function that returns the area of the rectangle.

Step 2

- Inside the main() function, get integer inputs for length and breadth.
- Create rect1 object by passing length and breadth as parameters to its constructor.
- Print its area by calling its calculate_area() function.
- Create another object rect2 without passing any arguments to its constructor.
- Assign the value of the breadth variable to the breadth variable of rect2.
- Print its area by calling its calculate_area() function.

#### Example

```text
Test Input6
4
```

```text
Expected Output24
32
```
