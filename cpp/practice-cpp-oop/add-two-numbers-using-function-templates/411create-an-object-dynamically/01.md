## Create an Object Dynamically

### Problem Description

Create a program to dynamically allocate memory to an object.

Step 1

- Create a class named Cube with an integer variable side.
- Create a constructor with an integer parameter side.
- Initialize the member variable side inside the constructor using the this pointer.
- Create a function calculate_volume() that returns the volume of the cube.

Step 2

- In main(), get integer input for the side variable.
- Dynamically create an object of Cube using the new operator.
- Pass the side variable as argument to the constructor of this object.
- Call the calculate_volume() function by using the -> operator.
- Store the return value of the function in the volume variable.
- Print volume.
- Deallocate the memory using delete.
