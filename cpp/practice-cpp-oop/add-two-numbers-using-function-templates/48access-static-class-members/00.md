## Access Static Class Members

### Problem Description

Create a program to access the static variable and function from main() function.

Step 1

- Create a class named College with a static variable name and static function display().
- Inside the function, print the value of name.
- Define the name variable outside the class (you can't access a static variable if you don't define it).

Step 2

- Inside the main() function, get string input for the input_name variable.
- Initialize the static variable name with the value input_name.
- Call the static function display().
