## Set And Get Salary Of An Employee

### Problem Description

Create a program to access and modify the salary of an employee using encapsulation.

Step 1

- Create a class named Employee with a private variable salary.
- Create a public setter function to set the salary of the employee.
- Create a public getter function to get the salary of the employee.

Step 2

- In main(), get a double input for the salary variable.
- Create an object of the Employee class.
- Call the setter function with the salary argument.
- Call the getter function and print the result.

```text
Test Input145323.9
```

```text
Expected Output145323.9
```
