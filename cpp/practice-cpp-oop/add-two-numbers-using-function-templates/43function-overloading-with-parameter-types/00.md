## Function Overloading With Parameter Types

### Problem Description

Create a program to overload a function with different types of parameters.

Step 1

- Create two functions having the same name add().
- The first add() function will take two integer parameters, perform addition and print the result.
- The second add() function will take two string parameters, join them and print the result.

Step 2

- Inside the main() function, get integer inputs for variables number1 and number2.
- Also, get string input for variables first and second.
- Call the add() function with arguments number1 and number2.
- Again call add() with arguments first and second.
