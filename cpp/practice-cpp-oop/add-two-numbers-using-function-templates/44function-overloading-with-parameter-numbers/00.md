## Function Overloading With Parameter Numbers

### Problem Description

Create a program to overload a function with different numbers of parameters.

Step 1

- Create two functions having the same name add_numbers()
- The first add_numbers() function will take two integer parameters, perform addition and print the result.
- The second add_numbers() function will take 4 integer parameters, perform addition and print the result.

Step 2:

- Inside the main() function, get integer inputs for variables n1, n2, n3, and n4.
- Call the add_numbers() function with arguments n1 and n2.
- Again call add_numbers() with arguments n1, n2, n3, and n4.

#### Example

```text
Test Input4
5
7
9
```

```text
Expected Output9
25
```
