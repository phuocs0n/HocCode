## Add Two Numbers Using Function Templates

### Problem Description

Create a program to add two numbers using function templates.

Step 1

- Create a function template add_numbers() with return type T and parameters num1 and num2 of T type.
- Inside the template, return the sum of num1 and num2.

Step 2

- Inside the main() function, create two integer variables n1 and n2, along with two double variables n3 and n4.
- Get inputs for the n1, n2, n3, and n4.
- Call the add_numbers() function for integer type by passing n1 and n2 as arguments. Store the return value in the sum_integer variable.
- Then, call the add_numbers() function for double type by passing n3 and n4 as arguments. Store the return value in the sum_double variable.
- Print sum_integer and sum_double.

#### Example

```text
Test Input5
6
5.5
6.6
```

```text
Expected Output11
12.1
```
