## Area of Square Using Encapsulation

### Problem Description

Create a program to calculate the area of a square using encapsulation.

Step 1

- Create a class named Square with a private variable length.
- Create a public setter function to initialize the value of length.
- Inside the setter function, use an if...else condition to check if the length parameter is greater than 0.
- If it's greater than 0, initialize the private variable with its value.
- Otherwise, print Length of a square cannot be less than 0. and set the value of length to 0.
- Create another function named calculate_area() to return the area of the square.

Step 2

- Inside the main() function, get integer input for the length variable.
- Create an object of Square.
- Call the setter function with the length argument.
- Call the calculate_area() function and store the return value in the area variable.
- Print area.
