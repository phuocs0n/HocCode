## Area of Two Triangles

### Problem Description

Create a program to find the area of two triangles.

The formula to compute the area of a triangle is:

```text
area = (base * height) / 2
```

Step 1

- Create a class named Triangle with integer variables base and height.
- Create a constructor with integer parameters b and h.
- Inside the constructor, initialize the base and height with values of b and h respectively.
- Create a function named calculate_area() to compute the area of triangle using the above formula and print it.

Step 2

- Inside the main() function, create an object t1 of the Triangle class with arguments 5 and 14.
- Call the calculate_area() function using the object.
- Create a second object t2 of Triangle with arguments 12 and 32.
- Call calculate_area() using the second object.

374
