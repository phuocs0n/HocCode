## Check if the Temperature is IcyHot

### Problem Description

Create a program to check if the temperature is IcyHot.

Step 1

- Create a class named Temperature with integer variables hot and cold to store temperatures.
- Initialize the value of these variables using a constructor.
- Create a function named check_icy_hot().
- Inside the function, if hot is greater than 100 and cold is less than 0, print IcyHot.

Step 2

- In main(), take integer input for variables hot and cold.
- Create an object of the Temperature class with arguments hot and cold.
- Call the check_icy_hot() function using the object.

#### Example

```text
Test Input300
-3
```

```text
Expected OutputIcyHot
```
