## Area of Rectangle

### Problem Description

Create a program to find the area of a rectangle.

The formula to compute the area of a rectangle is:

```text
area = length * breadth
```

Step 1

- Create a class named Rectangle with two integer variables length and breadth.
- Create a function named calculate_area() that computes the area using the above formula and prints it.

Step 2

- Inside the main() function, create an object of the Rectangle class named rect.
- Get two integer inputs for  length and breadth of rect.
- Call the calculate_area() function using the object.

#### Example

```text
Test Input9
3
```

```text
Expected Output27
```
