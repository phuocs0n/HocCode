## Get and Set Student Name

### Problem Description

Create a program to access and modify the private variable using getter and setter functions.

Step 1

- Create a class named Student with a private string variable name.
- Inside the class, create a public function set_name() with a string parameter, n.
- Inside the function, print Setting Name and initialize the value of name with the parameter.
- Create another public function named get_name().
- Inside the function, print Getting Name and return the value of name.

Step 2

- In main(), get a string input for the variable name.
- Create an object of the Student class.
- Use the object to call the set_name() function with the argument name.
- Call the get_name() function using the object and print the returned value.
