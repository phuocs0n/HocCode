## Find the Lowest Element From the Array

### Problem Description

- Create an integer array named numbers of size 5.
- Get input value for the array.
- Create an integer variable named lowest and assign the first element of the array to it.
- Run a for loop from i = 1 to i < 5.
- Inside the loop, if the element at i is less than lowest, assign that element to lowest.
- Finally, print the value of lowest.

#### Example

```text
Test Input13
23
9
31
19
```

```text
Expected Output9
```
