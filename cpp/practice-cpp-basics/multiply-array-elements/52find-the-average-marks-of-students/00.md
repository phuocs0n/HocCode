## Find the Average Marks of Students

### Problem Description

Create a program to find the average marks of a student.

- Create a double array named marks of size 4.
- Get input values from the user.
- Find the sum of all the elements present in the array.
- Divide the sum by 4.0 to find the average marks.
- Print the average.

#### Example

```text
Test Input96.5
72
45.5
39
```

```text
Expected Output63.25
```
