## Compute Standard Deviation

### Problem Description

Create a program to find the standard deviation.

Step 1:

- Create a function calculate_SD() with an array data as parameter.
- Inside the function, find the sum of all the array elements.
- Compute the mean of array elements.
- Find the difference of each array value and mean.
- Compute the square of each difference using pow().
- Add all the squared differences and assign to result.
- Compute the variance by dividing the result by 5.
- Compute the square root of variance using sqrt() and assign it to sd.
- Return sd.

Step 2:

- Inside main(), get 5 integer input values for an array numbers.
- Call calculate_SD() with the array as argument.
- Print the returned value.

#### Example

```text
Test Input9
12
21
11
14
```

```text
Expected Output4.128
```
