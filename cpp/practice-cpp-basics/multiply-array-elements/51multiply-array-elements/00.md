## Multiply Array Elements

### Problem Description

Create a program to multiply the elements of an array.

- Take integer input for the variable multiplier.
- Create an integer array numbers with the elements 4, 6, 8, 10.
- Use a for loop from i = 0 to i = 3.
- Inside the loop, multiply each array element by multiplier and print it.

#### Example

```text
Test Input10
```

```text
Expected Output40
60
80
100
```
