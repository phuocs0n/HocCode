## Compute the Area of Circle

### Problem Description

Create a program to compute the area of a circle using a function.

The formula to compute the area of a circle is:

```text
Area = 3.14 * radius * radius
```

Step 1:

1. Create the compute_area() function that accepts double parameters radius and pi.
2. Inside the function, compute the area of the circle and return it.

Step 2:

1. Inside main(), get a double input value for the radius of the circle.
2. Create a double variable named pi with value 3.14.
3. Call compute_area() with arguments radius and pi.
4. Print the returned value.

#### Example

```text
Test Input12.8
```

```text
Expected Output514.46
```
