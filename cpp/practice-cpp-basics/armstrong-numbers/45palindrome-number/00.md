## Check Palindrome Number

### Problem Description

Create a function to check if a number is palindrome or not.

A number is palindrome if the reverse of that number is equal to the original number. For example, 1001, 343, etc.

Step 1:

- Create a find_reverse() function that accepts an integer argument number.
- Inside find_reverse(), find the reverse of the number and return it.

Step 2:

- Inside main(), get an integer input for the number variable.
- Call the find_reverse() function with an argument number.
- Compare if the reversed number is the same as the original number.
- If true, the number is palindrome.
- Otherwise, the number is not palindrome.

#### Example

```text
Test Input1001
```

```text
Expected OutputPalindrome Number
```
