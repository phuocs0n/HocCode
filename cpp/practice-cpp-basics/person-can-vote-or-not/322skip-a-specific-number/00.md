## Skip a Specific Number

### Problem Description

Create a program to skip a specific number in a loop.

- Get integer input for the variable number.
- Using a for loop, loop from 0 to 5 (inclusive).
- Check if the number is equal to number.
- If so, skip the current iteration using continue.
- Otherwise, print current number in the iteration

#### Example

```text
Test Input3
```

```text
Expected Output0
1
2
4
5
```
