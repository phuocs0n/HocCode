## Check if a Number is Prime

### Problem Description

Create a program to check if a number is prime or not.

A prime number is defined as a number that can only be divided by 1 and itself. For example: 2, 3, 5, 7, etc.

- Create an integer variable count and assign the value 0 to it.
- Get integer input for the variable number.
- Using a for loop, loop from i = 1 to i = number.
- Inside the loop, if number is divisible by i, then increase the value of count by 1.
- Outside the loop, check the value of count.
- If it is equal to 2, print "prime". Else, print "not prime".
