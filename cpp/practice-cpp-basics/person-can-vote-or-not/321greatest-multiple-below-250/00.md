## Greatest Multiple of a Number Below 250

### Problem Description

Create a program to print the greatest multiple of a number that is less than or equal to 250.

- Get an integer input for the variable number.
- Using a for loop, loop from i = 250 to i = 0 backwards.
- Check if i is perfectly divisible by number.
- If so, print i and stop the iteration using break.

#### Example

```text
Test Input7
```

```text
Expected Output245
```
