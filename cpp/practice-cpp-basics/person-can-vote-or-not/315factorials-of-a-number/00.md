## Factorials of a Number

### Problem Description

Create a program to find the factorials of a number.

The factorial of a number N is the product of all the numbers from 1 to N.

```text
factorial = 1 * 2 * 3 * 4 * ... * N
```

- Get an integer input and assign it to the variable number.
- Declare another variable factorial and initialize it with value 1.
- Create a for loop that iterates from i = 1 to number.
- Inside the loop, update factorial by multiplying it by i.
- Outside the loop, print the value of factorial.

#### Example

```text
Test Input4
```

```text
Expected Output24
```
