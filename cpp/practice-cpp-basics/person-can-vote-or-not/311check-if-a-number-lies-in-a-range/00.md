## Check if a Number Lies in a Range

### Problem Description

Create a program to check if a given number falls in the given range.

- Get input for two int variables number and range.
- Create a bool variable in_range and assign  false to it.
- Run a for loop from i = 1 to i =  range.
- Check if number is equal to i.
- If number falls within range, change the value of in_range to true and break the loop.
- Outside the loop, print Within Range if the value of in_range is true.
- Else, print Out of Range.

#### Example

```text
Test Input25
12
```

```text
Expected OutputOut of Range
```
