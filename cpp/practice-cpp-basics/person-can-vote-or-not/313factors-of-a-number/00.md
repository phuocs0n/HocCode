## Print all Factors of a Number

### Problem Description

Create a program to find the factors of a number.

The factors of a number are all the numbers that can divide that number perfectly.

For example, the factors of 6 are 1, 2, 3, and 6 since all these numbers can divide 6 perfectly.

- Get an integer input and assign it to a variable number.
- Create a for loop that iterates from i = 1 to number.
- Inside the loop, check if number is perfectly divisible (remainder 0) by i.
- If so, print the value of i.

#### Example

```text
Test Input4
```

```text
Expected Output1
2
4
```
