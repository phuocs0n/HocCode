## Print the First N Numbers

### Problem Description

Create a program to print the first N numbers, i.e., from 1 to N.

- Get an integer input for the variable number.
- Use a for loop to loop from i = 1 to i = number.
- Inside the loop, print the value of i.

#### Example

```text
Test Input3
```

```text
Expected Output1
2
3
```
