## Sum of Natural Numbers

### Problem Description

Create a program to find the sum of first N natural numbers.

Natural numbers are positive integers i.e. 1, 2, 3, ... and the sum of natural numbers up to N is the total sum from 1 to N.

```text
sum of natural numbers = 1 + 2 + 3 + ... + N
```

- Get an integer input for the variable number.
- Declare another variable sum and initialize it with the value 0.
- Create a for loop that iterates from i = 1 to number.
- Inside the loop, update sum by adding it to i.
- Outside the loop, print the value of sum.
