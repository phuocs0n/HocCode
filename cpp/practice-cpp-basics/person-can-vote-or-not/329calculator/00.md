## Create a Calculator Using switch...case

### Problem Description

Create a program to that adds, subtracts, multiplies, or divides two variables based on the operator given by the user.

- Create two double variables number1 and number2.
- Assign the values 69.7 and 36.2436 to number1 and number2 respectively.
- Get character input for the variable operation.
- Using switch...case, perform the appropriate operations for the following operation values:
- '+' - addition (number1 + number2)
- '-' - subtraction
- '*' - multiplication
- '/' - division
- Print "Error!" for any other input.

Note: Use break; inside every case block except for the default block.
