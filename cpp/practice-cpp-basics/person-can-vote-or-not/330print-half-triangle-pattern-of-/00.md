## Print Half-Triangle Pattern of *

### Problem Description

Create a program to print a half-triangle pattern of *.

- Get input for num.
- Use a for loop from row = 1 to row = num.
- Inside this loop, use another for loop from column = 1 to column = row.
- Print "*" inside the second loop.
- Print a new line outside the second loop and inside the first loop.

#### Example

```text
Test Input5
```

```text
Expected Output* 
* * 
* * * 
* * * * 
* * * * *
```
