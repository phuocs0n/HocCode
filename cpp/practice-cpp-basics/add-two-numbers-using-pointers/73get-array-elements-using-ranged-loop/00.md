## Get Array Elements Using Ranged Loop

### Problem Description

Create a program to get array elements using a ranged loop.

- Create an integer array num of size 3.
- Using a ranged for loop, get input for the num array.
- Print the array elements using another ranged for loop.

Hint: Use the & operator with the data type to get the input.

#### Example

```text
Test Input25
36
47
```

```text
Expected Output25
36
47
```
