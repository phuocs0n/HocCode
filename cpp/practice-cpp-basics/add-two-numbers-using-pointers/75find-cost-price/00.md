## Find Cost Price

### Problem Description

Create a program to find the cost price by passing addresses to a function. The formula for finding the cost price is:

```text
Cost Price = Selling Price - Profit
```

Step 1

- Create a function calculate_CP() that accepts two double pointers ptr_sell and ptr_profit as its parameters.
- Inside the function, calculate the cost price by dereferencing the pointer parameters.
- Store the result in a double variable named cost_price.
- Return the value of cost_price.

Step 2

- In main(), get double input for selling_price and profit.
- Create a double variable cost_price and use it to call the calculate_CP() function.
- Pass the addresses of selling_price and profit as arguments to the function.
- Print the value of cost_price.

Assumption: The user input for selling_price is always greater than that for profit.

#### Example

```text
Test Input256.56
71.25
```

```text
Expected Output185.31
```
