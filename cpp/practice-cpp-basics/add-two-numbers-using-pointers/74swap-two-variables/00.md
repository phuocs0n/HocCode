## Swap Two Variables

### Problem Description

Create a program to swap two variables by passing its address to a function.

Step 1

- Create a function swap() that accepts two integer pointers ptr1 and ptr2 as its parameters.
- Inside the function, swap the numbers pointed to by ptr1 and ptr2.

Step 2

- In main(), get integer input for num1 and num2.
- Call the swap() function by passing the addresses of num1 and num2 as arguments.
- Print num1 and num2.

#### Example

```text
Test Input25
36
```

```text
Expected Output36
25
```
