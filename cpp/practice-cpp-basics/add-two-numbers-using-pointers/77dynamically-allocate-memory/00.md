## Dynamically Allocate Memory

### Problem Description

Create a program to dynamically allocate memory to a variable.

- Create an integer pointer ptr and dynamically allocate memory to it using the new operator.
- Get integer input for the memory in ptr by dereferencing it.
- Print the value by dereferencing ptr.
- Deallocate the memory using the delete operator.
