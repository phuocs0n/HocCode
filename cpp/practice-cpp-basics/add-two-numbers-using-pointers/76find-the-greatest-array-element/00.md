## Find the Greatest Array Element

### Problem Description

Create a program to find the greatest element in an array.

Step 1

- Create a function find_greatest() that takes an integer array num[] of size 3 as an argument.
- Inside the function, check if the first element is the greatest.
- If it is, return the address of the first element.
- If it isn't, check if the second element is greatest.
- If it is, return the address of the second element.
- Else, the third element is greatest. So return its address.

Step 2

- In main(), create an integer array num[] of size 3.
- Get input for all 3 elements.
- Call the find_greatest() function and store its return value in the integer pointer ptr.
- Print the greatest element by dereferencing ptr.

#### Example

```text
Test Input56
45
68
```

```text
Expected Output68
```
