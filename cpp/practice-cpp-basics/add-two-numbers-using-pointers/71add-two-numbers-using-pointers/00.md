## Add Two Numbers Using Pointers

### Problem Description

Create a program to add two numbers using pointers.

- Create two integer variables num1 and num2.
- Then, create two integer pointers ptr1 and ptr2 to point to num1 and num2, respectively.
- Get input for num1 and num2 using the pointers.
- Add num1 and num2 using the pointers and print the sum.

Hint: Use the dereference operator *.

#### Example

```text
Test Input5
6
```

```text
Expected Output11
```
