## Create an Array Dynamically

### Problem Description

Create a program to dynamically allocate memory to an array.

- Declare an integer n and a pointer marks.
- Get input for n.
- Allocate memory to marks of size n using the new operator.
- Get n inputs for marks using a for loop that runs from i = 0 to i = n -1.
- Print the values stored in addresses of marks in separate lines using another for loop.
- Deallocate the memory using delete.

#### Example

```text
Test Input3
1
2
3
```

```text
Expected Output1
2
3
```
