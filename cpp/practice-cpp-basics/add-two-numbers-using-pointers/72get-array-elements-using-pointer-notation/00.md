## Get Array Elements Using Pointer Notation

### Problem Description

Create a program to get array elements using pointer notation.

- Create an integer array num of size 3.
- Using a for loop, get input for the num array using pointer notation.
- Print the array elements using pointer notation in another for loop.

Hint: Use the dereference operator *.

#### Example

```text
Test Input25
36
47
```

```text
Expected Output25
36
47
```
