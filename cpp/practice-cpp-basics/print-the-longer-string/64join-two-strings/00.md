## Join Two Strings Using append()

### Problem Description

- Create two string variables named text1 and text2.
- Get input value for both variables using getline() function.
- Use append() function with text1 to join two strings.
- Make sure to insert a space between two strings while joining them.
- Print the joined strings i.e. text1.
