## Count the Frequency of a Character in a String

### Problem Description

- Get string input for a variable named text.
- Get character input for a char variable named character.
- Find the length of the input string.
- Run a for loop to access each character of the string.
- Inside the loop, check if the character matches the input character character.
- If true, increase the value of a count variable by 1.
- Finally print the count.
