## Count the Number of Vowels

### Problem Description

- Get input value for a string variable using getline().
- Create an integer variable named vowels with initial value 0.
- Create a char variable character.
- Run a loop to access each character of the string.
- Inside the loop, convert the string character to lowercase using the tolower() function and store it in the character variable.
- Now, check if character is a lowercase vowel or not.
- If it is, then increase the value of vowels by 1.
- Print the value of vowels outside the loop.
