## Convert a String to Uppercase

### Problem Description

- Get input value for a string variable using getline().
- Run a loop to access each character of the string.
- Inside the loop, convert the string character to uppercase using the toupper() function.
- Print the string variable outside the loop.

Note: The syntax of the toupper() function is:

```text
toupper(character);
```

#### Example

```text
Test InputIron Maiden
```

```text
Expected OutputIRON MAIDEN
```
