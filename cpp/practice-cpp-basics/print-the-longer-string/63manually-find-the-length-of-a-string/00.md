## Manually Find the Length of a String

### Problem Description

- Get a string input for the variable named text using getline() function.
- Create a count variable with initial value 0.
- Use a for loop to loop through the whole string. (Hint: loop from i = 0 to text[i] != '\0').
- Inside the loop, increase the value of count by 1.
- Print the count.

Note: The syntax of the getline() function is:

```text
getline(cin, variable_name);
```
