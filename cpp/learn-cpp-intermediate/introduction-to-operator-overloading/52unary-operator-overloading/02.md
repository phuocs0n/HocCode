## Unary Operator Overloading

Before overloading the unary operator let's look at it syntex:

```cpp
return_type operator operator_symbol(arguments) {
    // your code
}
```

Here,

- return_type can be void, built-in types (int, double, char, etc.), or custom types such as objects or struct variables.
- operator is the name of the overloading function, and is used to denote that we are overloading an operator.
- operator_symbol is the operator we want to overload, such as ++, --.
- arguments are the arguments passed to the operator() function.

Now, let's use the above syntax in the Person class we introduced in the previous page.

```cpp
class Person {
    ... ... ...

    void operator ++ () {
        ++age;
    }

    ... ... ...
};
```

The above code overloads the ++ operator inside the Person class. This overloaded operator increments the age variable of Person and doesn't return any value.
