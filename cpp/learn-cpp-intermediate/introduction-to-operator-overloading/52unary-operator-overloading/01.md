## Unary Operator With Objects

```cpp
1#include <iostream>
2using namespace std;
3
4class Person {
5public:
6    int age;
7
8    // constructor to initialize age
9    Person(int input) : age(input) {}
10};
11
12int main() {
13
14    Person person(5);
15    
16    // attempt to use ++ to increment person 
17    ++person;  
18
19    cout << "Age: " << person.age << endl;
20
21    return 0;
22}
```

Output

```cpp
ERROR!   17 |     ++person;
      |     ^~~~~~~~
```

The C++ unary increment operator ++ is designed to work with predefined data types such as integers, floating-point numbers, and other built-in types.

Since Person is a custom class and not a predefined data type, C++ does not inherently know how to increment the value of a Person object using the unary increment operator.

To enable this functionality, the operator needs to be explicitly overloaded for the Person class, defining how the increment operation should be performed on Person objects.
