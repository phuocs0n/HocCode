## Self-Study: Adding Extra Features

The program we just completed is merely the bare-bones version of a complex calculator. To further enhance the program, you can add the following features to your code:

- User input for both the complex numbers and the operator.
- do...while loop that won't stop until the user enters the correct operator.
- Add a new method that performs all mathematical operations (addition, subtraction, multiplication, and division). The user can then decide whether to perform a single operation by supplying an operator, or if they want to view the results of all operations.

This concludes our small project on complex calculations. Next, we'll build a word-guessing game called Hangman.
