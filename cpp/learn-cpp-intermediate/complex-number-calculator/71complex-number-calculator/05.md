## Step 3: Adding Functionality to display_result()

The display_result() method prints the result based on two things: the imaginary value of the result and the operation performed.

- Parameters - A Complex object result and a char parameter op
- Return Value - string in the format of real + imag i or result - imag i

Now, let's complete this function inside the Complex class:

```cpp
class Complex {
public:

    double real;
    double imag;
    
    Complex() : real(0.0), imag(0.0) {}
    
    Complex(double real, double imag) {
        this->real = real;
        this->imag = imag;
    }
    
    Complex operator + (Complex arg) {    
        Complex complex_sum;
        complex_sum.real = this->real + arg.real;
        complex_sum.imag = this->imag + arg.imag;
        return complex_sum;
    }
    
    Complex operator - (Complex arg) {        
        Complex complex_difference;
        complex_difference.real = this->real - arg.real;
        complex_difference.imag = this->imag - arg.imag;        
        return complex_difference;
    }
    
    Complex operator * (Complex arg) {        
        Complex complex_product;
        complex_product.real = (this->real * arg.real) - (this->imag * arg.imag);
        complex_product.imag = (this->real * arg.imag) + (this->imag * arg.real);        
        return complex_product;
    }
    
    Complex operator / (Complex arg) {        
        Complex complex_division;        
        double denominator = pow(arg.real, 2) + pow(arg.imag, 2);
        complex_division.real = ((this->real * arg.real) + (this->imag * arg.imag)) / denominator;
        complex_division.imag = ((this->imag * arg.real) - (this->real * arg.imag)) / denominator;               
        return complex_division;
    }


    // method to return the result
    string get_result() {

        // variable to store the result
        string result;

        // only return real if imaginary part is 0
        if (imag == 0) {
            result = to_string(real);
        }


        // return string "real - imagi" if imag is negative
        else if (imag < 0) {
            result = to_string(real) + " - " + to_string(abs(imag)) + "i";
        }

        // return string "real + imagi" if imag is positive
        else {
            result = to_string(real) + " + " + to_string(imag) + "i";
        }
        
        return result;
    }

};
```

Since display_result() returns a string, we have used the to_string() function to convert real and imag to string.

We have also used the abs() function to return the absolute value of imag when its value is negative. As a result, the - sign won't be repeated twice in the result.
