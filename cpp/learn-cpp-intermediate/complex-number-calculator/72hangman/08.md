## Step 1.3: Defining the Message Methods (II)

#### The invalid_character_message() Method

The invalid_character_message() method is invoked whenever the player tries to enter a non-alphabetic character.

```cpp
void invalid_character_message() {
    cout << "\nInvalid character!" << endl;
    cout << "Input must be an alphabet!" << endl;
}
```

#### The already_entered_message() Method

The already_entered_message() method is called whenever the player tries to enter a letter more than once.

```cpp
void already_entered_message() {
    cout << "\nYou have already entered this letter!" << endl;
    cout << "Enter another letter!" << endl;
}
```

#### The correct_message() and incorrect_message() Methods

The correct_message() method is called if the guess made by the player is correct.

```cpp
void correct_message() {
    cout << "\nCorrect!" << endl;
}
```

The incorrect_message() method is called if the guess made by the player is incorrect.

```cpp
void incorrect_message() {
    cout << "\nIncorrect!" << endl;
}
```

#### The final_result() Method

This method displays the final result. Thus, it is only called after the game ends.

```cpp
void final_result(string user_answer, string word) {

    // display user_answer
    cout << "Your Answer: ";
    for (char c: user_answer) {
        cout << c << " ";
    }
    cout << endl << endl;

    // win message
    if (user_answer == word) {
        cout << "-----------------------------------------------" << endl;
        cout << "\t\t\t\tY O U W I N!" << endl;
        cout << "-----------------------------------------------" << endl;
    }

    // loss message
    else {
        cout << "The correct answer is: " << word << endl << endl;
        cout << "-----------------------------------------------" << endl;
        cout << "\t\t\t\tY O U L O S E!" << endl;
        cout << "-----------------------------------------------" << endl;
    }
}
```

Here,

- user_answer - the string containing the answer guessed by the user
- word - the string containing the mystery word i.e. the correct answer

The win message is displayed if user_answer matches word, otherwise we display the loss message.
