## Step 1.5: Modeling the Game Class

Now, let's create a class for handling the actual gameplay. It needs to perform the following functions:

- Check if the entered character is valid.
- Check if the guess is correct or not.
- Check when the game ends.
- Call methods from the Message class to display the game status and the final result.

#### Attributes

The game class will have the following attributes:

- string word - stores the chosen word
- string user_answer - stores the answer uncovered by the player
- string incorrect - store the incorrect guesses made by the player
- string entered_characters - stores all the alphabetic characters entered by the player
- int misses - stores the number of incorrect guesses made by the player
- Message message - a Message object to display appropriate messages inside the appropriate methods

Now, let's create a method to initialize the attributes.

#### The Game() Constructor

This parameterized constructor initializes all the attributes of the game class.

```cpp
Game(string chosen_word) {
    word = chosen_word;
    incorrect = "";
    entered_characters = "";
    misses = 0;

    // create a string of underscores
    // having length equal to word.length()
    for (int i = 0; i < word.length(); ++i) {
        user_answer += "_";
    }
}
```

Here,

- word is initialized with chosen_word which is the word chosen by the computer for the game
- user_answer is initialized with the number of dashes equal to the length of word
- incorrect and entered_characters are initialized as empty strings
- misses is initialized as 0
