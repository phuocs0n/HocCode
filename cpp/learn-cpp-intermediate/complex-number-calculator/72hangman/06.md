## Step 1.1: Modeling the Message Class

First, let's start by modeling the Message class. We need to display the following messages during the gameplay:

- Begin by greeting the player.
- Display the number of remaining misses before the player loses.
- Show a list of both correct and incorrect guesses made by the player.
- Notify the player if they enter an invalid character.
- Inform the player if they attempt to enter a letter repeatedly.
- Display the final result.

Now let's start creating methods in the Message class to perform the tasks listed above.
