## Step 1.6: Defining Game Methods

#### The is_guess_valid() Method

The is_guess_valid() method takes a character argument, checks if it is an alphabet, and returns false if it is not.

Additionally, it checks if the character has already been entered by the user before. If so, it also returns false along with a corresponding message.

If the guess is valid, it returns true.

```cpp
bool is_guess_valid(char letter) {

    // check if letter is an alphabet
    if (!isalpha(letter)) {
        message.invalid_character_message();
        return false;
    }

    // check if the user has already entered the letter
    for (int i = 0; i < entered_characters.length(); ++i) {            
        if (letter == entered_characters[i]) {
            message.already_entered_message();
            return false;
        }
    }

    // return true if valid
    return true;
}
```

#### The is_guess_correct() Method

If letter is a correct guess, this method updates the user_answer string and calls the correct_message() method of the message object.

Otherwise, it updates the incorrect string, increments misses, and triggers the incorrect_message() method of the message object.

Regardless of the guess's correctness, it adds letter to the entered_characters string.

```cpp
void is_guess_correct(char letter) {

    bool guess = false;

    // check if the guess is correct
    for (int i = 0; i < word.length(); i++) {
       if (letter == word[i]) {
            user_answer[i] = letter;
            guess = true;
        }
    }

    // display message if correct
    if (guess) {
        message.correct_message();
    }

    // if incorrect, display incorrect message
    // then update incorrect string and
    // increment misses variable
    else {
        message.incorrect_message();
        incorrect += letter;
        incorrect += ", ";
        ++misses;
    }

    // update entered_characters
    entered_characters += letter;
}
```

#### The is_game_over() Method

The is_game_over() method returns true if the player guesses the word correctly or if the number of maximum allowed misses is exceeded. Otherwise, it returns false.

```cpp
bool is_game_over() {
    if (user_answer == word || misses >= max_misses) {
        return true;
    }
    return false
}
```

#### The display_game_status() Method

This method calls the display_incorrect_message(), display_user_answer(), and display_misses() methods of the message object to display the game status and the number of misses remaining.

```cpp
void display_game_status() {
    message.display_incorrect_guesses(incorrect);
    message.display_user_answer(user_answer);
    message.display_misses(misses);
}
```

#### The display_final_result() Method

This method calls the final_result() method of the message object to display the final result.

```cpp
void display_final_result() {
    message.final_result(user_answer, word);
}
```
