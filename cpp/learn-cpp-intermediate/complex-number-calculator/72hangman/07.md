## Step 1.2: Defining the Message Methods (I)

#### The greet() Method

This method displays the welcome message to the player.

```cpp
void greet() {
    cout << "------------------------------" << endl;
    cout << "\t\tH A N G M A N" << endl;
    cout << "------------------------------" << endl;
    cout << "Guess the Word" << endl << endl;
}
```

#### The display_misses() Method

This method displays the number of misses a player can make before the player loses.

```cpp
void display_misses(int misses) {
    cout << "Remaining misses: "<< max_misses - misses << endl << endl;
}
```

Here, max_misses is a global variable with a value of 6.

```cpp
const int max_misses = 6;
```

This means that the game ends after the player makes 6 misses.

#### The display_incorrect_guesses() Method

This method displays all the incorrect letters guessed by the player so far.

```cpp
void display_incorrect_guesses(string incorrect) {
    cout << "Incorrect Guesses: " << incorrect << endl;
}
```

#### The display_user_answer() Method

This method displays the answer uncovered by the player so far

```cpp
void display_user_answer(string user_answer) {
    cout << "Your Answer: ";

    for (char c: user_answer) {
        cout << c << " ";
    }

    cout << endl;
}
```
