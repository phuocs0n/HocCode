## Organizing the Project

Before starting to code, let's first organize our project into 3 different stages: starting from a simple, bare-bones game and progressing to a complete game with optimized features.

| Stage | Description | Primary Focus |
| --- | --- | --- |
| 1 | Text-based hangman game with minimal user interface and only a single word in the word database. | Logic of the game |
| 2 | Game consists of multiple possible mystery words in the word database. | Random number generation to select a random word |
| 3 | Finishing the Project with full UI features. | Improving UI by adding text-based graphics |

We have divided our project into these stages to ensure effective development.

Each stage focuses on a specific aspect of the program, allowing us to create functional programs while addressing one or two key elements at a time.

To enhance our programming logic and code organization, we further break down each stage into multiple steps.
