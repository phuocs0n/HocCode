## Project Description and Requirements

#### Project Description

Here's how our project works:

- This game will be played between the computer and a player.
- The computer will randomly select a word from a list of words.
- The player will then try to guess the word by entering letters one at a time.
- For each correct guess, the computer will fill in the letter in the correct place in the word.
- For each incorrect guess, the computer will draw a part of a hangman.
- The game ends when the player has guessed all of the letters in the word or when the hangman is complete.
- If the player guesses all of the letters in the word before the hangman is complete, they win.
- If the hangman is complete before the player has guessed all of the letters in the word, they lose.

#### Requirements

- Word Database: The game should have a database of words from which a random word can be selected for each round of the game.
- Game Mechanics: The program should display the word as a series of underscores (representing the hidden letters) and allow players to guess letters one at a time.
- Correct Guesses: When a player guesses a correct letter, the program should reveal all occurrences of that letter in the word and update the displayed word accordingly.
- Incorrect Guesses: For each incorrect guess, the program should update the hangman figure by adding a body part. This indicates the number of incorrect guesses remaining before the player loses the game.
- Win Condition: The player should win the game if they successfully guess all the letters in the word before running out of guesses.
- Loss Condition: The player should lose the game if they exhaust all the allowed incorrect guesses before guessing the word correctly.
- User Interface: The game should provide a user-friendly interface to display the hangman figure, the word, the letters guessed, and the number of remaining guesses.
- User Input Validation: The program should validate user inputs, ensuring that only non-repetitive alphabetic characters are accepted as valid guesses.
