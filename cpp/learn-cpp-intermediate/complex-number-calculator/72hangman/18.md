## Stage 3: Source Code

Before we add the artwork to our program, we first need to make some minor changes to the display_game_status() and display_final_result() methods of the Game class.

#### The display_game_status() Method

This is how the method looked in the previous stages:

```cpp
// method used in previous stages
void display_game_status() {
    message.display_incorrect_guesses(incorrect);
    message.display_user_answer(user_answer);
    message.display_misses(misses);
}
```

In this stage, we'll call message.display_misses() first instead of last:

```cpp
// method to use in Stage 3
void display_game_status() {
    message.display_misses(misses);
    message.display_incorrect_guesses(incorrect);
    message.display_user_answer(user_answer);
}
```

We have done this for aesthetic reasons: it just looks better to display the artwork first and then display the incorrect guesses and the user's answer.

#### The display_game_status() Method

This is how the method looked in the previous stages:

```cpp
// method used in previous stages
void display_final_result() {
    message.final_result(user_answer, word);
}
```

Now, we will also call message.display_misses() before calling message.final_result(). If we don't do this, then the complete hanged man artwork will not be displayed when you lose the game.

```cpp
// method used in previous stages
void display_final_result() {
    message.display_misses(misses);
    message.final_result(user_answer, word);
}
```

187        entered_characters = "";
188        misses = 0;
189
190        for (int i = 0; i < word.length(); ++i) {
191            user_answer += "_";
192        }
193    }
194
195    // method to ensure that user input is
196    // an alphabet and not a previous input
197    bool is_guess_valid(char letter) {
198
199        if (!isalpha(letter)) {
200            message.invalid_character_message();
201            return false;
202        }
203
204        for (int i = 0; i < entered_characters.length(); ++i) {            
205            if (letter == entered_characters[i]) {
206                message.already_entered_message();
207                return false;
208            }
209        }
210
211        return true;
212    }
213
214    // method to check if guess is correct
215    void is_guess_correct(char letter) {
216
217        bool guess = false;
218
219        for (int i = 0; i < word.length(); i++) {
220            if (letter == word[i]) {
221                user_answer[i] = letter;
222                guess = true;
223            }
224        }
225
226        if (guess) {
227            message.correct_message();
228        }
229        else {
230            message.incorrect_message();
231            incorrect += letter;
232            incorrect += ", ";
233            ++misses;
234        }
235
236        entered_characters += letter;
237    }
238
239    // method to check if the game is over
240    bool is_game_over() {
241        if (user_answer == word || misses >= max_misses) {
242            return true;
243        }
244        return false;
245    }
