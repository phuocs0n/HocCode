## Example 1: Exception Handling

```cpp

2using namespace std;
3
4int main() {
5
6        double numerator, denominator;

10        
11
12    try {
13
14
15        cout << "Enter denominator: ";
16        cin >> denominator;
17
18
19        // throw an exception if denominator is 0

21            throw 0;
22

29

33
34

```

Here, the exception occurs if the denominator is 0. Let's see how this program works for different values of denominator.

Output when denominator is not 0

```text
Enter numerator: 2
Enter denominator: 1
Result: 2
```

In this case, exceptions do not occur. Hence, the catch block is skipped.

Output when denominator is 0

```text
Enter numerator: 4
Enter denominator: 0
Denominator cannot be 0. Try again.
```

In this case, an exception is raised because of the following code:

```cpp
if (denominator == 0)
    throw 0;
```

When the exception occurs, the code after it is ignored, and the catch block is executed.
