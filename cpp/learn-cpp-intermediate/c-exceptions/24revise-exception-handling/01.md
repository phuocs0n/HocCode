## Summary II

Now, let's revise standard exceptions in C++.

### Standard Exceptions

These exceptions are defined in the <exception> header file.

In this chapter, we learned the following standard exceptions classes:

| Exception Class | Description |
| --- | --- |
| std::bad_alloc | Exception class to be used when allocating excessive memory. |
| std::exception | Parent class used to catch all standard exceptions. |

If we include the using namespace std; code in our program, we can simply write these classes as:

- bad_alloc
- exception

### C++ bad_alloc

We use the bad_alloc exception class when we try to allocate excessive memory to a dynamically declared array. For example,

```cpp
1#include <iostream>
2#include <exception>
3using namespace std;
4
5int main() {
6
7    try {
8
9        int* ptr = new int[1000000000000000];
10
11        delete[] ptr;
12    }
13
14    catch (bad_alloc e) {
15
16        cout << "Cannot allocate memory!!";
17    }
18
19    return 0;
20}
21
22// Output: Cannot allocate memory!!
```

### C++ std::exception

We can use the exception class to catch any standard or non-standard exceptions.

We need to throw the exception() function to the catch block if we want to manually throw an exception.

```cpp
// catch a bad_alloc exception using exception class
try {
    int* ptr = new int[1000000000000000];
    delete[] ptr;
}

catch (exception e) {

    cout << "Cannot allocate memory!!";
}

// catch a non-standard exception
try {
    int numerator = 10, denominator = 0;


    if (denominator == 0)
        throw exception();


    int result = numerator / denominator;
    cout << result;
}

catch (exception e) {

    cout << "Error! Cannot divide by 0";
}
```

### The what() Function

The what() function returns the error message of the exception class whose object is calling the function. For example,

```cpp
1#include <iostream>
2#include <exception>
3using namespace std;
4
5int main() {
6
7    try {
8        int* ptr = new int[1000000000000000];
9        delete[] ptr;
10    }
11    catch (bad_alloc e) {
12
13        cout << e.what();
14
15    }
16
17    return 0;
18}
19
20// Output: std::bad_alloc
```
