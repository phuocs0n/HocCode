## C++ std::exception

We can also use the exception class to catch standard exceptions (or even non-standard ones). Let's explore this by rewriting the bad_alloc program of the previous section.

```cpp
1#include <iostream>
2#include <exception>
3using namespace std;
4
5int main() {
6
7    try {
8        // allocate excessive memory to dynamically created array
9        int* ptr = new int[1000000000000000];
10
11        // deallocate the memory
12        delete[] ptr;
13    }
14
15
16    // catch exception if excessive memory is allocated
17    // use object of exception class as catch argument
18    catch (exception e) {
19
20        cout << "Cannot allocate memory!!" << endl;
21
22        cout << "Error: " << e.what() << endl;
23
24    }
25
26    return 0;
27}
```

Output

```text
ERROR!
Cannot allocate memory!!
Error: std::exception
```

As you can see, the program works just fine when we replace the bad_alloc object with an exception object.

And since we're using the exception class, the what() function returns the string std::exception instead of std::bad_alloc.
