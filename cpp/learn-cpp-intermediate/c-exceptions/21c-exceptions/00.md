## Errors and Exceptions

You might have run into errors numerous times while programming. These errors are of two types:

1. Syntax errors

These errors are caused because of improper use of the C++ syntax, such as missing semicolons, wrong spelling, etc. For example,

```cpp
1#include <iostream>
2using namespace std;
3
4int main() {
5
6    cout << "Hey"
7
8    return 0;
9}
```

Output

```cpp
ERROR!    6 |     cout << "Hey"
      |                  ^
      |                  ;
    7 | 
    8 |     return 0;
      |     ~~~~~~
```

Here, we are getting an error because we missed a semicolon after cout << "Hey". We can easily solve these errors by fixing the syntax.

2. Exceptions

Even if our code is syntactically correct, we may still get an error every now and then. These errors are called exceptions. For example, we will get an error if we divide a number by 0.

```cpp
1#include <iostream>
2using namespace std;
3
4int main() {
5
6    int result = 5 / 0;
7    cout << result;
8
9    return 0;
10}
```

Output

```text
Floating point exception
```

Here, the syntax of our code is correct. However, we are not allowed to divide a number by 0 in C++. This is what we call an exception.

In this case, we are getting the Floating point exception.
