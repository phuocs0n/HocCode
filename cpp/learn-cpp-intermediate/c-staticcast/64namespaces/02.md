## Example: C++ namespace

```cpp
1#include <iostream>
2using namespace std;
3
4
5// create namespace with double variable var
6namespace my_namespace {
7    double var;
8}
9
10
11int main() {
12
13    // initialize var of main()
14    int var = 5;
15    cout << "main() var = " << var << endl;
16
17
18    // initialize var of my_namespace
19    my_namespace::var = 5.55;
20
21    // print var of my_namespace
22    cout << "my_namespace var = " << my_namespace::var << endl;
23
24
25    return 0;
26}
```

Output

```text
main() var = 5
my_namespace var = 5.55
```

Here, we have created a namespace my_namespace where we have defined a double variable var.

We have defined another var of int type in main(). By using the code my_namespace::var, we can use the variable of my_namespace alongside the variable in main().

Thus, we can see that using the my_namespace namespace has prevented a naming conflict from appearing in our program.
