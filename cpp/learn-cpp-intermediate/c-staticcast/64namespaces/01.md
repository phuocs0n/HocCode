## C++ Namespaces

In C++, a namespace is a named scope inside our code that can prevent naming conflicts by enclosing its entities within that scope.

If we have multiple entities with the same name in our program, we can specify which entity we are using at a particular time by specifying its namespace.

#### Creating a Namespace

We can create a namespace by using the namespace keyword and declaring/defining our entities within its scope:

```cpp
namespace my_namespace {
    double var;
}
```

Here, we have created a namespace called my_namespace. We can now use the scope resolution operator :: to specify that we are using the var variable belonging to my_namespace:

```cpp
int main() {

    // initialize var of main()
    int var = 5;

    // initialize var of my_namespace
    my_namespace::var = 5.55;

    return 0;
}
```
