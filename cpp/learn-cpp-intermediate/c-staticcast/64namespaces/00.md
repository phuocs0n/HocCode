## Naming Conflicts in C++

Consider the following code:

```cpp
int main() {

    int var = 5;

    // Error: conflicting declaration
    double var = 5.55;

    return 0;
}
```

This code cannot be compiled successfully because we have declared two variables of the same name (var) within the scope of the main() function. In C++, this is known as a naming conflict.

One way to compile the code without errors is to declare one var in another scope separate from the other var:

```cpp
int main() {

    int var = 5;

    // separate local scope
    {
        double var = 5.55;
    }

    return 0;
}
```

However, there is another way to use the same name for multiple variables (or any other identifier for entities such as arrays, vectors, functions, etc.) inside the same scope. And that can be achieved through namespaces.

In other words, namespaces in C++ are a way to prevent naming conflicts within the program, especially if it is a large project.
