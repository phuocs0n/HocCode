## C++ #include Preprocessor

As we know, the #include preprocessor is used to include header files to our program. For example,

```cpp
#include <cmath>
```

Here, <cmath> is a header file that is readily available when we install the C++ compiler.

The #include preprocessor directive replaces the above line with the contents of the <cmath> header file.

### Custom Header Files

We can also include custom header files in our program using the #include directive. For example,

```cpp
#include "C:/cpp_files/my_header.h"
```

Here, we have included the header file named my_header.h in our program before our program is compiled. This header file is inside the cpp_files folder of the C: drive.

It is a good practice to divide a large program into multiple files. We can then include these files in our main file (say, main.cpp) using the #include preprocessor.
