## C++ Constants

In C++, we can use the const keyword to create variables with constant values i.e. their values cannot be changed. For example,

```cpp
1#include <iostream>
2using namespace std;
3
4int main() {
5
6
7    // define a double constant PI with the value 3.14
8    const double PI = 3.14;
9
10
11    // create variable to store the radius of a circle
12    double radius;
13
14    // get user input for radius
15    cout << "Enter the radius: ";
16    cin >> radius;
17
18    // calculate the area of the circle
19    double area = PI * radius * radius;
20
21    // print the area
22    cout << "Circle Area = " << area;
23
24    return 0;
25}
```

Output

```text
Enter the radius: 2.5
Circle Area = 19.625
```

Here, we have declared a constant of double type called PI and stored the value 3.14 in it.

```cpp
const double PI = 3.14;
```

This value cannot be changed later in the program. If we try to change the value, we will get an error. For example,

```cpp
1#include <iostream>
2using namespace std;
3
4int main() {
5
6    // define a double constant PI with the value 3.14
7    const double PI = 3.14;
8
9    // print the constant value
10    cout << "Initial PI = " << PI << endl;
11
12
13    // attempt to change the value of the constant
14    PI = 7.99;
15
16
17    // print the constant value
18    cout << "Updated PI = " << PI;
19
20    return 0;
21}
```

Output

```cpp
ERROR!   13 |     PI = 7.99;
      |     ~~~^~~~~~
```

As you can see, we get an error when we try to change the value of the constant.
