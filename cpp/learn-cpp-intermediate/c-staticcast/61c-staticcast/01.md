## Type Casting Operators

Now that we have revised the basics of type conversion in C++, it is time to focus our attention towards type casting operators.

These type casting operators are used for explicit data conversion, and are actually safer compared to the explicit type conversion method we've been using so far.

There are 4 major type casting operators in C++:

- static_cast
- dynamic_cast
- reinterpret_cast
- const_cast

In this lesson, we will only focus on static_cast, since the other types of casting require knowledge of topics we have not yet covered.
