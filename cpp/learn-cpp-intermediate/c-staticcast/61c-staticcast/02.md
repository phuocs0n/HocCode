## C++ static_cast

The C++ static_cast operator can be used to convert variables and values from one type to another. These types can be built-in data types (such as int, double, char, etc.) or they can be user-defined types (such as pointers to objects, structs, etc.).

Let's look at this with an example.

```cpp
1#include <iostream>
2using namespace std;
3
4int main() {
5
6    // initialize a double variable
7    double number1 = 85.247;
8
9
10    // equivalent to
11    // int result1 = int(number1);
12    int result1 = static_cast<int>(number1);
13
14
15    // initialize an integer variable
16    int number2 = 28;
17
18
19    // equivalent to
20    // double result2 = double(number2);
21    double result2 = static_cast<double>(number2);
22
23
24    // print the results
25    cout << result1 << endl;
26    cout << result2;
27
28    return 0;
29}
```

Output

```text
85
28
```

Here, we have converted number1 and number2 to different types using static_cast.

As stated before, using static_cast is preferable to the methods we've been using so far, since it checks the type compatibility at compile-time and throws an error if the types are not compatible.

This helps to catch type conversion errors early in the development cycle and avoid potential runtime errors.
