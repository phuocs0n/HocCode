## Example: Enumeration Type

```cpp
1#include <iostream>
2using namespace std;
3
4
5// create enum to store days of the week
6enum week { Sunday, Monday, Tuesday, Wednesday, Thursday, Friday, Saturday };
7
8
9int main() {
10
11    // create variable of enum week type
12    week today;
13
14    // initialize today with the value Wednesday
15    // today = 3
16    today = Wednesday;
17
18    // Wednesday is the 4th day of the week
19    // so (today + 1) = (3 + 1) = 4
20    cout << "Day " << today + 1;
21
22    return 0;
23}
```

Output

```text
Day 4
```

Here, we have created an enum named week consisting of the days of the week as its values.

Here, the integral values corresponding to the enum values are:

```cpp
Sunday = 0
Monday = 1
Tuesday = 2
Wednesday = 3
Thursday = 4
Friday = 5
Saturday = 6
```

In main(), we have created a week variable named today and initialized it with Wednesday. So, the week variable is actually storing the integer value 3.

Since Wednesday is actually the 4th day of the week but its enum value is 3, we added 1 to it while printing its position in the week.

```cpp
cout << "Day " << today + 1;
```
