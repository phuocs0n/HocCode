## Read From a File and Write to Another

Here, we will copy the contents of one file to another. For this, we will use

- getline() function to read the content of a file to a string variable
- the << operator to write the content from the string variable to another file

Suppose we have a file named source.txt with the following content:

```cpp
This is a sample file.
This will be copied to another file.
```

Let's now copy the file content to another file named destination.txt.

Here's the program required to do that:

```cpp
#include <iostream>
#include <fstream>
using namespace std;

int main() {


    // open source.txt in read mode
    fstream source("source.txt", ios::in);

    // open destination.txt in write mode
    fstream destination("destination.txt", ios::out);


    // string variable to store file content
    string content;

    // check the files for error
    if (source.fail() || destination.fail()) {
        cout << "Error opening file(s).";
        exit(0);
    }


    // loop until the end of source.txt
    while (!source.eof()) {

        // store current line of source.txt
        // to content variable
        getline(source, content);

        // write the source content to destination.txt
        destination << content << endl;
    }


    // close the files
    source.close();
    destination.close();

    return 0;
}
```

When we run this file, the content of the destination.txt file will be

```cpp
This is a sample file.
This will be copied to another file.
```
