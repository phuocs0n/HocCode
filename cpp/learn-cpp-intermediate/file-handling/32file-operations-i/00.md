To perform these operations, we need to open the files in their respective modes.

### File Opening Modes

Here are the different file open modes available in C++. We need to open files in the respective modes to perform the desired operations.

| Mode | Meaning | Description |
| --- | --- | --- |
| ios::in | input | Open file for reading. |
| ios::out | output | Open file for writing. |
| ios::app | append | Open file for appending. |

Let's see an example,

```cpp
fstream my_file;

// open the file in write mode
my_file.open("sample.txt", ios::out);

// open file in read mode
my_file.open("sample.txt", ios::in);
```

The in, out, and app objects are members of the ios class. Hence, we need to use the scope resolution operator :: when specifying the file open modes.
