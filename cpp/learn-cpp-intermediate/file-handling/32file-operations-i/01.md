## Read From a File

We already learned how to read a file in the previous lesson:

```cpp
string content;

// create fstream object
fstream my_file;

// open file in read mode
my_file.open("message.txt");

// read until the End of File
while (!my_file.eof()) {
    getline(my_file, content);
    cout << content << endl;
}
```

But starting from now, we will always open the file explicitly in read mode/input mode to perform the read operation.

To open a file in read mode, we need to supply ios::in as the second argument to the open() function.

```cpp
// create fstream object
fstream my_file;

// open file in input mode
my_file.open("message.txt", ios::in);
```

Let's rewrite the previous program by specifying the read mode.

```cpp
#include <iostream>
#include <fstream>
using namespace std;

int main() {

    string content;

    // create fstream object
    fstream my_file;


    // open file in read mode
    my_file.open("message.txt", ios::in);


    // check if the file has opened properly
    if (my_file.fail()) {

        // print error message
        cout << "File failed to load!";

        // exit the program
        exit(0);
    }
    else {

        // print success message
        cout << "File loaded successfully!" << endl;
    }

    // read until the End of File
    while (!my_file.eof()) {
        getline(my_file, content);
        cout << content << endl;
    }

    // close the file
    my_file.close();

    return 0;
}
```

Output

```text
File loaded successfully!
I love programming.
I love Programiz.
```
