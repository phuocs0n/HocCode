#### Course: Learn C++ Intermediate

## Open a File Without Using open()

In C++, we can directly open a file during object creation. This is because the fstream, ifstream, and ofstream classes contain constructors that allow us to open a file.

In such cases, we don't need to use the open() function. For example,

```cpp
// open file in read mode during object declaration
fstream f_file("cpp.txt", ios::in);

// open file in read mode during object declaration
ifstream if_file("cpp.txt");

// open file in write mode during object declaration
fstream f_file("cpp.txt", ios::out);

// open file in write mode during object declaration
ofstream of_file("cpp.txt");

// open file in append mode during object declaration
fstream f_file("cpp.txt", ios::app);

// open file in append mode during object declaration
ofstream of_file("cpp.txt", ios::app);
```

You can try this yourself by rewriting the previous programs without the open() function.

Note: You can only use this method during object declaration. Otherwise, you must use the open() function if you want to open the file after creating the object. For example,

```cpp
// create fstream object
fstream my_file;

// invalid code
my_file("cpp.txt", ios::out);

// valid code
my_file.open("cpp.txt", ios::out);
```
