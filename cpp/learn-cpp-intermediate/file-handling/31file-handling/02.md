## Example: Opening a File

Now, let's see an example of opening a file.

```cpp
#include <iostream>
#include <fstream>

using namespace std;

int main() {

    // create fstream object
    fstream my_file;

    // open file in read mode
    my_file.open("message.txt");

    // check if file opening is unsuccessful
    if (!my_file) {
        cout << "File opening is unsuccessful";
        return 1;
    }

    return 0;
}
```

While opening a file in read mode, we need to make sure that the file exists in the specified location. Otherwise, the open() function will return a NULL value.

If we didn't have any file named message.txt, we will get the following output.

```text
File opening is unsuccessful
```
