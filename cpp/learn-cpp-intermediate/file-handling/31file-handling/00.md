## Introduction

The concept of computer files needs no introduction. In this lesson, we will learn to perform file operations, such as reading content from files and writing content to files.

There are three steps involved in working with files:

1. Opening a file
2. Perform file operations (read and write files)
3. Close the file

In C++, we use the <fstream> library to work with files. To use this library, we must include the <fstream> header file in our program.

```cpp
#include <fstream>
```

Once we've imported the <fstream> header file, we can now create an object of the fstream class.

```cpp
// create an fstream object
fstream my_file;
```

Now, we can use the my_file object to read from and write to files. Next, we'll learn how to use an fstream object to open a file.

By the way, our C++ compiler doesn't support working with files at the moment, so we have to rely on images.
