## Introduction

So far, we have used the fstream class to handle our file operations. However, we can also perform these tasks using the ifstream and ofstream classes. These classes are defined inside the <fstream> header file.

Let's look at some of the basic features of these classes.

| fstream Class | Description |
| --- | --- |
| ifstream | Stands for Input File Stream.
Used for reading files.
Uses ios::in mode by default. |
| ofstream | Stands for Output File Stream.
Used for writing/appending files.
Uses ios::out mode by default.
We need to pass ios::app as an argument for appending. |

Next, we will use ifstream to read from a file.
