## C++ STL

The C++ Standard Template Library (STL) is a collection of class templates and algorithms that makes it easy to work with common data structures like queues, lists, and stacks.

It simplifies complex tasks, so you don't have to write everything from scratch. For example, if you need a stack of integers, you can just write:

```cpp
std::stack<int> my_stack;
```

Don't worry about how this works; just know that it creates a stack. We will learn in detail about how this works later.

Now, you can easily add and remove data from a stack using the push() and pop() functions.

```cpp
stack.push(1);
stack.pop();
```

Besides data structures, the STL also offers many useful algorithms for tasks like searching and sorting.

Throughout the course, we will briefly look into:

- STL Containers - Implementation of various data structures
- STL Algorithms - Implement of various algorithms

We'll first start with STL Containers and then move on to STL Algorithms.
