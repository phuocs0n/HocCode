## STL Container

As the name suggests, STL containers store a collection of data (objects) for various purposes.

Think of them as special boxes that can hold different items (data) in specific ways, depending on what you need to do with them.

There are three main types of containers in the STL:

1. Sequential container : These containers implement data structure that can be accessed sequentially. For example: vector, list, std::array etc.
2. Associative container: These containers store data in a way that makes searching easy and fast. The data is usually sorted. For example: map, set etc.
3. Container Adapters: These containers provide a simplified interface on top of other containers, helping you work with data in different ways. For example: stack, queue etc.

Basically, C++ containers are classes that provide implementations of commonly used data structures. For example,

- list - implements doubly linked lists
- stack - implements stacks
- queue - implements queues
- and so on.
