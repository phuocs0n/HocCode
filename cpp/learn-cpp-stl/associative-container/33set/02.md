## Create and Initialize a Set

In order to create a set, we first need to include the set header file.

```cpp
#include <set>
```

We then use create a set as,

```cpp
// Create an integer set
set<int> numbers;
```

We can also initialize this set using the following methods:

```cpp
// Method 1
set<int> numbers = {3, 2, 5, 4, 3, 5, 1};

// Method 2
set<int> numbers {3, 2, 5, 4, 3, 5, 1};
```

Here, the set numbers is of integer type and contains the following elements:

```cpp
{1, 2, 3, 4, 5}
```

We can then iterate through the set using a ranged for loop. For example,

```cpp
1#include <iostream>
2#include <set>
3using namespace std;
4
5int main() {
6
7    // Create an integer set
8    set<int> numbers {3, 2, 5, 4, 3, 5, 1};
9
10    for (int num : numbers) {
11        cout << num << ", ";
12    }
13
14    return 0;
15}
```

Output:

```text
1, 2, 3, 4, 5,
```

Notice that the keys have been arranged in ascending order and contain no duplicates, even though we have repeated the integers 3 and 5 when initializing the set.
