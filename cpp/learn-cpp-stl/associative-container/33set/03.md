## Example: C++ Set

Now, let's write a program to create the string set we saw in the introduction, and see how the keys are arranged.

```cpp
1#include <iostream>
2#include <set>
3
4using namespace std;
5
6int main() {
7
8    // Create a string set
9    set<string> animals {"Tiger", "Dog", "Elephant", "Goat"};
10
11    for (string var: animals) {
12        cout << var << endl;
13    } 
14
15    return 0;
16}
```

Output:

```text
Dog
Elephant
Goat
Tiger
```

As you can see, the set elements are arranged in alphabetical order.
