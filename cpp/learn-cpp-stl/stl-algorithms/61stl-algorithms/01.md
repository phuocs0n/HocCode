## accumulate()

The accumulate() function computes the sum of all the elements in the given range along with a given initial value.

Let's look at the function signature first,

```cpp
Type accumulate(iterator first, iterator last, Type init_val);
```

Here,

- first : Iterator to the first element of the range.
- last : iterator to the last element of the range.
- init_val : the initial value that is added to the sum.

This function returns the sum of the elements in the given range including the given initial value.
