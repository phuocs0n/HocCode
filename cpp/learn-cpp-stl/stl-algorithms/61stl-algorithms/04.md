## Example: copy()

Consider, we have a vector of string ,

```cpp
vector<string> names {"James", "Paul", "Maya", "Stuti"};
```

To copy the first two elements of the names vector into another vector,

```cpp
// A new destination vector with the size same as the names vector
vector<string> male_names(names.size());
```

we do

```cpp
copy(names.begin(), names.begin() + 2, male_names.begin());
```

This copies the first two elements of the names vector into male_names vector. Let's see a full example.

```cpp
1#include <iostream>
2#include <vector>
3
4using namespace std;
5
6int main(){
7
8    vector<string> names{"James", "Paul", "Maya", "Stuti"};
9
10    // A new destination vector with the size same as the names vector
11    vector<string> male_names(names.size());
12    // Copy the first two elements of the vector to new male_names vector
13    copy(names.begin(), names.begin() + 2, male_names.begin());
14
15    // Print the male_names vector:
16    for(auto name : male_names){
17       cout << name << " ";
18    }
19}
```

Output:

```text
James Paul
```
