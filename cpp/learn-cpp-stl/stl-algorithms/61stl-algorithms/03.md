## copy()

The copy() function copies a range of values to some new destination. Let's see the function signature first.

```cpp
iterator copy(iterator first, iterator last, new_iterator destination_first);
```

Here,

- first : Iterator to the first element of the range.
- last : iterator to the last element of the range.
- destination_first : iterator to the destination container.

This function returns an iterator to the element in the destination container which is one past the last element copied.
