## Example: Access the First Element

```cpp
1#include <iostream>
2#include <vector>
3
4using namespace std;
5
6int main() {
7    vector<int> numbers = {12, 2 ,3, 4, 5};
8    
9    // Get an iterator to the first element
10    auto iter = numbers.begin();
11
12    cout << iter << endl;
13
14    return 0;
15}
```

If you run the above program, you will encounter an error instead of getting the first element. Let's understand why.

We used begin() to obtain the iterator to its first element.

When we try to print the element with:

```cpp
cout << iter << endl;
```

It results in an error because iterators behave like pointers, and we need to dereference them to access the elements they point to.
