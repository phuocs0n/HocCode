## Introduction

Adapters provide a simplified interface to work with existing containers in a more specialized way.

Adapters allow you to use a container as if it were a different data structure, without having to directly interact with the underlying container's full range of functionality.

For example: std::stack adapts a container to provide an interface for the stack data structure.

Don't worry if you don't know what a stack is, we'll cover them in detail.

In this chapter, we'll look into 3 container adapters:

- STL Stack
- STL Queue
- STL Deque

Let's start with the stack.
