# Create and Initialize a Deque

#### Course: Learn C++ STL

## Create and Initialize a Deque

### Create a Deque

We need to import the deque header file to use the STL deque. Then, we can use the deque keyword to create a deque container.

```cpp
// Include deque header file
#include <deque>

// Create an double deque
deque<double> numbers;
```

### Initialize a Deque

Unlike a queue, we can initialize a deque using the following methods.

```cpp
// Method 1
deque<double> numbers1 = {5.7, 2.95, 3.33};

// Method 2: Uniform Initialization
deque<double> numbers2 {5.7, 2.95, 3.33};

// Method 3: Fill Constructor method
// numbers3 = {2.95, 2.95, 2.95, 2.95, 2.95};
deque<double> numbers3(5, 2.95);
```
