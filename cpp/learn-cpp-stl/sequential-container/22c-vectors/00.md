## Introduction

A vector in C++ is similar to the generic arrays.

Remember the code for declaring an array.

```cpp
int numbers[5] = {69, 59, 49, 39, 29};
```

Here, we have created an integer array named numbers. The size of this array is 5 and it cannot be changed.

But what if you don't know exactly how many elements you need in advance? This can be problematic because we need to know the size of an array.

That's where vectors come in.

Unlike arrays, vectors in C++ allow you to create collections that can automatically resize as you add or remove elements.

A vector can be considered as a dynamic array.

Now that you understand why you should use vectors instead of arrays, let's learn how to create them.
