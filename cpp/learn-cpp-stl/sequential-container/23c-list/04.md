## Access List Elements

We can access the first and last elements of the list by using the front() and back() methods respectively. For example,

```cpp
1#include <iostream>
2#include <list>
3
4using namespace std;
5
6int main() {
7
8    list<char> vowel = {'a', 'e', 'i', 'o', 'u'};
9
10
11
12    cout << "First Element: " << vowel.front() << endl;
13    cout << "Last Element: " << vowel.back();
14
15    return 0;
16}
```

Output

```text
First Element: a
Last Element: u
```

Here,

- vowel.front() - returns the first element
- vowel.back() - returns the last element
