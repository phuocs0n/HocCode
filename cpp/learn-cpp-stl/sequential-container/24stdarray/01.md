## Create a std::array

std::array is defined in the <array> header so we must include this header before we can use std::array.

```cpp
#include <array>

// Declaration of std::array 
std::array<int, 5> numbers;
```

Here, we declared a std::array of size 5 that stores a list of numbers.

### Example: C++ std::array

```cpp
1// C++ program to demonstrate the usage of std::arrays
2
3#include <iostream>
4#include <array>
5
6using namespace std;
7
8int main(){

11
12    cout << "The elements are: " << endl;
13
14    // Use a ranged for loop print the elements
15    for(const int num: numbers){
16        cout << num << " ";
17    }
18}
```

Output

```text
The elements are: 
1 2 3 4 5
```
