## Complete Syntax: C++ Lambda

A complete syntax for a lambda expression looks like:

```cpp
[] () mutable throw() -> int {
 // lambda body
}
```

Let's look at each part one by one.

1. [] (Capture Clause)

A capture clause in a lambda expression is used to capture values from the surrounding scope. There are various ways to capture values however we'll look into two ways:

a. Capture by Value

To capture variables by value, we add the symbol = inside the capture clause, i.e., [=] as:

```cpp
[=] {
  cout << "Capturing surrounding variables by value"
}
```

b. Capture by Reference

To capture variables by reference, we add the symbol & inside the capture clause, i.e., [&] as:

```cpp
[&] {
  cout << "Capturing surrounding variables by reference"
}
```

2. () (Parameter List)

A parameter list is optional and is similar to a function's parameter list.

```cpp
[=] (int x, int y) {
  // lambda body
}
```

This lambda expression expects two function parameters, x and y both of type int.

3. Mutable Specification

A mutable specification is optional and if added allows the lambda expression to mutate (change) the variables captured by value within the lambda expression.

```cpp
[=] mutable {
  // variables can be changed here 
}
```

4. Exception Specification

Exception specification allows us to indicate whether the lambda expression throws an exception or not.

This is also optional.

To indicate no exception is thrown,

```cpp
[] () noexcept{
  // don't throw exception
}
```

Here we used the noexcept keyword to indicate that the lambda doesn't throw an exception.

5. Trailing Return Type

A trailing return type is used to indicate the return type of the lambda expression. This is also optional.

```cpp
[] (int x, int y) -> int {
  return x + y;
}
```

Here, -> int indicates that the return value is of type int.
