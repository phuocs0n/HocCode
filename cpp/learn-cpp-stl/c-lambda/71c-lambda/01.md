## Example: A complete Lambda

```cpp
1#include <iostream>
2
3using namespace std;
4
5int main(){
6
7    auto lambda_add = [](int x, int y) -> int {
8        return x + y;
9    };
10int sum = lambda_add(5, 5);
11    cout << "The sum is " << sum;
12}
```

Output:

```text
The sum is 10
```

Here, we created an lambda expression,

```cpp
[](int x, int y) -> int {
  return x + y;
}
```

The lambda takes two parameters, x and y as an input and returns their sum. We then assigned it to a variable, lambda_add.

We then invoked the lamdba_add passing it two parameters, 5 and 5.

```cpp
int sum = lambda_add(5, 5);
```
