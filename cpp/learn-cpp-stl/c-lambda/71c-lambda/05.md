## Example: Lambda mutating captured variable

Consider the following example,

```cpp
#include <iostream>

using namespace std;

int main(){
    int i = 5;
    auto val = [=](int x, int y) -> int {
        i = 78;
        return i + x + y;
    } (5,5);


    cout << "The sum is : " << val;
}
```

Here we are trying to modify the captured value i by assigning it to new value 78. But this is an error unless we use the mutable specification.

The correct way is to specify the mutable keyword.

```cpp
1#include <iostream>
2
3using namespace std;
4
5int main(){
6    int i = 5;
7    auto val = [=] (int x, int y) mutable -> int {
8        i = 78;
9        return i + x + y;
10    } (5,5);
11
12
13    cout << "The sum is  " << val;
14}
```

Output:

```text
The sum is 88
```
