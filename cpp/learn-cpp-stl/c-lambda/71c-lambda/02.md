## In-place Lambda

We can invoke the lambda expression in place as well i.e. right after its definition.

```cpp
1#include <iostream>
2
3using namespace std;
4
5int main(){
6    auto val = [](int x, int y) -> int {
7        return x + y;
8    } (5,5);
9
10
11    cout << "The sum is : " << val;
12}
```

Output:

```text
The sum is : 10
```

Here, (5, 5) right after the closing curly brace invokes the lambda expression and the return value is stored into the val variable.
