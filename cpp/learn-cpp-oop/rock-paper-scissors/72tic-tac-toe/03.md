## Step 1: Create the Board Class

```cpp
1#include<iostream>
2using namespace std;
3
4
5class Board {

7    public:

10        void print_board() {

19
```

Output

```text
|   |  
-----------
   |   |  
-----------
   |   |
```

Here, the Board class has a member named board which is an array of nine elements. Initially, the value of each element is an empty space. We will update these elements with either X or O symbols once the players start choosing the position.

And the print_board() function prints the board in a visually intuitive manner.

We have created an object of the Board class inside the main() function. Then, we called the print_board() function using the object of the Board class.

We will add other functions to the Board class later. Next, we will create the Player class.
