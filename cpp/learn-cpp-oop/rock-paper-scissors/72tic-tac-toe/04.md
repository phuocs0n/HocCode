## Step 2: Create the Player Class

### Project Changes

- Remove object of the Board class from the main() function.
- Create the Player class.

```cpp
1#include<iostream>
2using namespace std;
3
4class Board {
5
6    public:
7        string board[9] = { " ", " ", " ", " ", " ", " ", " ", " ", " " };
8
9        void print_board() {
10            cout << " " << board[0] << " | " << board[1] << " | " << board[2] << endl;
11            cout << "-----------" << endl;
12            cout << " " << board[3] << " | " << board[4] << " | " << board[5] << endl;
13            cout << "-----------" << endl;
14            cout << " " << board[6] << " | " << board[7] << " | " << board[8] << endl;
15        }
16};
17
18
19class Player {
20    public:
21        string name;
22        char type;
23
24        // function to select the player type and name
25        void set_info(char type) {
26
27            // player type is 'X' if parameter is 'X' or 'x'            
28            if (type == 'X' || type == 'x') {
29
30                // set member variable to 'X'
31                this->type = 'X';
32
33                // get player name
34                cout << "Player selecting " << this->type << ", enter your name: ";
35                getline(cin, name);
36            }
37
38            // player type is 'O' if parameter is any other character 
39            else {
40                this->type = 'O';
41                cout << "Player selecting " << this->type << ", enter your name: ";
42                getline(cin, name);
43            }
44        }
45};
46
47
48 int main() {
49
50    Player player1;
51    player1.set_info('X');
52
53    Player player2;
54    player2.set_info('Y');
55 
56    return 0;   
57}
```

Output

```text
Player selecting X, enter your name: Lily
Player selecting O, enter your name: Robin
```

Here, we have added the Player class, which has two member variables name and type, where type is used for symbols that are either 'X' or 'O'.

The set_info() function is then used to perform the following tasks:

- It sets the type member variable (this->type) to 'X' if the type parameter of the constructor is 'X' or 'x'.
- For all other parameter values, it sets  this->type to 'O'.
- Finally, it sets the full name of the player using getline().

We will assume that the first player will always take the 'X' symbol and the second player will always take the 'O' symbol.

Inside the main() function, we have created two objects player1 and player2 of the Player class. We have passed 'X' and 'Y' to player1 and player2 respectively while creating their objects.

As you can see from the output, the type variable of player2 is set as 'O' even though we passed 'Y' to it.
