The check_winner() function

This function checks if three same symbols (type) appear in a row. If that's the case, the player with that symbol won the game. In that case, we have returned true, else we have returned false.

We will later call this function from inside the play() function of the Game class.

By the way, the if condition inside the class is very large. That's why we have written it in multiple lines.

The check_draw() function

If all variables of the board are filled and there is yet to be a winner, then it's a draw. To check if all the variables are filled, we have created a count variable.

Inside the update_board() function, we have increased the value of count by 1 every time the board updates.

That means the value of count is 1 when one element of the board is filled. Similarly, when all 9 elements of the board are filled, the value of count will be 9.

This means the following condition is met:

```cpp
(count == 9)
```

So, the check_draw() function will return true.

We will later call this function from inside the play() function of the Game class.
