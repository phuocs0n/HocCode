The update_board() function

This function takes two arguments:

- position - the position selected by the user (an integer).
- type - if the current player is player1, it will be 'X'; otherwise it will be 'O'.

This function checks if the position is already filled or not. If it's not filled, we will update the board, and true is returned. However, if the position is already filled, a message is shown, and false is returned.

By the way, we have used board[position - 1] to update the board. It's because if a player selects position 2, we have to update index 1 of the list. Remember that the array index starts from 0.

The play() function

Inside the function, we have a while loop to run the game continuously; we will add logic to terminate the loop later.

Inside the loop, we ask the user to enter a position between 1 and 9.

Then, we call the update_board() function of the Board class. To call this function, we have used the following code:

```cpp
bool update = board.update_board(position, current_player->type);
```

We have called the update_board() function with parameters position and the current player type.

If the position passed to update_board() is not already selected, true is returned. In that case, the current_player is changed to the next player.
