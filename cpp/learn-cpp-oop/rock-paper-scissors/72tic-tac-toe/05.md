## Step 3: Create the Game Class

### Project Changes

- Remove the Player objects from the main() function (we will add it inside the Game class).
- Create the Game class.

```cpp
1#include<iostream>
2using namespace std;
3
4class Board {
5    public:
6
7        string board[9] = { " ", " ", " ", " ", " ", " ", " ", " ", " " };
8
9        void print_board() {
10            cout << " " << board[0] << " | " << board[1] << " | " << board[2] << endl;
11            cout << "-----------" << endl;
12            cout << " " << board[3] << " | " << board[4] << " | " << board[5] << endl;
13            cout << "-----------" << endl;
14            cout << " " << board[6] << " | " << board[7] << " | " << board[8] << endl;
15        }
16};
17
18class Player {
19    public:
20
21        string name;
22        char type;
23
24        // function to select the player type and name
25        void set_info(char type) {
26
27            // player type is 'X' if parameter is 'X' or 'x'            
28            if (type == 'X' || type == 'x') {
29
30                // set member variable to 'X'
31                this->type = 'X';
32
33                // get player name
34                cout << "Player selecting " << this->type << ", enter your name: ";
35                getline(cin, name);
36            }
37
38            // player type is 'O' if parameter is any other character 
39            else {
40                this->type = 'O';
41                cout << "Player selecting " << this->type << ", enter your name: ";
42                getline(cin, name);
43            }
44        }
45};
46
47
48class Game {   
49    public:
50
51        Board board;
52
53        Player player1;
54        Player player2;
55
56        // pointer to point to address of the
57        // current player (either player1 or player2)
58        Player* current_player;
59        
60        // constructor to set player data
61        Game() {
62            player1.set_info('X');
63            player2.set_info('O');
64            current_player = &player1;
65        }
66        
67        // this function will be later used to play the game
68        void play() {
69            // empty for now
70        }
71};
72
73
74int main() {
75
76    Game game;
77    game.play();
78    return 0;
79}
```

Output

```text
Player selecting X, enter your name: Robin
Player selecting O, enter your name: Lily
```

Inside the Game class:

| Object | Description |
| --- | --- |
| board | Object of the Board class. |
| player1 | Object of the Player class for the first player. |
| player2 | Object of the Player class for the second player. |
| current_player | Pointer of Player class to identify the turn of either player.

In the beginning, it's the turn of the first player, so we have assigned the address of player1 to it. |

The play() function will be used to write our game logic, which is empty for now.

Next, we will update the play() function.
