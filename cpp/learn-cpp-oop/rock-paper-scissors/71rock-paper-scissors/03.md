## Step 2: Get Computer's Pick

### Project Changes

- Add the get_computer_pick() function to the Game class.

### Function Objectives

The purpose of this function is to generate a random number between 1 and 3. If the number is

- 1 - return "rock"
- 2 - return "paper"
- 3 - return "scissors"

```cpp
#include <iostream>

#include <cstdlib>
#include <ctime>

using namespace std;

class Game {
    private:
        string user_pick;
        string computer_pick;
        string result;


    public:

        // function to return computer's pick
        string get_computer_pick() {
            
            // generate random number based on time
            srand(time(NULL));

            // random number between 1 and 3
            int random_number = (rand() % 3) + 1;

            switch(random_number) {
                case 1:
                    computer_pick = "rock";
                    break;
        
                case 2:
                    computer_pick = "paper";
                    break;

                case 3:
                    computer_pick = "scissors";
                    break;
            }

            return computer_pick;
        }

};
```

get_computer_pick() Function

Inside the function, we have generated a random number between 1 and 3, which is assigned to the random_number variable.

To generate a random number, we have used the srand() function defined in the cstdlib header file and the time() function defined in the ctime file.

```cpp
// generate random number based on time
srand(time(NULL));

// random number between 1 and 3
int random_number = (rand() % 3) + 1;
```

Then, we have used the switch...case statement to assign value to the computer_pick variable. We have assigned "rock", "paper", and "scissors" corresponding to the values 1, 2, and 3, respectively.

Technically, this function returns a random value among "rock", "paper", and "scissors".
