## Step 1: Create a Class

To create this project, we will first create a class named Game.

```cpp
class Game {
    ... .. ...    
}
```

This class will have three private member variables:

- user_pick - to store the user's pick
- computer_pick - to store the computer's pick
- result - to store either "win", "lose", or "draw" based on the user's pick and the computer's pick

```cpp
class Game {
    private:
        string user_pick;
        string computer_pick;
        string result; 
};
```

We have made these variables private because they are sensitive game data, and should be handled with care.
