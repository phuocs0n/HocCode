## C++ Constructors

Basically, a constructor is like a member function of a class that has the same name as the class but no return type. A constructor is automatically called when we create an object of the class. For example,

```cpp
1#include <iostream>
2using namespace std;
3
4class Sample {
5  public:
6   
7
8    // default constructor with no arguments
9    Sample() {
10        cout << "Object created!" << endl;
11    }
12
13};
14
15int main() {
16
17
18    // create an object of the Sample class
19    Sample sample1;
20
21
22    return 0;
23}
24
25// Output: Object created!
```

Here, Sample() is a constructor of the Sample class and is called automatically the moment we create the sample1 object. It is a default constructor since it takes no arguments.

### Parameterized Constructor

Constructors can also take parameters. For example,

```cpp
1#include <iostream>
2using namespace std;
3
4class Sample {
5  public:
6
7
8    // constructor with integer parameter
9    Sample (int num) {
10        cout << "Constructor Parameter: " << num << endl;
11    }
12
13};
14
15int main() {
16
17
18    // create object of Sample
19    // supply 9 as argument to its constructor
20    Sample sample(9);
21
22
23    return 0;
24}
25
26// Output:
27// Constructor Parameter: 9
```
