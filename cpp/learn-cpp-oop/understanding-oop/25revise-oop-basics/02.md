## Public and Private Modifiers

In C++, the public and private keywords are known as access modifiers.

Public Access Modifier

Class members declared as public can be accessed from outside the class (say, the main() function). For example,

```cpp
1#include <iostream>
2using namespace std;
3
4class Rectangle {
5
6    public:
7
8 
9        // public member variables
10        int length, breadth;
11
12        // public member function
13        void calculate_area() {
14            int area = length * breadth; 
15            cout << "Area: " << area << endl;
16        }
17};
18
19int main() {
20    
21    // create object of the Rectangle class
22    Rectangle rectangle1;
23
24
25    // access public member variables
26    rectangle1.length = 12;
27    rectangle1.breadth = 5;
28
29    // access public member function
30    rectangle1.calculate_area();
31
32
33    return 0;
34}
35
36// Output: Area: 60
```

Private Access Modifier

Class members declared as private cannot be accessed from outside the class. For example,

```cpp
1#include <iostream>
2using namespace std;
3
4class Rectangle {
5
6    private:
7
8 
9        // private member variables
10        int length, breadth;
11
12        // private member function
13        void calculate_area() {
14            int area = length * breadth; 
15            cout << "Area: " << area << endl;
16        }
17};
18
19int main() {
20    
21    // create object of the Rectangle class
22    Rectangle rectangle1;
23
24
25    // error: cannot access private member variables
26    rectangle1.length = 12;
27    rectangle1.breadth = 5;
28
29    // error: cannot access private member function
30    rectangle1.calculate_area();
31
32
33    return 0;
34}
```

Getter and Setter Functions

We need to create public getter and setter functions in order to access private members of a class. For example,

```cpp
1#include <iostream>
2using namespace std;
3
4class Square {
5    private:
6    
7        // private variable
8        int side;
9        
10
11    public:
12 
13        // setter function that assigns
14        // the value of the s parameter
15        // to the private variable side
16        void set_side(int s) {
17            side = s;
18        }
19        
20        // getter function that returns
21        // the value of the private variable
22        int get_side() {
23            return side;
24        }
25
26};
27
28int main() {
29    
30    // create object of the Square class
31    Square square1;
32
33
34    // call setter function
35    // initialize side to 6
36    square1.set_side(6);
37    
38    // call getter function to calculate area
39    int area = square1.get_side() * square1.get_side();
40
41
42    // print the area
43    cout << "Area: " << area << endl;
44
45    return 0;
46}
47
48// Output: Area: 36
```
