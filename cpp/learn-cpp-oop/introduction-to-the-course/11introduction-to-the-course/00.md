## Introduction

In the first part of this interactive C++ course, we learned the fundamental concepts of C++ and programming in general. If the concepts below don't ring a bell, we suggest taking the C++ Basics Course first.

- The if...else statement
- Loops
- User-defined functions
- Taking input from the user
- Arrays, strings, structures, and pointers

However, if you are comfortable writing programs involving these topics, it's time to delve into C++ more deeply. That's what this course is about.

This course will focus on Object-Oriented Programming (OOP).

After learning OOP, you will gain a much deeper understanding of C++ and be ready to write more complex and real-world programs.
