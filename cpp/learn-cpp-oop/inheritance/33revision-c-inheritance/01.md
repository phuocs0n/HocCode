## Revise Inheritance

Let's revise what we have learned in this chapter.

1. C++ Inheritance

We use the : operator to inherit one class from another. For example,

```cpp
class Person {
    public:
        void display() {
            cout << "I am a person" << endl;
        }
};

class Student: public Person {};
```

During inheritance, the child class inherits all the member variables and functions of the parent class.

```cpp
1#include<iostream>
2using namespace std;
3
4class Person {
5    public:
6        void display() {
7            cout << "I am a person" << endl;
8        }
9};
10
11class Student : public Person {};
12
13int main() {
14    
15    Student student1;
16    student1.display();
17    
18    return 0;
19}
20
21// Output: I am a person
```

2. Function Overriding

If the same function is present in both the parent class and the child class, the function in the child class overrides the same function in the parent class.

```cpp
1#include<iostream>
2using namespace std;
3
4class Person {
5    public:
6        void display() {
7            cout << "I am a person" << endl;
8        }
9};
10
11class Student : public Person {
12    public:
13        void display() {
14            cout << "I am a student" << endl;
15        }
16};
17
18int main() {
19    
20    Student student1;
21    student1.display();
22    
23    return 0;
24}
25
26// Output: I am a student
```

3. The :: Operator

We can use the :: operator to access the overridden function of the parent class.

```cpp
1#include<iostream>
2using namespace std;
3
4class Person {
5    public:
6        void display() {
7            cout << "I am a person" << endl;
8        }
9};
10
11class Student : public Person {
12    public:
13        void display() {
14            cout << "I am a student" << endl;
15            
16            // access overridden function from inside the function
17            Person::display();
18        }
19};
20
21int main() {
22    
23    Student student1;
24    student1.display();
25    
26    // access overridden function using object
27    student1.Person::display();
28    
29    return 0;
30}
```

Output

```text
I am a student
I am a person
I am a person
```
