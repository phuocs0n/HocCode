## Thought Process

To find out the nth number in the Fibonacci sequence, we need to pass the (n-1)th and (n-2)th numbers to a function.

The first two terms of the series are always 0 and 1. So, for the first two terms, we can simply return 0 and 1, respectively (base case).

```python
if n == 0 or n == 1:
    return n
```
