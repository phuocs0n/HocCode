## Thought Process

The sum of the first n natural numbers can also be written as follows:

```python
total = n + (n - 1) + (n - 2) + . . .+ 3 + 2 + 1
```

We will take n as an argument. With each function call, we'll decrement n by one until we reach 1. This marks our base case.

Base Case

If n equals 1, the sum is 1. This will be our base condition.

```python
if n == 1:
    return 1
```
