## Base Case for Recursion

Consider the following program to print numbers:

```python
1def print_numbers(n):
2   
3    print(n)
4    print_numbers(n + 1)
5
6print_numbers(1)
```

Output

```text
1
2
3
...
```

This program displays numbers infinitely because it lacks a stopping condition.

So, let's add a base case so that the program ends after displaying 3.

```python
1def print_numbers(n):
2
3    # base case
4    if n == 4:
5        return   
6
7    # execute code if base case is not met
8    print(n)
9    print_numbers(n + 1)
10
11print_numbers(1)
```

Output

```text
1
2
3
```

In the program, we have added the following base case:

```python
# base case
if num == 4:
    return
```

Therefore, if n is equal to 4, the function encounters the return statement, and the recursive call ends.
