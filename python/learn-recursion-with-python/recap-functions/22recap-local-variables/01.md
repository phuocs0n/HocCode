## Why are Local Variables Important?

Local variables are important because they make functions independent.

As you already know, it doesn't matter what's inside a function and what variables are used in it; we can use that function if we know two things:

- arguments that the function takes
- return value from the function

Source Code

```python
1def add_numbers(n1, n2):
2    result = n1 + n2
3    return result
4
5n1 = 2
6n2 = 5
7result = add_numbers(n1, n2)
8print(result)    # Output: 7
```

In the program, it's essential to understand that the n1, n2, and result variables inside the function are local to the add_numbers() function.

They are different from n1, n2, and result variables that are outside of the function (even though their names are the same).

They can also be written using different variable names. The above program is equivalent to the following program:

```python
1def add_numbers(n1, n2):
2    result = n1 + n2
3    return result
4
5num1 = 2
6num2 = 5
7result = add_numbers(num1, num2)
8print(result)    # 7
```
