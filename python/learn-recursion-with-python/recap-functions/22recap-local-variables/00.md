## Introduction

The concept of local variables is critical in recursion since each recursive call possesses a separate local variable.

Thus, we must revisit this topic here.

### Local Variables

Any variable that is created inside a function is local to it. For example,

```python
1def add_numbers(n1, n2):
2    result = n1 + n2
3
4add_numbers(2, 5)
5print(result) # NameError: name 'result' is not defined
```

Here, when the execution of the add_numbers() function ends, all the variables inside it—n1, n2, and result—are destroyed.

The reason why the above program throws an error is that Python thinks that the result variable is not defined.

We can fix it by using a return statement.

```python
1def add_numbers(n1, n2):
2    result = n1 + n2
3    return result
4
5output = add_numbers(2, 5)
6print(output) # Output: 7
```

By using a return statement, we are not using the local variable directly. Instead, we are returning its value to the calling function.

Next, we will see why this concept of local variables is important.
