## Recap (I)

### Exceptions

Even if our code is syntactically correct, we may sometimes get an error. These errors are known as exceptions.

```python
1result = 10/0
2print(result)
```

Since a number cannot be divided by 0, this causes the ZeroDivisionError exception.

### Exception Handling

We use the try...except block to handle exceptions.

```python
1try:
2   result = 10/0
3   print(result)
4except:
5   print('Something is wrong.')
```

We put the code that may raise exceptions inside the try block. If an exception occurs, the except block is executed. If exceptions don't occur, the except block is skipped.
