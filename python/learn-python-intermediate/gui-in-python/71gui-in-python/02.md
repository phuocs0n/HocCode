# What is a GUI?

#### Course: Learn Python Intermediate

## What is a GUI?

A GUI (Graphical User Interface) is how users interact with software through windows, buttons, sliders, and inputs.

Until now, your Python programs ran in the terminal. GUI apps let users actually see and use your code.

Learning GUI development means turning your Python logic into full, polished applications.
