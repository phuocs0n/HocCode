## Tools for Building GUIs

Python supports several GUI libraries. Each has its use cases:

1. Tkinter: Comes built-in. Great for learning and small apps.
2. Pygame: Best for 2D games and animations.
3. PyQt / PySide: Advanced, used for professional-grade apps.

We'll be using Tkinter, as it's simple, powerful, and beginner-friendly.

It's perfect for building your first visual applications and games.
