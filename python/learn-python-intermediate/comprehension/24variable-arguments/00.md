## Introduction

We know that the number of arguments in the function call and the function definition must match; otherwise, we'll get an error.

```python
1def greet(message):
2    print(message)
3
4greet('Hi', 'Hello')
```

Output

```text
TypeError: greet() takes 1 positional argument but 2 were given
```

One way to fix this problem is by placing a second parameter in the function definition like this:

```python
1def greet(message, message1):
2    print(message)
3
4greet('Hi', 'Hello')
```

Output

```text
Hi
```

The other way to solve this problem is by using a variable argument so that the function can take any number of arguments.

Next, we will see how to use a variable argument.
