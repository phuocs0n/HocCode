## Recursion Introduction

Normally, we call functions to run the code inside them. But did you know a function can also call itself?

A function that calls itself is known as a recursive function and this process is known as recursion.

Recursion is not unique to Python; many programming languages support it. We are covering it here because it can be a tricky concept, and getting into the practice of writing recursive programs can prepare you early on.

Since recursion can be challenging, we'll break it down step-by-step to help you understand it clearly.
