## Example: Infinite Recursion

```python
1def print_number(n):
2    print(n)
3
4    # recursive function call
5    print_number(n + 1)
6
7print_number(1)
```

Output

```text
1
2
3
...
```

Here, we have first called the print_number() function with 1 as an argument.

Inside the first print_number():

- 1 (value of n) is printed.
- print_number() is called again with 2, n + 1, as an argument.

Inside the second print_number():

- 2 (value of n) is printed.
- print_number() is called again with 3 as an argument.

This process goes on and on.

Again, remember that each n inside the print_number() functions are different.

### End Infinite Recursion

To prevent infinite recursion, if...else statement or a similar approach should be used where the recursive call ends if a certain condition is met.
