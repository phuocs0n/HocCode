## Algorithms

Let's start by understanding what an algorithm is — a step-by-step set of instructions to solve a specific problem.

For example, an algorithm to print the sum of two numbers might look like this:

Problem: Add Two Numbers

```python
Step1: Initialize two variables number1 and number2.
Step2: Add number1 and number2.
Step3: Print the total.
```

In this example, the algorithm is written in English. However, if we use a programming language to write an algorithm, it's called code.

Let's examine the Python code for adding two numbers.

```python
1# initialize two variables
2number1 = 33
3number2 = 2
4
5# add the numbers
6total = number1 + number2
7
8# print total
9print(total)
```

Output

```text
35
```
