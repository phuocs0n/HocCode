## Analyzing Algorithms

Let's solve a simple problem of finding the sum of the first 1000 natural numbers:

```python
1n = 1000
2total = 0 
3
4
5# iterate n times
6for i in range(1, n + 1):
7    total = total + i
8
9print(total)
```

Output

```text
500500
```

This code takes n steps to complete.

Now, suppose our computer executes one step per second. At this rate, running 1,000 steps would take 1,000 seconds (about 16 minutes).

Now, if we try to find the sum of 1011 natural numbers, it would take 1 * 1011 seconds, which would be 31 years!

That is why optimizing algorithms is crucial. A more efficient approach can significantly reduce execution time and improve performance.
