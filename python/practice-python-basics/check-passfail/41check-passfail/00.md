## Check Pass/Fail

### Program Description

Write a program to check if the student passed or failed his/her examination by creating a function.

- Create a function named check() with  argument marks.
- Inside the function, check if the user input mark is greater than 40.
- If it is greater than or equal to 40, print Pass. Otherwise, print Fail.
- Outside the function, take user input for marks.
- Call the function using the function name.

```text
Test Input50
```

```text
Expected OutputPass
```
