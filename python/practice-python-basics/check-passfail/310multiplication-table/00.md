## Multiplication Table of n From 1 to 5

### Program Description

Write a program to print a multiplication table of a number from 1 to 5.

- Take integer input from the user and store it in n.
- Create a for loop to iterate from 1 to 5 and print the multiplication table.

#### Example

```text
Test Input6
```

```text
Expected Output6
12
18
24
30
```
