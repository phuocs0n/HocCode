## Print All Numbers Except Multiples of 3

### Program Description

Write a program to print all numbers from 1 to n except the multiples of 3.

- Run a for loop from i = 1  to  n.
- Check if i is perfectly divisible by 3.
- If i is divisible by 3, skip the loop and go to the next iteration.
- Print the value of i.

#### Example

```text
Test Input7
```

```text
Expected Output1
2
4
5
7
```
