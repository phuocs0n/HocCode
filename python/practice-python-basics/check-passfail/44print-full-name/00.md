## Print Full Name

### Program Description

Write a program to print full name with space in between using a function.

- Define a function named full_name() with two arguments first_name and last_name.
- Inside the function, print first_name and last_name and separate them by an empty space.
- Outside the function, take string input for first name and last name and assign them to first and last variables.
- Call the function and pass first and last as arguments.
