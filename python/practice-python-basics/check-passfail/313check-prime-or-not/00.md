## Check Prime or Not

### Program Description

Write a program to check whether a number is prime or not.

A prime number is a number that is only divisible by either 1 or itself. For example, 7, 5, 19, etc.

#### Problem Descriptions

- Get an integer input for the number variable.
- Initialize the flag variable to 0.
- Run a loop from 2 to number - 1 and check if the number variable is divisible by any number in that range.
- If the number is divisible, set the flag variable to 1.
- Outside the loop, check if the value of flag is 1.
- If it is, print Not a Prime Number.
- Otherwise, print Prime Number.

#### Example

```text
Test Input7
```

```text
Expected OutputPrime Number
```
