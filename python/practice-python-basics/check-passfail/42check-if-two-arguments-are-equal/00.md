## Check if Two Arguments Are Equal

### Program Description

Write a program to check if the two arguments passed are equal or not by creating a function.

- Get two integer inputs num1 and num2.
- Create a function my_function() that accepts two arguments.
- Inside the function, check to see if the two arguments are equal.
- If they are equal, return True, else return False.
- Call the function, pass integers num1 and num2 as arguments to the function, and print the returned value.

#### Example

```text
Test Input1
2
```

```text
Expected OutputFalse
```
