## Sum of N Natural Numbers

### Program Description

Write a program to find the sum of first N natural numbers.

- Get an integer input for a variable n.
- Run a loop from 1 to n.
- Inside the loop, find the sum of all numbers from 1 to n.
- Print the result.

#### Example

```text
Test Input9
```

```text
Expected Output45
```
