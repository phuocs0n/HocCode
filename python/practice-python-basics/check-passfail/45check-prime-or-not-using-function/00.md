## Check Prime or Not Using Function

### Program Description

Write a program to check whether a number is prime or not using a function.

A prime number is a number that is only divided by either 1 or itself. For example, 7, 5, 19, etc.

- Define a function named check_prime().
- Inside the function, create a variable named flag with value 0 and run a loop from 2 to number - 1, and check if number is divisible by any number between 2 to number - 1.
- If the number is divisible, set the flag variable to 1.
- Outside the loop, if flag is 1, print Not a Prime Number. Otherwise, print Prime Number.
- Outside the function, get an integer input for the number variable.
- Call the function and pass number as an argument.

#### Example

```text
Test Input7
```

```text
Expected OutputPrime Number
```
