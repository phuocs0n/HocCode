## Print Numbers Until User Enters 0

### Program Description

Write a program to print numbers until the user enters 0.

- Run a while loop that is always True.
- Inside the loop, get an integer input value from the user and store it in the number variable.
- Check if the value is 0.
- If the input value is 0, terminate the loop.
- Print all the values of the number.

#### Example

```text
Test Input33
23
12
0
```

```text
Expected Output33
23
12
```
