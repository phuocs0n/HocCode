## Example: Priority Queue

```python
1# change the priority (key) of an element already in the priority queue
2def change_key(self, value, new_priority):
3    # search for value
4    for i in range(self.size()):
5        # if value is found
6        if self.heap[i][1] == value:
7            # change priority
8            old_priority = self.heap[i][0]
9            self.heap[i] = (new_priority, value)
10            # heapify after changing priority to maintain heap property.
11            # we can simply call heapify but heapify_up/down is more efficient
12            if new_priority < old_priority:
13                self.heapify_up(i)
14            else:
15                self.heapify_down(i)
16            return
```
