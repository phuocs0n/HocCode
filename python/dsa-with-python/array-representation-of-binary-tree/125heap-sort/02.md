```python
2def heap_sort(lst):

4    sorted_array = []

6    heap = MinHeap()

8    for i in lst:

```

Output

```text
[5, 12, 15, 16, 25]
```

Notes:

- If you want to sort the list in descending order, you can simply reverse the sorted list using return array[::-1].
- If you use a max heap instead of a min heap, the normal sort would give the list in descending order, whereas the reversed sort (using [::-1]) would give the list in ascending order.
