## Source Code: Binary Trees

```python
1class BinaryTreeNode:
2    def __init__(self, data):

8    def add_left_child(self, node):

11
12    def add_right_child(self, node):

15    
16class BinaryTree:
17    def __init__(self, root=None):
18        self.root = root

20
21# creating nodes
22root_node = BinaryTreeNode("root")
23left_node = BinaryTreeNode("left")

25
26# linking nodes
27root_node.add_left_child(left_node)
28root_node.add_right_child(right_node)
29
30# creating binary tree
31tree = BinaryTree(root_node)
```

Output

```text
Node root was created

Node right was created
```
