## Source Code

Now let's combine what we have built so far to build a working program and visualize how it works.

```python
1def maximize_profit(weight, value, capacity):
2    # Initialize an empty table dp_table
3    dp_table = [[0] * (capacity + 1) for _ in range(len(weight) + 1)]
4
5    # Run the loop once for each item
6    for item_index, item_weight in enumerate(weight):
7        for index in range(capacity + 1):
8            # You can only add an item if the bag size is larger than the item weight
9            if index >= item_weight:
10                dp_table[item_index + 1][index] = max(
11                    dp_table[item_index][index],
12                    dp_table[item_index][index - item_weight] + value[item_index]
13                )
14            # Otherwise, just copy the profit from one row above
15            else:
16                dp_table[item_index + 1][index] = dp_table[item_index][index]
17
18    # The last cell returns the maximum profit.
19    return dp_table[-1][-1]
20
21# Initialize variables
22weight = [1, 2, 3, 5]
23value = [60, 100, 200, 310]
24capacity = 10
25
26# Call the function and print the result
27print(maximize_profit(weight, value, capacity))
```
