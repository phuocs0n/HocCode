## Source Code: Reverse Elements of a Linked List

To reverse elements of a linked list, we will

1. Copy the values of the linked list to a new list.
2. Iterate through the new list in reverse order.
3. Assign the reversed values to the nodes of the linked list.

```python
1def reverse_elements(self):
2    # new list to copy the values
3    values = []
4    current = self.head
5
6    # copy values of linked list to the new list
7    while current:
8        values.append(current.data)
9        current = current.next
10    
11    current = self.head
12
13    # iterate through the new list in reverse order
14    for value in reversed(values):
15        # copy the reversed value to the original list
16        current.data = value
17        current = current.next
```

Output

```text
Original Linked List:
2->4->6->8->None

Reversed Elements:
8->6->4->2->None
```
