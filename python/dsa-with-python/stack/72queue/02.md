## Visualize Queue

To get a better understanding of how enqueue and dequeue works in a queue, run the visualizer below:

```python
1# create class to represent queue
2class Queue:
3    def __init__(self):
4        self.queue = []
5
6    def enqueue(self, item):
7        self.queue.append(item)
8
9    def dequeue(self):
10        return self.queue.pop(0)
11
12    def print_queue(self, message):
13        print(f"{message}: {self.queue}")
14
15# Initialize the queue
16queue1 = Queue()
17
18# Add elements to the queue
19queue1.enqueue(5)
20queue1.enqueue(10)
21queue1.enqueue(100)
22
23# Print the queue
24queue1.print_queue("Queue after adding 3 elements")
25
26# Remove one item
27print(f"Dequeued Element: {queue1.dequeue()}")
28queue1.print_queue("After removing one item")
29
30# Remove another item
31print(f"Dequeued Element: {queue1.dequeue()}")
32queue1.print_queue("After removing another item")
```
