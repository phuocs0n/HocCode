## Source Code: Fixed Sized Queue

In the implementation below, we've completed our fixed-size queue by adding two important methods:

- is_full() — to check if the queue has reached its maximum capacity
- is_empty() — to check if the queue has no elements left to remove

To make these checks possible, we've introduced a new attribute: count.

- count keeps track of the number of elements currently in the queue.
- It increases by 1 every time we enqueue an item.
- It decreases by 1 every time we dequeue an item.

By comparing count to the queue's capacity, we can easily determine whether the queue is full or empty.

```python
1class Queue:
2    
3    def __init__(self, capacity):
4        # Set the queue's maximum size
5        self.capacity = capacity
6
7        # Create the fixed-size list
8        self.queue = [None] * capacity
9
10        # Rear starts at -1 to indicate no items have been added yet
11        self.rear = -1
12
13        # Front starts at 0 to remove from the first slot
14        self.front = 0
15
16        # Count keeps track of the number of items in the queue
17        self.count = 0
18
19    # Check if the queue is full
20    def is_full(self):
21        return self.count == self.capacity
22
23    # Check if the queue is empty
24    def is_empty(self):
25        return self.count == 0
26
27    # Insert elements into the queue
28    def enqueue(self, item):
29        if self.is_full():
30            print("We can't add elements. The queue is full.")
31            return
32
33        # Move rear forward before inserting
34        self.rear += 1
35        self.queue[self.rear] = item
36        self.count += 1
37
38    # Remove elements from the queue
39    def dequeue(self):
40        if self.is_empty():
41            print("We can't remove elements. The queue is empty.")
42            return None
43
44        item_removed = self.queue[self.front]
45        self.queue[self.front] = None
46        self.front += 1
47        self.count -= 1
48        return item_removed
49
50    # Display the queue
51    def display(self):
52        print(self.queue)
53
54queue1 = Queue(5)
55
56print("Initial queue:")
57queue1.display()
58print("---")
59
60queue1.enqueue(12)
61queue1.enqueue(77)
62
63print("After inserting two elements:")
64queue1.display()
65print("---")
66
67print(f"Item removed: {queue1.dequeue()}")
68print("After removing an item:")
69queue1.display()
70print("---")
71
72print(f"Item removed: {queue1.dequeue()}")
73print("After removing an item:")
74queue1.display()
75print("---")
76
77# Try removing from an empty queue
78print(f"Item removed: {queue1.dequeue()}")
79queue1.display()
```
