## Implementation of Enqueuing (Adding) Elements

To insert an item into a fixed-size queue, we follow these steps:

- Set rear = -1 when initializing the queue (nothing is inserted yet).
- Each time we enqueue, we increment rear and insert the item at that position.

Here's the code:

```python
1class Queue:
2    
3    def __init__(self, capacity):
4        self.capacity = capacity
5        self.queue = [None] * capacity
6        self.rear = -1  # Points to the last inserted item
7
8    # Insert elements to the queue
9    def enqueue(self, item):
10        self.rear += 1
11        self.queue[self.rear] = item
12
13    # Display the queue
14    def display(self):
15        print(self.queue)
16
17queue1 = Queue(5)
18
19print("Initial queue:")
20queue1.display()
21
22# Insert two items into the queue
23queue1.enqueue(12)
24queue1.enqueue(77)
25
26print("After inserting two elements:")
27queue1.display()
```

Output

```text
Initial queue:
[None, None, None, None, None]
After inserting two elements:
[12, 77, None, None, None]
```
