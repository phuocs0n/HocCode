## Implementation of Dequeuing (Removing) Elements

To remove from a queue:

- front starts at 0 (first element to remove)
- dequeue() returns the element at front, clears it, and moves front forward

Here's how the code looks:

```python
1class Queue:
2    
3    def __init__(self, capacity):
4        self.capacity = capacity
5        self.queue = [None] * capacity
6        
7        # rear points to the last inserted element (starts at -1 because queue is empty)
8        self.rear = -1
9
10        # front points to the element to be removed next
11        self.front = 0
12
13    # Insert elements into the queue
14    def enqueue(self, item):
15        # Move rear to the next position
16        self.rear += 1
17
18        # Add the item at the new rear index
19        self.queue[self.rear] = item
20
21    # Remove elements from the queue
22    def dequeue(self):
23        item_removed = self.queue[self.front]
24        self.queue[self.front] = None
25        self.front += 1
26        return item_removed
27
28    # Display the queue
29    def display(self):
30        print(self.queue)
31
32queue1 = Queue(5)
33
34print("Initial queue:")
35queue1.display()
36
37queue1.enqueue(12)
38queue1.enqueue(77)
39
40print("After inserting two elements:")
41queue1.display()
42
43print(f"Item removed: {queue1.dequeue()}")
44print("After removing an item:")
45queue1.display()
```

Output

```text
Initial queue:
[None, None, None, None, None]
After inserting two elements:
[12, 77, None, None, None]
Item removed: 12
After removing an item:
[None, 77, None, None, None]
```
