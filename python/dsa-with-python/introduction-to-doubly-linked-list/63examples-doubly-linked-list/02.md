## Source Code: Reverse Doubly Linked List

```python
1def reverse(self):
2    # no need to reverse in case of 0 or 1 nodes
3    if self.length() < 2:
4        return
5    
6    # start from head
7    current = self.head
8    while True:
9        # swap previous and next node pointers
10        current.prev, current.next = current.next, current.prev
11        
12        # move to the new previous node
13        current = current.prev
14        
15        # repeat until you reach None
16        if current == None:
17            break
18        
19    # swap head and tail
20    self.head, self.tail = self.tail, self.head
```
