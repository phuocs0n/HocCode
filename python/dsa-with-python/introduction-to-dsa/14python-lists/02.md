## List Slicing Examples

```python
1numbers = [10, 20, 30, 40, 50, 60]
2
3# items from index 0 to 3
4print(numbers[0: 4])    # [10, 20, 30, 40]
5
6# items from index 3 to 4
7print(numbers[3: 5])   # [40, 50]
8
9# using negative index in slicing
10
11# items from the fourth item (3rd index)
12# to the second-last item
13
14print(numbers[3: -1])   # [40, 50]
```

Here, numbers[3: -1] returns a list with items from index 3 to index -2 (because the last index -1 is exclusive and not included in the list).
