## Getting Started

Python is one of the most popular programming languages today. Because of its use in multiple fields, Python is widely used in most companies.

Python's popularity means there are several job openings (more than 100K on Indeed) in the IT sector at any given time.

This 'Python Interview Questions' course includes 100 interview questions that are frequently asked in coding interviews across different companies.

Interview questions in this course include:

- Solved Questions - where you will learn to approach a question and build an overall thought process around the solution
- Theory Questions - where you will revise the most frequently asked Python-specific theoretical questions
- Coding Exercises - where you will apply your knowledge and solve various practice problems

By the end of this course, you will be confident enough to face a Python interview.

If a topic in this course proves to be difficult, you can refer to our Python Courses for revision.

Let's get started.
