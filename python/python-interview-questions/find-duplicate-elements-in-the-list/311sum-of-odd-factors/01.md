## Thought Process

To add the odd factors only, we first need to find all factors of the given number. And from these factors, we can select the odd numbers and then calculate the sum.

Steps to solve the problem,

1. Initialize an empty list to store all factors of a number.
2. Start loop from 1 to the given number.
3. If the iteration number is divisible by the original number, that means the iteration number is a factor of the number.
4. Append the factor to the factors list.
5. Finally, calculate the sum of the odd elements in the factors list using a loop and an if statement.
