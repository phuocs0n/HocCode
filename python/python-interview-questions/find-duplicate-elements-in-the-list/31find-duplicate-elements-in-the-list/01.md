## Thought Process

To find the duplicate elements in a list, we first need to track all the elements encountered during the iteration.

Then, if any element is present more than once, we can mark it as a duplicate.

In this approach, we use two lists:

- seen_elements: to track all the elements we've seen so far
- duplicates: to store any elements that appear more than once in the input list

We start by initializing seen_elements as an empty list to store the elements as we encounter them during the iteration. We also create an empty duplicates list to store any duplicate elements.

We then run a loop through each element of the input list:

- If an element has already been added to seen_elements and is not yet in duplicates, it means the element is a duplicate. We then add it to the duplicates list.
- If the element has not been encountered before, we add it to the seen_elements list to track it.
- At the end of the loop, the duplicates list will contain all the duplicate elements.

This method effectively finds duplicates by checking each element's occurrence and using two lists to keep track of unique and duplicate elements separately.
