## Question

Given a non-empty list, break the list into chunks that contain 4 elements.

For example,

You are given a list of numbers,

```python
numbers = [2, 3, 6, 7, 3, 5, 7, 8, 9, 2, 20, 24, 16, 17, 23, 19]
```

Here, we can break numbers into chunks,

```python
[2, 3, 6, 7]
[3, 5, 7, 8]
[9, 2, 20, 24]
[16, 17, 23, 19]
```
