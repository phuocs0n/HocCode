## Thought Process

To solve this problem, we first need to find the size of the list (represented by n). We can then use the size to find the sum of all the numbers from sequence 1 to n+1 (including the missing number).

We can then find the sum of all elements present in the current list (list with the missing number).

Finally, if we subtract the sum of all elements of the current list from the sum of the sequence, we will get the missing number.

Steps to solve the problem:

1. Find the size of the list, let's say n.
2. Find the sum of the sequence from 1 to n + 1 (use formula: ( (n + 1) * (n + 2) ) / 2 ).
3. Find the total sum of the current list using the sum() function.
4. Subtract the sum of the current list from the sum of the sequence to get the missing number.
