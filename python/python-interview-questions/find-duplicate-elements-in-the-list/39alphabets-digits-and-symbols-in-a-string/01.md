## Thought Process

In Python, there are inbuilt string methods such as isdigit() and isalpha() that helps to check if the element is a digit or an alphabet.

We can solve the problem by following these steps:

1. Create counters for alphabets, digits, and symbols.
2. Loop through each character in a string.
3. By using the isalpha() method, check if the character is the alphabet.
4. If the character is the alphabet, increment the alphabet counter by 1.
5. Again, by using the isdigit() method, check if the character is a digit.
6. If the character is a digit, increment the digit counter by 1.
7. If none of the above conditions satisfy, increment the symbol counter by 1.
8. Finally, print the results of all counters.
