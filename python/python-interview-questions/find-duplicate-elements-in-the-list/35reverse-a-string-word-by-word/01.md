## Thought Process

Here, we have to reverse the string, word by word.

So, we can split the sentence into list elements by the spaces in between. Here, each word will be an element in a list.

Now, we need to reverse the order of the list elements. We can do so by slicing a list using [::-1] or by using the reverse() method. In this solution, we will slice each element into a list by the end.

By doing this, the letters in the element will be in the same order, but the place will be reversed.

Finally, we can join the list with a string by adding a space in between. This will give us our word-by-word reversed string.
