## Thought Process

To solve this problem, we must first understand the snake case and pascal case.

In snake case, all words are in lowercase but separated by an underscore. For example, this_is_written_in_snake_case.

Similarly, in pascal case, each word is separated by the first uppercase letter. For example, ThisIsWrittenInPascalCase.

Now, to convert snake case to pascal case,

1. Use a while loop to iterate through characters in a string by its index.
2. If the character is the first character, capitalize it and add it to a new string.
3. Check if the character is an underscore.
4. If the character is an underscore, skip it and capitalize the next character.
5. If the character is not an underscore, add the character as it is.
