## Thought Process

When an integer is passed, we can find the numbers that come before and after the given number by subtracting and adding 1 respectively.

The following steps can be used to solve this problem:

1. Calculate before by subtracting 1 from the passed number.
2. Calculate after by adding 1 to the passed number.
3. Return the tuple as (before, passed number, after)
