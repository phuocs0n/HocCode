## Thought Process

In any string, the string length must be an odd number to have any letter in between. So this is how we need to structure our program:

- First, we have to check the length of the string.
- If the length of the string is even, we can return the empty string.
- But if the length of the string is odd, then the string has a middle letter and we need to return it.

To find the middle letter, we can

1. Divide the length of the string by 2.
2. Take the floor value of the result. This value is the actual quotient.
3. Then return the letter at the string index value of the quotient.
