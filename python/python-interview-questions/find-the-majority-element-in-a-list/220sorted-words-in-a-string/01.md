## Thought Process

There is a simple solution to this problem. If we can remove the spaces and convert the words to a list, we can easily sort the elements.

In Python, there is an inbuilt string method split() which converts the string into a list. The split() function removes spaces by default and changes the remaining parts into the list.

We can follow these steps to solve the question:

1. Split the sentence into a list of words using the inbuilt Python string method split().
2. Sort the list of words.
3. Loop through each word in the word list and print the word.
