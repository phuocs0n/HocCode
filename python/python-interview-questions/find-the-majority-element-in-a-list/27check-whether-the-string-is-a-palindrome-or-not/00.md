## Question

Write a Python program to check whether or not a string is a palindrome. Your program should print:

- String is Palindrome - if the given string is a palindrome
- String is not Palindrome - if the given string is not a palindrome

A palindrome string is a string that reads the same backward. For example,

- hannah
- level
- radar

Here, the reverse of all the above strings is the same as the original string.
