## Thought Process

Before starting to code, let's think about how we can solve the problem.

Since a palindrome reads the same from the start and the end, it's pretty easy to solve the problem if we can reverse the string.

Once we reverse the string, we can compare the original string with the reversed string. If the original and reversed strings are the same, we know the string is a palindrome.

Now let's see how we can solve this problem.

1. Reverse the original string using slicing with a negative index (string[::-1]).
2. Compare the reversed string with the original one using an if...else statement.
3. If the result is true, then print 'String is Palindrome'.
4. Otherwise, print 'String is not Palindrome'.
