## Thought Process

When a for loop is used in a dictionary, it gives us the key of the pair. Using that key, we can get the value in the dictionary.

Let's look at the steps required to do this.

1. Loop through the dictionary.
2. Looping gives us the key in each iteration of loop.
3. Using that key, we can select the value and increment it by 1.
4. Finally, print the updated dictionary.
