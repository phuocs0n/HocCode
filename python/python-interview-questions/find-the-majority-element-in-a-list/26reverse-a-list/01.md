## Thought Process

In Python, we can use slicing to reverse a list. Let's first understand how slicing works.

Slicing allows us to get any part of any iterable objects (lists, strings, tuples, and so on) in Python.

Here's a syntax of list slicing:

```python
num_list[start_index:end_index:step]
```

You can see three parameters are separated by :

- start_index (inclusive) - specifies from where we should start slicing
- end_index (exclusive) - up to what element we want to slice the list
- step - specifies which item to be selected between start_index and end_index

For example, if we have a list num_list = [1, 2, 3, 4, 5] then

- num_list[3:1:-1] - includes start and end index with negative stop, returns [4, 3]
- num_list[3::] - includes only start index, returns [4, 5]
- num_list[2:3:] - includes start and end index, returns [3]

If you think this concept is difficult to understand, we highly recommend you revisit Python List Slicing.

In the above example, you can see that the negative step has returned the list element in reverse order from index 3 to 1.

Hence, we can use a negative step without a start and end index, num_list[::-1], to get a reversed list: [5, 4, 3, 2, 1].
