## Thought Process

Here, the given list contains strings as elements. We can use list comprehension to create another list by filtering the strings that start with a vowel letter.

We can do this through the following steps:

1. Loop through each element in the first list.
2. Take an element for each element in the list only if the first letter of the element is not in the 'aeiouAEIOU' string.
3. Store the result in another variable.
