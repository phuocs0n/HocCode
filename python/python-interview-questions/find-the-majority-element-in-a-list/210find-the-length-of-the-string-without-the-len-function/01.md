## Thought Process

The length of a string is the number of characters present in the string. In Python, we can find this using the len() function.

However, to find the length of a string without using the len() function, we need to loop through each character in the string.

To do this, we first need to initialize the counter variable with 0.

Then, for each character, we need to increment the length counter by 1.

With this, our length counter will hold the total number of characters in a string, which is the length of the string.
