## Thought Process

Here, we need to create a function that takes a string as a parameter and removes all vowels from the string.

For that, we need to create a string of all vowels in small and capital letters. We also need to create a blank string so that it will hold the string after removing vowels.

Now, we need to loop through each character in a string. If the character is not in the vowel string, we need to concatenate the character in a new string variable.

After completing the loop, we will have a new string by removing all the vowels. Finally, we can print this string.
