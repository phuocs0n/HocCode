## Question

Given a list of numbers of size N, find the kth largest element in the numbers list, where k is less than N.

For example

If you are given a list and a number as

```python
numbers = [2, 3, 1, 5, 6, 4]
k = 3
```

Then, you need to find the 3rd largest element in the numbers list.

Here, the kth (3rd) largest element in the numbers list is 4.

Assumptions: We will assume that:

- All elements in numbers are distant from each other.
- The given array is an unsorted array.
- k < N
