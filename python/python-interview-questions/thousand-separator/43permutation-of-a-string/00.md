## Question

Given a non-empty string, print all the permutations of that string. But before that, let's define permutation.

Permutation refers to the different ways elements from a set can be arranged. For example, given a string pan, the total permutations are:

```python
pan
nap
npa
apn 
pna
anp
```

Similarly, for an input string pro, the total permutations are:

```python
pro
por
rpo
rop
opr
orp
```
