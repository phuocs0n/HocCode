## Thought Process

The permutation of a string is the possible combination of letters in a string. We can swap and shift letters within a string from the given string.

To solve this problem, we will use recursion. Here's how this program will work:

1. Initially, we will create a recursive function that accepts a string and integer (with default value 0) parameters.
2. We will then compare the integer parameter with the length of the string parameter. If they are equal, we will print the string. It will act as a termination condition which will end our recursive function.
3. Run a for loop that starts from the integer parameter to the length of the string.
4. Inside the loop, we will create a list containing each character of the string.
5. We will then swap each character of the string with one another for multiple permutations and make the recursive call to the function.
