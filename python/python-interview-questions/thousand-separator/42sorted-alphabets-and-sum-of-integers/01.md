## Thought Process

Since we are sure the string will only contain alphabets and numbers, we can loop through each character in the string.

If the character is a number, we can append it to a numbers list, whereas if the character is an alphabet, we can append it to a new string.

In Python, the is_digit() method is used to check whether the character is a number or not. If the character is a number, the function returns True.

So, the steps we need to follow are:

1. Create a blank list to store numbers from the string.
2. Create an empty string to store alphabets from the string.
3. Loop through each character in the string.
4. By using the is_digit() method, check if the current character is a digit.
5. If the character is a digit, convert it to an integer and append it to the numbers list.
6. If the character is not a digit, concatenate it to new_string.
7. Now, sort new_string using the sorted() function, which returns a sorted list.
8. Then, join the list elements using the join() method, which creates a string.
9. Calculate the sum of elements in the numbers list using the sum() function.
10. Then, append the sum of numbers to the new string by converting the sum to string.
11. Finally, print the resulting string.
