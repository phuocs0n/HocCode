## Thought Process

There are many ways we can solve this problem. One easy way to solve this problem is by looping through the number by its index. Whenever the index is divisible by 3, we add a comma.

Steps to solve this problem could be,

1. First, we need to convert the passed integer to a string.
2. Then we need to reverse the string as the commas are added from right to left.
3. Also, we need to create an empty string named separated to store the result.
4. Now, we need to loop through the string by its index.
5. If the index is divisible by 3 and is not 0, we need to add a comma to the separated string.
6. Then, we need to add the actual individual digit to the separated string.
7. Finally, we can reverse the separated string again to bring it back to its original order and return the separated number.
