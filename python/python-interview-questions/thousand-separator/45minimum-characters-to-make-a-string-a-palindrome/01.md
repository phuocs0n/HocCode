## Thought Process

At this stage, we know palindrome strings are strings that can be read the same either from start or from the end.

For example, the string exe is a palindrome because the string would be the same when read from either side.

For this problem, we need to count the number of letters needed to make the given string a palindrome.

To do this, we need to follow the given steps:

1. Define the string variable and a counter variable.
2. Run a while loop as long as the length of the string is greater than 0.
3. Then, compare the original string with the reversed string to check if the string is palindrome.
4. If the string is already a palindrome, break the loop.
5. Otherwise, update the string by deleting the last letter from the string and increase the counter by 1.
6. Repeat the same process until the length of the string is 0.
7. Finally, print the counter variable that holds the count of letters needed to make the string palindrome.
