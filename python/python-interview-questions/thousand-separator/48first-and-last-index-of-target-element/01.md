## Thought Process

To find the indexes of the target element, we can loop through the list and update the first and last index when the element is found.

Here are the steps to solve this problem:

1. Initialize the first and last variables to store the first and last occurrence indexes of the target element.
2. Loop through each element in the list using the enumerate() function so that we can access the element along with its index.
3. Inside the loop, we need to check if the current element is our target element.
4. If the current element is our target element, we need to check if the value of the first variable is None.
5. If the first variable is None, update the value of the first variable to the current index. It means this is the first time the target element has been found.
6. Again, outside the if contidition, we need to replace the last index each time the target element is found.
7. Finally, after the loop is completed, we can return the first and last variables in a tuple.
