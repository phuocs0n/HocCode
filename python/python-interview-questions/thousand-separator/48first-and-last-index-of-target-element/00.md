## Question

Given a list of numbers, you are given an element called target_element.

Find the first and last occurrence of target_element and return its index value.

For example

If you are given a list and target element as:

```python
[1, 5, 6, 7, 8, 2, 7, 9, 1]
target_element = 7
```

Then, the index of the first occurrence of 7 is 3.

Similarly, the index of the last occurrence of 7 is 6.

You need to print the two indexes in tuple (3, 6).
