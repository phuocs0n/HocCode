## Question

Given a list of integers, find the smallest missing integer and print it.

The smallest missing positive integer means the smallest integer not present in the given list.

For example

You are given a list:

```python
[2, 4, 6, 5, 1, 0]
```

Here, the smallest missing positive integer is 3.

If we arrange the elements in the list in a sequence, here's how it'll be: 1, 2, 4, 5, 6. Now you can see that the smallest missing integer is 3.

Assumptions: We will assume that:

- The given list is an unsorted list.
- Every element in the array is distinct.
