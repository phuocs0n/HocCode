## Thought Process

In this problem, we are trying to make the list elements continuous. It doesn't matter from what number the list starts or to what number the list ends.

Because of that, we should sort the list first. Then, for the list to be continued, adding 1 to each element should make the next element in a list.

If adding 1 to the element doesn't make the next element, that means the next element that should be, is our smallest missing element.

Steps to solve this problem,

1. First of all, sort the elements in a list using the sort() function.
2. Then, we need to loop through the list using the enumerate() function so that we can access the index and element in each iteration.
3. Now, if adding 1 to the current element makes the next element, we need to continue the loop as the sequence is already continuous.
4. However, if adding 1 to current element does not make next element, the element that should be, is the smallest required missing number.
