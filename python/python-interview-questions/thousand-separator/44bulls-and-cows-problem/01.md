## Thought Process

In this Python program, we need to create a function that takes two parameters - the secret number and the guess - in string format.

Then, we have to initialize bulls and cows variables to store the numbers of bulls and cows.

Now, loop from 0 to the length of the secret number. Within the loop, check if the digits in secret and guess at the same index are equal or not. If it is, increment the bulls variable by 1.

If the digits in secret and guess are not equal, we need to check if the digit at the current index in secret is also in guess. If it is, we need to increment the cows variable by 1.

Finally, print the number of bulls and cows in the required format, i.e., xAyB.
