## Thought Process

We know that if adding two elements, a and b, gives the result t, then subtracting one element from the result gives another element. That is,

```python
a + b == t
t - a == b
t - b == a
```

We will use the same logic to find the combinations of numbers whose sum results in the target value.

We can loop through each element in the list and subtract it from the target value. If the difference is also in the list, that means the current element and the difference value can make a sum.

But there is still a problem left: the same combination will be scanned twice and will be printed twice as well.

To solve this problem, we can create a temporary list to append the value once it is scanned. Then we will print the combination only if target - current element is in the temporary list. This way, there will be no repeating of elements.

Here are the steps to solve this problem:

1. Initialize the temporary list.
2. Loop through each element in the original list.
3. If the difference between the target number and the current element is in the temporary list, print both elements.
4. Also, add the current element to the temporary list.
5. Do the same for all other elements in the original list.
