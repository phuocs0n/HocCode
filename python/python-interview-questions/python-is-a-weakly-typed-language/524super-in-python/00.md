## What is super() in Python?

The super() method is used to call the parent class's properties from the child class. Using super(), we can invoke any method or constructor of the parent class. For example,

```python
1class Person:
2    def __init__(self, name):
3        self.name = name
4
5    def walk(self, to):
6        print(self.name, 'is walking to', to)
7
8
9class Student(Person):
10    def __init__(self, name):
11        super().__init__(name)
12
13    def go_school(self):
14        super().walk(to='school')
15
16    def go_home(self):
17        super().walk(to='home')
18
19
20obj = Student('John')
21obj.go_school()
22obj.go_home()
23
24# Output:
25# John is walking to school
26# John is walking to home
```

Here, we have used super() to call the constructor and methods of the parent class (Person) from the child class (Student).
