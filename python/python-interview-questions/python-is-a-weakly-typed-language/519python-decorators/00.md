## What are Python Decorators?

Python has an interesting feature called decorators to add functionality to an existing code. It simply takes in a function, adds some functionality, and returns it.

We can create decorators in Python by creating a nested function. Let's try to understand this by example,

```python
def liner(func):
    def inner():
        print('----------')
        func()
        print('----------')

    return inner
```

Here, the above codee is our decorator. A liner() function takes another function as a parameter. Inside the liner() function, we have defined the inner() function, which simply prints the line before and after executing the passed function.

Then, we returned the inner() function from the liner() function.

Now, let's use this decorator.

```python
def normal():
    print('normal')


decorated = liner(normal)
decorated()
```

Here, we defined another function that needs to be decorated. We called the liner() function with the normal() function as a parameter. Also, we stored the returned function from the liner() in the decorated variable.

Now, when we call the decorated() function, we'll get this as output.

```text
----------
normal
----------
```

There's also another way to decorate the function by using the @ symbol. Here's how,

```python
@liner
def decorated():
    print('decorated')


decorated()
```

This works the same way as before.
