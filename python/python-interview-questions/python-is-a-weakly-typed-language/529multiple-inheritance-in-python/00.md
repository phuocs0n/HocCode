## Does Python Support Multiple Inheritance?

Yes, Python supports multiple inheritance.

Take a look at this example,

```python
1class Person:
2    def can_walk(self):
3        print('person can walk')
4        
5class Student:
6    def can_study(self):
7        print('Student can study')
8        
9
10class Boy(Person, Student):
11    pass
12
13
14b = Boy()
15b.can_walk()
16b.can_study()
```

Here, Person and Student are two separate classes. But the Boy class is inherited from both the Person and Student classes.
