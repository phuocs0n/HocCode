## range() With One Argument

If we use the range() function with only one argument, it will return a sequence of numbers from 0 to that number. For example,

```python
1# numbers from 0 to 4
2numbers = range(5)
3
4# convert numbers to list for printing
5numbers = list(numbers)
6
7print(numbers)
8
9# Output
10# [0, 1, 2, 3, 4]
```

Here, range(5) returns a sequence of numbers from 0 to 4.

Suppose we have to iterate a loop n number times. Here's the easiest way to do it:

```python
1n = 3
2
3for i in range(n):
4    print("Hello")
```

Output

