## The tuple() Function

The tuple() function converts an iterable (list, string, dict, or set) to a tuple. For example,

```python
1# convert list to tuple
2result = tuple([1, 2, 3])   # (1, 2, 3)
3print(result)
4
5# convert string to tuple
6result = tuple("Hello")   # ('H', 'e', 'l', 'l', 'o')
7print(result)
8
9# convert dictionary to tuple
10# dictionary's keys will be tuple's items
11result = tuple({2: 4, 10: 20})   # (2, 10)
12print(result)
13
14# convert set to tuple
15result = tuple({1, 2, 3})   # (1, 2, 3)
16print(result)
```
