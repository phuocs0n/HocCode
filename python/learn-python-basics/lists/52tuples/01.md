## Creating Tuples

A tuple is created by putting items inside () separated by commas.

```python
1# a tuple of numbers
2numbers1 = (10, 20, 30)
3print(numbers1)   # (10, 20, 30)
4
5# empty tuple
6numbers2 = ()
7print(numbers2)
8
9# tuple of mixed data types
10mixed_tuple = (1, 'Hello', [3, 4])
11print(mixed_tuple)  # (1, 'Hello', [3, 4])
```

### Creating a Tuple With Only One Item

Creating a tuple with only one item is a bit tricky.

If we put a single item inside (), it will create a string. For example,

```python
1text = ('Hello')
2print(text)   # Hello
```

To create a tuple with one item, we also need to put a trailing comma to indicate that it is, in fact, a tuple.

```python
1tuple1 = ('Hello',)
2print(tuple1)   # ('Hello',)
```
