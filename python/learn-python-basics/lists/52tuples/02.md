## Tuple Length

We use the same len() function to get the number of items a tuple has. For example,

```python
1# tuple containing 3 items
2languages = ('Python', 'JavaScript', 'C++')
3
4length = len(languages)
5print(length)    # Output: 3
6
7# empty tuple
8animals = ()
9
10length = len(animals)
11print(length)   # Output: 0
```
