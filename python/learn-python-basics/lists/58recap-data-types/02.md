## Example: Get Substring From a String

We can use slicing to get a substring from a string. For example,

```python
1my_string = "I love Python"
2
3# print characters from index 2 to 5
4print(my_string[2:6])    # love
5
6# print characters from index 2 to last character
7print(my_string[2:])    # love Python
```
