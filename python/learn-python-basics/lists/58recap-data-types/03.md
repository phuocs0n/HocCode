## Example: Get the Value if Key Exists

In this example, we will check if a key exists in a dictionary. If the key is in the dictionary, we will print its value.

```python
1cubes = {'one': 1, 'two': 2, 'three': 3}
2
3if 'three' in cubes:
4    print(cubes['three'])
```

Output

```text
3
```

Here, 'three' in cubes returns True because the 'three' key is in the cubes dictionary. Hence, we printed its corresponding value using cubes['three'].
