## Example: Get the Largest Item

In this example, we will print the largest item of the list.

```python
1numbers = [10, 45, 61, -6]
2
3# assign the first value to the largest variable
4# we will update the largest variable inside the loop
5largest = numbers[0]
6
7# loop iterates from 0 to last item of numbers
8for number in numbers:
9    if largest < number:
10        largest =  number
11
12print(f"largest: {largest}")
```

Output

```text
largest: 61
```

Initially, the first number is assigned to the largest variable.

```python
largest = numbers[0]
```

Then, we used a for loop to iterate from the first item to the last item.

In each iteration, if the number variable (the current item of the list) is larger than the largest variable, we assign number to the largest variable.

```python
# inside the loop
if largest < number:
    largest = number
```

Here's how this code works:

| Iteration | number | largest < number | largest |
| --- | --- | --- | --- |
| 1st | 10 | False | 10 |
| 2nd | 45 | True | 45 |
| 3rd | 61 | True | 61 |
| 4th | -6 | False | 61 |

#### The max() Function

There's an easier way to accomplish the same task using the built-in max() function, which returns the largest item of an iterable (lists, tuples etc.).

```python
1numbers = [10, 45, 61, -6]
2
3# get the largest number
4largest = max(numbers)
5
6print(f"largest: {largest}")
7
8# Output
9# largest: 61
```
