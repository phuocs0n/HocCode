## Creating Sets

A set is created by placing items inside curly braces {}, separated by commas. For example,

```python
1animals = {'dog', 'cat', 'tiger'}
2print(animals)   # {'dog', 'cat', 'tiger'}
3
4mixed_set = {4, 'tiger', 3.5}
5print(mixed_set)   # {3.5, 'tiger', 4}
```

If we look at the output, we can see that items may be printed in a different order.

### Duplicate Items in a Set

Now, let's see what will happen if we try to include duplicate items in a set.

```python
1numbers = {1, 2, 1, 5, 2}
2print(numbers)   # {1, 2, 5}
```

Here, we can see that there are no duplicate items in the set since a set cannot contain duplicates.

### Creating an Empty Set

We cannot create an empty set using {} because it would create a dictionary instead. To create an empty set, we use the built-in set() function.

```python
1# empty set
2my_set = set()
3
4print(my_set)   # set()
```
