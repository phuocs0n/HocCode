## Concatenate (Join) Strings

We can concatenate two strings using the + operator.

```python
1first_name = "Jack"
2last_name = "Sparrow"
3
4name = first_name + " " + last_name
5print(name)   # Jack Sparrow
```

In the above program, we used the + operator to concatenate three strings:

- the value of first_name (which is "Jack")
- a string containing a single space " " (serves as a separator between first_name and last_name)
- the value of last_name (which is "Sparrow")
