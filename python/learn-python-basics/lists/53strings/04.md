## Escape Sequences

Suppose, we want to print a string like this:

```text
"What's there?", asked Paul
```

Since there are quotation marks in it, we have to use \' to indicate ' and \" to indicate ". For example,

```python
1text = "\"What\'s there?\", asked Paul"
2print(text)
```

Output

```text
"What's there?", asked Paul
```

Here, \' and \" are called escape sequences. They allow us to include special characters in strings.

Another commonly used escape sequence is \n, which is used for newline (next line).

```python
1print("Hey\nHello\nHowdy?")
```

Output

```text
Hey
Hello
Howdy?
```

As you can see, when \n is encountered, it's treated as a newline.
