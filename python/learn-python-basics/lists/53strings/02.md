## Creating Strings

We know a string is created using single quotes or double quotes.

However, there are also other ways to create strings: using triple single quotes or triple double quotes. For example,

```python
1# use triple double quotes
2text1 = """Hello"""
3print(text1)   # Hello
4
5# use triple single quotes
6text2 = '''Hey'''
7print(text2)   # Hey
```

Usually, triple quotes are used to create multiline strings. For example,

```python
1lyrics = '''Don't stop believing
2Hold on to that feeling
3Streetlight, people'''
4
5print(lyrics)
```

Output

```text
Don't stop believing
Hold on to that feeling
Streetlight, people
```
