## Strings

So now you know — anything inside quotes is a string in Python. Like this:

```python
"This is a string."
```

But guess what? You can also use single quotes:

```python
'This is also a string.'
```

To show them on the screen, just wrap them inside the print() function, like this:

```python
1print("This is a string.")
2print('This is also a string.')
```

Go ahead — click the Run Code button to see the output.

You can use single or double quotes — just try to be consistent so your code stays nice and tidy.
