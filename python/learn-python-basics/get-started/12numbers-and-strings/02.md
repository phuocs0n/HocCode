## Be Careful When Using Strings

If you do not wrap text inside quotation marks, it is not recognized as a string. For example:

```python
1print(Hey there)
```

Output

```python
ERROR!  File "<string>", line 1
    print(Hey there)
          ^^^^^^^^^
SyntaxError: invalid syntax. Perhaps you forgot a comma?
```

If you execute this program, you will get an error.

Here is another example:

```python
1print("Hey)
```

Output

```python
ERROR!  File "<string>", line 1
    print("Hey)
          ^
SyntaxError: unterminated string literal (detected at line 1)
```

You will get an error here because the closing quotation mark is missing at the end of "Hey.

These kinds of errors are super common when you're starting out, so don't worry — you'll get the hang of it!
