## Error Converting String to Integer

We cannot convert all types of strings to integers. Let's take an example.

```python
1string_number = "Howdy!"
2
3
4# Convert string to integer
5integer_number = int(string_number)    # Error!
6
7
8print(integer_number)
```

Output

```text
ValueError: invalid literal for int() with base 10: 'Howdy!'
```

Here, Python cannot convert "Howdy!" to its equivalent integer because this string consists of alphabets instead of just numbers. Hence, we will get an error.
