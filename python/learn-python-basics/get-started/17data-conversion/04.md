## Error Converting String to Float

We have already learned not all strings can be converted to integers. Similarly, some strings can't be converted to floating-point numbers. Let's look at an example to see why.

```python
1string_number = "12a"
2
3
4# Convert string to float
5float_number = float(string_number)    # Error!
6
7
8print(float_number)
```

Output

```text

```

Here, Python cannot convert "12a" to its equivalent floating-point number. Hence, we will get an error.
