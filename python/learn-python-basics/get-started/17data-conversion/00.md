## Introduction to Data Conversion

So far in this course, you've learned to work with three different types of data:

- Integer - 5, -6, 17, 0.
- Float - 5.6, 0.0, -7.84, 16.0.
- String - "hello there", "5", "Number is 5.0".

In real-world projects, data may not always be in the format you need. For example, numbers might be stored as text, such as "5.3".

In such situations, you may need to change data from one type to another. In this lesson, you will learn to perform such data conversions.
