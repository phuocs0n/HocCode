## + Operator

As we have seen from the last example, the + operator is used to add operands (values and variables).

```python
1x = 10
2y = 20
3
4# Use + to perform addition
5total = x + y + 30
6
7print(total)    # Output: 60
```

In the program, total = x + y + 30 first computes the sum of x, y, and 30. Then, the result is assigned to the total variable.
