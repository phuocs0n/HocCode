## Print Multiple Values

We can print multiple pieces of data at once by separating them with commas. For example:

```python
1# Display three numbers
2print(67, -5, 19)
3
4# Display two strings
5print("Hey.", "Are you enjoying the course?")
6
7# Display numbers and strings
8print("Rating:", 8.5)
```

Output

```text
67 -5 19
Hey. Are you enjoying the course?
Rating: 8.5
```

Here, the comma is used for separation and is not printed.

Additionally, spaces before or after the comma don't affect the output. By default, print() always inserts a single space between the values.
