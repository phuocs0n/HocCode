```python

4print(f"Hey {first_name} {last_name}!")
```

Data conversion

The data you are trying to use may not always be in the required format. In such situations, you need to perform data conversions.

```python
1# Convert strings to integers
2x = int(input("Enter the first number: "))
3y = int(input("Enter the second number: "))
4
5remainder = x % y
6power = x ** y
7
8print(f"Remainder: {remainder}")
9print(f"Power: {power}")
```
