## User Input Without Prompt

Let's take another example of user input.

```python
1full_name = input()
2print("Full Name:", full_name)
```

Sample Output

```text
Micheal Smith
Full Name: Micheal Smith
```

Here, we have used the input() function without putting text (prompt message) inside it.

The full_name = input() function doesn't print anything but makes the program wait until the user enters some input.

When the user types something and hits the ENTER key, it is assigned to the full_name variable.
