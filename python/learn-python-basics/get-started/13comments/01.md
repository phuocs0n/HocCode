## Python Comments

In Python, we use the # symbol to write comments in our code.

On the last page, we saw that writing something like this:

```python
1print(34.0) this shows the temperature
```

will give you an error. That's because Python tries to read everything on the line, and it doesn't know what to do with the extra text.

But sometimes, you do want to write a quick note to explain what a line of code is doing. To do that without causing an error, you can use a comment.

Just add a # before the explanation, like this:

```python
1print(34.0)  # This shows the temperature
```

Now Python will run the first part (print(34.0)) and completely ignore anything after the #. In fact, Python skips any line that starts with #—it doesn't run it, and it won't appear in the output at all.
