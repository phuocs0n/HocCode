## Convert Kilometers to Miles

We can convert distance in kilometers to miles using this formula:

```python
1 kilometer = 0.621 miles
```

#### Example

```python
1# Program to convert distance in kilometer to miles
2# The distance will be entered by the user
3
4# Get distance in kilometers 
5km = float(input("Enter distance in km: "))
6
7# Conversion ratio
8ratio = 0.621
9
10# Compute distance in miles
11miles = km * ratio
12print(f"Distance in miles: {miles}")
```

Output

```text
Enter distance in km: 10
Distance in miles: 6.21
```

Here's how this program works.

In line 6: km = float(input("Enter distance in km: "))

We are taking input from the user using the expression input("Enter distance in km: ").

Before it's assigned to the variable, we have converted it to a floating-point number using the float() function. It's because we want the distance to be a number, not a string.

In line 12: miles = km * ratio

We then calculated the distance in miles by multiplying the distance in kilometers by 0.621.
