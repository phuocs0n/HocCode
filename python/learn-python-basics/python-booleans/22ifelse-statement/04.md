## Indentation is Important

A small mistake in indentation can lead to unexpected behavior or errors. Let's try one more example to see how indentation affects code execution.

Consider this program:

```python
1# Check eligibility for discount.
2
3total = float(input("Enter the total amount: "))
4
5# check if total is greater than 100
6if total > 100:
7    print("Congratulations!")
8    print("You are eligible for a discount")
9
10print("Program ends.")
```

Here, the two print() statements immediately after the if block are indented, making them part of the if block:

```python
print("Congratulations!")
    print("You are eligible for a discount")
```

However, the following line is not indented and is not part of the if block:

```python
print("Program ends.")
```

That's why the last print() statement always executes, regardless of whether total > 100 is True or False.
