## Understanding Booleans

Boolean values, True and False, are fixed values, similar to numbers like 25, 5.9, or text like "Hello". This means:

1. Booleans aren't strings

"True" is a string (text). However, when you use True without quotation marks, it's a boolean value.

The boolean value True generally means yes and False means no. This property makes booleans essential for creating programs that make decisions.

2. Booleans are not variables

Even though True and False might seem like variable names, they can't be used as variables because they are fixed values, like numbers and strings. For example:
