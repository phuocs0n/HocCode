## Booleans

A boolean is a data type, like integers, floating-point numbers, and strings.

However, unlike numbers and strings, which can represent many values, booleans can only have one of two possible values: True or False. Let's look at an example.

```python
1result1 = True
2result2 = False
3
4print(result1)
5print(result2)
```

Output

```text
True
False
```
