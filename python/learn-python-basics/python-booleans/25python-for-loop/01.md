## Example: Iterator Over a String

Consider this example:

```python
1name = "Eva"
2
3for character in name: 
4    print("Hello")
```

Here's how you read this for loop code in plain English:

For each character in the name string, execute the block of code (in this case, printing "Hello").

Output

```text
Hello
Hello
Hello
```

Since the string has three characters, the loop runs three times, and "Hello" is printed once for each character.
