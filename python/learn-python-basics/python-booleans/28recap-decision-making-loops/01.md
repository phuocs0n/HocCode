## Recap (II)

When working with loops, you often need more control over how the loop runs. This is where the break and continue statements come in.

#### The break Statement

The break statement terminates the loop immediately when it is encountered.

```python
1# Iterate from 1 to 100
2for i in range(1, 101):
3
4    # Terminate the loop when i becomes 3
5    if i == 3:
6        break
7
8    print(i)
```

Output

```text
1
2
```

### The continue Statement

The continue statement skips the rest of the code in the current iteration and moves directly to the next iteration of the loop.

```python
1# Iterate from 1 to 5
2for i in range(1, 6):
3
4    # Skip printing when i is 3 or 4
5    if i == 3 or i == 4:
6        continue
7
8    print(i)
```

Output

```text
1
2
5
```
