The if Statement

Instead of simply executing code sequentially, you can use the if statement to perform different tasks based on specified conditions.

```python
1car_color = "black"
2
3if car_color == "white":
4    print("You have a white car.")
5else:
6    print("You do not have a white car.")
```

The while Loop

You can use loops to execute code repeatedly. The while loop repeats a block of code as long as its condition evaluates to True.

```python
1# Program to take input until user enters a positive integer
2number = int(input("Enter an integer: "))
3
4while number <= 0:
5    number = int(input("Enter an integer: "))
6
7print(f"Positive number you entered: {number}")
```

The for Loop

The for loop is used to iterate over a sequence.

```python
1# Loop through numbers from 1 to 3 (inclusive)
2for i in range(1, 4):
3    print(i)
```
