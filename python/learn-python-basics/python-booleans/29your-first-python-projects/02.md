# Your Project Options

#### Course: Learn Python Basics

## Your Project Options

Here's what you can build:

1. Student Grade Calculator

- Enter marks for subjects, calculate an average, and decide a grade.
- Great for practicing logic and formulas.

2. Simple Calculator

- Add, subtract, multiply, and divide—like a real calculator.
- Perfect for performing calculations on user input.

3. Number Guessing Game

- The computer picks a secret number. You try to guess it.
- A fun way to practice loops and decision-making.

Each choice is equally valuable—it's up to you whether you want to start with something practical, functional, or fun.
