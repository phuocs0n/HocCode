## The while Loop

In Python, there are two types of loops: while loop and for loop. Let's learn about the while loop in this lesson.

The syntax of the while loop is:

```python
while condition:
    statement(s)
```

The while loop runs the statements inside it as long as the condition (a boolean expression) evaluates to True.

Unlike an if statement that only executes once, the while loop repeatedly checks the condition and continues execution until the condition evaluates to False.
