## while Loop

Here's the program from the last page:

```python
1count = 1
2
3while count <= 3:
4    print("I am inside a loop.")
5    print("Looping is interesting.")
```

Here, the loop continues forever because the boolean expression, count <= 3, is never False. The value of count is always 1.

To run this loop only a fixed number of times, we need to update the value of the count variable inside the loop so that count <= 3 eventually evaluates to False. Here's how:

```python
1count = 1
2
3# Loop continues as long as count is 3 or less
4while count <= 3:
5    print("I am inside a loop.")
6    print("Looping is interesting.")
7
8    # Increment count by 1 in each iteration
9
10    count = count + 1
11
12
13print("OUTSIDE THE LOOP")
```

Output

```text
I am inside a loop.
Looping is interesting.
I am inside a loop.
Looping is interesting.
I am inside a loop.
Looping is interesting.
OUTSIDE THE LOOP
```

In the program, we have added a statement, count = count + 1, to increase the value of count by 1 in each iteration of the loop.

The value of count changes as follows:

- 1 in the first iteration
- 2 in the second iteration
- 3 in the third iteration

When count is updated to 4, the condition count <= 3 evaluates to False, and the loop terminates.

After the loop terminates, the next statement, print("OUTSIDE THE LOOP"), is executed.
