## Example: while Loop

```python
1count = 1
2
3# Loop continues as long as count is 3 or less
4while count <= 3:
5    print("I am inside a loop.")
6    print("Looping is interesting.")
```

Here, the body of the loop contains two print statements. We know this because of the indentation before them (spaces at the beginning).

If you run this program, the two statements inside the loop are executed again and again.

Output

```text
I am inside a loop.
Looping is interesting.
I am inside a loop.
Looping is interesting.
... .. ...
```

Let's analyze what this program is doing.

- Initially, count is 1. The boolean expression count <= 3 evaluates to True and the loop body is executed.
- Again, count <= 3 is evaluated. As it's still True, the loop body is executed.
- In this program, count <= 3 never becomes False, hence the loop runs forever.

This is called an infinite loop because the boolean expression is never False and the loop runs forever. It also means that the end of the program is never reached.

The code above is equivalent to:

```python
1while True:
2    print("I am inside a loop.")
3    print("Looping is interesting.")
```

In many situations, however, rather than running a loop forever, we want the loop to end at some point.

Next, you'll learn to make this happen.
