## Logical Operator: and

The and operator evaluates to:

- True if both boolean expressions are True
- False if either of the expressions is False

Example

Suppose a bank offers a loan if the applicant's credit score is 700 or higher, and they have a stable income.

In this case, both conditions must be True for the applicant to qualify for the loan. This is where the and operator is applied.

Here's what this condition looks like:

```python
condition = (credit_score >= 700) and (stable_income == "yes")
```

By the way, it's not necessary to use parentheses. The above code is equivalent to:

```python
condition = credit_score >= 700 and stable_income == "yes"
```

Next, we'll use this condition inside the if...else statement.
