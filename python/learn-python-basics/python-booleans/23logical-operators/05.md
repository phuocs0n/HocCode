## Largest of Three Numbers

We will now build the logic to find the largest number among n1, n2, and n3.

We know n1 is the largest number if:

- n1 is greater than n2, and
- n1 is greater than n3

Similarly, we can check if n2 or n3 is largest using the same logic. To solve this problem, we can use the and operator.

Here's the complete code:

```python
1# User input
2n1 = int(input("Enter the first number: "))
3n2 = int(input("Enter the second number: "))
4n3 = int(input("Enter the third number: "))
5
6# Check if n1 is the largest?
7if (n1 >= n2) and (n1 >= n3):
8    largest = n1
9
10# Check if n2 is the largest?
11elif (n2 >= n1) and (n2 >= n3):
12    largest = n2
13else:
14    largest = n3
15
16print("The largest number is:", largest)
```
