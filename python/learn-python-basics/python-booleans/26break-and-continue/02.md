## Break with if...else Statement

Consider this scenario where you have a list of integers (both positive and negative). Your task is to display the numbers until the first negative integer is found.

Let's first write code to loop through each item of the list.

```python
numbers = [10, 15, 20, -5, 30, -40]
for number in numbers:
    print(number)
```

Since you need to display numbers only until the first negative integer is found, you can add a condition to check if the number is negative. If it is, use the break statement to exit the loop.

```python
1numbers = [10, 15, 20, -5, 30, -40]
2for number in numbers:
3
4    # Exit loop is negative number is found
5    if number < 0:
6        break
7
8    # Print the number because it's not negative
9    print(number)
```

Output

```text
10
15
20
```
