## Python break Statement

The break statement terminates the loop immediately when it is encountered. For example,

```python
1# Iterate from 1 to 5
2for i in range(1, 6):
3    print(i)
4 
5    # The break statement
6    break
7
8print("This is outside the loop.")
```

Here, in the first iteration of the loop, the value of i (which is 1) is printed. Then, the break statement is encountered, which terminates the loop.

The program then proceeds to execute the code outside the loop.

Output

```text
1
This is outside the loop.
```

You might be wondering why use a break statement if it terminates the loop immediately.

Usually, we want to terminate the loop only when the specified condition is met. For this reason, the break statement is almost always used inside an if..else statement. Let's explore it next.
