## Example: Nested Loops

```python
1# outer loop iterates from i = 0 to 2
2for i in range(3):
3    # inner loop iterates from j = 0 to 1
4    for j in range(2):
5        print(f"i = {i}, j = {j}")
```

Output

```text
i = 0, j = 0
i = 0, j = 1
i = 1, j = 0
i = 1, j = 1
i = 2, j = 0
i = 2, j = 1
```

In this program, the outer loop iterates from i equals 0 to 2. In each iteration of the outer loop, the inner loop iterates from j equals 0 to 1.
