## Nested Loops

It's possible to put a loop inside another loop. This is known as a nested loop.

In a nested loop, the inner loop is executed for each iteration of the outer loop. Let's try to understand it with the help of an example.

```python
1attributes = ['Electric', 'Fast']
2cars = ['Tesla', 'Porsche', 'Mercedes']
3
4for attribute in attributes:
5    for car in cars:
6        print(attribute, car)
```

Output

```text
Electric Tesla
Electric Porsche
Electric Mercedes
Fast Tesla
Fast Porsche
Fast Mercedes
```

Here, the inner loop is iterated once for each item of the attributes list. Here's how this code works:

First iteration of the outer loop

| Inner Loop Iteration | attribute | car |
| --- | --- | --- |
| 1 | 'Electric' | 'Tesla' |
| 2 | 'Electric' | 'Porsche' |
| 3 | 'Electric' | 'Mercedes' |

Second iteration of the outer loop

| Inner Loop Iteration | attribute | car |
| --- | --- | --- |
| 1 | 'Fast' | 'Tesla' |
| 2 | 'Fast' | 'Porsche' |
| 3 | 'Fast' | 'Mercedes' |
