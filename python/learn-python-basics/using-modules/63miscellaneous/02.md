## Example: Arithmetic Operators

Example 1

```python
1total = 100
2
3total += 10   # total = total + 10
4print(total)
5
6# Output: 110
```

Here, total += 10 adds 10 to the total variable.

Example 2

```python
1x = 10
2
3x //= 4   # x = x // 4
4print(x)
5
6# Output: 2
```

Here, x //= 4 computes the quotient when x is divided by 4, and assigns the quotient to x.
