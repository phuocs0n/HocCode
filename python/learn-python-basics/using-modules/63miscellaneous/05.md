## Example: Truthy and Falsy

Suppose we need to find the largest number between three numbers.

```python
1n1 = 20
2n2 = 10
3n3 = 30
4
5if n1 > n2 and n3:
6    print(n1)
7elif n2 > n1 and n3:
8    print(n2)
9else:
10    print(n3)
```

Output

```text
20
```

Here, we are getting 20 as the largest number.

Can you find out where the error is?

Take a look at this code:

```python
if n1 > n2 and n3:
    print(n1)
```

Here, n1 > n2 evaluates to True, and n3 also evaluates to True because 30 is considered True.

Instead here's what we should have written:

```python
if n1 > n2 and n1 > n3:
    print(n1)
```
