## Assignment Operators

We have used the = operator many times in our code. It's used to assign a value to a variable. For example,

```python
# assign 3.1415 to the pi variable
pi = 3.1415
```

Now, let's take a look at other assignment operators.

| Operator | Example | Equivalent to |
| --- | --- | --- |
| += | x += 5 | x = x + 5 |
| -= | x -= 5 | x = x - 5 |
| *= | x *= 5 | x = x * 5 |
| /= | x /= 5 | x = x / 5 |
| %= | x %= 5 | x = x % 5 |
| //= | x //= 5 | x = x // 5 |
| **= | x **= 5 | x = x ** 5 |

These assignment operators perform arithmetic and assignment operations at the same time.
