## Recap (I)

As you write more complex programs, you'll quickly encounter repetitive code. Functions help you structure your code to make it reusable and organized.

Functions don't add additional logic; they are a tool that organizes and reuses existing logic efficiently.

#### Define a Function

Here's an example to define a function:

```python
# Define the function
def calculate_product():
    n1 = int(input("Enter a number: "))
    n2 = int(input("Enter a number: "))
    
    total = n1 * n2
    print(total)
```

### Function Call

Creating a function doesn't run it; you need to call the function to run its code.
