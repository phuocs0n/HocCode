## Local Variables

Any variable that is created inside a function definition is local to that function. In other words, the variable doesn't exist outside the function. For example:

```python
1def add_numbers(n1, n2):
2    result = n1 + n2
3
4add_numbers(2, 5)
5print(result)
```

Here, when the execution of the add_numbers() function ends, all the variables inside it: n1, n2, and result, are destroyed.

This is the reason why the above program throws an error. Python thinks the result variable is not defined.

If you remember, you can fix it by using a return statement.

```python
1def add_numbers(n1, n2):
2    result = n1 + n2
3    return result
4
5output = add_numbers(2, 5)
6print(output)
```

By using a return statement, you are not using the local variable directly. Instead, you're returning its value to the function call.
