## Why Are Local Variables Important?

Local variables are important because they make functions self-contained, independent, and versatile.

As we discussed earlier, the inner workings of a function and the variables it uses don't matter as long as we understand two key aspects:

- Arguments that the function takes.
- Return value from the function.

Source Code

```python
1def add_numbers(n1, n2):
2    result = n1 + n2
3    return result
4
5n1 = 2
6n2 = 5
7result = add_numbers(n1, n2)
8print(result)    # Output: 7
```

In this program, it's important to understand that n1, n2, and result variables inside the function are local to the add_numbers() function.

They are different from n1, n2, and result variables that are outside of the function (even though their names are identical).
