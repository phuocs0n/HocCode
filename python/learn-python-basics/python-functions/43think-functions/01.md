## Example: Sum of Natural Numbers From 1 to n

### Program Summary

Write a program to find the sum of the first n natural numbers (where n is a positive integer) by creating a function. The function should work for any positive integer.

```python
total = 1 + 2 + 3 + ... + n
```

### Arguments and Return Value

Arguments

We are finding the sum from 1 to n. Our function will take only one argument, n. It's because the first number will always be the same value 1.

Return Value

The function should return the sum of numbers.

### Source Code

```python
1def compute_sum(number):
2    total = 0
3
```
