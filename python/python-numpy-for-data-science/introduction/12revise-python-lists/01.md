## Creating Lists

A List can store any number of items. And these items may be of different types (int, float, str, etc.).

Let's take a look at some examples:

```python
1# empty list
2list1 = []
3print(list1)   # Output: []
4
5# list of integers
6numbers = [1, 2, 3]
7print(numbers)   # Output: [1, 2, 3]
8
9# list with mixed data types
10mixed_list = [1, "Hello", 3.4]
11print(mixed_list)   # Output: [1, 'Hello', 3.4]
12
13# list with duplicate items
14list2 = [1, 2, 3, 1, 3]
15print(list2)   # Output: [1, 2, 3, 1, 3]
```

A list can also contain another list as an item. This is called a nested list

```python
1# nested list
2list1 = ['mouse', [1, 2, 3], [4]]
3print(list1)   # Output: ['mouse', [1, 2, 3], [4]]
```
