## What Does This Course Cover?

In this Python NumPy for Data Science course, you'll learn:

- The fundamentals of NumPy
- How to create 1-D and n-D NumPy arrays
- Methods to manipulate data in arrays, and much more

- Learn a concept.
- Edit and run NumPy code.
- Reinforce your learning with quizzes, exercises, and a project.

By the end, you'll be writing multiple programs using NumPy and feel confident working with NumPy arrays.
