## Array Slicing

NumPy array slicing works similar to Python's list slicing.

Array slicing allows us to access a subset of elements of a Numpy array. For example,

```python
1import numpy as np
2
3# create a numpy array
4numbers = np.array([2, 4, 6, 8, 10])
5
6# access the first 3 elements of the array
7sliced_numbers = numbers[:3]
8print(sliced_numbers)
9
10# Output: [2 4 6]
```

Here, numbers[:3] selects the elements at indices 0, 1, and 2 of the array. Here, 3 is the stop parameter that specifies the last index where slicing ends.

We can also include the start parameter to specify the first index from where we want to start your slicing.

For example,

```python
1import numpy as np
2
3# create a numpy array
4numbers = np.array([2, 4, 6, 8, 10])
5
6# access elements from index 1 up to 4
7sliced_numbers = numbers[1:4]
8print(sliced_numbers)
9
10# Output: [4 6 8]
```

Here, numbers[1:4] sliced the elements from index 1 up to the index 4 (not including the element at index 4).

Note: If we omit the

- start parameter- slicing starts from the first element
- stop parameter - slicing continues up to the last element
