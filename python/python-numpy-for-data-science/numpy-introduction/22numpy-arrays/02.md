## Creating an Array Using Python List

First, let's recall how to create Python lists:

```python
1# create list of numbers
2numbers = [1, 2, 3, 4, 5, 6]
3print(numbers)
4
5# Output: [1, 2, 3, 4, 5, 6]
```

In the above example we have created a list of numbers by placing comma separated elements inside square brackets [].

Now, let's use this list to create a 1-D NumPy array.

```python
1import numpy as np
2
3# create list of numbers
4numbers = [1, 2, 3, 4, 5, 6]
5
6
7# create numpy array using the numbers list
8np_array = np.array(numbers)
9
10
11print(np_array)
```

Output

```text
[1 2 3 4 5 6]
```

Here, we've created a NumPy array from the numbers list.

In the line,

np_array = np.array(numbers)

the np.array() method creates an array from the numbers list and assigns it to the np_array variable. The output is a NumPy array.

You can also directly pass the list elements to np.array(). For example,

```python
1import numpy as np
2
3
4# create numpy array using a list
5np_array = np.array([1, 2, 3, 4, 5, 6])
6
7
8print(np_array)
9
10# Output: [1 2 3 4 5 6]
```

This code is similar to our previous example.

Note: NumPy arrays are preferred over Python lists because they are implemented in C, making them faster and more efficient. Also, NumPy supports vectorized operations, allowing you to perform mathematical operations on entire arrays at once.

These features of NumPy arrays make working with large amounts of data easier when compared to Python lists.
