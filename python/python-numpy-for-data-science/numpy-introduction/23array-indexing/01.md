## Access NumPy Array

We can use indexes to access individual elements of a NumPy array. For example,

Suppose we have a NumPy array:

```python
array1 = np.array([1, 2, 3, 4, 5])
```

Now, let's use the index number to access each of these elements. Here,

- array1[0] - gives us the first element
- array1[1] - gives us the second element
- array1[2] - gives us the third element
- array1[3] - gives us the fourth element
- array1[4] - gives us the fifth element

Let's see an example.

```python
1import numpy as np
2
3array1 = np.array([1, 2, 3, 4, 5])
4
5# access numpy elements
6print(array1[0])    # 1
7print(array1[1])    # 2
8print(array1[2])    # 3
9print(array1[3])    # 4
10print(array1[4])    # 5
```

Output

```text
1
2
3
4
5
```

As you can see we have successfully accessed each element of the NumPy array using the corresponding indexes.
