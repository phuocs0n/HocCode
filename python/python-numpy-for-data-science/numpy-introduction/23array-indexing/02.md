## NumPy Array IndexError

In the above example, there were 5 elements and we accessed them. But what happens if we try to access the 6th element?

Let's see an example.

```python
1import numpy as np
2
3arr = np.array([1, 2, 3, 4, 5])
4
5# access numpy elements
6print(arr[0])    # 1
7print(arr[1])    # 2
8print(arr[2])    # 3
9print(arr[3])    # 4
10print(arr[4])    # 5
11
12# try to access element at index 5
13print(arr[5])
```

When we run this code, we will first get all 5 elements and then an error message:

```text
IndexError: index 5 is out of bounds for axis 0 with size 5
```

This is because our array only has 5 elements and we are trying to access the 6th element using index 5.
