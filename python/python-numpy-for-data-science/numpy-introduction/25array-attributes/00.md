## Introduction to Array Attributes

Array attributes are properties of NumPy arrays that provide information about the array's shape, size, data type, dimension, and so on.

Let's say we want to find the number of elements in the array. For that we can use NumPy's size attribute.

```python
1import numpy as np
2array1 = np.array([1, 2, 3, 4, 5])
3print(array1.size) #5
```

Here, array1.size returns 5 as there are 5 elements in the above array.

In NumPy, there are several attributes that we can use to get information about a single dimensional array.

Here are some of the commonly used array attributes:

| Attributes | Description |
| --- | --- |
| ndim | specifies the number of dimensions of an array (for 1D array, it is 1) |
| shape | returns the size of the array in each dimension (for 1d array, it is the length of the array) |
| size | specifies total number of elements in the array |
| dtype | specifies the data type of elements of the array (float, int, or complex) |
| itemsize | represents the size in bytes of each element of the array |
| nbytes | represents total size in bytes of the array (nbytes = itemsize * size) |
