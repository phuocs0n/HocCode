## Dimension and Shape of Array

```python
1import numpy as np
2
3# create a NumPy array
4numbers = np.array([2, 4, 6, 8, 10, 12])
5
6# give the array dimension
7print('Number of dimensions:', numbers.ndim)
8
9# get shape of the array
10print('Shape:', numbers.shape)
```

Output

```text
Number of dimensions: 1
Shape: (6,)
```

Here,

- numbers.ndim: returns 1 because we are using a 1-D array
- numbers.shape: returns a tuple (6,) which represents the dimension of the array (single element means a single-dimensional array)
