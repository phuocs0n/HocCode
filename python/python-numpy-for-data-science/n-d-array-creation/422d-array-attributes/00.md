## Dimension Size

We use the ndim attribute to access the number of dimensions.

```python
1import numpy as np
2
3# create 2-D array
4arr = np.array([[2, 4, 6], [1, 3, 5]])
5
6# print dimension size
7print("Array Dimension", arr.ndim)
8
9# Output: 2
```

In this example, arr.ndim returns the number of dimensions present in arr. As arr is a 2-D array, we got 2 as an output.
