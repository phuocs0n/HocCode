## Example: Comparison Operators

```python
1import numpy as np
2
3first_array = np.array([1, 2, 3])
4second_array = np.array([3, 2, 1])
5
6# less than operator
7result = first_array < second_array
8print(result)    # Output: [ True False False]
9
10# greater than operator
11result = first_array > second_array
12print(result)    # Output: [False False  True]
13
14# equal to operator
15result = first_array == second_array
16print(result)    # Output: [False  True False]
```

Output

```text
[ True False False]
[False False  True]
[False  True False]
```

Here, we can see that the output of the comparison operators is also an array, where each element is either True or False.

1. first < second returns [True False False] because

- 1 < 3 (first element of the first_array array < first element of the second_array array) is True
- 2 < 2 (second element of the first_array array < second element of the second_array array) is False
- 3 < 1 (third element of the first_array_ array < third element of the second_array array) is False

2. first > second returns [False False True] because

- 1 > 3 is False
- 2 > 2 is False
- 3 > 1 is True

3. first == second returns [False True False] because

- 1 == 3 is False
- 2 == 2 is True
- 3 == 1 is False
