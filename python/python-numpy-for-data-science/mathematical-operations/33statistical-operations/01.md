## Calculate Mean

The mean value of a NumPy array is the average value of all the elements in the array.

It is calculated by adding all elements in the array and dividing the result by the total number of elements in the array.

```python
1import numpy as np
2
3# create a numpy array
4marks = np.array([76, 78, 81, 66, 85])
5
6# compute the mean of marks
7mean_marks = np.mean(marks)
8print(mean_marks)
9
10# Output: 77.2
```

Here, the mean value is 77.2, which is calculated by adding the elements (76, 78, 81, 66, 85) and dividing the result by 5 (total number of array elements).
