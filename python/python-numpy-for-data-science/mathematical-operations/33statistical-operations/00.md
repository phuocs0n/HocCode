## Statistical Functions

Statistics is a branch of mathematics that deals with the collection, analysis, interpretation, presentation, and organization of data.It plays a crucial role in data analysis, interpretation, and decision-making across various fields.

NumPy provides various built-in functions that can be used to perform different statistical operations on arrays.

The mean(), median(), std() functions are some examples of the most commonly used statistical functions provided by NumPy.

Here are some of the statistical functions provided by NumPy:

| Functions | Descriptions |
| --- | --- |
| median() | returns the median of an array |
| mean() | returns the mean of an array |
| std() | returns the standard deviation of an array |
| percentile() | returns the nth percentile of elements in an array |
| min() | returns the minimum element of an array |
| max() | returns the maximum element of an array |
