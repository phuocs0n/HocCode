## Element-wise Addition

As mentioned earlier, we can use the both + operator and the built-in function add() to perform element-wise addition between two NumPy arrays. For example,

1. Using the + operator

```python
1import numpy as np
2
3first = np.array([1, 3, 5, 7])
4second = np.array([2, 4, 6, 8])
5
6# using the + operator
7sum = first + second
8print(sum)
9
10# Output: [ 3  7 11 15]
```

2. Using the add() function

```python
1import numpy as np
2
3first = np.array([1, 3, 5, 7])
4second = np.array([2, 4, 6, 8])
5
6# using the add() function
7sum = np.add(first, second)
8print(sum)
9
10# Output: [ 3  7 11 15]
```

Here, we can see that both + and add() are returning the same result.
