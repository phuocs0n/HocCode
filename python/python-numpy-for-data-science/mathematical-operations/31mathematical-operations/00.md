## Mathematical Operations

So far we've learned about NumPy array basics and array creation. Now we'll learn about array manipulation.

We can perform various mathematical operations such as addition and subtraction on each element of the NumPy array.

To perform each operation, we can either use the associated operator or built-in functions.

For example, to perform addition, we can either use the + operator or the add() built-in function.

Here's a list of various mathematical operations along with their associated operators and built-in functions:

| Element-wise Operation | Operator | Function |
| --- | --- | --- |
| Addition | + | add() |
| Subtraction | - | subtract() |
| Multiplication | * | multiply() |
| Division | / | divide() |
| Exponentiation | ** | power() |

Next, we will see examples of each of these operations.
