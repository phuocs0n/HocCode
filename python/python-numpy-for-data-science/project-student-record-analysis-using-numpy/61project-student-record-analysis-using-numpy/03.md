## Step 3: Display Student Records

So far we've learnt how to initialize a student record and also how to add a new record. Now, we'll learn how to display them.

One of the major parts of data analysis is data visualization. Analyzing data is important but data presentation is equally important.

There are also other libraries that aid in data visualization but for this course we are strictly limiting ourselves to NumPy.

Here is a code to visualize the data in a pleasing format.

```python
# display the record in visually pleasing form
def display_record(studentArray, subjectArray, marksArray):
    # print the subjects as table header
    header = f"Student/Subject |"
    header += "|".join(subjectArray)
    print(header)

    # print the separator line
    separator = "-" * 16 + "+" + "+".join(["-" * len(sub) for sub in subjectArray])
    print(separator)

    # print the marks for each student
    for i, student in enumerate(studentArray):
        row = f"{student :<{16}}"
        row += ''.join(f"|{mark:<{len(subjectArray[col])}}" for col, mark in enumerate(marksArray[i]))
        print(row)
```

Python's join() method is used to concatenate strings from an iterable into a single string joined together by the specified separator. For example,

```python
','.join(['apple', 'banana', 'orange']) would return the string 'apple,banana,orange'
```

Similarly, Python's split() method is used to split a string into a list of substrings based on a specified separator. For example,

```python
'apple,banana,orange'.split(',') would return the list ['apple', 'banana', 'orange'].
```
