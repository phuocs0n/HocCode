## Step 1: Create Data as NumPy Arrays

In the first step, we'll create some student records which we can work on. For this, we'll use the concept of array creation.

Let's assume five subjects at random.

- English
- Maths
- Science
- Social
- History

Now, let's create an array with these 5 subjects:

```python
1import numpy as np
2
3# create a subject array
4subject = np.array(['English', 'Maths', 'Science', 'Social', 'History'])
5
6print(subject)
```

Output

```text
['English' 'Maths' 'Science' 'Social' 'History']
```

Next, we'll create an array of students. We'll use some random names.

```python
1import numpy as np
2
3# create a student array
4students = np.array(['Alice', 'Bob', 'Charlie', 'Dan'])
5
6print(students)
```

Output

```text
['Alice' 'Bob' 'Charlie' 'Dan']
```

Finally, let's assign marks to each student.

```python
1import numpy as np
2
3# create a subject array
4subject = np.array(['English', 'Maths', 'Science', 'Social', 'History'])
5
6# create a student array
7students = np.array(['Alice', 'Bob', 'Charlie', 'Dan'])
8
9# assign random marks for each student and subject
10marks = np.array([[81, 78, 80, 60, 63],
11                  [50, 60, 65, 48, 55],
12                  [30, 83, 97, 79, 75],
13                  [99, 55, 60, 48, 30]])
14
15print(marks)
```

Sample Output

```text
[[81 78 80 60 63]
 [50 60 65 48 55]
 [30 83 97 79 75]
 [99 55 60 48 30]]
```

Note: We can also use a random function provided by NumPy to create a much larger dataset. For example,

```python
marks = np.random.randint(30, 101, size=(len(students), len(subjects)))
```

However, in this project, we manually created datasets to ensure data consistency.

Now, let's put all these codes inside a function.

```python
1import numpy as np
2
3# function to initialize and store data
4def initialize_data():
5
6    subject = np.array(['English', 'Maths', 'Science', 'Social', 'History'])
7    students = np.array(['Alice', 'Bob', 'Charlie', 'Dan'])
8    marks = np.array([[81, 78, 80, 60, 63],
9                      [50, 60, 65, 48, 55],
10                      [30, 83, 97, 79, 75],
11                      [99, 55, 60, 48, 30]])
12    return subject, students, marks
13
14# main function
15def main():
16    # call the function initialize_data
17    subject, students, marks = initialize_data()
18    print(subject)
19    print(students)
20    print(marks)
21
22# call the main function
23main()
```

Sample Output

```text
['English' 'Maths' 'Science' 'Social' 'History']
['Alice' 'Bob' 'Charlie' 'Dan']
[[81 78 80 60 63]
 [50 60 65 48 55]
 [30 83 97 79 75]
 [99 55 60 48 30]]
```

Although the program works just fine without functions, using functions allows us to organize our code into modular and reusable blocks, making it easier to understand, maintain, and debug.

To define a function we use:

```python
def function_name(arguments):
	# function logic
```

Later, we can use that function by simply calling it.

```python
function_name(arguments)
```
