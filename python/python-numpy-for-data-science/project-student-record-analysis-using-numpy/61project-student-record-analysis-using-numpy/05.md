## Step 5: Data Analysis

Finally, we perform data analysis. The main focus in data analysis is to perform statistical and data analysis operations to gain insights and draw conclusions.

For this project we will be obtaining the following statistics and data analysis records.

- Average marks for each subject
- Standard deviation and variation of marks
- Identify top performing and bottom performing students
- Subject comparison
- Overall performance

Average Marks:

We can simply use np.mean()to find average marks.

```python
avgSubject = np.mean(marksArray, axis=0)
avgStudent = np.mean(marksArray, axis=1)
```

From average marks, we can obtain following insights:

- identify which subjects tend to have higher or lower average marks
- understand the relative difficulty of subjects
- calculate the overall performance of students

Standard deviation and Variation of Marks:

We use np.std() and np.var(). We can calculate deviation and variance for both students and for subjects.

```python
stdSubject = np.std(marksArray, axis = 0)
varSubject = np.var(marksArray, axis = 0)
stdStudents = np.std(marksArray, axis = 1)
varStudents = np.var(marksArray, axis = 1)
```

For subjects:

- Higher standard deviation and variance mean marks are more spread out, with a wider range of performance among students.
- Lower standard deviation and variance mean marks are more consistent, showing similar performance among students.

For students:

- Higher standard deviation and variance mean their marks vary more across different subjects.
- Lower standard deviation and variance mean their marks are more consistent across subjects.

Identify top performing and bottom performing students:

We assume that the student with the most marks is the top student and the student with least marks is the bottom performing student. First, we calculate the total marks of each student.

```python
np.sum(marksArray, axis=1)
```

Next, we find the index at which the sum is maximum.

```python
np.argmax(np.sum(marksArray, axis=1))
```

Finally, we use this index to find the student.

```python
topPerformer =  studentArray[np.argmax(np.sum(marksArray, axis=1))]
```

Similarly for bottom performer,

```python
bottomPerformer =  studentArray[np.argmin(np.sum(marksArray, axis=1))]
```

Subject Comparison

We assume the subject with the most marks on average is the easiest subject and the subject with least marks is the hardest subject.

Similar to above, we also take mean, use argmax() or argmin() to find corresponding indexes and use indexing to find respective subjects.

```python
easiestSubject = subjectArray[np.argmax(avgSubject)]
hardestSubject = subjectArray[np.argmin(avgSubject)]
```

Overall Performance

Finally, we calculate the overall metrics of the student record i.e. average, standard deviation and variance for all students across all subjects. For this use again use np.mean(), np.std() and np.var() without specifying the axis.

```python
totalAverage = np.mean(marksArray)
totalStd = np.std(marksArray)
totalVar = np.var(marksArray)
```

We will create a new function called obtain_results(). This is how the function looks like:

```python
def obtain_results(studentArray, subjectArray, marksArray):
    
    # data part
    #  average marks for each subject
    avgSubject = np.mean(marksArray, axis=0)
    
    # deviation and variation of marks
    stdSubject = np.std(marksArray, axis = 0)
    varSubject = np.var(marksArray, axis = 0)
    stdStudents = np.std(marksArray, axis = 1)
    varStudents = np.var(marksArray, axis = 1)
    
    # top and bottom performing student 
    topPerformer =  studentArray[np.argmax(np.sum(marksArray, axis=1))]
    bottomPerformer =  studentArray[np.argmin(np.sum(marksArray, axis=1))]
    
    # subject comparison
    easiestSubject = subjectArray[np.argmax(avgSubject)]
    hardestSubject = subjectArray[np.argmin(avgSubject)]
    
    # overall performance
    totalAverage = np.mean(marksArray)
    totalStd = np.std(marksArray)
    totalVar = np.var(marksArray)
    
    # analysis and visualization part
    # total number of students
    print('Total Number of students: ', len(studentArray))
    
    # average marks for each subject
    print('\nAverage Marks in Each Subject')
    for i,subject in enumerate(subjectArray):
        print('\t',subject,':', avgSubject[i])
    
    # deviation and variation of marks
    print('\nStandard Deviation and Variance per Subject')
    header = np.array(['Subject Name','Standard Deviation','Variance'])
    print("|".join(header))
    # print the separator line
    separator = "+".join(["-" * len(item) for item in header])
    print(separator)
    for i, subject in enumerate(subjectArray):
        row = f"{subject :<{len(header[0])}}" +'|'+ f"{stdSubject[i] :<{len(header[1])}}" + '|' + f"{varSubject[i] :<{len(header[2])}}"
        print(row) 
    
    print('\nStandard Deviation and Variance per Student')
    print("|".join(header))
    # print the separator line
    print(separator)
    for i, student in enumerate(studentArray):
        row = f"{student :<{len(header[0])}}" +'|'+ f"{stdStudents[i] :<{len(header[1])}}" + '|' + f"{varStudents[i] :<{len(header[2])}}"
        print(row)
   
    # top and bottom performing student 
    print('\nTop performer: ', topPerformer)
    print('Bottom performer:', bottomPerformer)
    
    #subject Comparison
    print('\nEasiest Subject:',easiestSubject, '\nHardest Subject:',hardestSubject)
    
    # overall performance
    print('\nMetrics across all Students and Subjects')
    print('Average Marks: ',totalAverage, '\nStandard Deviation: ',totalStd, '\nVariance: ',totalVar)
```
