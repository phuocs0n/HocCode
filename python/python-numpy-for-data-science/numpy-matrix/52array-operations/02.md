## NumPy where()

The NumPy where() method finds indices that are true in an array based on a given condition.

Let's say we want to replace all negative elements from an array with value 0, we can use np.where() in the following way:

```python
1import numpy as np
2array1 = np.array([[1,2,-1,-2,10,12,20],[1,2,3,-6,1,-10,-1]])
3
4# replace negative values with 0
5print(np.where(array1>0,array1,0))
```

Output

```text
[[ 1  2  0  0 10 12 20]
 [ 1  2  3  0  1  0  0]]
```

In the code above,

```python
np.where(array1>0, array1, 0)
```

The np.where() function creates a new array based on the condition array1 > 0.

If the condition is true, it selects the corresponding element from array1, otherwise, it selects 0.
