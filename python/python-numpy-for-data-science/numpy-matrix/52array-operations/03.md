## where() with Multiple Conditions

The test condition in a where() method may have multiple conditions.

We use

- the | operator to perform OR operation on multiple conditions
- the & operator to perform AND operation on multiple conditions

```python
1import numpy as np
2
3array1 = np.array([1, 2, 3, 4, 5, 6, 7])
4
5
6# if element is less than 2 or greater than 6, test condition is True
7test_condition1 = (array1 < 2) | (array1 > 6)
8
9
10# select element of x if test condition is True
11# return 0 if test condition is False
12result1 = np.where(test_condition1, array1, 0)
13
14print(result1)
15
16
17# if element is  greater than 2 and less than 6, test condition is True
18test_condition2 = (array1 > 2) & (array1 < 6)
19
20
21# select element of x if test condition is True
22# return 0 if test condition is False
23
24result2 = np.where(test_condition2, array1, 0)
25
26print(result2)
```

Output

```text
[1 0 0 0 0 0 7]
[0 0 3 4 5 0 0]
```
