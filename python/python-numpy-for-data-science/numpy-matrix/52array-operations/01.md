## Array Filtering

We can filter arrays based on conditions to obtain an identical sized array of booleans which describes if the condition is satisfied at an index in the array.

Let's say we want to identify where in an array we have negative values. We can filter the array based on the condition less than 0.

```python
1import numpy as np
2array1 = np.array([[1,2,-1,-2,10,12,20],
3                   [1,2,3,-6,1,-10,-1]])
4
5print("Original array : \n",array1)
6
7print("Identify Negative values:")
8print(array1<0)
```

Output

```text
Original array : 
[[  1   2  -1  -2  10  12  20]
 [  1   2   3  -6   1 -10  -1]]

Identify Negative values:
[[False False  True  True False False False]
 [False False False  True False  True  True]]
```

Now that we have identified the negative values from the array1 array, let's filter array1 and obtain only negative values.

```python
1import numpy as np
2array1 = np.array([[1,2,-1,-2,10,12,20],
3                   [1,2,3,-6,1,-10,-1]])
4
5filtered_arr = array1[array1 < 0]
6
7print(filtered_arr)
```

Output

```text
[ -1  -2  -6 -10  -1]
```

Here, filtering can be divided into two parts.

First, we perform array1<0. This will create a boolean array of the same shape and size as array1. In this boolean array, the element is True if the element in array1<0 and False otherwise. This boolean array is also called a boolean mask.

In the second part, we are using this boolean mask as an index for array1. This returns a 1-D array containing only the elements where the corresponding position in the boolean mask is True.

Think of boolean masking as a technique to select elements from an array based on a boolean condition.
