## Examples of Universal Functions

Here are some examples of NumPy Universal Functions:

Arithmetic Operations:

```python
1import numpy as np
2
3array1 = np.array([1, 2, 3, 4])
4array2 = np.array([5, 6, 7, 8])
5
6# addition
7result1 = np.add(array1, array2)
8
9# multiplication
10result2 = np.multiply(array1, array2)
11
12print("Addition:", result1)
13print("Multiplication", result2)
```

Output

```text
Addition: [ 6  8 10 12]
Multiplication [ 5 12 21 32]
```

Here, we used the universal function add() and multiply() on two arrays, array1 and array2.

Trigonometric Functions:

```python
1import numpy as np
2
3# array of angles in radians
4angles = np.array([0, 1])
5print("Angles:", angles)
6
7# compute the sine of the angles
8sine_values = np.sin(angles)
9print("Sine values:", sine_values)
10
11# compute the inverse sine of the angles
12inverse_sine = np.arcsin(angles)
13print("Inverse Sine values:", inverse_sine)
```

Output

```text
Angles: [0 1]
Sine values: [0.         0.84147098]
Inverse Sine values: [0.         1.57079633]
```

In this example, we have used universal functions sin() and arcsin() to compute the sine and inverse sine values respectively.

When we perform the sin() function to the array angles, an element-wise operation is performed to entire elements of the array. This is called vectorization.

Aggregation Functions:

```python
1import numpy as np
2
3array1 = np.array([1, 2, 3, 4, 5])
4
5# calculate the median
6median = np.median(array1)
7print("Median is:",median)
8
9# find the largest element
10result = np.min(array1)
11print("Smallest element is", result)
```

Output

```text
Median is: 3.0
Smallest element is 1
```

Here, we have used the universal functions median() and min() to find the median and smallest element of array1.
