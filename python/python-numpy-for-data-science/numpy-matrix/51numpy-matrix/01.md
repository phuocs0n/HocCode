## Matrix Creation

NumPy matrix is a type of NumPy ndarrays. Unlike arrays, matrices can't have more than 2 dimensions.

So, we can use the np.array() function to create a matrix.

```python
1import numpy as np
2
3# create a 2x2 matrix
4matrix1 = np.array([[1, 2], 
5                    [3, 5]])
6
7print("2x2 Matrix:\n",matrix1)
8
9# create a 3x3  matrix
10matrix2 = np.array([[1, 2, 3],
11                    [5, 7, 9],
12                    [12, 6, 8]])
13                    
14print("\n3x3 Matrix:\n",matrix2)
```

Output

```text
2x2 Matrix:
 [[1 2]
 [3 5]]

3x3 Matrix:
[[ 1  2  3]
 [ 5  7  9]
 [12  6  8]]
```

As we can see, we have successfully created two matrices: 2x2 matrix and 3x3 matrix by passing a list of lists to the np.array() function respectively.

#### Create Prefilled Matrix

We can also create a matrix filled with ones or zeros using the np.ones() or np.zeros() functions.

```python
1import numpy as np
2
3# create a 3x3 matrix filled with ones
4ones_matrix = np.ones((3, 3))
5
6# create a 2x4 matrix filled with zeros
7zeros_matrix = np.zeros((2, 4))
8
9print("Matrix filled with ones: \n", ones_matrix)
10
11print("\nMatrix filled with zeros:\n", zeros_matrix)
```

Output

```text
Matrix filled with ones: 
[[1. 1. 1.]
 [1. 1. 1.]
 [1. 1. 1.]]

Matrix filled with zeros:
[[0. 0. 0. 0.]
 [0. 0. 0. 0.]]
```
