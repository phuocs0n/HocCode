## Infinite Recursion With Changing Arguments

Here's a slight modification of the program we previously wrote:

```c
1#include <stdio.h>
2
3void print_numbers(int n) {
4
5    printf("%d\n", n);
6
7    // argument is decreased by 1 in each recursive call
8    print_numbers(n - 1);
9}
10
11int main() {
12
13    print_numbers(100);
14    return 0;
15}
```

Output

```text
100
99
98
97
96
...
```

Here, we have initially called the print_numbers() function with 100 as an argument.

In the first function call (original call):

- n is 100, which is printed.
- print_numbers(99) is called.

In the second function call (first recursive call):

- n is 99, which is printed.
- print_numbers(98) is called.

Essentially, the value of the argument is reduced by one in each subsequent function call.
