#### Course: Learn Recursion With C

## Why are Local Variables Important?

Local variables are important because they make functions independent.

As you already know, it doesn't matter what's inside a function and what variables are used in it; we can use that function if we know two things:

1. Arguments that the function takes.
2. Return value from the function.

Source Code

```c
1#include <stdio.h>
2
3int add_numbers(int n1, int n2) {
4
5    int result = n1 + n2;
6    return result;
7}
8
9int main() {
10
11    int n1 = 2;
12    int n2 = 5;
13
14    int result = add_numbers(n1, n2);
15    printf("%d", result);
16
17    return 0;
18}
19
20// Output: 7
```

In this program, it's essential to understand that the n1, n2, and result variables inside the add_numbers() function are local to that function.

They are different from any n1, n2, and result variables that are outside of the function, even if their names are the same and they store the same values.

These outside variables can also be written using different variable names. Thus, the above program is equivalent to the following program:

```c
1#include <stdio.h>
2
3int add_numbers(int n1, int n2) {
4
5    int result = n1 + n2;
6    return result;
7}
8
9int main() {
10
11    int num1 = 2;
12    int num2 = 5;
13
14    int result = add_numbers(num1, num2);
15    printf("%d", result);
16
17    return 0;
18}
19
20 // Output: 7
```
