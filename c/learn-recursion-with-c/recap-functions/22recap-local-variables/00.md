## Introduction

The concept of local variables is critical in recursion since each recursive call possesses a separate local variable. Let's revisit local variables.

### Local Variables

Any variable that is created inside a function is local to it. For example,

```c
1#include <stdio.h>
2
3int add_numbers(int n1, int n2) {
4    int result = n1 + n2;
5}
6
7int main() {
8
9    // call the function
10    add_numbers(2, 5); 
11
12    // error code
13    // attempt to print result variable 
14    printf("%d", result); 
15
16    return 0;
17}
```

Here, when the execution of the add_numbers() function ends, all the variables inside it (n1, n2, and result) are destroyed.

The reason the above program throws an error is that the result variable is not defined in the scope where it is being accessed. In other words, the result variable doesn't exist inside the main() function.

Next, we will see how we can fix it and use the value returned by the function.
