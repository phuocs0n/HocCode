## Thought Process

To find the nth number in the Fibonacci sequence, we need to find the sum of the (n-1)th and (n-2)th numbers.

As such, we need to recursively call two functions by passing n - 1 and n - 2 as arguments, and then add the return values of these two functions.

```c
return fib(n - 1) + fib(n - 2);
```

Here, fib() is the recursive function to find the nth Fibonacci number.

The first two terms of the series are always 0 and 1. So, for the first two terms, we can simply return 0 and 1, respectively (base case).

```c
if (n == 0 || n == 1) {
    return n;
}
```
