# Thought Process

#### Course: Learn Recursion With C

## Thought Process

Recursive Call

To convert 6 to binary, let's first think what argument needs to be passed in each recursive call.

1. At first, we will pass 6 as an argument to the function.
2. Then, we will perform integer division on it by 2 to get the quotient (3) and find the remainder as well.
3. We will then call the function again with the quotient (3) as the parameter.
4. Again, we will divide the function by 2 to get the quotient and the remainder.

Base Condition

The above process will go on recursively till the quotient becomes 0, which is our base condition.

We get the result in binary by concatenating the remainder of each division from bottom to top (or from the last remainder obtained to the first).
