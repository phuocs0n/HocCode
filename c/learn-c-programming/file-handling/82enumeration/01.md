## Integral Constants

In C, enum constants are internally represented by integral constants. So, by default the value Sunday is 0, Monday is 1, Tuesday is 2 and so on.

Let's see an example.

```c
1#include <stdio.h>
2
3enum Days {
4  Sunday,
5  Monday,
6  Tuesday,
7  Wednesday,
8  Thursday,
9  Friday,
10  Saturday
11};
12
13
14int main() {
15
16  // create enum variable
17  enum Days currentDay;
18
19  // assign value to enum variable
20  currentDay = Friday;
21
22
23  // print enum variable
24  printf("%d", currentDay);    // 5
25
26  
27  return 0;
28}
```

As you can see, we get the integral constant 5 as output, which represents the enum constant Friday.
