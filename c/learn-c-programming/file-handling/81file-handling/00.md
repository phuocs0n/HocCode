## Introduction

We know about computer files. In this lesson, we will learn to perform file operations such as reading content from files and writing content to files.

There are three steps involved in working with files:

1. Opening a file
2. Performing file operations (read and write)
3. Closing the file

Let's cover each of these topics in detail.

By the way, our C compiler doesn't support working with files at the moment, so we have to rely on images.
