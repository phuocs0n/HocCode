## Example: Nested Loops

```c
1#include <stdio.h>
2
3int main() {
4
5  // outer loop iterates from i = 0 to 2
6  for (int i = 0; i <= 2; ++i) {
7    // inner loop iterates from j = 0 to 1
8    for (int j = 0; j <= 1; ++j) {
9      printf("i = %d, j = %d\n", i, j);
10    }
11  }
12
13  return 0;
14}
```

Output

```text
i = 0, j = 0
i = 0, j = 1
i = 1, j = 0
i = 1, j = 1
i = 2, j = 0
i = 2, j = 1
```

In this program, the outer loop iterates from i equals 0 to 2. In each iteration of the outer loop, the inner loop iterates from j equals 0 to 1.
