## String Header File

Strings are one of the most frequently used types in programming. To make working with strings easier, there are several string functions. For example, the strlen() function allows us to find the length of a string.

To use these functions, we must first import the string.h header file in our program. This is because the definition of these functions is provided inside this file.

In this lesson, we will see the working of some of the basic functions that are very handy while working with strings.

- strlen() - finds the length of a string
- strcpy() - copies a string to another
- strcat() - joins two strings together
- strcmp() - compares two strings
