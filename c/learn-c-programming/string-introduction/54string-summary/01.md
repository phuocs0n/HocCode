4. String Input

If we need to take a single word as input, we can use the scanf() function.

```c
1#include <stdio.h>
2
3int main() {
4
5  char text[100];
6
7  printf("Enter the string: ");

9
10  printf("%s", text);
11
12  return 0;
13}
```

5. Get Complete Line as Input

We can also take the entire line as input using the fgets() function.

```c
1#include <stdio.h>
2
3int main() {
4
5  char text[100];
6
7  printf("Enter the string: ");
8  fgets(text, sizeof(text), stdin);
9
10  printf("%s", text);
11
12  return 0;
13}
```
