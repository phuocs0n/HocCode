## scanf() Function

Let's look at the previous program we wrote:

```c
1#include <stdio.h>
2
3int main() {
4
5    // Create a variable
6    int age;
7
8    // Store user input in the variable
9    scanf("%d", &age);
10
11    // Print the variable
12    printf("Age is %d", age);
13
14    return 0;
15}
```

We used the statement scanf("%d", &age); to take the input for the age variable. Notice that we've used &age instead of age.

Now, suppose we typed 25 and pressed the Enter key. The value 25 will be assigned to the age variable.

The output of this program will vary based on the input value.

Sample Output 1

```text
25
Age is 25
```

Sample Output 2

```text
31
Age is 31
```
