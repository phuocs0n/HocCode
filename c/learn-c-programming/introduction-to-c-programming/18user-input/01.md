## User Input

In the example on the last page, we learned that without user input, an ATM wouldn't know how much money to dispense.

Similarly, a program written to print your age wouldn't know what to print unless you provide the specific input (in this case, your age).

In C, to generate that input, we use the scanf() function.

Let's look at an example:

```c
1#include <stdio.h>
2
3int main() {
4
5    // Create a variable
6    int age;
7
8    // Store user input in the variable
9    scanf("%d", &age);
10
11    // Print the variable
12    printf("Age is %d", age);
13
14    return 0;
15}
```

If we run this program, the program waits for the user data.

You need to enter the age in the designated area in the console and then press the Enter key.

The program execution won't be completed until you've done that.
