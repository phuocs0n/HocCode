## Understanding User Input

Suppose you're at an ATM to withdraw cash. The machine doesn't randomly dispense money - it waits for you to provide specific inputs.

First, it asks you to insert your card and enter your PIN. Then, it asks how much money you'd like to withdraw.

Based on your input, the ATM processes the requests and prints the exact amount of cash you asked for.

In programming, user input works similarly. A program asks the user to provide some information and then uses that input to produce an output.

For example, the user might input a number, and the program prints it back to the screen or performs calculations before displaying the result.

Next, we will try to implement this concept in C programming.
