## + Operator

The + (addition) operator is used to add two values. Let's take an example:

```c
1#include <stdio.h>
2
3int main() {
4
5    int number1 = 34;
6    int number2 = 12;
7
8    // + adds values of two variables
9    int sum = number1 + number2;
10
11    printf("Sum = %d", sum);
12
13    return 0;
14}
```

Output

```text
Sum = 46
```

Here, int sum = number1 + number2; first adds the value of number1 and number2. Then, the result is assigned to the sum variable.
