## Implicit Type Conversion

In implicit type conversion, the type changes automatically. There is no special syntax for this type of conversion.

Let's see an example to understand it better.

```c
1#include <stdio.h>
2
3int main() {
4
5    // Initialize a double variable
6    double doubleValue = 45.4567;
7    
8    // Assign double to an int 
9    int intValue = doubleValue;
10
11    // Print the int variable
12    printf("%d", intValue);
13
14    return 0;
15}
```

Output

```text
45
```

There are two key takeaways from the output:

1. We can assign one type of variable to another.
2. We may encounter data loss. For example: we lost the remaining 0.4567 in the above example.

Here, the double value 45.4567 was automatically converted to an int value 45. This automatic conversion between data types is known as implicit type conversion.
