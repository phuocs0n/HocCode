## Data Type: double

Numbers with decimal parts can be represented using the double data type.

For example, 32.9, -56.5, 9.0, etc., can all be represented by the double data type.

As we learnt earlier, %d is the format specifier for the int data type. Similarly, %lf is the format specifier for the double type.

Let's see a program that declares and prints a double variable:

```c
1#include <stdio.h>
2
3int main() {
4
5    // Initialize a double variable
6    double PI = 3.1415;
7
8   // Use %lf to print a double
9   printf("The value of pi is %lf", PI);
10
11   return 0;
12}
```

Output

```text
The value of pi is 3.141500
```

The above program prints 3.141500 as an output.

We'll learn how to print only the required number of digits after the decimal point in the 'More on Printing Output' lesson.
