## Introduction to Comments

Many of us use Google Docs to collaborate, adding comments to explain ideas, suggest changes, or clarify decisions.

Comments in C work the same way—they're notes written directly in your code to explain your thought process, clarify tricky sections, or provide context.

These comments help others (or your future self) understand why certain choices were made, making the code easier to follow and maintain.

Just like Google Docs comments don't change the document itself, code comments are ignored by the compiler and exist purely for human readers.
