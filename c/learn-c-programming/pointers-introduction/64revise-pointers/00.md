## Pointers Summary

Let's revise what we have learned in this chapter:

1. Memory Address

&number gives the address of the number variable. For example,

```c
1#include <stdio.h>
2
3int main() {
4
5  int number = 32;
6
7  // use of %p to print the address
8  printf("%p", &number);
9}
10
11// Output: 0x7ffe61e30e94
```

2. Pointer Variables

A pointer variable is used to store the memory address of a variable. For example,

```c
1#include <stdio.h>
2
3int main() {
4
5  int number = 32;
6  
7  // pt is a pointer variable that stores
8  // memory address of number
9  int* pt = &number;
10  printf("%p", pt);
11}
12
13// Output: 0x7ffce681f5ec
```

3. Access value using pointers

*pt accesses the value pointed by the address stored in the pt pointer. For example,

```c
1#include <stdio.h>
2
3int main() {
4
5  int number = 32;
6  
7  // pt is a pointer variable that stores
8  // memory address of number
9  int* pt = &number;
10  
11  // value pointed by pt
12  printf("%d", *pt);
13}
14
15// Output: 32
```
