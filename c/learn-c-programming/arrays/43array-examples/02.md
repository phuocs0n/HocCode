## Understanding: Find the Largest Element in an Array

Initially, the first element of the array is assigned to the largest variable.

```c
int largest = numbers[0];
```

Then, we have used a for loop to iterate from the second element of the array to the last element.

In each iteration, if the largest variable is smaller than any element of the array, that element is assigned to the largest variable.

```c
// Inside the for loop
if (largest < numbers[i] {
  largest = numbers[i];
}
```

Here's how this code works:

| Iteration | numbers[i] | largest < numbers[i] | largest |
| --- | --- | --- | --- |
| 1st | 64 | true | 64 |
| 2nd | 75 | true | 75 |
| 3rd | 80 | true | 80 |
| 4th | 65 | false | 80 |
