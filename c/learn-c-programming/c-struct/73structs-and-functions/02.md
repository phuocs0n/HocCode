# Example: Struct as Function Argument

#### Course: Learn C Programming

## Example: Struct as Function Argument

```c
1#include <stdio.h>
2
3struct Student {
4  char name[50];
5  int age;
6};
7
8// function definition
9void display(struct Student s1) {
10  printf("Name: %s\n", s1.name);
11  printf("Age: %d", s1.age);
12}
13
14int main() {
15
16
17  // create and initialize struct variable
18  struct Student student1 = {.name = "Adam", .age = 25};
19
20  // function call
21  display(student1);
22
23
24  return 0;
25}
```

Output

```text
Name: Adam
Age: 25
```

In this example, we have passed the struct variable student1 to the display function. Inside the function, we have printed the name and age of student1.
