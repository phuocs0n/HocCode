## Example: C struct

```c
1#include <stdio.h>
2
3// create Person struct
4struct Person {
5  int age;
6  double salary;
7};
8
9int main() {
10
11  // create struct variable
12  struct Person person1;
13
14
15  // assign values to struct members
16  person1.age = 25;
17  person1.salary = 3465.78;
18
19  // print struct members
20  printf("Age: %d\n", person1.age);
21  printf("Salary: %.2lf", person1.salary);
22
23
24  return 0;
25}
```

Output

```text
Age: 25
Salary: 3465.78
```

Here, you can see that we have used

- person1.age - to assign and access the age member of Person
- person1.salary - to assign and access the salary member of Person
