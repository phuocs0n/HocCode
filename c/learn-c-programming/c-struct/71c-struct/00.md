## Struct Introduction

A struct (structure) is a collection of variables (can be of different types) under a single name.

Suppose, we want to store the name, age and salary of a person. We can do that by using 3 different variables.

However, a better approach would be to put these data under a single name because they are data of the same person. In these situations, we can use structs.

They make our code easier to write and understand.

Now that you understand why structs are used, let's see how we can create structs in C.

### Defining a Structure

We use the struct keyword to define structures. Let's create a struct for our above example.

```c
struct Person {
  char name[50];
  int age;
  double salary;
};
```

You can see, the struct Person includes variables of 3 different types.

When we define a struct like this, we are basically creating a data type like double and int. In this example, the data type is struct Person.

Now, we can create variables of this struct Person type (similar to variables of int and double types).
