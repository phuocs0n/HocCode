## Add Two Distances Using Struct

In this example, we will learn to take two distances (in the inch-feet system), add them and display the result on the screen.

### Source Code

```c
1#include <stdio.h>
2
3typedef struct Distance {
4  int feet;
5  int inch;
6} distances;
7
8int main() {
9
10  // create struct variables
11  distances d1;
12  distances d2;
13  distances result;
14
15  // get feet and inch inputs for d1 and d2
16  printf("Enter 1st distance\n");
17  printf("Enter feet and inch: ");
18  scanf("%d %d", &d1.feet, &d1.inch);
19
20  printf("Enter 2nd distance\n");
21  printf("Enter feet and inch: ");
22  scanf("%d %d", &d2.feet, &d2.inch);
23
24  // find sum
25  result.feet = d1.feet + d2.feet;
26  result.inch = d1.inch + d2.inch;
27
28  // if inch is greater than 12 add it to feet
29  // and reduce inch
30  result.feet = result.feet + (result.inch / 12);
31  result.inch = result.inch % 12;
32
33  printf("Sum: %d feet and %d inch", result.feet, result.inch);
34
35  return 0;
36}
```

Output

```text
Enter 1st distance
Enter feet and inch: 5
6
Enter 2nd distance
Enter feet and inch: 6
11
Sum: 12 feet and 5 inch
```
