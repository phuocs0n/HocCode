# Summary Struct

#### Course: Learn C Programming

## Summary Struct

1. Define a struct

We use the struct keyword to define a struct. For example,

```c
struct Rectangle {
  int length;
  int breadth;
};
```

2. Create struct Variables

The syntax of creating a struct variable is similar to that of creating a regular variable. For example,

```c
// create struct variable
struct Rectangle rect1;

// create integer variable
int age;
```

3. Access struct Members

Once we create a struct variable, we can use it to access the member of a structure. For example,

```c
// assign value to the length and breadth
rect1.length = 12;
rect1.breadth = 8;

// print length and breadth
printf("%d\n", rect1.length);
printf("%d", rect1.breadth);
```
