### Arguments and Return Value

Arguments are inputs to the function and return value is the output from the function.

```c
1#include <stdio.h>
2
3// Function takes two arguments
4// returns the sum of numbers
5int addNumbers(int n1, int n2) {
6
7  int result = n1 + n2;
8
9  return result;
10}
11
12int main() {
13
14  // Function call
15  int total = addNumbers(12, 36);
16  printf("%d\n", total);    // 48
17
18  total = addNumbers(10, 20);
19  printf("%d", total);    // 30
20
21  return 0;
22}
```

### Function Prototype

Function prototype allows us to call functions before defining them.

```c
1#include <stdio.h>
2
3int addNumbers(int, int);
4
5int main() {
6
7  // Function call
8  int result = addNumbers(12, 36);
9  printf("%d", result);    // 48
10
11  return 0;
12}
13
14// Function definition
15int addNumbers(int n1, int n2) {
16
17  int sum = n1 + n2;
18
19  return sum;
20}
```
