## Why Are Local Variables Important?

Local variables are important because they make functions independent.

As we discussed earlier, it doesn't matter what's inside a function and what variables are used in it, we can use that function if we know two things:

- arguments that the function takes
- return value from the function

Source Code

```c
1#include <stdio.h>
2
3int addNumbers(int n1, int n2) {
4
5  int result = n1 + n2;
6  return result;
7}
8
9int main() {
10
11  int n1, n2;
12  printf("Enter two values: ");
13  scanf("%d %d", &n1, &n2);
14
15  int result = addNumbers(n1, n2);
16  printf("Sum: %d", result);
17  
18  return 0;
19}
```

Output

```text
Enter two value: 9
3
Sum: 12
```

In the program, it's important to understand that n1, n2, and result variables inside the function are local to the addNumbers() function.

They are different from n1, n2, and result variables that are outside of the function (even though names are the same).
