## Introduction to Local Variables

Consider the following program:

```c
1#include <stdio.h>
2
3void add (int num1, int num2) {
4
5    int result = num1 + num2;
6}
7
8int main() {
9
10    printf("%d", result);
11}
```

The above program fails to run, stating result is undeclared. However, we have declared the result variable in the add function.

This is because of a concept known as variable scope. Next, we'll understand what it is.
