## Example: Scope of a Variable

```c
1#include <stdio.h>
2
3int main() {
4   int x = 5;
5
6    // Create a new scope
7   { 
8
9       int y = 56; 
10       // y in current scope is 56.
11       printf("%d\n", y);
12     }  
13     // y in not accessible outside the scope
14
15     // Attempt to access and print y outside the scope
16     // printf("%d", y);
17     // Error: cannot access y
18}
```

Output

```text
56
```

Here, we used { to create a new scope within the main function. Within that newly created scope, we created a variable y.

Variable y is only accessible within the scope it is defined. So if we try printing the variable outside the scope, we'll get an error.

Thus, a variable is local to the scope it is defined. Next, we'll look into why local variables are important.
