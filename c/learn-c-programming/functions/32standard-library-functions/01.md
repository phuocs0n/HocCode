## Library Function: printf()

Throughout the course, we've been using the printf() function to print values and variables.

The following is the first C program we wrote.

```c
1#include <stdio.h>
2
3int main() {
4
5  printf("Hello World");
6
7  return 0;
8}
```

Output

```text
Hello World
```

Here, printf() is a standard library function that prints the text on the screen.

We haven't provided any definition for the printf(), but we are still able to use it in our program.

This is because the function definition of printf() is already defined inside the stdio.h file. That's why we have included it inside our program.

Similarly, the scanf() function that we use to take user input is also a standard library function defined inside the same stdio.h header file.
