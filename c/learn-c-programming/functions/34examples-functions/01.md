## Sum of Natural Numbers From 1 to n

### Program Summary

Write a program to find the sum of first n natural numbers (where n is a positive integer) by creating a function. The function should work for any positive integer.

```c
sum = 1 + 2 + 3 + ... + n
```

### Arguments

We need to find the sum of numbers from 1 to n. So, our function will take only one argument, n.

### Return Value

The function should return the sum of numbers.
