## Comparison Operators: >

The > "greater than" operator returns 1 (true) if the first value is greater than the second value. If not, it returns 0 (false).

Let's take an example.

```c
1#include <stdio.h>
2
3int main() {
4
5    int age1 = 20, age2 = 18;
6
7    // 0 because age1 is not greater than 20
8    printf("Result: %d \n", age1 > 20);
9
10    // 0 because age2 is not greater to 50
11    printf("Result: %d \n", age2 > 50);
12
13    // 1 because age1 is greater than age2
14    printf("Result: %d \n", age1 > age2);
15
16    return 0;
17}
```
