## Introduction to Loops

Modern computers are incredibly fast and can execute millions of C operations in just a few seconds.

But does that mean you need to write millions of lines of code to harness this power? Absolutely not.

That's where loops come in. With loops, you can execute C statements repeatedly—10, 1,000, or even 1,000,000 times—all with just a few lines of code.

With clever logic, you can write some truly interesting programs using loops, which you'll learn in this lesson.
