## The while Loop

In C, there are two types of loops: while loop and for loop. Let's learn about the while loop in this lesson.

The syntax for the while loop is:

```c
while (booleanExpression) {
  // statement
}
```

The while loop runs the statements inside it as long as the condition evaluates to true.

Unlike an if statement that only executes once, the while loop repeatedly checks the condition and continues execution until the condition evaluates to false.
