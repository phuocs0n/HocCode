## Example: Finite while Loop (II)

To run this loop only for a fixed number of times, we must update the value of count inside the loop so that count <= 3 eventually becomes false.

Here's how:

```c
1#include <stdio.h>
2
3int main() {
4
5    int count = 1;
6
7    while (count <= 3) {
8
9      printf("I am inside a loop.\n");
10      printf("Looping is interesting.\n");
11
12      count = count + 1;
13    }
14
15    // Code outside loop
16    printf("OUTSIDE THE LOOP");
17  
18    return 0;
19}
```

Output

```text
I am inside a loop.
Looping is interesting.
I am inside a loop.
Looping is interesting.
I am inside a loop.
Looping is interesting.
OUTSIDE THE LOOP
```
