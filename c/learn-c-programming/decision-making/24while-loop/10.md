## Example: Print Numbers From 1 to 5 (III)

Here's how the program runs in each iteration of the loop.

| Variable | count <= 5 | Body of loop |
| --- | --- | --- |
| count = 1 | true | count is increased to 2.
Count = 2 is printed. |
| count = 2 | true | count is increased to 3.
Count = 3 is printed. |
| count = 3 | true | count is increased to 4.
Count = 4 is printed. |
| count = 4 | true | count is increased to 5.
Count = 5 is printed. |
| count = 5 | true | count is increased to 6.
Count = 6 is printed. |
| count = 6 | false | The loop terminates. |
