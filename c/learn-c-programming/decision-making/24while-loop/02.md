## Example: while Loop

```c
1#include <stdio.h>
2
3int main() {
4
5    int count = 1;
6
7    while (count <= 3) {
8
9      // Loop continues until count exceeds 3
10      printf("I am inside a loop.\n");
11      printf("Looping is interesting.\n");
12    }
13  
14    return 0;
15}
```

Here, the body of the loop contains two printf() statements. We know this because they are included inside the curly braces {} (which indicate the body of the loop).

If you run this program, the two statements inside the loop are executed again and again.

Output

```text
I am inside a loop.
Looping is interesting.
I am inside a loop.
Looping is interesting.
...
...
```
