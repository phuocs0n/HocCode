## Logical Operators

Now that you're familiar with comparison operators, it's time to learn about logical operators.

Logical operators allow you to combine multiple conditions and create more complex expressions.

There are three logical operators in C Programming:

- && (AND)
- || (OR)
- ! (NOT)
