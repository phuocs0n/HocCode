## Number of Vowels in String

### Problem Description

Create a program to count the number of vowels present in a string.

- Get input value for a string variable using fgets().
- Create an integer variable named vowels with initial value 0.
- Run a loop to access each character of the string.
- Inside the loop, check if the character is either a lowercase vowel or an uppercase vowel.
- If the character is a vowel, increase the value of vowels by 1.
- Print the value of vowels.
