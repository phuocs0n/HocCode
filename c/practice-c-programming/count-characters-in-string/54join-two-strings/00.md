## Join Two Strings

### Problem Description

Create a program to join two strings using strcat().

- Create two string variables named text1 and text2.
- Get input value for both variables using scanf().
- Use strcat() function to join two strings.
- Make sure to insert a space between two strings while joining them.
- Print the joined strings.

Assumption: We will assume that the user will only provide a single word as input value.

#### Example

```text
Programming
```

