## Frequency of Characters in String

### Problem Description

Create a program to find the total occurrence of a character in a string.

- Get string input for a char array named str.
- Get character input for a char variable named ch.
- Find the length of the input string.
- Run a for loop to access each character of the string.
- Inside the loop, check if the character matches the input character ch.
- If true, increase the value of a count variable by 1.
- Finally print the count.
