## Find the Longer String

### Problem Description

Create a program to find the longer string among two strings.

findLength() Function

- Create a findLength() function that takes a string as its parameter.
- Inside the function, create a count variable with initial value 0.
- Run a while loop to access each character of the string. [Use condition (text[count] != '\0') ].
- Inside the loop, increase the value of count by 1.
- Outside the loop, return the value of count.

main() Function

- Get two strings input from the user.
- Call the findLength() function two times with string inputs as arguments respectively.
- Compare the returned length for both the string and print the string with the largest return value.
