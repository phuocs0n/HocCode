## Compute the Area of Circle

### Problem Description

Create a program to compute the area of a circle using a function.

The formula to compute the area of a circle is:

```text
Area = 3.14 * radius * radius
```

1. Create the computeArea() function that accepts double parameters radius and pi.
2. Inside the function, compute the area of the circle and return it.
3. Inside main(), get a double input value for the radius of the circle.
4. Create a double variable named pi with value 3.14.
5. Call computeArea() with arguments radius and pi.
6. Print the returned value up to 2 decimal points.

#### Example

```text
Test Input12.8
```

```text
Expected Output514.46
```
