## Prime Numbers Between Intervals

### Problem Description

Create a function to find all the prime numbers between two intervals using a function.

Inside main()

- Create two variables x and y.
- Get input values for x and y such that the value of y should be greater than x.
- Run a loop to access each element between x and y.
- Pass each value (number) between x and y to a function isPrime().

Inside isPrime()

- Create a flag with value 0.
- Run a for loop from i = 2 to i < number (function parameter).
- Inside the loop, check if number is divisible by i. If true, change the value of flag to 1.
- Outside the loop, if flag is equal to 0, print the number (parameter) with a new line character.

#### Example

```text
Test Input21
50
```

```text
Expected Output23
29
31
37
41
43
47
```
