## Check Palindrome Number

### Problem Description

Create a function to check if a number is palindrome or not.

A number is palindrome if the reverse of that number is equal to the original number. For example, 1001, 343, etc.

#### Problem Description

- Get an integer input for the number variable.
- Call the findReverse() function with an argument number.
- Inside findReverse(), find the reverse of the number.
- Returned the reversed number to the function caller.
- Compare if the reversed number is the same as the original number.
- If true, print Palindrome Number. Otherwise, print Not a Palindrome Number

#### Example

```text
Test Input1001
```

```text
Expected OutputPalindrome Number
```
