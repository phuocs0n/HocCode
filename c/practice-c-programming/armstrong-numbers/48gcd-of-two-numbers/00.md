## GCD of Two Numbers

### Problem Description

Create a program to find the GCD of two numbers using a function.

GCD (Greatest Common Divisor) of two numbers is the largest number that can exactly divide both the numbers.

- Create a function findGCD() with parameters: num1 and num2.
- Inside the function, create an integer variable gcd with value 1.
- Run a for loop from  i = 1 to i <= num1  and  i <= num2.
- Inside the loop, if i divides both num1 and num2, set gcd as i.
- Return the value of gcd.
- Inside main(), get integer input for two variables x and y.
- Call findGCD() with arguments x and y.
- Print the returned value.

#### Example

```text
Test Input81
153
```

```text
Expected Output9
```
