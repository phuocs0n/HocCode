## Armstrong Numbers Between Intervals

### Problem Description

Create a function to display armstrong numbers between two intervals.

A number is called an Armstrong number of order 3 if the sum of cubes of each digit is equal to the number itself. For example, 153

```text
153 = 1^3 + 5^3 + 3^3
```

Inside main()

- Get input values of two variables x and y.
- Run a loop from x to y and call the checkArmstrong() function with the value of x in each iteration.

Inside checkArmstrong()

- Create variable originalNumber with value number (function parameter), sum with value 0, and remainder.
- Run a while loop with condition originalNumber != 0.
- Inside the loop, find the last digit using originalNumber % 10 and add the cube of last digit to the sum variable
- Change the value of originalNumber using originalNumber / 10.
- Outside loop, if sum is equal to number (parameter), print the number with a new line character.

Assumption: We will assume that the input value is in between 100 and 999.

#### Example

```text
Test Input100
500
```

```text
Expected Output153
370
371
407
```
