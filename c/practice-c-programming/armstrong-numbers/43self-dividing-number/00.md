## Check Self-Dividing Number

### Problem Description

Create a function to check if a number is a self-dividing number.

A self-dividing number is a number that is divided by every digit it contains. For example, 128

```text
128 % 1 == 0
128 % 2 == 0
128 % 8 == 0
```

- Get an integer input for the variable number.
- Call the checkSelfDivide() function with an argument number.

Inside checkSelfDivide()

- Run a while loop to access each digit of the number.
- Inside the loop, check if each digit of the number divides the number perfectly.
- If all the digits of the number divides the number, return 1. Otherwise return 0.

Inside main()

- Check the returned value. If it is 1, print Self Dividing Number. Otherwise, print Not a Self Dividing Number.

Assumption

The input value shouldn't end with 0. For example, 230, 460, etc.

#### Example

```text
Test Input128
```

```text
Expected OutputSelf Dividing Number
```
