## LCM of Two Numbers

### Problem Description

Create a program to find LCM of two numbers using a function.

LCM (Lowest Common Multiple) of two numbers, x and y is the smallest positive integer that is perfectly divisible by both x and y.

- Create a function named findLCM() with parameters num1 and num2.
- Inside the function, set lcm equal to the largest value among num1 and num2.
- Run an infinite while loop and increase the value of lcm by 1 in each iteration.
- Inside the loop, check if lcm is perfectly divisible by num1 and num2.
- If true, stop the loop.
- Outside the loop return lcm.
- Inside main(), get integer input for x and y.
- Call findLCM() with parameters x and y.
- Print the returned value.

#### Example

```text
Test Input72
120
```

```text
Expected Output360
```
