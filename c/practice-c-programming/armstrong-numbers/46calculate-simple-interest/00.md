## Calculate Simple Interest

### Problem Description

Create a program to calculate simple interest using a function.

The formula to calculate simple interest is:

```text
Simple Interest = (principal * time * rate) / 100
```

simpleInterest() Function

- Create a function simpleInterest() that accepts three double arguments: principal, time and rate.
- Inside the function, compute simple interest and return it.

main() Function

- Inside main(), get three double inputs: principal, time and rate.
- Call simpleInterest() with 3 parameters.
- Print the returned value upto 2 decimal points.
