## Multiply Array by 10

### Problem Description

Create a program to multiply each element of an array by 10.

- Create an integer array with elements: 1, 2, 3, 4, 5.
- Create another array of the same size.
- Run a for loop to access each element of the first array.
- Inside the loop, multiply each element of the first array by 10 and assign it to the second array.
- Print the second array.
