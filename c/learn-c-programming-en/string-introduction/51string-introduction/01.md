# Create Strings

#### Course: Learn C Programming

## Create Strings

Let's start with the syntax of creating strings in C.

```c
char message[] = "Hello World";
```

You can see the syntax of string looks somewhat similar to an array. This is because strings are an array of characters.

Print a string

As we know, we use format specifiers to print any variable in C and to print a string, we use the %s format specifier.

Let's see an example,

```c
1#include <stdio.h>
2
3int main() {
4
5  // create strings
6  char message[] = "Hello World";
7  char text[] = "Strings are fun";
8
9  printf("%s\n", message);
10  printf("%s", text);
11  
12  return 0;
13}
```

Output

```text
Hello World
Strings are fun
```

As you can see, we have successfully printed two strings.
