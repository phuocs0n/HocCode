## Summary (I)

Let's now quickly revise what we have learned so far in this chapter:

1. Create a String

In C, the syntax to create a string is similar to that of an array. It is because string is an array of characters.

```c
char text[] = "Programiz";
```

2. Print a String

We use the %s format specifier to print a string.

```c
1#include <stdio.h>
2
3int main() {
4
5  char text[] = "Programiz";
6
7  printf("%s", text);    // Programiz
8  
9  return 0;
10}
```

3. Change a String

We can change the character of a string by assigning a new character at that position.

```c
1#include <stdio.h>
2
3int main() {
4
5  char text[] = "Car";
6
7  // change value at position 2 to 't'
8  text[2] = 't';
9
10  printf("%s", text);    // Cat
11
12  return 0;
13}
```
