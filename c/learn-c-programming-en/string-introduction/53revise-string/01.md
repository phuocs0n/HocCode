## Frequency of a Character

### Problem Description

We are given a string and a character. We need to find the number of times this character is present in the string.

### Thought Process

We need to access each character of the string using a for loop. Then, we need to compare those characters with the given character using if..else.

If there is a match, we need to record the number of matches.
