### Operators

In programming, you often need to perform calculations on values and variables, not just print them. To handle mathematical calculations, we use operators.

```c
1#include <stdio.h>
2
3int main() {
4    
5    float totalDistance = 89.5;
6    float distanceTravelled = 23.5;
7
8    float remainingDistance = totalDistance - distanceTravelled;
9
10    printf("The remaining distance is:  %.1f\n", remainingDistance);
11
12    return 0;
13}
```
