# Converting Distance in Kilometers to Miles

#### Course: Learn C Programming

## Converting Distance in Kilometers to Miles

To convert a distance in kilometers to miles, we need to multiply the distance in kilometers by the value 0.621. This is because:

```c
1 kilometer = 0.621 miles
```

Let's see a complete program:

```c
1// Program to convert distance in kilometer to miles
2// The distance will be entered by the user
3
4#include <stdio.h>
5
6int main() {
7
8    double km;
9    double miles;
10
11    // Conversion ratio
12    double conversionRatio = 0.621;
13  
14    printf("Enter distance in km: ");
15
16    // Take distance input from the user
17    scanf("%lf", &km);
18
19    // Compute distance in miles
20    miles = km * conversionRatio;
21
22    printf("Distance in miles: %lf", miles);
23
24    return 0;
25}
```

Output

```text
Enter distance in km: 33
Distance in miles: 20.493000
```

Here's how the program works:

- scanf("%lf", &km); - takes distance input in kilometers from the user and stores it in the km variable
- miles = km * conversionRatio; - computes the distance in miles by multiplying the distance in km by 0.621.

Notice how we used the double data type to represent the distance. Distances are generally floating-point numbers, such as 3.5 kilometers.
