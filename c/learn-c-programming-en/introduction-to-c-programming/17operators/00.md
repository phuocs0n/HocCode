## Introduction to Operators

An operator is a symbol used to perform operations on values.

For example, the + symbol is used to add two numbers and is also an operator in C.

In fact, we've already used one operator many times in our programs without realizing it—the = operator.

```c
int age = 25;
```

Here, the = operator assigns the value on the right (25) to the variable on the left (age). This is known as an assignment operator.

In this lesson, we will focus on different arithmetic operators available in C. Let's get started.
