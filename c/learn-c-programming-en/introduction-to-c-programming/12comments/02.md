## Single Line Comments

In C, we can use // (two forward slashes) to start a single-line comment. For example:

```c
1#include <stdio.h>
2
3int main() {
4  
5    // Print Hello World
6    printf("Hello World");
7 
8    return 0;
9}
```

Output

```text
Hello World
```

Here, // Print Hello World is a comment. It is ignored by the compiler because it begins with a double slash //.
