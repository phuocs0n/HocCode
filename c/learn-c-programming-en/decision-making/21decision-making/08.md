## Comparison Operators List

Here's a list of all comparison operators in C comparing variable var with a value, 5.

| Operator | Expression | Question |
| --- | --- | --- |
| > | var > 5 | Is var greater than 5? |
| >= | var >= 5 | Is var greater than or equal to 5? |
| < | var < 5 | Is var less than 5? |
| <= | var <= 5 | Is var less than or equal to 5? |
| == | var == 5 | Is var equal to 5? |
| != | var != 5 | Is var not equal to 5? |
