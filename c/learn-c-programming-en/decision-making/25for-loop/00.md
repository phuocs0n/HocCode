## Introduction to for Loops

So far, you've learned about the while loop, which repeats code based on a condition. In this lesson, we'll explore the for loop.

A for loop is ideal when you know exactly how many times you need to repeat a task, like when iterating through a sequence, such as a list of numbers.

It's particularly useful for predictable repetition and is generally more concise and readable than other loop types.
