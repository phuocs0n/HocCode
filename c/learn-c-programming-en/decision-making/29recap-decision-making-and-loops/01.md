## Recap (II)

When working with loops, you often need more control over how the loop runs. This is where the break and continue statements come in.

### The break Statement

The break statement terminates the loop immediately when it is encountered. It is usually used inside an if...else statement.

```c
1#include <stdio.h>
2
3int main() {
4
5  for (int i = 1; i <= 100; ++i) {
6
7    if (i == 3) {
8      break;
9    }
10
11    printf("%d\n", i);
12  }
13
14return 0;
15}
16
17// Output: 
18// 1
19// 2
```

### The continue Statement

The continue statement skips the code inside the loop for that current iteration.

```c
1#include <stdio.h>
2
3int main() {
4
5  for (int i = 1; i <= 5; ++i) {
6
7    if (i == 3 || i == 4) {
8      continue;
9    }
10
11    printf("%d\n", i);
12  }
13
14return 0;
15}
16
17// Output:
18// 1
19// 2
20// 5
```

### The switch Statement

The switch statement can be used as a replacement for if...else if when there are multiple alternatives to choose from. For example,

```c
1#include <stdio.h>
2
3int main() {
4
5  int number = 3;
6
7  switch(number) {
8
9    case 1:
10      printf("One");
11      break;
12    
13    case 2:
14      printf("Two");
15      break;
16
17    case 3:
18      printf("Three");
19      break;
20    
21    default:
22      printf("Invalid Number");
23  }
24
25return 0;
26}
27
28// Output:
29// Three
```
