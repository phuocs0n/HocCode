### The if Statement

Instead of simply executing code sequentially, you can use the if statement to perform different tasks based on specified conditions.

```c
1#include <stdio.h>
2
3int main() {
4
5  int age = 21;
6
7  if (age >= 18) {
8    printf("You can vote");
9  }
10
11  else {
12    printf("You cannot vote");
13  }
14
15return 0;
16}
17
18// Output:
19// You can vote
```

### The while Loop

You can use loops to execute code repeatedly. The while loop repeats a block of code as long as its condition evaluates to True.

```c
1#include <stdio.h>
2
3int main() {
4
5  int age;
6  printf("Guess the age: ");
7  scanf("%d", &age);
8
9  while (age != 21) {
10
11    printf("Your guess is wrong.\n");
12    printf("Guess the age: ");
13    scanf("%d", &age);
14  }
15
16  printf("You guessed it right");
17
18return 0;
19}
20
21// Output:
22// Guess the age: 18
23// Your guess is wrong. 
24// Guess the age: 21
25// You guessed it right
```

### The for Loop

The for loop is used to run a block of code for a certain number of times. For example,

```c
1#include <stdio.h>
2
3int main() {
4
5  for (int i = 1; i <= 3; ++i) {
6    printf("%d\n", i);
7  }
8
9return 0;
10}
11
12// Output:
13// 1
14// 2
15// 3
```
