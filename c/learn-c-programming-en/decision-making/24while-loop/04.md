## Example: Finite while Loop (I)

Here's the program from the previous page:

```c
1#include <stdio.h>
2
3int main() {
4
5    int count = 1;
6
7    while (count <= 3) {
8        printf("I am inside a loop.\n");
9        printf("Looping is interesting.\n");
10    }
11  
12    return 0;
13}
```

Here, the loop continues forever because the boolean expression, count <= 3, is never false because the value of count is always 1.
