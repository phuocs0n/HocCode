## Example: Print Numbers From 1 to 5 (I)

Suppose you want to print numbers from 1 to 5 using the while loop.

To solve this problem, let's first create a loop that runs 5 times.

```c
int count = 1;

while (count <= 5) {

  count = count + 1;
}
```

Here, the loop runs for 5 times from count equals to 1 to 5. After that, count becomes 6 and the loop terminates.
