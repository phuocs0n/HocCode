## Nested Loops

It's possible to put a loop inside another loop. This is known as a nested loop.

In a nested loop, the inner loop is executed for each iteration of the outer loop. Let's try to understand it with the help of an example.

```c
1#include <stdio.h>
2
3int main() {
4
5  int floors[2] = {1, 2};
6  char apartments[3] = {'A', 'B', 'C'};
7
8  for (int i = 0; i < 2; ++i) {
9
10    for (int j = 0; j < 3; ++j) {
11      printf("%d%c\n", floors[i], apartments[j]);
12    }
13  }
14
15  return 0;
16}
```

Output

```text
1A
1B
1C
2A
2B
2C
```

Here's how the code works:

1. First Iteration of the Outer Loop

- floor is 1, apartment is 'A'
- floor is 1, apartment is 'B'
- floor is 1, apartment is 'C'

2. Second Iteration of the Outer Loop

- floor is 2, apartment is 'A'
- floor is 2, apartment is 'B'
- floor is 2, apartment is 'C'
