## Example: Truthy and Falsy

Suppose we need to find the largest number among three numbers.

```c
1#include <stdio.h>
2
3int main() {
4
5  int n1 = 20;
6  int n2 = 10;
7  int n3 = 30;
8
9  if (n1 > n2 && n3) {
10    printf("%d", n1);
11  }
12  else if (n2 > n1 && n3) {
13    printf("%d", n2);
14  }
15  else {
16    printf("%d", n3);
17  }
18
19  return 0;
20}
```

Output

```text
20
```

Here, we are getting 20 as the largest number.

Can you find out where the error is?

Take a look at this code:

```c
if (n1 > n2 && n3) {
  printf("%d", n1);
}
```

Here, n1 > n2 evaluates to true and n3 also evaluates to true because 30 is considered true.

Instead here's what we should have written:

```c
if (n1 > n2 && n1 > n3) {
  printf("%d", n1);
}
```
