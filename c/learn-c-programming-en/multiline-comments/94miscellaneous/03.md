## Example: Arithmetic Assignment

Example 1

```c
1#include <stdio.h>
2
3int main() {
4
5  int total = 100;
6  
7  total += 10;  // total = total + 10
8  printf("%d", total);
9
10  return 0;
11}
12
13// Output: 110
```

Here, total += 10 adds 10 to the total variable and assigns the result back to the total variable.

Example 2

```c
1#include <stdio.h>
2
3int main() {
4
5  int x = 100;
6  
7  x %= 9;  // x = x % 9
8  printf("%d \n", x);
9
10  return 0;
11}
12
13// Output: 1
```

Here, x %= 9 computes the remainder when x is divided by 9 and assigns the result back to x.
