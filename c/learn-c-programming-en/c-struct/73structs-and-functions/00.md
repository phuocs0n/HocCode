## Revise Function

Let's first revise the working of a function with an example.

```c
1#include <stdio.h>
2
3// function to add two numbers
4int addNumbers(int n1, int n2) {
5  int sum = n1 + n2;
6  return sum;
7}
8
9int main() {
10  
11  int number1 = 32;
12  int number2 = 44;
13
14  // function call
15  int result = addNumbers(number1, number2);
16  printf("Result: %d", result);
17  
18  return 0;
19}
20
21// Output:
22// Result: 76
```

In the above program, we have created the addNumbers() function that

- takes two parameters, n1 and n2 (input)
- adds n1 and n2
- and returns the sum (output)

Like the regular variables (n1 and n2), we can also pass structs as arguments to functions.

In this lesson, we will learn to

- pass a struct to a function
- return a struct from a function
