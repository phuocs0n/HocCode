## Pass a Struct to a Function

Suppose we have a struct like this:

```c
struct Student {
  char name[50];
  int age;
};
```

We know that a struct is a type in C just like int and double. And, we can also create variables of a struct just like creating regular variables

```c
// create struct variable
struct Student s1;

// create int variable
int a1;
```

Since struct works like a data type, we can also pass struct variables to a function. For example,

```c
// passing struct to function
void display(struct Student s1) {
  ...
}

// passing a regular variable to function
void display(int a1) {
  ...
}
```
