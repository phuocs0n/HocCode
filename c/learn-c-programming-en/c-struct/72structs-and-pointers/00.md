## Revise Pointers

Let's first revise pointers with this example.

```c
1#include <stdio.h>
2
3int main() {
4
5  int number = 33;
6
7  // pointer variable to store address of number
8  int* pt = &number;
9
10  // print address of number
11  printf("%p\n", pt);    // 0x7ffd323dc88c
12
13  // print value pointed by the pt pointer
14  printf("%d", *pt);    // 33
15
16  return 0;
17}
```

Here, you can see

- int* pt - creates a pointer variable
- &number - returns the address of the number variable
- *pt - returns value pointed by the pointer pt

Just like the regular variable number, we can also use pointers to work with struct variables which we will see next.
