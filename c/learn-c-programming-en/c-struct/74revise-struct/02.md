#### Course: Learn C Programming

## Store Information of a Student Using Struct

In this example, we will learn to store information about a student by using a structure.

```c
1#include <stdio.h>
2
3struct Student {
4  char firstName[50];
5  int roll;
6  double marks;
7} student1;
8
9int main() {
10
11  // get information of the student
12  printf("Enter name: ");
13  fgets(student1.firstName, sizeof(student1.firstName), stdin);
14
15  printf("Enter roll: ");
16  scanf(" %d", &student1.roll);
17
18  printf("Enter marks: ");
19  scanf(" %lf", &student1.marks);
20
21
22  // print student info
23  printf("Name: %s", student1.firstName);
24  printf("Roll: %d\n", student1.roll);
25  printf("Marks: %.2lf", student1.marks);
26
27  return 0;
28}
```

Output

```text
Enter name: John
Enter roll: 213
Enter marks: 83
Name: John
Roll: 213
Marks: 83.00
```
