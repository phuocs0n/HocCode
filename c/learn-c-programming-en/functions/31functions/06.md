## Calling a Function (II)

This is how we call a function named sayHello:

```c
// Call a function
sayHello();
```

Let's see a complete example:

```c
1#include <stdio.h>
2
3// Define a function named sayHello
4void sayHello() {
5
6    printf("Hello");
7}
8
9int main() {
10
11  // Call the function
12  sayHello();
13
14  return 0;
15}
```

Output

```text
Hello
```
