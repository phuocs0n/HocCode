## Calling a Function

Defining a function is not enough, we have to call them.

Let's understand what this means by using the following example.

```c
1#include <stdio.h>
2
3// Define a function named sayHello
4void sayHello() {
5
6    // Print the text Hello
7    printf("Hello");
8}
9
10int main() {
11
12    return 0;
13}
```

If you run this code, you won't get any output. This is because a function definition by itself does nothing; we need to call the function whenever we need its functionality.

Next, we'll learn how to call a function.
