## Recap (I)

### Function

A function is a block of code put together that performs a specific task.

```c
1#include <stdio.h>
2
3// Function to print hello
4void sayHello() {
5
6  printf("hello\n");
7}
8
9int main() {
10
11  return 0;
12}
```

### Function Call

Defining a function won't do anything. We need to call the function to bring it into action.

```c
1#include <stdio.h>
2
3// Function to print hello
4void sayHello() {
5
6  printf("hello\n");
7}
8
9int main() {
10
11  // Function call
12  sayHello();
13
14  return 0;
15}
```
