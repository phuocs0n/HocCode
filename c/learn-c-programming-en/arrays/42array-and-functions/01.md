## Array Element as Function Argument

We can pass individual array elements to a function the same way we pass variables/values to functions.

Let's see an example:

```c
1#include <stdio.h>
2
3// Function to return the larger value
4int findLarger(int age1, int age2) {
5
6  // Compare two ages and return the larger age
7  if (age1 > age2) {
8    return age1;
9  }
10  else {
11    return age2;
12  }
13}
14
15int main() {
16
17  int ages[5] = {25, 31, 30, 17, 39};
18
19  // Call the function with second and fifth array element
20  int result = findLarger(ages[1], ages[4]);
21  printf("%d", result);
22 
23  return 0;
24}
```

Output

```text
39
```

Here, we have passed two array elements to the findLarger() function.

- age1 argument takes the value ages[1] (31)
- age2 parameter takes the value ages[4] (39)

The function then compares the two ages and returns the larger age. In our case, it's 39.
