## Compute Student Grade

```c
1#include <stdio.h>
2
3// Compute grade and return it
4char computeGrade(double averageScore) {
5
6    char grade;
7  
8    if (averageScore >= 80.0) {
9        grade = 'A';
10    }
11    else if (averageScore >= 60.0) {
12        grade = 'B';
13    }
14    else if (averageScore >= 50.0) {
15      grade = 'C';
16    }
17    else {
18        grade = 'F';
19    }
20
21    return grade;
22}
23
24int main() {
25
26    double averageScore = 67.80;
27
28    char grade = computeGrade(averageScore);
29    printf("%c", grade);  // Output: B
30
31    return 0;
32}
```

Here, the computeGrade() function computes the student's grade based on the average score and returns it.
