## Get Average Score

```c
1#include <stdio.h>
2
3// Find the average score and return it
4double getAverageScore(double scores[5]) {
5
6    double sum = 0;
7
8    // Find the sum
9    for (int i = 0; i < 5; ++i) {
10        sum = sum + scores[i];
11     }
12
13     // Calculate the average
14    double average = sum / 5;
15
16    return average;
17}
18
19int main() {
20
21    // An array of scores
22    double scores[5] = {55, 64, 75, 80, 65};
23
24    double averageScore = getAverageScore(scores);
25    printf("%.2lf", averageScore);
26
27    return 0;
28}
```

Output

```text
67.80
```

Here, the getAverageScore() function takes an array as an argument.

Inside this function, we have used a for loop to find the sum of all scores.

Then, we have computed the average by dividing the sum by 5 (number of array elements).

Next, we will use the average score to compute the student's grade.
