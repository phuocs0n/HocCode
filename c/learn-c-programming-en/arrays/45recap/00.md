## Recap (I)

Create an Array

An array is created by placing elements inside curly braces {}, separated by commas.

```c
1#include <stdio.h>
2
3int main() {
4
5    int numbers[5] = {1, 2, 3, 4, 5};
6
7    return 0;
8}
```

Access Array Elements

We use the array index to access array elements.

```c
1#include <stdio.h>
2
3int main() {
4
5  int numbers[5] = {1, 2, 3, 4, 5};
6
7  printf("Numbers: ");
8
9  for (int i = 0; i < 5; ++i) {
10    printf("%d  ", numbers[i]);
11  }
12
13  return 0;
14}
```
