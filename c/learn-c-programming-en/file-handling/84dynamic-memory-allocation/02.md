## Dynamic Memory Allocation

Let's first revise the concept of pointers with the help of this example.

```c
1#include <stdio.h>
2
3int main() {
4
5  // create a variable
6  int number = 36;
7
8  // create a pointer variable and
9  // assign the address of number to it
10  int* ptr = &number;
11
12  // print value of number using ptr
13  printf("%d", *ptr);    // 36
14
15  return 0;
16}
```

Here,

- &number - memory address of number
- int* ptr - pointer variable
- *ptr - gives the value pointed by the ptr pointer

Now, let's get back to dynamic memory allocation.

C provides three major library functions to perform dynamic memory allocation.

- malloc()
- realloc()
- free()

To use these functions, we must include the stdlib.h header file first.
