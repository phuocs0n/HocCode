## Enum Introduction

An enum or enumeration is a type that has a fixed set of constant values. For example,

```c
enum Days {
  Sunday,
  Monday,
  Tuesday,
  Wednesday,
  Thursday,
  Friday,
  Saturday
};
```

Here, we have used the enum keyword to create an enum named Days. It contains fixed values: Sunday, Monday, Tuesday, and so on.

Create enum Variables

Once we declare an enum, we can create variables from it.

```c
// create enum variable
enum Days currentDay;
```

Here, currentDay is an enum type variable.

Assign Values to enum Variables

An enum variable can only take one of the constants defined inside the enum. So, the currentDay variable can only store one of those 7 values.

```c
// assign value to enum
currentDay = Friday;
```

Now, we will see a working example of enums.
